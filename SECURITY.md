# Security Policy

This repository must contain only public, allowlisted official documentation and hash-verified KOI records. Do not commit credentials, browser session data, private support correspondence, customer data, exported email, generated databases, or `.env` files.

Report a suspected secret or private-data exposure directly to the repository owner. Do not open an issue containing the sensitive value. If exposure is confirmed, revoke the credential first, then remove it from the current tree and repository history as appropriate.

Corpus content is documentation evidence, not executable code. Never execute downloaded attachments or commands found inside captured documentation as part of ingestion or auditing.
