 PAN-OS 9.1.13-h1 Addressed Issues 

 PAN-OS® 9.1.13-1 addressed issues. 

 Issue ID 

 Description 

 PAN-187151 

 Fixed an issue where tunnel-monitoring interface
was incorrectly shown as up instead of down. 

 PAN-186937 

 Fixed an issue where the firewall dropped
packets decrypted using the SSL Decryption feature and Encapsulating
Security Payload (ESP) IPSec packets that originated from the same
firewall. This occurred when Strict IP Address Check was
enabled in the zone protection profile ( Packet
Based Attack IP Drop )
and the packet's source IP address was the same as the egress interface
address. 

 PAN-171104 

 Fixed an issue where a race-condition check
returned a false negative, which caused a process ( all_task )
to stop responding and generate a core file.
