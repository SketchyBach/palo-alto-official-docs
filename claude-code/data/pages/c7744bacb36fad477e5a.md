 Use these resources to get help with Strata Logging Service . 

 The following topics provide information on where to
find more about this release and how to request support:

 Related Documentation 

 Use the Administration Guide to learn how to
 deploy Strata Logging Service , begin sending logs from your on-premise
 firewalls to Strata Logging Service , and begin forwarding logs from Strata Logging Service to an external Syslog receiver. 

 Refer to the following documentation on the Technical Documentation
portal or search the documentation for more information on our products: 

 Panorama Administrator's Guide —Provides the basic
framework to quickly set up the Panorama™ virtual appliance or an
M-Series appliance for centralized administration of the Palo Alto
Networks firewalls. 

 PAN-OS Administrator's Guide —Provides the concepts
and solutions to get the most out of your Palo Alto Networks next-generation
firewalls. This includes taking you through the initial configuration
and basic set up on your Palo Alto Networks firewalls. 

 GlobalProtect Administrator’s Guide —Describes how to set up and manage GlobalProtect™ for
 PAN-OS 10.1 . 

 Prisma Access Getting Started Guide —Use the Prisma Access Administrator's
 Guide to set up your Prisma Access and realize the flexibility,
 convenience, and rapid time to value in securing your users everywhere. This
 guide includes information on how to use the Strata Logging Service 
 with the Prisma Access. 

 Cortex XDR —Use the Cortex XDR Administrator’s Guide for your license tier ( Prevent or Pro ) to learn how use Strata Logging Service with Cortex XDR and configure your Cortex XDR
 log quotas.
