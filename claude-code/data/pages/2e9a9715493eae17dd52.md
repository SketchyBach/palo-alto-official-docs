 dump probe config 

 Use the dump probe config command to display all the probe
 configurations for a device. 

 Command 

 dump probe config ( all | config ID = confID ) 

 Options 

 all Enter all to display the probe configurations. 

 config ID Enter the probe config ID to list details of the probe
 configuration like endpoints, protocol, probe duration, probe count,
 and path types. 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands NA 

 Introduced in Release 6.4.1 

 Example 

 dump probe config configid=1710934377425002537
Probe Config : test-https (1710934377425002537)
Enabled : false
Endpoints :
 Fqdn/URL : www.google.com
 Protocol : https
 Probe Cycle Duration : 5
 Probe Count : 5
 Path Types : vpn
 Http Response Codes : 
 Code : 200
 Http Response String : 
 Allow Insecure Https Connection : true
