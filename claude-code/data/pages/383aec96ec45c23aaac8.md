 Onboard a Microsoft Exchange App to SSPM 

 Connect a Microsoft Exchange instance to SSPM to detect posture risks. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 SaaS Security Posture Management license 

 Or any of the following licenses that include the Data Security license: 

 CASB-X 

 CASB-PA 

 We discontinued the separate Microsoft Exchange connector
 in March 2026, because the Microsoft Outlook connector now onboards
 both Microsoft Outlook and Microsoft Exchange. The new Microsoft Outlook connector
 leverages the deep integration between Microsoft Outlook and Microsoft Exchange to
 scan both of these product instances. For this reason, the separate Microsoft
 Exchange connector is no longer necessary. 
 Previously, you could onboard Microsoft
 Exchange by supplying account credentials to SSPM. If you already connected SSPM
 to your Microsoft Exchange instance by using this earlier connector, your
 established connection will continue to work. However, if there is any change to
 the configuration information that you provided to SSPM (such as an updated
 login password), you will need to onboard both Microsoft Outlook and Microsoft
 Exchange by using the Microsoft Outlook connector .
