 Configure Identity and Access Management 

 Configure IAM roles and permissions for Prisma AIRS AI Skill Security, including
 custom roles creation and API access setup with minimum required permissions for SDK
 usage. 

 Where Can I Use This? What Do I Need? 

 Prisma AIRS (AI Skill Security) 

 No License required for preview 

 If you have an active deployment profile but lack IAM
 permissions for AI Skill Security, it may result in user authentication error. Hence
 it is important to have an active deployment profile and IAM permission to access AI
 Skill Security. 

 Navigate to Strata Cloud Manager Identity and Access Management (IAM) settings, Common Services Identity & Access . 

 Navigate to Identity & Access Access Management and select the tenant from the tenants list. Verify the
 Identity Information for the selected tenant to
 ensure that the Role assigned is either
 Superuser for all apps and services, or a custom role
 with access to AI Skill Security.
