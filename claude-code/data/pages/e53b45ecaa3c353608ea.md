 inspect vpn status 

 Use the inspect vpn status command to inspect the VPN status and
 view the Authenticated Encryption with Associated Data (AEAD) algorithm used. 

 Command 

 inspect vpn status ( all | VpnID = VPN ID ) 

 Options 

 all Enter all to display the status for all the VPN paths
 for a device. 

 vpn-id Enter the VPN ID to display the status for a specific
 VPN path. 

 Command Notes 

 Role Super, Read Only 

 Related Commands — 

 Introduced in Release 6.5.1 

 Example 

 inspect vpn status VpnID=1717665231673020628
