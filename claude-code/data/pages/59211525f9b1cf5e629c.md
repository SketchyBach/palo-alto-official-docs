Zscaler Guide

Easily integrate Koi with Zscaler ZIA using proxy chaining

This guide explains how to integrate Koi with Zscaler ZIA using proxy chaining to direct marketplace traffic to Koi's proxy. Follow the steps below to ensure a smooth and secure configuration.

Prerequisites

Before starting the integration, make sure you have the following:

Access to Zscaler ZIA Panel.

Organizational Root Certificate Authority (CA): Ensure it is installed and trusted by your organization's devices.

List of Marketplace Domains: See Marketplace domains.

Proxy IP Address/FQDN + Port: Provided by Koi.

Signed Certificate: The CSR provided by Koi has been signed with your root CA.

Zscaler Advanced Firewall license, or other tier that supports proxy chaining

Steps to Integrate
1. Upload Your CA to Zscaler

If organizational CA is already uploaded to Zscaler skip to step 2.

Navigate to Zscaler ZIA Panel.

Navigate to Administration → Root Certificates.

Add a new CA:

Choose Add Root Certificate (top-left corner).

Fill in the following attributes:

Name: Assign a descriptive name

Type: Choose Proxy Chaining

Content: Choose the CA .pem file you used to sign Koi CSR

Click Save.

2. Create a Proxy Item

Navigate to Administration → Proxies & Gateways → Proxies (tab).

Add a new proxy:

Choose Add Proxy (top-left corner).

Fill in the following attributes:

Proxy Name: Assign a descriptive name, such as Koi Proxy

IP Address / FQDN: Provided by Koi

Port: Provided by Koi

Proxy’s Root Certificate: Choose the organizational CA you used to sign Koi CSR

Insert X-Authenticated-User: Make sure the toggle is on

Enable Base64 Encoding for X-Authenticated-User value: Turn off

Save the Proxy.

3. Create a Proxy Gateway

Go to Administration → Proxies & Gateways → Proxy Gateways (tab).

Add a new gateway:

Choose Add Gateway for Proxies (top-left corner).

Fill in the following attributes:

Gateway Name: Assign a descriptive name, such as Koi Gateway

Fail Close: Leave it on

Primary Proxy: The name of the proxy you created in Step 1

Secondary Proxy: Leave it as None

Save the gateway.

4. Create a Forwarding Control Policy

Navigate to Policy → Forwarding Control.

Click on Add a Policy.

Add a Forwarding Rule:

Choose Add Forwarding Rule (top-left corner).

Fill in the following attributes:

Rule Name: Assign a descriptive name, such as Koi Forwarding

Rule Order: Highest priority possible

Rule State: Enabled

Forwarding Method: Proxy Chaining

Navigate to the Destination tab.

Enter the given list of marketplace domains.

Click Add Items.

In the Action section, choose the name of the gateway you created in Step 2.

5. Activate Your Changes

Hover over Activation button (on the sidebar).

Click Activate to apply your changes.

Summary

By completing these steps, you have successfully configured Zscaler ZIA to integrate with Koi. This integration ensures that all marketplace traffic is securely directed to Koi's proxy for enhanced security and control.
