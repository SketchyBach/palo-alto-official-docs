 Editing Built-in Accounts 

 You can update any of the following settings of an existing built-in account: 

 Change its name 

 Choose a different owning team 

 Change the scope assignment 

 Change the validity period 

 Replace the private key 

 To Edit Settings of an Existing Built-in Account 

 Sign in to Next-Gen Trust Security. 

 Click System Settings > Certificate Settings > Built-in Accounts . 

 Find the built-in account you want to edit and click its name. 

 Make the changes you want to make and then click Save .
