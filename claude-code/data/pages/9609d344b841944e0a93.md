 dump network-policy config policy-sets 

 Use the dump network-policy config policy-sets command
to display the current details of a device interface. 

 Information
displayed includes the name of the policy set and the policy set
ID. 

 Command 

 dump network-policy config policy-sets all

 Options 

 None 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands — 

 Introduced in Release 5.0.1 

 Example 

 dump network-policy config policy-sets all
 Network Policy Set : 15306005116850233 : DFR-1
 Network Policy Set : 15282771307010195 : Policy Set-1
