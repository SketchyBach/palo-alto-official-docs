 getCorrelationRules 

 Gets a list of correlation rules. Filter arguments support both a single string and a comma-separated list of strings. 

 Arguments 

 Argument Name 

 Description 

 Required 

 rule_id 

 The id(s) of the correlation rule(s). 

 Optional 

 name 

 The name of the correlation rule. 

 Optional 

 severity 

 The severity level. Supports predefined values or the 'SEV_XXX_NAME' format (e.g., SEV_050_CRITICAL). Possible values are: info, low, medium, high, critical, unknown. 

 Optional 

 xql_query 

 The XQL query of the correlation rule. 

 Optional 

 is_enabled 

 Whether the rule is enabled. Possible values are: true, false. 

 Optional 

 dataset 

 The dataset for the correlation rule. 

 Optional 

 alert_name 

 The alert name generated by the rule. 

 Optional 

 alert_category 

 The alert category. 

 Optional 

 alert_fields 

 The alert fields. 

 Optional 

 alert_domain 

 The alert domain. 

 Optional 

 filter_json 

 A JSON string representing filter conditions. 

 Optional 

 extra_data 

 Whether to include extra data in the response. Possible values are: true, false. 

 Optional 

 limit 

 The maximum number of results to return. 

 Optional 

 page_size 

 The number of results per page. 

 Optional 

 page 

 The page number to retrieve. 

 Optional 

 Outputs 

 Core.CorrelationRule.rule_id number 

 The unique identifier of the correlation rule. 

 Core.CorrelationRule.name string 

 The name of the correlation rule. 

 Core.CorrelationRule.severity string 

 The severity of the correlation rule. 

 Core.CorrelationRule.is_enabled boolean 

 Whether the rule is enabled. 

 Core.CorrelationRule.description string 

 The description of the correlation rule. 

 createCorrelationRule

 Argument Name 

 Description 

 Required

 The name of the correlation rule.

 deleteCorrelationRule 

 Deletes one or more correlation rules by ID. Deleting a rule stops it from generating any further issues. 

 Arguments 

 Argument Name 

 Description 

 Required 

 rule_id 

 A comma-separated list of correlation rule IDs to delete. 

 Required 

 Outputs

 getContributingEvents 

 Returns the contributing events for the specified correlation alerts. 

 Arguments 

 Argument Name 

 Description 

 Required 

 alert_ids 

 A comma-separated list of correlation alert IDs from which to retrieve the contributing events. Large lists may take longer to complete. 

 Required 

 limit 

 The maximum number of contributing events to retrieve per alert. Default is 50. 

 Optional 

 page_size 

 The number of contributing events to return per page, per alert. When set, manual pagination is used and limit is ignored. 

 Optional 

 page 

 The page number to return, per alert, starting from zero. When set, manual pagination is used and limit is ignored. 

 Optional 

 Outputs 

 Core.ContributingEvent.alertID string 

 The correlation alert ID. 

 Core.ContributingEvent.events unknown 

 The contributing events for the alert.
