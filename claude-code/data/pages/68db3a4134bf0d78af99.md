 Configure DSCP 

 Lets learn on configuring DSCP in Prisma SD-WAN . 

 Where Can I Use
 This? What Do I Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 Quality of Service (QoS) policies allow you
to specify differentiated services code point (DSCP) values, priority, and
traffic type. You can define DSCP mapping in any policy set, but
only the first match is used for a decision. The order of DSCP mapping
lookup is the same as a policy set order. 

 If an application
traffic flow matches any two rules defined in the default rule policy
set and matches the DSCP value defined in DSCP mapping, the flow
is placed in the priority queue and transfer type specified in the
DSCP map. The table below shows the mapping of DSCP values, priority,
and traffic type. 

 DSCP Values Priority Traffic Type 

 EF Platinum Audio 

 AF41, AF31 Gold Video 

 CS6 Platinum Transactional 

 AF21 Silver Transactional 

 AF11 Bronze Bulk 

 Select Configuration Prisma SD-WAN Policies QoS QoS Stacks Advanced QoS Sets . 

 For a QoS Set , click the ellipsis menu. 

 Select DSCP Configuration . 

 On the DSCP Mappings screen, enter DSCP
Hex values . 

 You can select up to 16 DSCP values from the available
list. 

 Select a Priority and the type
of traffic from the Transfer Type drop-down. 

 (Optional) Click Add Configuration to
define additional DSCP configurations, if required. 

 Save & Exit .
