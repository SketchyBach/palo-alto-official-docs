 High Availability for Cortex XSOAR 

 Documentation for Cortex XSOAR On-prem 8.5 (EoL). 

 Coming soon, if you deploy a cluster of three nodes you can implement built-in High Availability (HA). A cluster of three nodes will enable distributing the workload and replicating data across the nodes to ensure continuous operation. If one node fails, the remaining nodes will take over the tasks and data handling, minimizing downtime and maintaining service availability. This setup will allow for redundancy, enhancing the overall resilience of the system.
