 OCI security group allows unrestricted ingress access to port 22 misconfiguration detected in code 

 Rule Details 

 Cortex AppSec Rule ID 

 APPSEC_OCI_22 

 Category - Subcategory 

 Public Exposure - Sensitive Ports 

 Provider 

 ORACLE 

 Severity 

 LOW 

 Framework 

 Terraform 

 Impact 

 Security groups are stateful and provide filtering of ingress/egress network traffic to OCI resources. We recommend that security groups do not allow unrestricted ingress access to port 22. Removing unfettered connectivity to remote console services, such as SSH, reduces a server's exposure to risk. 

 How to Fix 

 [source,go] 

 resource "oci_core_network_security_group_security_rule" "pass" { ... direction = "INGRESS" protocol = "all" source = "0.0.0.0/0" 

 tcp_options { destination_port_range { 

 max = 25 

 min = 25 

 max = 22 

 min = 22 } } }
