 information about endpoint OS compatibility.

Software or Content Release Version

 GlobalProtect 6.1 and requires PAN-OS 11.0 and above. You cannot
 disable End-user Notification about GlobalProtect Session Logout
 unless the PAN-OS version is 11.0 or above.
