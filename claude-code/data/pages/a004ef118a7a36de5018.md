 Alibaba Cloud cloud onboarding 

 Onboard Alibaba Cloud 

 Follow the Alibaba Cloud onboarding wizard and Cortex Cloud creates a custom CloudFormation authentication template to be deployed in Alibaba Cloud. 

 Use the cloud onboarding wizard to integrate an Alibaba Cloud environment with Cortex Cloud. The onboarding wizard requires minimal configuration to set up the integration. You can optionally define the scope of the Alibaba regions and have tags automatically added to any new resources created by Cortex Cloud. 

 Cortex Cloud generates a Terraform authentication template based on the configuration settings. The authentication template grants required permissions to Cortex Cloud. Execute the authentication template in Alibaba Cloud and then manually connect the cloud instance to complete the onboarding process.
