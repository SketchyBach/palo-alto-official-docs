 Manage content using a remote repository 

 Use a remote repository to manage and propagate Cortex XSOAR 8 SaaS multi-tenant content. 

 If you are working with remote repositories, and want to use selective propagation to add propagation labels to content, you need to follow the steps described in this task. 

 Before you begin, if you haven't done so already, set up a remote repository, as described in Step 5. Set up a remote repository . 

 In the development environment, do the following. 

 Add propagation labels to content as needed. 

 Push content to the production tenant. 

 For more information, see Push content from a development tenant 

 Propagation labels added to content on your development tenant appear when pushing content to production 

 In the production tenant, do the following: 

 Install the content that is pushed from the development tenant. For more information, see Install content on a production tenant . 

 Confirm that the propagation labels were added to the content and that the labels are available for use, by going to Settings & Info → Settings → Tenant Management. 

 Add propagation labels to child tenants. For more information, see Add propagation labels to a child tenant . 

 Sync content to child tenants. For more information, see Sync content to child tenants .
