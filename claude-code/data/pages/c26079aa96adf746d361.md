 Configure Equipment Objects and Equipment Group Objects 

 Configure equipment and equipment group objects for policy rules. 

 Where Can I Use
 This? What Do I Need? 

 NGFW (PAN-OS & Panorama Managed) 

 GTP Security must be enabled on the
 firewall. 

 All Gen 3–5 hardware platforms, VM-Series, and
 CN-Series. See the Compatibility Matrix
 for the GTP supported platforms . 

 Use equipment objects to represent mobile network devices by name in security
 policy rules. Equipment objects can match a single IMEI, a range of IMEI values, or
 an IMEI prefix. Equipment group objects collect multiple equipment objects so that
 a single policy rule can cover a defined set of devices. 

 Configure an Equipment Object (Single IMEI) 

 Select Objects Mobile Networks Equipment . 

 Click Add . 

 Enter a Name for the equipment object. 

 (Optional) Enter a Description . 

 Set Type to IMEI . 

 Enter the IMEI value (15 or 16 digits). 

 Click OK . 

 Configure an Equipment Object (IMEI Range) 

 An IMEI range matches any IMEI value between a specified start and end. The range
 is defined from digit 6 through digit 16. 

 Select Objects Mobile Networks Equipment . 

 Click Add . 

 Enter a Name for the equipment object. 

 (Optional) Enter a Description . 

 Set Type to IMEI Range . 

 Enter the Start IMEI value and the
 End IMEI value. 

 Example: 

 Start: 4002223008001000 

 End: 4002223009505000 

 Click OK . 

 Configure an Equipment Object (IMEI Prefix) 

 An IMEI prefix matches any IMEI that begins with the specified digits. The prefix
 can start from digit 6 and must end with a * wildcard. 

 Select Objects Mobile Networks Equipment . 

 Click Add . 

 Enter a Name for the equipment object. 

 (Optional) Enter a Description . 

 Set Type to IMEI
 Prefix . 

 Enter the prefix value followed by *. 

 Example: 

 353234121* — matches all IMEIs beginning with
 353234121 

 35323412122* — matches all IMEIs beginning with
 35323412122 

 Click OK . 

 Configure an Equipment Group Object 

 An equipment group object references one or more equipment objects. Use
 an equipment group object in a security policy rule when you want a single rule
 to match a defined set of devices. 

 Select Objects Mobile Networks Equipment Group . 

 Click Add . 

 Enter a Name for the equipment group. 

 (Optional) Enter a Description . 

 In the Equipments field, add the equipment objects
 to include in the group. 

 Click OK . 

 Commit the configuration. 

 Verify Equipment Configuration 

 Use the following CLI commands to verify your
 equipment objects and
 groups: 

 show mobile-network equipment <equipment-name> 
show mobile-network equipment-group <group-name>
