Private Items Scan

Private Items Scanning extends Koi's risk engine to internally developed artifacts. Upload private AI Skills or Chrome Extensions to receive a content-based security assessment, helping identify risky behaviors, insecure implementations, and other security findings before distributing them across your organization.

Currently, Private Items Scanning supports AI Skills (SKILL.md) and Chrome Extensions(.zip file).

How It Works

Navigate to Threat Intel → Private Items.

Click Upload.

Select the item type:

Skill

Chrome Extension 

Upload the relevant file:

Skill: SKILL.md

Chrome Extension: Extension package (ZIP)

Click upload to start Koi risk engine analysis

Koi's Wings engine analyzes the uploaded item, which then appears in the Private Items table with its risk assessment

Note: Newly uploaded items initially appear with a Pending status while the scan is in progress. Once analysis completes, the status changes to Completed.

Skills Inventory Correlation

For AI Skills, Koi automatically correlates uploaded private skills with skills discovered on managed endpoints.

When Koi discovers a skill on a managed device:

If it matches a previously uploaded private skill, the discovered inventory item inherits the uploaded skill's risk assessment.

The same findings and risk score become available directly from the Skills inventory.

Users can investigate discovered skills without needing to upload them again.

If a discovered skill has not been uploaded previously, it appears as an unknown private skill with no associated risk assessment. After the skill is uploaded and scanned, Koi matches it to the discovered inventory item during the next MDM sync and displays the scan findings in the Skills inventory.

Private Items Scanning is also available through the Koi API, allowing you to upload items, retrieve scan results, and manage your private items programmatically.

For API endpoints and usage examples, see the Private Items API Documentation.
