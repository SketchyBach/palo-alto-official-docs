 Run a Script using an Engine 

 Run scripts using engines in Cortex XSOAR 6.13. 

 You can run a script on an engine or load-balancing group to distribute the workload and improve performance. 

 On the Automations page, select the automation and click the Settings button. 

 In the Run on section, select either a single engine or a load-balancing group. 

 The option to select an engine or load-balancing group only appears if at least one engine or load-balancing group is connected. 

 From the drop-down, select the name of the engine or load-balancing group. 

 Click Save .
