 During the onboarding process for most applications, SSPM establishes a connection to
 your SaaS app instance by using credentials that you provide, such as a login password
 or an access token. After SSPM has established this connection, SSPM can scan the SaaS
 app instance's settings by using an API provided by the SaaS app or by using data
 extraction techniques. 

 SSPM also provides support for the following SaaS apps through a manual workflow. When
 you onboard the following SaaS apps to SSPM, you don’t supply SSPM with authentication
 credentials. SSPM does not establish a connection to the SaaS app. Instead, you manually
 enter the SaaS app settings, which SSPM will compare against its recommended
 settings.
