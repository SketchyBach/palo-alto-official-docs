 Increase the CPUs and Memory for Panorama on Oracle Cloud
Infrastructure (OCI) 

 Increase the CPUs and memory for a Panorama™ virtual
appliance deployed on Oracle Cloud Infrastructure (OCI). 

 You can change the instance type of the Panorama™
virtual appliance to increase the CPUs and memory allocated to the
Panorama virtual appliance instance. Be sure to review the Setup Prerequisites for the Panorama Virtual Appliance before
modifying the Panorama virtual appliance instance CPUs and memory. 

 Log in to the Oracle Cloud Infrastructure console. 

 Power off the Panorama virtual appliance instance. 

 Select Compute Instances and click the name
of the Panorama virtual appliance instance. 

 Stop the Panorama virtual appliance
instance. 

 Increase the CPUs and memory. 

 In the instance details, select Edit Edit Shape . 

 Increase the number of CPUs and memory allocated to
the instance. 

 Save Changes . 

 In instance details, Start the
Panorama virtual appliance. 

 Verify the increased CPU and memory. 

 Log in to the Panorama CLI . 

 View the Panorma virtual appliance system information. 

 admin> show system info 

 Verify that the num-cpus and ram-in-gb display
the correct number of CPUs and amount of memory as per the instance
type you selected.
