 Use the Prisma Agent to Access Your Projects 

 Learn how to use Prisma Agent to access your organization's
 project-specific applications and resources, SaaS applications, or the internet. 

 Where Can I Use This? What Do I Need? 

 Prisma Agent 

 macOS 14 and later or Windows 10 version 2024 and later desktop devices 

 Internet access 

 If your organization is an IT or IT Enabled Services (ITES) company that needs to control
 which users have access to their customer projects, Dynamic Privilege Access provides a
 seamless, secure, and compartmentalized way for you to access only those projects that
 are assigned to you. 

 If your administrator has set up Prisma Access and the Prisma Agent for
 Dynamic Privilege Access, you can use the Prisma Agent to access and work
 on the projects that you are assigned to. 

 After you log in to your project, you can access your organization's network, resources
 in the network, or software-as-a-service applications that are specific to the project.
 Learn how to: 
 Log in to the Dynamic Privilege Access enabled Prisma Access Agent 

 View the status of your
 connection 

 Change preferences for the Dynamic Privilege
 Access enabled Prisma Access Agent 

 Connect to a different Prisma Access
 location 

 View app notifications 

 In addition, if you are assigned to work on different projects, you can switch to a different project or connect the Prisma Access Agent to a different
 server .
