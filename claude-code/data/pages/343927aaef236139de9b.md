 DNS Security (Resolver and SDWAN and Panos 12.1 or later) 

 DNS Security logs contain information that the DNS Security service collects, such as
 server response and request information based on your firewall security policy
 rules, associated action, and the DNS query details when performing domain
 lookups. 

 See the following for information related to supported log formats:
