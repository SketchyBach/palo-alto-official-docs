 Approaching Max Capacity - Address Objects 

 Incident Code 

 INC_NGFW_CAPACITY_ADDRESS_OBJECTS 

 Severity 

 Warning 

 Category 

 Device 

 Subcategory 

 System Resources 

 Product 

 Supported on NGFWs and VM-Series firewalls. 

 Description 

 The number of address objects has been consistently high and is approaching the maximum capacity the firewall can support. 

 Raise Condition 

 This incident is triggered when Address Objects usage exceeds 90% of the capacity of that respective firewall model and the number of available Address Groups is less than 5000 , with both of these states persisting for five or more days in past seven days. 

 Clear Condition 

 This incident is cleared when Address Objects usage is less than 90% of the capacity of that respective firewall model and the number of available Address Groups is more than 5000 , with both of these states persisting for two weeks.
