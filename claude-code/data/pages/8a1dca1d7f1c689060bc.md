 ServiceNow CloudBlade Integration 

 Learn about the ServiceNow CloudBlade integration release notes. 

 Prisma SD-WAN introduces the ServiceNow CloudBlade which is used
 to translate events raised on Prisma SD-WAN into incident tickets on ServiceNow. Once a
 ticket is created in ServiceNow, it ensure that the IT Operations team has a seamless
 process to check network conditions and take immediate action for remediation. 

 ServiceNow CloudBlade Version 1.7.1 

 The 1.7.1 version of the ServiceNow CloudBlade includes improved infra related bug
 fixes, and supports the following new Events. 
 DEVICEHW_TEMPERATURE_SENSOR 

 DEVICESW_CONCURRENT_FLOW_SOFTLIMIT_EXCEEDED 

 USER_ID_DIRECTORY_SYNC_FAILED 

 USER_ID_HUB_SELECTION_FAILED 

 ServiceNow CloudBlade Version 1.6.1 

 This topic contains the new/updated features in the ServiceNow CloudBlade Version
 1.6.1. 

 New/Updated Features 

 The version 1.6.1 ServiceNow CloudBlade supports the following new Events 
 HUB_CLUSTER_SITE_COUNT_THRESHOLD_EXCEEDED 

 DEVICE_CELLULAR_FIRMWARE_NOT_AVAILABLE 

 DEVICE_CELLULAR_INTERNAL_MODEM_ERROR 

 DEVICE_CELLULAR_MODEM_TEMP_HIGH 

 DEVICE_CELLULAR_MTU_MISMATCH 

 DEVICE_CELLULAR_ROAMING 

 DEVICE_CELLULAR_SIGNAL_STRENGTH_THRESH 

 DEVICE_CELLULAR_SIM_PIN_ERROR 

 DEVICE_CELLULAR_SIM_PUK_NEEDED 

 DEVICE_CELLULAR_SIM_REMOVAL 

 DEVICE_CELLULAR_SIM_SECURITY_ERROR 

 DEVICE_CELLULAR_SIM_SWITCHOVER 

 An incident on ServiceNow is updated any time there is an update to the following
 Prisma SD-WAN event parameters: 
 acknowledged 

 suppressed 

 notes 

 cleared
