 Domain Categories 

 The Advanced DNS Security Resolver a cloud-delivered, AI-powered security service
 that categorizes traffic. 

 Where Can I Use
 This? What Do I Need? 

 Strata Cloud Manager 

 Advanced DNS Security Resolver License 

 The Advanced DNS Security Resolver provides domain categories that can be configured with various
 actions, when a corresponding domain type is encountered. The following table describes
 the currently available domain categories, based on the available signature sources. 

 Content-based DNS signatures are used to identify and categorize DNS requests and are
 generated using data from Advanced WildFire, Advanced URL filtering, passive DNS,
 machine learning, threat research from Unit 42, as well as third-party threat feeds.
 These on-demand signatures (automatically updated and immediately available on your
 tenant) complement the more advanced, ML-based, real-time DNS threat detection mechanism
 of Advanced DNS Security.
