 Code Sign Client 

 The Code Sign Client connects your organization's signing workstations to signing keys managed by the code signing capability. After downloading and installing the client, you authenticate using a built-in account. Once authenticated, you can list the keys and certificates available to you and begin using them to sign. 

 For installation and configuration steps, see Install and configure the Code Sign Client . 

 For CLI reference details and sample integrations, see Dev Central .
