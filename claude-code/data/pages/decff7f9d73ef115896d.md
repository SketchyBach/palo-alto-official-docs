 Downgrade a Windows Agent from PAN-OS 9.1 

 Downgrade a Windows Agent. 

 After you uninstall the PAN-OS 9.1 Windows-based User-ID
agent, perform the following steps before you install an earlier
agent release. 

 Open the Windows Start menu and select Administrative
Tools . 

 Select Computer Management Services and Applications Services and
double-click User-ID Agent . 

 Select Log On , select This account ,
and specify the username for the User-ID agent account. 

 Enter the Password and Confirm
Password . 

 Click OK to save your changes.
