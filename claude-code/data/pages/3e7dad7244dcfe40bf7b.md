 M-200 and M-600 Electrical Specifications 

 Learn about the M-200 and M-600 appliance electrical
specifications. 

 The following table describes M-200 and M-600 appliance
electrical specifications. 

 Specification 

 Value 

 Power Supplies 

 M-200 and M-600 appliances —Two 750W AC
power supplies; the second power supply is for redundancy. 

 Input voltage and frequency 

 M-200 and M-600 appliance —100-240VAC (50-60Hz) 

 Power consumption 

 M-200 appliance —330W 

 M-600 appliance —486W 

 Maximum current consumption 

 M-200 and M-600 appliance —9.5A@100VAC,
4.5A@240VAC 

 Maximum inrush current (per power supply) 

 M-200 appliance —35A 

 M-600 appliance —35A
