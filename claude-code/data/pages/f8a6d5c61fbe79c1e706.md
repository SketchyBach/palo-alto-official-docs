 Enhanced Tracking Protection 

 Enhanced Tracking Protection control 

 Where Can I Use This? What Do I Need? 

 This feature allows you to manage tracking protection and cross sight tracking. 

 From Strata Cloud Manager , select Configuration Policy Control Sets Browser Security Privacy 

 Select Enhanced Tracking Protection . 

 Select one of the following options: 

 Enable Tracking Protection - Automatically block
 transfers. 

 Disable Tracking Protection - Allow trackers across all
 sites. 
 Exclude specific domains - When you select
 either option above, you can select certain specific domains that
 will be ignored. For example, excluding a domain when you Enable
 tracking protection means that the selected domain will allow the
 trackers for that domain. 

 Click Set .
