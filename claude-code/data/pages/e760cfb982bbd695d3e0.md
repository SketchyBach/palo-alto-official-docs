 DNS Proxy Overview 

 Network > DNS Proxy 

 DNS servers perform the service of resolving a domain
name with an IP address and vice versa. When you configure the firewall
as a DNS proxy, it acts as an intermediary between clients and servers
and as a DNS server by resolving queries from its DNS cache or forwarding
queries to other DNS servers. Use this page to configure the settings
that determine how the firewall serves as a DNS proxy.
