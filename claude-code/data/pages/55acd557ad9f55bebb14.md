 IBM Maximo Attribute Reference 

 This reference lists the attributes that Device Security collects from IBM Maximo,
 their names as stored in Device Security , and the Device Security device fields
 they map to.

 Device Security integrates with IBM Maximo to enrich the device inventory with
 enterprise asset management data. The attributes in this reference cover device
 identification, hardware, and configuration data collected from IBM Maximo
 asset records. 

 The third-party attribute name in Device Security refers to the attribute name
 as it appears in the Assets Inventory table and in Query Engine. This follows the format
 of third-party-name . attribute-name .
 When viewing the attribute name in the Assets Inventory table column selector or on a
 Device Details page, where the third-party name can be found as a header for the
 attributes section, then the third-party name is removed from the attribute name.

 For example, micrsoft_defender_xdr.macAddress would appear in the
 Query Builder and in the Assets Inventory table, but under Device Details Attributes Integration Specific Attributes Microsoft Defender , the attribute would appear as macAddress .

 Device Attributes 

 Device Security collects device attributes from the IBM Maximo asset management
 API, which provides detailed asset records including hardware specifications, network
 configuration, and lifecycle information stored as asset specification (assetspec)
 fields. The following table lists each IBM Maximo attribute, its name as stored in
 Device Security , the Device Security device field it maps to (if applicable),
