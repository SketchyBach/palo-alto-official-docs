 Simplified Application Dependency Workflow 

 Provides access to find and manage application dependencies. 

 You now have simplified workflows to find
and manage any application dependencies. These workflows allow you
to see application dependencies when you create a new Security policy
rule and when performing Commits. When a policy does not include
all application dependencies, you can directly access the associated
Security policy rule to add the required applications. 

 Using
these workflows along with Policy Optimizer , you
can now more easily identify, organize, and resolve application
dependencies. You can take advantage of the new workflows by upgrading
your Panorama management server to 9.1 and pushing rules to your
firewalls. Resolve Application Dependencies provides
detailed steps. 

 Create a security policy rule . 

 Specify the application that the rule will allow or block. 

 Click OK and Commit your
changes. 
 Review any Commit warnings in the App
Dependency tab. 

 Select the Rule name to open
the policy and add the dependencies. 

 Click OK and Commit your changes.
