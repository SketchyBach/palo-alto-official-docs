 Commit Your Panorama Configuration Changes 

 Best practices for committing configuration changes management
on the Panorama™ management server. 

 Panorama provides many ways for you to control
the commit process. It is worthwhile to understand what they are
and adopt them in your day-to-day operations. 

 When you commit Panorama configuration
changes , select Commit Changes Made by to
only commit your own changes and not commit configuration changes
made by other admins. This ensures other configuration changes that are
in progress or not yet approved are not erroneously committed to Panorama. 

 When committing configuration changes, require admins to Preview
Changes and review the change summary. A visual check
of the configuration changes often helps catch mistakes and saves
time in operational maintenance later.
