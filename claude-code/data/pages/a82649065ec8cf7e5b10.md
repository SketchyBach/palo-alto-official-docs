 Allowed List of IP Addresses for SaaS Agent Security 

 The following list of IP addresses have to be added to the allowed list so that NGFW or Prisma Access tenants don't block SaaS Agent Security . 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 SaaS Agent Security license 

 Or any of the following licenses that include the SaaS Agent Security license: 

 CASB-X 

 CASB-PA 

 SaaS Security Posture Management license 

 Add the following region-specific IP addresses to the allowed list on your: 
 Agent platform instance's IP Allow-list (for example Salesforce Agentforce) 

 NGFW or Prisma Access tenant 
 Doing so ensures that these IP addresses are not blocked.
