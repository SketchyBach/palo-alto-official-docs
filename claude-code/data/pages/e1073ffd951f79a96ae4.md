 WildFire Canada Cloud 

 A new Wildfire regional cloud is now available
in Canada. The WildFire Canada cloud provides the best of both worlds
for our Canadian customers. Customers can now utilize the WildFire
cloud-based threat analysis and prevention engine, while ensuring
that files submitted for analysis stay in the country to address
data location concerns. Note that certain metadata connected to
submitted samples, as described in the WildFire Privacy Datasheet ,
are shared with our other regional clouds. While submissions stay
within Canadian borders, Canadian customers still benefit from the
global security intelligence and updates based on the network effect
of Palo Alto Networks 42,000+ WildFire customers. Sensitive data
and submissions are restricted from leaving Canada when using the
WildFire cloud threat analysis service. Samples submitted to the
WildFire Canada cloud and the resulting malware analysis, signature
generation and delivery occur and remain within Canadian borders. 

 Any
firewall with basic WildFire service enabled
can forward PE (portable executables) samples to the WildFire Canada
cloud, while users with an active WildFire subscription can forward
all supported file types .
Additionally, you can access the WildFire Canada portal using your
support account credentials to manually upload files for analysis
and view WildFire analysis reports. 

 You can submit samples
to the WildFire Canada cloud from the firewall, WildFire appliance,
WildFire Canada portal, and using the WildFire API. 

 Submit samples to the WildFire Canada
cloud From the firewall. 

 Log in to the firewall and select Device
> Setup > WildFire and edit General Settings . 

 Enter the URL for the WildFire Canada cloud: ca.wildfire.paloaltonetworks.com 

 Click OK to save your settings. 

 Submit locally-discovered malware or sample reports to
the WildFire Canada cloud For additional analysis. 

 Enable a WildFire appliance to submit locally-discovered
malware or sample reports to the WildFire Canada cloud for additional
analysis and signature distribution: 

 Connect the WildFire
appliance to the WildFire Canada cloud by entering the following
command from the WildFire appliance CLI: 

 admin@WF-500# set
deviceconfig setting cloud-server ca.wildfire.paloaltonetworks.com 

 Enter the following command to submit malware to the WildFire
Canada cloud: 

 admin@WF-500# set
deviceconfig setting wildfire cloud-intelligence submit-sample yes 

 Manually submit samples to the WildFire Canada cloud
using the WildFire Canada portal. 

 You can manually submit samples to the WildFire Canada
cloud using the WildFire Canada portal: https://ca.wildfire.paloaltonetworks.com. 

 After
uploading files or URLs to the WildFire Canada portal, you can also
view the WildFire analysis verdict and report for the sample. 

 Submit samples through the WildFire API 

 Use the following resources to submit samples through the
WildFire API to the WildFire Canada cloud: 

 Submit
a file: https://ca.wildfire.paloaltonetworks.com/publicapi/submit/file 

 Submit a file through a URL: https://ca.wildfire.paloaltonetworks.com/publicapi/submit/url 

 Submit a URL: https://ca.wildfire.paloaltonetworks.com/publicapi/submit/link 

 Submit multiple URLs: https://ca.wildfire.paloaltonetworks.com/publicapi/submit/links 

 To
get information about your file submissions to the WildFire Canada
cloud, you must also use the base URI that corresponds to the WildFire
Canada cloud. Example: 
 https://ca.wildfire.paloaltonetworks.com/publicapi/get/verdict
