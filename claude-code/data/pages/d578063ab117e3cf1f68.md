 debug speedtest interface 

 Use the debug speedtest interface command line interface for
 testing internet bandwidth using speedtest.net. 

 Command 

 debug speedtest interface | interface name | verbose | bytes 

 Options 

 verbose Enter verbose to view the detailed information about
 the bandwidth test. 

 interface Enter interface name (mandatory) ION interface to
 select from. (Only wan interface). 

 bytes Enter bytes to view the values in bytes instead of
 bits. 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands 

 dump speedtest status 

 Introduced in Release 6.3.6 

 Example 

 debug speedtest interface controller1 1
