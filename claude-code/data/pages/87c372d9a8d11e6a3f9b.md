 dump routing vpn host tracker 

 Use the dump routing vpn-host-tracker command to display the
 routing configurations and status for VPN Host Reachability Tracking, you can
 effectively monitor LAN connections with a tracker that provides consistent
 connectivity. 

 Command 

 dump routing vpn-host-tracker (config | status) 

 Options 

 config Enter config to display the learned VPN configuration
 routes for Host Tracking. 

 status Enter status to display the learned VPN routes status
 for Host Tracking. 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands — 

 Introduced in Release 6.5.1 

 Example 

 dump routing vpn-host-tracker config
VRF : Name - Global, Vni - 0, ID - 1687757759246017728
IP : 10.2.15.103 

 dump routing vpn-host-tracker status
VRF : Name - Global, Vni - 0, ID - 1687757759246017728
IP : 10.2.15.103
Status : true
