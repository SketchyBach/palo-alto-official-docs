 Increase CPUs and Memory for Panorama on Alibaba Cloud 

 Select a new instance type to increase the CPUs and memory
for a Panorama™ virtual appliance deployed on Alibaba Cloud. 

 You can change the instance type of the Panorama™ virtual appliance to increase the CPUs and
 memory allocated to the Panorama virtual appliance instance. Be sure to review the
 supported Alibaba Cloud instance
 types and the Setup Prerequisites for the Panorama Virtual Appliance before changing the instance
 type. 

 Log in to the Alibaba Cloud Console . 

 Select Elastic Compute Service Instances & Images Instances and navigate
to the Panorama virtual appliance instance. 

 In the Actions column, select More Instance Status Stop. 

 Change the Panorama virtual appliance instance type. 

 Select the Panorama virtual appliance if
not already selected. 

 In the Actions column, select Change Instance
Type . 

 Select the desired instance type and Change the
instance type. 

 When prompted, select Console to
view your Panorama virtual appliance instance. 

 In the Actions column for the Panorama virtual appliance
instance, select More Instance
Status Start. 

 Verify the increased CPU and memory. 

 Log in to the Panorama CLI . 

 View the Panorma virtual appliance system information. 

 admin> show system info 

 Verify that the num-cpus and ram-in-gb display
the correct number of CPUs and amount of memory as per the instance
type you selected.
