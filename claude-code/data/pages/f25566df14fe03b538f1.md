 Monitor Using Prisma Access Insights 

 Learn how to access Prisma Access Insights from the Strata Multitenant Cloud Manager . 

 While the Strata Multitenant Cloud Manager offers you multiple opportunities to monitor your tenants
 directly from the platform, you might find it useful to perform more in-depth
 monitoring, which you can do using the Prisma Access 
 Insights Administrators
 Guide . 

 Prisma Access Insights is offered as a part of your tenant's
 Prisma Access instance. To monitor using Insights, go to the appropriate and
then select Insights .
