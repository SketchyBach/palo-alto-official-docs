 Install Cortex XDR agents 

 Learn about the initial steps required to deploy Cortex XDR agent software to endpoints. 

 The Cortex XDR agent monitors endpoint activity and collects endpoint data that Cortex XDR uses to generate issues. Before you can begin collecting endpoint data, you must create an agent installation package and then install the Cortex XDR agent.
