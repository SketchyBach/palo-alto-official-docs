 System Diagnostics Server Configurations 

 Reference Cortex XSOAR 6.14 server configurations for system diagnostics. 

 Key 

 Description 

 Default 

 diagnostics.notification.enabled 

 False disables all system diagnostics email notifications. 

 True 

 diagnostics.notification.send.on.atRisk 

 False disables notifications when status is at risk. 

 True 

 diagnostics.notification.send.to.default.admins 

 False disables notifications to default administrators. 

 True 

 diagnostics.notification.send.to.roles 

 Can be empty (no roles), or a list: "Role1, Role2, Role3." Notifies all users in the roles provided. If empty (no roles), default administrators still receive notifications. 

 Administrator 

 diagnostics.notification.hour.of.the.day 

 The hour of the day to send the notification email (server time). Format is HH.
