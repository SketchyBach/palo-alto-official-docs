 Limitation 

 SaaS Agent Security Dashboard 

 SaaS Agent Security scans your onboarded Agent Platforms
 every 15 minutes, but refreshes the dashboard with new data every
 hour. 

 This means that it will take at least one hour to display any changes
 you make to your Agent Platforms as a response to a SaaS Agent Security remediation recommendation .
