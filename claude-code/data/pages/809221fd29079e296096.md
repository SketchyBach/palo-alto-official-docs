Salt Guide

Learn how to configure Koi into your environment with Salt

This document provides step-by-step instructions on integrating Koi into your environment with Salt.
In this guide, we’re going to create a new Salt state and schedule it to run periodically on the minions.

Configuration Guide

Prerequisites

Access to your Salt-Master.

The configuration script provided by Koi.

Internet access from managed devices (salt-minions).

Integration Steps

Upload the Koi script to your Salt Master at /srv/salt/koi/files/koi_script.sh

Ensure the file has executable permissions.

Ask
Copy
chmod +x /srv/salt/koi/files/koi_script.sh

Create a new Salt State File named /srv/salt/koi/init.sls and add the following configuration:

Ask
Copy
koi_configuration:

  cmd.script:

    - source: salt://koi/files/koi_script.sh

Create a new schedule in /srv/salt/scheduler.sls:

Ask
Copy
schedule_koi:

  schedule.present:

    - function: state.apply

    - job_args:

      - koi

    - minutes: 60

    - enabled: True

    - splay: 300

    - maxrunning: 1

    - run_on_start: True

Apply the new scheduled Koi state:
(replace '*' with your desired target group, or leave it in order to apply to all minions)

Ask
Copy
salt '*' state.apply scheduler

Verify deployment

Run the Koi state manually to verify it executes correctly:

Ask
Copy
salt '*' state.apply koi

Then check the job history to confirm successful execution:

Ask
Copy
salt-run jobs.list_jobs

salt-run jobs.lookup_jid <jid_number>
