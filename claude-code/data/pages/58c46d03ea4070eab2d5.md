 Transfer Data to Cloud Account (T1537), Modify Cloud Compute Infrastructure (T1578) 

 Severity 

 Informational 

 Description 

 An unusual cloud identity was granted permissions to a BigQuery table or dataset. 

 Attacker's Goals 

 Exfiltrate sensitive data that resides inside BigQuery tables or datasets. 

 Investigative actions 

 Check if {cloud_best_identity_match} intended to change BigQuery resource policy. 

 Verify if the affected tables or datasets did not contain any sensitive information.
