 Firewall Disconnected from Panorama 

 Incident Code 

 INC_NGFW_TO_MANAGING_PANORAMA_CONNECTIVITY 

 Severity 

 Warning 

 Category 

 Device 

 Subcategory 

 Management 

 Description 

 The connection between Firewall and Panorama has been lost. 

 Raise Condition 

 This incident is raised when a Next-Generation Firewall (NGFW) loses its
 connection for more than 1 hour to its managing Panorama. This indicates that the
 firewall is currently unable to communicate with its central management, which may
 impact policy updates, logging, and monitoring. The system will continue to try
 and re-establish the connection. 

 Clear Condition 

 This incident will clear automatically as soon as the connection between the NGFW
 and Panorama is successfully restored and stays connected for at least 2 hour. If
 a firewall is permanently decommissioned while this incident is active, the
 incident will be automatically cleared after a 90-day grace period. 

 Probable Root Cause Incident 

 "INC_NGFW_CONNECTION_FAIL_UNKNOWN_SNI", 

 "INC_NGFW_PANORAMA_PRE_SC3", 

 "INC_NGFW_INVALID_AUTHKEY_GIVEN_BY_DEVICE"
