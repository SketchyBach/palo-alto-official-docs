 End-of-Life (EoL)

 Set Commands Removed in PAN-OS 9.1 

 Command line interface 'set' commands that are removed
in PAN-OS 9.1: 

 The following commands are no longer available starting
with PAN-OS 9.1. 

 set deviceconfig system panorama-server
set deviceconfig system panorama-server2

set deviceconfig system update-schedule url-database

set deviceconfig setting url

set deviceconfig high-availability interface ha2 link-speed
set deviceconfig high-availability interface ha2 link-duplex
set deviceconfig high-availability interface ha2-backup link-speed 
set deviceconfig high-availability interface ha2-backup link-duplex 

set network qos profile <name> class <name> class-bandwidth
set network qos profile <name> class <name> class-bandwidth egress-max
set network qos profile <name> class <name> class-bandwidth egress-guaranteed

set network shared-gateway <name> service <name> protocol sctp

set shared service <name> protocol sctp

set shared profiles url-filtering <name> dynamic-url 
set shared profiles url-filtering <name> license-expired 

set vsys <name> profiles url-filtering <name> dynamic-url 
set vsys <name> profiles url-filtering <name> license-expired 

set vsys <name> service <name> protocol sctp
