 Issue ID 

 Description 

 PAN-306502 

 Fixed an issue where TLS connection failure occurred when traffic was
 over TLS1.2 or below, header insertion was enabled on the firewall,
 send TLS handshake to CTD was enabled,
 and traffic hit a decryption policy rule configured with the
 no-decrypt action.
