 The Palo Alto Networks Open-Source Software (OSS) Licenses documentation lists the open-source software that is included—either in part or in whole—within each product feature release. 

 NOTE: When a component version is updated in a maintenance release, customers should upgrade to that latest release to benefit from and be protected by all the changes in the latest release, which sometimes includes new OSS versions. As such, only the newest OSS version used in the latest version for each release is listed in this document. If you need to know in which maintenance release an OSS version was updated, please review the release notes for your product and release.
