 Where Can I Use This? What Do I Need? 

 Managed AIRS for AWS 

 Access to Strata Cloud Manager (SCM) 

 Managed AI Runtime security resource is an instance of the Cloud NGFW
 service platform, you can view the registered Managed AI Runtime
 resources similar to other Cloud NGFW resources in Strata Cloud Manager
 for security policy management. 

 You can view, organize, and manage your esources within Strata Cloud Manager (SCM).
 Once your resource is linked to an SCM tenant, you can view all registered firewalls
 and details such as Resource ID, Tenant ID, serial number, cloud provider, region,
 and config sync status. To streamline configuration across multiple firewalls,
 resources can be logically grouped into custom or nested folder structures accessed
 under folder management. 

 You can also set up folders by specifying a name, optional labels, and a parent
 location (such as All Firewalls or an existing nested folder). Once
 organized, administrators can target specific folders under Manage >
 Configuration > NGFW and Prisma Access to author, configure, and globally
 apply security policy rules across all contained Cloud NGFW AWS resources. 

 For more information, see view the registered Managed AI Runtime
 resources .
