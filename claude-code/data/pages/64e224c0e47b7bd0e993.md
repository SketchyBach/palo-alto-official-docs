 Deploy the VM-Series Using the Security-Centric Workflow 

 This section describes the ways to deploy the VM-Series using the security centric
 workflow. 

 Where Can I Use This? What Do I Need? 

 VMware NSX 

 VM-Series Firewall License (BYOL) 

 Panorama 

 VM-Series plugin 

 Panorama plugin for NSX 

 You can use the security-centric workflow to control and manage your VM-Series
 firewall for NSX-T from Panorama. You do not need to access NSX-T Manager to create
 service chains and steering rules; however, the service deployment must be created on
 NSX-T Manager. 

 In a security-centric workflow, you can use Panorama as a single pane of glass to control
 and manage security operations. You complete the entire deployment workflow from
 Panorama. The Panorama plugin for VMware NSX pushes configuration to NSX-T Manager that
 creates service chains and steering rules. 

 This option is well suited if your security administrator has access to Panorama but not
 NSX-T Manager. Additionally, choose this option if your deployment does not require
 frequent changes to NSX-T steering rules.
