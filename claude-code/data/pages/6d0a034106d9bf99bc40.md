 Integrate Device Security with ServiceNow Service Graph Connector 

 Integrate Device Security with ServiceNow Service Graph Connector using
 the Device Security Cloud API.

 The ServiceNow Configuration Management Database 
 application stores details about the assets and services that make up an organization's
 infrastructure. Device Security integrates with the ServiceNow CMDB
 through a Service Graph Connector ,
 a predefined integration from ServiceNow . When importing and exporting
 data, a Service Graph Connector ensures that data is mapped to the correct tables in the
 CMDB. Use the integration to enrich the data in your Device Security inventory by
 learning additional device attributes from the CMDB for assets already in your
 inventory. You can also export assets from Device Security to the CMDB. The
 integration provides a default mapping between Device Security and the CMDB data
 fields, with the flexibility to customize the mappings to fit your needs.

 To support the integration, you need to create an access key 
 for the Device Security Cloud API. Configure and manage the Service Graph Connector 
 integration from your ServiceNow instance. Find and download the
 Service Graph Connector for PANW IoT in the
 ServiceNow Store.
 You can find the application installation and configuration guide
 under App details Other information Links and documents on the
 Service Graph Connector for PANW IoT page in the ServiceNow store.
 Follow the installation guide and the guided setup in the interface to configure
 the Service Graph Connector for PANW IoT.
