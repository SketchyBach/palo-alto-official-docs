 Disable Zoom Monitoring 

 You can disable the Zoom integration or delete the ADEM
 synthetic tests that are configured for Zoom. This topic describes how to disable the
 Zoom integration without deleting the synthetic tests. Disabling the Zoom integration
 stops the collection of the QSS integration data without affecting the configured Zoom
 synthetic tests, which continue to run. 

 If QSS is disabled for all Zoom application tests or all Zoom application tests
 are deleted, historical QSS data will be deleted. If the QSS integration is
 disabled for all tests but at least one Zoom application test remains active,
 only QSS data will be deleted and ADEM synthetic test data will remain. 

 To stop monitoring the Zoom calls, follow these steps: 

 Open the Applications dashboard in ADEM and select the
 Application Tests tab. 

 Under Application Test Name , click
 zoom-meeting , the pre-defined application test for
 Zoom to open the Edit App Test page. 

 Click and drag the blue slider button under Enable Zoom Integration
 for Mobile Users to the left to disable Zoom monitoring for the
 users. 

 When prompted to confirm that you want to disable Zoom monitoring and delete
 the QSS data. Click Disable and Delete .
