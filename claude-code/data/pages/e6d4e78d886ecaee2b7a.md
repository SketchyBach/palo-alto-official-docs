 Convert a Cloud NGFW Free Trial to an AWS Marketplace Subscription 

 Convert an active Cloud NGFW free trial to a paid AWS Marketplace subscription
 without interrupting your existing Cloud NGFW resources. 

 Where Can I Use This? What Do I Need? 

 Cloud NGFW for AWS 

 Active Cloud NGFW free trial with resources already created
 in Strata Cloud Manager 

 AWS Marketplace account 

 AWS Account ID for billing 

 To transition from a free trial to a paid subscription without service
 interruption, you must link your Strata Cloud Manager (SCM) tenant to your AWS
 Marketplace account. Follow these steps if you have already started creating your
 Cloud NGFW resources within SCM. 

 Step 1: Generate a Billing Code in Strata Cloud Manager 

 Log in to the Strata Cloud Manager console. 

 Select Workload Setup Cloud NGFW . 

 Click Subscription . 

 Click Add New Subscription . 

 Enter the AWS Account ID you want to use for billing and click
 Generate . 

 Copy the unique billing subscription code that appears. 

 The billing subscription
 code expires in 48 hours. Copy and use it before the time window
 closes. 

 Step 2: Subscribe via AWS Marketplace 

 Click Complete the Subscription in Strata Cloud
 Manager, or navigate directly to the Cloud NGFW for AWS listing in the AWS
 Marketplace. 

 Ensure you are already logged in to the
 AWS account you want to use for billing before completing this step. For
 example, open your AWS account in another tab in the same
 browser. 

 Click View purchasing options . 

 Click Subscribe . 

 If you have previously subscribed to Cloud
 NGFW from this account, Subscribe is unavailable.
 Click Set up your account to go to the Quick
 Launch page, as described in Generate Billing Code and
 Subscribe using AWS Marketplace. 

 If you manage multiple Strata Cloud Managers, you can link each
 one to your subscription account using AWS Marketplace
 Billing Aggregation . 

 Click Sign in or create an account . 

 Once subscribed, click Set up your account . 

 Step 3: Link the Account 

 On the Create a New Cloud NGFW Tenant page, when
 prompted whether you have an existing SCM billing code, select
 Yes . 

 If your AWS account is already associated with a Cloud NGFW tenant, your
 AWS account details appear on the page. When prompted whether you have an
 existing SCM billing code, select Yes . 

 Enter your email address and paste the billing code you copied from Strata
 Cloud Manager. 

 Click Continue to finalize the link. 

 Your trial transitions to a paid subscription based on your AWS
 Marketplace agreement. 

 For a
 visual walkthrough of this process, watch the Simplified Try & Buy Journey for Cloud
 NGFW . 

 To verify the subscription, log in to the Strata Cloud Manager console,
 select Workload Setup Cloud NGFW , and confirm that your AWS account PAYG subscription shows an
 active status.
