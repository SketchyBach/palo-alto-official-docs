# Unified Risk Management for identities, cloud entitlements, and web applications

Unified Risk Management for identities, cloud entitlements, and web applications
NEW
August 25, 2026

You can now view and remediate risk across user identities, cloud entitlements, and web applications from a unified Risk Management page in Detect and Respond > Risk Management.

The page includes dedicated dashboards for each entity type, step-by-step remediation guidance, and risk trend tracking so you can measure your security posture over time.

Out-of-the-box detections help you quickly identify high-impact issues such as users with standing admin access, privileged users without MFA, and apps with shared credentials.

You can also customize Automation risk using new enrichment rules, which support tag-based configuration, configurable severity levels, and automated asset enrichment.

These updates are part of an ongoing initiative to deliver complete entity-level risk consolidation.

Important
This capability is being released in a rollout process that will be completed in the coming weeks.

For more information, see Risk Management.
