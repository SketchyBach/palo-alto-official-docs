 XSOAR 8 SaaS 

 Licensing & Pricing 

 Find Cortex XSOAR 8 SaaS FAQs for licensing, subscriptions, and pricing. 

 Is there a cost for existing Cortex XSOAR customers who wish to migrate to the SaaS version? 

 Migration of existing hosted and On-prem customers to Cortex XSOAR 8 SaaS will be done at no charge for single-tenant customers. The pricing model for multi-tenant customers will be provided later, once the offering becomes available. 

 How does user licensing work for a development tenant? 

 In the development tenant, we do not impose user licensing restrictions. Users can log in above their licensed user limit. 

 How will license renewals be handled on Cortex XSOAR 8 SaaS? 

 Licenses will no longer be handled by the customers but will be automatically updated in the Cortex XSOAR backend with no customer interaction required. 

 When is a user counted as an 'Active User'? 

 For both CSP and SSO users, when they log into a tenant, they are considered Active Users. 

 Will an Account Admin from the CSP be counted as an 'Active User'? 

 Only when the user logs in to the tenant for the first time. 

 When will a user not be counted as an 'Active User'? 

 Only when the user is deleted from the user table (SSO User), or in the CSP (if CSP user), will they be removed from the count.
