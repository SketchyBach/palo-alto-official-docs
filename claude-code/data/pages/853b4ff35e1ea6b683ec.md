 Terraform workflows for rules 

 Deploy and maintain custom detection logic programmatically across multiple tenants. This enables you to define the logic directly in HCL via the frameworks block, ensuring identical rule distribution organization-wide. 

 Configuration : Use the cortexcloud_appsec_rule resource. 

 How it works : Define rule attributes like severity, scanner, category, and deploy the detection logic using the frameworks block. 

 For more information, refer to Manage resources .
