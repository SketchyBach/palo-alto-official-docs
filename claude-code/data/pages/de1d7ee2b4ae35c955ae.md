 Features Introduced in 2025 

 April 2025 

 This section describes the new features and updates introduced in the Cortex XSOAR SaaS 8.11 release. 

 Release highlights 

 The Cortex XSOAR 8.10 release includes the following highlights: 

 Feature 

 Description 

 Automatically export incidents 

 For customers who need to store incidents beyond their retention period, XSOAR can now automatically export incidents to external storage, enabling indefinite retention and continued access to historical incident data. 

 Support for additional Cortex XSOAR APIs 

 The expanded API support enables organizations to reset the ROI widget, update existing lists, get a list, upload files, and clone playbooks so they can better fine-tune automated incident workflows and integrations.

 Cortex XSOAR has added coverage for new scenarios in the Guard Rails page, which helps maintain a stable environment.
