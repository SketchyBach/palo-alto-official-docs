 Autonomous Digital Experience Management (ADEM) 

 With Autonomous DEM you get an insight into remote users' networks (laptops, Wi-Fi,
 SaaS and internal applications, LANs, and traffic levels). This in turn helps you
 troubleshoot their performance-related issues.

 Autonomous Digital Experience Management (ADEM) provides native end-to-end visibility and performance
 metrics for real application traffic for both mobile users and remote sites in your
 Secure Access Service Edge (SASE) and Next-Generation Firewall deployments. 

 ADEM continuously monitors every segment in the service
 delivery path and simplifies remediation by providing insights that help you quickly
 isolate the segment that is causing application experience problems. 

 ADEM with Strata Cloud Manager Pro 

 To use ADEM , you must have Strata Cloud Manager Pro . ADEM with Strata Cloud Manager Pro gives you
 holistic observability across your network; it helps to automate complex IT
 operations, reduce ticket volume, and shorten the mean time to resolution
 (MTTR). 

 ADEM with Strata Cloud Manager Pro provides the full
 suite of ADEM features: 
 End-to-end visibility from users to applications, allowing administrators to
 diagnose impacted service delivery chains. 

 Hop by hop views of exact segments through synthetic testing. 

 Browser-based real user monitoring. 

 Access Analyzer powered by AI/ML/Formal. 

 Here’s how to activate Strata Cloud Manager
 Pro so you can get started. 

 Mobile Users 

 In the case of a mobile user connecting to an application through Prisma Access or a Next-Generation Firewall gateway, ADEM is
 natively integrated with GlobalProtect to monitor every hop
 of the user's experience including Device, Wi-Fi, LAN, internet, and the
 application and therefore does not require you to deploy any additional
 appliances. 

 In addition, ADEM offers real-time
 visibility into user experience of SaaS applications, other internet-based
 applications, and applications in your own data center through Browser-Based Real User Monitoring (RUM) . 

 To get started with monitoring Mobile Users , click here. 

 Remote Sites 

 In the case of remote site experience, ADEM 
 monitors all segments on all paths from Prisma SD-WAN and SD-WAN
 for NGFW remote sites to the application. 

 To get started with monitoring Remote Sites , click
 here.
