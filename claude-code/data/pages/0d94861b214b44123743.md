 Description 

 A rare process created an SSH session to an uncommon cloud resource. 

 Attacker's Goals 

 Attackers may use SSH or any similar utility as a Command and Control (C2) channel or to exfiltrate data to a remote host. 

 Investigative actions 

 Investigate the actor process and its causality. 

 Review the remote cloud asset, is it managed by the organization or a partner? 

 Search for processes or files that were accessed by this SSH instance.
