 Configure Device Security 

 Learn how to configure your device to manage security violations. 

 Where Can I Use This? What Do I Need? 

 NGFW 

 PAN-OS 12.1 and later 

 Configure your device to manage how security violations are handled. 

 Select Device Setup PAN-OS Security or Panorama Device Setup PAN-OS Security . 

 Edit Device Security Settings . 

 Select continue-running (default) or
 maintenance-mode to configure the appliance or
 firewall response to a security violation.
