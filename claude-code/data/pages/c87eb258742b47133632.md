 dump static-arp config 

 Use the dump static-arp config command
to display the address resolution protocol (ARP) table and displays
the ARP cache for all or a specific interface. 

 Command 

 dump static-arp config ( all | interface ) 

 Options 

 all Enter all to display the entire ARP cache. 

 interface Enter interface to display the ARP cache for
a specific interface name or ID. 

 Command Notes 

 Role Super, Read Only 

 Related Commands — 

 Introduced in Release 5.5.1 

 Example 

 dump static-arp config all
 Interface : eth1
 Static ARP : 10.10.10.1, mac 00:33:4f:9f:f9:03 
 : 10.10.10.20, mac bb:2f:43:3c:7b:b7
