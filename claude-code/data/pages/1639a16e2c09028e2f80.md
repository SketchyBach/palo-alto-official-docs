 Strata Cloud Manager 

 Data Security license 

 Or any of the following licenses that include the Data Security license: 

 CASB-X 

 CASB-PA 

 Add the following region-specific IP addresses to the allowed list on your: 
 SaaS app instance's IP Allow-list (for applicable SaaS apps, for example
 Salesforce) 

 NGFW or Prisma Access tenant
