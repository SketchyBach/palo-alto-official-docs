 Use a signed certificate instead of SSL 

 Use a signed certificate in Cortex XSOAR 8.8 On-prem for MSSP. 

 Self-signed certificates are customizable and cost-effective for internal systems or development environments where external trust is not required, offering independence from third-party Certificate Authorities. 

 Disable SSL verification for Multi-tenant 

 In a multi-tenant setup, if a child tenant has a self-signed certificate, you can disable SSL verification for requests between the parent and child tenant. 

 From the textual UI menu in your VM, select Application Settings . 

 Select Skip SSL Verification for MSSP . 

 Click Apply .
