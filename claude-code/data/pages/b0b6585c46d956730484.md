 Deploy Prisma Cloud DSPM on AWS 

 Onboarding AWS Organization 

 Prerequisites 

 Ensure an orchestrator is deployed within the organization intended for onboarding. 

 Ensure the individual performing the onboarding possesses administrative privileges for the organization. 

 Procedure 

 Access Prisma Cloud DSPM. 

 In Prisma Cloud DSPM, go to Preferences > Integrations, and locate the Cloud Platforms section. 

 Click on the Amazon Web Services thumbnail, then click Configure to access the Amazon Web Services Connect Accounts page.

 Connect AWS organization. 

 On the Amazon Web Services Connect Accounts page, select Add organization from the Add New dropdown menu.

 Sign in to an AWS account with permissions to execute a stack set across the organization. 

 Choose the location of the orchestrator for the organization from the dropdown menu. 

 Click Generate Template .

 Copy the template link. 

 In the Add AWS organization pop-up window, copy the provided template link. 

 Click StackSet page , which redirects to the AWS Sign in page.

 Create a StackSet. 

 In the sidebar menu, navigate to StackSets , and click Create StackSet to open the Choose a template window.

 Choose a template. 

 In the Choose a template window, scroll down to Specify template section. 

 Enter the URL, copied earlier, into the Amazon S3 URL field. 

 Click Next to proceed to the Specify StackSet details page.

 Specify StackSet details. 

 In the StackSet name field, provide a meaningful name and an optional description for the StackSet . 

 Click Next to proceed to the Configure StackSet options page.

 Configure the StackSet options. 

 Optionally add tags and select a Managed execution option. 

 Click Next to proceed to the Set deployment options page.

 Specify the deployment options. 

 Choose to deploy Prisma Cloud DSPM at the organization level or select specific organizational units. If you select specific units, specify the units you intend to onboard. 

 Ensure the Activated and Delete Stacks options are selected in the Auto-deployment options section. 

 Since you are creating global IAM roles that are not region specific, you need to select only one region, otherwise the extra executions will fail. 

 Click Next to review the configuration.

 Review and submit. 

 Scroll down to the foot of the Review page and click Submit to initiate the deployment.

 Track the deployment. 

 Wait until the stack status changes from Running to Succeeded. 

 Track the deployment progress of each individual stack in the Stack instances section. Note that the individual accounts are generally populated and viewable in Prisma Cloud DSPM within several minutes.
