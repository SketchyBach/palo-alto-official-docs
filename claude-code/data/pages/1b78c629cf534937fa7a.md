# FS-ISAC STIX/TAXII Guide for Cortex XSOAR

Configure Cortex XSOAR 8 SaaS or Cortex XSOAR 8x On-prem to connect to the FS-ISAC IntelX Repo through a STIX/TAXII feed integration.

Assist FS-ISAC member firms in connecting and configuring Cortex XSOAR through a STIX/TAXII feed integration with the FS-ISAC Threat Intelligence Exchange Repository (IntelX Repo).

Use this guide to:

* Install the TAXII Feed integration
* Set up the FS-ISCA instance in Cortex XSOAR
