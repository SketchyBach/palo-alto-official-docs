 Switch Between the Prisma Agent and GlobalProtect App 

 You can use either the Prisma Agent app or the Prisma Access command-line tool
 (PACli) to switch between the Prisma Agent and the Global Protect app. 

 Where Can I Use This? What Do I Need? 

 Prisma Agent 

 macOS 14 and later or Windows 10 version 2024 and later desktop devices 

 Internet access 

 In some organizations, the Prisma Agent is installed on user devices
 that already have the GlobalProtect app installed. After installing the Prisma
 Agent, you can switch between the Prisma Agent and the GlobalProtect app as
 needed.

 Switch Between the Prisma Agent and GlobalProtect App (Using Prisma Agent App) 

 Learn how to switch between the Prisma Agent and the Global Protect app using
 the Prisma Agent App. 

 Before switching to the GlobalProtect™ app, you need to disable the
 Prisma Agent. If your administrator configured the feature to allow users to disable
 the Prisma Agent, you can use the app to disable the Prisma Agent. After you disable
 the Prisma Agent, you can start the GlobalProtect app. 

 Your administrator must contact the Palo Alto Networks team
 to enable this tenant-level feature. It's not available as an agent setting on Strata Cloud Manager . 

 To switch from the Prisma Agent to the GlobalProtect app: 

 Open the Prisma Agent. 

 If you're disabling the agent for the first time, open the Prisma
 Agent app and sign out of the Prisma Agent. 

 Select the hamburger menu and select Sign
 Out . 

 Log in to the Prisma Agent app again to make the
 Disable link appear in the
 preferences window. 

 Click the hamburger menu to open the preferences window. 

 Disable the Prisma Agent. 

 Close the preferences window by clicking the
 X . 

 The Prisma Agent is disabled. 

 Start the GlobalProtect app and Connect to
 GlobalProtect. 

 To switch from the GlobalProtect app back to the Prisma Agent: 

 Open the GlobalProtect app. 

 Click the options menu and select
 Disconnect . 

 Launch the Prisma Agent app. 

 Click the hamburger menu to open the preferences window. 

 Enable the Prisma Agent. 

 Close the preferences window by clicking the
 X . 

 If the agent is in Always On mode, the agent is enabled and will
 connect to the best location. 

 If the agent is in On-Demand mode, the Prisma Agent is enabled but
 remains disconnected. Click the lock icon to connect to the Prisma
 Access location. 

 Switch Between the Prisma Agent and GlobalProtect App (Using
 PACli) 

 Learn how to switch between the Prisma Agent and the Global Protect app using
 the command line. 

 To switch between the Prisma Agent and the GlobalProtect app, run the
 Prisma Access command-line tool (PACli). When switching to the GlobalProtect app,
 the PACli tool will prompt you for the anti-tamper unlock password if the
 administrator set one up during the onboarding of the Prisma Agent. Switching to the
 desired app disables the app that you're currently using. 

 To switch from the Prisma Agent to the GlobalProtect app: 

 Run the switchto command to switch agents: 

 On macOS devices, open a Terminal window and issue the
 following command: 

 sudo /Applications/Prisma\ Access\ Agent.app/Contents/Helpers/pacli switchto GlobalProtect 

 On Windows devices, open a Command Prompt window and issue
 the following command: 

 "C:\Program Files\Palo Alto Networks\Prisma Agent\pacli" switchto GlobalProtect 

 ( macOS ) Enter the admin password when prompted. 

 If prompted, enter Y to switch to the
 GlobalProtect app. 

 If prompted for a supervisor password, enter the anti-tamper unlock
 password. 

 The following
 text shows an example of switching from the Prisma Agent to
 GlobalProtect on a macOS
 device: 
 <username@hostname> ~ % cd /Applications/Prisma\ Access\ Agent.app/Contents/Helpers
<username@hostname> Helpers % sudo ./pacli switchto GlobalProtect 
Enter supervisor password:
Disabled Prisma Access Agent.
Starting the GlobalProtect service. This can take up to 60 seconds...
Successfuly started GlobalProtect. Switch complete.
<username@hostname> Helpers %

 action
