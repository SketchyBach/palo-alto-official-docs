 Integrate Device Security with Jamf Pro 

 Integrate Device Security with Jamf Pro to improve the asset inventory
 and security operations for mobile device management (MDM).

 Where Can I Use This? What Do I Need? 

 Device Security (Managed by Strata Cloud Manager) 

 (Legacy) IoT Security (Standalone portal) 

 One of the following subscriptions: 

 Device Security subscription for an advanced
 Device Security product (Enterprise Plus,
 Industrial OT, or Medical)

 Device Security X subscription

 One of the following Cortex XSOAR setups:

 A free, cohosted, limited-featured
 Cortex XSOAR instance

 AND 

 A free Cortex XSOAR Engine (on-premises integration)

 A full-featured Cortex XSOAR server

 Integrate Jamf Pro with Device Security to enhance device management
 and security across your Apple ecosystem. Through the integration,
 Device Security can enrich the asset inventory by learning new devices and
 additional device attributes from Jamf Pro . Additionally, the
 integration provides Device Security with visibility into which devices in your
 Device Security inventory Jamf Pro manages as an endpoint solution.

 Integrating with Jamf Pro makes Device Security a more comprehensive
 device management and security solution, particularly for environments with a
 significant Apple device presence. Through the Jamf Pro 
 integration, Device Security can learn the following attributes:

 Device serial number 

 MAC address 

 Model 

 OS Version 

 Mobile IMEI 

 Mobile network code 

 Mobile country code 

 Mobile TAC 

 Installed software 

 MDM device ID 

 MDM model identifier 

 Mobile MEID 

 Mobile integrated circuit card identification 

 MDM managed status 

 MDM supervised status 

 MDM vendor 

 MDM lost mode capable 

 MDM lock status 

 The integration supports key use cases, including identifying managed
 Apple devices and taking immediate action on potentially compromised
 devices. When you receive a security alert for suspicious behavior, you can lock
 devices directly from the Device Security portal. These capabilities are
 valuable when responding to security threats involving lost or stolen devices.
 Combining Jamf Pro ’s mobile device management (MDM) capabilities with
 Device Security ’s threat detection capabilities improves risk assessment and
 response time for security incidents, enabling a more effective device lifecycle
 management.

 For a full list of attributes that Device Security can learn through the
 integration, see
 Jamf Pro Attribute Reference .

 Integrating with Jamf Pro requires either a
 full-featured Cortex XSOAR™ server 
 or the
 activation of a Device Security 
 free
 cohosted Cortex XSOAR instance .
