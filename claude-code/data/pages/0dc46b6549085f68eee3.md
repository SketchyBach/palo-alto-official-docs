 Review changes to default behavior in Device Security . 

 Where Can I Use This? What Do I Need? 

 Device Security (Managed by Strata Cloud Manager) 

 (Legacy) IoT Security (Standalone portal) 

 One of the following subscriptions: 

 Device Security subscription

 Precision AI bundle subscription

 Device Security X subscription

 Review the following changes to default behavior in Device Security . 

 Changes to Default Behavior Introduced in May 2026 

 The following table details the changes in default behavior for
 Device Security in Strata Cloud Manager , introduced in May 2026.

 Component Change 

 IP Endpoints 

 The time filter on the IP Endpoints page now provides an option for
 one hour.

 Applications 

 The Applications page filter now supports filtering on sub-types of
 IoT devices.

 Network Visualizations 

 The Network Visualizations page now hides empty Purdue Levels
 by default.

 Tenant Details 

 The Tenant Details page now displays the TSG ID.

 Changes to Default Behavior Introduced in April 2026 

 The following table details the changes in default behavior for
 Device Security in Strata Cloud Manager , introduced in April 2026.

 Component Change 

 Integrations 

 The polling integration through Cortex XSOAR 
 increased coverage for platforms learned through the
 Mitsubishi MELSOFT protocol, and the integration learns
 additional attributes through the MMS-ICS, Modbus, and UPNP
 protocols.

 Custom Dashboards 

 We updated the design of the widget library for
 custom dashboards. All functionality remains the same.

 Changes to Default Behavior Introduced in March 2026 

 The following table details the changes in default behavior for
 Device Security in Strata Cloud Manager , introduced in March 2026.

 Component Change 

 All pages 

 We made multiple minor enhancements to the web interface
 for consistency and usability, such as a
 persistent filter, added breadcrumbs and a header to
 the Network Visualization page, and standardized
 severity and priority badges.

 Changes to Default Behavior Introduced in February 2026 

 The following table details the changes in default behavior for
 Device Security in Strata Cloud Manager , introduced in February 2026.

 Component Change 

 All pages 

 The Device Security banner no longer appears on pages that 
 aren't part of the tabbed navigation.

 Device Details and Asset Inventory 

 The Last Activity attribute for devices now comes from
 two new, distinct timestamp attributes. The
 Last Network Activity attribute reflects only
 network traffic, while the Last Third-Party Activity 
 attribute reflects third-party integrations data. The
 Last Activity attribute displays the latest activity
 timestamp between Last Network Activity and
 Last Third-Party Activity .

 Device Details and Asset Inventory 

 The AD Join Status now uses information from traffic
 in addition to existing information from third-party
 CIE integrations.

 Changes to Default Behavior Introduced in January 2026 

 The following table details the changes in default behavior for
 Device Security in Strata Cloud Manager , introduced in January 2026.

 Component Change 

 Firewalls 

 On the Firewalls page, the filter bar moved into
 the Firewalls table to reflect the limited scope
 of filtered data.

 Assets 

 When downloading the Assets Inventory, the web interface
 now shows an estimated download time.

 Query Builder 

 Throughout the web interface, all pages and workflows 
 now use the new Query Builder. The behavior of the Query Builder 
 may be fixed depending on the capability of the feature or workflow 
 where it appears.
