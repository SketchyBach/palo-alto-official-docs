 Bind Path or QoS Stacks to Sites 

 Learn how to bind path or QoS stacks to sites. 

 Where Can I Use
 This? What Do I Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 In order for policy rules in Path or QoS stacks
to be active, bind Path or QoS stacks to a site. You can bind a single
Path or QoS stack to a site at a time. 

 Select Configuration Prisma SD-WAN Policies Stacked Bindings . 

 For a site, select a path policy set stack from the Path Policy Set
 Stack , Performance Policy Set Stack ,
 QoS Policy Set Stack , and Security Policy
 Set Stack from the respective drop-downs and
 Save . 

 (Optional) You can assign a path policy set stack and a QoS policy
 set stack to multiple sites at a time by selecting multiple sites, clicking
 and assigning the path or QoS stacks to the sites. 

 Alternatively, select Configuration > Prisma SD-WAN > Branch Sites (or
 Data Centers ) and select a site. In the Branch Site
 Details section, under Policy Stack ,
 click the Manage Policy Bindings link to change the assigned
 stacks. 

 You can view the currently assigned stacks in the Policy Stack section.
 Clicking any of the respective policy stack names will route you
 directly to that specific policy's configuration page 

 The Manage Policy Bindings link opens the Stacked Bindings page
 under Policies where you can apply your drop-down selections
