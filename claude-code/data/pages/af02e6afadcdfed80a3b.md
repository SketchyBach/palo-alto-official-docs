 XDR Collector audit logs 

 Review XDR Collector audit logs in Cortex XSIAM. 

 Learn more about XDR Collector audit logs. 

 Cortex XSIAM logs entries for events related to the XDR Collector monitored activities. Cortex XSIAM stores the logs for 365 days. To view the XDR Collector audit logs, select Settings → XDR Collector Audit Logs.
