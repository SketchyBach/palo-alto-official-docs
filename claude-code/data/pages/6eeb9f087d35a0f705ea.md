 Set Up the Prisma Agent for Dynamic Privilege Access 

 Learn how to set up the Prisma Agent so that your mobile users can use
 the agent to access your organization's network based on the customer projects your users
 are assigned to. 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access 5.1 Innovation 

 Prisma Access 
 license with the Mobile User subscription 

 macOS 14 and later or Windows 10 version 2024 and later desktop devices 

 Role: Superuser 

 Your end users will use the Prisma Agent to access your organization's
 network based on the customer projects that your users are assigned to. 

 After you set up the project-specific agent settings and created the
 projects , you can configure other Prisma Agent settings such as
 staged rollouts and global agent settings.
