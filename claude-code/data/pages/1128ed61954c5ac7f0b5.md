 Microsoft Teams Integration with ADEM 

 Integrate Microsoft Teams with ADEM, enabling you to receive Microsoft Teams meeting
 data for your organization. 

 Where Can I Use
 This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 Prisma Access license 

 ADEM or Strata Cloud Manager Pro 
 license 

 GlobalProtect or Prisma Access Agent license 

 With the widespread reliance on Microsoft Teams for enterprise communication, the need
 for a streamlined solution to manage call quality has never been more urgent. In today's
 dynamic, hybrid work environment, effective communication, and collaboration are
 essential for driving employee productivity and success. However, ensuring a seamless
 virtual meeting experience poses significant challenges for IT and help desk
 administrators. Some of the key challenges that customers consistently face include: 

 Manual correlation of data between the Microsoft Teams Dashboard and enterprise
 monitoring tools, often leading to delays in troubleshooting and hindering swift
 resolution of call quality issues. 

 Access restrictions to the Microsoft Teams Dashboard, which can impede
 administrators' visibility into critical call quality metrics, further complicating
 the troubleshooting process. 

 Networking team admins, unified communications as a service (UCaaS) team leads, and help
 desk personnel want to resolve or communicate UCaaS performance issues before they
 impact end-user experience. The integration of Microsoft Teams meeting metrics with ADEM
 data provides visibility and root cause analysis to a wide user base, so users can
 resolve or communicate possible UCaaS performance issues before they affect end-user
 experience. The Microsoft Teams dashboard data correlates with ADEM synthetic data,
 giving networking team, UCaaS team, and help desk admins the information they need to
 troubleshoot Microsoft Teams calls. 

 Call records for online Microsoft Teams meetings are generated 30 minutes after the
 meeting ends and are associated with a collection of media streams. Microsoft Teams
 integration with ADEM provides a Microsoft Teams admin with a detailed view that has
 meeting performance data for ADEM users for the desired time frame as well as an
 organization-wide UCaaS performance dashboard. 

 Learn how to perform Microsoft Teams integration with ADEM, enabling you to receive
 Microsoft Teams meeting data for your organization. 

 Onboard Microsoft Teams 

 Onboard Microsoft Teams using the integrated in-app workflow, which enables ADEM to
 receive call quality data from Microsoft Teams. 

 Go to Insights Application Experience Application Tests . 
 The Applications Tests page has
 multiple preconfigured applications that admins can easily enable. Admins
 can edit these preconfigured tests if required. 

 Select MS Teams (Predefined) from the
 Application Tests table. 

 Scroll down on the Edit Application Test page to select
 Authorize Microsoft Teams Integration . 

 Sign in to an account with Teams Administrator permissions. 

 A message appears, saying that Initiating Microsoft Teams
 Integration has begun. Review the message that appears, and
 select Done . 

 A default tenant (circled in green, below) appears after you have successfully
 authorized ADEM to receive Microsoft Teams meeting data. 
 Optionally, to add a
 new test manually, select Add Application Test . In
 the Add Application Test page that opens, complete
 the required fields, and select Save .
