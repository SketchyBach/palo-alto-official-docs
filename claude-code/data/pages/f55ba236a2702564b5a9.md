 Understand Cortex Data Security Licenses 

 License expiration 

 Cortex Data Security licenses are valid for the period associated with the license purchase. 

 Access grace period: After the license expires, you retain console access for an additional 48 hours. After the 48-hour grace period, the interface is disabled until the license is renewed. 

 First 31 days after expiry: Cortex Data Security continues to monitor your data sources and retains data in the Cortex Data Layer according to your retention settings (default 30 days for ingested data). 

 After 31 days: The tenant is decommissioned. All data, configurations, and data security policies are deleted, and data collection ceases. 

 Warning: To avoid data loss, renew the license or extend retention before the 31-day decommissioning window ends. Purged data cannot be recovered.
