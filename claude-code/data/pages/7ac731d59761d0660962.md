 Global or Local Scope for BGP Peers 

 Learn the significance of configuring, learning, and advertisement of routes based on
 global or local scope for BGP peers at branch sites in Prisma SD-WAN. 

 Where Can I Use
 This? What Do I Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 On a branch ION, you can configure global or local scope for BGP peers. On a data
 center ION, you can configure global or local scope for BGP peers starting with ION
 software release 6.5.1. The following table explains the learning and advertisement of
 routes based on global or local scope configured for LAN and WAN peers.
