 Licensing of an HSF Cluster 

 HSF requires an HSF subscription license for the configuration and utilization of the
 HSF cluster. 

 Where Can I Use This? What Do I Need? 

 Prisma AIRS 

 Software NGFW Credits 

 HSF subscription license 

 HSF requires the free HSF subscription license (configured in the Prisma
 AIRS deployment profile) for the configuration and utilization of the HSF cluster. This
 license is free and supplementary to FW-Flex credits for Prisma AIRS and other
 feature subscription licenses. Each Prisma AIRS instance within the cluster requires
 individual licensing and will be assigned a unique serial number. 

 During cluster deployment, the Prisma AIRS | AIRS Network Intercept deployment
 profile authentication code should be provided to the Panorama HSF cluster orchestration
 plugin. The orchestration plugin will transmit this authentication code to the cluster
 nodes as a bootstrap parameter. 

 The same license authentication code is applicable to both P-Nodes and S-Nodes.
 Despite the differing CPU footprints between these instance types, the licensing code
 will procure the necessary credits from the CSP in an amount that matches the number of
 CPU cores in the instance.
