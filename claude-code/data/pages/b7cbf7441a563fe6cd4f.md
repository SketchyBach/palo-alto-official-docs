 New Features - Autonomous DEM - January 2023 

 Prisma Access Locations Dashboard Enhancements 

 Release Date: January 2023 
 | 
 Last Updated: June 2026 

 The Prisma® Access Locations dashboard now consolidates network and application performance data into a single view, eliminating the need to navigate multiple pages to understand how your deployment is serving users. New widgets surface all Network Performance and Application Performance metrics monitored from cloud agents, giving you a complete performance picture at each location. An enhanced Map View adds application distribution data for connected Mobile Users and Remote Sites, so you can see how applications are delivered across your Prisma Access locations at a glance. 

 When you hover over a location in the Map View , the application distribution pop-up uses color coding on its left border to represent the lower of the Mobile Users status and Remote Sites status. This lets you immediately identify which locations have degraded experience—without drilling into each one individually—and prioritize where to focus your troubleshooting effort. 

 A new deployment-type filter lets you narrow the dashboard view to the specific segment you need to troubleshoot, whether you are focusing on Mobile Users, Remote Sites, or a specific deployment combination. These enhancements give you a unified, location-centric perspective on how Prisma Access is performing across your SASE environment.
