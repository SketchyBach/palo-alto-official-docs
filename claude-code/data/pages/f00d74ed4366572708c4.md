 ATT&CK Tactic 

 Initial Access (TA0001) 

 ATT&CK Technique 

 Valid Accounts: Cloud Accounts (T1078.004) 

 Severity 

 Informational 

 Description 

 A user with no activity in the past 30 days with the target, attempted to authenticate via universal authentication. 

 Attacker's Goals 

 Use an account that was possibly compromised in the past to gain access to the network. 

 Investigative actions 

 Confirm that the activity is benign (e.g. the user returned from a long leave of absence). 

 Variations 
 Successful authentication by an inactive user from a risky IP address
