 SentinelOne 

 SentinelOne 

 Use SentinelOne data in Cortex XSIAM. 

 Important 

 This connector is only available for tenants that onboarded after July 26, 2026. For tenants that onboarded before this date, use Marketplace to access the standalone integration. For more information, see Marketplace . 

 This connector is available with any active Cortex XSIAM license. 

 Integrate with SentinelOne for endpoint protection. Fetch activities, threats, and alerts from SentinelOne, and use SentinelOne to receive alerts from endpoints, search for processes, block endpoints, and manage the endpoint protection policy. 

 This connector includes the following sub-capabilities (Marketplace integrations link to PAN DEV for more information): 

 SentinelOneEventCollector : This integration fetches activities, threats, and alerts from SentinelOne. 

 To configure this connector, follow the steps outlined in the configuration wizard.
