 Integrate Device Security with NetBrain 

 Integrate NetBrain with Device Security to gain greater visibility into 
 your network infrastructure and connected devices.

 Where Can I Use This? What Do I Need? 

 Device Security (Managed by Strata Cloud Manager) 

 (Legacy) IoT Security (Standalone portal) 

 One of the following subscriptions: 

 Device Security subscription for an advanced
 Device Security product (Enterprise Plus,
 Industrial OT, or Medical)

 Device Security X subscription

 One of the following Cortex XSOAR setups:

 A free, cohosted, limited-featured
 Cortex XSOAR instance

 AND 

 A free Cortex XSOAR Engine (on-premises integration)

 A full-featured Cortex XSOAR server

 Integrate NetBrain with Device Security to gain greater visibility into your 
 network infrastructure and connected devices. By integrating Device Security with 
 your NetBrain network management platform, you can enrich the
 Device Security Assets Inventory. The greater context and additional attributes
 help Device Security identify connected devices with more confidence, ensuring you
 get more relevant and timely recommendations and alerts for your network security.

 When you integrate Device Security with NetBrain , you can retrieve device 
 attributes such as hostname, MAC address, vendor information, model details, and network 
 connections. This enriched data provides you with visibility into where your devices 
 connect to your network infrastructure and how they relate to your broader network 
 topology.

 The integration provides you information about the network context of your devices, 
 which you can use for security investigations, compliance reporting, or
 network troubleshooting. The integration also helps you identify which network switch
 and port each device connects to, enabling faster incident response and
 more effective network segmentation strategies.

 For a full list of attributes that Device Security can learn through the
 integration, see
 NetBrain Attribute Reference .

 Integrating with NetBrain requires either a full-featured Cortex™ XSOAR server 
 or the activation 
 of a Device Security free cohosted Cortex XSOAR instance .
