 Manage users for Cloud NGFW for AWS. 

 Where Can I Use This? What Do I Need? 

 Cloud NGFW for AWS 

 Cloud NGFW subscription 

 Palo Alto Networks Customer Support Account (CSP) 

 AWS Marketplace account 

 User role (either tenant or administrator) 

 At any time, you can modify a user’s role or roles to expand or reduce their access
 and permissions. You can delete a user and individual users can view their roles and
 change their name or password as necessary. 

 For more information on users and roles in the tenant started from an AWS member
 account, see Getting started from an AWS member account
 . 

 The email address domain for users invited by the tenant administrator must
 exactly match the email address domain of the tenant administrator's login
 credentials. Subdomains (For example: user@external.domain.com )
 are currently not supported if the tenant is registered under
 domain.com . To manage users from a different domain or
 subdomain, you must create a separate tenant.

 Delete a User 

 If you need to completely remove a user’s access and permissions, you can delete
 that user. 

 Select Settings User and Roles . 

 Select the check box to the left of the user’s name. 

 Select Actions Delete . 

 Edit User Information 

 A non-tenant administrator can update their name or change their password if
 needed. However, they cannot modify their assigned roles. 

 Select Settings User and Roles . 

 Click the username. 

 Modify the First Name and Last
 Name if necessary. 

 To change a password: 

 Click Change Password . 

 Enter the Current Password . 

 Enter and re-enter the New Password . 

 Click Change . 

 Changing the password logs you out of the Cloud NGFW tenant.
 Log back in using the new password. 

 Click Save .
