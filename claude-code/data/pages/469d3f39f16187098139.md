 Managed AI Runtime Security for AWS 

 Managed Prisma AI Runtime Security (AIRS) for AWS extends standard cloud firewall
 capabilities by introducing a dual-data plane architecture. 

 Where Can I Use This? What Do I Need? 

 Managed AIRS for AWS 

 Access to Strata Cloud Manager (SCM) 

 This feature is currently in Private Preview. It is intended for testing and
 evaluation purposes only and should not be used for production
 workloads. 

 To get started with Managed AIRS for AWS Private preview , send an
 email to dl-managed-airs-fw-preview@paloaltonetworks.com with your
 TSG ID of Strata Cloud Manager tenant. 

 Managed AI Runtime Security (AIRS) for AWS extends standard cloud firewall
 capabilities by introducing a dual-data plane architecture. 

 Managed AIRS for AWS provides deep contextual security specifically optimized
 for enterprise artificial intelligence pipelines, safeguarding high-throughput,
 low-latency environments like distributed training clusters, containerized Kubernetes
 pods, and large language model (LLM) infrastructures and the following advanced security
 vectors are activated: 

 Uses AI-powered security inspection to detect and block sophisticated
 threats, malicious prompts, and compliance anomalies targeting model
 traffic. 

 Delivers deep packet inspection tailored for containerized environments
 as well as non-AI traffic. 

 Key Benefits 

 Frictionless Setup and Centralized Management: Deploy AI Runtime
 Security with automated provisioning and auto-scaling. Streamline visibility
 and control through Strata Cloud Manager, eliminating the need for complex
 IAM configurations. 

 Advanced AI Threat and Data Protection: Block zero-day GenAI threats,
 such as toxic content and prompt injections. Maintain compliance with GDPR,
 HIPAA, and PCI-DSS using integrated Enterprise DLP that masks sensitive data
 patterns. 

 Zero Maintenance Operations: Experience a fully managed AIRS resource
 with automated elastic scaling and simplified deployment, eliminating the
 need for manual updates or infrastructure management. 

 For more information, see Deploy Managed AIRS for AWS in Strata Cloud Manager . 

 To get started with Managed AIRS for AWS Private preview , send an
 email to dl-managed-airs-fw-preview@paloaltonetworks.com with your
 TSG ID of Strata Cloud Manager tenant.
