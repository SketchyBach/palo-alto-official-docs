 dump bypass-pair config 

 Use the dump bypass-pair config command
to display bypass-pair configuration details. Information displayed
includes port names configured as part of a bypass-pair, status
of LAN state propagation—whether enabled or not, Hardware Relay
connection status, admin state, and use of the port for public or
private networks. 

 Command 

 dump bypass-pair config 

 Options 

 None 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands — 

 Introduced in Release 4.6.1
