 Integrate Prisma Access Browser with Votiro 

 Integrate the Prisma Access Browser with Votiro to scan and sanitize files that your
 users download or upload using the Prisma Access Browser . 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 Standalone Prisma Access Browser 

 Prisma Access with Prisma Access Browser bundle license or
 Prisma Access Browser standalone license 

 Role: Prisma Access Browser
 Roles 

 Votiro 

 You can integrate the Prisma Access Browser with Votiro to protect your organization
 from zero-day and undisclosed attacks by sanitizing files that your Prisma Access Browser users download or upload. Using Votiro's file sanitization technology, you can
 ensure that every downloaded or upload file in the Prisma Access Browser is free from
 threats. 

 After you configure the Vitiro integration, your Prisma Access Browser users will be
 able to use it as a file scanning engine. For more information, refer to Malicious File Protection . 

 Obtain the Votiro token. 

 Sign in to the Votiro management UI as the administrator. 

 Go to Configuration Service Tokens . 

 Create a new integration and copy the generated token to the
 clipboard. 

 Enable the Votiro integration in Strata Cloud Manager . 

 Go to Manage Configuration Prisma Access Browser Administration Integrations Services . 

 Scroll to Votiro Integration and expand
 it. 

 Click Enabled , then enter the Votiro
 URL and Votiro Token that you
 obtained. 

 Click Save .
