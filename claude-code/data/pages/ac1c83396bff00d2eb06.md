 Reference A: Create a Bitbucket Data Center PAT 

 Create a properly scoped Personal Access Token (PAT) for this integration. 

 Refer to the Bitbucket documentation for PAT details. 

 Navigate to Bitbucket Server → Manage account → Account settings → Personal access tokens . 

 Enter a token name. 

 Select the Permissions scope: 

 Projects : Administrator permissions. 

 Repositories : Administrator permissions. 

 Select Expire automatically . 

 Select Create . 

 Copy the generated token. 

 Repository permissions must match or exceed project permissions. An expiration requires token rotation before expiry.
