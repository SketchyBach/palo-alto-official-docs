 dump standingalarms 

 Use the dump standingalarms command
to display the outstanding alarms. Information displayed includes
the codes, alarm severity, time of alarm generation along with the
site ID. 

 Command 

 dump standingalarms

 Options 

 None 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands — 

 Introduced in Release 4.4.1

 dump standingalarms
