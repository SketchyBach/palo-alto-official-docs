 Use the dump vlan member command
to view the VLAN members of the switch ports. 

 Command 

 dump vlan member

 Options 

 None 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands — 

 Introduced in Release 6.0.2 

 Example 

 VLAN ID VLAN Name VLAN type Members
 -------- ------------------- --------- ----------------
 1 vlan1 data 10, 7, 8, 9
 1000 vlan_1000 data 5
 1001 vlan_1001 data 6
 * Default Vlan : vlan1
