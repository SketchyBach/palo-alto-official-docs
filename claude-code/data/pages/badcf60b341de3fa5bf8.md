 NGFW FedRAMP Moderate and High Support 

 Learn which apps and features NGFW FedRAMP Moderate and High environments support for
 use. 

 NGFW FedRAMP Moderate and High environments support the following apps and features for
 use. 

 Advanced WildFire (AWF), Advanced URL Filtering (AURL), and Advanced Threat
 Prevention (ATP) use single file manager to process data related to Inline Cloud
 Analysis. 

 AWF FedRAMP Mod customers who have been migrated to the new FedRAMP Moderate
 cloud FQDN should not enable Inline Cloud Analysis (ICA) if you are
 using AWF, AURL, and ATP in a FedRAMP Moderate deployment. You might encounter
 issues with AURL and ATP if your NGFW AWF configuration uses a FedRAMP Moderate
 FQDN and ICA is enabled. 

 To utilize ICA functionality for AURL and ATP, purchase a FedRAMP Moderate
 license and enable ICA .
