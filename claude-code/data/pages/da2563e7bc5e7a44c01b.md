Shell Write Access

Severity

🟢 Low (0)

Short Description

Flags extensions that can execute commands in the system shell.

Suggestion

Ensure the extension’s shell write capabilities are necessary and do not introduce security risks.

Information

Shell write access allows extensions to execute commands on the system shell, which could be exploited to modify system configurations or install malware.

Risks of Shell Write Capability

Remote Code Execution: Extensions may execute malicious scripts.

Privilege Escalation: Unauthorized commands could alter system settings.

Recommended Actions

Validate Shell Write Access:

Confirm the extension’s necessity for shell execution.

Ensure commands executed do not introduce risks.

Enhance Controls:

Block unauthorized shell execution.

Monitor executed shell commands for anomalies.
