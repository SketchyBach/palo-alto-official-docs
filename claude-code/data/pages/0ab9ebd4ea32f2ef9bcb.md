 INC_CIE_DIRECTORY_DISCONNECT 

 Learn about the INC_CIE_DIRECTORY_DISCONNECT incident. 

 Incident Code 

 INC_CIE_DIRECTORY_DISCONNECT 

 Title Template 

 Directory {directory_id} might be out of sync. {error_message} {action_message} 

 Category 

 Network Services 

 Subcategory 

 Authentication 

 Description 

 The directory service within the Cloud Identity Engine (CIE) is disrupted or disconnected. The directory service is crucial for authentication, user management, and policy enforcement within the Prisma Access environment. When the connection to the directory service is lost, it can lead to authentication failures, user access issues, and policy enforcement gaps. It is essential to investigate and address the directory service disconnection promptly to restore proper functionality and security within the Prisma Access environment. 

 Raise Condition 

 Incident is Raised when the CIE directory is out of sync 

 Clear Condition 

 Incident is Cleared when the CIE directory is in sync
