 Features Introduced in Prisma Access 1.6.1 

 The following table describes the new features introduced
in Prisma Access version 1.6.1. 

 Feature 

 Description 

 Simplified License Activation 

 If you are new to Prisma Access and activating
your product for the first time, or adding a different license type
to an existing license, the improved process steers you through
the activation flow so you can quickly get started with using Prisma
Access to secure your network and users. It doesn’t matter if you
plan to use Panorama or Cloud Management, the activation process
is just as speedy. The license activation email enables you to view
and activate all your Prisma Access purchases and tie them to a
Customer Support account in one streamlined flow on the Hub.
