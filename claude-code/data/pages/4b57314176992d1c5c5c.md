 Configure the Egress Path 

 Understand how to configure egress, per-tenant interconnect and shared
 interconnect 

 Where Can I Use
 This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Tenant or Tenant Service
 Group (TSG) 

 Role : Multitenant
 Superuser or Superuser 

 The Egress Path determines how traffic originating from your Prisma Access mobile
 users and remote networks exits to its destination. You must configure the egress
 path on the root tenant. When you are configuring the SP interconnect for the first
 time, you will be prompted to choose the Egress path: 

 Egress back to the service provider network - All
 outbound traffic from Prisma Access is routed back to your SP network
 before heading to its final destination. Supported for GCP and AWS. 

 Egress via Prisma Access default interconnect - Outbound traffic is
 sent directly via the default Prisma Access internet path. Supported only
 for GCP. 

 After you configure the egress path, continue to the ingress interconnect
 configuration. Note that once the ingress configuration is complete, the
 selected egress path cannot be modified.
