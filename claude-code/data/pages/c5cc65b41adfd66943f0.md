Expanded suspicious activity detection in SIA RDP sessions
NEW
July 21, 2026

Session monitoring now includes AI-powered detection of risky activities in interactive RDP sessions managed through Secure Infrastructure Access (SIA). Previously, detecting risky activities within a session based on the Windows title was native to Privileged Session Manager (PSM).

AI reads and parses active window titles during SIA RDP sessions to detect suspicious behavior, aligning SIA RDP protection with the existing SSH and command-line protections. This gives you uniform, automated, multi-protocol session visibility across your hybrid infrastructure, no matter how users connect.

For more information, see Suspicious activities in sessions alerts.

For more information about AI-based monitoring of SIA RDP sessions, see Use CORA AI to summarize RDP session audits.
