 Back up and Restore Cortex XSOAR 

 Back up and restore data in Cortex XSOAR 8.9 On-prem. 

 You can periodically back up data, configurations, and settings to ensure continuous and efficient operation of your Cortex XSOAR tenant. This minimizes downtime, prevents data loss, and helps you to recover in case of failure, corruption, or rollback. 

 You can perform on-demand or scheduled backups and on-demand restore from external storage. 

 Note 

 If you used backup and restore in Cortex XSOAR 8.8, after upgrading to Cortex XSOAR 8.9 the following will happen: 

 Backup and restore via the CLI is deprecated in Cortex XSOAR 8.9. 

 Your NFS server connection will be seamlessly created under Settings & Info → Settings → System → External Storage . 

 Any existing backup schedules will be seamlessly created in the system and will continue to back up at the same scheduled times. If you see an error message that the schedule cannot be converted, contact support. 

 Cortex XSOAR 8.8 backups can be viewed in the Restore tab by choosing the automatically created external storage, and the default relative path backups .
