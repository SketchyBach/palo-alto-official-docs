 Features Introduced in 2025 

 December 22, 2025 

 This section describes a feature change of the Cortex XSIAM 3.3 release. 

 XDR Collectors 

 XDR Collectors 1.5.1 : Windows 1.5.1.2048 and Linux 1.5.1.1950 

 XDR Collectors 1.4.3 : Windows 1.4.3.1686 

 FEATURE 

 DESCRIPTION 

 XDR Collector error visibility and auditing 

 Health reporting has been adjusted to reduce noise, allowing for more precise calibration and ongoing improvements to the monitoring system. The Status column on the XDR Collectors Administration page will no longer display real-time status updates for individual collectors.
