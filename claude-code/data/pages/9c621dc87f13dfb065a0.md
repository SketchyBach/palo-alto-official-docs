 Install the PA-400R Series Firewall on a DIN Rail 

 Install a PA-400R Series firewall in an equipment rack on a DIN rail. 

 The PA-410R and PA-410R-5G firewalls can be installed
 on a DIN rail using PAN-PA-RGD-DIN-CLIP. This DIN rail mounting clip must be
 purchased separately. 

 Using four M4 screws, install the DIN rail mounting clip to the back panel of
 the device. Ensure that you orient the firewall so that the bottom panel of the device is facing downwards and the
 DIN rail mounting clip aligns with the DIN rail. 

 Using slight downward pressure, attach the firewall onto the DIN rail so that
 the two metal clips lock into place. 

 Keep the device clean and clear of dust
 to ensure optimal heat dissipation and maintain proper hardware
 operation.
