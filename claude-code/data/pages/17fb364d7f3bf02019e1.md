 Prisma Access Activity Dashboards and Reports 

 Prisma Access Activity Dashboards and Reports provide interactive dashboards,
 reports, log viewer, and search capabilities to analyze network data and inform policy
 updates. 

 Where can I use
 this? What do I need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 Prisma Access 
 license 

 Review the
 licenses and other requirements for Activity dashboards and
 reports 

 Activity identifies key findings that you
 can use to inform your policy updates and close enterprise security and user
 productivity gaps. Activity gives you: 

 Interactive dashboards where you can explore data for the applications,
 threats, users, and, security subscriptions at work in your network. 

 Reports that you can share offline and schedule for regular updates. 

 Log Viewer provides an audit trail for system, configuration, and network
 events. You can jump from dashboards to the Log Viewer to get more context
 and drill down on data. 

 Search for Security Artifacts helps you to search on artifacts such as a file
 hash, a URL, a domain, or an IP address (IPv4 or IPv6) to interact with data
 just for that artifact. Search results include the history of artifact,
 threat intelligence on the artifact, and third-party analysis findings for
 the artifact. 

 Insights is supported as part of Prisma SASE FedRAMP High “In Process” certification.
 Activity is supported as part of Prisma SASE FedRAMP High “In Process”
 certification.
