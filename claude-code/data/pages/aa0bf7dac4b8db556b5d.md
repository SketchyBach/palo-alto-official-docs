 Branch Microsegmentation 

 Learn to update the Shasta switch profile to enable Port Isolation and the Network
 SSID to Client Isolation. 

 To enforce host segmentation and isolate wireless and wired ports, you must
 update the Shasta switch profile to enable Port Isolation and the Network SSID to
 Client Isolation. 

 Where Can I Use This? What Do I Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 On the CloudBlades page, select Configure on the Shasta LAN tile and
 select Manage Shasta. 

 Select Infrastructure > Profiles and edit the switch profile that you
 want to enable segmentation. 

 Select Configuration and Enable Port Isolation . 

 Choose the Uplink and Downlink Ports that connect to other Shasta
 devices and Prisma SD-WAN ION devices. 

 To apply isolation to Access Points, navigate to Networks , select the
 name, and apply Client Isolation.
