 Release Notes: VSatellite 

 VSatellite is a component that enables secure communication between CyberArk Certificate Manager - SaaS and your private network resources, allowing certificate discovery, issuance, and management for on-premises infrastructure. 

 Come back here to learn about current and past releases. 

 Release 2.0.26 

 23 April 2026 

 This release focuses on improving connector deployment capabilities. 

 Key Features 

 Connectors Deployment Improvements : Enhanced the deployment process for connectors, providing better reliability and performance. 

 Release 2.0.25 

 30 March 2026 

 This release addresses Microsoft AD CS integration issues and provides additional authentication visibility. 

 Key Features 

 Microsoft AD CS Chain Retrieval Fix : Resolved a bug related to Microsoft AD CS certificate chain retrieval. 

 Microsoft AD CS Authentication Type Reporting : Added reporting capabilities for Microsoft AD CS authentication type information, improving visibility into authentication methods. 

 Release 2.0.24 

 11 March 2026 

 This release focuses on improving websocket connection reliability. 

 Key Features 

 Websocket Connection Improvements : Enhanced websocket connection stability and performance. 

 Release 2.0.23 

 10 March 2026 

 This release continues to enhance websocket connection capabilities. 

 Key Features 

 Websocket Connection Improvements : Further improvements to websocket connection reliability and performance. 

 Release 2.0.22 

 04 March 2026 

 This release introduces direct Microsoft AD CS communication support and addresses key generation issues with HSM. 

 Key Features 

 Direct Microsoft AD CS Communication : Introduced support for direct communication between the satellite and Microsoft AD CS server, eliminating intermediary requirements. 

 HSM Key Generation Fix : Fixed a bug related to key generation when used with HSM (Hardware Security Module). 

 Websocket Connection Improvements : Continued enhancements to websocket connection stability. 

 Release 2.0.21 

 19 February 2026 

 This release updates the underlying GO runtime and addresses security vulnerabilities. 

 Key Features 

 GO Version Update : Updated GO version to 1.25.6, ensuring compatibility with the latest language features and improvements. 

 CVE Fixes : Resolved multiple Common Vulnerabilities and Exposures (CVE) issues, strengthening security posture.
