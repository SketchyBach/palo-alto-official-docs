 Supported regions 

 Supported regions in which you want to host Cortex Data Security and any associated services. The following table lists the regions available to host Cortex Data Security and any associated Cortex services: 

 Americas 

 Country 

 Description 

 US (United States) 

 All Cortex Data Security logs and ingested data remain hosted within the boundaries of the United States. 

 Brazil (BR) 

 All Cortex Data Security logs and ingested data remain hosted within the boundaries of Brazil. 

 Canada (CA) 

 All Cortex Data Security logs and ingested data remain hosted within the boundaries of Canada. However, if you have a WildFire Canada cloud subscription, consider the following:
• You cannot send file submissions for bare-metal analysis.
• You will not be protected against macOS-borne zero-day threats. However, you will receive protection against other macOS malware in regular WildFire updates.
