 Custom Reports 

 Custom Reports is a WYSIWYG editor in AI Canvas for building multi-page security
 reports that you can download, share, or schedule as PDF output. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 Strata Cloud Manager
 Pro license 

 Prisma Access license 

 Standard report templates may not include the specific data your audience needs. Strata Cloud Manager provides option to create custom reports with AI Canvas editor
 that lets you design multi-page security reports where the editor view matches the final
 PDF output. You can build a report from scratch or start from a pre-built template
 (called widgets), organizing content across as many pages as your report requires. Each
 page supports a different layout, and you can add, remove, or reorder pages at any point
 during editing. 

 The widget library for Custom Reports draws from the same AI Canvas widget library but includes only the
 visualization types that render accurately in static PDF output: bar charts, horizontal
 bar charts, grouped and stacked bar charts, line charts, donut charts, pie charts,
 single-value widgets, tables, and text boxes. Widgets that require user interaction to
 reveal core data are not available in the report editor. Table widgets support flexible
 column configuration so you can include only the fields relevant to your audience. When
 a table contains more rows than it can fit on a single page, the editor automatically
 paginates the content and repeats column headers on each subsequent page. 

 Filters in Custom Reports apply globally across every widget on every page of the report
 simultaneously. The filters available in a given report adjust dynamically based on the
 widgets present, so the filter options reflect the data sources currently in use. You
 can configure filters such as time range, user, application, and region The filter
 configuration is saved with the report so you don't need to reapply it each time you
 generate or schedule the report. 

 You can also use Strata™ Copilot to populate a widget by describing the content you want
 in natural language. The editor analyzes the prompt and uses appropriate widgets from
 the library to build the page layout. If the page already contains content, the editor
 prompts you to confirm before replacing it. 

 When a report is complete, it is saved and appears in the Custom
 Reports section of the Strata Canvas Reports page.
