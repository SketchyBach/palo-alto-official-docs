 HTTP Header Expansion 

 Headers can now support values of up to 16K bytes. 

 Palo Alto Networks HTTP header insertion entries
now support header values up to 16K bytes. The larger header value
size enables you to manage access to SaaS applications that require longer
values and specify more tenants that users on your network can access.
For example, if you currently have tenant restrictions configured
for Microsoft Office 365 but could not list some approved tenants
under the Restrict-Access-To-Tenants HTTP
header due to size constraints, you can now include additional domains
or directory IDs registered with tenants. 

 Add or select a URL Filtering
Profile to include the HTTP header insertion entry. 

 Select Objects Security
Profiles URL Filtering HTTP
Header Insertion . 

 Add an entry. 

 Specify a Name and
a custom or predefined Type . 

 Select a Header and enter a Value (up
to 16,000 bytes). 

 Click OK to save your changes. 

 Click OK to save the URL Filtering
Profile.
