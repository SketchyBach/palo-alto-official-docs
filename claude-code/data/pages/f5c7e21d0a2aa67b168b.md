 ION 2000 Installation Kit Components 

 Learn the various installation kit components of the
 ION 2000. 

 The ION 2000 installation kit contains
the following parts and tools to install the device: 

 1x 36W power adapter 

 1x USB-to-RJ45 cable 

 1x power cord, which varies depending on the country or region 

 The following hardware parts are optional and must be ordered
separately: 

 Rack-mount kit: 

 2x rack brackets 

 1x screw kit 

 Wall-mount kit: 

 2x wall brackets 

 1x screw kit 

 Additional external power supply kit: 

 1x extra
power supply and connector 

 1x power cable
