 Deploy the CN-Series Firewall with Rancher Orchestration 

 Where Can I Use This? What Do I Need? 

 CN-Series deployment 

 CN-Series 10.2.x or above Container Images 

 Panorama running PAN-OS 10.1.x or above version 

 You can now deploy the CN-Series firewall as a Kubernetes
service using the Rancher orchestration and PAN OS 10.1. Rancher is
an open source container orchestration platform that you can use
to deploy the CN-Series firewall. 

 For CN-Series firewall deployment with Rancher cluster support,
your Panorama instance must have 16 vCPUS, 32G memory with an extra
2TB disk. Panorama will be deployed in a mode that will facilitate
collecting logs from the CN-Series firewall deployments. 

 When deploying the CN-Series firewall within On-Premises Rancher
Kubernetes cluster, do the following: 

 Ensure that the Components Required to Secure Kubernetes Clusters with the CN-Series Firewall are
 available. 

 Ensure that the Kubernetes cluster meets the minimum system requirements. For more information,
 see CN-Series System Requirements . 

 Perform the Deploy the CN-Series Firewall with Rancher Orchestration . 

 Modify the Rancher Cluster Options YAML File 

 Install the Kubernetes Plugin for CN-Series
 Firewall . 

 License the CN-Series Firewall . 

 Deploy the CN-Series Firewall as a Kubernetes Service (Recommended mode of Deployment) on Rancher.
