 dump spoke-ha failover-timeline 

 Use the dump spoke-ha failover-timeline command to displays a
 chronological record of High Availability (HA) events. Use this command to measure
 failover convergence time and identify bottlenecks when a branch device transitions from
 standby to active in an branch HA configuration. 

 This timeline reflects the status of the primary WAN instance, including the first WAN
 interface IP address, route, and Prisma SD-WAN Secure Fabric Link. 

 Became Active: The time the system or device transitioned to the active role in the
 HA pair. 

 Interface and GARP: The time the system programmed the first WAN interface and sent
 a Gratuitous ARP (GARP) on the LAN side to attract traffic. 

 Routes programmed: The time the system installed routes for the first WAN interface
 in the route table. 

 Traffic start: The time the device became ready to forward traffic. 

 Prisma SD-WAN Secure Fabric Link up: The time the system established the first
 Prisma SD-WAN Secure Fabric Link tunnel. 

 The timeline displays all timestamps using US date annotation
 and a 12-hour clock (for example: 2026-02-24 16:01:48.827). 

 Command 

 dump spoke-ha failover-timeline 

 Options 

 None 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands — 

 Introduced in Release 6.6.1

 dump spoke-ha failover-timeline
