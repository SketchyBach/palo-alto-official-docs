 Deploy the VM-Series Using the Operations-Centric Workflow 

 Review the overview of the operations-centric workflow. 

 Where Can I Use This? What Do I Need? 

 VMware NSX 

 VM-Series Firewall License (BYOL) 

 Panorama 

 VM-Series plugin 

 Panorama plugin for NSX 

 In an operations-centric workflow, some portions of the deployment procedure
 are performed on Panorama and the remainder are performed on NSX-T manager. On Panorama,
 you must first enable communication between Panorama and NSX-T Manager, configure the
 service definition, and launch the VM-Series firewall. Then, you must log in to NSX-T
 Manager to continue the configuration by creating service chains and steering rules. To
 complete your VM-Series deployment, you must return to Panorama to create a security
 policy. 

 This option is well suited if your security administrator has access to both your NSX-T
 environment and Panorama. Additionally, choose this option if you have a complex NSX-T
 deployment and requires frequent changes to NSX-T steering rules. 

 Operations-centric workflow overview: 

 Panorama: Install the Panorama Plugin for VMware NSX 

 Panorama: Enable Communication Between NSX-T Manager and Panorama 

 Panorama: Create Template Stacks and Device Groups on Panorama 

 Panorama: Configure the Service Definition on Panorama 

 Panorama: Launch the VM-Series Firewall on NSX-T (East-West) 

 NSX-T Manager: Add a Service Chain 

 NSX-T Manager: Direct Traffic to the VM-Series Firewall 

 Panorama: Apply Security Policies to the VM-Series Firewall on NSX-T (East-West) 

 Optional VM-Series Firewall: Use vMotion to Move the VM-Series Firewall Between Hosts
