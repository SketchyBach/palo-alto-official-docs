 Prisma Access CloudBlade Integration Release 3.1.6 

 Learn about the Prisma Access CloudBlade Integration release 3.1 6 release
 information. 

 It is required for Prisma SD-WAN tenants created after August 20, 2022 to
 use the 3.1.6 version of the Prisma Access for Networks CloudBlade (Cloud managed).
 This release includes an SDK update required for new tenants created after August 20th.
 There is no change in functionality compared to the 3.1.5 version of the Prisma Access .
