 View All API Keys 

 Use this command to show all API keys along
the date the key was generated and the last time the key was used. 

 Use this command to show all API keys along the
date the key was generated and the last time the key was used. 

 admin@WF-500> show
wildfire global api-keys all 

 In this example,
the API responds with the API key named my-api-key :

| Apikey | Name | 
+---------------------------------------------------+------------+ 
| <API KEY> | my-api-key | 
+---------------------------------------------------+------------+ 
+---------+---------------------+---------------------+ 
| Status | Create Time | Last Used Time | 
+---------+---------------------+---------------------+ 
| Enabled | 2017-03-02 19:14:36 | 2017-03-02 19:14:36 |
