 What's New in Network Discovery 3.2.1 

 The following new feature is introduced in the Network Discovery 
 plugin 3.2.1 for PAN-OS 12.1.2 and later.

 New Feature Description 

 PA-1500 Series Firewall Support 

 PAN-OS 12.1.2 and later 

 The Network Discovery plugin now supports
 PA-1500 series firewalls (PA-1510, PA-1520, and PA-1530),
 expanding the range of hardware on which you can run network
 discovery.

 What's New in Network Discovery 3.2.0 

 The following new features are introduced in the Network Discovery 
 plugin 3.2.0 for PAN-OS 12.1.2 and later.

 New Feature Description 

 Expanded SNMPv3 protocol support 

 PAN-OS 12.1.2 and later 

 The Network Discovery plugin now supports
 additional SNMPv3 authentication protocols (SHA-224, SHA-256,
 SHA-384, and SHA-512) and privacy protocols (AES-192, AES-256,
 and 3DES). This expansion lets you align SNMP polling with
 stricter cryptographic standards required in regulated
 environments.

 Additional OT polling protocol support 

 PAN-OS 12.1.2 and later 

 The Network Discovery plugin now polls
 operational technology (OT) devices using Beckhoff (UDP),
 Siemens Webserver, Codesys (TCP), and GE Carescape patient
 monitors. With these additions, you can discover and profile
 a broader range of industrial and medical devices on your
 network.

 Test and debug CLI commands 

 PAN-OS 12.1.2 and later 

 A new set of CLI commands let you validate connectivity, test
 polling queries, and gather diagnostic data for the
 Network Discovery plugin directly from the
 firewall. See
 Test and Debug the Network Discovery Plugin .
