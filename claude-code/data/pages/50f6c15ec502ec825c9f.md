 Prisma Access CloudBlade Release 3.1.6 

 Learn about the Prisma Access CloudBlade integration with Prisma SD-WAN version 3.1.6
 release information. 

 This document contains the Prisma Access for Networks (Panorama Managed) CloudBlade,
 version 3.1.6 release notes. 

 Features Introduced in Prisma Access CloudBlade 3.1.6 

 The new/updated features introduced in Prisma Access CloudBlade version 3.1.6
 are: 

 It is required for Prisma SD-WAN tenants created after
 August 20, 2022 to use the 3.1.6 version of the Prisma Access for
 Networks CloudBlade (Panorama Managed). This release includes an SDK
 update required for new tenants created after August 20th. There is no
 change in functionality compared to the 3.1.5 version of the Prisma Access for Networks CloudBlade (Panorama Managed). 

 Customize names of the objects created by the Prisma Access CloudBlade
 (Panorama managed) by using the tag
 prisma_name:<custom_name> for a site. Note
 that you can customize this tag only for newer site onboardings.
