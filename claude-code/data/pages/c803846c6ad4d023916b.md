 PA-220R Physical Specifications 

 Learn about the PA-220R firewall physical specifications. 

 The following table describes PA-220R firewall physical specifications. 

 Specification Value 

 Dimensions and Rack units (U) 

 Firewall Dimensions 

 2.0” H x 8.66” D x
9.25” W (5.08cm H x 22cm D x 23.5cm W) 

 The depth measurement
includes hardware that protrudes from the front of the firewall.
If the rubber feet are installed on the bottom of the firewall,
add .78” (2cm) to the height. 

 Rack Units 

 The
following dimensions apply when the firewall is installed in the
PA-220R 19-inch rack kit: 

 Rack units —2U 

 Rack kit dimensions —3.5” H x 8” D x 19” W (8.89cm H x
20.32cm D x 48.26cm W) 

 Weight 

 Firewall weight —4.5 lbs. (2.04kg) 

 Shipping weight —6 lbs. (2.72kg)
