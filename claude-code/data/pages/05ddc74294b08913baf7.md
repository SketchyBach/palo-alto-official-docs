 List View Options 

 In the Cortex Xpanse Expander, you can filter page results, manage columns and rows, and save or share the filters. 

 Many pages in Cortex Xpanse present lists in a table format and provide controls to help you manage and filter the results. If additional views or actions are available for a specific value, you can pivot (right-click) from the value in the table. For example, you can view the incident details or you can pivot to the results for a query. 

 On most pages, you can also refresh ( ) the content on the page.
