 dump-support 

 Use the dump-support command to download all the CLI command
 outputs, cores and device logs in a tar file. Saves the log file in your home directory;
 You can list the files using the file list command. You can also
 export the file to an SCP server using the file export command. 

 Command 

 dump-support ( all | cores | syslog |outputs ) file= <tar_name> 

 Options 

 syslog Enter syslog to collect all the syslog
 files. Release 6.4.1 

 cores Enter core to collect all the core files. Release
 6.4.1 

 outputs Enter output with a file name tp collect all the
 output files to be exported. It displays the device configuration,
 current state, logs, and core dump summaries. 

 all Enter all to capture syslog, core and output files to
 be exported. Release 6.4.1
