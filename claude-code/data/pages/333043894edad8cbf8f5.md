 Assign the ION Device 

 Learn about how to assign the ION device. 

 Where Can I Use
 This? What Do I
 Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 You may begin to assign devices to the branch
or data center site. Assigning a device simply means that you are
associating it with a specific branch or data center site. With
the exception of ports on the physical and virtual devices, the
steps to assign and configure the devices are identical. 

 Select Configuration Prisma SD-WAN ION Devices Claimed 

 Under State , select the icon. 

 A drop-down displays. 

 Select Assign to a site to assign
the device to a site. 

 Enter the name of the branch site, or select the branch
site to associate the site with the device from the list of sites. 

 Select Done . 

 The device assignment occurs in the background; if it shows green, it is up, and red for
 down.
