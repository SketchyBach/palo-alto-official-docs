 Manage Data Security Administrators 

 Add Data Security administrators, manage authentication, create admin teams, and
 view activity on the Data Security dashboard. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 Data Security license 

 Or any of the following licenses that include the Data Security license: 

 CASB-X 

 CASB-PA 

 To resolve incidents identified by Data Security , you must be able to understand the
 content and the context around each incident to determine if the incident poses a threat
 to sensitive data or intellectual property. Depending on the size of your organization,
 the number of SaaS apps you manage, and the total number of managed assets and users,
 you can create more than one administrative account with access to manage all cloud apps
 or a team administrator to manage a group of apps on Data Security . 

 For example, you can delegate risks found in financial documents to the team administrator of the
 Box folder for your finance department and delegate risks in your GitHub repository to
 the GitHub administrator in your engineering department without giving them access to
 every cloud app. If your administrator role has access to all SaaS apps, you can assign
 incidents to the appropriate administrator to resolve, either manually or by configuring
 automated remediation in the affected policy.
