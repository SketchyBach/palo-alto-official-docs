 Upgrade a Panorama Plugin 

 You can upgrade your Panorama plugin to take advantage of the latest features and
 functionality. 

 Use the following procedure to upgrade the version of most plugins installed on your
 Panorama management server. When upgrading one of the plugins listed below, use the
 procedure at the link provided. To upgrade to the latest VM-Series plugin, 

 Upgrade the Enterprise DLP Plugin 

 Upgrade the Panorama Interconnect Plugin 

 See the VM-Series for VMware NSX documentation 
 when upgrading the Panorama plugin for VMware NSX. 

 Refer to the Compatibility Matrix for the minimum
 supported PAN-OS version for each Panorama plugin. 

 Review the Panorama Plugin Release Notes to
 identify your target plugin version. 

 Review the Panorama Plugins Upgrade/Downgrade Considerations . 

 Beginning
 with PAN-OS 12.1.2, you no longer have to manually find and download compatible
 plugin versions before installing them. Now, compatible plugins are
 automatically downloaded with the Panorama image, and you can directly install
 the ones you need. For more information on plugin bundling, see Panorama Plugins . 

 Download the plugin. 

 Select Panorama Plugins . 

 Select Check Now to retrieve a list of available
 updates. 

 Select Download in the Action column to download
 the plugin. 

 Install the plugin. 
 Select the version of the plugin you downloaded in the previous step and click
 Install in the Action column to install the plugin.
 Panorama will alert you when the installation is complete. 

 When installing the plugin for the first time on a Panorama HA pair,
 install the plugin on the passive peer before the active peer. On
 installing the plugin on the passive peer, it transitions to a
 non-functional state. Then, after you successfully install the plugin on
 the active peer, the passive peer returns to a functional state. 

 Optional You can review your plugin upgrade logs using the following
 CLI commands. 

 tail plugins-log ...
tail mp-log plugin_install.log
