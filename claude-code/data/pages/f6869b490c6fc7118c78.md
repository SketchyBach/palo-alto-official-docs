 ION 1000 Installation Kit Components 

 The Prisma SD-WAN ION 1000 comes with installation kit
that contains tools to install the device. 

 The ION 1000 installation kit contains
the following parts and tools to install the device: 

 1x 36W power adapter. 

 1x power cord, which varies depending on the country or region. 

 The following optional hardware parts must be ordered separately: 

 Additional external power supply kit: 

 1x
power adapter. 

 1 x region specific power cable. 

 1x USB to RJ45 serial cable. 

 Rack mount kit. 

 Wall mount kit.
