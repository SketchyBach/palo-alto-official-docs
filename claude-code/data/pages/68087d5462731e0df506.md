 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 Advanced SD-WAN license for NGFW 

 NGFW Not Connected to Strata Cloud Manager 

 If the NGFW is not connected to SCM: 

 First check the management interface for connectivity. 

 Check cloud-management-status . 

 Check device-certificate status . 

 NGFW Connection to Controller 

 To check the NGFW connection to the Prisma SD-WAN controller, run the command:
 show csdwan device-reachability . 

 VPN Issues 

 To check the VPN connection issue on the ION device, run the command:
 dump vpn summary and dump vpn status
 VpnID=<> . 

 To check the VPN connection issue on the NGFW, run the command: show
 interface ethernet1/1 .
