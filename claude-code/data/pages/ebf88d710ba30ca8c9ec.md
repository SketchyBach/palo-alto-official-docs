 Use
an SNMP Manager to Explore MIBs and Objects 

 To use SNMP for monitoring Palo Alto Networks firewalls,
Panorama, or WF-500 appliances, you must first load the Supported MIBs into
your SNMP manager and determine which object identifiers (OIDs)
correspond to the system statistics and traps you want to monitor.
The following topics provide an overview of how to find OIDs and
MIBs in an SNMP manager. For the specific steps to perform these
tasks, refer to your SNMP management software.
