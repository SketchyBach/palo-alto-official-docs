 Device Security Extended API Functionality 

 Release Date: February 2025 
 | 
 Last Updated: May 2026 

 Device Security extends API support to include getting all saved filters and managing custom attributes. You can use GET Filters to retrieve a list of saved filters. To create, delete, and edit custom attributes, use the following new API requests: 

 POST – Create a new custom attribute 

 DEL – Delete a custom attribute 

 GET – Get a list of custom attributes 

 PUT – Update a custom attribute
