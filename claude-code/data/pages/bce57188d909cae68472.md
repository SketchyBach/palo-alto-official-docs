 Create the Read-Only Dashboard 

 Create a read-only dashboard for Cortex XSOAR 6.14 users. 

 When creating the read-only dashboard, from the Quick Chart definitions window, in the Data query field, ensure that you add the createdBy:{me} filter. 

 ro-dashboard-filter.png 

 This allows users to see their own data in the dashboard. The administrator can see the dashboard but cannot see the data. 

 ro-dashboard.png 

 Share the dashboard with the read-only user after you create it. For information about creating dashboards, see Create a New Dashboard .
