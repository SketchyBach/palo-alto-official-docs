 Enable Advanced DNS Security Resolver 

 Learn to enable the Advanced DNS Security Resolver by creating or modifying profiles,
 verifying connection sources, and reviewing optional security tasks before
 deployment. 

 Where Can I Use
 This? What Do I Need? 

 Strata Cloud Manager 

 Advanced DNS Security Resolver License 

 To enable the Advanced DNS Security Resolver, you must create (or modify) a DNS
 Security profile and add/verify connection sources used by the Advanced DNS Security
 Resolver service. There are optional tasks that provide extended functionality and
 additional security options. 

 Please review all of the steps below before committing to the deployment process. 

 Verify that you have a license for
 the Advanced DNS Security Resolver . 

 Log in to the Strata Cloud Manager on the hub . 

 Configure an Advanced DNS Security Resolver security profile. You can also use
 the default best-practice security profile, however, you should still review the
 configuration to verify that it is appropriate for your deployment. 

 Alternatively, you can create an Advanced DNS Security Resolver security
 profile from the Create Connection Source menu ( Configuration ADNS Resolver . This allows you to create a security profile (step 2)
 and add connection sources as part of a single workflow (step 6). 

 Select Configuration ADNS Resolver and then go to the DNS Security
 Profiles tab. 

 Select Create DNS Security Profile and in the
 General tab, provide a name and description
 for the security profile. 

 In the Categories tab, for each of the domain
 categories listed under the primary groupings
 ( Content , DNS
 Security , and Advanced DNS Security ),
 specify a policy Action to take when a
 corresponding domain type is detected. 

 Policy Action
 Options: 

 allow —The DNS query is allowed. 

 alert —The DNS query generates an
 alert. DNS queries that generate an alert are saved in the
 DNS Security log. 

 block —The DNS query is blocked. 

 sinkhole —Forges a DNS response for a
 DNS query targeting a detected malicious domain. This
 directs the resolution of the malicious domain name to a
 specific IP address (referred to as the Sinkhole IP), which
 is embedded as the response. 

 (Optional) Add domains that you want the ADNS
 Resolver to bypass . If your organization uses third party
 threat feeds as part of a comprehensive threat intelligence solution,
 you can also reference those in the form of external dynamic lists
 (EDLs) as part of your overrides configuration. 

 Review your Advanced DNS Security Resolver configuration settings and provide
 connection sources. 

 Select Configuration ADNS Resolver and then go to the DNS Resolver
 Configurations tab. 

 From here, you can review your DNS resolver details: 

 Connection Source Verification
 Status —Provides a breakdown of the verification
 status of all the connection sources you have added to your Advanced DNS Security Resolver configuration. You must validate the egress
 IP address of a connection source to enable processing of DNS
 requests. If the IP is not validated, it is not considered to be
 part of the network and requests to that IP are rejected. 

 DNS Resolver Info —The Palo Alto Networks
 Advanced DNS Security Resolver server details. The server that you
 connect to is dependent on your geolocation. The Advanced DNS
 Security Resolver connects you to the service via an anycast IP
 to provide optimum service reliability and performance. You can
 toggle between IPv4 and IPv6 values, as necessary. 

 DNS Sinkhole Settings —Indicates the
 currently selected DNS sinkhole server (the default is the Palo
 Alto Networks hosted DNS sinkhole) and the configured block page
 contents. 

 Connection Sources —Lists all of the
 connection sources added to your Advanced DNS Security Resolver.
 Connection sources are egress IP addresses in your
 branch/campus/datacenter that will be subject to the security
 policies dictated by the Advanced DNS Security Resolver
 policies. 

 Add and configure connection sources to your Advanced DNS
 Security Resolver configuration. 

 ( Internal DNS Server ) Configure your internal DNS server to use the
 Advanced DNS Security Resolver anycast IP addresses located under DNS
 Resolver Info . 

 Configure your ADNS Resolver sinkhole settings and,
 optionally, configure a customized block page. 

 (Optional) Update your access control configuration to
 include . The following default
 Enterprise Roles provide multiple read and write permissions for the Advanced DNS Security Resolver (shown as Atmos Resolver ): 

 (Optional) Add internal domains to be excluded from getting processed by
 the Advanced DNS Security Resolver. 

 (Optional) Search for threat intelligence that Palo Alto
 Networks has collected for a domain using Strata Cloud Manager IOC Search.

 The IOC Search does not currently support visualization of local network
 activity seen by the Advanced DNS Security Resolver. 

 (Optional) Review logs generated by the 

 (Optional) View Activity Insights: Domains for a high
 level view of the trends and statistics of your DNS Security
 usage .
