 Where Can I Use This? What Do I Need? 

 NGFW (Managed by Panorama or Strata Cloud Manager)

 Prisma Browser 

 Enterprise Data Loss Prevention (E-DLP) license 

 Review the Supported
 Platforms for details on the required license

 Or any of the following licenses that include the Enterprise DLP license 

 Prisma Access CASB license 

 Next-Generation
CASB for Prisma Access and NGFW (CASB-X) license 

 Data Security license 

 Known issues that impact the Enterprise Data Loss Prevention (E-DLP) cloud service can impact NGFW and Prisma Access tenants managed by either Strata Cloud Manager or a Panorama® management server , or Prisma Browser . 

 DSS-25541 

 Enterprise DLP incidents ( Configuration Data Loss Prevention DLP Incidents ) don't display the full snippet details if the matched sensitive data is
 999 characters away from the proximity keyword for a custom data pattern or a cloned
 custom data pattern. 

 DSS-22556 

 Enterprise DLP Audit Logs ( Manage Configuration Data Loss Prevention Audit Log ) may display the incorrect Time a data profile ( Manage Configuration Data Loss Prevention Data Profile ) configuration change occurred. 

 DSS-22522 

 Adding the predefined Address - Cyprus data pattern to a
 data profile that includes the predefined National Id - US Social Security
 Number - SSN data pattern results in inaccurate SSN detections. 

 DSPM-636 

 Snippets fail to display in the Data Asset Explorer ( Manage Configuration Data Loss Prevention Data Asset Explorer ) Asset Details page.
