 PAN-TRAPS.my 

 Use PAN-TRAPS.my to see a complete listing of all the
generated traps and information about them (for example, a description).
For a list of traps that Palo Alto Networks firewalls, Panorama, and
WF-500 appliances support, refer to the PAN-COMMON-MIB.my panCommonEvents panCommonEventsEvents panCommonEventEventsV2 object.
