 Upgrade/Downgrade Considerations 

 Review the upgrade and downgrade considerations for the Network Discovery
 plugin. 

 Where Can I Use This? What Do I Need? 

 NGFW (Managed by PAN-OS or Panorama) 

 One of the following subscriptions: 

 Device Security subscription

 Precision AI bundle subscription

 Device Security X subscription

 The following table lists the features that have upgrade or downgrade impact. Make sure
 you understand all upgrade and downgrade considerations before you upgrade to or
 downgrade from a Network Discovery plugin release. 

 Feature Upgrade Considerations Downgrade Considerations 

 — 

 Network Discovery 3.0.1 

 Network Discovery 3.0.1 can only be installed on
 firewalls managed directly. If you are managing your firewalls
 on Panorama , you need to switch to direct management
 of your firewalls to upgrade.

 If you want to downgrade to Network Discovery 3.0.0,
 you need to do so directly on the firewall. You cannot downgrade
 through Panorama .

 — 

 Network Discovery 3.0.0 and later 

 Network Discovery 3.0.0 and later are only
 supported on PAN-OS 12.x and later. If you are running an older
 version of PAN-OS, 
 uninstall Network Discovery 2.x or earlier prior
 to upgrading to PAN-OS 12.x. After upgrading to PAN-OS 12.x, you
 can install Network Discovery 3.0.0 and later.

 Network Discovery 3.0.0 and later are only
 supported on PAN-OS 12.x and later. If you want to downgrade
 to Network Discovery 2.x.x or earlier, you need
 to uninstall Network Discovery , downgrade to
 a supported version of PAN-OS, and then install the
 Network Discovery version 2.x or earlier that you
 want to use.

 — 

 Network Discovery 2.2.0 and later 

 Uninstall Network Discovery 2.0.x or earlier prior to
 installing a 2.2.0 plugin version or later.

 Upgrading from Network Discovery 2.1.x or later to 2.2.0 or later
 isn't affected.

 Uninstall Network Discovery 2.2.0 or later prior to installing
 a 2.0.x plugin version.

 — 

 Network Discovery 2.1.0 and later 

 Uninstall Network Discovery 2.0.x or earlier prior to installing
 a 2.1.0 plugin version or later.

 Uninstall Network Discovery 2.1.0 or later prior to installing
 a 2.0.x plugin version.

 — 

 Network Discovery 2.0.0 

 Uninstall Network Discovery 1.0.x prior to installing the 2.0.0
 plugin. 

 None
