 Authenticate Users with Active Directory 

 Authenticate users with Active Directory in Cortex XSOAR 6.13. 

 You can use the Active Directory Authentication integration to enable users to log in to Cortex XSOAR with their Active Directory usernames and passwords. Permissions in Cortex XSOAR are set according to the groups and mapping set in Active Directory.
