 Firewall Dataplane Not Ready 

 Incident Code 

 INC_NGFW_DP_NOT_IN_READY_STATE 

 Severity 

 Critical 

 Category 

 Device 

 Subcategory 

 Hardware 

 Description 

 This incident is triggered when the firewall dataplane fails to reach or maintain
 the "ready" state. 

 Raise Condition 

 This Incident is generated when the firewall dataplane self-check indicates that
 the dataplane is not ready after 1 hour of the firewall powering up. 

 Clear Condition 

 After taking the remedial actions, when the dataplane checks show that it has
 initialized successfully.
