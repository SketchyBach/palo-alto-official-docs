 This context matches an SCTP Payload Protocol Identifier
(PPID). 

 Additional Details 

 A PPID is
a 32-bit unsigned integer value that represents an application (upper
layer) specified protocol identifier. It identifies the type of
information being carried in a SCTP DATA chunk.
