 Cortex XDR Agent 7.8 Release Information 

 Changes to Default Behavior in Cortex XDR Agent 7.8 

 Changes to default behavior in Cortex XDR agent 7.9 for Windows, macOS, and Linux endpoints. 

 When Cortex XDR Agent is deployed on a Linux-based endpoint which is connected to/part of a Microsoft Windows/Active Directory Domain, the agent will now report the domain of the logged in user. 

 The Protection process list no longer displays content. We now protect all processes using a different mechanism. In future versions, this option will removed from the user interface.
