 Configure the Maximum Number of Configuration Backups on
Panorama 

 Select Panorama Setup Management and
edit the Logging and Reporting Settings. 

 Select Log Export and Reporting and
enter the Number of Versions for Config Backups (default
is 100; range is 1 to 1,048,576). 

 Click OK to save your changes. 

 Select Commit Commit
to Panorama and Commit your
changes.
