                                                                Release notes for the Windows EPM agent
                                                                This topic summarizes the updates, enhancements, and resolved issues in recent versions of the Windows EPM agent.
                                                                
                                                                    
                                                                        What's new has moved to the unified platform feed.
                                                                        
                                                                        As of July 20, 2026, all product updates and announcements have moved to the unified What's new feed. The unified feed highlights the latest capabilities across the entire Idira Identity Security Platform.
                                                                        This page is no longer being updated.
                                                                    
                                                                
                                                                
                                                                    
                                                                        For versions of the EPM release notes prior to 2026, see EPM Release notes.

                                                                Deprecated capabilities
                                                                For details on features deprecated prior to version 26.1.0, see the release notes for each previous version.
                                                                Version 26.6.1
                                                                Version 26.6.1 is a patch for the Windows EPM agent release 26.6. Starting with release 26.6, patches may be provided to address critical issues in an agent release. For more details about EPM agent patches, see EPM versioning conventions.
                                                                Resolved issues
                                                                Move Set removed agent from Endpoints page
                                                                    
                                                                        We fixed an issue where performing a Move Set operation on an endpoint that appears on both the My Computers page and the Endpoints page caused the agent to disappear from the Endpoints page.
                                                                        See details.
                                                                    
                                                                
                                                                AD user or group policy conditions skipped after startup
                                                                    
                                                                        The agent now evaluates policy conditions with explicit AD user or group targets correctly after startup. Previously, timing issues caused the agent to skip AD-related policy conditions during evaluation.
                                                                        See details.
                                                                    
                                                                
                                                                Computer group policy target inactive after restart without AD
                                                                    
                                                                        When the Windows agent starts without an AD connection, the agent continues to use cached AD data for policy matching. Previously, a policy with a computer group target became inactive in this scenario.
                                                                        See details.
                                                                    
                                                                
                                                                
                                                                    When should you install this version?
                                                                    
                                                                        
                                                                            If you plan to upgrade to version 26.6.0, we recommend that you install version 26.6.1 instead.
                                                                        
                                                                        
                                                                            If you have already installed release 26.6, review the resolved issues above and install version 26.6.1 if any fixes apply to your deployment.
                                                                        
                                                                    
                                                                
                                                                Version 26.6.0
                                                                
                                                                    If you plan to upgrade to version 26.6.0, we recommend that you install version 26.6.1 instead.
                                                                
                                                                New capabilities and enhancements
                                                                Entra ID machine targeting on script distribution policies
                                                                    
                                                                        Script distribution policies can now be targeted by Entra ID machines.
                                                                    
                                                                
                                                                NOPROXY option was added to EPM install CLI
                                                                    
                                                                        We added the NOPROXY option to remove proxy configuration from the agent, enabling the agent to rely on the OS configuration during agent upgrades.
                                                                        For details, see Upgrade the Windows agent from the command line.
                                                                    
                                                                
                                                                Support for multiple proxies
                                                                    
                                                                        We added support for multiple proxies delimited by semicolons (;) in a proxy PAC file, for sets that have onboarded to the new endpoint management service.
                                                                        For details, see the PROXYPAC option in install an EPM agent using a configuration file.
                                                                    
                                                                
                                                                New golden image flow
                                                                    
                                                                        We have updated the process for creating a golden image.
                                                                        For details, see Create a golden image for large scale agent deployment.
                                                                    
                                                                
                                                                Support apps downloaded from the Windows Store in default policies
                                                                    
                                                                        We now support apps downloaded from the Windows Store in Default policies.
                                                                        For details, see Default policies.
                                                                    
                                                                
                                                                Support device ID as part of Entra ID step-up
                                                                    
                                                                        We added support for the deviceID claim when you use Entra ID as an identity provider. This allows you to leverage device identity and compliance status metrics directly inside your Conditional Access policies.
                                                                    
                                                                
                                                                Support for authenticated proxies for ESI
                                                                    
                                                                        Endpoint sign-in now uses configured proxy authentication settings when they are defined.

                                                                New capabilities and enhancements
                                                                Target Entra ID machines in Windows policies

                                                                EPM SOC Response
                                                                    
                                                                        Identity-based and privilege-based endpoint SOC response
                                                                        
                                                                        We are excited to announce the release of the EPM SOC response integration, a powerful new capability designed to bridge the gap between high-speed threat detection and targeted endpoint enforcement.
                                                                        The challenge
                                                                        
                                                                        With a significant number of alerts reaching the SOC team being False Positives (FPs), analysts are often forced to choose between ignoring a potential threat or "pulling the plug" on a productive employee. This fear of "breaking the business" creates a dangerous gap that attackers use to hide and pivot while the analyst investigates.
                                                                        The solution
                                                                        
                                                                        The intelligent privilege controls within EPM provide a third option: Immediate, proportional tightening of security on the potentially compromised endpoint. This capability empowers SOC teams to mitigate threats in real-time by selectively hardening the endpoint and verifying the end user identity without the need for full device isolation. It is the perfect solution for grey area alerts that require investigation time before making a final decision that could cause significant operational impact.
                                                                        Key benefits
                                                                        
                                                                        
                                                                            
                                                                                Act Earlier with Confidence: Don't wait for 100% certainty. Harden the system immediately with reversible EPM risk reduction response policies while you finish your investigation.
                                                                            
                                                                            
                                                                                Automated User Demotion: Instantly remove administrative rights and block unauthorized application execution the moment a threat is detected. This prevents attackers from disabling security controls, installing malware, or moving laterally through the network.
                                                                            
                                                                            
                                                                                Minimize Business Disruption: Keep your users productive. Secure the device with no reboots, no network cut-offs, and no service halts to critical business functions.
                                                                            
                                                                            
                                                                                Simplified Operations: Response actions are triggered directly from your existing security SOAR console and are easily reversible, removing the manual recovery times associated with traditional isolation.
                                                                            
                                                                        
                                                                        Native integration support
                                                                        
                                                                        EPM SOC Response is available now for customers using the following:
                                                                        
                                                                            
                                                                                Palo Alto Networks: Cortex XSIAM and XSOAR
                                                                            
                                                                            
                                                                                SentinelOne: Singularity Hyperautomation

                                                                Version 26.2.1
                                                                Upgrade requirements for Windows endpoints
                                                                Before you upgrade Windows agents to version 26.2.0 or 26.2.1, you must ensure that those endpoints appear on the Endpoints page. If an endpoint does not appear, resolve the connectivity issues before you proceed with the upgrade.
                                                                For details about facilitating connectivity, see Network setup. If you cannot resolve the connectivity issues, contact Technical Support.
                                                                Chromium-based browser performance
                                                                Addressed performance issues seen intermittently on the EPM Windows agent, when working with Chromium-based browsers, such as Chrome and Edge. Previously, opening or switching between multiple tabs simultaneously could cause the browser to stop responding for a short time. This update ensures stable performance when interacting with fields across multiple active tabs. This update is available in agent version 26.2.1 and later.
                                                                
                                                                    When should you install this version?
                                                                    
                                                                        
                                                                            If you experience the issue described above.
                                                                        
                                                                        
                                                                            If you plan to upgrade to version 26.2.0, we recommend that you use version 26.2.1 instead, to avoid this issue.
                                                                        
                                                                    
                                                                
                                                                Version 26.2.0
                                                                
                                                                    If you plan to upgrade to version 26.2.0, we recommend that you use version 26.2.1 instead, to avoid the Chromium-based browser performance issue addressed above.
                                                                
                                                                
                                                                    Before upgrading to this version, see Upgrade requirements for Windows endpoints in the version 26.2.1 section above.
                                                                
                                                                New capabilities and enhancements
                                                                Windows apps support
                                                                    
                                                                        Windows apps are Packaged Modern Applications, often listed as Packaged Apps, and refer to software that uses Microsoft's modern deployment framework. These applications are defined by their installation format and their default location in the restricted C:\Program Files\WindowsApps directory. They include the Windows 10 and Windows 11 versions of core Windows apps like Notepad and Calculator, and applications downloaded through the Microsoft Store. EPM identifies them separately because they run in an AppContainer, which is a virtualized sandbox, rather than as a standard desktop process.
                                                                        The Elevate if necessary policy type now supports Windows app elevation as an explicit definition type. If you have existing application policies for Windows apps that use Executable as the definition type, you must change it to Windows app for Windows agent version 26.2.0 and later.
                                                                        This change is not backward compatible. While you transition your agent deployment to version 26.2.0, we recommend using different policies depending on the agent version. For an example of how to implement version-specific policies, see the community article Version-Specific Application Policies.
                                                                    
                                                                
                                                                Grace period added in Endpoint sign-in policy
                                                                    
                                                                        Set admins can now configure the Endpoint sign-in policy such that users can avoid reauthentication for a configured period of time, while limiting the number of authentication attempts.
                                                                    
                                                                
                                                                Enhanced Entra ID query and response management
                                                                    
                                                                        We have significantly reduced the volume of queries required to retrieve a user's groups from Microsoft Entra ID. In addition, we have enhanced backoff and retry handling for cases where the system receives a too many requests response.
