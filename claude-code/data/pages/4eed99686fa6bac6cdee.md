Endpoint integration

Endpoint integration enables visibility, remediation and prevention for AI agents and brew.

Overview

Endpoint Integration is how Koi reaches the devices in your organization. Once a device is connected, Koi can see the software and AI components running on it, assess their risk, and apply the policies and guardrails you set. 

It allows organizations to:

Discover installed items on the devices in the org like Browsers, Code packages, MCP ,Skills, Plugins and more.

Prevent AI agents actions  that violate defined policies with runtime hooks.

Remediate items that violate defined policies by deleting them from the endpoints.

Prevent hombrew OS packages that violate defined policies from being download to the endpoints.

Before you start

Access to the Koi portal, with permission to reach Settings → Deployment.

Admin access to the MDM or EDR your organization uses to manage devices.

A small group of test devices to start with. Deploy to that group first, confirm it works, then roll out to the rest.
