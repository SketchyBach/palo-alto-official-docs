 dump routing multicast status 

 Use the dump routing multicast status command
to display the routing multicast status of a ION device. 

 Command 

 dump routing multicast status 

 Options 

 None 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands — 

 Introduced in Release 5.6.1 

 Example 

 dump routing multicast status
 Multicast Service running
 PIMD Service running

 When PIMD is not running:

 dump routing multicast status
 Multicast Service running
 PIMD Service not running, Reason: "No configured multicast interface" 
 And all other multicast toolkit commands will show:
