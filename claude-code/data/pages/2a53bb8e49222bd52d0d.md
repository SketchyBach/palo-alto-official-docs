 Manage Action Sets 

 View, activate, disable, and delete action sets from the Action Center list page in
 Strata Cloud Manager .

 Where Can I Use This? What Do I Need? 

 Device Security (Managed by Strata Cloud Manager) 

 One of the following subscriptions: 

 Device Security subscription

 Precision AI bundle subscription

 Device Security X subscription

 After you create an action set, you manage it from the list page at
 Policies Action Center . The All Action Sets table on the page shows every action set
 in your tenant along with its name, last run status, action intents,
 actioning systems, trigger type, trigger, and status. Hover over an attribute
 to see its full value.

 The Last Run Status column indicates the outcome of the most recent run of
 each action set.

 When an action set includes taking an action through a third-party solution,
 the Last Run Status indicates only whether or not Device Security 
 successfully sent the request to the third-party solution. You need to check
 in your third-party solution to validate whether or not it completed the
 expected action.

 Status Meaning 

 In Progress 

 The action set is currently running. For runs that act on
 multiple devices, the status shows progress as x 
 of y .

 Partial 

 The action set finished, but the action succeeded on
 some entities and failed on others.

 Completed 

 The action set finished and the action succeeded on every
 entity that matched the scope query.

 Failed 

 The action set finished and the action did not succeed on
 any entity that matched the scope query.

 Action Center management actions — create, activate, disable, edit,
 view history, and delete — are role-based. Users without the required role
 don't see the corresponding action in the action menu.

 View Action Set Details 

 View an action set's full configuration in a side panel to confirm the
 scope query and the configured actions.

 Select Policies Action Center .

 Click the name of an action set in the list. 

 The details panel opens on the right side of the page and shows
 the action set's name, description, trigger type, trigger events,
 scope query, schedule information (for schedule triggers), main
 actions, and any fallback actions.

 Activate or Disable an Action Set 

 Activate an action set to let it run when its trigger fires. Disable an
 action set to stop it from running without deleting it — for example,
 when you want to pause an automation during a maintenance window or while
 you troubleshoot an integration.

 Select Policies Action Center .

 Locate the action set in the list. 

 Open the action menu for the action set and click
 Activate to activate the action set, or
 Disable to stop it from running.

 When the status is Active, Device Security runs the action set
 each time its trigger fires. When the status is Disabled, the
 action set remains in the All Action Sets table but doesn't run.

 Delete an Action Set 

 Delete an action set when you no longer need it. Deletion removes the
 action set from your tenant and cannot be undone.

 Select Policies Action Center .

 Locate the action set in the list. 

 Open the action menu for the action set and click
 Delete .

 Confirm the deletion. 

 If the action set is currently running when you delete it,
 Device Security returns a 409 error and the action set is
 not deleted. Wait for the current run to finish and then retry
 the delete.
