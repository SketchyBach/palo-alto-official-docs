 AL_MU_IP_POOL_USAGE 

 Learn about the AL_MU_IP_POOL_USAGE alert. 

 Synopsis 

 Mobile user private IP address pool use exceeds 90% or 75% worldwide for the Americas
 theater. 

 IP subnet usage is compared to the total of IP subnets at the theater/worldwide
 level. 

 Alert Code—AL_MU_IP_POOL_USAGE 

 License Required 

 Prisma Access 

 Severity 

 When the mobile user private IP address pool use exceeds 90% worldwide or for the
 Americas theater, the severity is high. 

 When the mobile user private IP address pool use exceeds 75% worldwide or for the
 Americas theater, the severity is medium.
