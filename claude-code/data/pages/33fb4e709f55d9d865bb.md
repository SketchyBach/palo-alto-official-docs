 Granular Access Control for Visibility and Reporting in Strata Cloud Manager 

 Release Date: August 2024 
 | 
 Last Updated: May 2026 

 To allow you more granular role-based access control (RBAC) for your Prisma Access (managed by Panorama) deployment, there is an additional ability to limit access to the Cloud Services plugin in the Panorama Admin Roles Admin Role Profile Plugins area for the Cloud Services plugin. This allows you to: 

 You can now create custom roles with granular access controls for the Visibility and Reporting (VnR) pages in Strata Cloud Manager, giving each user exactly the permissions they need. When a user has multiple roles, Strata Cloud Manager automatically aggregates permissions and grants access based on the highest level assigned, ensuring consistent and predictable access across the platform. 

 You can now define page-level access for the following pages: 

 Command Center 

 Activity Insights 

 AI Access 

 Reports 

 Executive Summary 

 Threat Search 

 WildFire 

 You can create or edit custom roles and update the permissions under the Visibility and Reporting section to modify Read and Write access for the Visibility and Reporting pages, ensuring they align with the users responsibilities. 

 For existing customers, all current access levels are fully retained. Predefined roles are automatically updated with the appropriate permission sets, allowing you to continue working seamlessly while gaining enhanced control over permissions.

 Streamlined NGFW Incidents and Alerts Management 

 Release Date: August 2024 
 | 
 Last Updated: May 2026 

 Navigating between incident summaries and detailed alert lists often requires additional steps and causes context loss, slowing down critical security response times. The Strata Cloud Manager Incidents & Alerts page now centralizes these views, allowing administrators to rapidly identify and respond to critical security events occurring across Next-Generation Firewalls (NGFWs). The unified view presents critical visual summaries and the corresponding detailed list side-by-side. You quickly grasp the overall context of an incident from the charts and immediately dive into the specifics without navigating away from the triage workflow. This streamlined access empowers you to conduct faster, more effective triage, helping you respond to security events with greater speed and confidence.
