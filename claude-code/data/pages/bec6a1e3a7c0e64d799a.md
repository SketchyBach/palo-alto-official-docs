 Provision to Microsoft Azure API Management 

 Use this procedure to provision a certificate from Next-Gen Trust Security to a Microsoft Azure API Management machine. 

 Sign in to Next-Gen Trust Security. 

 Click Insights > Certificate Installations > Machines . 

 Click the name of your Azure API Management machine. 

 In the machine drawer, click Installations . 

 Click Provision . 

 In Search a certificate by name, expiration or fingerprint , begin typing the name of the certificate you want to provision. Click the certificate when you see it listed. 

 Verify that you selected the correct certificate by reviewing the Subject DN , Validity , and Fingerprint . 

 Note: Only Next-Gen Trust Security-generated and user-imported certificates with private keys can be provisioned. The certificate's common name (CN) or subject alternative name (SAN) must match the custom domain hostname you specify in the next step. 

 In Hostname , enter the hostname of the Azure API Management custom domain where you want to install the certificate, for example api.example.com . 

 From the Domain Type drop-down, select the type of custom domain endpoint: 

 Gateway – The primary API gateway endpoint (default). 

 Developer Portal – The developer portal endpoint. 

 Management – The management API endpoint. 

 Source Control (SCM) – The source control management endpoint. 

 Configuration API – The configuration API endpoint. 

 From the Certificate Source drop-down, select Custom (Uploaded) . 

 Note: If a custom domain is already configured with a certificate from Microsoft Azure Key Vault, provisioning to that hostname replaces the Azure Key Vault reference with the uploaded (Custom) certificate. Azure Key Vault-backed certificates on other, non-targeted domains are flagged during discovery and left unchanged. 

 (Optional) In Description , enter a machine installation description. 

 To prevent the certificate from being pushed immediately, set Push upon saving to No . 

 Click Save . 

 Tip: You can schedule your provisions daily, weekly, or monthly. Learn more 

 After saving, the certificate is converted to Azure's required format and submitted to the specified custom domain. The connector reports success once Azure accepts the update. The certificate installation completes asynchronously. All other custom domains on the same API Management instance are preserved.
