 Modify a Custom Role Through Common Services 

 Learn how to modify a custom role through Common Services . 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 Strata Multitenant Cloud Manager 

 The Activation Console 

 Superuser or Multitenant Superuser role 

 If you add a custom role or you create
one by cloning a role ,
you can modify it. 

 Use one of the various ways to access 
 Common Services Identity & Access . 

 Select Identity & Access Roles Custom Roles to add a custom role. 

 Scroll to the role that you want to modify. 

 Select Actions . 

 You can Edit , Clone ,
or Delete . 

 You cannot delete a custom role if it is assigned
to a user or a service account.
