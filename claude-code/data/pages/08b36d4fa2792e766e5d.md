 Copy alerts 

 You can copy an alert into memory. 

 You can copy alert text into memory and paste them into an email. This is helpful if you need to share or discuss a specific alert with someone. If you copy a field value, you can also paste it into a search or begin a query. 

 How to copy an alert value 

 From the Alerts page, right-click the alert you want to send. 

 Select one of the following options: Copy alert URL . 

 Copy text to clipboard 

 Copy entire row 

 Copy alert URL 

 Cortex XDR saves the copied text to memory. 

 Paste the URL into an email or use it as needed to share the information.
