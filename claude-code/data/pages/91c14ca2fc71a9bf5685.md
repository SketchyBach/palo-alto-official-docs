 Legacy Password Manager 

 This control allows you to enable the Prisma Browser Enterprise Password Manager to manage and secure company passwords and logins. 

 From Strata Cloud Manager , select Configuration Prisma Browser 
 Policy Controls Browser Security 

 Select Password Manager . 

 Select one of the following options: 

 Enable - Enable the Password Manager to manage
 users passwords and logins. 

 Disable - Do not enable the Password Manager .

 Password Manager 

 The Prisma Browser Password Manager is an enterprise-grade password
 management solution built directly into the Prisma Browser . It enables users
 to securely store, organize, and autofill credentials for web applications that
 are not protected by Single Sign-On (SSO). Users can share accounts with
 colleagues ( Prisma Browser Pro) and import existing credentials from other
 password managers — all from a side panel within the browser. 

 When the Password Manager is first enabled for users who have the Legacy Password
 Manager active, a welcome wizard introduces the new experience and imports
 existing credentials automatically. 

 The Password Manager is available on Prisma Browser Desktop (Windows, macOS,
 and Linux) with both Core and Pro licenses. Credential sharing with colleagues
 requires Prisma Browser Pro. 

 About the Password Manager Control 

 Prisma Browser Desktop Prisma Browser Extension Prisma Browser for Mobile 

 Full support No support No support 

 The Password Manager control and the Legacy Password Manager control are
 independent. Enabling or disabling one does not affect the other. Both appear
 under the Passwords and Autofill section of the browser
 security policy. 

 The Password Manager is disabled by default for all tenants.
 Administrators must explicitly enable it to opt in. 

 Administrators can choose to: 

 Enable the Password Manager while keeping the Legacy Password Manager
 enabled (allows users to access both during transition). 

 Enable the Password Manager and disable the Legacy Password Manager (forces
 full migration). 

 Enable the Password Manager while leaving the Legacy Password Manager
 enabled for export purposes only. 

 To set the Password Manager control: 

 From Strata Cloud Manager , select Prisma Browser Rules Browser Security 

 Under Password Manager , select one of the following
 options: 

 Enable - The Prisma Browser installs
 the Password Manager for end users matching this rule. Users can
 store, autofill, and share credentials from the browser side
 panel. 

 Enable Account Sharing - allows you to configure
 account sharing for this particular password. 

 Multi-factor Authentication - Allows you to require
 multi factor authentication for additional security. You can
 also configure a specific time limit for the MFA, after
 which you need to re authenticate. 

 Disable - The Password Manager is not
 available to end users matching this rule. 

 Click Set . 

 Mobile Password Saving 

 Mobile Browser - Full
 support 

 This feature determines whether the browser will be able
 to save passwords for websites. 

 From Strata Cloud Manager , select Configuration Prisma Browser 
 Policy Controls Browser Security 

 Select Password Saving . 

 Select one of the following options: 

 Allow - Users will be able to save passwords in
 the browser. 

 Block - Users will be restricted to save passwords in the
 browser. 

 Click Set . 

 Autofill of Forms 

 Mobile Browser - No support 

 This feature determines whether or not the browser will store
 information to autofill forms. 

 From Strata Cloud Manager , select Configuration Prisma Browser 
 Policy Profiles Browser Security 

 Select Autofill of Forms . 

 Select one of the following options: 

 Allow – The browser will save information to
 autofill forms in the future. 

 Block – The browser will not save form information to be
 filled automatically in the future. 

 Click Set . 

 Autofill of Credit Cards 

 Mobile Browser - No support 

 This feature determines whether or not the browser will allow users to store
 credit card information. 

 From Strata Cloud Manager , select Configuration Prisma Browser 
 Policy Controls Browser Security 

 Select Autofill of Credit Cards . 

 Select one of the following options: 

 Allow – Prisma Browser will be able to save
 credit card details. 

 Block – Prisma Browser will be restricted from saving
 credit card details for future use. 

 Click Set .
