 Task 7. Manage playbook content 

 Manage playbook content and versions in Cortex XSOAR 8.14 On-prem. 

 Manage playbook content by either using a remote repository, or by saving versions of your playbook in Cortex XSOAR to maintain version history. For more details, see Manage playbook content . 

 Cortex XSOAR also manages playbook editing conflicts by only allowing one user at a time to edit a playbook and locking it for other users to edit. It automatically clears the playbook edit lock when the user currently editing the playbook saves the playbook, closes the editor, logs out, or when their session expires. In addition, you can grant a permission to designated users so they can manually unlock playbooks from the Playbooks page or editor.
