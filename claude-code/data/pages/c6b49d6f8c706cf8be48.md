 Map Duo Groups to Cortex XSOAR Roles 

 Map Duo groups to roles in Cortex XSOAR 6.12. 

 By mapping Duo groups to Cortex XSOAR roles, you set permission levels for your Duo users. When you specify the Duo group in Cortex XSOAR, it must match the exact group name as it appears in Duo. 

 Go to Settings → Users and Roles → Roles . 

 Create or edit an existing role . 

 In the SAML Roles Mapping field, specify one or more SAML groups to map to the Cortex XSOAR role.
