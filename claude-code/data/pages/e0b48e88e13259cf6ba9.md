 Feature Enhancements 

 Vulnerability Management 

 FEATURE 

 DESCRIPTION 

 Enhanced vulnerability findings 

 Prioritize and remediate vulnerability findings faster and with greater confidence using additional details like remediation guidance, Cortex Vulnerability Risk Scores, and intelligence score sources. Vulnerability findings are also accessible via XQL queries. 

 Vendor advisory links in Vulnerability Intelligence 

 Gain quick access to vulnerability technical details and links to vendor advisory sites on Vulnerability Intelligence pages. 

 Accelerate remediation with resolution actions 

 To expedite issue resolution, Vulnerability Management now features Resolution Actions. Resolution Actions are suggested quick actions, such as creating a ticket, deploying an XDR agent, or notifying users, that can be executed through the UI, AI, automation, or APIs.
