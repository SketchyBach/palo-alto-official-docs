 Manage Browser-Based Real User Monitoring 

 Learn about managing domains and users monitored by browser-based Real User
 Monitoring. 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 Prisma Access license 

 ADEM or Strata Cloud Manager Pro 
 license 

 Prisma Browser license 

 ADEM Plugin for Prisma Access Browser 

 Browser-based Real User Monitoring (RUM) gives you granular control over
 the data it monitors. You can manage data collection at the tenant level, or
 specifically for existing and newly discovered application domains, users, and user
 groups. When RUM is enabled for a tenant, the system automatically discovers new
 application domains and displays them in the UI, allowing you to easily configure
 their monitoring settings. RUM collects data through consumer browsers (Chrome and
 Edge) or the Prisma Access Browser. 

 You can't enable or disable data collection through the browser or browser
 extension. You must manage all monitoring configurations centrally within Strata
 Cloud Manager via application domains, user or user groups, or tenant-level
 settings. 

 Configure Browser-based Real User Monitoring
 Settings 

 Log in to Strata Cloud Manager. 

 Select Insights Application Experience Your Organization Manage Monitoring Settings . 

 Click the Browser-based Real user monitoring tab. 

 Toggle the Browser-based Real User Monitoring button to
 enable or disable RUM at the tenant level. When tenant level monitoring is
 disabled, data collection stops across all domains and all users and user
 groups. 

 When tenant level monitoring is enabled, ADEM automatically discovers new
 domains and lists them in the Application Domains table. By default, these are
 marked as Included for monitoring. To change this behavior, disable the
 Automatically include newly discovered application domains for
 monitoring setting. Once disabled, ADEM will continue to list
 and track newly discovered domains, but will default their monitoring status to
 Excluded . You can then manually manage these domains through the
 Application Domains table as needed. 

 The Automatically include newly discovered domains for monitoring 
 setting is not retroactive. This setting only applies to new domains
 discovered after the setting is enabled. It does not change the
 monitoring status (Included or Excluded) of any domains that have
 already been discovered and listed in the Application Domains table.

 to determine whether newly discovered domains are monitored or held for
 review.
