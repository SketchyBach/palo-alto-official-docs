 E2B API Key detected in code 

 Rule Details 

 Cortex AppSec Rule ID 

 APPSEC_SECRET_370 

 Category 

 Secrets 

 Severity 

 HIGH 

 Framework 

 Git 

 Impact 

 E2B (Execute to Build) API keys provide access to cloud-based code execution environments. Exposed keys could allow unauthorized users to run arbitrary code in your E2B sandboxes, potentially leading to resource abuse, data exposure, or unauthorized compute usage. Revoke and rotate immediately if compromised. 

 How to Fix 

 Revoke the exposed E2B API key and generate a new one. Store API keys in secure vaults or environment variables.
