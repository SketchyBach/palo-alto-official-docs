 Disable Device Telemetry 

 You can configure the telemetry data that PAN-OS collects and shares with Palo Alto Networks 

 Where Can I Use This? What Do I Need? 

 NGFW (Managed by Strata Cloud Manager) 

 NGFW (Managed by PAN-OS or Panorama) 

 For Strata Cloud Manager managed NGFWs: 

 Strata Cloud Manager Essentials 

 Strata Cloud Manager Pro 

 If your next-generation firewall is configured to share data with Palo Alto Networks, you can
 disable this sharing by:

 Navigate to Device Setup Telemetry 

 Edit the Telemetry 
 widget.

 Uncheck the Enable Telemetry box.

 Click OK , and
 then commit your changes.

 Any telemetry data currently stored in Strata Logging Service is
 automatically purged one year after your firewall uploaded it. Optionally, if
 you do not want the data to reside in Strata Logging Service for this
 amount of time after you disable telemetry, open a support ticket and ask Palo
 Alto Networks to purge your telemetry data.
