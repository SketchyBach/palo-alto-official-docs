 CLI Commands in Prisma SD-WAN ION Release 6.3 

 Learn about the CLI commands in Prisma SD-WAN ION device release
 6.3. 

 CLI Commands in Prisma SD-WAN ION Device Release 6.3.1 

 Commands Description 

 New 

 clear routing 

 Clears the border gateway protocol (BGP) peer
 sessions on a device. 

 debug performance-policy 

 Debugs circuit information for a path used in
 performance policy. 

 debug log-agent eal-file-log 

 Enables or disables logging of the IP and MAC address
 bindings. 

 dump log-agent iot-snmp config 

 Displays the SNMP discovery-related configuration on
 the device. 

 dump log-agent iot-snmp device-discovery-stats 

 Displays various statistics for IoT discovered
 devices such as status of discovery, number of endpoints,
 interfaces, subnets, and VLANs. 

 dump log-agent iot-snmp neighbor-discovery-stats 

 Displays various statistics related to neighbor
 discovery such as status of discovery and number of nodes
 discovered. 

 dump log-agent ip-mac-bindings 

 Displays the list of discovered IP and MAC addresses
 of the devices. 

 dump performance-policy config policy-rules 

 Displays the performance policy rule configuration for
 a device. 

 dump performance-policy config policy-sets 

 Displays the performance policy set configuration for
 a device. 

 dump performance-policy config policy-set-stacks 

 Displays the configuration of performance policy sets
 within a stack for a device. 

 dump performance-policy config threshold-profile 

 Displays the performance policy thresholds for a
 device. 

 dump routing peer neighbor 

 Displays the configuration of BGP peers. 

 dump routing peer route-via 

 Displays the installed routes learned from BGP
 peers. 

 dump vrf 

 Displays the VRF, VRF Profiles, and VRF Route Leak Rules
 configurations. 

 inspect performance-policy fec status 

 Inspects the status of FEC in the performance policy
 rule. 

 inspect fib-leak 

 Inspects the forwarding information base (FIB) table,
 to display FIB leak entries, and to debug path selection
 issues. 

 inspect performance-policy hits analytics 

 Inspects the hit counts for performance policy rules
 and allows hit count information to be displayed for performance
 policy rules. 

 inspect performance-policy incidents 

 Inspects the incident summary and details of the link
 quality circuits for performance policies. 

 inspect performance-policy lookup 

 Inspects the performance policy rules and identifies
 those policy rules which override the other rules in the
 stack. 

 inspect system vrf 

 Inspects all the kernel VRF link information for a
 device 

 Updated 

 dump dhcp-server config 

 Displays the DHCP server configuration. 

 dump dhcp-server status 

 Displays the dynamic host configuration protocol (DHCP) server
 status. 

 dump dhcpstat 

 Displays the dynamic host configuration protocol (DHCP) server
 statistics. 

 dump interface config 

 Displays the interface configurations. 

 dump interface status 

 Displays the interface status (port or sub
 interface). 

 dump routing peer advertised routes 

 Displays the routes advertised to BGP peers. 

 dump routing peer config 

 Displays the configuration of BGP peers. 

 dump routing peer neighbor 

 Displays the configuration of BGP peers. 

 dump routing peer received-routes 

 Displays the filtered routes received from BGP
 peers. 

 dump routing peer route-json 

 Displays the installed routes learned from BGP peers
 in java script object notation (JSON) format. 

 dump routing peer routes 

 Displays the installed routes learned from BGP
 peers. 

 dump routing peer status 

 Displays the status of BGP Peers. 

 dump routing peer route-via 

 Displays the installed routes learned from BGP
 peers. 

 dump routing static-route config 

 Displays the details of static route configured on device. 

 dump routing static-route reachability-status 

 Displays the reachability status of a next hop on a static
 route. 

 dump routing prefixlist 

 Displays the information on prefixlist. 

 dump routing routemap 

 Displays the information in a route map. 

 dump routing summary 

 Displays the summary for a BGP Peers. 

 dump vpn summary 

 Displays the information for a virtual private network (VPN). 

 dump vrf 

 Displays the VRF configurations. 

 inspect fib 

 Inspects the forwarding information base (FIB) table, to display
 FIB entries, and to debug path selection issues. 

 inspect flow brief 

 Inspects the brief details for active flows. 

 inspect flow detail 

 Inspects the details on active flows and to debug current flows
 matching the user-specified options. 

 inspect vrf 

 Inspects all the route tables for a device and used
 to debug any routing- related issues on the device. 

 inspect wanpaths 

 Inspects the VPN WAN paths from the controller and
 displays all VPN WAN paths on a device sent by the
 controller.
