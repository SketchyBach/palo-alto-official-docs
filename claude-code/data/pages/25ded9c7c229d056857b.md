 Active Directory Certificate Services Analytics 

 ATT&CK Tactic 

 Privilege Escalation (TA0004) 

 ATT&CK Technique 

 Valid Accounts: Domain Accounts (T1078.002) 

 Severity 

 Informational 

 Description 

 A privileged certificate was requested via certificate template. 

 Attacker's Goals 

 An attacker may attempt to exploit the Active Directory Certificate Services to escalate privileges to a domain controller or privileged account. 

 Investigative actions 

 Check if this is a legitimate certificate request. 

 Check if the certificate issued was used to request a Kerberos ticket. 

 Investigate actions done with the issued certificate and its owner. 

 Check for possible NTLM relay alerts.
