 Broker VM 29.0.71 (Major) 

 The Broker VM major 29.0.71 release was released as part of Cortex XDR 3.16. The release is divided into three deployments: November 9, 2025, November 16, 2025, and November 23, 2025. For more information on the changes integrated on this major release, see the Broker VM Version feature in the Cortex XDR 3.16 Release Notes .
