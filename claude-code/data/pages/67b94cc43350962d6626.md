 Config
Logs 

 Config logs display entries for changes to the firewall
configuration. Each entry includes the date and time, the administrator
username, the IP address from where the administrator made the change,
the type of client (Web, CLI, or Panorama), the type of command
executed, the command status (succeeded or failed), the configuration
path, and the values before and after the change.
