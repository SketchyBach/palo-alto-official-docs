 Configure Header Modification 

 Configure the Header Modification controls to add custom HTTP headers or modify the
 User-Agent string on Prisma Browser HTTP/S requests for matched
 applications. 

 Custom HTTP Header 

 Prisma Browser Desktop Prisma Browser Extension Prisma Browser for Mobile 

 Full support Full support No support 

 The Custom HTTP Header control adds a custom HTTP header to Prisma Browser HTTP/S requests for matched applications. Use this control to
 identify Prisma Browser traffic to downstream services, enforce tenant
 restrictions, or pass organization-specific metadata. 

 To set the Custom HTTP Header control: 

 From Strata Cloud Manager , select Configuration Prisma Browser Policy Access & Data Control 

 Select or create a rule, then go to Controls Header Modification . 

 Select Custom HTTP Header . 

 Select one of the following options: 

 Keep default headers - the Prisma Browser uses the default HTTP headers without
 modification. 

 Add a custom HTTP header - the Prisma Browser adds a custom HTTP header to requests for
 matched applications. 

 Custom Header Name - Specify the
 custom header name. Alphanumeric characters,
 underscores, and hyphens only. Maximum 256
 characters. 

 Custom Header Value - Specify the
 custom header value. Maximum 1024 characters. 

 Click Set . 

 User-Agent 

 Prisma Browser Desktop Prisma Browser Extension Prisma Browser for Mobile 

 Full support Full support Partial support 

 On mobile, only "any internet and SaaS" scoping is supported.
 If a rule targets specific URLs, the rule is ignored for mobile
 users. 

 The User-Agent control appends an additional component to the default
 User-Agent string on Prisma Browser HTTP/S requests for matched applications.
 Use this control to identify Prisma Browser traffic by User-Agent string when
 integrating with third-party services or analytics platforms. 

 To set the User-Agent control: 

 From Strata Cloud Manager , select Configuration Prisma Browser Policy Access & Data Control 

 Select or create a rule, then go to Controls Header Modification . 

 Select User-Agent . 

 Select one of the following options: 

 Use default User-Agent - The Prisma Browser uses the default User-Agent string without
 modification. 

 Set an additional User-Agent component -
 The Prisma Browser appends the specified component to the
 default User-Agent string for matched applications. 

 Specify the additional User-Agent component. 

 Click Set .
