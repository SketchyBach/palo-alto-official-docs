SSO Set Up

Leverage Single Sign On using SAML authentication and JIT (Just-In-Time) to manage users end-to-end using your idP.

Capabilities

User creation and access is managed via your IdP.

Group mapping - Map groups to Koi platform's roles to manage users’ permissions in the platform. The current roles are:

Read only - View access to all platforms' sections

Security - Full access to all platform's sections, with exception of the settings page

Admin - Full access to all platform's sections

Default Authentication
By default, user authentication to your tenant is done via a 'magic link' that is sent to authorized users' email address and is accessed through their inbox. The link will expire after 3 minutes and access will remain open for 30 days after using the link.

How to set up SSO?

Request SSO set-up link from your Koi customer experience representative, and by following the link, complete the Wizard set up process:

From the home page, select SSO Configuration

Choose your IdP vendor and click *SAML. You would then be forwarded to the "Service Provider Information" page, and be asked to fill the information according to the relevant vendor.

If you don't find your IdP vendor, use the generic configuration options at the bottom of the screen.

User attribute mapping - you can map attribute names from the IdP (name, email, etc.) to user attributes.

Group Attribute Mapping you can add group attribute statements on the same page.

Add the Identity Provider information

Assign Groups:

SSO Domains - Specify the approved domains for SSO

Testing- Perform the test at the end of the set up wizard. Please send the test results to your customer experience representative.

Once the set up wizard is complete, Koi's team will approve and complete the SSO configuration.
