 Addressed issues in Cortex XDR agent 8.6.2 release for Windows, macOS, and Linux. 

 The following issues were resolved in this release. 

 Issue 

 Description 

 ­CPATR‑29203 

 (Windows) 

 Fixed a rare issue that may arise on rare occasions when using the RPC tracking capability. 

 CPATR-29112 

 (Windows) 

 Fixed a rare issue where Script Context may have been unable to retrieve script’s content. 

 CPATR-28903 

 (Windows) 

 Fixed an issue to resolve a misleading ProductType when using Windows Enterprise multi-session OS builds. 

 CPATR-28504 

 (Windows) 

 Fixed an issue to improve and stabilize device control. 

 CPATR-28368 

 (Windows) 

 Fixed an issue to improve the Cortex XDR agent security and stability posture. 

 CPATR-27836 

 (Windows) 

 Fixed an issue that may occur in non-US locale OS editions, affecting exception handling logic. 

 CPATR-27779 

 Fixed an issue to improve the handling of large databases in low-memory environments. 

 CPATR-27550 

 (Windows) 

 Fixed an issue to improve the Cortex XDR agent security and stability posture. 

 CPATR-27148 

 (Windows) 

 Fixed an issue that in rare cases may generate a false indication of a successful security event. 

 CPATR-27022 

 (Windows) 

 Extended the Local Analysis alert exclusion mechanism to include support for the DLL file type. 

 CPATR-26168 

 Fixed an issue where a post-detection alert may be listed in the Alerts Table incorrectly. 

 CPATR-24802 

 (MacOS) 

 Fixed an issue where the Cytool log set_level command may not validate a password. 

 CPATR-23086 

 (Windows) 

 Improvement made to the Cortex XDR agent security and stability posture.
