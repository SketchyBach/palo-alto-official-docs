 Generate an Upgrade Check Report for Managed Devices 

 Generate an upgrade check report on Panorama for managed devices. 

 Where Can I Use This? What Do I Need? 

 Panorama appliances with managed devices 

 PAN-OS 12.1.2 or later 

 Use this feature to generate Upgrade Check reports on Panorama to assess upgrade
 readiness, remediate potential issues, and view the post-upgrade state of managed
 devices. 

 During an Upgrade 

 Manually 

 Generate an Upgrade Check Report for Managed Devices During an Upgrade 

 Generate an upgrade check report on Panorama for managed devices during an
 upgrade. 

 Navigate to Panorama Device Deployment Software . 

 Select the devices you intend to upgrade. 

 Click Generate Upgrade Check Report . 

 (Optional) Add a Report Description 

 Describe whether the report is being generated before an upgrade or after
 an upgrade, and any remediation that has been made. 

 After the report generation is complete, click View Report to view the
 combined report of all selected devices. 

 You can also view combined reports from the task
 manager. To view individual reports for each device, navigate to Panorama Device Deployment Upgrade Check and click the report under Report
 Name . 

 (Optional) If a check status is Warning or
 Critical_ALERT , remediate the issue . 

 If no remediation is needed, click OK to proceed with the install. 

 (Optional) After the install is completed, navigate to Panorama >
 Device Deployment > Upgrade Check , generate a post-install report, and
 add a description. 

 (Optional) Select the pre-install and post-install reports and click
 Compare Reports . 

 (Optional) 
 Download PDF/CSV to retain a copy of the report. 

 Generate an Upgrade Check Report for Managed Devices Manually 

 Generate an upgrade check report for managed devices outside of the upgrade
 process. 

 Navigate to Panorama Device Deployment Upgrade Check . 

 Select the devices you intend to upgrade. 

 Click Generate Report . 

 (Optional) Add a Report Description 

 Note any remediation that been made or the reason for generating the
 report. 

 Click Generate Report 

 Click the generated report under Report Name to open
 it. 

 If a check status is Warning or Critical_ALERT , remediate the issue . 

 (Optional) Select two reports and click Compare Reports . 

 (Optional) 
 Download PDF/CSV to retain a copy of the report.
