 Access to playbooks 

 Manage access to playbooks with object-level roles in Cortex AgentiX. 

 Access to playbooks is managed at the object level. This enforces least-privileged access to automation logic. Sensitive workflows remain visible and editable only to authorized users. For a complete description of object-level access across Cortex AgentiX, see Manage access to playbooks and scripts . 

 Playbook access roles 

 When a playbook is shared, users have one of these access levels: 

 Owner : Full control of the object and its permissions. 

 Editor : Can view and modify the playbook definition and logic. 

 Viewer : Can view the playbook structure and use it in workflows. Viewers cannot make changes.
