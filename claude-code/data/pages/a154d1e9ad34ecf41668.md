 Upgrade WildFire Appliances in a Cluster

 WildFire Appliance 

 WildFire License 

 You can use the CLI to upgrade WildFire appliances enrolled in
a cluster individually, or use Panorama to upgrade the cluster as
a group. When you use Panorama, the upgrade process is automated
through a workflow engine that manages the upgrade sequence across
all nodes in the cluster, including uploading software, installing,
rebooting, and validating each node. 

 Depending on the number of samples the WildFire appliance has analyzed and stored, the time
 required to upgrade the appliance software varies; this is because upgrading requires
 the migration of all malware samples and 14 days of benign samples. 

 All nodes in a cluster must run the same version
of the operating system. 

 Do not submit samples or commit and push configurations during
an upgrade. The automated Panorama upgrade workflow blocks commits
automatically, but you should also ensure that frontend and backend
queues are empty before initiating an upgrade. 

 You can also use Panorama to manage WildFire appliances and appliance clusters. 

 Ensure the devices are connected to a reliable power source.
A loss of power during an upgrade can make the devices unusable.
