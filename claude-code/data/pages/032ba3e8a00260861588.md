 PAN-OS 12.2 IKE and Web Certificate Cipher Suites 

 List of cipher suites supported for Internet Key Exchange (IKE) and PAN-OS® web
 certificates on firewalls running PAN-OS 12.2 in normal operation mode. 

 The following table lists cipher suites for Internet Key Exchange (IKE) and PAN-OS® web
 certificates that are supported on firewalls running a PAN-OS 12.2 release in normal
 (non-FIPS-CC) operational mode.

 If your firewall is running in FIPS-CC mode, see the list of PAN-OS 12.2 Cipher Suites Supported in FIPS-CC Mode .
