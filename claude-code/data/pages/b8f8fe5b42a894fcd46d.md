 Configure and Distribute Self Serve Notifications 

 Select the type of notifications, such as WiFi-related, or device-related notifications,
 that a user receives when he experiences a degradation in application
 experience. 

 Where Can I Use
 This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 Prisma Access license 

 ADEM or Strata Cloud Manager Pro 
 license 

 GlobalProtect or Prisma Access Agent license 

 A role that has
 permission to configure Self-Serve. 

 Select the notification types you wish to broadcast to your users. Once active, calibrate the
 default threshold limit sliders to your
 specific requirements; notifications are only sent when an event exceeds these
 defined limits. Finally, establish your distribution scope by either targeting the
 entire organization or selecting a specific subset of users and user groups. When
 configured for a user group, notifications are automatically enabled for all members
 of that group. You can configure notifications for the following events: 

 CPU 

 Memory 

 WiFi Quality 

 Internet Outage 

 Go to Strata Cloud Manager Insights Activity Insights Users tab and change the Scope Selection to
 Prisma Access . 

 Click the Self Serve button. 

 In Notification Detection section, select the
 notification type tab and toggle the button to enable or disable the
 notification alerts and set the thresholds. By default, all notification types
 alerts are enabled. 

 When you disable a notification type, the user does not receive notifications
 about the metric when it hits the configured threshold. Even if you disable
 notifications for a metric, the data still displays in Access
 Experience interface. 

 Adjust the thresholds by sliding the
 dot on the threshold lines against each notification type and
 Save your changes. 

 In the Distribution section, select one of the
 following: 

 All users - Select to send notifications for all
 users and user groups in your organization. 

 Custom - Select specific users and user groups
 for whom you wish to send the notifications.
