 You can deploy the Panorama virtual appliance across a range of on-premises hypervisors
 and public cloud environments. 

 Before installation, decide whether to run the virtual appliance in Panorama mode,
 Management Only mode or Log Collector mode. Each mode has different resource
 requirements, as described in Setup Prerequisites for
 the Panorama Virtual Appliance . You must complete the prerequisites before
 starting the installation. 

 As of September 1, 2025, the
 legacy mode is no longer supported on Panorama. For additional information, see the
 official end-of-life notice . 

 Installation procedures vary by platform, but the underlying requirements and
 configuration goals remain consistent across environments. Each platform-specific topic
 in this section provides the steps needed to deploy the virtual appliance image,
 configure initial networking, and prepare the instance for use. Follow the topic that
 corresponds to your target environment and refer to the prerequisite guidance if you are
 unsure which mode or resource profile applies to your deployment. 

 As new hypervisor and cloud platforms are validated and supported, additional
 installation topics will be added to this section.
