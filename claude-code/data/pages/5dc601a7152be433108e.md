 The [edit...] banner presented below the Configure mode command
prompt line shows the current hierarchy context. 

 [edit] 

 indicates that the relative context is the top level of the hierarchy,
whereas 

 [edit deviceconfig] 

 indicates that the relative context is at the deviceconfig level. 

 Use the commands listed in to navigate through the configuration
hierarchy. 

 Level 

 Description 

 edit 

 Sets the context for configuration within
the command hierarchy. 

 up 

 Changes the context to the next higher level
in the hierarchy. 

 top 

 Changes the context to the highest level
in the hierarchy. 

 The set command issued after using
the up and top commands
starts from the new context.
