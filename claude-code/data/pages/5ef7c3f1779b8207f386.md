 Device > Setup > Smart Connect AI 

 You can use the Smart Connect AI tab to enable, configure, and
 monitor VIMS (Vehicle Ignition Monitoring System) on the firewall hardware. VIMS uses
 IGN+ and BATT+ inputs to detect instances of vehicle ignition and draw electrical
 current to power the connected appliance. By installing a supported firewall in this
 way, you can effectively establish a mobile network perimeter, track vehicle data, and
 secure sensitive data in remote locations. 

 Only the following firewalls support VIMS: 

 PA-52R-5G 

 PA-54R-POE 

 PA-54R-POE-D-5G 

 These firewalls have BATT- and IGN+ inputs that must be connected to the vehicle's
 primary power source. You can only enable VIMS configuration once
 the connection between the firewall and the vehicle is established. The PA-54R-POE and
 PA-54R-POE-D-5G in particular require the use of an AMPSU (Automotive Power Supply
 Unit). The interface between the AMPSU and the firewall offers input/output pins that
 can be configured to monitor and report on different conditions of the VIMS deployment
 based on voltage signals. 

 Item 

 Description 

 Vehicle Ignition Monitoring System 

 Enable VIMS Configuration 

 Select this option to enable VIMS. 

 Ensure that an AMPSU is
 connected to the firewall appliance before selecting this
 option. 

 PoE Power Off Timeout (In minutes) 

 Enter a value between 1 and 60 to determine the time (in minutes) PoE
 remains active after the vehicle ignition is powered off. You can
 enter 0 to disable the timeout. 

 System Power Off Timeout (In Minutes) 

 Enter a value between 1 and 60 to determine the time (in minutes) the
 device continues running after the vehicle ignition is powered off.
 You can enter 0 to disable the timeout. 

 Smart IO Configuration 

 Enable Smart IO Pin <#> 

 Select this option to enable the Smart IO pin. 

 Description 

 Enter a description for the pin. 

 Type 

 Select Input or Output 
 to designate the pin type. An input pin monitors for voltage signals
 and an output pin triggers the appropriate response. 

 Action when monitored HIGH 

 Select which action(s) to take when the pin detects a high voltage
 signal. 

 Alarm generates an alert on the dashboard;
 Info Logging generates a system log. 

 Action when monitored LOW 

 Select which action(s) to take when the pin detects low voltage
 signal. 

 Alarm generates an alert on the dashboard;
 Info Logging generates a system log.
