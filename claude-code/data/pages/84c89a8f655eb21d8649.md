 Learn about the INC_PA_SERVICE_DEGRADATION_RN_SITE_CONNECTIVITY incident. 

 Incident Code 

 INC_PA_SERVICE_DEGRADATION_RN_SITE_CONNECTIVITY 

 Title Template 

 Prisma Access Service Degradation impacting branch site connectivity for location {location} 

 Category 

 Network Services 

 Subcategory 

 Prisma Access Infrastructure 

 Description 

 There is a degradation in the Prisma Access service related to connectivity with a remote network site. This degradation may result in reduced or unstable connectivity between the Prisma Access infrastructure and the specified remote network site. It is important to investigate this incident promptly to identify the root cause and take necessary actions to restore stable connectivity and ensure smooth operation between Prisma Access and the affected remote network site.
