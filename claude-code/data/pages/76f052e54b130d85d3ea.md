 Configuration: End User Coaching 

 Define the brand profile and manage the content, format, and behavior of end-user
 notifications in notification templates. 

 Where Can I Use This? What Do I Need? 

 Prisma Access 

 (with Strata Cloud Manager or Panorama 
 configuration management) 

 Enterprise Data Loss Prevention (E-DLP) license 

 Prisma Access (Managed by Strata Cloud Manager) — Prisma Access license 

 Autonomous DEM Agent 6.0 or later for ADEM Self Serve
 Notifications 

 End User Coaching in Strata™ Cloud Manager is a unified notification framework that
 delivers real-time, branded notifications to end users when ADEM or DLP policy events
 occur. Notifications reinforce security awareness and provide coaching guidance without
 requiring ongoing administrator intervention after initial setup. Strata Cloud Manager
 delivers notifications in the end user's device default language based on device
 locale. 

 Supported Product Types 
 Autonomous Digital Experience Management (ADEM) 
 ADEM uses End User Coaching to notify users
 about digital experience issues detected on their endpoints. The ADEM Agent
 (version 6.0.0 or later) delivers self-serve notifications directly to the
 endpoint. ADEM End User Coaching supports the following event
 types: 

 Event Event Type Description 

 Device High CPU Utilization Notifies the user when CPU utilization consistently
 exceeds the configured threshold. 

 High Memory Utilization Notifies the user when memory utilization consistently
 exceeds the configured threshold. 

 WiFi Wi-Fi Signal Strength Notifies the user when the endpoint's Wi-Fi signal falls
 below the configured threshold. 

 Wi-Fi Disconnected Notifies the user when the endpoint's Wi-Fi is unable to
 access internet. 

 Wi-Fi Degradation SSID Changed Notifies the user when the endpoint's Wi-Fi quality is
 poor compared to the previous Wi-Fi connection. 

 Internet Internet Disconnected Notifies the user when the device is not connected to the
 internet. 

 Enterprise Data Loss Prevention (E-DLP) 
 Enterprise DLP uses End User Coaching to
 notify users when their actions violate a Network DLP or Endpoint DLP rule.
 Enterprise DLP blocks the action and a notification is displayed on the
 user's screen. A notification template specified in the DLP rule determines
 the layout, text, and variables of the notification displayed to the user.
 The notification template also determines whether the user can request an
 exemption. 

 Brand Profile 

 The Brand Profile defines the visual identity applied globally to all notifications.
 You configure it once per tenant, and the settings apply to every notification
 template automatically. 

 Notification Templates 

 Notification templates define the content, format, and behavior of end-user
 notifications. You associate templates with DLP profiles to trigger notifications
 when specific events occur. Strata Cloud Manager includes pre-configured default
 notification templates for each supported product. Default notification template
 apply automatically when no custom template is assigned to a policy or event. 
 For DLP , you can create a new
 template, modify the default template directly or clone it as a starting
 point for a custom template. 

 For ADEM , you can modify the
 content and settings of the default ADEM template, but cannot create new
 templates. 

 Strata Cloud Manager displays the following information for each template: 
 Template Name : The name of the template. 

 Product Type : The product that triggers the notification;
 ADEM or DLP 

 Policies using this template : To trigger notifications from DLP
 policy matches, you must associate a notification template with the relevant
 DLP template. Templates are associated with policies during policy
 configuration. To assign a template: 
 Network DLP : The DLP rules specify the
 notification template. 

 Endpoint DLP : The Endpoint DLP rules specify
 the notification template. 

 ADEM: Configuration is managed within the ADEM notifications
 section here in Strata Cloud Manager. 

 Actions : You can perform the following actions on the notification
 templates: 
 Edit : Modify an existing template's content, type, or
 settings. 

 ( Only applicable to DLP Templates ) Clone : Create a
 copy of a template to use as a starting point for a new one. 

 Preview : View how the notification message appears with the
 configured brand profile, theme and templates. 

 Delete : Remove a template. You can't delete a template that
 is assigned to an active DLP profile or an ADEM event.
