 Install Cortex XDR agents 

 Install Cortex XDR agents with agent installation packages to monitor endpoints and collect Cortex XSIAM endpoint data. 

 The Cortex XDR agent monitors endpoint activity and collects endpoint data that Cortex XSIAM uses to generate issues. Before you can begin collecting endpoint data, you must create an agent installation package and then install the Cortex XDR agent.
