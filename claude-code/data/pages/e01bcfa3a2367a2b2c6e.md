 Addressed issues in Cortex XDR agent 8.5.2 

 The following issues have been resolved in Cortex XDR agent release 8.5.2 

 Issue 

 Description 

 CPATR‑27836 

 (Windows) 

 Fixed an issue that may occur in non-US locale OS editions, affecting exception handling logic. 

 CPATR-27550 

 (Windows) 

 Fixed an issue to improve the Cortex XDR agent security and stability posture. 

 CPATR-27148 

 (Windows) 

 Fixed an issue that in rare cases may generate a false indication of a successful security event. 

 CPATR-27022 

 (Windows) 

 Extended the Local Analysis alert exclusion mechanism to include support for the DLL file type. 

 CPATR-26540 

 (Linux) 

 Improvement made to the Cortex XDR agent stability posture. 

 CPATR-26325 

 (Windows) 

 Fixed an issue to improve the Cortex XDR agent security and stability posture. 

 CPATR-26168 

 Fixed an issue where a post-detection alert may be listed in the Alerts Table incorrectly. 

 CPATR-24802 

 (MacOS) 

 Fixed an issue where the Cytool log set_level command may not validate a password. 

 CPATR-23086 

 (Windows) 

 Improvement made to the Cortex XDR agent security and stability posture. 

 CPATR-18158 

 (Windows) 

 Fixed an issue that may occur when the Java Deserialization Protection module is enabled on a machine.
