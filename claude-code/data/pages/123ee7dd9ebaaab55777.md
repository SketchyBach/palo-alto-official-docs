 Tunnel Creation Failure - IPSec IKE SA Failure 

 Incident Code 

 INC_NGFW_TUNNEL_IKE_FAILURE 

 Severity 

 Warning 

 Category 

 Network and Traffic 

 Subcategory 

 Site/Tunnel 

 Description 

 IPSec IKEv1 Phase1 and IKEv2 SA Failure 

 Raise Condition 

 The Incident is created when IKEv1 Phase 1 or IKEv2 SA negotiation steps fail.

 Clear Condition 

 When the tunnel IKEv1 or IKE v2 SA negotiation succeeds (OR) When the tunnel
 associated is established
