 Objects > Mobile Networks > Subscriber Groups 

 Use Subscriber Group objects to combine individual subscriber objects. 

 To simplify the management of security policies, you can combine individual subscriber
 objects into subscriber groups. Subscriber groups can contain up to 5,000 members. When
 used in a security rule, the group entries are flattened and pushed to the data plane
 for policy matching. 

 Field Description 

 Name Enter a name for the subscriber object (up to 63 characters). The
 name is case-sensitive, must be unique, and can contain only letters,
 numbers, spaces, hyphens, and underscores. 

 Shared Select this option if you want the subscriber object to be available
 to every virtual system (vsys) on a multi-vsys firewall or every device
 group on Panorama. 

 Description Enter an optional description for the object (up to 1,023
 characters). 

 Subscribers Manage Subscriber objects by group: 
 Browse —Select from available Subscriber
 or Subscriber Group objects. 

 Add —Add new Subscriber or Subscriber
 Group objects to the group. 

 Delete —Delete Subscriber or Subscriber
 Group objects from the group.
