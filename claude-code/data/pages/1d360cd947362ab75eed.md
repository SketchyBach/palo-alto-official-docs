 Open the Access Experience Notifications Interface 

 Learn how to open the Access Experience user interface when you receive a notification
 informing you of possible application experience degradation. 

 Where Can I Use
 This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 Prisma Access license 

 ADEM or Strata Cloud Manager Pro 
 license 

 GlobalProtect or Prisma Access Agent license 

 Enable Self Serve
 Notification 

 If you have not received a notification, you can still check for CPU, memory,
 WiFi, and internet connectivity issues that may impact your applications' performance by
 opening the Access Experience UI directly. To do so: 

 On Macintosh: 

 Use one of the following methods: 

 ( Prisma Access Agent 25.3.1 and higher ) Click the Access Experience icon
 in Prisma Access Agent to open the Access Experience app. 

 In Prisma Access Agent versions below 25.3.1, you can
 find the Access 
 Experience icon in the menu bar. 

 ( GlobalProtect ) Click the Access Experience menu bar item. 

 Open the app from the Applications Access Experience folder in Finder. 

 Use Spotlight to find the Access Experience app and double-click it. 

 On Windows: 

 Use one of the following methods: 

 ( Prisma Access Agent 25.3.1 and higher ) Click the Access Experience icon
 in Prisma Access Agent to open the Access Experience app. 

 In Prisma Access Agent versions below 25.3.1, you can
 find the Access 
 Experience app in the task bar. 

 ( GlobalProtect ) Right-click the Access Experience icon in the
 task bar. 

 Open it from the Start menu.
