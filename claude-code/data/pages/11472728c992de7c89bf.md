 debug process 

 Use the debug process command
to start, stop, restart a process, or check the status of a process. Services
are interrupted, and traffic for the duration of the restart. Stopping
or restarting a procedure should only be done under the guidance
of support team. 

 Command 

 debug process (status (all | process name) |start |stop | restart) <process name> 

 Options 

 status Enter status to check the status of a process.
Enter all to check the status of all processes, or enter
a process name to check the status of a specific process. 

 start Enter start to start a process. 

 stop Enter stop to stop a process. 

 restart Enter restart to restart a process. 

 Command Notes 

 Role Super 

 Related Commands — 

 Introduced in Release 4.6.1 

 Example 

 debug process status name=dns
 dns RUNNING pid 940, uptime 5 days, 23:41:38
 debug process stop name=rtr_mgr_api
