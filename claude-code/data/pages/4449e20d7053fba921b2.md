 ADEM Settings Dashboard 

 Manage your Autonomous DEM users and view licensing details
and audit logs. 

 Use the Settings page to manage
your Autonomous DEM users and remote sites, see licensing details
about how many users and tests are available and how many are used.
Also see how much ADEM bandwidth is allocated and available based
on the ADEM license allocation on Prisma Access compute locations.
View the audit logs to see which administrators have authenticated
to Prisma Access during the selected Time Range . 

 Select or define a custom Time Range to
view the data for only the time window selected. 

 Filter (click 

 ) the data shown
in the widgets in this dashboard. The following filters are available:
