 Create a Radware Alteon Machine 

 Creating a new machine is the initial step in enabling Next-Gen Trust Security to connect directly to application keystores for certificate management. Once you have created machines, you can move on to provisioning certificates to those machines. 

 Before You Begin 

 IP address or hostname of the Radware Alteon ADC. 

 Port number (Optional): The port number for connecting to the device. 

 Credentials: Choose between user credentials or shared credentials. 

 User credentials: The account you use must have admin permission. 

 Shared credentials: Optionally, you can use shared credentials from your credential provider (CyberArk is the only credential provider currently supported by Next-Gen Trust Security). To use this option, first set up the connection to CyberArk . 

 Enter the Server Hostname . 

 If your Radware Alteon ADC uses a port other than 443, enter the port number in the Port field. 

 From the Credential Type drop-down, select either Enter Credentials or Select Credentials . Only users with the enabled "CyberArk shared credential" capability will see this option. 

 Important: Your view of credentials depends on the workspace you have selected. Under Tenant you can select any credential in the tenant. Inside a workspace you can select that workspace's credentials and any that another workspace has shared with it through Authorized Workspaces . 

 Note: 

 Enter Credentials - Is used to enter your admin credentials manually. 

 Select Credentials - Is used to select your shared credentials from CyberArk. 

 If you choose Enter Credentials , enter your Radware Alteon ADC admin credentials in the Username and Password fields. 

 If you choose Select Credentials , from the Credential drop-down, select your shared credentials. 

 Click Test Access , then click Continue . Note that Continue is only enabled if the Test Access is successful. 

 Warning: Remember to store your username and password securely when creating a new machine. For security reasons, you will not be able to modify the fields under the "Access" tab without these credentials. This ensures that only authorized individuals can modify these fields. 

 What's Next? 

 Refer back to Create a new machine to finish setting up your new machine by configuring Discovery and Provisioning scheduling. 

 For existing machines: 

 Now that you have one or more machines created, you can provision certificates to those machines . 

 You can also discover certificates on machines to enable easy tracking of certificates deployed to your machines.
