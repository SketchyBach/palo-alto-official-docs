 Features Introduced in June 2021 

 Learn what’s new in Prisma SD-WAN in June 2021. 

 New Feature/Enhancement Description 

 Updated Web Interface 

 When you next log in to Prisma SD-WAN , you will
see an updated web interface. 

 App Switcher 

 Customers onboarded through the Palo
Alto Networks hub only. 

 Use App Switcher to switch seamlessly
between your Palo Alto Networks applications. 

 New Terminology—Standard VPN 

 The terms 3rd Party VPN and 3rd Party are
now referred to as Standard VPN across the Prisma
SD-WAN web interface and related documentation.
