 ADEM Licensing 

 In order to get access to the metrics gathered by ADEM, you must purchase a Strata
 Cloud Manager Pro licenses. 

 Where Can I Use
 This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 Prisma Access license 

 ADEM or Strata Cloud Manager Pro 
 license 

 GlobalProtect or Prisma Access Agent license 

 AI-Powered ADEM addresses the NOC, IT Helpdesk, Network and Security admin
 persona. These are the licenses that give you AI-Powered ADEM: 

 Strata Cloud Manager Pro, for Prisma Access (New) You
 can purchase Strata Cloud Manager Pro in addition
 to a Prisma Access license purchased October 2024 or later. Strata Cloud Manager
 Pro includes AI-Powered ADEM, and is your first step to start leveraging the
 complete set of AI-Powered ADEM features. 

 AI-Powered ADEM and ADEM Observability, as add-ons to your Prisma
 Access license 
 (If you purchased Prisma Access before October 2024) Before we
 introduced Strata Cloud Manager Pro, you could add an AI-Powered ADEM and an
 ADEM observability license onto Prisma Access: 

 If you were using AI-Powered ADEM or ADEM Observability with
 Prisma Access before October 2024, your licenses remain supported and
 you can continue to amend, extend, or renew them. 

 If you purchased your Prisma Access license before October
 2024, and would now like to get started with Autonomous DEM, you must
 purchase the AI-Powered ADEM license. 

 This licensing model must be enabled on the
 entire Prisma Access base and cannot be enabled for partial tenant
 (Mobile Users only or Remote Networks only). This license will and must
 always match Prisma Access Mobile Users and Prisma Access NET (Remote
 Networks) license. 

 After you add an ADEM license, ADEM pages may not appear
 immediately. Allow at least 6 hours for the cache to refresh and apply your new
 license. 

 AI-Powered ADEM with Strata Cloud Manager Pro 

 AI-Powered ADEM with Strata Cloud Manager Pro gives you
 holistic observability across your network; it helps to automate complex IT
 operations, reduce ticket volume, and shorten the mean time to resolution
 (MTTR). 

 AI-Powered ADEM with Strata Cloud Manager Pro provides the full suite of
 ADEM features, including ADEM Observability features, predictive analytics, and
 Access Analyzer powered by AI/ML/Formal. Here’s how to activate Strata Cloud Manager
 Pro so you can get started. 

 Continued Support for the AI-Powered ADEM & ADEM Observability
 Licenses 

 Starting in October 2024, the newly-available Strata Cloud Manager Pro license gives you
 AI-Powered ADEM. 

 However, if you were using either an ADEM Observability License or
 AI-Powered ADEM license previous to this date, your licenses remain supported and
 you can continue to extend, amend, or renew them. Additionally, if you purchased a
 Prisma Access license before October 2024, you can also still newly-purchase an
 AI-Powered ADEM license. 

 ADEM Observability 

 With the ADEM Observability add-on license you get all features that come
 with the Prisma Access base license. In addition, you can purchase one or both
 of the following licenses: 

 Mobile User License—Gives you access to Mobile User metrics that
 ADEM gathers through Browser-Based Real User Monitoring (RUM) or
 synthetic monitoring. 

 Remote Site License—Gives you access to Remote Site metrics that
 ADEM gathers through synthetic monitoring. 

 For optimal performance, use only 10 synthetic application tests per
 mobile user or remote site. 

 AI-Powered ADEM 

 AI-Powered ADEM license includes ADEM Observability features as well as
 predictive analytics, Access Analyzer powered by AI/ML/Formal and an enhanced view
 of Incidents. If you have purchased Mobile Users and Remote Networks in a Prisma
 Access base license, ensure that you have an AI-Powered ADEM license for Mobile
 Users and Remote Networks with the same number of licenses as the base. 

 For details on which features are available with each ADEM license, see
 Prisma SASE AI-Powered Autonomous Digital
 Experience Management .
