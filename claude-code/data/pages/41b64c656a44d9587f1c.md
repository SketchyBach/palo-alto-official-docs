 Remote PsExec-like command execution 

 Synopsis 

 Field 

 Value 

 Activation Period 

 14 Days 

 Training Period 

 30 Days 

 Test Period 

 N/A (single event) 

 Deduplication Period 

 1 Day 

 Required Data 

 XDR Agent 

 Detector Tags 

 Impacket Analytics 

 ATT&CK Tactic 

 Lateral Movement (TA0008), Execution (TA0002) 

 ATT&CK Technique 

 Remote Services (T1021), System Services: Service Execution (T1569.002), Lateral Tool Transfer (T1570) 

 Severity 

 Informational 

 Description 

 A remotely triggered service initiated a command execution in a PsExec-like manner by a host that rarely triggers services to other remote hosts. 

 Attacker's Goals 

 Perform lateral movement to new hosts to expand the foothold within a network. 

 Investigative actions 

 Investigate the processes being spawned on the host for malicious activities. 

 Correlate the RPC call from the source host and understand which software initiated it.
