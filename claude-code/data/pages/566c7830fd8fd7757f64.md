 Reveal Password on Windows Logon Screen for GlobalProtect 

 You can use the reveal password feature to display the password you type. 

 When logging in to your Windows 10 or Windows 11 desktop or when changing your
 password, you can click the Reveal Password icon to display
 the password as you type. The password is displayed in plain text. This feature
 helps prevent typing errors and reduces the risk of account lockouts by allowing you
 to confirm your password visually. 

 This feature is available in GlobalProtect™ 6.3.3 onwards and can be enabled via a
 registry key. For details about the registry key, refer to App Display Options . 

 The Windows login screen displays the GlobalProtect connection status and gateway in
 addition to the Reveal Password icon in the password field. 

 The Change Password dialog box shows your username, domain name, GlobalProtect
 connection status, and gateway in addition to the Reveal Password icon in the
 password field.
