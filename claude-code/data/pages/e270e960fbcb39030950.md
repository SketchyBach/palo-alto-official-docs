 Demisto SDK commands 

 zip-packs 

 Package Cortex content packs into ZIP archives for distribution or upload. 

 The zip-packs command packages content packs into a .zip file that can be uploaded to Cortex XSOAR using the Upload pack button in the Cortex XSOAR Marketplace, or directly with the -u flag of the zip-packs command. 

 Arguments 

 Argument 

 Description 

 -i, --input 

 The packs for which to create artifacts. Accepted values are all or a comma-separated list of pack names. 

 -o, --output 

 The path to the directory in which to save the .zip file. 

 -v RELEASE_VERSION, --content-version RELEASE_VERSION 

 The content version to set in CommonServerPython . 

 -u, --upload 

 Uploads the zipped packs to Cortex XSOAR Marketplace. 

 --zip-all 

 Zips all the packs into a single .zip file. 

 Examples 

 demisto-sdk zip-packs -i Campaign -o "DestinationDir" 

 Zips the Campaign pack into the Campaign.zip file in the DestinationDir directory. 

 demisto-sdk zip-packs -i Campaign -o "DestinationDir" -u 

 Zips the Campaign pack into the uploadable_packs.zip file in the DestinationDir directory and uploads the created uploadable_packs.zip to Marketplace.
