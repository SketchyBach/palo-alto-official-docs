 INC_ZTNA_CONNECTOR_MEMORY 

 Learn about the INC_ZTNA_CONNECTOR_MEMORY incident. 

 Incident Code 

 INC_ZTNA_CONNECTOR_MEMORY 

 Title Template 

 ZTNA connector {connector_name} average available memory is lower than 10% over 30 mins 

 Category 

 Device 

 Subcategory 

 System Resources 

 Description 

 There has been a higher than normal memory utilization observed on a specific ZTNA (Zero Trust Network Access) Connector. This could lead to performance degradation, instability, or even service interruptions on this ZTNA Connector, as available memory is becoming constrained. 

 Raise Condition 

 ZTNA Connector Average Memory Utilization in last 30 minutes exceeds 90% of total memory 

 Clear Condition 

 ZTNA Connector Average Memory utilization in last 30 minutes has dropped below 85% of total memory
