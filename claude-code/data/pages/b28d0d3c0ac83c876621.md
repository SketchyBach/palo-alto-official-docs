 Autonomous DEM Plugin 

 View Autonomous DEM plugin version compatibility. 

 Autonomous Digital Experience Management
 (ADEM) supports its end-to-end application experience and performance monitoring
 capabilities beyond the SASE platform to next-generation firewalls (NGFWs) for a more
 comprehensive view into your users’ digital experience. To enable ADEM monitoring in
 NGFWs, use the PAN-OS plugin for ADEM. 

 The following table briefly describes the features and PAN-OS versions in which the ADEM
 plugins are introduced. 

 ADEM Plugin Version Included in PAN-OS Base Image New Features or Changes 

 2.0.0 12.2.2 N/A 

 1.1.0-h3 12.1.3 N/A 

 1.0.1 11.1.9 N/A 

 1.0.0 11.2.6 Initial release of PAN-OS plugin for ADEM to support
 application experience and performance monitoring capabilities beyond
 the SASE platform to next-generation firewalls (NGFWs). 

 Autonomous DEM plugin is supported on all VM-Series
 firewall except VMs with ARM based instances.
