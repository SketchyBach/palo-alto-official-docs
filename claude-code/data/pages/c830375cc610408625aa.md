 Cortex DDR Command Center 

 The Cortex Data Detection and Response (DDR) Command Center is the central hub for monitoring and responding to real-time threats against your data. It brings your open issues, MITRE ATT&CK coverage, and highest priority threats into a single interactive view. From there, you can see which threats are targeting your sensitive data, how quickly your team is containing them, and what to work on next. 

 The dashboard covers real-time threat detections across your data stores, your SaaS IdPs and SaaS apps, and threats detected by AI Detection and Response (AIDR). DSPM and DLP issues aren't included. To see those, use the Cortex Data Security Command Center. 

 The dashboard is designed to guide you from the current state of your environment—how many threats are open, how old they are, and how fast you are closing them—down to the individual issue you need to investigate. 

 A global time filter of 24H , 7D , or 30D applies to every widget on the dashboard, and defaults to 24H .

 The dashboard inherits the same role-based and scope-based access control (RBAC and SBAC) settings as the Data Security Command Center. 

 How to access the Cortex DDR Command Center 

 You can open the DDR Command Center from any of the following locations: 

 Modules → Data Security → Data Detection and Response 

 Modules → Data Security → Data Command Center , then select the Data Detection and Response branch. 

 Dashboards & Reports → Dashboard , then choose Data Detection & Response from the dashboard drop-down menu in the header. 

 The DDR Command Center is a system-provided dashboard, and is read-only and cannot be edited or deleted. To build your own version, select Save as new to create a custom dashboard you can modify while preserving the original. For more information, see Data Security dashboards. 

 Current state 

 These widgets summarize your threat backlog and how quickly your team is working through it: 

 Issue breakdown: The total open issues in your environment, broken down by severity, with a trend indicator comparing the count to the preceding time window. 

 Mean time to remediate issues: The MTTR for issues, plotted per severity alongside the overall average. 

 Open issues by age: Unresolved issues sorted by how long they have been in the system. 

 Issue Burndown: A trendline of issues created against issues resolved, with the total for each shown in the legend. When more issues are created than resolved, your security debt is growing. 

 MITRE ATT&CK 

 Maps your open issues to the MITRE ATT&CK framework, with the number of issues and techniques recorded against each tactic. The full matrix is always shown, including tactics with no open issues, so you can track an attacker's progress and judge whether a quiet tactic reflects effective controls or a detection gap. 

 Select a tactic or technique to filter Top data security issues , or select Open full view to see the complete matrix. 

 Top data security issues 

 Lists the individual threats in your environment so you can triage them by priority. Alongside the issue name, severity, and status, each row shows the insert time and the issue category. You can add further columns, such as the issue description and a link to the associated case. 

 Select a row to open the issue investigation view in a side card.
