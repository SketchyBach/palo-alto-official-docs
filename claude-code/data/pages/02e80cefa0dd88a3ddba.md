 ION 2000 Ports 

 Learn how you can use the ION 2000 ports for different
purposes. 

 The ports on the ION 2000 are used as
follows: 

 Ports Description 

 AUX This port is an auxiliary access port intended
for offline access, configuration, and troubleshooting a system
during installation. 

 USB This port is reserved for future use. 

 Controller This port is used by ION 2000 to communicate
with the Prisma SD-WAN controller. 

 Internet/LAN/WAN Ports Ports 1 - 5 are used for internet, local area
network (LAN), or private router or multi-path label switching (MPLS) connectivity.
The WAN or LAN ports can be coupled or de-coupled as needed. By
default, ports 2 and 3 are DHCP-enabled ports. 

 Fail-to-Wire Port Pair By default, ports 4 and 5 are pre-configured
as a fail-to-wire port pair. This port pair may be set to fail open
or closed.
