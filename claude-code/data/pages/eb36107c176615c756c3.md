 New Features - Cloud Identity Engine - April 2026 

 Forward Logs from the Cloud Identity Engine to Strata Logging Service 

 Release Date: April 2026 
 | 
 Last Updated: May 2026 

 The Cloud Identity Engine (CIE) now supports automated log forwarding to the Strata Logging Service (SLS). This integration provides granular visibility into Directory Sync and Administrative Audit events. By centralizing this telemetry in SLS, administrators can move beyond minimal service insights to efficiently troubleshoot synchronization errors, monitor real-time sync progress, and gather the evidence required for internal compliance audits.
