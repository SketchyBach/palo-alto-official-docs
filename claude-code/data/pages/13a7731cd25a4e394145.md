 AL_ZTNA_CONNECTOR_TUNNEL_DOWN 

 Learn about the AL_ZTNA_CONNECTOR_TUNNEL_DOWN alert. 

 Synopsis 

 This alert is raised when the tunnel <tunnel-name> is down for connector
 <connector-name> in connector-group <group-name>. The alert is cleared when
 the tunnel between the connector and ZTT is reestablished. 

 Alert Code—AL_ZTNA_CONNECTOR_TUNNEL_DOWN
