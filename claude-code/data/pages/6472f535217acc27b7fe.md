 Cisco Meraki SD-WAN Solution Guide 

 Learn about the Cisco Meraki integration with Prisma Access in aggregate bandwidth
 and site based licensing models. 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 Prisma Access 
 license 

 Physical Cisco Meraki (MX or Z) devices or virtual Cisco Meraki
 (vMX) devices with a minimum version of 15.12 

 Prisma Access provides a flexible way to effectively secure Cisco Meraki SD-WAN
 deployments. By delivering security from the cloud and closer to the branch networks,
 Prisma Access lets you optimize networking and security with the same protections that
 you have at corporate headquarters. This integration is managed through two distinct
 licensing models, each with a unique approach to bandwidth and tunnel management. 

 Prisma Access's site-based licensing model streamlines the deployment of
 IPSec tunnels for remote networks by shifting the focus from aggregate bandwidth to
 site-specific capacity. This approach simplifies a key step in integrating third-party
 SD-WAN solutions, where IPSec tunnels are used to establish secure connections between
 the branch offices and the cloud-delivered security of Prisma Access. Instead of
 manually pre-allocating bandwidth for each tunnel, administrators now simply assign a
 licensed site type to a location, and the system automatically manages the underlying
 connection details, making it easier to scale and manage secure, high-performance
 network access. 

 The aggregate bandwidth model is a licensing approach for Prisma Access
 Remote Networks. In this model, you can purchase a total, or aggregate, amount of
 bandwidth for your entire remote network deployment. You're then required to manually
 estimate and allocate portions of this total bandwidth to specific Prisma Access compute
 locations (SPNs) for each individual remote site. 

 You can onboard a remote network using IPSec tunnels between the Cisco Meraki SD-WAN
 device and Prisma Access automatically or manually .
