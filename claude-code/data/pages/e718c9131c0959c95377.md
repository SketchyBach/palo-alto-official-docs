 Increase the System Disk on the Panorama Virtual Appliance 

 Expand the system disk on the Panorama virtual appliance 

 Expand the system disk capacity to 224GB for the Panorama virtual appliance to
 support large datasets to allow for sufficient disk space for things such as dynamic
 updates when you Manage Large-Scale Firewall Deployments with Panorama . Additionally, a 224GB system disk
 expands storage for monitoring and reporting data for managed firewall health if you
 intended to use the Panorama virtual appliance in Panorama mode to manage your SD-WAN deployment
