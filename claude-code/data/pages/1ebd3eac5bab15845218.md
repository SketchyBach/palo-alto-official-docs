 Enable Autonomous DEM in Prisma Access (Cloud Managed CloudBlade) 

 Enable Autonomous DEM in Prisma Access (Cloud Managed CloudBlade) and refer the ADEM
 considerations. 

 To enable ADEM in Cloud Managed Prisma Access . 

 Click Manage and select Remote
 Networks . 

 In Remote Networks Setup , under the
 Autonomous DEM column, to enable Remote Networks on a
 Compute Location , move its slider to the right until
 it turns blue. 
 For more information on the ADEM configuration, see Cloud Managed Prisma Access . 

 ADEM Considerations 

 The following are the prerequisites to enable ADEM for Prisma SD-WAN Remote Networks. 

 The minimum Prisma Access for Networks (Cloud Managed) CloudBlade
 version requirement for integrating Prisma SD-WAN remote
 networks with ADEM is version 3.x.x. 

 ADEM is only supported when Aggregate Bandwidth is enabled on Prisma Access . 

 You must allocate Remote Networks bandwidth on the
 compute locations in Prisma Access .
