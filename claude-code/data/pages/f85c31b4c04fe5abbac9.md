 PAN-OS 10.2 Nebula release introduced an advanced routing engine that uses an industry-standard configuration methodology to reduce your learning curve. The advanced routing engine contains new filtering concepts and relies heavily on routing profiles. Use the migration scripts to simplify the advanced routing configuration. This migration reference guide provides information about the exceptions and proposes some alternatives to make the migration process go as smoothly as possible.
