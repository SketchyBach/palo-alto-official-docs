# Introduction to Demisto SDK

Introduction to the Demisto SDK Python library that assists with your content development needs.

The Demisto SDK is a Python library designed to aid the development process, both to validate entities being developed and to assist in the interaction between your development setup and Cortex XSOAR or Cortex XSIAM. This guide provides information about installation and setup, as well as a detailed description of Demisto SDK commands.
