 Rule Details 

 Cortex AppSec Rule ID 

 APPSEC_SECRET_369 

 Category 

 Secrets 

 Severity 

 CRITICAL 

 Framework 

 Git 

 Impact 

 Cursor API keys provide access to Cursor AI coding assistant services. If exposed, attackers could use your API quota, access your coding sessions, or potentially view code snippets processed through the service. Rotate the key immediately if exposed and implement proper secret management. 

 How to Fix 

 Rotate the Cursor API key immediately and store it securely using environment variables or a secrets management service.
