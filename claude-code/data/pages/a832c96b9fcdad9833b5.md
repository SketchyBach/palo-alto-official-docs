 Application Details - Performance Trends for Mobile Users 

 The widgets in this tab show you performance
data for a specific application across all Mobile User devices. 

 Application Experience Score Trend for Mobile User Devices 

 View the experience score trend during the selected Time Range for
a specific application across all mobile users. 

 Performance Metrics 

 Track the responsiveness and availability metrics for
a single app in these widgets. 

 App Performance Metrics 

 Metric Description 

 Availability Application availability (in percentage) during
the Time Range . 

 DNS Lookup DNS resolution time. 

 TCP Connect Time taken to establish a TCP connection. 

 SSL Connect Time taken to establish an SSL connection. 

 HTTP Latency Time taken to establish an HTTP connection. 

 Time to First Byte The total of DNS Lookup, TCP Connect, SSL Connect
and HTTP Latency time results in the Time to First Byte. 

 Data Transfer Total time taken for the entire data to be
transferred. 

 Time to Last Byte Time to First Byte + Data Transfer time. 

 Network Performance Metrics 

 Metric Description 

 Availability Network availability metrics during the Time Range . 

 Network Latency Time taken to transfer the data over the network. 

 Packet Loss Loss of packets during data transmission. 

 Jitter Change in latency during the Time Range .
