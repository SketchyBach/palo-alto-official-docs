 Cortex XDR Agent 9.2 Release Information 

 Feature Enhancements 

 The following tables describe the new features introduced in Cortex XDR agent 9.2, according to the supported agent operating systems. The release will be divided into three deployments; 3 May 2026, 17 May 2026, and 31 May 2026. 

 General 

 FEATURE 

 DESCRIPTION 

 Device guardrails for SD cards 

 Fortify your perimeter by blocking SD Card devices connected via the PCI Bus. This new capability closes a critical vector for data exfiltration and neutralizes a common entry point for malicious code. 

 Container as a Service (CaaS) support for AWS ECS Fargate 

 Embed the Cortex XDR agent within the container image for CaaS workloads and get real-time monitoring and protection against active threats. This is available via the Cloud Runtime Security add-on for Cortex XDR. 

 Advanced Java malware protection 

 Prevent cyberattacks from compromising your applications. You can now automatically detect and block malicious Java-based threats on Windows and Linux. This allows protecting Java applications in real-time (Windows only) or when potentially malicious Java files are saved to your file system. 

 Linux 

 FEATURE 

 DESCRIPTION 

 Shared objects file examination 

 Secure your Linux environment against hidden threats. You can now automatically block malicious code from executing through non-standard loading methods. We updated the Cortex XDR agent to examine and stop harmful shared object files before they impact your system. 

 Linux Kernel update 

 Cortex XDR agent 9.2 is compatible with Linux Kernel >= 3.10 

 Platform support 

 Added support for OpenShift 4.19 

 macOS 

 FEATURE 

 DESCRIPTION 

 On-write malicious file detection 

 Stop cross-platform threats from entering your network. You can now detect malicious mach-o files and non-native macOS binaries (such as Windows PEs and Linux ELFs) the moment they are saved to your system. We updated the Cortex XDR agent to provide comprehensive on-write detection for these binary types. 

 Windows 

 FEATURE 

 DESCRIPTION 

 Streamlined installation for Citrix app layering 

 Simplify agent deployment in virtual desktop environments. We integrated a new VDI deployment method supporting platform layer and MCS/PVS provisioning, streamlining agent installation in Citrix non-persistent VDI's that utilize Citrix App Layering.
