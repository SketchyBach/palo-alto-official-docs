 Stop or Start the Staged Rollout of Prisma Access Agents 

 Learn how to stop and start the staged rollout of Prisma Access Agents 
 manually. 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 NGFW (Managed by Panorama) 

 Check the prerequisites for the deployment you're
 using 

 macOS 14 and later or Windows 10 version 2024 and later
 desktop devices 

 Contact your Palo Alto Networks account representative to
 activate the Prisma Access Agent feature 

 You can stop a staged rollout of the Prisma Access Agents for any reason, such
 as connectivity problems encountered during the rollout or other business reasons.
 Suppose some devices in an upgrade ring weren’t upgraded successfully during a
 staged rollout. You can stop the staged rollout to investigate and resolve any
 issues, and then start the staged rollout again. 

 When you stop the staged rollout, any devices that have been upgraded already
 will remain upgraded. When you start the rollout again, the rollout will begin
 at Ring 0, and any devices that have been upgraded won't receive the upgrade
 again. 

 Stop a Stage Rollout 

 To stop a staged rollout: 

 Select Configuration Endpoint Management . 

 In the Agent Upgrade Progress section, click
 Stop . 

 When prompted, select a reason for stopping the staged rollout and
 Submit . 

 Start a Staged Rollout 

 To start a staged rollout: 

 Select Configuration Endpoint Management . 

 In the Agent Upgrade Progress section, click
 Start . 

 In the confirmation window, click Yes to confirm
 that you want to start the staged rollout. 

 You are notified of the upcoming upgrade after confirming the staged
 rollout. The upgrade begins automatically at the end of the notification
 period (5 minutes). 

 The staged rollout will start from Ring 0.
