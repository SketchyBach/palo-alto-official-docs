 View Target Details 

 If target endpoints were previously configured, they'll show up as a list of
 available Targets (in AI Security AI Red Teaming Targets ). 

 You can edit these existing targets, or, remove them. 

 Each target also displays a profiling State that indicates
 the current state of agentic profiling for that target. The Recommended
 Action is the next best step you should take based on your target's
 current state, helping you move forward with target profiling or scanning. 

 Draft is a target state where
 your target configuration is incomplete and has not yet been successfully
 added. You won't be able to perform target profiling or target scanning
 until your target moves out of the Draft state. Which
 means you can start a scan ( 

 ) for your target (and you can run any scan
 type, including Agent-led scans) in all profiling states except
 Draft . 

 Target Profiling State Description Recommended Action 

 Draft The target configuration is incomplete and has not yet been
 successfully added. Continue Adding Target . 

 Active The target is active and available for scanning. Target
 Profiling has not been initiated for this target. Select Run Profiling to complete
 target profiling. You can also directly scan the target using
 Start Scan completely skipping the Run
 Profiling action. Proceed with any scan type,
 including Agent-led scans. 

 Profiling In-Progress Target profiling is currently running for this target. 

 Select Scan Target . Proceed with any
 scan type, including Agent-led scans. The target profile updates
 automatically on completion. 

 Profiling Complete Target profiling has successfully completed and full target
 context is available. 

 Select Scan Target . Proceed with any
 scan type, including Agent-led scans. 

 Profiling Failed Target profiling encountered an error and did not
 complete. 

 Select Retry Profiling in the panel
 to trigger a new target profiling job. 

 Partially Profiled Target Profiling completed but some target information could
 not be discovered. 

 Select Retry Profiling in the panel
 to trigger a new target profiling job. 

 View Target Profile, Risk Overview, and Configuration 

 Select a target to view its details. The details page is organized into three
 sections: Profile displays the Target Background you configured,
 Additional Context and System Capabilities contains
 target-related information that are automatically populated by AI Red Teaming
 (separate from your manual configuration), Risk Overview displays risk
 scores from completed scans, and Configuration displays target setup
 details. 

 The Profile section contains: 
 Target Background : All details are displayed
 upfront and can be modified directly within the section, avoiding
 the need to return to the target page. 

 Additional Context : All details are displayed
 upfront and can be modified directly within the section, avoiding
 the need to return to the target page. 

 System Capabilities : Appears dynamically only
 when agentic profiling is enabled and has successfully completed.

 The System
 Capabilities section is not available if
 profiling has never been run for the target. 

 If no further changes are needed, you can Start
 Scan directly from this window. 

 The Risk Overview section displays the risk score for
 completed scans and a list of all scans that have been executed. 
 After
 reviewing the risk details, you can Start Scan 
 directly from this window. 

 The Configuration section contains the basic target
 details. 
 If no further changes are needed, you can Start
 Scan directly from this window.
