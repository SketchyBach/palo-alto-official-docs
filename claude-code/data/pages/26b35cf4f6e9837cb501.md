 Microsoft Identity 

 Use Microsoft Identity data for Cortex Cloud. 

 Important 

 This connector is only available for tenants that onboarded after July 26, 2026. For tenants that onboarded before this date, use Marketplace to access the standalone integration. For more information, see Marketplace . 

 Manage Microsoft Entra ID (formerly Azure Active Directory) identity resources — users, groups, applications and service principals, directory roles, conditional access, and risky users. 

 This connector includes the following sub-capabilities (Marketplace integrations link to PAN DEV for more information): 

 AzureRiskyUsers : Azure Risky Users provides access to all at-risk users and risk detections in the Azure AD environment. This connector is available with any active Cortex XSIAM, Cortex Cloud Posture Security, Cortex Cloud, Cortex Cloud Runtime Security, Cortex XDR, or Cortex AgentiX license. 

 Microsoft Graph Groups : Entra ID Groups integration (formely Azure Active Directory Groups) enables you to create and manage different types of groups and group functionality according to your requirements. This connector is available with any active Cortex XSIAM, Cortex Cloud Posture Security, Cortex Cloud, Cortex Cloud Runtime Security, Cortex XDR, or Cortex AgentiX license. 

 Microsoft Graph User : The Entra ID Users integration (formerly Azure Active Directory Users) is a Unified gateway to security insights - all from a unified Microsoft Graph User API. This connector is available with any active Cortex XSIAM, Cortex Cloud Posture Security, Cortex Cloud, Cortex Cloud Runtime Security, Cortex XDR, or Cortex AgentiX license. 

 MicrosoftGraphApplications : Use the Entra ID Applications integration (formerly Azure Active Directory Applications) to manage authorized applications. This connector is available with any active Cortex XSIAM, Cortex Cloud Posture Security, Cortex Cloud, Cortex Cloud Runtime Security, Cortex XDR, or Cortex AgentiX license. 

 MicrosoftGraphIdentityandAccess : Use the Entra ID Identity And Access integration to manage roles and members (formerly Azure Active Directory Identity And Access). This connector is available with any active Cortex XSIAM, Cortex Cloud Posture Security, Cortex Cloud, Cortex Cloud Runtime Security, Cortex XDR, or Cortex AgentiX license. 

 To configure this connector, follow the steps outlined in the configuration wizard.
