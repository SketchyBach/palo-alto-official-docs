 Issue ID 

 Description 

 PAN-325120 

 Fixed an issue on PA-415, PA-415-5G, PA-445, PA-455, and PA-455-5G
 platforms where certain PAN-OS versions caused intermittent
 connectivity failures on the Eth1/1 data port and loss of power on
 PoE ports. 

 PAN-300615 

 Fixed an issue where the pan_comm process
 stopped after multiple content versions were installed and the memory
 limits were reached.
