 Commands Description 

 Updated 

 dump nat6 counters Displays the NAT configuration on the device via IPv6
 tables. 

 dump routing prefix-reachability Displays the reachability information for a prefix. 

 inspect connection Inspects the established connections. 

 inspect flow brief Inspects brief details for active flows matching user-specified
 options. 

 inspect flow detail Inspects details for active flows matching user-specified
 options. 

 CLI Commands in Prisma SD-WAN ION Release 6.4.1 

 See the updated device CLI commands in Prisma SD-WAN ION
 Device Release 6.4.1. 

 Commands Description 

 New 

 clear routing ospf Clears all the open shortest path first (OSPF)
 sessions on a device. 

 dump ml7-mctd counters Displays the global counters for App IDs. 

 dump ml7 mctd session Displays the session status for App IDs. 

 dump ml7 mctd version Displays the library and content version of the App
 IDs. 

 dump routing ospf Displays the open shortest path first (OSPF) specific
 device configurations. 

 dump probe profile Displays all the probe profile configurations for a
 device. 

 dump probe config Displays all the probe configurations for a
 device. 

 Updated 

 dump flow count summary Displays the total concurrent flows and fps for
 monitoring purposes. 

 dump interface config Displays the interface configurations. 

 dump overview Displays the basic information about the
 device. 

 dump performance-policy config policy-rules Displays a device's path policy rule
 configuration. 

 dump performance-policy config
 threshold-profile Displays all the threshold configurations for the
 policy. 

 dump service link summary Displays information on standard VPNs. 

 dump support Displays the CLI command outputs, cores, and device
 logs in a tar file. 

 dump vpn status Displays the information for a virtual private
 network (VPN) link. 

 inspect performance-policy lookup Inspects to identify the potential performance
 policies for an application flow. 

 inspect performance-policy incidents Inspects to identify potential system related health
 alarms. 

 inspect wanpaths Inspects the VPN WAN paths from the controller and
 displays all the VPN WAN paths on the device sent by the
 controller.
