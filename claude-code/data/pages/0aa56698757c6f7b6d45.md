 Activate the Security Lifecycle Review (SLR) App 

 Learn how to activate the Security Lifecycle Review (SLR) app. 

 Security Lifecycle Review (SLR) is a free Palo Alto Networks app that requires Strata Logging Service . 

 SLR examines the network data in Strata Logging Service to provide an overview of your
 security posture. To use SLR for the first time, you must activate the SLR app on
 the hub . When you first activate SLR, you are creating a single SLR app
 instance , and each SLR instance must be paired with a Strata Logging Service instance. You can create as many instances of the SLR
 app as you like; for example, you might create different SLR instances to generate
 reports for specific regions or audiences. 

 Log in to the hub and find the Security
Lifecycle Review (SLR) app listed under More Available
Palo Alto Networks Apps . 

 Activate the SLR app. 

 Continue to pair this instance of the SLR app with a Strata Logging Service instance. SLR findings are based on the data
 stored in the Strata Logging Service instance you choose. 

 Enter a descriptive Name for this SLR app
 instance. 

 Select the Region in which Palo Alto Networks
 has deployed your Strata Logging Service infrastructure (SLR and
 Strata Logging Service must be deployed in the same
 region). 

 Select the Strata Logging Service 
 instance to pair with SLR. SLR report data is based off the logs
 forwarded to this Strata Logging Service instance. 

 Agree and Activate SLR. 

 You’ll now see SLR displayed as one of your apps on the hub .
