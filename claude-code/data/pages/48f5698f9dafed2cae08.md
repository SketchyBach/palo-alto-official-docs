 getActionStatus 

 Retrieves the status of an action by its action ID. Returns per-endpoint status and error details if applicable. 

 Arguments 

 Argument Name 

 Description 

 Required 

 action_id 

 A comma-separated list of action IDs to query. 

 Required 

 Outputs 

 Core.GetActionStatus.action_id number 

 The specified action ID. 

 Core.GetActionStatus.endpoint_id string 

 Endpoint ID. 

 Core.GetActionStatus.status string 

 The status of the specific endpoint ID. 

 Core.GetActionStatus.error_description string 

 Description of the error if the action failed. 

 retrieveFileDetails 

 Returns file retrieval details for a completed file retrieval action. Use getActionStatus first to verify the action completed successfully. 

 Arguments 

 Argument Name 

 Description 

 Required 

 action_id 

 A comma-separated list of action IDs to retrieve file details for. 

 Required 

 Outputs 

 File.Size number 

 The size of the file. 

 File.SHA1 string 

 The SHA1 hash of the file. 

 File.SHA256 string 

 The SHA256 hash of the file. 

 File.Name string 

 The name of the file. 

 File.SSDeep string 

 The SSDeep hash of the file. 

 File.EntryID string 

 The entry ID of the file. 

 File.Info string 

 File information. 

 File.Type string 

 The file type. 

 File.MD5 string 

 The MD5 hash of the file. 

 File.Extension string 

 The file extension.
