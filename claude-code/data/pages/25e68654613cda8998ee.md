 Retrieve an External Dynamic List from the Web Server 

 When you Configure
the Firewall to Access an External Dynamic List , you can
configure the firewall to retrieve the list from the web server
on an hourly (default)five minute, daily, weekly, or monthly basis.
If you have added or deleted IP addresses from the list and need
to trigger an immediate refresh, use the following process to fetch the
updated list. 

 To retrieve the list on demand, select Objects External Dynamic Lists . 

 Select the list that you want to refresh, and click Import
Now . The job to import the list is queued. 

 To view the status of the job in the Task Manager, see Manage
and Monitor Administrative Tasks . 

 ( Optional ) After the firewall retrieves the
list, View
External Dynamic List Entries .
