 Manage User Roles 

 Use the following procedure to manage user roles: 

 Select Settings User and Roles . 

 Select the name of the user. 

 Modify the First Name and Last
 Name if necessary. 

 Modify the user’s Roles & Scope . To add a role: 
 Click Add Role . 

 Select the Role and Scope 
 from the respective drop-downs. 
 To delete a role: 

 Click the delete icon ( 

 ) located to
 the right of the rule. 

 Click Save . 

 Delete a User 

 If you need to completely remove a user’s access and permissions, you can delete that
 user. 

 Select Settings User and Roles . 

 Select the check box to the left of the user’s name. 

 Select Actions Delete . 

 Click Save . 

 Edit User Information 

 A non-tenant administrator can update their name or change their password if needed.
 However, they cannot modify their assigned roles. 

 Select Settings User and Roles . 

 Select the name of the user. 

 Modify the First Name and Last
 Name if necessary. 

 To change a password: 
 Click Change Password . 

 Enter the Current Password . 

 Enter and re-enter the New Password . 

 Click Change . 

 Changing the
 password logs you out of the Cloud NGFW tenant. Log back in using the new
 password. 

 Click Save .
