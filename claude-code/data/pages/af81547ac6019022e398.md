 Configure Site-Level Settings to Onboard a Site 

 Listed are the site-level settings and processes that you must perform to onboard a
 site. 

 Where Can I Use This? What Do I Need? 

 Supported CloudBlades: 

 Prisma Access for Networks (Managed by Panorama) 

 Prisma Access for Networks (Cloud Managed) 

 Prisma SD-WAN 

 Prisma Access 

 Supported Cloud Plugin Versions 

 Prisma Access for Networks (Managed by Panorama) CloudBlade versions 3.x.x and
 later 

 Prisma Access for Networks (Cloud Managed) CloudBlade versions 3.x.x and
 4.x.x 

 After you configure the CloudBlade, you can integrate Prisma SD-WAN and Prisma Access for
 Networks CloudBlade (Panorama Managed and Cloud Managed). Following are the site-level
 settings that you must perform to onboard a site. Follow the processes as required. 

 Onboard ECMP: the ECMP onboarding of sites is simplified by just having to configure
 the prisma_access tag on a site, in conjunction with the IPSec Termination
 Node region tags applied. 

 Onboard Non-ECMP: For basic onboarding, configure sites and site tags. 

 Enable BGP, regardless of ECMP or single connection to Prisma Access. 

 Tag interfaces appropriately to add them to a non-ECMP deployment for Prisma
 Access. 

 Customize Prisma Access objects names using the CloudBlade tag. 

 Review and edit the application policy network rules. 

 Configure standard groups and assign domains to the sites.
