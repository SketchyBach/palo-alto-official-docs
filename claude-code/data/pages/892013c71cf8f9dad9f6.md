 Feature Enhancements 

 AI Security 

 FEATURE 

 DESCRIPTION 

 Strengthen security for open-source AI models 

 Secure your AI environment against vulnerabilities in open-source models. You can now assess risks instantly using dashboard tracking and direct links to reputation databases. We updated the model asset card to include Prisma AIRS insights for better security decision-making. 

 Visibility into AI agents collaboration 

 As AI ecosystems grow more complex, collaborations between agents are an important part of the attack surface. We’ve added the ability to track these relations between AI agents, now visible within Graph Search and on each agent's Asset Card.
