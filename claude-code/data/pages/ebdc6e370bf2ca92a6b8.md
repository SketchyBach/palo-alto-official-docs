 Onboard a Microsoft OneDrive App to SSPM 

 Connect a Microsoft OneDrive instance to SSPM to detect posture risks. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 SaaS Security Posture Management license 

 Or any of the following licenses that include the Data Security license: 

 CASB-X 

 CASB-PA 

 We discontinued the separate Microsoft OneDrive connector in August 2025, because
 the Microsoft SharePoint connector now
 onboards both Microsoft SharePoint and Microsoft OneDrive. The new Microsoft
 SharePoint connector leverages the deep integration between Microsoft SharePoint
 and Microsoft OneDrive to scan both of these product instances. For this reason,
 the separate Microsoft OneDrive connector is no longer necessary. 

 Previously, you could onboard Microsoft OneDrive by supplying account credentials
 to SSPM. If you already connected SSPM to your Microsoft OneDrive instance by
 using this earlier connector, your established connection will continue to work.
 However, if there is any change to the configuration information that you
 provided to SSPM (such as an updated login password), you will need to onboard
 both Microsoft SharePoint and Microsoft OneDrive by using the Microsoft SharePoint
 connector .
