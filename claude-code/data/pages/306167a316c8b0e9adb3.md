 Addressed Issues in 2025 

 Enterprise Data Loss Prevention (E-DLP) and Endpoint DLP known issues addressed in 2025. 

 Addressed Issues in October 2025 

 ID 

 Description 

 DSS-18161 

 The log View link in an Endpoint DLP
 Incident ( Manage Configuration Data Loss Prevention DLP Incidents ) redirects the user to the Strata Cloud Manager Command Center Log Viewer ( Incidents and Alerts Log Viewer ) with no filters applied to view the log details
 for the incident being investigated. 

 Workaround: Manually apply the following filters in the
 Log Viewer. 

 For the Log Type, select
 Endpoint/Troubleshooting (Prisma Access
 Agent) 

 For the filter query, enter
 sub_type.value='dlp' 

 Addressed Issues in May 2025 

 ID 

 Description 

 DIT-54573 

 Enterprise DLP fails to block a file containing sensitive
 data uploaded to LinkedIn Messenger that it successfully blocks
 for other supported apps. 

 Workaround : Install dynamic content version 8978-9450 or
 later. 

 DSS-22557 

 The pass keyword for the following
 predefined data patterns generate a large number of false
 positive detections. 

 Passport - Austria 

 Passport - Belgium 

 Passport - Estonia 

 Passport - Finland 

 Passport - Germany 

 Passport - Liechtenstein 

 Passport - Luxembourg 

 Passport - Norway 

 Passport - Switzerland 

 DSS-21945 

 Enterprise DLP Audit Logs ( Manage Configuration Data Loss Prevention Audit Log ) show the User as
 UNKNOWN when configuration
 changes are made to your syslog Log Forwarding configuration ( Manage Configuration Data Loss Prevention Settings Logging Settings ). 

 DSS-21292 

 On Strata Cloud Manager , the predefined DLP Administrator role
 and DLP Policy Administrator roles ( Settings Identity & Access Roles ) Web UI and API permissions display
 No Results Available . 

 DSS-21179 

 Enterprise DLP fails to inspect and render verdicts on
 nested 7z files.
