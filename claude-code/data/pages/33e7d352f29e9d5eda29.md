 IPQ Component Error Detected 

 Incident Code 

 INC_NGFW_IPQ_ERROR 

 Severity 

 Critical 

 Category 

 Device 

 Subcategory 

 Hardware 

 Description 

 A critical IPQ (Ingress Packet Queue) fatal error has been detected on a
 Forwarding Engine (e.g., FE100-series chip) within the firewall. This error
 indicates that a reseat is needed, or there is a hardware failure. 

 Raise Condition 

 The log file /opt/var.cp/log/pan/brdagent.log on device contains the error
 pattern: "ERROR FE[14]00 IPQ Fatal error". At least one occurrence of this error
 message is observed. (FS Scenario 15 implies detection based on presence within a
 1-day window, checked hourly). The device model is one of the following series:
 PA-3200, PA-5200, PA-7000, PA-5400, or Blackbird (as per FS Scenario 15). 

 Clear Condition 

 This incident is cleared when no new "ERROR FE[14]00 IPQ Fatal error" log
 messages have been observed in /opt/var.cp/log/pan/brdagent.log for a continuous
 period of 1 day.
