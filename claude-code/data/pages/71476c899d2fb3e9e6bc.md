 Schedule incident export and delete 

 Schedule incident exports and deletions to external storage in Cortex XSOAR 8.13 On-prem. 

 Schedule incident export, deletion, or both in Cortex XSOAR 8.13 On-prem. Scheduled exports store incident data in configured external storage. You can delete incidents only, or delete them after export. 

 Before you begin 

 To export incidents, first configure an external storage solution. See Configure access to external storage . 

 The first time incidents are exported, the process may take multiple days or weeks, depending on the number of incidents and the amount of data. The system must complete the previous export before starting another. 

 To stop an existing export process, click the Abort button. The Abort button appears only when an export is in progress. 

 If an export fails, the Instance Admin receives an email notification. To enable or disable notification settings, click on your username and select User Preferences → Notifications → Other Notifications → Scheduled export and delete failure . 

 Once an incident has been exported, it is not exported again, even if it remains in the system and is modified after the export. 

 After you enable scheduling, the Export and Delete Incidents page shows the next scheduled procedure. It also shows the last successful procedure. During an active procedure, it shows the current status. 

 Schedule incident actions 
 Schedule an incident export 

 Go to Settings & Info → Settings → System → Export Incidents . 

 Toggle the button to Enable scheduled exports . 

 Select Export . 

 Select the time range. For example, if you select three months, all incidents created more than three months ago are exported. The minimum value is one month. 

 Select whether to Include incident attachments . 

 Choose the frequency, days, and time. 

 Choose an existing external storage option. 

 Enter the relative storage path. For example, for the export_incidents folder in an Amazon S3 bucket, enter export_incidents . 

 Save . 

 Schedule incident deletion 

 Go to Settings & Info → Settings → System → Export Incidents . 

 Toggle the button to Enable scheduled exports . 

 Select Delete . 

 Select the time range. For example, if you select three months, all incidents created more than three months ago are deleted. The minimum value is one month. 

 Choose the frequency, days, and time. 

 Save . 

 Schedule incident export and deletion 

 If you choose to export and then delete incidents, no incident is deleted until it has been exported. 

 Go to Settings & Info → Settings → System → Export Incidents . 

 Toggle the button to Enable scheduled exports . 

 Select Export then delete . 

 Select the time range. For example, if you select three months, all incidents created more than three months ago are exported and then deleted. The minimum value is one month. 

 Select whether to Include incident attachments . 

 Choose the frequency, days, and time. 

 Choose an existing external storage option. 

 Enter the relative storage path. For example, for the export_incidents folder in an Amazon S3 bucket, enter export_incidents . 

 Save .
