 XQL Language Structure 

 Understand Cortex Query Language query structure in Cortex AgentiX. 

 Cortex Query Language (XQL) queries usually begin by defining a data source, be it a dataset, preset, or Cortex Data Model (XDM). You must specify the dataset mapped to the XDM that you want to run your query against. In a dataset query, unless otherwise specified, the query runs against the xdr_data dataset, which contains all log information that Cortex AgentiX collects from all Cortex product agents, including EDR data, and PAN NGFW data. It's possible to change the default dataset in the Dataset Management page of Cortex AgentiX. For more information, see What are datasets? . 

 After specifying a data source, you use zero or more stages to form the XQL query. Each stage is delimited using a pipe character ( | ). The function performed by each stage is identified by the stage keyword that you provide. XQL queries can contain different components depending on the type of query you want to build.
