 clear routing 

 Use the clear routing command to clear the border gateway
 protocol (BGP) peer sessions on a device. 

 Command 

 clear routing (vrf-name | vrf-id) peer-ip 

 Options 

 vrf-name This clears the BGP peer session with the associated
 VRF name and peer IP. 

 vrf-id This clears the BGP peer session with the associated
 VRF id and peer IP. 

 Command Notes 

 Role Super

 Introduced in Release 6.3.1

 clear routing vrf-name=IOT-Data peer-ip 6.6.8.254 

 clear routing vrf-id=1686679744525012828 peer-ip 6.6.8.254
