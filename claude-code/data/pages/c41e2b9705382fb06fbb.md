 Create a Dashboard 

 Create and customize a Cortex XSOAR 6.14 dashboard with widgets, data views, and security operations insights. 

 You can create and customize multiple dashboards, which are personal to the user. 

 In the DASHBOARD tab, select Add dashboard → New Dashboard . 

 In the Widget’s Library section, add the widgets to the dashboard . 

 From the Date Range drop down list, set the date range for the dashboard. 

 Widgets can have their own date range, which may be different from the dashboard’s date range. 

 Type a name for the dashboard. 

 Click Save or Save Version . 

 Save Version enables you to view a history of the changes made to your dashboard. You can revert to previous versions.
