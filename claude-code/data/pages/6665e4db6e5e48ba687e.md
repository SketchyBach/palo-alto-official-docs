 Configure the engine to call the server without using a proxy 

 Configure direct engine calls in Cortex XSOAR On-prem 8.6 (EoL). 

 On the computer where you have installed the engine, go to the directory for d1.conf file. 

 For RPM, DEB, Shell go to /usr/local/demisto . 

 Add the following configuration:

 Key 

 Value 

 engine.to.server.proxy 

 false (default is true)
