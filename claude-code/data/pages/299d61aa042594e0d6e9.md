 Enable Multiple Virtual Systems Support on VM-Series Firewall 

 PAN-OS 11.1.3 and later releases After you install the virtual system
 license on your firewall, perform the following steps to enable the multiple virtual
 systems support on VM-Series: 

 Log in to the firewall web interface and navigate to Device >
 Licenses . 

 Go to General Settings , and then select the Multi virtual system
 Capability check-box. 

 Click OK . 

 You can now see the Virtual Systems option on the left pane. 

 Click Add to create multiple virtual systems based on the
 number of vsys that you have on your virtual system license. 

 To update the number of vsys on your virtual system license, Edit Deployment Profile and change
 the number of vsys license, and then update the deployment profile 

 Enable Multiple Virtual Systems Support on VM-Series in Panorama Console 

 PAN-OS 11.1.3 and later releases After you enable the multiple virtual
 systems support on the VM-Series firewall, perform the following steps to
 configure multiple virtual systems using the Panorama console. 

 Log in to Panorama. 

 Go to Device and select the Multi Vsys check-box. 

 Navigate to Virtual Systems and then click Add to configure
 virtual systems on your firewall. 

 Configure Virtual Systems on
 your VM-Series firewall. 

 Select Commit > Push to Devices and push the entire Panorama
 managed configuration to each vsys of the multi-vsys firewall. 

 Enable Multiple Virtual Systems Support Using Bootstrap Method 

 PAN-OS 11.1.3 and later releases You can enable multiple
 virtual systems support on VM-Series firewall using the bootstrap method. Store
 basic configuration parameters as key-value pairs in
 config/init-cfg.txt in the bootstrap package. 

 For more information, see Bootstrap the VM-Series Firewall and
 Choose a Bootstrap method . 

 To enable multiple virtual systems support, you must configure the following
 parameter as key-value pair in the config/init-cfg.txt 
 file. 

 op-command-modes=multi-vsys 

 For more information, see Create the init-cfg.txt File and init-cfg.txt File Components .
