 Prisma SD-WAN Ports and Interfaces 

 Let us discuss the ports and interfaces in the Prisma
SD-WAN. 

 Where Can I Use
 This? What Do I Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 After you have completed the sites and devices' set-up, configure the ports and
 interfaces. Ports are the physical interfaces on the ION device and Interfaces are the
 logical interfaces on the ION device. Every port or interface has specific configuration
 steps that must be followed. Read on to understand to configure ports and interfaces on
 an ION device. 

 For more information on the Port Panel user interface, see Prisma SD-WAN Port Panel Status Indicators . 

 The various physical ports are: 

 Controller Ports 

 Internet Ports

 The various logical interfaces are:

 Prisma SD-WAN Standard VPN
