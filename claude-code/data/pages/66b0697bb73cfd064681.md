 Panorama Plugins 

 The Panorama plugins are categorized into two different grids. 

 The Bundled Plugins grid displays all built-in plugins that come pre-packaged
 with the Panorama system; you cannot manually upload or download these plugins. 

 The Cloud Services Plugins grid displays the cloud services plugins, which
 are the only plugins that you can manually upload or download. This grid appears
 only if Panorama has a valid Strata Logging Service license installed. 

 Bundled Plugins 

 Select Panorama Plugins to install and manage the plugins that support third-party integrations
 on Panorama. 

 Bundled Plugins 

 Description 

 Name 

 The plugin file name. 

 Size 

 The plugin file size. 

 Currently Installed 

 Provides the current installation status of each plugin on
 Panorama. 

 Actions 

 Install —Installs the appropriate
 version of the plugin. Installing a new version of the
 plugin overwrites the previously installed version. 

 Remove Config —Removes all
 configuration related to the plugin. To completely
 remove all configuration related to a plugin, you must
 also perform and Uninstall after
 using Remove Config . 

 When removing configuration from the Panorama plugin for
 VMware NSX, this action deletes service definition(s)
 and service manager(s) only. It does not remove other
 related configuration, such as zone, device groups, or
 templates. Additionally, to complete this action in a
 Panorama HA deployment, you must remove config on the
 active first, initiate a failover to make the secondary
 active, and then remove config on the new active
 peer. 

 Uninstall —Removes the current
 installation of the plugin. This does not remove the
 plugin file from Panorama. If you uninstall the plugin,
 you lose any configuration related to that plugin. Only
 use when completely removing the related
 configuration. 

 Release Note URL 

 Provides a link to the release notes for the corresponding
 version. 

 Cloud Services Plugins 

 Select Panorama Plugins to install, remove, and manage the plugins that support third-party
 integrations on Panorama. 

 Cloud Services Plugins 

 Description 

 Upload 

 Allows you to upload a plugin installation file from a local
 directory. This does not install the plugin. After uploading the
 installation file, the Install link becomes
 active. 

 Check Now 

 Retrieves a list of available updates. 

 File Name 

 The plugin file name. 

 Version 

 The plugin version number. 

 Release date 

 The release date of this version of the plugin. 

 Size 

 The plugin file size. 

 Downloaded 

 Provides the status of currently downloaded plugin. 

 Currently Installed 

 Provides the current installation status of each plugin on
 Panorama. 

 Actions 

 Download ——Indicates that a new update
 file is available. Click the link to begin downloading the
 file directly to the firewall. After successful download,
 the link changes from Download to
 Install . 

 Install —Installs the specified version
 of the plugin. Installing a new version of the plugin
 overwrites the previously installed version. 

 Delete —Deletes the specified plugin
 file. 

 Remove Config —Removes all
 configuration related to the plugin. To completely remove
 all configuration related to a plugin, you must also perform
 and Uninstall after using
 Remove Config . 

 When removing configuration from the Panorama plugin for
 VMware NSX, this action deletes service definition(s) and
 service manager(s) only. It does not remove other related
 configuration, such as zone, device groups, or templates.
 Additionally, to complete this action in a Panorama HA
 deployment, you must remove config on the active first,
 initiate a failover to make the secondary active, and then
 remove config on the new active peer. 

 Uninstall —Removes the current
 installation of the plugin. This does not remove the plugin
 file from Panorama. If you uninstall the plugin, you lose
 any configuration related to that plugin. Only use when
 completely removing the related configuration.
