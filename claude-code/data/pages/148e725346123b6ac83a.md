 Prisma SASE FedRAMP Moderate and High SLS IP Address Blocks 

 Learn which IP address blocks are supported for use in Prisma SASE FedRAMP Moderate
 and High environments. 

 The Following IP address blocks are used by the applications in the federal region. When
 user traffic to the portal passes through a NAT device on a perimeter firewall, edge
 router, or VPN gateway, provide the IP address to which NAT translates the users’
 original IP addresses. After you submit a support ticket with these addresses to Palo
 Alto Networks, customer services will create an allow list for the addresses you
 provided, which will let users log in from these addresses and access the portal. If
 your enterprise uses allow lists, be sure to add these IP addresses to your allow lists
 to make sure that Strata Logging Service can receive the logs. 

 Moderate IP Address Blocks 

 The following are FedRAMP Moderate IP Address Blocks. 

 Strata Logging Service FedRAMP Moderate block for log forwarding
 from PANW: 34.67.50.64/28 

 High IP Address Blocks 

 The following are FedRAMP High IP Address Blocks. 

 Strata Logging Service FedRAMP High block for log forwarding from
 PANW: 34.132.154.128/28
