 Cellular Interfaces 

 Learn how to configure a 5G cellular interface. 

 Where Can I Use This? What Do I Need? 

 NGFW (Managed by PAN-OS or Panorama) 

 PAN-OS 11.1 or later depending on the firewall model. 

 One of the supported 5G-integrated firewalls listed in the Mobile Network Infrastructure
 Feature Support compatibility matrix 

 The 5G cellular interface is available on the PA-415-5G platform. Beginning with PAN-OS
 11.1.3, the PA-450R-5G firewall supports 4G/5G. Beginning with PAN-OS 11.1.5, the
 PA-410R-5G firewall supports 4G/5G. Beginning with PAN-OS 11.2.3, the PA-455-5G firewall
 supports 4G/5G. The 5G cellular interface allows you to provide a primary internet
 connection or to configure a secondary connection for redundancy in case the primary
 connection is unavailable. It provides data connectivity using the 5G mobile network and
 automatically switches to a 4G or 3G network if the 5G network is unavailable. You can
 also configure the 5G interface for load-balancing using weighted round-robin. To easily
 monitor information about the status of the 5G network, use the Dashboard widgets. 

 You can configure a primary and secondary (if available) SIM card. If you have a
 secondary SIM card, you can configure the firewall to switch from one SIM card to
 another if one SIM card becomes unavailable. For security, enable a PIN code for the SIM
 card to prevent misuse. 

 As carriers provide updates to new capabilities and resolve issues, you can download
 cellular firmware upgrades from the Customer Support Portal and install them on the
 firewall. This allows the firewall to push the updates to the appropriate users on your
 network. A simplified interface makes it easy to review, manage, and deploy cellular
 firmware updates on your 5G network. Keeping the cellular firmware up to date provides
 new features and capabilities and helps protect your users from threats and
 vulnerabilities. 

 ( PAN-OS 12.2.2 and later releases ) You can configure the cellular interface to relay Dynamic Host Configuration
 Protocol (DHCP) broadcasts from LAN-side devices to a centralized DHCP server
 across the cellular WAN. To use this feature, you must first enable DHCP relay
 capability at the modem level, an action that reboots the modem and terminates active
 cellular sessions.
