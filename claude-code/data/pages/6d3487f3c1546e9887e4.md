 Remote Content Repository (Dev/Prod) 

 Find Cortex XSOAR 8 SaaS FAQs for Dev and Prod remote content repositories. 

 How does Dev/Prod work in Cortex XSOAR 8? 

 Similar to Cortex XSOAR 6, but much easier to set up in the Cortex Gateway and Cortex XSOAR, with a built-in or private Git repository for sharing data between dev and prod. 

 Will it still be possible to use your own Git Repositories? 

 Yes. You can set up your own private Git repository in Cortex XSOAR. 

 How does the built-in Git repository in XSOAR 8 differ from the one in 6, and what does "built-in" mean? 

 In Cortex XSOAR 6, customers need to configure their own Git repository. In Cortex XSOAR 8, you can do that or use a built-in repository that manages content between Dev and Prod in the Cortex XSOAR tenant, without requiring Git or branch management knowledge. 

 Will Dev/Prod also work for multi-tenancy environments? 

 Yes. 

 Is OOTB Git available as well for On-prem? 

 For On-prem, Git will be managed by you, as it is now. 

 Does the OOTB Git repository support blame and reversing to Dev? 

 These features are not offered by Cortex XSOAR 6 and 8. 

 How difficult will it be to move from your Git repository to the one provided by Cortex XSOAR 8? 

 It will be done by our migration process.
