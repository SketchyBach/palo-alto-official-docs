 Features Introduced in 2024 

 July 2024 

 This section describes the new features and updates of the Cortex XDR 3.11 and Cortex XDR Agent 8.5 releases. 

 July 22, 2024 - XDR Collectors 

 Windows 1.4.2.1373 and Linux 1.4.2.1302 

 For more information on maintenance releases, see Maintenance Releases 

 FEATURE 

 DESCRIPTION 

 XDR Collectors bypasses hosts file in a DNS query 

 To avoid unauthorized host redirection using the changes in the Windows hosts file ( C:\Windows\System32\drivers\etc\hosts ), XDR Collectors now bypasses the hosts file in a DNS query. 

 July 21, 2024 - Broker VM 

 Version 24.5.1 (reboot required) 

 For more information on maintenance releases, see Maintenance Releases 

 Feature 

 DESCRIPTION 

 Broker VM 24.5.1 

 To ensure Cortex XDR is updated with the latest security updates, the latest Broker VM 24.5.1 release includes security updates for a number of vulnerabilities. 

 July 14, 2024 - Broker VM 

 Version 24.4.7 (reboot required) 

 For more information on maintenance releases, see Maintenance Releases 

 Feature 

 DESCRIPTION 

 Broker VM 24.4.7 

 This release includes the following improvements and bug fixes: 

 Cortex XDR has improved the Database Collector query parallelism capabilities. 

 Cortex XDR has fixed the data duplication issue with the Database Collector when the Unique IDs option was configured in the Database Query settings.
