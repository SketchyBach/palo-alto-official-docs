 ION 9000 Installation Kit Components 

 The Prisma SD-WAN ION 9000 installation kit components
contains all the required tools and parts to install the device. 

 The ION 9000 installation kit contains
the following parts and tools to install the device: 

 2x 19-inch 1RU rack mount sliding rails built-in with quick-attach
square hole adapters. 

 2x Mounting brackets with accompanying screws. 

 2x 19-inch slide lock ears with accompanying screws. 

 2x Red Cat.5E crossover/rollover ethernet cable. 

 1x Grey Cat.5E straight through ethernet cable. 

 2x Power cord—varies depending on the country or region. 

 1x Screwdriver. 

 1x USB to Cat5/RJ-45 serial cable. 

 2x Slide lock ears. 

 Fitting pins.
