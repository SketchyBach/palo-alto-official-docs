 Import and Overwrite Existing Template Stack Variables 

 Import template or template stack variables to easily
reuse template or template stacks. 

 Where Can I Use This? What Do I Need? 

 NGFW (Managed by Panorama) 

 Device management license 

Use template stack variables to replace IP addresses, IP ranges, FQDN,
 interfaces, or group ID in your firewall configurations. Variables allow you to
 reduce the total number of templates and template stacks you need to manage, while
 allowing you to preserve any firewall-specific values. 

 Importing template
stack variables allows you to overwrite the values of multiple existing
variables, and you cannot create new template stack variables when importing.
For more information how on how to create new template or template stack
variable, see Configure a Template or Template Stack Variable . 

 Log in to the Panorama Web
 Interface . 

 Export
the existing template stack variables. 

 Select Panorama Templates and select a template
or template stack. 

 Select Variable CSV Export . The configured template
stack variables are downloaded locally as a CSV file. 

 Open the exported CSV. 

 Edit the
CSV file containing the template stack variables to import to Panorama in
the following format: 

 Values that display as #inherited# are
values that are defined in the template stack. 

 Correct the number of the cells containing
the firewall serial number. Repeat this step for all firewalls in
the CSV file. 

 Right-click the cell containing the firewall serial
number and select Format Cells . 

 Select Number Text and
click OK . 

 Add a 0 at the beginning of the serial
number. 

 Enter a new value for the desired template variable. 

 Select File Save As and save the file in CSV
UTF-8 format. 

 Import the CSV file to the template stack. 

 Log in to the Panorama Web
 Interface . 

 Select Panorama Templates and select the template
stack for which you exported the variables in Step 2 . 

 Select Variable CSV Import and Browse for
the CSV file edited in Step 3 . 

 Click OK to import the template
stack variables. 

 Select Commit Commit
to Panorama and Commit your
changes. 

 Enter the variables in the appropriate locations. 

 Click Commit and Commit
and Push your changes to managed firewalls. 

 When you push a device group configuration with references to template or
 template stack variables, you must Edit
 Selections and Include Device and Network
 Templates . 

 When you import template variables via CSV, Selective Push is not
 supported. You must perform a Full Push to push your changes to managed
 firewalls. If you need to override template variables for specific
 devices without requiring a Full Push, you can change the values
 directly from the Panorama Managed Devices Summary page. For more information, see Push Selective Configuration
 Changes to Managed Devices .
