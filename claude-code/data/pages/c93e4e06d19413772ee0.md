 A cloud storage object was copied to a foreign cloud account 

 Synopsis

 Value

 Detection Modules 

 Cloud 

 Detector Tags 

 Cloud Data Asset Exfiltration, Cloud Data Asset Configuration, Data Detection & Response 

 ATT&CK Tactic 

 Exfiltration (TA0010) 

 ATT&CK Technique 

 Transfer Data to Cloud Account (T1537) 

 Severity 

 Medium 

 Description 

 A cloud storage object was copied or moved to a foreign cloud storage account. The destination account was either not monitored or not seen within your tenant for the last 30 days. 

 Attacker's Goals 

 Exfiltrate data to a foreign account. 

 Investigative actions 

 Check the legitimacy of the copy operation. 

 Review further actions performed by the identity. 

 Variations
