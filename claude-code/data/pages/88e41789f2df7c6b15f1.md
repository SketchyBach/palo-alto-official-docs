 Remapped Poland Location 

 To better optimize performance of Prisma Access , starting with the
 Prisma Access 4.0 infrastructure upgrade, the Poland location is
 remapped to the Europe Central (Warsaw) compute location. 

 This remapping applies to all existing Prisma Access deployments,
 even if you have not installed the Cloud Services plugin 4.0. Your
 current compute location-to-location mapping is not affected;
 however, if you have an existing Prisma Access deployment that uses
 one of these locations and you want to take advantage of the
 remapped compute location, follow the procedure to add a new compute location to a
 deployed . 

 New deployments have this mapping applied automatically. 

 Bulk Import of Remote Networks 

 The number of remote networks that you can onboard in bulk using a
 CSV file has changed from 1000 to 100.
