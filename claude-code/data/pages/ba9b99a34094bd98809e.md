 Terminal Server (TS) Agent 11.1 Release Information 

 The following information applies to all current 11.1 releases. 

 Changes to Default Behavior 

 The Terminal Server (TS) Agent 11.1 release has no changes to default
 behavior. 

 Known Issues 

 There are no known issues associated with the Terminal Server agent 11.1
 release. 

 For recent updates to known issues for a given PAN-OS release, refer to
 https://live.paloaltonetworks.com/t5/Integration-Articles/Critical-Issues-Addressed-in-PAN-OS-Releases/ta-p/52882 . 

 Addressed Issues 

 There are no addressed issues associated with the Terminal Server agent 11.1
 release. 

 Terminal Server (TS) Agent 11.1.1 Release Information 

 The following information is specific to the 11.1.1 TS agent release. 

 Features Introduced in TS Agent 11.1.1 

 The Terminal Server (TS) 11.1.1 release includes the following new feature. 

 New Feature 

 Description 

 Windows Server 2025 Support 

 You can now install the Terminal Server (TS) agent on the
 Windows Server 2025 operating system. 

 Terminal Server (TS) Agent 11.1.0 Release Information 

 The following information is specific to the 11.1.0 TS agent release. 

 Features Introduced in TS Agent 11.1.0 

 The Terminal Server (TS) Agent 11.1.0 release includes the following new
 feature: 

 New Feature 

 Description 

 Windows Filtering Platform Support 

 The Transport Driver Interface ( TDI ) framework has
 been deprecated by Microsoft. The TS agent has been updated
 to support the new Windows Filtering Platform ( WFP ) framework.
 There is no difference in functionality as a result of this
 change. 

 This feature requires Windows Server
 2019 or later. For more information, see the Compatibility
 Matrix . 

 Upgrade the TS Agent 

 Due to the introduction of WFP support, you must complete the upgrade procedure
 described in the Palo Alto Networks Knowledge Base .
