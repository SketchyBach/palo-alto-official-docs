 View Child Tenant Threat Details Through the Strata Multitenant Cloud Manager 

 Learn how to drill down into child tenant threat details
in the Strata Multitenant Cloud Manager . 

 If you activate a SASE license or a Prisma
Access license for your tenant, after you monitor tenant
threats for a parent tenant, you can drill down into threat
details in Prisma Access for a specific child tenant. 

 Select
the name of the parent tenant. 

 Select Next until
the child tenant is displayed. 

 Select the child tenant. 

 This
page displays the following threat activity and policy widgets: 

 Widget 

 Description 

 Threat Types 

 Displays a chart of the threat types seen
in the tenant environment. 

 You can hover over each threat
type segment in the chart to see the number of threats per type,
and the percentage of each threat type compared to the total number
of threats. 

 View threat details to
drill down into the Prisma Access activity dashboard as a shortcut
alternative to Activity Dashboards Executive Summary Threat Prevention . 

 Threat Trend 

 Displays a graph of the number of threats
seen in the tenant environment over the specified time period. 

 View
threat details to drill down into the Prisma Access 
activity dashboard as a shortcut alternative to Activity Dashboards Executive Summary Threat Prevention . 

 Threat Summary 

 Displays the following information about
the tenant environment: 

 Number of total threats. 

 Number of blocked threats. 

 Number of unblocked threats. 

 Wildfire malicious URLs. 

 Wildfire unknown URLs. 

 View security
threats to drill down into the Prisma Access activity
dashboard as a shortcut alternative to Activity Dashboards Executive Summary Summary . 

 Top Users with Critical Threats 

 Displays the four users with the highest
number of critical threats in the tenant environment and the number
of threats per user. 

 Select a username to display the associated
 Prisma Access threat log entries per user. 

 View
security threats by user to drill down into the Prisma
Access activity dashboard as a shortcut alternative to Activity Logs Log
Viewer Firewall/Threat . 

 Threats by Source 

 Displays a chart of the critical threats
by source seen in the tenant environment based on your license. 

 Hover
over each source segment in the chart to display the number of critical
threats per source and the percentage from that source compared
to the total number of critical threats. 

 View security
threat logs to drill down into the Prisma Access activity
dashboard as a shortcut alternative to Activity Logs Log Viewer Firewall/Traffic . 

 Security Rules & Unblocked Threats 

 Displays the top security rules and unblocked
threats from, and the number of threats per user. 

 View
security rules to drill down into the Prisma Access 
activity dashboard as a shortcut alternative to Manage Configuration Security Services Security Policy . 

 Top Users Accessing Risky URLs 

 Displays the users with the highest number of critical threats from accessing blocked and
 unblocked risky URLs in the tenant environment and the number of
 threats per user. 

 View
risky URLs to drill down into the Prisma Access activity
dashboard as a shortcut alternative to Activity Logs Log Viewer Firewall/URL . 

 Security Rules & Unblocked Risky URLs 

 Displays the Security policy rules that
matched the highest number of unblocked risky URLs in the tenant
environment and the total for each rule. 

 View risky
URLs to drill down into the Prisma Access activity dashboard
as a shortcut alternative to Manage Configuration Security Services Security Policy . 

 Switch tenants to
drill down into a child tenant for a different root-level parent
tenant.
