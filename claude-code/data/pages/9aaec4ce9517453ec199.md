 Agentix for C2C 

 Use Agentix to explore Code-to-Cloud coverage, gaps, and lineage. 

 Cortex Cloud's AI copilots (Agentix) answer coverage questions in natural language, grounded in the same view-def, graph-data, and coverage data sources as the dashboard, and respecting the user's RBAC and SBAC scope. 

 AppSec Agentix answers Code-2-Cloud (code-first) questions — for example, "What is the Code-2-Cloud Artifact Coverage % for Application X considering also not-onboarded repositories?" — including per-application and per-provider scoping 

 Cloud Posture Agentix answers the symmetric Cloud-2-Code (cloud-first) questions 

 Use the copilots for ad-hoc, conversational coverage lookups without navigating the dashboard filters. Each answer maps to a Coverage query scoped by direction, type, and optional application or provider.
