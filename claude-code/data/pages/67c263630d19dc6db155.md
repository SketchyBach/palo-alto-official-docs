 Run a Report 

 Run reports and download them in PDF format. 

 Run a predefined report or previously defined custom report and download it in PDF format. 

 Select Reports → Report Templates . 

 Right-click the report you want to generate and select Generate Report . 

 You will receive a notification when the report is ready to download. You can download the report directly from the notification or from the Reports → Reports tab. 

 Go to the Reports → Reports tab, right-click the report and select Download . 

 The report will remain in the Reports list view so you can access it again as needed.
