 dump appaccel status 

 Use the dump appaccel status CLI command to view the status of the app
 acceleration tunnels. Tunnels are built to regions which are closest to the geographical
 location of the branch site. 

 Command 

 dump appaccel status 

 Options 

 None 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands 

 dump interface config 

 Introduced in Release 6.5.2 

 Example 

 dump appaccel status
