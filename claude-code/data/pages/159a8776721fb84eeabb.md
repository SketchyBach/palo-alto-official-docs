# Dynamic Context Instruction

For the complete documentation index, see llms.txt. This page is also available as Markdown.

Dynamic Context Instruction

Severity

🟡 Medium (5)

Short Description

Flags AI extensions that instruct the agent to fetch and act on context or code retrieved from a remote source at runtime.

Suggestion

Verify the remote source and confirm it is one the publisher controls and documents. Where the fetched content steers the agent's behavior, treat the source's operator as having influence over your agent.

Information

This is the instruction-level counterpart to Dynamic Context. Rather than executing remote content directly, the skill, command, subagent, or rule tells the agent to fetch content from a remote source and then act on it. That is often exactly what a component should do — documentation lookups, API schema retrieval, and package registry queries are all legitimate — and the severity is lower than the executable variant because the agent mediates the result rather than executing it.

The risk is that fetched content becomes instructions. When a component passes remote text into the agent's context, whoever controls that source can influence what the agent does next. That overlaps with Instruction Vulnerable to Prompt Injection; a component carrying both findings should be reviewed with the stronger of the two in mind.

Risks

Remote influence over the agent: Whoever controls the source can shape agent behavior through the content it returns.

No install-time review: The content that arrives at runtime was never part of what you approved.

Injection surface: Fetched content entering the agent's context is a direct prompt injection vector.

Source compromise: A breach of the remote source affects every installation that fetches from it.

Recommended Actions

Investigate the component

Read the evidence to identify the remote sources and what the agent is told to do with the content.

Confirm the sources belong to the publisher and are documented.

Check for a co-occurring Instruction Vulnerable to Prompt Injection finding.

Contain and remediate

Restrict the agent's network access to approved domains.

Keep confirmation prompts enabled for actions the agent takes after fetching remote content.

Remove the component if the source is undisclosed, untrusted, or unnecessary.
