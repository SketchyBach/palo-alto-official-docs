 Azure vWAN CloudBlade Integration 

 Learn about Azure vWAN CloudBlade integration release notes. 

 Microsoft Azure Virtual WAN (vWAN) provides a high-speed global network with minimal
 latencies. Prisma SD-WAN CloudBlades™ platform enables the secure delivery of branch
 infrastructure from the cloud. The Prisma SD-WAN Azure vWAN CloudBlade optimizes branch
 to Azure connectivity by securely and seamlessly integrating an enterprise WAN with
 Azure Virtual WAN. 

 Azure vWAN CloudBlade Version 2.0.1 

 The updated feature in the Azure vWAN CloudBlade version 2.0.1 includes the
 upgrade of the Azure SDK version, due to which the CloudBlade now uses the
 RespondOnly mode to form any new VPN connections, with the
 IKE lifetime being 7 hours by default.
