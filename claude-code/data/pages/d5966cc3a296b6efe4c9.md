 App services do not use Azure files misconfiguration detected in code 

 Rule Details 

 Cortex AppSec Rule ID 

 APPSEC_AZURE_88 

 Category - Subcategory 

 Storage - Encryption 

 Provider 

 AZURE 

 Severity 

 LOW 

 Framework 

 ARM, Bicep, Terraform, Terraform Plan 

 Impact 

 The content directory of an app service should be located on an Azure file share. The storage account information for the file share must be provided before any publishing activity. 

 How to Fix 

 Resource: azurerm_app_service 

 Arguments: storage_account.type [source,go] 

 resource "azurerm_app_service" "example" { ... 

 storage_account { name = "test_name" 

 type = "AzureFiles" ... } }
