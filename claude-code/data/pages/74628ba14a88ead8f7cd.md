 View the Query Log 

 View previously executed scheduled queries for Device Security and download their
 results from the Query Log.

 Where Can I Use This? What Do I Need? 

 Device Security (Managed by Strata Cloud Manager) 

 One of the following subscriptions: 

 Device Security subscription

 Precision AI bundle subscription

 Device Security X subscription

 When scheduled queries run, the results of the queries appear in the Query Log. From 
 the Query Log, you can view previously executed queries and download the results. 
 Each query run has the date and time of the run appended to the name, so that you 
 can identify individual query runs for the same scheduled query.

 View the Query Results 

 Navigate to Queries Query Log and find the query run that you want to view.

 In the Actions column, select 
 Three-dots menu Download to download the query run results as a .zip file.

 The log may be split into multiple CSV files if there are a lot of 
 results.

 Open the downloaded zip file to find and view the CSV files of the 
 query log.

 View the Executed Query 

 Scheduled queries can have their matching criteria updated without changing 
 the query name or the schedule. Viewing the executed query shows you what 
 matching criteria was used for each run of the query.

 Navigate to Queries Query Log and find the query run that you want to view.

 Select the query run's name to open up the executed query in a side-panel.

 The side-panel displays a non-editable view of the Query Builder, 
 pre-filled with the matching criteria used for that query run.
