 Task 8. Verify you can log into Cortex XSOAR 

 Verify access to Cortex XSOAR 8.9 On-prem. 

 After the installation tasks run, an Installation completed message displays in the textual UI. However, you need to wait until the installation process fully completes (approximately 30 minutes) and then check that you can log in to Cortex XSOAR. You then need to upload your license to enable all Cortex XSOAR pages. 

 Log in to Cortex XSOAR. 

 When you log in for the first time, use the Admin password and email you set during installation. 

 Upload your license to Cortex XSOAR. 

 For more information, see Add the Cortex XSOAR license .
