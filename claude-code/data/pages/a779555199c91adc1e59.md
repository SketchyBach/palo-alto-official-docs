 debug bounce interface 

 Use the debug bounce interface command
to disable an interface for five seconds and to re-enable it. Useful
to force DHCP resynchronization or link speed renegotiation. 

 Command 

 debug bounce interface = interface number 

 Options 

 None 

 Command Notes 

 Role Super 

 Related Commands — 

 Introduced in Release 4.5.1 

 Example 

 debug bounce 1
