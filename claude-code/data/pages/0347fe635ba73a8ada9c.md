Activate AES module on the Cortex agent

If your organization have XDR license, you can activate Agentic Endpoint Security (AES) directly from the XDR portal for macOS and Windows endpoints. 

Before you start

Make sure you have purchased AES license

How to activate AES module

The AES deployment portal includes a full step-by-step guide for activating the AES module.

Step 1 - Create or edit an agent settings profile

Go to Inventory → Endpoints → Policy management → Prevention → Profile.

Select Add profile → Create new, or right-click an existing profile to edit it.

Choose the OS (Windows or macOS), then open Agent settings.

Go to Agentic Endpoint Security (AES) and set the AES run-mode to XDR + AES - for customers with an XDR license. Runs AES alongside your existing XDR protection.

Repeat for both Windows and macOS profiles.

Step 2 - Apply the profile with a policy rule

Go to Inventory → Endpoints → Policy management → Prevention → Policy rules.

Right-click a policy rule to edit it and set Agent settings to your new profile, or create a new policy rule.

Repeat for both macOS and Windows, and scope the rule to the endpoints in your deployment.

New to Cortex?

If you don't have agents deployed yet, follow Steps 1-2 above, then create an installation package: go to the Installation page, select New, download the package, and distribute it with your MDM, learn more here.
