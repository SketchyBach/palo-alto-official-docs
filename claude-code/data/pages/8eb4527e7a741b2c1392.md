 Or any of the following licenses that include the SaaS Security Inline license: 

 CASB-X 

 CASB-PA 

 The availability of a growing number of SaaS applications creates a problem known as
 shadow IT. Lack of visibility into SaaS app usage prevents security teams like yours
 from having control over employees’ use and abuse of unsanctioned SaaS apps,
 introducing security risks to your organization, including data leakage, malware
 entry, and non-compliance. 

 SaaS Security Inline is a
 security service that offers advanced risk scoring, analytics, reporting, and
 Security policy rule authoring so that your organization has the SaaS visibility and
 security controls to prevent data security risks of unsanctioned SaaS app usage on
 your network. 

 SaaS Security Inline includes SaaS visibility and advanced analytics to help you understand
 cloud-based threats and provides SaaS policy rule recommendation authoring to
 protect against those threats by blocking traffic for unsanctioned SaaS apps and
 risky user activity. 

 SaaS Security Inline offers the following capabilities : 

 SaaS visibility 

 SaaS policy rule recommendation authoring with policy enforcement
(policy synchronization) 

 ACE (App‑ID Cloud Engine)
