# View cloud service entitlements

Skip To Main Content
Our Products
View cloud service entitlements

This section describes how to evaluate and address security risks posed by cloud identities identified during scans of the cloud environments that are connected to Idira.

To view entitlements:

Sign in to the Manage space.

Prerequisite: Make sure that a discovery scan has run as close as possible to when you start remediation. For details, see Discover cloud service entitlements.

In the left pane, select Inventory > Means of access > Cloud service entitlements.

This page displays all the cloud identities from your cloud environment that have standing cloud entitlements, tagged with risk severity.

For each identity, the following details are displayed:

The type of identity (user or group)

The cloud entity where the identity was discovered

The number of roles that the identity is directly associated with

These indicators show risky access that should be remediated:

Privileged - The identity has administrative permissions

Sensitive permissions - The identity is allowed to perform read and write operations on critical cloud services or elevate its own permissions.

The date the risk was first detected

Search for an identity to analyze using the filter and search.

Searches are case-sensitive

If expected identities aren't listed, rerun the relevant discovery scan (see Discover cloud service entitlements).

Click an identity in the list to display more details:

An overview containing identity details

The identity's assigned roles and an indication of whether it has sensitive roles that pose a potential risk and should be migrated to ZSP

The identity's group memberships

Export the list of identities with standing access

To export the list of identities that have standing cloud access to a CSV file, in the top right corner of the Cloud service entitlements page, click Export to CSV.
