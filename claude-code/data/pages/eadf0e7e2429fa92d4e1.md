Kandji Guide

This document provides step-by-step instructions on integrating Koi into your environment with Kandji.

Configuration Guide

Prerequisites

Access to the Kandji management dashboard.

The configuration script provided by Koi.

Internet access from managed devices.

Integrations Steps

Log in to Kandji's admin dashboard

In the sidebar, navigate to LIBRARY

In the top right corner, click the Add Library Item button

Search for the Custom Scripts component. Select it, then click Add and configure at the bottom right.

Configuring the library

Add title to the component (eg: Koi Security)

In the Execution Frequency section, select Run every 15 minutes

inside Script Details -> Audit Script, paste the Koi MDM script provided to you

Press Save on the bottom right

Add the recent created library you created, into a Blueprint in order to apply the MDM script to the devices
