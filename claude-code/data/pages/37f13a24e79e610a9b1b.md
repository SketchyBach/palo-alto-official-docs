 Context data 

 Use Cortex XSIAM context data to support investigation and remediation workflows. 

 Context data is a map (dictionary) that stores structured data related to an issue, including issue fields and automations data. You can use context data to pass information between playbook tasks and to create scripts that map data to case and issue fields.
