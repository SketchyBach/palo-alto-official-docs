 Autonomous Digital Experience Management (ADEM) is a service that provides native, end-to-end visibility and
 performance metrics for real application traffic in your Secure Access Service Edge
 (SASE) environment. ADEM continuously monitors every segment in the service delivery
 path and provides insights that help you quickly isolate the segment which is causing
 digital experience problems and simplify remediation. 

 ADEM for China leverages the Strata Cloud Manager user interface to enhance usability
 and provide a consistent experience, while following all regulations and mandates. All
 features are supported with ADEM agent hosted in China, except for the following
 functionality. The table shows you the support for ADEM features and add-ons; a check
 mark (√) indicates that it's supported and dash (—) indicates that it's not
