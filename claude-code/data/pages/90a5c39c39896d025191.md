 runPlaybook 

 runPlaybook 

 Runs an automation playbook on the specified issues, executing its configured tasks against each issue. The playbook argument accepts either a playbook name or a playbook ID. 

 Arguments 
 Arguments 

 Argument Name 

 Description 

 Required 

 playbook 

 The playbook name or ID to execute. 

 Required 

 issue_ids 

 A comma-separated list of issue IDs on which to execute the playbook. 

 Required 

 Outputs 

 There are no outputs for this command.
