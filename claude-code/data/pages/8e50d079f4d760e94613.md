 Google Workspace Automation and Collection 

 Use Google Workspace Automation and Collection data for Cortex AgentiX. 

 Important 

 This connector is only available for tenants that onboarded after July 26, 2026. For tenants that onboarded before this date, use Marketplace to access the standalone integration. For more information, see Marketplace . 

 Automate and collect across Google Workspace: manage users, groups, roles, and devices in the Admin console; fetch security alerts and audit logs; send and process Gmail messages; work with Calendar, Docs, and Sheets; and support archiving and eDiscovery with Google Vault. 

 This connector includes the following sub-capabilities (Marketplace integrations link to PAN DEV for more information): 

 G Suite Security Alert Center : This connector is available with any active Cortex XSIAM or Cortex AgentiX license. 

 Gmail : This connector is available with any active Cortex XSIAM, Cortex Cloud Posture Security, Cortex Cloud Runtime Security, Cortex XDR, or Cortex AgentiX license. 

 Gmail Single User : This connector is available with any active Cortex XSIAM, Cortex Cloud Posture Security, Cortex Cloud Runtime Security, Cortex XDR, or Cortex AgentiX license. 

 GoogleCalendar : This connector is available with any active Cortex XSIAM or Cortex AgentiX license. 

 GoogleDocs : This connector is available with any active Cortex XSIAM or Cortex AgentiX license. 

 GoogleDrive : This connector is available with any active Cortex XSIAM or Cortex AgentiX license. 

 GoogleSheets : This connector is available with any active Cortex XSIAM, Cortex Cloud Posture Security, or Cortex AgentiX license. 

 google-vault : This connector is available with any active Cortex XSIAM or Cortex AgentiX license. 

 GSuiteAdmin : This connector is available with any active Cortex XSIAM, Cortex Cloud, Cortex Cloud Runtime Security, Cortex XDR, or Cortex AgentiX license. 

 GSuiteAuditor : This connector is available with any active Cortex XSIAM or Cortex AgentiX license. 

 To configure this connector, follow the steps outlined in the configuration wizard.
