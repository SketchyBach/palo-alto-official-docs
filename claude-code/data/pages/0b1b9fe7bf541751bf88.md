 NGFW ZTNA Connector Integration 

 Automate secure application access to Prisma® Access using NGFW as ZTNA Connectors, simplifying setup, configuration, and
 management. 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Panorama) 

 Prisma Access (Managed by Strata Cloud Manager) 

 NGFW (Hardware and VM-Series) 

 PAN-OS 
 ® version 12.1.5 and later 

 Prisma Access version 6.1 and later 

 NGFW ZTNA Connector Integration leverages your
 Palo Alto Networks® NGFW s ( VM-Series and Hardware NGFW) as ZTNA Connectors. This provides secure,
 automated connectivity to private applications for Prisma
 Access users, supporting mobile, contractor, and branch users. You can
 manage NGFW Connectors using either Panorama or Strata Cloud Manager .
