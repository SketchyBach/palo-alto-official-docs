 Cloud NGFW for AWS Free Trial 

 Subscribe to the Cloud NGFW through AWS Marketplace for a free trial. 

 Where Can I Use This? What Do I Need? 

 Cloud NGFW for AWS 

 Cloud NGFW subscription 

 Palo Alto Networks Customer Support Account (CSP) 

 AWS Marketplace account 

 User role (either tenant or administrator) 

 Free Trial when you get started from AWS Marketplace 

 When you subscribe to the Cloud NGFW through AWS Marketplace, you're
 automatically enrolled for a free trial. Go to the Subscription Management page
 to validate that your Cloud NGFW tenant is linked to the AWS Marketplace Palo Alto
 Networks Cloud NGFW Pay-As-You-Go subscription listing and that your free trial
 is active with credits. 

 Free Trial when you get started from Strata Cloud Manager 

 When you deploy the first Cloud NGFW resource in the Strata Cloud Manager,
 you're automatically enrolled for a free trial. This flexibility allows you to explore
 all the features during a trial period before committing to billing immediately.
 However, you are expected to complete the AWS Marketplace Subscription before the end of
 the free trial period. 

 Free Trial Credits 

 To enable this free trial, the Cloud NGFW associates the free trial credits
 with your newly created tenant. These credits allow you to create up to two firewalls
 securing up to 100 GB of traffic and manage them natively or using Panorama or Strata
 Cloud Manager. These credits allow you to explore the full features during a trial
 period before committing to billing immediately. 

 Free Trial Expiry 

 The system expects you to complete the AWS Marketplace subscription before the
 Free trial ends. 

 When the free trial period ends, you begin paying for consumption. You can
 navigate to the Subscription Management page to validate that your Cloud NGFW
 tenant is still linked to the AWS Marketplace Palo Alto Networks Cloud NGFW
 Pay-As-You-Go subscription listing and that your free trial period is no longer
 active. 

 You cannot pause the free trial period. 

 At the end of your free trial period, you begin incurring charges
 when using the Cloud NGFW.
