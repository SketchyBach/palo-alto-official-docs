 CNGFW: URLs or IPs with EDLs approaching max limits on Resource 

 Incident Code 

 INC_CNGFW_URL_IP_EDL_USAGE 

 Severity 

 Warning 

 Category 

 Device 

 Subcategory 

 System Resources 

 Description 

 The number of URLs, IPs, or Domains within the configured EDL(s) used in policy on this firewall is approaching the maximum capacity that the firewall can support. 

 Raise Condition 

 When URLs or IPs with EDLs usage exceed 95% of the capacity of that respective Cloud NGFW Resource and stays beyond 95% for five days over a week 

 Clear Condition 

 When URLs or IPs with EDLs usage falls below 95% of the capacity of that respective Cloud NGFW Resource and stays below 95% for two weeks
