 List View Options 

 Export Results to File 

 If needed, you can export the page results for most pages in Cortex Xpanse to a tab-separated values (TSV) file. 

 (Optional) Filter page results to reduce the number of results for export. 

 Select export to file ( ). 

 Cortex Xpanse exports any results matching your applied filters in TSV format. The TSV format requires a tab separator, automatic detection does not work in the case of multi-event exports.
