 Alerts by name 

 Email marked as spam and bulk based on Spam Confidence Level and Bulk Complaint Level values 

 Synopsis 

 Field 

 Value 

 Activation Period 

 14 Days 

 Training Period 

 30 Days 

 Test Period 

 N/A (single event) 

 Deduplication Period 

 1 Day 

 Required Data 

 Microsoft 365 Emails 

 Detection Modules 

 Email 

 Detector Tags 

 Spam 

 ATT&CK Tactic 

 Reconnaissance (TA0043), Initial Access (TA0001) 

 ATT&CK Technique 

 Phishing for Information (T1598), Phishing (T1566) 

 Severity 

 Informational 

 Description 

 The Spam Confidence Level (SCL) and Bulk Complaint Level (BCL) values, detected in the email's antispam headers, indicate that a message is more likely to be spam. 

 Attacker's Goals 

 Achieve financial gain, distribute malware, or phish for sensitive information through mass unsolicited emails. 

 Investigative actions 

 Examine email headers to trace origins and check for signs of spoofing. 

 Analyze the email content for spam indicators like suspicious links and aggressive marketing language. 

 Monitor further actions taken, such as file downloads or access to potentially malicious links.
