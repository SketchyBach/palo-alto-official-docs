 Cortex XSOAR 8 (SaaS) 

 Scripts 

 Create and manage Cortex XSOAR 8 SaaS scripts. 

 Scripts perform specific automated actions using commands that are used in playbook tasks and in the War Room. 

 On the Scripts page, you can view, edit, and create scripts in JavaScript, Python, or PowerShell. When creating a script, you can access all Cortex XSOAR APIs, including access to alerts, and investigations, and share data to the War Room. Scripts can receive and access arguments and can be password protected.
