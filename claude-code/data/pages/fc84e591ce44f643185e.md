 Cortex Cloud Posture 

 M365 Automation and Collection 

 Use M365 Automation and Collection data for Cortex Cloud. 

 Important 

 This connector is only available for tenants that onboarded after July 26, 2026. For tenants that onboarded before this date, use Marketplace to access the standalone integration. For more information, see Marketplace . 

 Automate and collect across Microsoft 365 and Office 365 services. 

 This connector includes the following sub-capabilities (Marketplace integrations link to PAN DEV for more information): 

 EWS Extension Online Powershell v3 : This connector is available with any active Cortex XSIAM, Cortex Cloud Posture Security, Cortex Cloud, Cortex Cloud Runtime Security, Cortex XDR, or Cortex AgentiX license. 

 EWS v2 : Exchange Web Services and Office 365 (mail). This connector is available with any active Cortex XSIAM, Cortex Cloud Posture Security, Cortex Cloud, Cortex Cloud Runtime Security, Cortex XDR, or Cortex AgentiX license. 

 EWSO365 : The new EWS O365 integration uses OAuth 2.0 protocol and can be used with Exchange Online and Office 365 (mail). This connector is available with any active Cortex XSIAM, Cortex Cloud Posture Security, Cortex Cloud, Cortex Cloud Runtime Security, Cortex XDR, or Cortex AgentiX license. 

 Microsoft Graph Calendar : O365 Outlook Calendar enables you to create and manage different calendars and events according to your requirements. This connector is available with any active Cortex XSIAM, Cortex Cloud, Cortex Cloud Runtime Security, Cortex XDR, or Cortex AgentiX license. 

 Microsoft Graph Mail Single User : This connector is available with any active Cortex XSIAM, Cortex Cloud, Cortex Cloud Runtime Security, Cortex XDR, or Cortex AgentiX license. 

 Microsoft Management Activity API (O365 Azure Events) : This connector is available with any active Cortex XSIAM, Cortex Cloud Posture Security, or Cortex AgentiX license. 

 Microsoft Teams : Send messages and notifications to your team members. This connector is available with any active Cortex XSIAM, Cortex Cloud Posture Security, Cortex Cloud, Cortex Cloud Runtime Security, Cortex XDR, or Cortex AgentiX license. 

 Microsoft Teams Management : Manage teams and members in Microsoft Teams. This connector is available with any active Cortex XSIAM, Cortex Cloud Posture Security, Cortex Cloud, Cortex Cloud Runtime Security, Cortex XDR, or Cortex AgentiX license. 

 Microsoft Teams via Webhook : This connector is available with any active Cortex XSIAM, Cortex Cloud Posture Security, Cortex Cloud, Cortex Cloud Runtime Security, Cortex XDR, or Cortex AgentiX license. 

 Microsoft_Graph_Files : Use the O365 File Management (Onedrive/Sharepoint/Teams) integration to enable your app to get authorized access to files in OneDrive, SharePoint, and MS Teams across your entire organization. This integration requires admin consent. This connector is available with any active Cortex XSIAM, Cortex Cloud, Cortex Cloud Runtime Security, Cortex XDR, or Cortex AgentiX license. 

 MicrosoftGraphMail : Microsoft Graph lets your app get authorized access to a user's Outlook mail data in a personal or organization account. This connector is available with any active Cortex XSIAM, Cortex Cloud, Cortex Cloud Runtime Security, Cortex XDR, or Cortex AgentiX license. 

 MicrosoftPolicyAndComplianceAuditLog : Use the integration to get logs from the O365 service. This connector is available with any active Cortex XSIAM, Cortex Cloud Posture Security, or Cortex AgentiX license. 

 To configure this connector, follow the steps outlined in the configuration wizard.
