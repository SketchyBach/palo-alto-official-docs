 dump priority-policy config policy-sets 

 Use the dump priority-policy config policy-sets command
to display the QoS policy sets configuration for a device. 

 Information
displayed includes the bandwidth allocation for business priorities
along with the bandwidth split per traffic in a priority. 

 Command 

 dump priority-policy config policy-sets all 

 Options 

 None 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands — 

 Introduced in Release 5.0.1
