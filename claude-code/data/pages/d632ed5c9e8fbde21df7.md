 Panorama > VMware NSX 

 To automate the provisioning of a VM-Series NSX edition
firewall, you must enable communication between the NSX Manager
and Panorama. When Panorama registers the VM-Series firewall as
a service on the NSX Manager, the NSX Manager has the configuration
settings required to provision one or more instances of the VM‑Series
firewalls on each ESXi host in the cluster.
