 Manage Focused Workflows with Strata Visions 

 Strata Visions 

 Strata™ Visions filters your Strata Cloud Manager UI with task-focused workflows,
 enhancing focus for different user workflows. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 To access and utilize Strata Visions, your Strata Cloud Manager 
 tenant must have at least one Strata Visions related product SKU
 provisioned. The visibility of specific Strata Visions and the items
 within them is determined by your entitlements (SKU) and Role-Based
 Access Control (RBAC) permissions. 

 Each of these licenses include access to Strata Cloud Manager : 

 Prisma® Access 

 AIOps for NGFW Premium 

 Strata Cloud Manager (Essentials or Pro) 

 Quantum Security Subscription 

 Next-Gen Trust Security (formerly CLM) 

 The features and capabilities available to you in Strata Cloud Manager depend on which license(s) you are using. 

 Strata Visions provides a tailored administrative experience that aligns the Strata Cloud
 Manager user interface with your immediate priorities. Using an intent-based model,
 Strata Cloud Manager displays the specific tools you need for your specific mission,
 whether it's Quantum Resilience or Next-Gen Trust Security (Certificate Lifecycle
 Management). This organization improves navigation and provides more focussed task
 management. For example, the workspace displays different toolsets for a Quantum Lead
 compared to a PKI administrator managing certificate lifecycles. 

 When you select a Vision, Strata Cloud Manager filters the navigation menu to show pages
 designed for that specific workflow. This view keeps your workspace clean and ensures
 that your most frequent tasks are easily accessible.

 As you expand your Palo Alto Networks ® deployment, Strata Visions integrates the new
 modules into these specific workflow views. 

 Launch Strata Visions 

 Log in to Strata Cloud Manager and access Strata Visions via the Strata Visions
 switcher located in the left navigation panel. 

 Strata Visions lists all visions available to you based on your licenses and user
 roles. 

 See Everything : For first-time access, Strata Cloud Manager 
 automatically sets a default vision based on your primary product. If no
 specific focus is determined, the view defaults to See
 Everything . 

 Switching views : Change your view by selecting a vision in the
 Strata Visions switcher. Strata Cloud Manager 
 automatically saves your selection and reloads that vision the next time you log in. 

 Strata Visions organizes workflows into three core administrative goals: Monitor,
 Investigate, and Configure. Your active product license determines which Strata
 Visions you can access in Strata Cloud Manager . The interface uses a split
 navigation structure to maintain context while reducing clutter. 

 Global Navigation : The L1 navigation bar remains consistent across all
 visions to provide a stable framework. The color-coded application header
 indicates your active security context. 

 Left Navigation : The left navigation menu automatically updates based on
 the active Strata Vision, hiding irrelevant items to present a task-focused
 view. Content is organized as follows: 
 Monitor : View high-level overviews, health indicators,
 connectivity status, and performance metrics to identify urgent tasks
 under Command Center ,
 Insights , and
 Reports . 

 Investigate : Analyze anomalies, hunt for threats, and review
 logs, events, and alerts to determine the root cause of incidents under
 Incidents and Log
 Viewer . 

 Configure : Perform proactive tasks such as creating security
 rules, managing device settings, customizing policies, and deploying
 configurations under Configuration and
 System Settings . 

 Supported Strata Visions 

 Quantum Resilience :
 The Quantum Resilience vision is accessible to tenants with a Quantum
 Security license. When selected, this vision filters the navigation to
 hide irrelevant tasks and sets the default landing page to Insights Quantum-safe Security . The Strata Cloud Manager user interface updates to a
 distinct visual theme to indicate the active focus. 

 Next-Gen Trust
 Security : The Next-Gen Trust Security (NGTS) vision is
 available to tenants with a Next-Gen Trust Security license. For
 standalone Next-Gen Trust Security tenants (provisioned only with NGTS
 and Telemetry instances), the Strata Cloud Manager defaults to the
 Next-Gen Trust Security vision. When selected, this vision filters the
 navigation to hide irrelevant tasks and sets the default landing page to Insights Certificate Insights 47-Day Readiness .
