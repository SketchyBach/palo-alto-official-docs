 Informational 

 Description 

 A cloud identity has disabled data encryption. 

 Attacker's Goals 

 An attacker is trying to access sensitive data in plaintext. 

 An attacker might try to exfiltrate plaintext data to an endpoint controlled by the attacker and avoid detection. 

 An attacker can re-encrypt the data with a key that is available only to the attacker. 

 Investigative actions 

 Check if the identity intended to disable data encryption. 

 Check which cloud assets were affected by manipulating the above-mentioned configuration file. 

 Check if the identity performed additional suspicious actions to affected assets.
