 Monitor and Troubleshoot Explicit Proxy ( Strata Cloud Manager ) 

 Monitor and troubleshoot your Prisma Access Explicit Proxy deployment. 

 Monitor Prisma Access Explicit Proxy deployment details to help you troubleshoot any
 issue. 

 Click Insights Activity Insights Users and select the Agentless Proxy
 Users connected method. 

 Select Insights Activity Insights Users and select the connection method as Agentless
 Proxy Users to view Mobile Users that connect to Prisma Access security services through Explicit Proxy on a web browser
 on their devices. 

 Select Insights Prisma Access Locations Explicit Proxy to see an overview of the health of all your Prisma Access locations for Explicit Proxy mobile users. 

 Check the traffic logs ( Incidents & Alerts > Log Viewer and
 select the log type Traffic ) and authentication logs
 ( Incidents & Alerts > Log Viewer and select the log type
 Authentication ) to troubleshoot authentication-related
 issues.
