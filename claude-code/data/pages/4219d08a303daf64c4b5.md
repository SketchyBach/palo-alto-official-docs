 Cortex XSOAR 6.13 Multi-Tenant 

 Configure the HTTP Request Timeout 

 In Cortex XSOAR 6.13, configure HTTP timeouts for multi-tenant accounts. 

 When you configure the HTTP timeout from the main account the timeout is applied to all tenant accounts. If you add the server configuration on tenants, it is ignored. 

 In the main account, go to Settings → ABOUT → Troubleshooting . 

 In the Server Configuration section click Add Server Configuration . 

 Key 

 Value 

 accounts.http.timeout 

 The amount of time after which the HTTP request times out (in seconds). The default value is 30.
