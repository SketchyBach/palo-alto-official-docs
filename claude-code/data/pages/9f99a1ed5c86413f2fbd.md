 Multi-Tenant for Enterprise 

 Cortex XSOAR 6.12 Hosted Service (EoL) is available for Multi-Tenant deployments for Enterprise. 

 Cortex XSOAR hosted multi-tenant deployments are designed for enterprises that require some data segregation, but also need the flexibility to share and manage critical security practices across accounts. For more information about multi-tenant deployments, see the Multi-tenant Guide. 

 Multi-tenant hosted accounts are only available for Enterprise, and are not available for MSSPs (managed security service providers). All of the standard service specifications for hosted service apply to multi-tenant accounts, but with the following limits: 

 No tenants can be created on the main account. 

 Only one tenant can be created per host, but there is no limit to the number of hosts.
