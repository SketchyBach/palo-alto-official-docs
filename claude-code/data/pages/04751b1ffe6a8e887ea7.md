 Firewall Traffic Disruption Detected 

 Incident Code 

 INC_NGFW_TRAFFIC_DISRUPTION 

 Severity 

 High 

 Category 

 Network and Traffic 

 Subcategory 

 Performance 

 Description 

 The firewall is experiencing a disruption in traffic forwarding.
 Throughput degradation, reduced packets received or sent may have
 been detected by anomaly detection. Investigation is required to
 identify and resolve the issue before broader connectivity impact
 occurs. 

 Raise Condition 

 If any one of the metric System Throughput, Packet Received, Packets
 sent usage drops to zero or below 30% from the anomaly baseline for
 2 hours. 

 Clear Condition 

 All metrics (System Throughput, Packet Received, Packets sent )
 return to normal baseline range for 8 consecutive hours.
