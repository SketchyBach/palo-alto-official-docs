 Connect the Prisma Agent to a Different Location 

 If needed, you can connect to a different Prisma Access location after you log in
 to the Prisma Agent . 

 Where Can I Use This? What Do I Need? 

 Prisma Agent 

 Minimum Prisma Agent version: 

 25.1 (macOS and Windows) 

 25.7 (Linux) 

 macOS, Windows, or Linux
 desktop devices 

 Check the prerequisites for the
 supported OS versions 

 Internet access 

 After you log in to the Prisma Agent , you’re automatically connected to
 the best available Prisma Access location. If you want to change locations, you
 can do so using the Location drop-down. Selecting a location
 pins it as your preferred gateway, and the agent reconnects to that location after
 network changes, sleep/wake cycles, reboots, and other external factors such as
 WebSocket connection issues and token expiry. If your device is located inside your organization’s
 network, the agent is connected automatically to an internal location (if your
 administrator enabled Internal Host Detection). If no internal location is available,
 the agent will use an external location. 

 Launch the Prisma Agent by clicking the Prisma Agent 
 icon 

 from the macOS menu bar, Windows
 taskbar, or Linux panel . 

 Select a different Location . You can
 Search for a location or choose a location from the
 list. 

 The list of available locations are sorted according to the best experience
 based on response time, availability, and other factors. The location that
 offers the best experience is listed as Best
 Location . 

 ( macOS and Windows
 only ) The selected location becomes your preferred gateway and is
 shown with a filled star icon ( 

 ) in the
 Location drop-down. The agent reconnects to
 this location after network changes, sleep/wake cycles, reboots, and other
 external factors such as WebSocket connection issues and token expiry. 

 If your administrator enabled On Demand mode for the Prisma Agent , click the lock icon to connect to the newly selected
 location. Otherwise, the Prisma Agent proceeds to change
 locations. 

 ( Optional ) ( macOS and Windows only ) To clear a preferred
 gateway and return to automatic selection, choose Best
 Location from the Location 
 drop-down.
