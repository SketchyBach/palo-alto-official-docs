 debug shutdown 

 Use the debug shutdown command to shutdown the device. Shutdown
 will stop all services on this device until either the external power is cycled or the
 power switch is manually pressed. 

 Command 

 debug shutdown 

 Options 

 None 

 Command Notes 

 Role Super 

 Related Commands — 

 Introduced in Release 4.4.1 

 Example 

 debug shutdown
Shutdown will stop all services on this box until either:
- external power is cycled
- the power switch is manually pressed
