 Description

 Fixed an issue on multi-dataplane platforms
where IPSec tunnels continuously flapped.

 Fixed an issue where the sysd process disconnected
from the pan_dha process after a high availability
(HA) failover or reboot.

 A fix was made to address CVE-2022-0028 .

 Fixed an issue where the firewall dropped

 Fixed an issue where the dataplane went
down, which caused an HA failover.
