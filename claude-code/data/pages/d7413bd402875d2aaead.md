 ATT&CK Tactic 

 Discovery (TA0007) 

 ATT&CK Technique 

 Account Discovery (T1087), Permission Groups Discovery (T1069) 

 Severity 

 Informational 

 Description 

 An identity performed multiple actions that were denied, which may indicate it is being misused. 

 Attacker's Goals 

 Execute various commands to explore the cloud environment. 

 Investigative actions 

 Check if the API calls were made by the identity. Check if there are additional calls executed by the identity.
