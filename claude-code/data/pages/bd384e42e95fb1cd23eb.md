 Approaching Max Capacity - Security Policies 

 Incident Code 

 INC_NGFW_CAPACITY_SECURITY_POLICIES 

 Severity 

 Warning 

 Category 

 Device 

 Subcategory 

 System Resources 

 Product 

 Supported on NGFWs and VM-Series firewalls. 

 Description 

 The number of security policy rules has been consistently high and is approaching the maximum capacity the firewall can support. 

 Raise Condition 

 This incident is triggered when Security Policies usage exceed 90% of the capacity of that respective firewall model and the number of available Security Policies is less than 1500 with both of these states persisting for five or more days in past seven days. 

 Clear Condition 

 This incident is cleared when Security Policies usage falls below 90% of the capacity of that respective firewall model and the number of available Security Policies is more than 1500 with both of these states persisting for two weeks
