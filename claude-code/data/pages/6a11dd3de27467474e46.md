 Prerequisites 

 Before you begin to onboard your Google Cloud Platform (GCP) environment to Cortex, ensure that: 

 Ensure you have the necessary permissions: 

 In Cortex, you must have a Cortex role with Data Sources - View & Edit permissions (to add/configure cloud accounts in Cortex). This role is included in the following built-in roles: Instance Administrator, Security Admin, and IT Admin. 

 In GCP, you must have an admin user with the required GCP permissions . 

 Enable the necessary APIs in the GCP project you are onboarding. 

 You identify and set your target project . 

 Decide on your resource naming convention. Throughout this manual onboarding process, you will need to choose your own names for service accounts, custom roles, and Pub/Sub topics. Use the Configuration values reference to keep track of the names as you will need to refer to them throughout the process.
