 Cortex AgentiX 

 CIRCL 

 Use CIRCL data for Cortex AgentiX. 

 Important 

 This connector is only available for tenants that onboarded after July 26, 2026. For tenants that onboarded before this date, use Marketplace to access the standalone integration. For more information, see Marketplace . 

 This connector is available with any active Cortex XSIAM or Cortex AgentiX license. 

 Use the CIRCL integration to research malware history for IPs, DNSs, and hostnames, and to query certificate history and details. It also searches for CVE information using circl.lu. 

 This connector includes the following sub-capabilities (Marketplace integrations link to PAN DEV for more information): 

 CIRCL : CIRCL Passive DNS is a database storing historical DNS records from various resources. CIRCL Passive SSL is a database storing historical X.509 certificates seen per IP address. The Passive SSL historical data is indexed per IP address. 

 CIRCL CVE Search : Searches for CVE information using circl.lu. 

 To configure this connector, follow the steps outlined in the configuration wizard.
