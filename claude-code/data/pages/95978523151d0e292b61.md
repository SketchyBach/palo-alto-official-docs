 AI Access Security Recommendations for Prisma Browser 

 Release Date: June 2025 
 | 
 Last Updated: May 2026 

 Navigating the complex landscape of GenAI app security presents many challenges, especially when understanding which GenAI apps are safe and appropriate for your organization. To help alleviate this challenge, AI Access Security now includes recommendations for Prisma Browser when you have a standalone Prisma Browser license to provide your security administrators comprehensive security insights directly within your browser environment. 

 As a Prisma Browser standalone security administrator, you will receive expert guidance on leveraging Prisma Access Browser to secure access to GenAI apps. AI Access Security tailors these recommendations to your specific environment, offering insights into potential risks, recommended controls, and best practices for GenAI app governance. The feature goes beyond simple alerts, providing strategic advice on managing GenAI app adoption, identifying potential security gaps, and implementing effective guardrails. 

 By delivering actionable, context-aware recommendations, AI Access Security empowers your organization to proactively manage GenAI app security risks. Your security administrators gain the ability to understand which GenAI applications are appropriate, recommendations for configuring appropriate access controls, and how to protect sensitive data across your browser-based GenAI app interactions. These recommendations are designed to help your security administrators make confident, informed decisions about GenAI app usage and to help address security gaps when using Prisma Browser .
