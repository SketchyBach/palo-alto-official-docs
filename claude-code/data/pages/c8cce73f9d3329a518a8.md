Inventory
List inventory items
GET
https://api.prod.koi.security
/api/external/v2/inventory

Retrieves a paginated list of items installed across your organization's endpoints. Supports filtering by marketplace, platform, risk level, publisher, name search, and view (predefined marketplace groups). All request and response fields use snake_case naming.
