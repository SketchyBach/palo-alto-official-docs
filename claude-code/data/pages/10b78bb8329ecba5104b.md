 Determine Your Tenant Version 

 Learn how to determine your Cloud NGFW for AWS tenant version. 

 Where Can I Use This? What Do I Need? 

 Cloud NGFW for AWS 

 Cloud NGFW subscription 

 Palo Alto Networks Customer Support Account (CSP) 

 AWS Marketplace account 

 User role (either tenant or administrator) 

 Tenant Information in Cloud NGFW console 

 If you have previously started from an AWS member account or AWS Firewall Manager account , you can
 access the Cloud NGFW console to view your tenant information. 

 To determine your tenant version: 

 Log into the Cloud NGFW console. 

 Select Settings . 

 Verify the Tenant Version . 

 If you have previously started from an AWS member account and created the
 Cloud NGFW tenant before Jul 30, 2025, the tenant information page will display
 the tenant version as V1. However, if you started from an AWS member account after Jul 30,
 2025, the tenant information page will display the tenant version as V2.
