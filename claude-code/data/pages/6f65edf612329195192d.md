 Additional Predefined Time Filters for the ACC, Monitoring,
and Reports 

 Filter the ACC, monitoring, and reports for the last
60 and 90 days using predefined filters. 

 Rather than create a custom timer filter,
administrators can now filter the ACC, view monitoring map data,
and generate reports for the last 60 or 90 days or calendar days
using new predefined time filters in PAN-OS 10.0. This enables improved
performance when querying data older than 30 days. 

 Filtering
the last 60 or 90 days displays data for the last 60 or 90 days
from when the you filtered or generated a report. Filtering the
last 60 or 90 calendar days filters data starting at the beginning
of the previous calendar day from when you filtered or generated
a report. 

 To filter data older than 30
days but newer than 60 days, use the Last 60 Days time
filter when viewing the ACC, monitoring maps, or generating reports.
To filter data older than 60 days but newer than 90 days, use the Last
90 Days time filter, instead. 

 Launch the firewall web interface . 

 Filter the ACC for the last 60
or 90 days. 

 Select Monitor App Scope and view the monitoring
data for the last 60 or 90 days. 

 Generate a report for the last 60 or 90 days. 

 Select Monitor PDF Reports and select a report
to generate. 

 Add a new report. 

 Configure the report so that the report captures all
data for the Time Period over the Last
60 Days or the Last 90 Days . 

 Click OK to save the report
or Run Now to generate the report. 

 Commit your changes.
