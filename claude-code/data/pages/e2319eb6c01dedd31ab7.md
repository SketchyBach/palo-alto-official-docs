# Unsafe Code Execution Instruction

Unsafe Code Execution Instruction

Severity

🟡 Medium (6)

Short Description

Flags AI extensions that instruct the agent to run dangerous shell operations such as rm, chmod, or curl piped into a shell.

Suggestion

Confirm the destructive operations are necessary and correctly scoped. Cleanup and uninstall components legitimately delete files; anything else asking the agent to delete recursively, rewrite permissions, or execute remotely fetched content should be removed.

Information

This is the instruction form of Unsafe Code Execution: a skill, command, subagent, or rule tells the agent to run destructive or irreversible shell operations.

The severity is lower than the executable variant because a confirmation prompt normally stands between the instruction and the command. That mitigation is genuine but thin: a destructive command approved by reflex does exactly as much damage as one that ran unattended.

Some components legitimately belong here — cleanup utilities, uninstall commands, and build-artifact removal all delete files by design, and the evidence shows the specific operations and targets that separate a scoped cleanup from an unbounded deletion. The critical check is whether the component also carries Safety Instruction Override: that combination is an attempt to run destructive commands without the confirmation step, and should be treated at the severity of the executable variant.

Risks

Data loss on approval: A destructive command approved without close reading is as damaging as one that ran unattended.

Prompt fatigue: Long agent sessions condition users to approve without evaluating each command.

Escalation with safety override: Paired with an override finding, the confirmation step can no longer be relied on.

Broad targets: Instructions phrased generally can resolve to a much wider scope than intended at execution time.

Recommended Actions

Investigate the component

Read the evidence to see the operations and their targets, and judge whether the scope is bounded.

Check for a co-occurring Safety Instruction Override finding.

Confirm that destructive behavior matches the component's stated purpose.

Contain and remediate

Keep confirmation prompts enabled for destructive command families.

Restrict the agent's permission allowlist so these operations always prompt.

Remove the component if the operations are unnecessary, unbounded, or paired with a safety-override finding.
