 set deviceconfig system panorama local-panorama panorama-server-2 

 Description 

 Configure the backup
Panorama server for managing the WildFire appliance or appliance
cluster. Configuring a backup Panorama server provides high availability
for cluster or individual appliance management. 

 Hierarchy Location 

 set deviceconfig system panorama local-panorama 

 Syntax 

 panorama-server-2 {IP address | FQDN}; 

 Options 

 + panorama-server-2 —
Configure the IP address or the fully qualified domain name (FQDN)
of the backup Panorama server you will use to manage the WildFire
appliance or appliance cluster. 

 Sample Output 

 The output is truncated
to show only the output stanza that displays the Panorama server
settings.
