 dig6 

 Use the dig6 command to display domain information groper (Dig)
 for querying domain name system (DNS) servers. It helps troubleshoot DNS problems along
 with displaying answers from the queried name servers. 

 Command 

 dig6
 <interface> 
 <server address> 
 <hostname> 

 Options 

 None 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands — 

 Introduced in Release 6.2.1 

 Example 

 dig6 3 2702::abcc host1.nyc3.example.com
