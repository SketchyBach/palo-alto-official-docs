 Release Notes 

 Release notes for Cortex XDR app 7.1 for Android releases. 

 New features, known issues, and addressed issues in Cortex XDR app 7.1 releases for Android are described below. 

 Features Introduced in Cortex XDR App 7.1 

 No new features were introduced in the 7.1 releases. 

 Known and Addressed Issues in Cortex XDR App 7.1 

 This table lists all known and addressed issues in all the Cortex XDR App 7.1 releases. 

 Issues 

 Description 

 CPATR-13990 

 This issue is resolved in Cortex XDR agent 7.1.3 release. 

 Fixed Cortex XDR Agent sending the same security alert twice. 

 CPATR-14744 

 This issue is resolved in Cortex XDR agent 7.1.3 release. 

 Fixed Cortex XDR Agent ignoring multiple hashes based on allow and block lists. 

 CPATR-13180 

 This issue is resolved in Cortex XDR agent 7.1.2 release. 

 On devices running Android 10 or later, the Cortex XDR app suddenly halted while scanning apps with internal archives. 

 CPATR-12831 

 This issue is resolved in Cortex XDR agent 7.1.1 release. 

 Sometimes, before the endpoint connects to Wi-Fi, the Cortex XDR agent reports the IP address of 0.0.0.0 or 127.0.01 to Cortex XDR instead of to the actual endpoint IP address. 

 CPATR-12549 

 This issue is resolved in Cortex XDR agent 7.1.1 release. 

 The Cortex XDR agent wrongly reports Administrative Hash Exception alerts for hashes that are not on the Block List. 

 CPATR-12548 

 This issue is resolved in Cortex XDR agent 7.1.1 release. 

 Sometimes endpoint scans initiated from Cortex XDR remain In Progress status and are not completed. 

 CPATR-12147 

 This issue is resolved in Cortex XDR agent 7.1.1 release. 

 The Cortex XDR app does not report the user name in security events. 

 Suggested workaround: Using the host name in the incident, go to Endpoints Management and locate the user associated with this endpoint.
