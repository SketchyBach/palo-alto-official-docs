 inspect qos-bwc queue-history 

 Use the inspect qos-bwc queue-history command
to inspect details of the QoS bandwidth queue history information. 

 Command 

 inspect qos-bwc queue-history [ latest ]

 Options 

 history Enter the history to inspect QoS queue activity
records for up to the last 5 minutes. 

 latest Enter the history with latest to inspect QoS
queue activity records for just the last 1 minute. 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands 

 dump qos-bwc config 

 Introduced in Release 6.0.1
