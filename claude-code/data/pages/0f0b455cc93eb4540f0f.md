 Hosted Service Overview 

 Cortex XSOAR 6.12 Hosted Service (EoL) enables you to use Cortex XSOAR without the infrastructure required for an on-premise deployment. 

 Cortex XSOAR hosted service is EOL. 

 The Cortex XSOAR hosted service enables you to use Cortex XSOAR for security orchestration, incident management, and investigation, without the infrastructure required for an on-premise deployment. Palo Alto Networks provides the service infrastructure layer, and you manage only the Cortex XSOAR application.
