 Monitor 
 Prisma SD-WAN Incidents Through the Strata Multitenant Cloud Manager 

 Learn how to monitor security alerts in the Strata Multitenant Cloud Manager . 

 Where Can I Use This? What Do I Need? 

 Strata Multitenant Cloud Manager 

 Prisma SD-WAN license or SASE bundle license 

 Identity & Access
 role : Multitenant Superuser or Superuser 

 If you activate a SASE license or a Prisma SD-WAN license for your tenant, you can monitor open

 incidents for devices across all your
 tenants. To view this information, access the 
 and select 
 Incidents Prisma SD-WAN Incidents . Prisma SD-WAN Incidents replaces
 the Network Alarms page. 

 Incidents are displayed based on priority.
 You can narrow down the results by Tenant or by 
 Incident Priority . 

 The 
 Tenant Incident Metrics widget
 displays the total open 
 incidents and 
 incidents based on priority for individual
 tenants. 

 You can filter 
 incidents based on priority. For example,
 when you click the count for 
 Tenant with P2 Incidents , the

 Tenant Incident Metrics widget
 sorts tenants based on the number of open P2 
 incidents . The default sorting is based on
 P1 
 incidents . 

 (Optional) Click a Tenant name or an 
 Incident to view details of the 
 incident for the tenant.
