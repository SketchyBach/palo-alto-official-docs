 You can manually submit files and URLs for WildFire analysis through the Advanced WildFire dashboard in Strata Cloud Manager or through the legacy WildFire portal . Palo Alto Networks recommends using Strata Cloud Manager for all manual sample submissions, as the WildFire portal is being deprecated. All Palo Alto Networks customers with a support account can manually submit up to five samples a day for analysis. If you have an Advanced WildFire or WildFire subscription, you can manually submit samples as part of your 1000 sample uploads daily limit; however, keep in mind that the 1000 sample daily limit also includes WildFire API submissions. 

 To upload samples through Strata Cloud Manager, you must first create a WildFire
 API token or migrate an existing API key to token-based authentication. 

 Manually upload files or URLs to the Advanced WildFire cloud for
 analysis. 

 Log in to the Strata Cloud Manager on the hub . 

 Click Strata Cloud Manager Insights Advanced WildFire to get started. 

 Click Upload Sample located on the upper-right
 of the dashboard. 

 To submit files for analysis, select
 File and
 Browse through your local file
 system and select the file you want to submit for
 analysis. 

 To submit a URL for analysis, click
 URL , enter a URL, and
 Upload for analysis. 

 Upon a successful file or URL submission, you will receive a
 confirmation message along with the file or URL name. 

 You can close the Submit Sample dialog or upload
 another URL or file. 

 View the verdict and analysis results for the file. 

 Please wait at least five minutes for Advanced WildFire to analyze the
 sample. 

 Because a manual upload is not associated with a specific firewall,
 manual uploads do not show session information in the reports. 

 Click Strata Cloud Manager Insights Advanced WildFire to return to the Advanced WildFire dashboard. 

 Scroll down to the Recent Submissions 
 widget. 

 Refer to the File Name or URL as well as the
 File Type references to find the sample
 submission. For additional details, you can Search for
 details from the Actions column. 

 The upload source for the URL or file that was manually submitted
 is the Strata Cloud Manager tenant from which you performed the
 upload action.
