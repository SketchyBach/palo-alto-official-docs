 Microsoft Teams Web Support in Prisma Browser 

 The Microsoft Teams web app is supported in Prisma Browser mobile on tablets only. It
 is not supported on smartphones. 

 Where Can I Use This? What Do I Need? 

 The Microsoft Teams web app ( teams.microsoft.com ) is not
 supported in Prisma Browser on smartphones. Microsoft does not support Teams for
 Web on mobile browsers. On smartphones, use the native Microsoft Teams app
 instead. 

 Prisma Browser mobile supports the Teams web app on tablets only. 

 Details 

 Microsoft states that Teams for Web is not supported on mobile browsers. For the full
 client requirements, see System requirements for the Teams client 
 in the Microsoft Teams documentation. 

 Because this is a limitation of the Teams web client rather than of Prisma Browser,
 opening Teams in Prisma Browser on a smartphone is subject to the same constraint.
 Use the native Microsoft Teams app on smartphones.
