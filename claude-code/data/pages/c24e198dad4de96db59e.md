 Remove Tags from Assets 

 Remove tags from one or more assets. 

 Perform these steps to remove an Asset Tag (AT) or IP Range Tag (IPR) from an asset. The tag will also be removed from associated services, alerts, and incidents. 

 Navigate to Inventory and select the appropriate asset list view page. 

 Select one or more rows in the asset list. 

 Check the check box in the far left column of the heading row to select all the rows in the list. 

 Right click and select Remove Asset Tags or Remove IP Range Tags . 

 Click the X for each tag you want to remove. 

 Click Save .
