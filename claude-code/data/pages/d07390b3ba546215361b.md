 Navigate the CLI 

 CLI commands are organized in a hierarchical structure.
To display a segment of the current hierarchy, use the show command.
Entering show displays the complete hierarchy,
while entering show with keywords displays
a segment of the hierarchy. 

 For example, the following command displays the configuration
hierarchy for the Ethernet interface segment of the hierarchy: 

 username@hostname>
 configure 
 Entering configuration mode
 [edit]
 username@hostname#
 show network interface ethernet

   ethernet1/1 {
     virtual-wire;
   }
   ethernet1/2 {
       virtual-wire;
   }
   ethernet1/3 {
     layer2 {
       units {
         ethernet1/3.1;
       }
     }
   }
   ethernet1/4;
 }
