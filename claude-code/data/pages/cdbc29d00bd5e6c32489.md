 Integrate Device Security with SentinelOne Singularity Endpoint

 Integrate SentinelOne Singularity Endpoint with Device Security 
 to gain comprehensive visibility and centralized management of all devices.

 Integrate SentinelOne Singularity Endpoint with 
 Palo Alto Networks Device Security to gain comprehensive visibility and 
 centralized management of all devices across your environment. This integration 
 addresses the challenge of fragmented device visibility by consolidating endpoint 
 data from SentinelOne into Device Security . You can also import open 
 vulnerabilities from SentinelOne . With the unified view of network devices 
 and vulnerabilities, the integration helps you to make informed security decisions 
 quicker.

 The integration imports detailed device information from SentinelOne 
 endpoints, such as operating systems, hardware information, network interfaces 
 and installed software. Through the integration, Device Security can also 
 learn XDR information from SentinelOne , such as: active directory (AD) 
 data, agent status and configuration, SBOM, scan data, and vulnerability 
 information. The vulnerabilities include CVE details, severity ratings, and 
 detection dates.

 Combining SentinelOne Singularity Endpoint's detection 
 capabilities with Device Security 's device management capabilities, provides 
 greater risk assessment capabilities for your network infrastructure. You can 
 track device inventories and applications, monitor vulnerability statues, and 
 maintain current device information across your infrastructure.

 The integration requires SentinelOne 's console with API access and 
 configured authentication tokens, supporting both on-premises and cloud 
 deployments. You can configure what information you want to import, from the 
 type of information to how far back in time Device Security should poll 
 SentinelOne for information.

 For a full list of attributes that Device Security can learn through the
 integration, see
 SentinelOne Attribute Reference .

 Integrating with SentinelOne Singularity Endpoint
 requires either a 

 full-featured Cortex XSOAR™ server

 or the 

 activation

 of a Device Security free 

 cohosted Cortex XSOAR instance
