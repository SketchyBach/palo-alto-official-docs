 Manage an investigation 

 Close an investigation 

 Close an investigation and manage its 24-hour grace period. 

 Close an investigation when it is resolved or no longer needed. 

 Closing starts a 24-hour grace period. Collections are deleted after that period. You can cancel the close request before deletion. 

 In the Forensic Investigations table, right-click the investigation. 

 Select Close . 

 In Close Investigation , review the investigation's exported evidence collections. 

 The investigation status changes to Close Pending . The timestamp shows when the investigation expires and data is deleted. 

 While closure is pending, right-click the investigation to select one of these actions: 

 Edit — Update the name, description, or user permissions. 

 Open — Cancel the close request. 

 Permanently delete — Delete the investigation and associated data immediately. This action cannot be canceled.
