 Integrate Device Security with SoftPro Medusa 

 Integrate Device Security with SoftPro Medical Solutions Medusa to improve device
 management and security operations in healthcare organizations.

 Integrating Device Security with SoftPro Medical Solutions Medusa
 ( SoftPro Medusa ) provides healthcare organizations a more comprehensive way
 to improve device management and security operations. This integration synchronizes
 assets between SoftPro Medusa and Device Security , aids decision-making
 for device lifecycle management, and improves security posture.

 You can enrich device data and streamline security workflows between the platforms.
 This integration provides a bidirectional workflow for matching devices and sending
 device attributes between SoftPro Medusa and Device Security .
 Additionally, you can send alerts and vulnerabilities information from
 Device Security to SoftPro Medusa for triaging and workflow management.

 Device Security imports medical device information from SoftPro Medusa ,
 such as location, maintenance history, and financial data, to supplement the
 Device Security assets inventory. In turn, SoftPro Medusa receives device
 information for assets in its database, as well as security context from
 Device Security , such as risk scores, vulnerability data, and network information.
 You can perform device searches in SoftPro Medusa , using MAC addresses, to
 get real-time device data from Device Security .

 Device Security learns these attributes from SoftPro Medusa : 

 Equipment ID and number 

 Serial number 

 Operational status 

 Brand 

 Model 

 Location 

 Owner 

 Room or lab 

 Purchase price 

 Replacement cost 

 Warranty 

 Maintenance schedules 

 End-of-life, end-of-service, and end-of-sale dates 

 Risk and risk level 

 Mission-critical status 

 Installed software 

 In addition to sending device details, the integration enables you to send security
 alerts and vulnerabilities to SoftPro Medusa 's ticketing system for
 remediation. From the Device Security portal, you can send tickets for alerts and
 vulnerabilities on the Device Details page or on the Alerts pages.

 For a full list of attributes that Device Security can learn through the
 integration, see
 SoftPro Medusa Attribute Reference .

 Integrating with SoftPro Medusa requires either a
 full-featured Cortex XSOAR™ server 
 or the
 activation of a Device Security 
 free
 cohosted Cortex XSOAR instance .
