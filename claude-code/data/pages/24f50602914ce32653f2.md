 Generate Reports 

 Download a report as a PDF, share it with colleagues by email, or schedule recurring
 delivery—available for any pre-defined template or custom report on the Reports
 page. 

 From the Reports page you can download any report as a PDF,
 share it by email with specific recipients, or set up recurring scheduled delivery.
 All three actions are available for both
 pre-defined report templates and for reports you build in Custom Reports . 

 Before distributing a report you can give it a custom name and description, apply
 data filters to scope the content, and—for share and schedule actions—add recipients
 and an optional personal message. For custom reports, a PDF preview is shown in the
 modal so you can confirm the layout before generating. 

 Select Strata Canvas Reports from the Strata Cloud Manager navigation menu. 

 Locate the report in the Pre-defined Reports 
 or Custom Reports 
 section , open the Generate Report dropdown and
 select Download , Share , or
 Schedule . 

 If the report is not visible in the default view, click View
 All in the respective section to open a searchable, filterable
 full-catalog page. 

 For pre-defined reports, the dialog opens with the configuration options. 

 For custom reports, the dialog opens with a PDF preview of the report on the
 left and the configuration options on the right. 

 In the Report Information section, enter a
 Report Name and, optionally, a
 Description . 

 In the Check Filters for Report Content section, review
 and adjust the data filters applied to the report. 

 Click Add Filter to add a new filter
 criterion. 

 Click Reset to return all filters to their
 default values. 

 Available filter options vary by report type. The current time range is shown
 as a filter and can be adjusted using its dropdown. 

 For Share or Schedule ,
 complete the Email to section: 

 In the Add Recipients field, type a name or
 email address and press Enter to add each
 recipient. Repeat for additional recipients. 

 Optionally, enter a note of up to 200 characters in the
 Message (optional) field to include
 additional context in the email body. 

 For Schedule , configure the delivery schedule in the
 Schedule section: 

 Frequency Configuration options 

 Daily Delivers the report every 24 hours at the time you
 specify in the Send by 
 field. 

 Weekly Select one or more days of the week (Sun–Sat) in
 Send by , and then select the
 delivery time. 

 Monthly Select a specific day of the month (1–31) in
 Send by , and then select the
 delivery time. 

 For Time Zone , select
 the time zone for report delivery. 

 For Start Date , select the date to begin
 scheduled delivery. Defaults to the current date. 

 For End Date , select
 the date to stop the scheduled delivery. 

 The report is delivered within 15 minutes of the
 scheduled time. Daylight Saving Time changes do not automatically update
 your report schedule and may affect the delivery time. 

 Click Download , Share , or
 Schedule to complete the action. 

 ( Optional ) To view and manage report activity, scroll to the
 Activity section at the bottom of the Reports
 page. 

 Select Scheduled Reports to view and manage
 all active schedules. Click the edit icon to modify the schedule or
 the delete icon to remove it. 

 Select History to view the list of reports
 generated in the past 90 days.
