 Upgrade the Enterprise DLP Plugin 

 Upgrade the Enterprise Data Loss Prevention (E-DLP) on your Panorama® management server . 

 Upgrade the Enterprise Data Loss Prevention (E-DLP) plugin version installed on your Panorama® management server . 

 See the Palo Alto Networks 
 Panorama plugin Compatibility Matrix and review the
 minimum PAN-OS version required for your target Enterprise DLP 
 plugin version. 

 Log in to the Panorama web
 interface. 

 Upgrade the Enterprise DLP plugin version on Panorama . 
 For Panorama in a high availability (HA) configuration, repeat this
 step on the Panorama HA peer. 

 Select Panorama Plugins and Check Now for the latest
 dlp plugin verison. 

 Download and Install the
 latest version of the Enterprise DLP plugin. 

 After the new plugin version successfully installs, view the Panorama 
 Dashboard and verify in the General Information
 widget that the Plugin DLP version displays
 the Enterprise DLP plugin version you upgraded to. 

 ( Upgrade to 4.0.0 only ) Edit 
 Enterprise DLP data filtering settings to reduce the Max File
 Size to 20 MB or less. 

 This is required when upgrading from Panorama plugin for Enterprise DLP 3.0.3 or later releases to Enterprise DLP 4.0.0 or
 later releases as this plugin version does not support large file size inspection .
