 Advanced DNS Security Resolver License 

 Strata Cloud Manager utilizes Role-Based Access Control (RBAC) to manage administrative
 privileges. This system allows you to define specific privileges and responsibilities
 for each administrator. Every administrator must have a user account with a designated
 role and specified authentication method, allowing you to set granular permissions for
 each role, and assign appropriate access rights to administrative users. The following
 provides a listing of the access permissions related to configuring RBAC for the
 Advanced DNS Security Resolver. 

 For general information about using and configuring Access Control , refer to
 Strata Cloud Manager: Manage: Access
 Control .
