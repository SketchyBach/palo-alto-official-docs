 Addressed issues in Cortex XDR agent 9.2 

 The following issues have been resolved in this release. 

 ISSUE 

 PLATFORM 

 DESCRIPTION 

 CPATR-36649 

 General 

 Fixed an issue where an invalid hardware ID may cause an agent installation or upgrade to fail. 

 CPATR-36490 

 General 

 Fixed an issue to resolve a synchronization edge case to ensure seamless and accurate execution of IP unblocking requests. 

 CPATR-36464 

 Windows 

 Improvement made to the Cortex XDR agent security posture. 

 CPATR-36025 

 General 

 Fixed an issue to prevent the repeated download of content update packages during restart. 

 CPATR-35812 

 General 

 Fixed an issue that in rare scenarios a file copy location may be reported incorrectly. 

 CPATR-35311 

 Linux 

 Fixed an issue to prevent multiple AVA scan logs from being archived. 

 CPATR-35036 

 Windows 

 Fixed a rare issue that may be encountered during low-memory edge cases. 

 CPATR-34085 

 Linux 

 Improvment to agent security posture in SELinux. 

 CPATR-33194 

 Linux 

 Fixed an issue that may occur in Ubuntu/Debian systems where other services inadvertently restart during agent upgrade. 

 CPATR-33161 

 General 

 Fixed an issue where a time jump on the system may negatively impact scheduled tasks. 

 CPATR-35293 

 Linux 

 Fixed an issue on Linux where NIS compatibility entries in /etc/passwd could prevent the agent from resolving usernames for collected events.
