 Link Incidents 

 Link related Cortex XSOAR 6.14 incidents from the interface, pre-process rules, or CLI. 

 You can link or unlink incidents through the following: 

 In the Related Incidents tab. 

 A pre-process rule, so that as soon as an incident is ingested into Cortex XSOAR it is linked to an existing incident. 

 Using the CLI . 

 After you link the incident, you can view linked incidents in the Case Info tab.
