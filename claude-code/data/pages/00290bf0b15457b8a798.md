 Prisma Access Locations Dashboard 

 Use this dashboard to see how the applications running
in your SASE environment are performing based on metrics collected
by each Prisma Access location. 

 The Prisma Access Locations page gives metrics about the digital experience from each Prisma
 Access location during the selected Time Range. Because the Autonomous DEM service
 performs synthetic network and application testing from each of your Prisma Access
 locations to all monitored applications for that location, you can quickly isolate and
 correlate performance for issues with applications in a specific Prisma Access
 location. 

 Use the Prisma Access Locations page to: 

 Quickly survey the digital experience across all of your locations and see whether there are any
 issues that are concentrated in one or more of your Prisma Access locations. The
 Map View helps you get the status of all your
 locations at a glance. 

 Hover over a location to see the average scores of the network performance metrics and
 application performance metrics across all of the applications in use in a
 location. The metrics displayed are separated by deployment type (Mobile User,
 Remote Networks). This helps you isolate the source of a low experience
 score.

 ) to narrow down the results:

 Experience Score

view the data for only the time window selected.
