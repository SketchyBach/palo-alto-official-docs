 Domain-Specific Summary and Insights 

 The Summary and Insights page in Strata
 Multitenant Cloud Manager has been completely redesigned to help you find relevant
 information faster across your tenant hierarchy. The previous Summary page organized
 data by product tabs (SASE, Prisma Access, Prisma SD-WAN), presenting all widgets in
 a single flat view. The new design organizes information by role and task, making it
 easier to locate the metrics that matter most to you. 

 The new Summary and Insights page replaces product-based tabs with three domain-specific views : 

 Security — Assess threat detection and blocking effectiveness across tenants. Replaces the threat-related widgets from the previous product tabs. 

 Operational — Monitor real-time infrastructure health and resolve connectivity issues. Replaces the infrastructure and status widgets. 

 Business — Track service adoption, subscription utilization, and subscription status. This is an entirely new capability with no equivalent in the previous portal. 

 A scope selection control within the Security and Operational tabs lets you switch between Prisma Access, Prisma SD-WAN, and Prisma Browser without adding more top-level tabs. The previous Summary and Insights pages are now combined into a single Summary and Insights page in the left navigation. 

 This redesigned experience provides: 

 Faster time to action — Each view is tailored to a specific task. You go directly to the relevant tab instead of scrolling through unrelated widgets. 

 Add-on visibility — The Security view separates base security from add-on services (AI Security, App Security, Device Security, Data Security), showing which tenants have gaps in coverage. 

 Real-time operational awareness — The Operational view shows the current state of your infrastructure without a time range filter, highlighting which connections are down and which tenants are affected. 

 Executive-level business reporting — The Business view provides service adoption metrics, bandwidth usage, usage trends, add-on penetration, subscription utilization (over-utilized vs. standard), and license lifecycle tracking across all tenants. 

 Scalable design — New products can be added to the scope selection without cluttering the interface. 

 Streamlined resolution workflow — Click through from aggregated metrics to the tenant table, open the recommendation panel, and navigate directly to the single-tenant view to take action. 

 For information about the new location of widgets from the previous Monitor,
 Insights, and Summary dashboards, see Dashboard Widget Mapping .

 Prisma Browser for Managed Service Providers 

 Prisma Browser for Managed Service Providers 

 Many organizations lack the time, resources, or expertise to manage enterprise-grade
 security tools effectively. Prisma® Browser for MSPs bridges this gap
 by enabling managed service providers to deliver powerful, browser-based security to
 customers of any size—even starting with a single user. This approach streamlines
 deployment, centralizes management, and removes the need for customers to maintain
 their own complex security infrastructure. 

 Key Features 

 Flexible Licensing — The Prisma Browser license and flexible license pooling let you purchase a central quantity of licenses and dynamically allocate or reclaim them from child tenants, making license management efficient for variable customer sizes. Child tenants can be as low as one user, while the root tenant still requires the minimum quantity (200) of standalone Prisma Browser licenses. 

 Centralized Management — The Strata Multitenant Cloud Manager provides a unified view of all customer tenants, allowing you to centrally manage browsing policies, enforce security controls, and maintain consistent configurations across your customer base. It also offers consolidated visibility into user activity, security events, and browser-based threats, enabling proactive monitoring and quicker response to risks. 

 Streamlined Onboarding — The new add tenant wizard is a self-service workflow that automates provisioning, including license allocation and Identity Provider (IdP) setup. 

 Simplified Identity — You can leverage the MSP Identity Provider (MSP IdP) architecture to host a single, centralized IdP at the root level to manage all users, eliminating the need for each small business to integrate its own complex IdP. 

 Reporting and Visibility — The dashboard surfaces aggregated security metrics across tenants, including the total number of websites analyzed and a detailed breakdown of threats blocked by category and method. You can also generate and download tenant-specific reports for individual customers, covering top malicious websites, malware families, and malicious extensions blocked to demonstrate value.

 Associate Snippets with Folders in Bulk Configuration 

 You can now associate bulk configuration snippets with one or
 more folders (such as Global, Prisma Access, or All Firewalls) before pushing them
 to tenants, enabling more granular control over which folder scopes receive specific
 configurations and reducing the risk of applying incompatible settings. 

 Targeted Deployments: Associate snippets with specific folders so
 configurations are applied only to the intended folder scopes, preventing
 misconfigurations across different deployment targets. 

 Reduced Deployment Risk: By explicitly linking snippets to folders during
 the assignment workflow, you eliminate the possibility of pushing incompatible
 configurations to tenants, improving deployment reliability and compliance. 

 Streamlined Workflow: The snippet association step integrates directly
 into the bulk configuration assignment process, allowing you to define folder
 associations once before pushing to multiple tenants—saving time and reducing
 manual errors. 

 Custom BGP IPv4 Address Allocation for VLAN Attachments 

 You can now define custom IP addresses for BGP peering sessions on GCP VLAN
 attachments to gain greater control over your network addressing and simplify
 integration with existing service provider infrastructure. 

 By default, GCP automatically assigns link-local addresses from the 169.254.0.0/16
 range for BGP peering between the edge router and the cloud router. While
 functional, auto-assigned addresses can conflict with existing network
 configurations and make troubleshooting more complex in large-scale deployments. 

 With custom BGP IPv4 address allocation, you choose between two options when adding a
 VLAN attachment: 

 Automatically Allocate Link-Local Range —GCP assigns addresses from the
 169.254.0.0/16 range (default behavior). 

 Specify Custom IP Address —You define Cloud Router IP and Peer IP
 addresses for both the primary and secondary VLAN attachments using /30
 subnets. 

 Custom IP allocation gives you consistent, predictable addressing across your
 interconnects, simplifies route management, and aligns BGP peering with your
 existing IP address plan. This is particularly beneficial if you manage multiple
 tenants and require deterministic IP assignments for operational visibility and
 automated provisioning workflows. 

 You can configure custom BGP IPv4 addresses when you add a VLAN attachment to an
 interconnect.

 Service Provider Interconnect with Non-IPsec 

 The Service Provider Interconnect (SPI)
 feature, formerly known as Service Provider Backbone (Cleanpipe), has been
 transformed to support native IP ingress and high-bandwidth connectivity, enabling
 service providers to deliver Prisma Access services more efficiently. With support
 for up to 20 Gbps per tenant and 400 Gbps per interconnect, SPI eliminates IPsec
 tunnel overhead and enhances throughput and scalability for large enterprise and
 MPLS deployments. It also unlocks the complete Prisma Access feature set—including
 ZTNA, CASB, and IoT Security—while maintaining strict multi-tenant isolation and
 offering flexible egress options through either the service provider’s network or
 Prisma Access-managed points. 

 Guided Configuration Workflow 

 The new Configuration Center provides a guided workflow that assists
 administrators in the end-to-end configuration of interconnects. The workflow covers
 all key stages, including ingress configuration involving cloud service provider
 setup, interconnect configuration, VLAN and IP pool configuration, and egress path
 definition. This guided process simplifies complex setup tasks and ensures accuracy
 and consistency across all interconnect deployments. 

 Visibility and Monitoring Enhancements 

 Management and monitoring interfaces are enhanced to offer a unified,
 centralized experience across all interconnects and associated tenants. You can: 

 View interconnect type, operational status, and capacity
 utilization at a glance. 

 Access detailed per-tenant insights on VLAN health, traffic usage,
 and routing states.

 The Prisma 5G SASE feature has been enhanced
 to deliver deeper monitoring, richer observability, and a more streamlined
 configuration experience for both RADIUS and API-based integrations. The
 configuration workflow is also enhanced and combined with the Service Provider

 Key Enhancements 

 Unified Configuration Workflow 

 Administrators can define the connection type (RADIUS or API)
 during setup. 

 Enables end-to-end configuration and monitoring across both 5G and

 Enhanced 5G SASE Monitoring 

 Existing monitoring capabilities are extended with dynamic metrics
 that adjust automatically based on the selected integration type. 

 Provides detailed proxy and API usage metrics, including: 

 Active, added, and cleared mappings. 

 Connection and processing status for each interface.

 Features a simplified UE Metrics Trend widget to track 5G
 registration and unknown IP trends, enabling quick analysis of user activity
 and connection patterns. 

 What's New in September 2025 

 Flexible Multitenant License Allocation 

 Administrators can now increase or decrease license quantities allocated to tenants
 after activation, giving them greater flexibility to manage licenses as
 organizational needs evolve. 

 This capability offers the following benefits: 
 Reallocation for New Tenants - If the administrator initially activate
 a tenant using the full allocated quantity of a license and later encounter
 a change in business requirements or a new operational need that requires a
 separate tenant, they can reduce the license quantity assigned to the
 original tenant. This reduction frees up capacity in the license pool, which
 administrators can then allocate to activate the new tenant, ensuring that
 they distribute resources efficiently to meet evolving organizational
 demands. 

 Post-Activation Readjustment -After activation, license usage often
 shifts as business needs evolve or consumption patterns change.
 Administrators can evaluate historical usage and redistribute licenses
 across tenants to ensure allocations match actual demand. For example, they
 can reduce license quantities in one tenant with low consumption and
 reassign that capacity to another tenant that requires more resources. This
 ongoing flexibility enables enterprises and service providers to maximize
 license efficiency and adapt quickly to business priorities.

 Application Monitoring Update 

 The Strata Multitenant Cloud Manager enables managed security service providers
 (MSSP) or distributed enterprise customers of to get a holistic view of the
 application landscape for all tenants. Depending on your license, you can monitor
 application activity to get visibility into the Prisma Access applications along
 with information on data usage, incidents, and user experience of the
 applications. 

 If you have an Autonomous Digital Experience Management (ADEM) license, now you have
 access to features such as experience scores , plus the single tenant
 view for monitored applications in Strata Cloud
 Manager. AI-Powered ADEM is a service that provides native end-to-end visibility and
 performance metrics for application traffic in your environment. However, usage data
 is displayed for applications whether an ADEM license is enabled or not. This means
 that you can still access essential information about your applications, even
 without the advanced features provided by ADEM. 

 The application monitoring display is enhanced with the introduction of a new chart
 view and an updated table view, making it easier for you to analyze and interpret
 the information presented for parent and child tenants. It's not an aggregated view
 of the total usage from the perspective of the parent tenant. Access the Strata Multitenant Cloud Manager and
 select Monitor Applications .
