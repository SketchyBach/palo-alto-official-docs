 Customize the SOC Name 

 Add a server configuration to customize the name of the security operations center (SOC) that appears in communication tasks in Cortex XSOAR 6x. 

 The default name that appears in the survey header is Your SOC team . Follow these steps to customize the name of the SOC. 

 Select Settings → About → Troubleshooting → Add Server Configuration . 

 Add the key soc.name , and add the display name of your SOC as the value. 

 This name is used in the default message and email of the communication tasks, and the web survey for all communication tasks.
