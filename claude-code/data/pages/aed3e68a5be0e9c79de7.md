 Enterprise DLP Plugin 3.0.6 

 Released in October, 2023 

 New Feature Description 

 Data Profile Enhancement 

 The data pattern character limit for a data profile is removed.
 Data profiles no longer limit the number of data pattern match
 criteria based on the number of alphanumeric characters in the
 data pattern name, description, regular expression, and
 proximity keywords. 

 Synchronization Enhancement 

 Improved synchronization when changes between the DLP cloud
 service and managed firewalls using Enterprise Data Loss Prevention (E-DLP) 
 when changes are made to data patterns and data profiles. 

 FIPS-CC Support 

 Enterprise Data Loss Prevention (E-DLP) plugin 3.0.6 and later plugin releases
 are now FIPS-CC compliant.

 Enterprise DLP Plugin 3.0.4 

 Released in March, 2023 

 New Feature Description 

 New Application Support 

 Enterprise Data Loss Prevention (E-DLP) now supports the following new applications . 

 Firewalls leveraging Enterprise DLP must be running PAN-OS 10.2.4 or later release and have Apps &
 Threats content version 8684-7912 installed. 

 Google Drive Web 

 Microsoft OneDrive Desktop - Business 

 Expanded Download Support for Existing
 Applications 

 Enterprise Data Loss Prevention (E-DLP) now supports download inspection for the
 following applications . 

 Firewalls leveraging Enterprise DLP must be running PAN-OS 10.2.4 or later release and have Apps &
 Threats content version 8684-7912 installed. 

 Box Desktop - Business 

 Microsoft SharePoint Desktop 

 Microsoft SharePoint Web 

 Naver Mail Web 

 Salesforce Web 

 Expanded File Size Support for Existing Applications 

 Enterprise Data Loss Prevention (E-DLP) now supports large file inspection for
 the following applications . 

 Firewalls leveraging Enterprise DLP must be running PAN-OS 10.2.4 or later release and have Apps &
 Threats content version 8684-7912 installed. 

 Microsoft OneDrive Desktop - Personal 

 Enterprise DLP Plugin 3.0.3 

 Released in February, 2023 

 New Feature Description 

 Large File Inspection for Box and Web Browsing 

 Enterprise Data Loss Prevention (E-DLP) now supports upload inspection of files
 up to 100MB in size for the Box Web App and Web Browsing
 applications . 

 Proxy Support for Enterprise DLP 

 Enterprise Data Loss Prevention (E-DLP) now supports connectivity to the DLP
 cloud service when Panorama uses a Proxy for its
 outbound internet connection. 

 Enterprise DLP Plugin 3.0.2 

 Released in September, 2022 

 New Feature Description 

 Support for HTTP/2 Traffic Inspection 

 Enterprise Data Loss Prevention (E-DLP) now supports inspection of file and
 non-file based HTTP/2 traffic. 

 Enterprise DLP Plugin 3.0.1 

 Released in April, 2022 

 New Feature Description 

 Web Form Data Inspection for Enterprise Data Loss
 Prevention 

 More data is being exchanged in non-file formats that leverage
 collaboration applications, web forms, cloud applications, and
 social media. PAN-OS 10.2.1 supports inspection of
 non-file format traffic to strengthen your security posture and
 prevent exfiltration of sensitive data. 

 Enterprise DLP Plugin 3.0.0 

 Released in February, 2022 

 New Feature Description 

 Enterprise DLP Plugin Upgrade 

 Upgrade to the Enterprise Data Loss Prevention (E-DLP) 3.0.0 plugin to increase
 reliability. Enterprise DLP plugin 3.0 is required to
 upgrade to PAN-OS 10.2 and is only supported on
 PAN-OS 10.2 and later releases.
