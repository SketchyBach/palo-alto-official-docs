 Edit an Application (Strata Cloud Manager) 

 After you have created a custom application, you can make changes to the
 configuration by clicking on the custom application name. This is done in the same
 manner, and with identical options, as to the creation of the custom application;
 refer to Create a Custom Application (Strata Cloud Manager) for details on the available options. 

 Predefined applications have limited editing options. From Strata Cloud Manager, you
 can change the Risk as well as various timeout values. To
 classify or tag predefined applications, use the Application Catalog
 ( Configuration Application Catalog ). 

 The following describes how to update your predefined application settings: 

 Select Manage Configuration NGFW and Prisma Access Objects Applications . 

 Select a predefined or local application and click Edit Predefined
 Application . 

 Update the details about the application, such as the TCP
 Timeout , TCP Half Closed , TCP
 Time Wait , UDP Time Out , and
 Risk values, to more appropriately fit the needs of
 your organization's network security requirements. 

 Click Update when finished updating the
 application.
