 INC_RN_AUTH_SERVER_UNREACHABLE_PER_PA_LOCATION 

 Learn about the INC_RN_AUTH_SERVER_UNREACHABLE_PER_PA_LOCATION incident. 

 Incident Code 

 INC_RN_AUTH_SERVER_UNREACHABLE_PER_PA_LOCATION 

 Title Template 

 Auth server {target} is unreachable for location {location} for RN 

 Category 

 Network Services 

 Subcategory 

 Authentication 

 Description 

 The authentication server is unreachable from the Remote Network for specific Prisma Access locations. This can lead to authentication failures for users or devices in those locations, impacting their ability to access resources securely. It is important to investigate and address this incident promptly to restore authentication services and ensure secure access for users within the affected Prisma Access locations. 

 Raise Condition 

 Incident is Raised when 85% of the instances can not reach the auth server for the last 12 minutes across the PA location 

 Clear Condition 

 Incident is Cleared when instances are able to the auth server for the last 6 minutes for the PA Location
