 Dashboards 

 Cortex Xpanse provides a comprehensive set of predefined dashboards and the ability to create custom dashboards. 

 Dashboards offer graphical overviews of your tenant's activities, enabling you to effectively monitor incidents and overall activity in your environment. Each dashboard comprises widgets that summarize information about your attack surface in graphical or tabular format. Cortex Xpanse provides a comprehensive set of predefined dashboards, as well as the ability to create your own custom dashboards. 

 Most dashboards can be filtered by tags, business units, and time range. An indicator at the top right side of the page shows the time that the dashboard was last updated, and if the data is not up-to-date you can click **Refresh **to update all widget data. 

 Click the dashboard options menu to see additional actions, including the option to save the dashboard as a report template, and set it as your default dashboard
