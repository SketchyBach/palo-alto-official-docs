 Content Inspection Features 

 Explore new content inspection features introduced in
PAN-OS ® 10.1. 

 New Content Inspection Feature Description 

 Additional Protections for Modern DNS-layer Attacks 

 DNS Security now features almost three times
the number of protections against DNS-layer attacks as before, including
several industry-first protections for attacks including ultra-slow
DNS tunneling and dangling DNS. Other protections include NSNX DDoS
attacks, fast-flux domains, dictionary DGA, DNS rebinding, and predictive
detection of newly registered domains. 

 Download the latest
PAN-OS content release to take advantage of the new protections.
