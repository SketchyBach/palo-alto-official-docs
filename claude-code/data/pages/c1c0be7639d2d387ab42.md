 IPsec profile uses insecure authentication algorithms on Palo Alto Networks devices misconfiguration 

 Rule Details 

 Cortex AppSec Rule ID 

 APPSEC_PAN_12 

 Category - Subcategory 

 Public Exposure - Encryption And Protocols 

 Provider 

 OTHER 

 Severity 

 MEDIUM 

 Framework 

 Ansible 

 Impact 

 This rule detects whether IPsec profiles in Palo Alto Networks devices use insecure authentication algorithms. Specifically, the rule checks that IPsec profiles do not use 'none', 'md5', or 'sha1' for ESP (Encapsulating Security Payload) authentication, as these algorithms are considered weak and vulnerable to attacks. Strong authentication algorithms are crucial for ensuring the confidentiality and integrity of IPsec VPN connections. 

 How to Fix 

 Resource: panos_security_rule 

 Attribute: disable_server_response_inspection 

 To mitigate this issue, ensure that the disable_server_response_inspection attribute is either set to 'false' or omitted in your panos_security_rule definitions. Disabling DSRI ensures that server responses are inspected, maintaining the efficacy of security policies.
