 Required Software Versions for Panorama Managed Prisma Access (4.0 Preferred) 

 The Cloud Services plugin 4.0 requires the following minimum software versions for
 Panorama and GlobalProtect. 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Panorama) 

 Prisma Access license 

 Minimum Required Prisma Access Version 4.0 Preferred 

 The Cloud Services plugin 4.0 requires the following minimum software versions for
 Panorama and GlobalProtect. 

 If you have a Prisma Access (Managed by Strata Cloud Manager) deployment, plugin upgrades are not required;
 however, the GlobalProtect versions apply to both Panorama and Cloud Managed versions of
 Prisma Access. 

 Software Version Minimum Required Panorama Version Minimum Required GlobalProtect Version 

 4.0 Preferred 

 PAN-OS 11.0 

 PAN-OS 10.2.3 or a later PAN-OS version of 10.2 

 PAN-OS 10.1.7 or a later PAN-OS version of 10.1 

 You must have a Panorama appliance running 10.2 to take
 advantage of the 10.2 features in Prisma Access. 

 Any GlobalProtect version that is not End-of-Life (EoL) is
 supported for use with Prisma Access.
