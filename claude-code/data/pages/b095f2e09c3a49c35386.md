 Known Issues in Network Discovery 3.1 

 Known issues in Network Discovery plugin 3.1. 

 Where Can I Use This? What Do I Need? 

 NGFW (Managed by PAN-OS or Panorama) 

 One of the following subscriptions: 

 Device Security subscription

 Precision AI bundle subscription

 Device Security X subscription

 The following list includes all known issues that impact a Device Security 
 Network Discovery plugin 3.1 release. This list includes both
 outstanding issues and issues that are addressed, as well as known issues that apply
 more generally or that are not identified by a specific issue ID.

 BAN-28254 

 While the Network Discovery plugin ran, it generated an excessive number of
 irrelevant logs.

 This issue is resolved in Network Discovery plugin 3.1.0. 

 BAN-27885 

 Configuration changes fail to appear when switching between Panorama-managed
 and local configuration by using the firewall to enable or disable
 template and device group configurations sent from Panorama.

 Workaround Reset the plugin using the following command:

 request plugins reset-plugin plugin-name network_discovery 

 BAN-27879 

 When running a multi-threaded neighbor discovery job, threads time out for a
 few switches.

 This issue is resolved in Network Discovery plugin 3.1.0. 

 BAN-27815 

 The Network Discovery plugin doesn't correctly resolve shared address objects
 used in OT polling when on a multi-vsys device.

 This issue is resolved in Network Discovery plugin 3.1.0. 

 BAN-27132 

 The neighbor discovery and data refreshment jobs did not return any endpoints for
 global ARP due to issues in VLAN handling.

 This issue is resolved in Network Discovery plugin 3.1.0. 

 BAN-22750 

 The Network Discovery plugin reports all timestamps as Pacific Time, instead of
 the firewall's configured time zone.

 This issue is resolved in Network Discovery plugin 3.1.0. 

 DIT-68976 

 The neighbor discovery and data refreshment jobs did not return any endpoints,
 even when the job details showed a successful crawl.

 This issue is resolved in Network Discovery plugin 3.1.0.
