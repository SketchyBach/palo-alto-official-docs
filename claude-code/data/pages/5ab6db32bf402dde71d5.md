 AutoFocus API Error Codes 

 The following table provides a list of standard HTTP
status codes that AutoFocus uses when returning errors. An accompanying
error messages includes additional details for clarification. 

 HTTP Status Code 

 Meaning 

 200 

 No errors. Successful call 

 404 

 Invalid URL. Example: 
 {"code": 404, "error": "Error 404 Not Found", "error_description":"The requested URL was not found on this server." } 

 409 

 Invalid message or missing parameters. For
example, if the scope is invalid, the corresponding error looks
like this: 
 { "message": "invalid scope" } 
 If
parameters are missing, the corresponding error looks like this: 
 {"message": "Missing Body Parameters: [\"scope\"]" } 
 If
the license has expired or is otherwise invalid, the corresponding
error looks like this: 
 { mwStatus: 409, mwMessage: 'Invalid license' } 

 500 

 Internal error. 

 503 

 Rate limit exceeded. Example: 
 {"message": "Minute Bucket Exceeded", "bucket_info": { "minute_points":200, "daily_points": 25000, "minute_bucket_start": "2015-09-13 01:23:23","daily_bucket_start": "2015-09-12 14:47:43", "minute_points_remaining":0, "daily_points_remaining": 24715, "wait_in_seconds": 53.086 }}
