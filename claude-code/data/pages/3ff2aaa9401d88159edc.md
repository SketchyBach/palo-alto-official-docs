 Add Performance Policy Set 

 Steps to add performance sets to a performance policy rule. 

 Where Can I Use This? What Do I Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 Physical and virtual ION devices running software version
 6.3.1 and higher 

 The Performance Sets tab contains policy rules and are a part
 of the policy set stacks. A policy set has default policy rules, which can't be
 changed, removed, or deleted. You can create custom policy rules to take precedence
 over the default policy rules. Select a stack, then a policy set within the stack,
 and then add policy rules to the policy set. 

 Use the Actions icons to Edit a policy set, view the audit logs or any system configuration
 changes, and remove a policy set. 

 To add a performance set: 

 Select Configuration Prisma SD-WAN Policies Performance Performance Sets . 

 Select Advanced and Add
 Set . 

 On the Add New Performance Set screen, enter a
 Name for the performance set, and optionally enter
 description and tags. 

 Select the Clone from Performance Set? checkbox to
 create a stack similar to an existing path stack. 

 Save your changes.
