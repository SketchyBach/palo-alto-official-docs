 AL_ZTNA_CONNECTOR_MEMORY_HIGH 

 Learn about the AL_ZTNA_CONNECTOR_MEMORY_HIGH alert. 

 Synopsis 

 The alert is raised when the ZTNA connector's average memory utilization over 30
 minutes exceeds 80%. The alert is cleared when the ZTNA connector's average memory
 utilization over 30 minutes is less than 75%. 

 Alert Code—AL_ZTNA_CONNECTOR_MEMORY_HIGH 

 Required License 

 Prisma Access 

 Severity 

 Critical
