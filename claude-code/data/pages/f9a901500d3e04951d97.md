 Create the notification rule for a failed report 

 You can receive an email notification if a report fails to run. 

 You can receive an email alert if a report fails to run due to a timeout or fails to upload to the GCP bucket. 

 Under Settings → Configurations → General → Notifications , click + Add Forwarding . 

 Enter a name and a description for your rule, and under Log Type , select Management Audit Logs . 

 Use a filter to select the **Type **as Reporting , Subtype as Run Report , and **Result **as Fail . 

 Under Distribution List , select the email address to send the notification to. 

 Click Done .
