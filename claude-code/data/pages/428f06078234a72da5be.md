 Supported Hardware and Software Versions 

 Supported hardware and software versions. 

 The minimum device software version supported is 6.2.3 and above.
 If you are using any lower version, upgrade to release 6.2.3. Refer to Upgrade the Device Software . For
 any installation support, contact Customer Support or the Product Management
 team. 

 The current controller version is release 6.2.3. Refer Upgrade On-Premises
 Controller . 

 All hardware ION devices are supported to deploy on-premises
 controller. 

 Upgrade or Downgrade Considerations 

 The minimum device software version supported is 6.2.3. Refer to the
 Deployment Guide to know more.
