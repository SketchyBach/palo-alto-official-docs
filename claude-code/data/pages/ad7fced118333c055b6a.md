 Use the dump auth status command
to display details of the logged-in users, roles, IDs, and user names. 

 Command 

 dump auth status 

 Options 

 None 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands 

 dump auth config 

 Introduced in Release 4.4.1 

 Example 

 dump auth status

 Login ID: elem-admin
 Role : super
