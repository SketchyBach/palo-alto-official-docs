 Prisma Browser Desktop Prisma Browser Extension Prisma Browser for Mobile

 Custom Texts allows administrators to replace the default text displayed in
 user-facing dialogs, security prompts, and other browser messages with
 organization-specific language. Use this control to add context to policy
 enforcement — for example, explaining why an action is blocked and how users
 can request an exception. This control can also be used to provide localized text if
 required. 

 From Strata Cloud Manager , select Configuration Policy Control Sets Browser Customization Branding 

 Select Custom Texts . 

 Select one of the following options: 

 Use default texts - All dialog texts, security checks, and
 other messages use the default, preconfigured text. 

 Customize and edit texts - Configure custom text for
 individual dialog entries. When selected, a sidebar navigation panel
 opens with the following sections: 

 Dialog Texts — Customize the text shown in browser
 action dialogs. Entries are grouped by category (for example,
 Clipboard Controls, File Controls, Identity Controls). Use the
 search bar to filter entries by name or text content. Use the
 category filter to narrow the list to a specific control
 group. 

 Security Checks — Customize the text shown in
 posture security check prompts. Use the search bar to filter
 entries. 

 Other — Customize the link name and URL in the
 Prisma Browser Extension About section. 

 The Other section is limited to
 the Prisma Browser Extension. 

 To edit an entry, locate it in the list and click the pencil icon. In
 the Edit Text dialog, modify the Title and
 Description fields. To revert an entry to its default
 text, click the undo icon next to that entry. 

 Text changes apply to all users covered by
 this profile. The Prisma Browser does not apply text
 customizations to the Prisma Browser for Mobile. 

 Click Set .
