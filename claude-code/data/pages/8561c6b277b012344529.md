 GTP Message Type 

 GTPv1 and GTPv2 have message types and corresponding
message values. 

 Indicates the type of GTP message. GTPv1 messages are
defined in 3GPP TS 29.060 release 13.4 and GTPv2 messages are defined
in 3GPP TS 29.274.
