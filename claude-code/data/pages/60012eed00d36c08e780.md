 Prisma SD-WAN and Prisma Access Integration Requirements (Panorama Managed CloudBlade) 

 Integration requirements are listed for Prisma SD-WAN CloudBlade for Prisma Access
 (Panorama Managed). 

 To integrate Prisma SD-WAN and Prisma Access , you must
 refer to the following requirements. 

 Product Requirements for (Managed by Panorama) 

 Prisma SD-WAN 

 Active Prisma SD-WAN subscription. 

 Prisma SD-WAN AppFabric deployed at one or
 more locations. 

 Physical and/or virtual ION devices running: 

 Recommended version is 5.4.3 or higher. 

 Minimum version supported is 5.1.9. 

 Prisma Access 

 Supported
 versions for the Cloud Plugin 

 Active Prisma Access for Networks subscription sufficient
 to cover remote sites. 

 Identification of the IPSec Termination Nodes within Prisma
 identified for connectivity. 

 Panorama to manage the Prisma Access for Networks with
 the following: 

 Cloud Services plugin installed. If the minimum
 version for the Cloud Services plugin is not
 available in Panorama, contact the Palo Alto Support
 team. 

 Verify that Panorama is running a supported version
 of the Prisma Access Cloud Services Plugin. 

 Cloud Services Infrastructure Subnet configured. 

 Cloud Services Remote Networks Zone Mappings (Trust
 or Untrust) configured.
