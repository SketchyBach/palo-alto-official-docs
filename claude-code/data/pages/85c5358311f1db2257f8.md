 Addressed Issues in Prisma SD-WAN ION Device Release 5.6.19 

 The following table lists the issues addressed in Prisma SD-WAN 
 ION Device Release 5.6.19. 

 Issue ID Description 

 CGSDW-13559 

 Resolved an issue where periodic flapping of the cellular data session was
 observed when using Verizon Wireless Network, Telstra, and possibly other carriers
 with direct to internet traffic on the ION 1200 devices. 

 CGSDW-16003 

 Resolved an issue where the FC was crashing due to an ADEM application probe. 

 CGSDW-19542 

 Assessed that the ION device is not vulnerable to a Terrapin attack
 (CVE-2023-48795). 

 CGSDW-23390 Added the latest ADEM package to device software version
 5.6.19.

 records in the ARP table were not being

 Issue ID Description

 prefix filters for security policies were missing

 Addressed Issues in Prisma SD-WAN ION Device Release
 5.6.13 

 The following table lists the issues addressed in Prisma SD-WAN ION Device Release 5.6.13. 

 Issue ID Description 

 CGSDW-2614 Resolved an issue where the
 memory usage was increasing when the device did
 not have connectivity with the controller. 

 CGSDW-8227 Resolved an issue that caused
 the system routes to disappear during a switchover
 in a branch high availability (HA)
 deployment. 

 CGSDW-10086 Resolved an issue in the
 Rtr-mgr , which was causing
 the system to eventually run out of
 memory. 

 CGSDW-10332 Resolved an issue where GRE
 tunnels were not being established on hardware
 platforms with Zscaler endpoints. 

 CGSDW-12127 Resolved an issue causing
 intermittent packet drops for ICMP/PING flows in
 WAN to LAN traffic from Prisma Access mobile
 users to a Prisma SD-WAN remote
 branch LAN host. 

 CGSDW-12189 Resolved an issue where the
 DHCP server could not configure the bootfile for
 devices without a PXEClient VCI. 

 CGSDW-12663 Resolved an issue in which the
 HA switchover took place only after restarting the
 flow controller (FC). 

 CGSDW-12977 Resolved an issue that was
 causing a missing ARP entry for the controller
 gateway after upgrading to version 5.6.11. 

 CGSDW-13551 Resolved an issue where
 asymmetric routing between DIA and GRE tunnels was
 not working for TCP traffic.

 5.6.11 

 The following table lists the issues addressed in Prisma SD-WAN ION Device Release 5.6.11. 

 Issue ID Description 

 CGSDW-8754 Resolved an issue in which the
 BGP status for a backup ION device displayed as
 unsynchronized on the web
 interface. 

 CGSDW-10791 Resolved an issue where the
 controller port was stuck with an incorrect ARP
 entry and went offline. 

 CGSDW-10905 Resolved an issue where a
 standard VPN tunnel may flap during the IKE rekey
 process. 

 CGSDW-11041 Resolved an issue where both
 the data center ION devices were advertising
 prefixes. 

 CGSDW-11147 Resolved an issue wherein the
 data center ION device were dropping fragmented
 packets for MTUs greater than 1376. 

 CGSDW-11241 Resolved an issue where a large
 number of UDP packets were being sent from the
 data center ION device to the branch ION
 device.

 Addressed Issues in Prisma SD-WAN ION Device Release
 5.6.7 

 The following table lists the issues addressed in Prisma SD-WAN ION Device Release 5.6.7. 

 Issue ID Description 

 CGSDW-6956 Resolved an issue where traffic
 stopped flowing between branch ION devices and GCP
 data center ION devices on release 5.6.x. 

 CGSDW-7761 Resolved an issue wherein all
 the VPNs for a data center ION device went
 down. 

 CGSDW-7776 Resolved an issue where the
 element manager process deleted interfaces on
 process reload or restart. 

 CGSDW-7845 Resolved an issue where
 graceful restart capability was not advertised to
 BGP peers. 

 CGSDW-7866 Resolved an issue where
 multiple DHCP processes were running for a single
 DHCP relay configuration. 

 CGSDW-9692 Resolved an issue wherein
 downloading large files over service links was
 slow, along with TCP retransmissions. This applies
 to private Layer 2 deployments. 

 Addressed Issues in Prisma SD-WAN ION Device Release
 5.6.5 

 The following table lists the issues addressed in Prisma SD-WAN ION Device Release 5.6.5. 

 Issue ID Description 

 CGSDW-2887 Resolved an issue where the RTR
 Manager was taking long time to clear the
 interface messages after a switchover. 

 CGSDW-4080 Added support for displaying
 the SNMP engine ID using the CLI toolkit
 commands. 

 CGSDW-4185 Added support to disable less
 secure ciphers on Prisma SD-WAN for
 SSH. 

 CGSDW-4410 Resolved an issue when the ION
 device received an application definition update
 which improperly removed the mapping entries for
 the HTTP and SSL applications. The result of which
 could be, incorrect policy matches for generic
 HTTP and SSL traffic.

 Workaround: A one time reboot of the device or a restart of the app-engine process using the command debug process restart name=tcpproxy . 

 CGSDW-4870 Resolved an issue where BGP
 routes were not parsing properly because of
 repeated spaces between AS numbers. 

 CGSDW-5020 Resolved an issue where a
 prefix was advertising from both hub device as the
 VPNs were in active/true status on both the hubs
 when VPN keepalive timers are set with a high
 value. 

 CGSDW-5057 Resolved an issue where the ION
 9000 device fan was making noise with
 DPDK. 

 CGSDW-5102 Resolved an issue where the hub
 was advertising same global prefix for multiple
 VPNs resulting in traffic failure. 

 CGSDW-5416 Resolved an issue where after
 tunnel and BGP creation by the Prisma Access 
 Cloudblade, BGP was down and did not show any
 status on the portal and CLI. 

 CGSDW-5603 Resolved an issue where the BWM
 server was holding open connections in AWS
 deployment. 

 CGSDW-6025 Resolved an issue where latency
 is miscalculated when it is higher than 500ms for
 ICMP probe. 

 CGSDW-6138 Resolved an issue where the
 Internet Direct Reachability Down alarm triggered
 on the backup device was not getting
 suppressed. 

 CGSDW-6194 Resolved an issue where the
 Layer 7 application were not being detected
 correctly. 

 CGSDW-6268 Resolved an issue where the
 data center ION device was not sending traffic to
 the branch ION device. 

 CGSDW-6355 Resolved OpenSSL vulnerability
 CVE-2022-0778. 

 CGSDW-6466 Resolved an issue in the IPSEC
 crypto offloading process logic which affected
 Data Center ION 9000s running 5.6.1 or 5.6.3. As a
 result of this, customers may observe a
 degradation in throughput performance, erroneously
 reported link quality latency measurements, or VPN
 flaps due to missed keepalives. 

 CGSDW-6724 Resolved an issue where DHCP
 relay was not working, if the DHCP server was
 running on interface through which DHCP relay
 packet was sent out. 

 CGSDW-6845 Resolved an issue where, in
 rare cases, FC was restarted when there was branch
 to branch asymmetric traffic through the hub with
 both branches on different hubs transition to the
 same hub.

 5.6.3 

 The following table lists the issues addressed in Prisma SD-WAN ION Device Release 5.6.3. 

 Issue ID Description 

 CGSDW-1424 Resolved an issue where
 multiple internal URLs were failing nslookup,
 causing NTP to be out of sync. 

 CGSDW-2816 Resolved an issue where
 static-route with higher AD was programmed on
 bypass pair FIB. 

 CGSDW-3227 Resolved an issue for SAML/SSO
 whereby '-' was not allowed in IdP domain names,
 this is supported now. 

 CGSDW-3420 Resolved an issue where the
 ADEM portal was not displaying the Prisma Access SPN name for Standard VPN interfaces. 

 CGSDW-3521 Resolved an issue where a large
 number of DCs assigned to a single DC group was
 causing the FC process to crash. 

 CGSDW-3958 Resolved an issue where the
 Site Summary screen was showing incorrect values
 for the current overall consumed bandwidth if the
 time range selected was not last one hour. 

 Addressed Issues in Prisma SD-WAN ION Device Release
 5.6.1 

 The following table lists the issues addressed in Prisma SD-WAN ION Device Release 5.6.1. 

 Issue ID Description 

 CGSDW-826 Resolved an issue where the LAN
 side FIB had no prefixes present even though the
 LAN interfaces were Admin Up and had learned or
 configured prefixes present. 

 CGSDW-955 Resolved an issue where BGP
 peer status was not in sync with the CLI and the
 web interface. 

 CGSDW-1081 Resolved an issue where
 NAT_POLICY_STATIC_NATPOOL_OVERRUN alarm was raised
 but not displayed properly in the web
 interface. 

 CGSDW-1634 Resolved an issue where data
 center ION devices that have internet access via
 the internet labeled ports only fail to establish
 remote access sessions. 

 CGSDW-1935 Resolved an issue where the web
 interface was showing Layer 3 LAN forwarding
 configured, but not configured on the ION device,
 while the LAN interfaces are configured as Layer 3
 on the ION device. 

 CGSDW-2679 Resolved an issue where the VPN
 marked as Admin Down did not remove the routes
 posted in the FIB associated with it. 

 CGSDW-3193 Resolved an issue where VPNs in
 a data center with 5.2.x and branch devices with
 5.6.1 do not come up. 

 CGSDW-3257 dhcp lease command failed
 because of missing file in dhcp package. 

 CGSDW-3725 Resolved an issue where when
 setting an interface status to Admin Down on a DC
 ION device on the user interface, the same status
 was not reflected on the ION device.
