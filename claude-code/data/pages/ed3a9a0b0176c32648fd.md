 Prepare Panorama for SCM-Panorama Configuration Sync 

 Install and configure the CloudConnector plugin on Panorama to enable secure
 communication for SCM-Panorama Configuration Sync. 

 Before Strata Cloud Manager can synchronize snippet configurations to your Panorama appliance, complete the following tasks on Panorama in
 the following order: 

 Install and enable the CloudConnector plugin. 

 Enable the SCM-Panorama Configuration Sync feature. 

 Fetch a Thermite device certificate. 

 Install the CloudConnector Plugin 

 Log in to the Panorama web interface. 

 Select Panorama Plugins . 

 Under Cloud Services Plugins , locate the
 CloudConnector plugin. 

 If your Panorama is running
 PAN-OS ® 11.0.1 or later, the CloudConnector
 plugin is pre-installed. Verify that you have the latest version before
 proceeding. 

 To use the
 SCM-Panorama Configuration Sync feature, you must have
 CloudConnector plugin version 3.0.2 or later installed. The
 required version depends on your PAN-OS ® 
 release: 
 For PAN-OS ® versions earlier than
 12.1, manually download and install CloudConnector
 3.0.2. 

 Select Check Now to retrieve the latest
 available versions. 

 Download and install the latest version. 

 Beginning with PAN-OS 12.1.2, you no longer have to manually
 find and download compatible plugin versions before
 installing them. Now, compatible plugins are automatically
 downloaded with the Panorama image, and you can directly
 install the ones you need. 

 Confirm that the plugin status shows as installed in the
 Currently Installed column. 

 Enable SCM-Panorama Configuration Sync 

 Log in to the Panorama CLI
 admin . 

 Enable the SCM-Panorama Configuration Sync feature. 

 request plugins cloudconnector scm-panorama-config-sync enable yes 

 Fetch the Thermite Device Certificate 

 The Thermite device certificate authenticates all communication between
 your Panorama appliance and Strata Cloud Manager. You must generate a One-Time
 Password (OTP) from the Customer Support Portal to fetch the certificate. 

 Log in to the CSP . 

 Navigate to Products Device Certificates Generate OTP 

 Select Generate OTP for a Panorama and click
 Next . 

 Select your Panorama device. 

 Generate an OTP for your Panorama and copy the OTP value. 

 On the Panorama CLI, fetch the device certificate, replacing
 OTP_value with the value you copied. 

 request certificate fetch otp <OTP_value> 

 Verify that the command completes without errors. 

 Each OTP is valid for a single
 use. If the certificate fetch fails, generate a new OTP from the CSP and
 retry. 

 After completing these steps, return to Strata Cloud Manager to associate your
 Panorama with your tenant and begin synchronizing configurations. See Sync Panorama Configurations with SCM
 Snippets in the Strata Cloud Manager Getting Started Guide.
