 Changes to Default Behavior 

 Review the changes in default behavior for Enterprise Data Loss Prevention (E-DLP) . 

 Feature 

 Change 

 Regional Support for Evidence Storage 

 Palo Alto Networks released Regional Support for Evidence Storage in
 October 2025. 

 If you had a storage bucket configured at the time this feature was
 released, Enterprise DLP creates an All
 Regions storage bucket that forwards evidence for
 all DLP incidents generated to this storage bucket regardless of the
 region where the incident was generated. 

 Set up region-specifc evidence storage to
 forward evidence files to storage buckets to ensure that sensitive
 data related to DLP incidents remains within specific regional
 boundaries the incident was generated to comply with local data
 protection laws. 

 Evidence Storage 

 Syslog Forwarding 

 Palo Alto Networks is enhancing the Enterprise DLP Evidence
 Storage and Syslog Forwarding infrastructure to improve performance
 and expand availability for these services globally. As a result,
 Palo Alto Networks is introducing new service IP addresses that
 you need to allow on your network to use these services. 

 What is happening? 

 Palo Alto Networks is introducing new service IP addresses for the
 following Enterprise DLP services: 

 Evidence
 Storage 

 Syslog
 Forwarding 

 Review the Setup Prerequisites 
 for Evidence Storage and Syslog Forwarding for the list of all
 service IP addresses you need to allow on your network. 

 When is this happening? 

 Starting on May 7, 2025 . 

 Who does this impact? 

 This change impacts all users currently using the Evidence Storage
 and Syslog Forwarding services and impacts only these services. 

 This change doesn’t impact any traffic forwarding to Enterprise DLP . You won’t experience any service disruption on
 May 7, 2025 if you aren’t currently using the Evidence
 Storage or Syslog Forwarding services. 

 What happens if I don't make the required changes? 

 If you don’t allow all the required service IP addresses by May 7,
 2025 , Enterprise DLP can’t: 

 Evidence Storage —Connect to your storage bucket to
 automatically store evidence of scanned traffic. 

 Syslog Forwarding —Connect to your third-party security
 information and event management (SIEM), Security
 Orchestration, and Response (SOAR), or other automated
 ticketing system to automatically forward Enterprise DLP
 incident syslogs. 

 Any File Type Setting in Data Filtering
 Profiles 

 In PAN-OS 11.0 and later releases and Enterprise DLP plugin 4.0 and later releases, Enterprise DLP removed the
 Any setting for the data filtering profile 
 File Type setting. 

 You must contact 
 Palo Alto Networks Support and open a ticket to request that a
 migration script convert all your existing predefined and custom
 data filtering profiles before you upgrade to PAN-OS 
 11.0 or later release and Enterprise DLP plugin 4.0 or later
 release.
