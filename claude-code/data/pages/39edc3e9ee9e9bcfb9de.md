 INC_RN_SPN_LONG_DURATION_EXCEEDED_CAPACITY 

 Learn about the INC_RN_SPN_LONG_DURATION_EXCEEDED_CAPACITY incident. 

 Incident Code 

 INC_RN_SPN_LONG_DURATION_EXCEEDED_CAPACITY 

 Title Template 

 SPN capacity exceeded 100% usage for 3 days in the last 5 days for SPN {spn_name} {initial_direction} traffic 

 Category 

 Network and Traffic 

 Subcategory 

 Site/Tunnel 

 Description 

 A Service Provider Network within the Remote Network setup has been operating beyond its capacity for a prolonged period. This extended overutilization can lead to performance degradation and potential service disruptions for users relying on this network. 

 Raise Condition 

 Incident is Raised when SPN capacity exceeded 100% usage for at least 3 days in the last 5 days for at least 1 hours a day in the given direction 

 Clear Condition 

 Incident is Cleared when SPN capacity didn't exceeded 90% usage in the last 8 days for at least 1 hours a day in the given direction
