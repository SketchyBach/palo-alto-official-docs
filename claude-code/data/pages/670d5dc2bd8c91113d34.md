 Edit an Application (PAN-OS & Panorama) 

 After you have created a custom application, you can make changes to the
 configuration by clicking on the custom application name. This is done in the same
 manner, and with identical options, as to the creation of the custom application;
 refer to Create a Custom Application (PAN-OS & Panorama) for details on the available options. 

 Predefined applications have limited editing options. From Strata Cloud Manager, you
 can change the Risk as well as various timeout values. 

 The following describes how to update your predefined application settings: 

 Navigate to Objects Applications to view the list of available applications. 

 Click on the name of a predefined or local application. You can also search for
 an app by keyword or by using the filters, 

 Update the details about the application, such as the TCP
 Timeout , TCP Half Closed , TCP
 Time Wait , UDP Time Out , and
 Risk values, as well as the App-ID
 Enabled status, to more appropriately fit the needs of your
 organization's network security requirements. 

 Click Close when finished updating the
 application.
