 Known issues in Network Discovery plugin 2.2. 

 Where Can I Use This? What Do I Need? 

 NGFW (Managed by PAN-OS or Panorama) 

 One of the following subscriptions: 

 Device Security subscription

 Precision AI bundle subscription

 Device Security X subscription

 The following list includes all known issues that impact a Device Security 
 Network Discovery plugin 2.2 release. This list includes both
 outstanding issues and issues that are addressed, as well as known issues that apply
 more generally or that are not identified by a specific issue ID.

 BAN-27132 

 The neighbor discovery and data refreshment jobs did not return any endpoints for
 global ARP due to issues in VLAN handling.

 This issue is resolved in Network Discovery plugin 2.2.5. 

 DIT-68976 

 The neighbor discovery and data refreshment jobs did not return any endpoints,
 even when the job details showed a successful crawl.

 This issue is resolved in Network Discovery plugin 2.2.4. 

 BAN-25724 

 DIT-63601, PAN-303996 

 The neighbor discovery and data refreshment jobs failed to discover endpoints.

 This issue is resolved in Network Discovery plugin 2.2.3. 

 BAN-25638 

 DIT-64256 

 The Network Discovery plugin failed to identify the new Device Security license.

 This issue is resolved in Network Discovery plugin 2.2.3. 

 BAN-24232 

 When running an OT polling job with the Reverse DNS protocol, the polling job
 did not respect the timeout value set in basic configuration mode.

 This issue is resolved in Network Discovery plugin 2.2.2. 

 BAN-22992, BAN-23331 

 The Device Security portal doesn't display the switch port and
 switch MAC address fields learned from the Network Discovery plugin. 

 This issue is resolved in Network Discovery plugin 2.2.2. 

 BAN-22858 

 The Network Discovery plugin deadlocks when running the data refresh job and the
 neighbor discovery job in parallel.

 This issue is resolved in Network Discovery plugin 2.2.1. 

 BAN-22756 

 Polling with the Axis Communications protocol doesn't work when multiple hosts
 are configured with a service route.

 This issue is resolved in Network Discovery plugin 2.2.1. 

 BAN-22750 

 The Network Discovery plugin reports all timestamps as Pacific Time, instead of
 the firewall's configured time zone.

 BAN-22468 

 Committing an unrelated configuration change caused the Network Discovery jobs
 to restart.

 This issue is resolved in Network Discovery plugin 2.2.1. 

 BAN-21860 

 Threads don't terminate when SNMP v3 is configured.

 This issue is resolved in Network Discovery plugin 2.2.0. 

 BAN-20264 

 After enabling OT Polling, the polling run might not start.

 This issue is resolved in Network Discovery plugin 2.2.0. 

 BAN-17265 

 The help page link errors out.

 This issue is resolved in Network Discovery plugin 2.2.1.
