 file view log 

 Use the file view log command
to display information for different types of logs. Choose or enter the
name of a log to view information for the specified log. 

 Command 

 file view log
 <log name> 

 Options 

 None 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands — 

 Introduced in Release 4.4.1
