 About
the AutoFocus API 

 The AutoFocus™ API extends the ability to query the
threat intelligence cloud through a programmatic, RESTful API. You
can integrate this API into a third-party service, application,
or script that accesses AutoFocus outside of the web portal. API responses
are in JSON or XML-based STIX format.
