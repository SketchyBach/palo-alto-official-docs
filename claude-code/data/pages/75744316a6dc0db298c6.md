 Custom Dashboards and Widgets 

 Build custom dashboards and widgets to get personalized insights into your network 
 security environment with relevant data and metrics.

 Where Can I Use This? What Do I Need? 

 Device Security (Managed by Strata Cloud Manager) 

 One of the following subscriptions: 

 Device Security subscription

 Precision AI bundle subscription

 Device Security X subscription

 Get personalized insights into your network security environment by building custom 
 dashboards and widgets. Build custom dashboards using a mix of custom widgets and 
 pre-defined system widgets to create a security monitoring interface with the data and 
 metrics most relevant to your organization. You can create custom widgets by specifying 
 the scope, the display type, and the formatting to help visualize the data. Once you've 
 defined the information you want reflected in the widgets, you can group them into 
 related views using custom dashboards.

 Custom widgets support various chart types, such as bar charts, pie charts, line graphs, 
 tables, and statistics displays. Within the charts, you can use grouping and 
 color-coding to arrange and highlight data. The various custom widget types include a 
 paragraph widget that lets you add contextual information or instructions directly 
 within your dashboards.

 By combining various types of widgets, custom dashboards provide visibility into 
 interconnected devices and data. As you build out a dashboard, you can also create 
 custom widgets within the custom dashboard interface. With the ability to create 
 multiple custom dashboards, you can monitor specific device subsets, track security 
 trends over time, and create executive-level summary views that focus on high-priority 
 metrics. A global time range feature ensures consistent temporal context across all 
 widgets within a dashboard.

 You can add the custom dashboards you build to the Dashboard tab, 
 so that you can quickly access your tailored views. Under Dashboard Manage Dashboards , select which custom dashboards 
 you want to display in the Dashboard tab. This helps you to find 
 the most important information in one location and holistically monitor your environment 
 with a focus on what's most critical for your organization.

 Get started with custom dashboards and widgets by logging into Device Security in 
 Strata Cloud Manager . Access Dashboard + New Dashboard to go 
 to the Custom Dashboard page. From here you can view the 
 Widget Library , Create a Widget , or 
 Create Dashboard from Scratch . You can also search for existing 
 dashboards in the Dashboard Library to edit or delete custom dashboard.
