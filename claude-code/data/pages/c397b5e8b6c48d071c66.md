 Restore Express Mode 

 Restore express mode on a 5G-ready, next-generation firewall
that has a K2-designated SKU if you changed from express mode to
secure mode. 

 If you take any of the following actions on
a firewall that has a K2-designated SKU and was in express mode ,
the firewall changes to secure mode: 

 You perform a Factory
Reset. 

 You downgrade to a PAN-OS ® release earlier than 9.0. 

 You follow the Return Material Authorization (RMA) procedure
for a solid-state drive (SSD) and install a new, imaged SSD. 

 If
you change the firewall to secure mode by one of those actions,
you can either purchase a secure mode upgrade or restore express
mode. 

 Restore express mode on a firewall that
has a K2-designated SKU. 

 Access the CLI. 

 > set deviceconfig setting session express-mode yes 

 View the mode of a firewall. 

 > show system info 

 The
output indicates express-mode: yes or express-mode: no .
