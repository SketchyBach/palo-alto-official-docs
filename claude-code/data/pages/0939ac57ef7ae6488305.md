 Panorama Hypervisor Support 

 Verify that you have what it takes to install Panorama™
on a hypervisor. 

 Before you deploy a Panorama™ virtual appliance, verify
that the hypervisor meets the minimum version requirements to deploy
Panorama. 

 VMX-19 is supported on Panorama running PAN-OS 11.1.5 or later on VMWare ESXi
 7.0. The supported base image for this configuration is Panorama-ESX-11.1.3.ova.
