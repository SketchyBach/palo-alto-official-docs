 New Features - Autonomous DEM - September 2024 

 ADEM Visibility for Agent-Based Proxy Traffic 

 Release Date: September 2024 
 | 
 Last Updated: June 2026 

 Previously, you had no way to monitor application performance through that specific access path using Agent-Based Proxy access in Prisma® Access. It was challenging to determine whether performance issues were related to the proxy itself or to the underlying application. ADEM now provides full visibility into application access and performance for Agent-Based Proxy traffic, giving you the context you need to troubleshoot without switching between separate monitoring tools. 

 With this integration, you can monitor performance across traffic forwarded to Prisma Access through the proxy, including traffic matched by destination, user or user group, operating system, or geographic location such as static branch egress IPs. Branches with dynamic egress IP addresses and specific geographic locations within a country are also covered. 

 You can correlate Agent-Based Proxy performance data with endpoint and network metrics to pinpoint the source of user experience degradation. Whether you need to identify a proxy-related bottleneck or confirm that an issue originates downstream, ADEM gives you a complete picture of the access path so you can troubleshoot efficiently and resolve issues faster.
