 Manage an Existing Canvas 

 Learn how to manage your Strata Cloud Manager AI Canvas: export to PDF, generate
 shareable links, and delete canvases efficiently. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 Strata Cloud Manager
 Pro license 

 Prisma Access license 

 Acceptance of the Strata Copilot SEULA for the tenant 

 Before you begin,
 view the AI Canvas Administrator Role Requirements to ensure that you have the correct administrator
 role to use AI Canvas features. 

 Export a Canvas 

 If you want to export a canvas, you can save it as a professionally formatted
 PDF. 

 Select Strata Canvas AI Canvas from Strata Cloud Manager menu. 

 Click View All Canvases if you don't see the canvas
 you want in Recent Canvases. 

 Open the canvas you want to export. 

 Click Generate Report and then Download
 Report . 

 Save as PDF or print the canvas as desired. 

 Share a Canvas 

 You can generate a shareable link that other administrators can use to quickly
 view a snapshot of a canvas. AI Canvas preserves the view of the data in the
 canvas at the time it was shared. 

 From AI Canvas, open the canvas you want to export. 

 Click Generate Report and then Share
 Report . 

 Select Copy link to save it to your clipboard and
 then Close the dialog. 

 Paste the link in your preferred communication tool of choice to send to
 the administrator. 
 The administrator must log in to the Strata Cloud Manager with their
 credentials to view the canvas snapshot.
