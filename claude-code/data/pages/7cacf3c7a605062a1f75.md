 PAN-ENTITY-EXT-MIB.my 

 Use PAN-ENTITY-EXT-MIB.my in tandem with the ENTITY-MIB to monitor power
usage for the physical components of a PA-7000 Series or PA-5450
firewall (for example, fan trays, and power supplies), which are
the only two Palo Alto Networks firewalls that support this MIB.
For example, when troubleshooting log forwarding issues, you might
want to check the power usage of the log processing cards (LPCs):
you can map the LPC indexes from the ENTITY-MIB (entPhysicalDescr
object) to values in the PAN-ENTITY-EXT-MIB (panEntryFRUModelPowerUsed
object).
