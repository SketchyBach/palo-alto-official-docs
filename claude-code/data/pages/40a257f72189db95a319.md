 INC_CIE_DIRECTORY_DISCONNECT 

 Learn about the INC_CIE_DIRECTORY_DISCONNECT incident. 

 Synopsis 

 Directory <directory-name> might be out of sync. Sync was not successful because
 the refresh token is invalid. 

 Incident Code—INC_CIE_DIRECTORY_DISCONNECT 

 Severity—High 

 Required License 

 AI-Powered ADEM 

 Details 

 Description 

 Raise condition 

 The CIE directory is out of sync. 

 Clear condition 

 The CIE directory is in sync. 

 Correlated Alerts 

 AL_CIE_DIRECTORY_DISCONNECT 

 Remediation 

 Use the information in the incident message to verify that your Okta
 configuration is valid. 

 Select Reconnect from the Actions 
 drop-down to find the domain that is experiencing the issue. 

 If these steps don't help you resolve your issue, contact the Palo Alto Networks Customer Support Portal .
