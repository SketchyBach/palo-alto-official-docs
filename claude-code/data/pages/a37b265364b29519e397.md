 Select the Types of Notifications to Send 

 You can select one or more of the following
types of notifications to send to your users. If you configure notifications
to be sent to a user group, notifications will be enabled for all
users in that group. 

 CPU 

 Memory 

 WiFi Quality 

 Internet Outage 

 Open the Monitored Mobile Users page. 

 Click the Self Serve tab. 

 In Self Serve Notification Type ,
select the type of notifications that you want to enable by selecting
the check box next to the notification type. By default, all notification
types are selected. Clear the check box next to the type of notification
you do not want to send and Save your changes.
