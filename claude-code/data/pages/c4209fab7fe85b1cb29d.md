 Install the OpenConfig Plugin 

 How to install the OpenConfig Plugin on PAN-OS. 

 (OpenConfig plugin version 2.0.1 and later) The
 plugin is automatically installed on PAN-OS version 11.0.4 and
 later. 

 (OpenConfig plugin version 2.0.2 and later) The
 plugin is automatically installed on PAN-OS version 10.2.11 and later versions
 of 10.2. 
 If you have device telemetry disabled, automatic telemetry streaming will also be disabled. 

 Download the plugin 

 Select Device Plugins . 

 Select Check Now to retrieve
a Actions list of available updates. 

 Select Download in the column
to download the plugin. 

 Alternatively, you can Upload a
packaged version of the plugin. 

 Install the plugin. 

 Select the version of the plugin and click Install in
the Actions column to install the plugin.
