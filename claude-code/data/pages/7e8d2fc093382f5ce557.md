 WildFire Appliance 

 WildFire License 

 When logging in, the WildFire appliance software CLI opens in
Operational mode. You can navigate between Operational and Configuration
modes at any time. 

 To enter Configuration mode from Operational mode, use
the configure command: 

 username@hostname> configure 
Entering configuration mode 
[edit] 
username@hostname# 

 To leave Configuration mode and return to Operational mode,
use the quit or exit command: 

 username@hostname# quit 
Exiting configuration mode 
username@hostname> 

 To enter an Operational mode command while in Configuration mode,
use the run command. For example, to show
system resources from configure mode, use run show system resources .
