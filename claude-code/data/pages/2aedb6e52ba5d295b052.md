 Changes to Default Behavior in Remote Browser Isolation 2.7 

 The following details the changes in behavior for RBI 2.7: 

 Starting in RBI 2.7, the Print (with
 Header/Footer) is no longer available in the RBI context menu. The ability to print with headers or
 footers is now part of the enhanced print options for RBI.
