 New Features - Prisma SD-WAN - August 2024 

 Incident Dampening 

 Release Date: August 2024 
 | 
 Last Updated: May 2026 

 Incident policy framework provides user defined control over system generated alerts and incidents in the network. You can use incident policy rules to suppress or escalate incidents that arise during a scheduled time period and can also change the default priority of system generated incidents to a priority level that is more aligned with the your business requirements. 

 You can now suppress incidents for a selected period of time using Incident Policies . With incident policy rules, you can specify the dampening interval during which the system suppresses events generated by resources during the specified period.

 SASE Easy Onboarding Enhancements 

 Release Date: August 2024 
 | 
 Last Updated: May 2026 

 Accelerating large-scale Prisma SD-WAN deployments and ensuring continuous SASE connectivity requires tools that minimize manual configuration and guarantee high availability. To address these needs, the easy onboarding process now includes several key enhancements: 

 Support for site templates with device pre-staging to accelerate deployment by allowing you to pre-provision sites before an ION device is physically available. 

 Support for automated BGP configuration with deployment modes that automatically configure route-map settings for various cases, including private application access and internet-only access. 

 Support for Prisma Access region redundancy by allowing connection to a secondary Prisma Access location as a backup. 

 Support for IPSec profile changes that allow you to synchronize the IPSec profile between Prisma SD-WAN and Prisma Access.

 Subscription Usage Visibility Enhancements 

 Release Date: August 2024 
 | 
 Last Updated: May 2026 

 Prisma SD-WAN subscription usage enables users to access comprehensive reports about both site and tenant bandwidth consumption. This enables users to effectively monitor bandwidth usage and facilitate the tracking and trending of monthly bandwidth utilization across all branch sites to ensure compliance with licensing agreements. 

 Previously, you could view the bandwidth usage of the top five branch sites for each month and the consolidated bandwidth usage of all sites for any month. To include enhanced consumption visibility at an application level, the Top Application Usage During Peak Utilization chart offers insights into the top 10 bandwidth consuming applications during the peak consumption period for each branch on a monthly basis. 

 You can view the top 10 application bandwidth usage over a 1 hour period (with summary) based on the selected month (previous 12 months) and the selected site, with the graph intelligently displaying the hour of aggregate bandwidth calculation, accounting for a time window of minus 30 to plus 30 minutes.
