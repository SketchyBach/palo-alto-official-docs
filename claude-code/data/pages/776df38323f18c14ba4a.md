 Learn about the INC_RN_SPN_LONG_DURATION_CAPACITY_EXCEEDED_THRESHOLD incident. 

 Incident Code 

 INC_RN_SPN_LONG_DURATION_CAPACITY_EXCEEDED_THRESHOLD 

 Title Template 

 SPN capacity exceeded 90% usage for 3 days in the last 5 days for SPN {spn_name} {initial_direction} traffic 

 Category 

 Network and Traffic 

 Subcategory 

 Site/Tunnel 

 Description 

 A Service Provider Network within the Remote Network has been operating above its designated capacity threshold for a considerable amount of time. Prolonged overutilization can result in performance degradation and potential service disruptions for users relying on this network. 

 Raise Condition 

 Incident is Raised when SPN capacity exceeded 90% usage for at least 3 days in the last 5 days for at least 4 hours a day in the given direction 

 Clear Condition 

 Incident is Cleared when SPN capacity didn't exceeded 90% usage in the last 8 days for at least 4 hours a day in the given direction
