 PAN-OS 10.1.13 Addressed Issues 

 PAN-OS® 10.1.13 addressed issues. 

 Issue ID Description 

 PAN-245701 

 Fixed an issue where snmpwalk displayed
 data port statistics incorrectly. 

 PAN-244548 

 Fixed an issue where ECMP sessions changed destination MAC addresses
 mid-session, which caused connections to be reset. 

 PAN-242561 

 Fixed an issue where GlobalProtect tunnels disconnected shortly after
 being established when SSL was used as the transfer protocol. 

 PAN-239337 

 Fixed an issue where the log_index was suspended and currupted BDX
 files flooded the index_log. 

 PAN-238769 

 ( VM-Series firewalls in FIPS-CC mode only ) Fixed
 an issue where upgrading Panorama caused all locally created Security
 policy rule actions to Deny. 

 PAN-233541 

 Fixed an issue where device group and template administrators with
 access to a specific virtual system were able to see logs for all
 virtual systems via Context Switch. 

 PAN-233191 

 ( PA-5450 firewalls only ) Fixed an issue where the Data
 Processing Card (DPC) restarted due to path monitor failure after
 QSFP28 disconnected from the Network Processing Card (NPC). 

 PAN-228323 

 Fixed an issue where a large number of Panorama management server
 cookies were created in the Redis database when the Cloud-Service
 plugin sent an authentication request every second, and logging in
 to or using Panorama was slower than expected. 

 PAN-226108 

 Fixed an issue where the masterd process was unable to
 start or stop the sysd process. 

 PAN-222188 

 A CLI command was introducted to address an issue where SNMP
 monitoring performance was slower than expected, which resulted in
 snmpwalk timeouts. 

 PAN-215430 

 Fixed an issue where Dynamic IP address NAT with SIP intermittently
 failed to convert RTP Predict sessions. 

 PAN-212553 

 Fixed an issue where the ikemgr process stopped
 responding due to memory corruption, which caused VPN tunnels to go
 down. 

 PAN-205482 

 Fixed an issue related to the configd process where
 Panorama displayed the error Server not
 responding when editing policies.
