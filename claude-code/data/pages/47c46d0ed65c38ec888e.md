 Archived or Deprecated MCP Server in Use is detected in IDE 

 Rule Details 

 Cortex AppSec Rule ID 

 APPSEC_CICD_374 

 Category - Subcategory 

 Pipeline Configuration - 3rd Party Services 

 Severity 

 CRITICAL 

 Impact 

 An MCP Server configured in a developer's IDE has been archived or explicitly deprecated by its vendor or maintainer. Archived projects receive no security patches, bug fixes, or updates. Continued use on the developer's workstation exposes both the individual and the organization to unpatched vulnerabilities.
