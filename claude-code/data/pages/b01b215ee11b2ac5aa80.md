 Setup Prequisites for Enterprise DLP FQDNs for Data Dictionaries 

 Fully Qualified Domain Names (FQDN) required to upload data dictionaries to Enterprise Data Loss Prevention (E-DLP) . 

 ( FedRAMP High only ) FedRAMP High
 Authorization — https://auth.fed.apps.paloaltonetworks.us 

 Required by FedRAMP High users to authorize Enterprise DLP functionality on
 your network. 

 Data Dictionary Uploads —The country-specific Public
 API URL and Storage Bucket FQDNs where
 you want your data dictionaries stored. 

 You must allow both FQDNs to successfully upload a data dictionary to an Enterprise DLP storage bucket.
