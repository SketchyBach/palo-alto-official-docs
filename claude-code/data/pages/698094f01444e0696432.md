 Where Can I Use This? What Do I Need?

 One of the following subscriptions: 

 Device Security subscription

 Precision AI bundle subscription

 Device Security X subscription

 The following list includes all known issues that impact a Device Security 
 Network Discovery plugin 3.2 release. This list includes both
 outstanding issues and issues that are addressed, as well as known issues that apply
 more generally or that are not identified by a specific issue ID.

 BAN-31973 

 The Network Discovery plugin failed to run WinRM OT polling jobs when the OT
 polling configuration was pushed from Panorama.

 This issue is resolved in Network Discovery 3.2.1. 

 BAN-31668 

 Network Discovery jobs continued to run after being explicitly disabled in the
 configuration.

 This issue is resolved in Network Discovery 3.2.1. 

 BAN-30326 

 WinRM OT polling traffic does not follow the configured service route.
