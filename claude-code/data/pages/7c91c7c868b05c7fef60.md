 Supported SaaS Applications on Data Security 

 Data Security provides a consistent security policy for your applications to
 detect data exfiltration and malware propagation. 

 SaaS applications are cloud apps owned and managed by
an application service provider, but you retain full control of
the data, including who can create, access, share, and transfer
information stored in the hosted application. Although most SaaS
applications allow you to configure rules about sharing and exposing
data, rules vary from application to application, which makes it
challenging to ensure consistent security policy across all applications,
assets, and users. 

 Data Security provides centralized policy and enforcement for your applications so you
 can protect your corporate data at all times. The service scans content to detect data
 exfiltration and malware propagation, monitors user activity, and provides activity-based
 alerting to notify you of malicious or risky behavior. This visibility allows you to assess
 incidents, quarantine users and data, and remediate any violations to protect against threats
 caused by malware, inadvertent sharing, excessive permissions, and data exposure. 

 The events you see for SaaS Security (either on the classic SaaS Security Console or on the new
 Strata Cloud Manager ) are of three types—legacy, new, and hybrid. All legacy connectors
 present each and every event independent of DLP match criteria. However, new connectors
 present only those events that meet the DLP match criteria. Hybrid connectors are a
 combination of new and legacy connectors. So, while some events are dependent on match
 criteria, some are not. Check your connector type in the following table to know how events
 are presented.

 also set your own limit. This rate limit is divided between
 forward and backward scans. When the rate limit reaches 60% of

 requests per second is recommended so that your forward scanning
 is not adversely affected.

 for most cloud apps. However, snippets might not be available for you if: 
 Data Security does not support snippets for your cloud app or the
 specific asset type (file vs. chat) 

 You have not set Write access for Request

 depends on the capabilities available in cloud app vendor’s public API.

 Supported SaaS Applications with Selective Scanning 

 Learn about the cloud apps and asset types that are supported
with group-based selective scanning. 

 Group-based selective scanning is available on the following cloud apps. Not all cloud apps are
 conducive to selective scanning. A cloud app must integrate with Azure Active Directory
 Services or other Identity Providers (through Cloud Identity Engine ) and must enforce file
 ownership. Many cloud apps are designed to share files with multiple owners, so they
 don’t have the necessary characteristics to work in a selective scanning framework. 

 If you want similar results for Google Drive, use OU scanning.
