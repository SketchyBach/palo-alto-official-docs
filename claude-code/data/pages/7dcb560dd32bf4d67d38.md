 INC_PA_SERVICE_DEGRADATION_PA_LOCATION 

 Learn about the INC_PA_SERVICE_DEGRADATION_PA_LOCATION incident. 

 Synopsis 

 Confirmed impact for mobile users in Prisma Access locations. All gateways in a
 location are impacted. 

 Clear statement—Confirm the Prisma Access location is able to service mobile users. 

 Incident Code—INC_PA_SERVICE_DEGRADATION_PA_LOCATION 

 Severity—Critical 

 For details about incident severity, see Incidents Distribution Over
 Time in Incidents and Alerts Overview . 

 Required License 

 Prisma Access 

 Details 

 Raise condition 

 Confirmed impact for mobile users in Prisma Access locations
 (all gateways in a location are impacted), mobile user to
 service connection connectivity is down with no alternate
 path. 

 Clear condition 

 Confirm the Prisma Access location is able to service mobile
 users.
