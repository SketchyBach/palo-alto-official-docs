 Approaching Max Capacity - Service Objects 

 Incident Code 

 INC_NGFW_CAPACITY_SERVICE_OBJECTS 

 Severity 

 Warning 

 Category 

 Device 

 Subcategory 

 System Resources 

 Product 

 Supported on NGFWs and VM-Series firewalls. 

 Description 

 The number of service objects has been consistently high and is approaching the maximum capacity the firewall can support. 

 Raise Condition 

 This incident is triggered when Service Objects usage exceed 90% of the capacity of that respective firewall model and stays beyond 90% for five days over a week 

 Clear Condition 

 This incident is cleared when Service Objects usage falls below 90% of the capacity of that respective firewall model and stays below 90% for two weeks
