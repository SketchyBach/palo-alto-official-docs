 APIs for managing dashboards 

 Get all dashboards details 

 get https://api-yourfqdn /xsoar/public/v1/dashboards 

 Retrieve details of all the dashboards in the system. Only dashboards the user has view access to are returned.

 OK

 Get dashboard details for the specified dashboard 

 get https://api-yourfqdn /xsoar/public/v1/dashboards/ {dashboard_id} 

 Use the dashboard ID to specify the dashboard you want to get details about.
