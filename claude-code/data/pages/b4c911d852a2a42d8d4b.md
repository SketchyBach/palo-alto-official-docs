 New Features - SaaS Agent Security - November 2025 

 SaaS Agent Security 

 Release Date: November 2025 
 | 
 Last Updated: May 2026 

 SaaS Agent Security addresses critical security challenges posed by AI agents in enterprise environments by providing comprehensive visibility and control over your AI agent deployments. SaaS Agent Security focuses on high-priority security concerns including agent discovery, authentication configuration, permission management, and data protection. Your data security administrators can onboard AI agent platforms to gain visibility into agent configurations, connected apps, and user access patterns. SaaS Agent Security automatically detects AI agents without proper authentication, those using excessive permissions, and connections with insecure configurations. SaaS Agent Security also offers remediations to help your data security administrators quickly address security concerns and immediately strength your security posture when deploying AI agents within your organization. 

 With SaaS Agent Security, you can view essential agent metadata including creator information, published date, access patterns, knowledge sources, allowed actions, and connected apps. Your data security administrators can identify authentication misconfigurations that could allow unauthorized access to AI agents, as well as excessive permissions that might enable AI agents to perform unauthorized actions. SaaS Agent Security detects when AI agents store plaintext credentials or sensitive tokens that could be exploited by malicious actors. Your data security administrators can use SaaS Agent Security to identify inactive AI agents that still maintain active permissions, enabling them to deactivate unused AI agents and reduce your organization's attack surface. 

 The SaaS Agent Security identity and permissions capabilities help your data security administrators understand which users have accessed AI agents and what actions they can perform. It can detect instances where AI agents enable indirect access to apps, enabling users to interact with systems they wouldn't normally have permission to access. SaaS Agent Security also identifies over-privileged connections between agents and SaaS apps, helping you enforce least-privilege principles. SaaS Agent Security can monitor agent-to-SaaS connections for authentication issues and receive notifications when security posture problems are detected, enabling quick remediation of potential vulnerabilities.
