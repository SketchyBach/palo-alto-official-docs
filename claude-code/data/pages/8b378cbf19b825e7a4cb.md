 Custom Roles Overview 

 Next-Gen Trust Security includes two built-in roles: Superuser (full access) and View Only Admin (read-only access). Create custom roles when you need more granular access control. 

 When to Use Custom Roles 

 Create custom roles to: 

 Limit users to specific tasks (certificate requests, approvals, reporting) 

 Implement least-privilege access 

 Replicate Certificate Manager, SaaS roles (Resource Owner, certificate-only operators) 

 Delegate administrative functions without granting full Superuser access 

 How Custom Role Permissions Work 

 Custom role permissions mirror the Next-Gen Trust Security UI navigation hierarchy. Permissions are organized into four categories: 

 Insights - Dashboards, certificate inventory, requests, installations 

 Configuration - Certificate authorities, policies, integrations, notifications 

 Settings - Event logs, licensing, built-in accounts 

 Super Approval - Approve actions without being on approvers lists 

 Your effective permissions are the intersection of your role and TSG membership. Role permissions apply only to resources in your assigned TSG. 

 Example Custom Roles 

 Certificate Operator 

 Allows requesting and downloading certificates only. 

 Permissions: 

 Certificate Requests ( ngts.insights_certificate_requests ) 

 Certificates ( ngts.insights_certificate_inventory ) 

 Request Policies ( ngts.configuration_issuing_templates ) 

 Use case: Developers who need certificates but shouldn't manage infrastructure. 

 Resource Manager 

 Manages certificates and installations within a child TSG. Cannot modify system-wide configuration. 

 Permissions: 

 Certificate Insights group ( ngts.insights_certificate_insights_group ) 

 Certificate Inventory group ( ngts.insights_certificate_inventory_group ) 

 Certificate Installations group ( ngts.insights_certificate_installations_group ) 

 Auto-Renewal ( ngts.configuration_auto_renewal ) 

 Certificate Lifecycle ( ngts.configuration_certificate_lifecycle ) 

 Use case: Replaces Certificate Manager, SaaS Resource Owner role for child TSG users. 

 Approval Manager 

 Reviews and approves certificate requests and revocations only. 

 Permissions: 

 Certificate Requests Approval ( ngts.insights_certificate_requests_approval ) 

 Certificate Revocation Approval ( ngts.insights_certificate_inventory_approve_revocation ) 

 Certificates - read only ( ngts.insights_certificate_inventory ) 

 Approval Rules - read only ( ngts.configuration_approval_rules ) 

 Use case: Security or compliance teams participating in approval workflows. 

 Create a Custom Role 

 Create custom roles in Strata Cloud Manager, not in the Next-Gen Trust Security UI. 

 Sign in to Strata Cloud Manager. 

 Go to Settings > Identity & Access > Roles . 

 Select Add Role > Custom Role . 

 Select Next-Gen Trust Security as the application. 

 Select the required permissions. 

 Assign the role to users in their TSG. 

 For detailed instructions, see Add a Custom Role Through Common Services . 

 Permission Reference 

 Insights Permissions 

 Certificate Insights ( ngts.insights_certificate_insights_group ) 

 Provides access to certificate insight dashboards and reports, including 47-day readiness, TLS certificates, and custom reports. 

 Permission Description 

 ngts.insights_47_day_readiness Provides access to the 47-Day Readiness Dashboard. 

 ngts.insights_tls_certificates Provides access to the TLS Certificates Dashboard. 

 ngts.insights_custom_reports Allows managing custom reports. 

 Certificate Inventory ( ngts.insights_certificate_inventory_group ) 

 Provides access to certificate inventory pages, including certificates, requests, endpoints, and keys. 

 Permission Description 

 ngts.insights_certificate_inventory Allows managing certificates. 

 ngts.insights_certificate_inventory_approve_revocation Allows approving or rejecting certificate revocation requests. 

 ngts.insights_certificate_requests Allows managing certificate requests. 

 ngts.insights_certificate_requests_approval Allows approving or rejecting certificate requests. 

 ngts.insights_tls_server_endpoints Allows managing TLS server endpoints. 

 ngts.insights_issuer_certificates Allows managing workload identity issuer certificates. 

 ngts.insights_signing_keys Allows managing codesign signing keys. 

 ngts.insights_acme_orders Allows managing ACME orders. 

 ngts.insights_trusted_ca_certificates Allows managing trusted CA certificates. 

 ngts.insights_applications Allows managing applications. 

 ngts.certificate_assign Allows assigning unassigned certificates to a TSG and unassigning them. In a child TSG, this permission also controls whether the user can see unassigned certificates. Users without it see only certificates assigned to their own TSG. 

 Certificate Installations ( ngts.insights_certificate_installations_group ) 

 Provides access to certificate installation pages, including cloud keystores, credentials, Kubernetes clusters, and machines. 

 Permission Description 

 ngts.insights_cloud_keystores Allows managing cloud keystores. 

 ngts.insights_credentials Allows managing credentials. 

 ngts.insights_kubernetes_installation Allows managing Kubernetes clusters. 

 ngts.insights_machines_page Allows managing machines. 

 Configuration Permissions 

 Certificate Configurations ( ngts.configuration_certificate_configurations_group ) 

 Provides access to certificate configuration pages, including ACME servers, issuer configurations, network discovery, and certificate tags. 

 Permission Description 

 ngts.configuration_acme_servers Allows managing ACME servers. 

 ngts.configuration_issuer_configurations Allows managing workload identity issuer configurations. 

 ngts.configuration_network_discovery Allows managing network discovery. 

 ngts.configuration_certificate_tags Allows managing certificate tags. 

 Certificate Policies ( ngts.configuration_certificate_policies_group ) 

 Provides access to certificate policy pages, including approval rules, issuer providers, and lifecycle policies. 

 Permission Description 

 ngts.configuration_approval_rules Allows managing approval rules. 

 ngts.configuration_issuer_sub_ca_providers Allows managing workload identity sub CA providers. 

 ngts.configuration_auto_renewal Allows managing auto-renewal configurations. 

 ngts.configuration_certificate_lifecycle Allows managing the certificate lifecycle. 

 ngts.configuration_issuing_templates Allows managing request policies. 

 ngts.configuration_workload_issuance_policies Allows managing issuance policies. 

 Certificate Integrations ( ngts.configuration_certificate_integrations_group ) 

 Provides access to certificate integration pages, including certificate authorities, cloud providers, and credential managers. 

 Permission Description 

 ngts.configuration_certificate_authorities Allows managing certificate authorities. 

 ngts.configuration_cloud_providers Allows managing cloud providers. 

 ngts.configuration_credential_managers Allows managing credential managers. 

 ngts.configuration_vsatellites Allows managing VSatellites. 

 Certificate Notifications ( ngts.configuration_certificate_notifications_group ) 

 Provides access to certificate notification pages, including providers, rules, branding, and templates. 

 Permission Description 

 ngts.configuration_notification_providers Allows managing notification providers. 

 ngts.configuration_notification_rules Allows managing notification rules. 

 ngts.configuration_notification_branding Allows managing notification branding. 

 ngts.configuration_notification_templates Allows managing notification templates. 

 Settings Permissions 

 Certificate Settings ( ngts.settings_certificate_settings_group ) 

 Provides access to certificate settings pages, including event logs, licensing, and built-in accounts. 

 Permission Description 

 ngts.system_settings_event_log Provides access to event logs. 

 ngts.insights_licensing Allows managing licensing. 

 ngts.settings_builtin_accounts Allows managing built-in accounts. 

 Super Approval Permissions 

 Super Approval ( ngts.super_approval_group ) 

 Allows approving or rejecting any action requiring approval. Skips additional approval steps if needed. 

 Permission Description 

 ngts.insights_certificate_inventory_super_approval_revocation Allows approving or rejecting certificate revocation requests, even if not on the approvers list. 

 ngts.insights_certificate_requests_super_approval Allows approving or rejecting certificate requests, even if not on the approvers list. 

 Warning: Super Approval permissions bypass approval workflows. Assign sparingly. 

 Best Practices 

 Use built-in roles when possible. Create custom roles only for specific requirements. 

 Grant minimum necessary permissions (least privilege). 

 Test custom roles in a child TSG before organization-wide deployment. 

 Document each custom role's purpose and intended users. 

 Review role assignments regularly as organizational needs change. 

 Remember that role permissions apply only within the user's assigned TSG.
