 ION 9000 Front Panel with LEDs 

 Learn about the various LEDs lights on the ION 9000 and
its status. 

 The ION 9000 LEDs indicate the following: 

 Icons Description 

 Displays power status 

 Green light—Powered on. 

 Black
light—Powered off. 

 Displays Controller connectivity status 

 Blue light—Connected. 

 No
light—Not Connected. 

 Displays disk status 

 Orange light (blinking)—Displays disk activity. 

 HA LED 

 Off—Not configured. 
 Solid Green—Active with
connected backup. 

 Green
(blinking)—Active without backup. 

 Solid
Red—Standby. 

 Red
(blinking)—Failed.
