 Prisma Agent Release Information 

 Release information is provided to help you stay up-to-date with the latest features
 and known issues in the Prisma Agent . 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Panorama or Strata Cloud Manager) 

 NGFW (Managed by Panorama) 

 Check the prerequisites for the
 deployment you're using 

 Contact your Palo Alto Networks account representative to
 activate the Prisma Agent feature 

 The Prisma Agent is a next-generation mobile access agent
 that allows you to use Prisma Access to secure your mobile workforce. The Prisma Agent delivers secure and convenient access to both enterprise apps
 and the internet, and also simplifies network, IT, and security operations for your
 organization. 

 Review the release information to stay up-to-date with the latest issues with the Prisma Agent .
