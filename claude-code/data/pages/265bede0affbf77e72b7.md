# Discover the new Privilege Cloud experience: Smarter navigation as part of the Identity Security Platform spaces

Discover the new Privilege Cloud experience: Smarter navigation as part of the Identity Security Platform spaces
NEW
August 27, 2026

Privilege Cloud (PAM SaaS) pages are now consolidated into dedicated spaces—Access, Manage, Audit and Reports, and Setup—making daily navigation faster and more intuitive.

What's New:

Streamlined workspace: Easily access Privilege Cloud (PAM SaaS) pages in clear, task-oriented spaces—Access, Manage, Audit and Reports, and Setup—making daily navigation faster and more intuitive.
Unchanged functionality: Enjoy an upgraded interface while keeping all existing Privilege Cloud tools, permissions, and workflows exactly as they are.
Dark mode support: A refreshed visual experience designed to reduce eye strain during extended admin sessions.

After the release, the new and current layouts will run side-by-side so you can explore the redesign at your own pace without interrupting your current workflow.
