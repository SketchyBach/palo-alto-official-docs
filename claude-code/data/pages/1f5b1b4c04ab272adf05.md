 Get Started with the AutoFocus API 

 To use the AutoFocus API™, first get your API key through
the Palo Alto Networks Customer Service Portal .
You can then use your API key to test a simple API call. 

 To use the AutoFocus API with Python, refer to the pan-python page on GitHub , which provides a
Python and command line interface for AutoFocus. View the corresponding Python
syntax for initiating searches for samples, sessions, and
aggregate data. You can also use the AutoFocus Python library ,
which provides an object-oriented interface into AutoFocus.
