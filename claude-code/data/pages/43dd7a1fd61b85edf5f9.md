 Cloud service provider (CSP) onboarding 

 Learn about onboarding your cloud service provider to Cortex Data Security. 

 Connect your cloud service provider (CSP) from the Data Sources & Integrations page. Onboarding creates a unified, normalized inventory of your cloud assets. This inventory gives you visibility and context for incident investigations. 

 Cortex Data Security supports onboarding these cloud service providers: 

 Amazon Web Services (AWS) 

 Microsoft Azure 

 Google Cloud Platform (GCP) 

 Oracle Cloud Infrastructure (OCI) 

 Onboarding has two phases: 

 Configure the authentication template in Cortex Data Security. 

 Deploy the template in your CSP environment. 

 Review your provider's prerequisites before starting. Then complete the provider-specific onboarding workflow. For end-to-end cloud service provider permission onboarding, see Cloud service provider (CSP) onboarding .
