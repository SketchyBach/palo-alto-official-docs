 Cortex Cloud licensing updates 

 The updated Cortex Cloud license reporting provides transparent and standardized calculations for billable workload units across VMs, containers, databases, and serverless functions. This enhancement ensures better transparency and clarity to your workload utilization by eliminating duplicate counting of workloads discovered by multiple sources and by metering consumption using a 90-day rolling average. This enables you to gain better control over your licenses through optimized quota usage rules, such as workload spill over between Cortex Cloud Posture and Cortex Cloud Runtime licenses, and access to full consumption details via the Public API for internal financial tracking.
