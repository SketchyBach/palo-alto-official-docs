 Application Security 

 The Application Security logs contain information to help you monitor and investigate
 threats found in your Application network traffic. 

 See the following for information related to supported log formats: 

 Application Security CEF Fields 

 Application Security EMAIL Fields 

 Application Security HTTPS Fields 

 Application Security LEEF Fields 

 APPLICATION SECURITY Field

 (Display Name)

 Description

 (ACTION)

 CEF field name: Action

 HTTPS field name: TRUE 

 LEEF field name: Custom

 CEF field name: Application
