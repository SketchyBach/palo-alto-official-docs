 INC_CIE_AGENT_DISCONNECT 

 Learn about the INC_CIE_AGENT_DISCONNECT incident. 

 Incident Code 

 INC_CIE_AGENT_DISCONNECT 

 Title Template 

 Agent {agent_id} is disconnected in CIE instance {cie_instance_name}. 

 Category 

 Network Services 

 Subcategory 

 Authentication 

 Description 

 The Cloud Identity Engine (CIE) agent has disconnected or lost connectivity. The CIE agent plays a crucial role in establishing secure connections and enforcing policies within the Prisma Access environment. When the CIE agent disconnects, it can lead to authentication and policy enforcement issues, impacting the security and functionality of the network. It is important to investigate and resolve the disconnection of the CIE agent promptly to ensure the continued security and performance of the Prisma Access environment. 

 Raise Condition 

 Incident is Raised when the agent for the CIE instance is disconnected 

 Clear Condition 

 Incident is cleared when the agent for the CIE instance is connected
