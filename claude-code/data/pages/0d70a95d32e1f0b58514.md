 Required Data 

 XDR Agent 

 Detector Tags 

 AppleScript Analytics, Evasion Analytics 

 ATT&CK Tactic 

 Execution (TA0002), Defense Impairment (TA0112) 

 ATT&CK Technique 

 Command and Scripting Interpreter: AppleScript (T1059.002), Disable or Modify Tools (T1685), Subvert Trust Controls (T1553) 

 Severity 

 Low 

 Description 

 The AppleScript interpreter executed a command to modify system configuration, bypass security controls, or evade detection. 

 Attacker's Goals 

 Employ defense evasion techniques by modifying system configurations and disabling or bypassing security tools. 

 Investigative actions 

 Analyze the command line and determine whether it performs any malicious or suspicious actions. 

 Check the events generated by the process or its children for potential malicious behavior. 

 Verify the legitimacy of the defense evasion technique being employed.
