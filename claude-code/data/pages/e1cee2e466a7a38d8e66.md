 Uninstall the ZTP Plugin 

 Uninstall the ZTP plugin from your Panorama™ management
server. 

 Where Can I Use This? What Do I Need? 

 NGFW (Managed by Panorama) 

 Device management license 

 Support license 

 Follow the procedure to remove the ZTP configuration
from your Panorama™ management server and uninstall the ZTP plugin.
If your Panorama is in a high availability (HA) configuration, repeat
these steps on both Panorama HA peers. 

 Log in to the Panorama web
 interface . 

 Delete the ZTP installer administrator account. 

 Select Panorama Administrators and select the ZTP installer administrator
account you previously configured. 

 Delete the ZTP installer administrator
account. 

 Select Panorama Administrators and select the installeradmin admin
role. 

 Delete the installeradmin admin
role. 

 Select Commit and Commit
to Panorama . 

 Uninstall the ZTP plugin 

 Select Panorama Plugins and navigate to the
ZTP plugin installed on Panorama. 

 In the Actions column, Remove Config to
delete ZTP related configurations from Panorama 

 Click OK when prompted to confirm
removing the ZTP configuration from Panorama. 

 Select Commit and Commit
to Panorama . 

 Uninstall the ZTP plugin. 

 Click OK when prompted to uninstall
the ZTP plugin from Panorama.
