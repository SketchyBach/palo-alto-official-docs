 Introduction to Cortex XSOAR 8 migration 

 Learn about migrating from Cortex XSOAR 6 to Cortex XSOAR 8. 

 Cortex XSOAR 8 has been designed to deliver improved performance and reliability. While Cortex XSOAR 8 is largely based on Cortex XSOAR 6, changes are detailed in Cortex XSOAR 8 Feature Changes . 

 Cortex XSOAR 8 SaaS is highly scalable, based on a revamped cloud-native microservice architecture. Palo Alto Networks manages performance and scaling, enabling you to focus on investigation and response. It runs on the Google Cloud Platform (GCP) and is available in multiple deployment regions. 

 For the latest Cortex XSOAR 8 SaaS features, see Cortex XSOAR 8 SaaS Release Notes . 

 You can migrate the following: 

 Cortex XSOAR 6 On-prem to Cortex XSOAR 8 SaaS migration 

 Cortex XSOAR 6 Multi-Tenant to Cortex XSOAR 8 SaaS Multi-Tenant migration 

 The migration wizard previously available to migrate from Cortex XSOAR 6 to Cortex XSOAR 8 is no longer supported. You can manually migrate to Cortex XSOAR 8 using the instructions in this guide.
