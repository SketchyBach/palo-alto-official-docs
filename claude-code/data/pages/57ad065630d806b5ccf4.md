 Assign App Permissions 

 Learn how to assign individual app permissions to users. 

 Some apps that support custom role creation
also allow you to assign individual permissions to users. This kind
of access control is useful when you want to grant specific permissions
to a few users without having to create a new role. 

 Log in to the Activation Console and select 

 Access Management . 

 Select the users to whom you want to assign permissions. 

 Click Assign Roles . 

 Select the app for which you want to assign permissions. 

 Not all apps support permission assignment. 

 Click the dropdown of the app instance for which you
want to grant the users permissions. 

 Select Assign Permission . 

 Select permissions to grant the users. 

 Save your selection. 

 ( Optional ) Select Save As New Role if
you would like to reuse the set of permissions that you selected. 

 Ensure that you successfully assigned permissions to
the users. 

 The dropdown of the instance should display the number
of permissions you assigned the users and a button to Edit permissions.
