 Configure a PAC File on AWS WorkSpace Clients 

 Using a PAC file is one method of securing internet traffic from AWS
 WorkSpaces. 

 One method of securing internet traffic from Amazon WorkSpaces is by using a proxy
 auto-configuration (PAC) file. A PAC file is JavaScript code that tells a web
 browser how to connect to a proxy server. Enterprise environments employ PAC files
 to control web traffic and enforce Security policy rules. A web server usually
 stores the PAC file, and the web browser downloads the PAC file when it starts
 up. 

 If you have not already, set up Prisma SASE Explicit
 Proxy . 

 You can either host a PAC file in Prisma SASE or the web server. Verify the
 PAC server is reachable from WorkSpace clients by accessing the PAC URL
 using a web browser. 

 Customize the Prisma SASE Explicit Proxy PAC file to update the Proxy FQDN and
 to define exclusions. 

 From Strata Cloud Manager, select Configuration NGFW and Prisma Access Configuration Scope Prisma Access Explicit Proxy Forwarding Rules 

 . 

 Edit the PAC file according to the PAC file guidelines . 

 Download Prisma SASE Explicit Proxy root
 certificates to install on the AWS WorkSpace . 

 Install the certificate on the AWS
 WorkSpace client to apply user-based policy rules, traffic inspection, and
 reporting. 

 This will allow the WorkSpace client to communicate with Prisma SASE Explicit
 Proxy. 

 Configure the PAC file on AWS WorkSpace. 
 The way that you do this depends on the browser you using. 
 Google Chrome: 
 Open Chrome. 

 Select the three dots in the upper right corner of the
 window. 

 Select Settings . 

 Select Advanced . 

 Under System , select Open
 proxy settings . 

 In the Local Area Network (LAN) Settings window, select
 Use automatic configuration
 script . 

 In the Address field, enter the URL of
 your PAC file. 

 Select OK to save your changes. 

 Firefox 
 Open Firefox. 

 Select the three lines in the upper right corner of the
 window. 

 Select Options . 

 Select Advanced . 

 In Network , select
 Settings . 

 In the Connection Settings window, select
 Automatic proxy configuration
 URL . 

 In the URL field, enter the URL of your
 PAC file. 

 Select OK to save your changes. 

 When you have applied the PAC file, Chrome and Firefox will use it to
 determine which proxy server to use for each website. 

 Restart the AWS WorkSpace
 browser . 
 After the WorkSpace browser restarts, it will pick up the new PAC file and
 start routing traffic through the Prisma SASE proxy. 

 Test and verify the traffic flow. 

 Once you have configured the WorkSpace clients to use the Prisma SASE
 Explicit Proxy, you can test the traffic flow by validating the certificate
 in the browser and viewing logs on Prisma Access . 

 If using Google Chrome, select the padlock in the address bar. 

 Select Connection is secure . 

 Select Certificate is valid . 

 Verify the correct certificate details that appear in the
 pop-up. 

 If using Safari, select the padlock icon in the address bar. 

 Select Connection secure . 

 Select More information . 

 Select View Certificate . 

 Verify the correct certificate details that appear in the
 pop-up.
