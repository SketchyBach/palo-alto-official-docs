 Associated Content and Software Versions for PAN-OS 12.1 

 What content and software versions are associated with PAN-OS 12.1. 

 The following minimum software and content release versions are compatible with PAN-OS 12.1. To
 see a list of the next-generation firewall models that support PAN-OS 12.1, see the
 Palo Alto Networks Compatibility Matrix . 

 Palo Alto Networks Software
or Content Release Version 

 Minimum Compatible Version with PAN-OS 12.1 

 Panorama 

 12.1 

 User-ID Agent 

 11.0 

 Terminal Services (TS) Agent 

 11.0 

 GlobalProtect App 

 6.0 

 Applications and Threats Content Release Version 

 9007 

 For PAN-OS 12.1, most plugins are bundled with the software package. The following
 plugins are part of the PAN-OS 12.1 package and available for installation from Panorama Plugins . The Compatibility Matrix Plugins provides details
 on plugin availability for other releases. 

 Beginning with PAN-OS 12.1.2, plugins are bundled with the software package. The
 compatible plugins are automatically downloaded with the Panorama image, and you can
 directly install the ones you need Panorama Plugins . The Compatibility Matrix Plugins provides details
 on plugin availability for other releases.
