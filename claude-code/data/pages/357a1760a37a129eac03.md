 Monitor Performance of Auto Scaling Through the ASC Support View 

 Learn how to monitor the performance of auto scaling through the ASC Support View . 

 Where Can I Use This? What Do I Need? 

 ASC Support View 

 Customer Support Portal role: ASC 

 Identity & Access
 role : Tier 1 Support 

 If you have the necessary roles, you can view auto scaling performance of the tenants,
 connections, and instances you support. To view this information, access the ASC Support View and select Monitor Performance Auto Scaling . 

 You can filter on any tenant where you have any role, and the time range of interest. The
 tenant region is displayed for convenience. The tenant chosen is persistent as you
 navigate through the other monitoring menus. 

 You can specify to view the following types of connections: 

 RN — remote networks 

 MU — mobile users 

 SC — service connections 

 You can specify the following types of instances: 

 Firewalls
