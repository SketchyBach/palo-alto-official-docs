 Increase CPUs and Memory for Panorama on Google Cloud Platform 

 How to increase the virtual CPU cores and memory for
a Panorama™ management server on Google Cloud Platform. 

 For the minimum CPUs and memory that Panorama™
requires, see Increase
CPUs and Memory on the Panorama Virtual Appliance . 

 Log in to the Google Cloud Console . 

 Stop the Panorama virtual appliance instance. 

 Select the Panorama virtual appliance instance
in the Products & Services menu ( Compute
Engine VM Instances ). 

 Stop the Panorama virtual appliance
instance. It can take 2 to 3 minutes for the Panorama virtual appliance
to completely shut down. 

 Reconfigure the Panorama virtual appliance resources. 

 Edit the Panorama
virtual appliance instance details. 

 Under Machine Type, Customize the
Panorama virtual appliance CPU cores and memory. 

 Save the changes to update the
Panorama virtual appliance instance. 

 Start the Panorama virtual appliance.
