 Rule Details 

 Cortex AppSec Rule ID 

 APPSEC_AZURE_188 

 Category - Subcategory 

 Public Exposure - Resource Health 

 Provider 

 AZURE 

 Severity 

 LOW 

 Framework 

 Terraform, Terraform Plan 

 Impact 

 Azure App Configuration is a managed service that helps developers centralize their application configurations simply and securely. 

 Using the standard SKU for Azure App Configuration provides a variety of benefits, such as more requests per second, higher level of availability, disaster recovery, and advanced security features. 

 This rule ensures that Azure App Configuration uses the 'standard' SKU to benefit from these advanced features.
