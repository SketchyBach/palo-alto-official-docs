 Create an SD-WAN Network Template 

 Create an SD-WAN template to contain all the networking configuration for
 your SD-WAN devices. 

 Where Can I Use This? What Do I Need? 

 NGFW 

 Advanced SD-WAN for NGFW 

 Create a template containing all the networking configuration objects for your SD-WAN hubs and branches. You must create a separate template and
 template stack for your hub firewalls and a separate template and template stack for
 your branch firewalls. It is a best practice to limit the number of templates and
 template stacks used to manage your SD-WAN device configuration.
 Limiting the number of templates and template stacks used across all hubs and
 branches greatly reduces the operational overhead of managing the configurations of
 multiple SD-WAN hubs and branches. Use template or template stack variables to
 help reduce the number of templates used. 

 Log in to the Panorama Web
 Interface . 

 Create the SD-WAN hub network template. 

 Select Panorama Templates and Add a new template. 

 Enter a descriptive Name for the template. 

 ( Optional ) Enter a Description for the
 template. 

 Click OK to save your configuration changes.

 Create a hub template stack. 

 Select Panorama Templates and click Add
Stack to add a new template stack. 

 Enter a descriptive Name for
the template stack. 

 ( Optional ) Enter a Description for
the template. 

 Add the SD-WAN network template
 you created in the Step 2 . 

 In the Devices section, select the check boxes
 for all your SD-WAN hub firewalls. 

 Click OK to save your configuration
changes. 

 Create the SD-WAN branch network template. 

 Add a new template. 

 Enter a descriptive Name for the template. 

 ( Optional ) Enter a Description for the
 template. 

 Click OK to save your configuration changes.

 Create a branch template stack. 

 Click Add Stack to
add a new template stack. 

 Enter a descriptive Name for
the template stack. 

 ( Optional ) Enter a Description for
the template. 

 Add the SD-WAN network template
 you created in the Step 4 . 

 In the Devices section, select the check boxes
 for all your SD-WAN branch firewalls. 

 Click OK to save your configuration
changes. 

 Commit your configuration changes.
