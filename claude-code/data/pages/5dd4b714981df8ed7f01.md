 PAN-OS 10.1 IPSec Cipher Suites 

 List of cipher suites supported for IPSec on firewalls
running PAN-OS® 10.1 in normal operation mode. 

 The following table lists the cipher suites for IPSec
that are supported on firewalls running a PAN-OS® 10.1 release in
normal (non-FIPS-CC) operational mode. 

 If your firewall is running in FIPS-CC mode, see the
list of PAN-OS
10.1 Cipher Suites Supported in FIPS-CC Mode .
