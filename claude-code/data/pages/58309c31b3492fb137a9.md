 Reference C: Technical background 

 The following sections provide foundational context on how the system calculates lineage and how the inventory interacts with other console dashboards. 

 Core concept: The single bidirectional field 

 The Unified Asset Inventory carries software lineage in a single, bidirectional field: Development Cycle Stages. 

 How It Works: This single field records the furthest stage an asset's lineage has been traced to 

 Context-aware direction: Direction is inherited automatically from the Class filter you are looking at. You do not need to specify forward or backward tracing; the inventory infers this from context 

 Tracing starts at Code/Build and reaches toward Runtime when looking at the Code Class (Forward). 

 Tracing starts at Runtime/Deploy and reaches toward Code when looking at the Compute Class (Backward) 

 The four stages and dropdown behavior 

 The Development Lifecycles filter offers four values representing the chronological software lifecycle: Code → Build → Deploy → Runtime. 

 Code : Source code repositories 

 Build : Build pipelines and CI/CD runs 

 Deploy : Container registries, deployment packages, and IaC definitions 

 Runtime : Running compute workloads in production 

 UI order alert: In the filter dropdown list, these values are listed alphabetically: Build, Code, Deploy, Runtime. This does not reflect chronological lineage progression. Do not read lineage sequence from the dropdown list order. 

 Troubleshooting empty tables 

 If a lineage filter unexpectedly returns an empty table, check these three common causes in order: 

 Value logic is set to AND : Ensure multiple filter criteria are joined by OR 

 The tracing Job has not run: If an asset was recently onboarded, its lineage stage is empty (NULL). An untraced filter (Not Contains) cannot capture it until the tracing job analyzes it 

 Incorrect table context : Confirm your filter matches the asset class. For example, applying Contains Code on a Code table is redundant and will not show forward tracing
