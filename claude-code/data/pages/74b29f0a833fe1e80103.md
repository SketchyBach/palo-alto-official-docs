 Operating System (OS) Compatibility 

 Review the OS compatibility details for the Windows User-ID™
agent 11.0 release. 

 Install the Windows-based User-ID™ agent 11.0 release
on a host computer that is running a supported OS version and then
connect the User-ID agent to a directory server that is also running
a supported OS version to enable the agent to monitor and obtain
IP address-to-username mapping information. 

 The User-ID agent is compatible with PAN-OS® 11.0 and earlier PAN-OS releases that Palo Alto
 Networks® still supports. To see where you can install the User-ID™ agent and
 which servers it can monitor , see additional
 compatibility information in the Palo Alto Networks Compatibility Matrix . 

 Before upgrading your User-ID Agent to version 11.0.2 or later
 versions, refer to this Knowledge Base article . Refer to this Knowledge Base article for upgrading User-ID
 Credential Agent and User-ID Agent.
