 Notification Profiles 

 Contains details about how to create and enable Notification Profile. 

 Notification Profiles provide a structured way to control how incidents generated in
 Prisma SASE are transmitted to ServiceNow. You can configure the delivery method,
 such as email, webhook, or ServiceNow incidents. 

 Create Notification Profile 

 To create a notification profile, perform the following: 

 Select Prisma SASE App for ServiceNow Incident Settings Notification Profiles New . 

 Specify a Profile Name . 

 For the ServiceNow Configuration , search and choose
 the ServiceNow Credentials that belong to this tenant. 

 Configure the required notification methods: 

 Select ServiceNow Profile Details to review the
 ServiceNow tables and Prisma SASE fields mapping, and modify them if
 needed. 

 Select Email Address and specify the email to which
 the incident notification must be sent. 

 Select Webhook and specify the webhook
 details. 

 Webhooks are custom HTTP callbacks that you define. They are
 triggered by an event, such as pushing code to a repository or posting a
 comment on an issue. When the event occurs, the source app makes an HTTP
 request to the URI configured for the webhook. 

 Select Incident Settings and configure the following
 to customize the incidents for which notification must be generated. 

 Specify a Settings Name for the Incident
 settings. 

 Specify the Owner email address of the user
 who can create or update the incident settings. 

 Select the Categories , Sub
 Categories , and Codes . 

 Select Tenants and select all the tenants to which
 the notification profile should apply. 

 Submit the notification profile configuration. 

 Enable the Notification Profile 

 The notification profiles are disabled by default. Hence, after creating the
 notification, you must enable the notification profile. 

 To enable the notification profile, perform the following: 

 Select Prisma SASE App for ServiceNow Incident Settings Notification Profiles . 

 Select the notification profile you want to enable. 

 Select enabled from the State dropdown. 

 Submit the updates.
