 Use an existing policy to create a new cloud workload policy 

 Duplicate an existing Cortex XSIAM cloud workload policy to reuse and modify its conditions, scope, and actions. 

 Navigate to Posture Management → Rules & Policies → Policies → Cloud Workload . 

 In the Cloud Workload Policies page, click the policy you want to enable or disable. 

 In the Details page, click the More Options icon ( ⋮ ) and then select Save as new . 

 Modify the necessary fields in the Policy Name, Conditions, Scope, and Actions screens. 

 Click Done to create the new custom policy.
