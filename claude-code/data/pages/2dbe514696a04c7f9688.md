 Terminal Server (TS) Agent 11.0 Release Information 

 The following information applies to all current 11.0 releases. 

 Changes to Default Behavior 

 The Terminal Server (TS) Agent 11.0 release has no changes to default
 behavior. 

 Known Issues 

 There are no known issues associated with the Terminal Server agent 11.0
 release. 

 For recent updates to known issues for a given PAN-OS release, refer to
 https://live.paloaltonetworks.com/t5/Integration-Articles/Critical-Issues-Addressed-in-PAN-OS-Releases/ta-p/52882 .

 The following information is specific to the 11.0.4 TS agent release. 

 TS Agent 11.0.4 Addressed Issues 

 The following table lists any issues that are fixed in the TS agent 11.0.4
 release. 

 Issues Descriptions 

 WINAGENT-1137 

 Fixed an issue that caused installation to silently fail. For
 more information, refer to the following link: KCSArticleDetail?id=kA1Ki000000k9gwKAA 

 Terminal Server (TS) Agent 11.0.3 Release Information 

 The following information is specific to the 11.0.3 TS agent release. 

 TS Agent 11.0.3 Addressed Issues 

 The following table lists any issues that are fixed in the TS agent 11.0.3
 release. 

 Issues Descriptions 

 WINAGENT-1122 

 Fixed an issue where after upgrading to the 11.0.2 version of
 the TS agent, the policy rules for the TS AppID
 (paloalto-terminal-svcs-agent) traffic were not matched
 correctly, resulting in dropped traffic. 

 Terminal Server (TS) Agent 11.0.2 Release Information 

 The following information is specific to the 11.0.2 TS agent release. 

 TS Agent 11.0.2 Addressed Issues 

 The following table lists any issues that are fixed in the TS agent 11.0.2
 release. 

 Issues Descriptions 

 WINAGENT-1032 

 Fixed a memory leak issue in TS agent caused by mismatched
 certificate between NGFW and TS agent, preventing the agent
 from functioning. 

 Terminal Server (TS) Agent 11.0.1 Release Information 

 The following information is specific to the 11.0.1 TS agent release. 

 TS Agent 11.0.1 Addressed Issues 

 The following table lists any issues that are fixed in the TS agent 11.0.1
 release. 

 Issue Description 

 WINAGENT-890 

 Fixed an issue where the User-ID agent and TS agent
 certificates were set to expire on November 18, 2024. With
 this fix, the expiration date has been extended to January
 2032. 

 Terminal Server (TS) Agent 11.0.0 Release Information 

 The following information is specific to the 11.0.0 TS agent release. 

 Features Introduced in TS Agent 11.0.0 

 The Terminal Server (TS) Agent 11.0.0 release includes the following new
 feature. 

 New Feature 

 Description 

 Windows Server 2022 and Windows 11 Enterprise
 Edition 

 You can now install the TS agent on the Windows Server 2022
 and Windows 11 Enterprise Edition operating systems. 

 Upgrade the TS Agent 

 Refer to the following documentation before upgrading your TS Agent: Palo Alto Networks Knowledge Base .
