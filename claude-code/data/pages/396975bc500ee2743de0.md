 Connect Power to a PA-220 Firewall 

 PA-220 firewall power connection overview. 

 The PA-220 firewall is powered by an
external power adapter that converts an AC power source to DC power.
The firewall can operate with one power adapter or you can install
a second power adapter for power redundancy.
