 PA-50R Series Firewall Miscellaneous Specifications 

 PA-54R-POE and PA-54R-POE-D-5G 

 Learn how to mount the PA-54R-POE and PA-54R-POE-D-5G firewalls on a
 wall. 

 The following table lists the items included in the PAN-PA-54R-WALL-MNT kit. 

 Parts List – PAN-PA-54R-WALL-MNT 

 Quantity Item 

 1 Wall mount bracket 

 4 Phillips pan head screw with plastic anchor — #6-20 Type AB,
 1.25" L, zinc-plated steel 

 2 Desiccant 

 Mark the locations on the wall that line up with the four wall mount holes on
 the bottom of the wall mount bracket. 

 Ensure there are no building services (water, gas, or wiring) behind the
 wall where you intend to install the firewall. 

 Drill holes into the four marked locations on the wall. Make sure to remove any
 loose debris around the holes. 

 Install the four provided wall anchors into the four holes. 

 Remove the DIN clip from the back panel of the firewall by unscrewing the four
 Flathead screws. 

 Attach the wall mount bracket onto the back panel by using four M4
 screws. 

 Secure the wall mount bracket using four additional M4 screws in the corner
 holes. 

 Using four #6-20 screws, install the wall mount bracket to the anchors in the
 wall.
