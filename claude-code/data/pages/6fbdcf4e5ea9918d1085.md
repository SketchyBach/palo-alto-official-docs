 Transfer Files in Secure Agentless Access 

 Learn how to transfer files in a Secure Agentless Access remote session. 

 Where Can I Use This? What Do I Need? 

 Secure Agentless Access (SAA) portal 

 A web browser that supports HTML5 

 SAA credentials 

 If permitted by the associated SAA 
 policy , a user can upload or download files while they are
 connected to a remote app. 

 Learn how to transfer files when connected to the following types of apps: 

 SSH or VNC 

 RDP 

 Transfer Files in Secure Agentless Access (SSH or VNC App) 

 Learn how to transfer files in an SSH or VNC app. 

 Learn how to transfer files when connected to an SSH or VNC app. 

 For admin-defined VNC apps, administrators must enable file transfer when adding VNC apps for . For user-defined VNC
 apps, the user must enable file transfer when they manually add VNC apps . 

 For SSH servers that require one-time password
 authentication, Secure Agentless Access (SAA) uses a single authenticated session for both
 terminal access and file transfer operations. SAA automatically
 handles the interactive prompts from your SSH server during the authentication
 process. File upload and download operations connect to the same authenticated
 terminal session, ensuring that file transfer capabilities work seamlessly with SSH
 servers configured for two-factor or two-step authentication. 

 To transfer files from an SSH or VNC app: 

 Log in to the SAA portal. 

 Launch an admin- or user-defined app to which they want to transfer
 files. 

 From the remote app window, click Transfer Files . 

 To upload files from the user's local machine to the remote app: 

 From the remote app window, click Transfer
 Files . 

 You won't see Transfer
 Files if the app is part of a SAA policy that does not permit file uploads and downloads. 

 In the File Upload section, Browse to the file
 you want to upload, select the file, and click
 Open . Alternatively, drag and drop a file to
 the File Upload box. The maximum file size for an upload is 100
 MB. 

 The file is transferred to the user's home directory on the remote
 machine. 

 To download a file from the remote app to the user's local machine: 

 Click Transfer Files . 

 Enter the Absolute File Path of the file and
 click Download . 

 The file is transferred to the Downloads 
 location in the user's home directory on the local machine. 

 Transfer Files in Secure Agentless Access (RDP App) 

 Learn how to transfer files in an RDP app. 

 To transfer files from an RDP app: 

 Log in to the SAA portal. 

 Launch an admin- or user-defined app to which they want to transfer
 files. 

 To upload files from the user's local machine to the remote app: 

 From the remote app window, click Transfer
 Files . 

 In the File Upload section, Browse to the file
 you want to upload, select the file, and click
 Select . Alternatively, drag and drop a file
 to the File Upload box. The maximum file size for an upload is 100
 MB. 

 The file is transferred to the This PC Transient Drive on SAA folder in the Windows remote desktop. 

 To download a file from the remote app to the user's local machine: 

 Click Transfer Files . 

 Drag and drop the file to the This PC Transient Drive on SAA Download folder. 

 The file is automatically transferred to the
 Downloads folder on the local
 machine. 

 Just select the file from the Windows remote desktop and drag the file
 to a location (such as the Downloads folder) on the user's local
 machine.
