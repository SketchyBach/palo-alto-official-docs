 Track your endpoint tags 

 View and filter Cortex XSIAM endpoint tags assigned by the Cortex XDR agent or in Cortex XSIAM. 

 Use endpoint tags to identify, filter, and manage assigned endpoints in Cortex XSIAM. 

 List endpoint tags with the Cortex XDR agent 

 Navigate to the Cytool folder location and open the CLI as an administrator. 

 Cytool Argument: cytool endpoint_tags list . 

 View and filter endpoint tags in Cortex XSIAM 

 Navigate to Inventory → Endpoints → All Endpoints → Tags field . 

 All Server and Agent tags assigned to the endpoint are displayed. Tags created in the Cortex XDR agent show a shield icon. 

 Filter or search the Tags field to find endpoints with assigned endpoint tags.
