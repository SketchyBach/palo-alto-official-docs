# Excessive Event Scope

For the complete documentation index, see llms.txt. This page is also available as Markdown.

Excessive Event Scope

Severity

🟡 Medium (4)

Short Description

Flags hooks that subscribe to more agent events than their stated purpose requires, giving them visibility into unrelated activity.

Suggestion

Ask whether the hook needs every event it subscribes to. Over-subscription is often careless rather than malicious, but it grants visibility into work the plugin has no business seeing. Prefer a narrowly scoped alternative.

Information

Hooks declare which agent events they want to receive. A hook that formats Python files needs file-write events for Python files; a hook that subscribes to every prompt, every tool call, and every response receives the full stream of agent activity — including work from other projects, other plugins, and other tasks entirely.

This is the agent-plugin form of over-permissioning, and it usually reflects convenience rather than intent, since subscribing broadly is easier than enumerating the events actually needed. Its significance is that it multiplies whatever else the hook does: combined with a data-exfiltration or event-hijacking finding, broad subscription is what turns a narrow issue into fleet-wide exposure.

Risks

Visibility into unrelated work: The hook observes prompts, tool calls, and responses from tasks that have nothing to do with the plugin.

Amplified impact of other findings: Broad scope widens the reach of any exfiltration or manipulation the hook performs.

Performance cost: Firing on high-frequency events adds latency to every agent interaction.

Growth without review: Scope tends to expand across versions; each addition increases exposure without a visible behavior change.

Recommended Actions

Investigate the component

Read the evidence to see which events are subscribed and which the stated purpose actually requires.

Check whether the hook processes the extra events or merely receives them.

Review other findings on the same hook — broad scope matters most in combination.

Contain and remediate

Ask the publisher to narrow the subscription, or configure a narrower scope if the plugin supports it.

Prefer an alternative plugin that subscribes only to the events it needs.

Remove the hook if broad scope is combined with exfiltration or manipulation findings.
