 New Features - SaaS Security - November 2024 

 Integrate CIE with Data Security 

 Release Date: November 2024 
 | 
 Last Updated: May 2026 

 Identity providers (IdPs) such as Okta and Active Directory are central to understanding user identities within an organization, including their organizational roles and structures. This information is critical for administrators like you to protect your organization's data. 

 As an administrator, you can integrate Cloud Identity Engine with Data Security to identify and verify all users across your infrastructure irrespective of whether your users are using on-premises, cloud hybrid, or multicloud Identity providers (IdP). Save time in the deployment and management of identity-based controls on your network security infrastructure using point-and-click configuration with real-time validation. Accurately enforce security decisions for all your users at all times, with assured synchronization of all identity-related data in the cloud. Easily apply these controls everywhere in your enterprise: Data center, campus, public cloud, branches, and remote users.

 NG-CASB Standalone Web Interface Deprecation in November 2024 

 Release Date: November 2024 
 | 
 Last Updated: May 2026 

 Security teams often face challenges managing cloud application security across fragmented interfaces, leading to operational complexity and delayed response times when addressing critical threats. To streamline operations and modernize the user experience, the standalone SaaS Security web interface (accessible at https:// < tenant-name>.aperture.paloaltonetworks.com/ ) is officially retiring on 30 November 2024. SaaS Security is now fully integrated into the unified Strata Cloud Manager platform. 

 Since April 2023, Strata Cloud Manager has enhanced data security management by providing a centralized solution that simplifies your workflows. By transitioning to this unified console, you gain immediate, significant benefits, including streamlined policy administration, improved cross-product data correlation, and holistic visibility across your entire security estate. This centralized approach enables your security team to respond faster to incidents and maintain a stronger, more consistent security posture, reducing unnecessary administrative overhead. Complete your transition now to leverage the full, integrated suite of capabilities offered by Strata Cloud Manager .
