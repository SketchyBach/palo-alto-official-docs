 Features Introduced in March 2023 

 Learn what’s coming new in Prisma SD-WAN in March 2023. 

 New Feature/Enhancement Description 

 Improved IoT visibility across SASE 
 Improved IoT visibility across Prisma SASE with Prisma SD-WAN 
 exporting logs to the IoT Security portal. 

 Device Software Version Required: 6.2.1 and later 

 Support for User-ID based policies Support for User-ID based policies 
 provides ease of configuration and consistency, as the same policy can
 be enforced for the same user or group, irrespective of the IP address.

 Device Software Version Required: 6.2.1 and
 later 

 ION 9200 Field Replaceable Unit (FRU) Storage drives (SSD) Switchover event 

 In the event of failure of an ION 9200 FRU
 SSD , logging and storage of core files will be switched
 to on-board SSD, till a replacement FRU SSD is added. 

 Device Software Version Required: 6.2.1 and later 

 Support for enhanced high availability topologies 

 A used for control option for
 Switch Virtual Interfaces
 (SVI) on all switched ports and sub-interfaces on
 routed ports. This allows the standby device to connect to
 the controller through the active device. 

 Cellular bypass pair with dual SIMs providing carrier and device
 redundancy in ION 1200-S 5G variant. 

 Device Software Version Required: 6.2.1 and later 

 Scale improvements for multicast 

 A data center site can now support a maximum of 400 branch sites for
 multicast traffic . For a
 specific multicast group, a data center site can support a maximum
 of 400 branch sites subscribing to that multicast group. 

 Device Software Version Required: 6.2.1 and later 

 IPv6 with LAN 

 Prisma SD-WAN now supports IPv6 on LAN interfaces 
 which have L3 LAN Forwarding enabled for branch and data center
 devices. IPv6 is now supported for statistics, address distribution,
 DHCP, DNS, ZBFW, QoS, policy support, flow control, and application
 identification. 

 For default path
 policy , only Direct on Any Private or Prisma SD-WAN on
 Any Public or Private paths are supported in Active Path. 

 Device Software Version Required: 6.2.1 and later 

 Support for device uptime and thermal sensor data and
 alarm 

 Enhancements are made to monitor the device operating
 temperatures: 

 Device operating temperatures are displayed under
 the System tab to monitor the device
 activity. If one or more thermal sensors report temperatures
 beyond the operationally safe threshold value, an alarm 
 DEVICEHW_TEMPERATURE_SENSOR is
 raised. 

 The System tab also displays
 the Uptime and Last
 Rebooted Reason for a device. 

 Device Software Version Required: 6.2.1 and later 

 Cellular Certifications New cellular certifications by Verizon, Telstra, Bell,
 and Australian country certification are supported for ION 1200 Cellular
 devices. For more information, refer to the ION 1200 Hardware Reference .

 Device Software Version Required: 6.2.1 and
 later 

 Aggregate Bandwidth utilization report 

 Prisma SD-WAN supports aggregate on-demand bandwidth
 utilization reports showing the monthly site and tenant
 utilization to help understand the bandwidth consumption.
