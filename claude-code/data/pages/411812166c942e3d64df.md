 Known Issues 

 Known issues for Advanced IP Defense . 

 PAN-330183 

 On NGFW and Panorama® management server running PAN-OS 12.2.2 or
 earlier, the Source column for Advanced IP Defense predefined external dynamic
 lists (EDLs) displays the human-readable name instead of the actual source identifier.
 For example, the Source column shows Palo Alto Networks - Adv. IP Defense:
 Exposed vulnerable services rather than
 panw-aipd-vuln-svcs-ip-list . 

 PAN-329754 

 After installing an antivirus content update on an NGFW or Panorama® management server running PAN-OS 12.2.2 or earlier, Advanced IP Defense external dynamic lists (EDLs) might display an incorrect entry
 count that is lower than the actual number of entries in the EDL. The EDL data on the
 NGFW and Panorama is correct and functioning; only the web
 interface display is affected. 

 Additionally, the EDLs display in reverse priority order.
