 Where Can I Use This? What Do I Need? 

 Prisma Agent 

 iOS 16 and later versions 

 Internet access 

 You can view the Prisma Agent connection details and troubleshoot any issues
 on the app settings page. 

 Open the Prisma Agent app. 

 Go to Settings page by tapping the Settings icon. 

 Review the settings. 

 If your administrator has configured IPv6 dual-stack support and if your
 device is IPv6-enabled, you will see both IPv4 and IPv6 addresses. 

 Click the left arrow to dismiss the Settings .
