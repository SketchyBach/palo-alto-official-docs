 Addressed issues in Cortex XDR agent 8.5.0 

 The following issues were addressed in the Cortex XDR agent 8.5 release. 

 Issue 

 Description 

 CPATR-24307 

 (Windows) 

 Fixed an issue where CLS or Clear commands may print extra whitespaces on Live Terminal. 

 CPATR-24256 

 (Windows) 

 Improvement made to the Cortex XDR agent security and stability posture. 

 CPATR-24120 

 (Linux) 

 Fixed an issue where Info log messages may be generated instead of Error log messages, when both event collection collectors KM and bpfec are disabled. 

 CPATR-23980 

 Fixed an issue where, in rare occurrences, a location change during the first heartbeat may not be accurate. 

 CPATR-23885 

 (Windows) 

 Fixed an issue where a successful manual scan status may be displayed incorrectly. 

 CPATR-22866 

 Mac 

 Fixed a rare race of agent process crashing (PMD), triggered by system process crash.
