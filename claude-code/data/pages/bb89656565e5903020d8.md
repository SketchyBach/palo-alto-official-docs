 Known Issues in ION Device Release 6.1.10 

 The following list includes outstanding known issues specific to ION release 6.1.10. 

 Issue ID Description 

 CGSDW-22659 The system does not display the correct interface speed for
 interfaces where no link is detected, i.e. when the operational status is
 down.

 The following list includes outstanding known issues specific to Prisma SD-WAN
 ION release 6.1.9. 

 Issue ID Description 

 CGSDW-16922 The fp-rte process crashes after a software
 upgrade to ION device version 6.1.5-b7. 

 CGSDW-18905 First flow of direct VNC traffic gets denied as the server port in
 the ION app-def is 0-0. 

 CGSDW-19357 When a DC ION receives routes for a /32 prefix from both the
 underlay and overlay, the DC ION tries to split the route and thus the BGP route
 selection process fails.

 Known Issues in ION Device Release 6.1.4 

 The following list includes outstanding known issues specific to Prisma SD-WAN
 ION release 6.1.4. 

 Issue ID Description 

 CGSDW-14432 The fp-rte process crashes when fetching
 information on security policy counters and app stats. 

 CGSDW-15257 After upgrading a data center ION device to software version 6.1.2,
 some of the Reachable Prefixes out of the Received
 Prefixes for a peer are displayed as Filtered
 Prefixes . 

 CGSDW-15868 High memory utilization due to the ADEM application is causing the
 system to run out of memory. 

 CGSDW-15970 When rebooting the active device in an HA configuration on the 2000
 platform, the bypass pair of the active device does not pass traffic during
 reload. 

 CGSDW-15988 On upgrading the device software, a parent interface with more than
 20 subinterfaces flaps, resulting in flapping of the IP addresses of the
 subinterfaces. 

 CGSDW-16005 The app-engine crashes while sending
 continuous TCP traffic on the 2000 platform. 

 CGSDW-16031 There is a delay in bringing down the BGP peer of a data center ION
 device when the remote end of the interface is shut down.
