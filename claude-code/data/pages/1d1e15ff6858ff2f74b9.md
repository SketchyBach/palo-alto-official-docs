 Cortex XDR Agent 7.9-CE Release Information 

 Features Introduced in Cortex XDR Agent 7.9 

 The following table describes new features in the Cortex XDR Agent 7.9 release. 

 Cross-Platform Features 

 The following features were added to Cortex XDR agents running on Windows, Linux, and Mac endpoints: 

 Feature 

 Description 

 Handling errors from WildFire Service 

 (Windows and Mac) 

 Cortex XDR introduces a new mechanism for handling errors from the WildFire service, in order to avoid creating benign alerts from non malicious files and eventually reducing the false positive ratio. 

 Handling Exceptions and Exclusions 

 Changes have been made to existing agent exceptions and alert exclusion flows, which are now managed in a central location. 

 Flexible/granular options have been added to exclude files and processes from agent prevention actions. 

 Linux Features 

 The following features were added to Cortex XDR agents running on Linux endpoints: 

 Feature 

 Description 

 New Linux Support 

 Cortex XDR, version 7.9, supports RockyLinux 9 and AlmaLinux 9 

 Red Hat Update for fapolicyd 

 Support added to run the Cortex XDR agent on RHEL8, RHEL9 and variants when the daemon fapolicyd is activated.
