 Ivanti 

 Cortex AgentiX 

 Ivanti 

 Use Ivanti data for Cortex AgentiX. 

 Important 

 This connector is only available for tenants that onboarded after July 26, 2026. For tenants that onboarded before this date, use Marketplace to access the standalone integration. For more information, see Marketplace . 

 This connector is available with any active Cortex XSIAM or Cortex AgentiX license. 

 Integrate with Ivanti IT service management products. Cherwell is a cloud-based IT service management solution where you can create, read, update, and delete business objects, together with attachments and relations operations. Ivanti Heat is the Ivanti Heat service manager. 

 This connector includes the following sub-capabilities (Marketplace integrations link to PAN DEV for more information): 

 Cherwell : Cloud-based IT service management solution. 

 Ivanti Heat : Use the Ivanti Heat integration to manage issues and create Cortex XSOAR incidents from Ivanti Heat. 

 To configure this connector, follow the steps outlined in the configuration wizard.
