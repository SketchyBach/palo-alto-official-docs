 Objects > Mobile Networks > Equipment Groups 

 Use Equipment Group objects to combine individual equipment objects. 

 Equipment groups enable you to group multiple equipment objects to treat them as a single
 unit in security policies. Each equipment group supports a maximum of 5,000 members.
 These groups are supported in multi-vsys environments and can be managed and pushed from
 Panorama to device groups. 

 Field Description 

 Name Enter a name for the equipment group object (up to 63 characters).
 The name is case-sensitive, must be unique, and can contain only
 letters, numbers, spaces, hyphens, and underscores. 

 Shared Select this option if you want the equipment group object to be
 available to every virtual system (vsys) on a multi-vsys firewall or
 every device group on Panorama. 

 Description Enter an optional description for the object (up to 1,023
 characters). 

 Type Manage Equipment objects by group: 
 Browse —Select from available Equipment or
 Equipment Group objects. 

 Add —Add new Equipment or Equipment Group
 objects to the group. 

 Delete —Delete Equipment or Equipment
 Group objects from the group.
