 Known Issues in Network Discovery 2.1 

 Known issues in Network Discovery plugin 2.1. 

 Where Can I Use This? What Do I Need? 

 NGFW (Managed by PAN-OS or Panorama) 

 One of the following subscriptions: 

 Device Security subscription

 Precision AI bundle subscription

 Device Security X subscription

 The following list includes all known issues that impact a Device Security Network
 Discovery plugin 2.1 release. This list includes both outstanding issues and issues that
 are addressed, as well as known issues that apply more generally or that are not
 identified by a specific issue ID.

 BAN-20569 

 Previous OT Polling job results still appeared after removing the configuration, and after deleting and reinstalling the plugin. 

 This issue is resolved in Network Discovery plugin 2.1.2. 

 BAN-20558 

 The data refreshment job caused high disk space usage alerts.

 This issue is resolved in Network Discovery plugin 2.1.2. 

 BAN-20360 

 When using SNMP crawling, consecutive data refresh jobs fail.

 This issue is resolved in Network Discovery plugin 2.1.2. 

 BAN-20289 

 The Network Discovery plugin web interface shows a configuration error when using
 the Basic mode to configure OT Polling for the winRM and SNMP protocols.

 This issue is resolved in Network Discovery plugin 2.1.2. 

 BAN-20264 

 After enabling OT Polling, the polling run might not start.

 Workaround: Do a dummy configuration change, such as a minor timeout change,
 and then commit the config.

 This issue is resolved in Network Discovery plugin 2.2.0. 

 BAN-20078 

 The Network Discovery plugin fails when trying to do SNMP crawling with a hop limit
 of 2 or more, and both CDP and LLDP discovery are enabled.

 This issue is resolved in Network Discovery plugin 2.1.1. 

 BAN-20050 

 The Network Discovery plugin could fail after configuring a timeout for SNMP
 crawling.

 This issue is resolved in Network Discovery plugin 2.1.1.
