 Configure the Number of Workers for the Server 

 Configure server workers through an engine in Cortex XSOAR 6.12. 

 If you experience performance issues, check the workers.log file to check if all workers are busy. Before increasing worker count, verify that there is enough CPU to handle the additional workers. You can configure the number of workers both for the server. When the worker count for the server is full, the system will send the user an email notification. 

 Select Settings → About → Troubleshooting → Add Server Configuration . 

 Add the following key and value: 

 Task 

 Value 

 workers.count.Tasks 

 Number of workers for the server. 

 Default: 4 workers per CPU core.
