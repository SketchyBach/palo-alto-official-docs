 Delete a Cloud NGFW Resource 

 Learn how to delete a Cloud NGFW for AWS resource. 

 Where Can I Use This? What Do I Need? 

 Cloud NGFW for AWS 

 Cloud NGFW subscription 

 Palo Alto Networks Customer Support Account (CSP) 

 AWS Marketplace account 

 User role (either tenant or administrator) 

 If you no longer need a Cloud NGFW resource, complete the following procedure to
 remove it from your AWS deployment. 

 Remove associated Cloud NGFW endpoints from your route tables. 

 Log in to the AWS Console. 

 Select VPC and locate the VPC containing the
 Cloud NGFW endpoint. 

 Select Route Tables and then select the route
 table of the endpoint to be removed. 

 Click Edit Routes . 

 Click Remove to delete the route from the route
 table. 

 Click Save Changes . 

 ( Customer-managed endpoints only ) If you deployed your own Cloud NGFW
 endpoints, you must delete them from the AWS console . 

 From the AWS console, select Endpoints and
 choose your Cloud NGFW endpoint. 

 Select Actions Delete and confirm the deletion. 

 Remove the Cloud NGFW resource from the Cloud NGFW Tenant. 

 Log in to the Cloud NGFW console and select
 NGFWs . 

 Select the resource to be deleted. 

 From the Actions drop-down, click
 Delete . 

 Confirm the deletion. 
 After a few minutes, the Cloud NGFW resource and all its endpoint are
 deleted from your Cloud NGFW deployment.
