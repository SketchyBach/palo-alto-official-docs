 Addressed Issues in Cortex XDR Agent 8.4 

 Cortex XDR agent 8.4.0 addressed issues 

 The following issues were addressed in the Cortex XDR agent 8.4 release. 

 Issue 

 Description 

 CPATR-23540 

 (Linux) 

 Fixed an issue that may prevent agents upgrading through P2P on Linux. 

 CPATR-23516 

 (Windows) 

 Improvement made to the Cortex XDR agent security and stability posture. 

 CPATR-23499 

 (Windows) 

 Fixed an issue where a short time lapse may have been encountered, in certain VPN solutions, before endpoint management recognizes the protection status of the XDR agent after the machine boots up. 

 CPATR-23443 

 (Windows) 

 Fixed a compatibility issue with 3-party applications and Cytray.exe 

 CPATR-23360 

 (Linux) 

 Fixed an issue that may be encountered when running a clean installation with a package manager on a specific system configuration, where the clean installation may be incorrectly seen as an upgrade. 

 CPATR-23360 

 Fixed an issue so that files with special characters in the filename may be deleted with the destroy command. 

 CPATR-23053 

 Fixed an issue that may prevent agents from connecting when DNS resolution encounters high latency. 

 CPATR-22985 

 (Windows) 

 Fixed an issue that may occur in rare cases when initiating an upgrade. 

 CPATR-22317 

 Fixed an issue that may be encountered with scheduled scan times after daylight saving time changes. 

 CPATR-22103 

 (Linux) 

 Fixed an issue that may occur when using an unprivileged user for sandbox in Kubernetes environments. 

 CPATR-21955 

 Fixed an issue to increase the agent stability. 

 CPATR-21703 

 Fixed an issue to improve character recognition and handling in the command execution script. 

 CPATR-20826 

 (Linux) 

 Reduction and cleanup of repeating logs. 

 CPATR-20245 

 (Windows) 

 Fixed an issue to improve hostname resolving in some network events. 

 CPATR-20233 

 Fixed an issue to ensure that an interrupted scheduled scan will resume scanning as close to the scheduled timeframe as possible. 

 CPATR-19295 

 (Windows) 

 Fixed an issue that may cause the agent to stop consuming events from Microsoft Windows Security Auditing after an upgrade or a fresh installation without a machine reboot.
