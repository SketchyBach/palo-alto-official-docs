 GCP Manual Onboarding Guide - Project Scope 

 Manual onboarding is designed for customers who require full control over the GCP onboarding process. Instead of relying on Cortex-generated Terraform templates, you provision every resource, including service accounts, custom IAM roles, Pub/Sub topics, and logging sinks, yourself. 

 This guide walks you through manually creating the required GCP resources for the Cortex integration using gcloud CLI commands at the Project scope.
