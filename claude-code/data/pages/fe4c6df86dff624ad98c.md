# Identity Security Terraform Provider

Skip To Main Content
Our Products
Identity Security Terraform Provider

The Identity Security Terraform Provider from Idira transforms how your organization can manage identity security.

Overview

Terraform is a leading Infrastructure-as-Code (IaC) tool that automates the deployment and management of IT infrastructure (like servers, networks, and cloud services).

By enabling teams to define and automate Idira configurations as Infrastructure as Code (IaC), it delivers consistent security, reduces operational risk, and accelerates deployment speed across all cloud and on-premises environments.

This solution ensures that identity and access controls scale securely alongside your critical infrastructure, maintaining full auditability and least-privilege control at every step.

Get started

The Identity Security Terraform Provider is available in the Terraform public registry.

For requirements and setup information, see the relevant Terraform provider documentation.

Supported Terraform versions

The Terraform public registry-based provider requires Terraform 0.13.x or later.
