 Enable BGP for Private WAN and LAN 

 Learn more about the enable BGP for private WAN and LAN in Prisma SD-WAN. Enable
 L3 Direct Private WAN Forwarding and L3 LAN
 Forwarding to use dynamic LAN routing. 

 Where Can I Use
 This? What Do I
 Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 Enable L3 Direct Private WAN Forwarding to
allow the ION device to peer with a BGP router via the private WAN
interface. 

 This is only applicable to Branch mode ION. 

 Enable L3 Direct Private WAN Forwarding and L3
LAN Forwarding to use dynamic LAN routing. 

 Select Configuration Prisma SD-WAN ION Devices Claimed Configure the device Basic Info . 

 Enable L3 Direct Private WAN Forwarding to
allow the ION device to send underlay MPLS traffic or peer with
a BGP router on a private WAN interface. 

 You do not need to enable this field if you intend to run
BGP on the internet or standard VPNs. 

 Enable L3 LAN Forwarding to use
dynamic LAN routing. 

 You can enable Layer 3 LAN Forwarding only when there are
no Private Layer 2 bypass pairs associated with any of the interfaces on
the device. Starting with Release 5.2.3, if there are Private Layer
2 interfaces on the device, you will see a message to remove the
Private Layer 2 interfaces associated with the device and then enable
Layer 3 LAN Forwarding. 

 You must enable both Enable L3 Direct
Private WAN Forwarding and L3 LAN Forwarding for
the ION device to use dynamic LAN routing.
