# AWS Manual Onboarding Guide

Manual onboarding is designed for customers who require full control over the AWS onboarding process. Instead of relying on Cortex-generated CloudFormation templates, you provision every resource, including custom IAM policy, IAM roles, SQS queue, and SNS subscription, yourself.
