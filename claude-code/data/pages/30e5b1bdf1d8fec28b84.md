 Use Syslog for Monitoring 

 Syslog is a standard log transport mechanism that enables
 the aggregation of log data from different network devices—such
 as routers, firewalls, printers—from different vendors into a central
 repository for archiving, analysis, and reporting. Palo Alto Networks
 firewalls can forward every type of log they generate to an external
 syslog server. You can use TCP or TLS (TLSv1.2 only) for reliable
 and secure log forwarding, or UDP for non-secure forwarding.
