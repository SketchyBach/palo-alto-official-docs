 Configure Identity and Access Management 

 Configure IAM roles and permissions for Prisma AIRS AI Red Teaming, including custom
 roles creation and API access setup with minimum required permissions for SDK
 usage. 

 Where Can I Use This? What Do I Need? 

 Prisma AIRS (AI Red Teaming) 

 Prisma AIRS AI Red Teaming License 

 Prisma AIRS AI Red Teaming Deployment Profile 

 If you have an active deployment profile but lack IAM
 permissions for AI Red Teaming, it may result in user authentication error. Hence it
 is important to have an active deployment profile and IAM permission to access AI
 Red Teaming. 

 Navigate to Strata Cloud Manager Identity and Access Management (IAM) settings, Common Services Identity & Access . 

 Navigate to Identity & Access Access Management and select the tenant from the tenants list. Verify the
 Identity Information for the selected tenant to
 ensure that the Role assigned is either
 Superuser for all apps and services, or a Read only
 role with access to AI Red Teaming. 

 ( Optional ) ( Administrator Only ) Create a custom role. 

 To create a new custom role and assign it to their identity, select
 Roles and then Custom
 Roles . 

 Enable AI Red Teaming . 

 Select Assign Roles and verify if the custom
 role that you created appears in the Apps &
 Services list. Select All Apps &
 Services and then assign the Role (for example,
 superuser).
