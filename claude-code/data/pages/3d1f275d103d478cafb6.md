 New Features 

 dump intra cluster tunnel 

 Use the dump intra-cluster-tunnel command to display the Intra
 Cluster Tunnel configurations and status information. You can set the Tunnel peer
 address as part of the Interface configuration to send this traffic to the peer DC-ION
 so it can be forwarded appropriately. 

 Command 

 dump intra-cluster-tunnel(config | status) 

 Options 

 config Enter config to display the learned configurations
 for Intra Cluster Tunnel. 

 status Enter status to display the learned status for Intra
 Cluster Tunnel. 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands — 

 Introduced in Release 6.5.1 

 Example 

 dump intra-cluster-tunnel config
Intra Cluster Tunnel Config
Disabled: false
Source Interfaces: eth5

Peer-Element Disabled Peer-IPs
 false 10.2.1.2 

 dump intra-cluster-tunnel status
Interface Local-IP Peer-IP Status
eth5 10.2.1.101 10.2.1.2 Up
