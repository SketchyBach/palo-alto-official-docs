 AWS Lambda function is not configured for function-level concurrent execution Limit misconfiguration 

 Rule Details 

 Cortex AppSec Rule ID 

 APPSEC_AWS_115 

 Category - Subcategory 

 Compute - Overprovisioned 

 Provider 

 AWS 

 Severity 

 LOW 

 Framework 

 CloudFormation, Terraform, Terraform Plan 

 Impact 

 Adding concurrency to Lambda initializes that number of execution environments for multiple parallel requests at low latency. However, this could spike costs and open the door for abuse. Adding concurrency limits can prevent a rapid spike in usage and costs, while also increasing or lowering the default concurrency limit. 

 How to Fix 

 Resource: AWS::Lambda::Function, AWS::Serverless::Function 

 Arguments: Properties/ReservedConcurrentExecutions [source,go] 

 Type: AWS::Lambda::Function Properties: ... ReservedConcurrentExecutions: 100 ...
