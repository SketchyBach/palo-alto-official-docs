 Install the ION 1000 by Replacing an Existing Router 

 Install the Prisma SD-WAN ION 1000 by replacing an existing
router to directly terminating the MPLS. 

 Install the ION 1000 to replace an existing
router, directly terminating the MPLS, especially in environments
where routers are not already present or required. 

 Configure the ION 1000 as a drop-in replacement
for the WAN Router. This mode is most useful for saving cost at new
sites that are designed without a traditional router in mind. 

 While this mode is used to remove an existing router at a site,
it is sometimes preferred to deploy with an existing router .
In such a scenario, the existing router is unplugged or disabled
after all functions are verified.
