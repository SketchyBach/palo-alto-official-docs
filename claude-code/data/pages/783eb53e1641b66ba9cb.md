 Onboard an Aptible App to SSPM 

 Connect an Aptible instance to SSPM to detect posture
risks. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 SaaS Security Posture Management license 

 Or any of the following licenses that include the Data Security license: 

 CASB-X 

 CASB-PA 

 For SSPM to detect posture risks in your Aptible instance, you must onboard your Aptible instance
 to SSPM. Through the onboarding process, SSPM logs in to Aptible using account
 credentials. SSPM uses this account to scan your Aptible instance for misconfigured
 settings. If there are misconfigured settings, SSPM suggests a remediation action
 based on best practices. 

 To onboard your Aptible instance, you complete the following actions: 

 Identify the Account for Accessing Aptible 

 Connect SSPM to Your Aptible Instance 

 Identify the Account for Accessing Aptible 

 To access your Aptible instance, SSPM requires
the following information, which you will specify during the onboarding process. 

 Item Description 

 User email The login email address of an Aptible user. 
 ( Required Permissions )
 The user must be assigned to the Rooms Collaborator role, or
 a role with greater permissions. 

 Password The password for the Aptible user account. 

 Identify the Aptible account that SSPM will use to access your Aptible instance. Verify that the
 account has the required permissions as shown in the preceding table. 

 Connect SSPM to Your Aptible Instance 

 By adding an Aptible app in SSPM, you enable
SSPM to connect to your Aptible instance. 

 Log in to 
 Strata Cloud Manager . 

 Select Configuration SaaS Security Posture Security Applications Add Application and click the Aptible tile. 

 Under posture security instances, Add Instance or,
 if there is already an instance configured, Add New 
 instance. 

 Choose the option to Log in with Credentials . 

 Enter the login email address and password for accessing your Aptible
 instance and Connect .
