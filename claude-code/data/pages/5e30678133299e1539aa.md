 Expanded Code-to-Cloud traceability to VMs 

 Code-to-Cloud traceability now extends beyond containers to Virtual Machines built from VM images.
This enhancement provides full lifecycle lineage, enabling you to bridge the gap between runtime assets and source code by tracing vulnerabilities and misconfigurations back to their origin and remediating them at the source.
