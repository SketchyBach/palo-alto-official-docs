 Manage Prisma Access Agents 

 Use the Inventory page to monitor the status and manage the lifecycle of Prisma Access Agents . 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 NGFW (Managed by Panorama) 

 Check the prerequisites for the deployment you're
 using 

 Contact your Palo Alto Networks account representative to
 activate the Prisma Access Agent feature 

 Prisma Access provides a cloud-managed service ( Prisma Access Agent Manager) that you
 can use to manage the lifecycle of Prisma Access Agents . This
 cloud-managed service can help you effectively manage Prisma Access Agents , gain
 visibility into the agents, and simplify troubleshooting. 

 You can perform the following tasks in the Endpoint Management
 page that's accessible from Configuration Endpoint Management : 
 View the Overall Status of Prisma Access Agents that you have
 deployed to your mobile users 

 View the status
 of staged agent upgrades 

 View the individual status of an
 agent and experience score for an agent (if Autonomous DEM is
 enabled) 

 Download the Prisma Access Agent
 package 

 Troubleshoot issues on
 specific agents , such as downloading agent logs ,
 downloading Host Information Profile (HIP) reports , and using a
 remote shell to complete diagnostic tasks 

 Selectively upgrade or downgrade agents for troubleshooting 

 Staged rollout upgrades, ADEM integration, remote shell, and
 selective upgrade and downgrade features are only supported on macOS and Windows
 agents.
