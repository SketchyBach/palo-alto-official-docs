 Prisma SD-WAN Port Panel Status Indicators 

 Learn about ports and interface status indicators in the Prisma SD-WAN . 

 Where Can I Use
 This? What Do I Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 The Port Panel web interface for all ION device models provides clear visual information
 regarding port status. This interface displays the current status and configuration of
 each port. 

 Additionally, the Extended Tooltip appears when you hover over a port, providing details
 about the port's status and configuration. 

 The table below define the icons and visual cues used in the Port Panel to represent the
 operational and administrative status of the interfaces. 

 The appearance of the port icon changes based on its physical
 connector type (SFP or RJ45). 

 Port Status Legends 

 Visual Cue WAN Port LAN Port Status 

 Connected and Configured 

 The port is physically connected and has a valid configuration. 

 Connected 

 The port is physically connected (link is up) but does not have a configuration. 

 Not Connected 

 The port has no physical connection (link is down). 

 Admin Up 

 The port is enabled by the administrator. 

 Admin Down 

 The port is disabled by the administrator. 

 Unplugged and configured 

 The port is unplugged and has a valid configuration. 

 POE Port 

 The port can provide Power over Ethernet (POE). 

 Hardware Bypass Pair Capable 

 The adjacent ports can be configured as a Hardware Bypass Pair. 

 Combo Port 

 The port functions as either a copper or fiber connection.
