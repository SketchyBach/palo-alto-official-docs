 Objects > Mobile Networks > Subscribers 

 Use Subscriber objects to identify and manage mobile subscribers in enterprise mobile
 networks. 

 Subscriber objects allow you to identify and manage mobile subscribers in enterprise
 mobile networks using the International Mobile Subscriber Identity (IMSI). Similar to
 how IP address objects are used in traditional networks, subscriber objects provide a
 meaningful identifier for administrators, facilitating reusability and improving rule
 readability within security policies. 

 Prerequisite: You must enable GTP Security to view and configure subscriber
 objects on the firewall. 

 Field Description 

 Name Enter a name for the subscriber object (up to 63 characters). The
 name is case-sensitive, must be unique, and can contain only
 letters, numbers, spaces, hyphens, and underscores. 

 Shared Select this option if you want the subscriber object to be
 available to every virtual system (vsys) on a multi-vsys firewall or
 every device group on Panorama. 

 Description Enter an optional description for the object (up to 1,023
 characters). 

 Type Specify the identifier type and the entry: 
 IMSI —Enter a 14 or 15-digit identifier. 

 IMSI Range —Enter a range of IMSI values. Ranges are
 supported from the 4th digit through the 15th digit. 

 IMSI Prefix —Enter a variable length prefix starting
 from the 4th digit (e.g., 300*).
