 Incident List 

 The Incident List shows you details about any incident in the
 time range you’ve selected. 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 AI-Powered ADEM license 

 Autonomous DEM license 

 Prisma Access license 

 In Strata Cloud Manager , select Incidents Prisma Access Incident List to view details about incidents in the time range you’ve selected in the
 Time Range filter. 

 You can filter the Incident List by selecting as many filters as you want from the
 following drop-downs: 

 Status — Raised ,
 Clearing , or Cleared . 

 Add Filter — Last Updated Time ,
 Severity , Category ,
 Code , Site Name , Tunnel
 Name , Prisma Access Location . 

 Select an Incident from the list to open the Incident
 Details page and review details about the incident you’ve chosen. 

 Incident Details 

 From the Incident Details page, view details about the
 incident you’ve chosen and take actions as needed. 

 Acknowledge the operations status—Under Incident Management ,
 review incident details and select Acknowledge to accept the
 status. 

 View Potential Impact —See details about how this incident
 affects branch users. You can see the number and location of unique affected and
 potentially impacted mobile users. 

 You must configure userid to IP mapping to
 view this information. 

 Suggested Next Steps —View Remediation Playbook steps you
 can take to resolve this incident. You can also view remediation steps for each
 incident in the AI-Powered ADEM Incidents and Prisma Access Incidents sections of
 this guide. 

 Metrics Details —View metrics details for the
 incident. 

 Correlated Alerts —See the alerts that are correlated to
 this incident. For information about alerts correlated with each incident,
 select the incident from AI-Powered ADEM Incidents , ADEM Incidents , or Strata Access Incidents . For
 information about individual alerts, see Priority Alert Codes . 

 Activity and Clear Information —View the activity for each
 incident, such as a description of the incident and when alerts associated with
 the event were created. Use the All Activity drop-down to
 filter by All Activity ,
 Notifications , Transitions ,
 and History . When an incident is cleared, you see that
 information under Clear Information . 

 Related Incidents —View child and parent incidents related
 to this incident. You can also see whether this incident occurred
 previously.
