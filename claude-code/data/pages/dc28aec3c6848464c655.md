 Use the dump dpdk cpu command
to display details of the dpdk cpu usage information. 

 Command 

 dump dpdk cpu 

 Options 

 None 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands 

 dump dpdk port status 

 Introduced in Release 5.6.1 

 Example 

 dump dpdk cpu
