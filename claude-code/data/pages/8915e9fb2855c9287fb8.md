 Configure WAN/LAN Ports 

 Let us learn to configure WAN/LAN ports. Ports are the physical interfaces on the ION
 device and Interfaces are the logical interfaces on the ION device. 

 Where Can I Use
 This? What Do I
 Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 Select Configuration Prisma SD-WAN ION Devices Claimed , select the device you want to configure. 

 Select WAN/LAN as a port pair. 

 In the General section, 

 Enter a Name and (Optional) 
 Description , and add Tags 
 for the port channel interface. 

 For Admin Up , select
 Up . 

 In the Network Setting section, 

 Interface Type displays the selected WAN/LAN
 bypass pair. 

 For Hardware Relay – Fail to Wire , select
 Yes to get fail-to-wire functionality. 

 For Use These Ports For , select
 Private WAN . 

 For Circuit Label , select the circuit label that
 corresponds to your private WAN connection for this site. 

 Select Enable IPv6 On This Interface to
 configure IPv6. 

 For IPv6 Configuration , select
 DHCP or Static . 

 Choose DHCP if the IP address is dynamically
 assigned. 

 Choose Static if the IP address is fixed and
 is manually assigned. Additionally specify the IPv6
 Address/Mask , Default
 Gateway(IPv6) , and DNS
 server(s)(IPv6) . 

 For Attached Networks , enter the router’s VLAN
 ID and IP address. 

 You may enter multiple VLAN IDs and IP addresses. 

 Select Network Context if this is a
 subnet and you would like to segment one subnet for which you
 would like to define a separate policy. For example, guest
 Wi-Fi. 

 For Security Zone , select a device to bind. 

 For Scope , toggle Local 
 or Global . 

 Select Local when defining an IP subnet that is not advertised to any
 other site. 

 Select Global when defining an IP subnet that is advertised to every
 Prisma SD-WAN site. 

 Prisma SD-WAN does not control traffic if a
 prefix/subnet is not defined on the ION device. 

 Optionally configure Routing, SNMP Config, Syslog Export, and NTP
 Client. 

 Click Save , you can save bypass pair .
