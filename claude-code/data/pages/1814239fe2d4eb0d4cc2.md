 Interpret the WF-500-B LEDs 

 The following table describes the meaning
of each Ethernet port LED on the appliance. 

 Each Ethernet port on the WF-500-B appliance has two LEDs
— one on the left and one on the right. 

 LED Description 

 Left 

 Off—No link 

 Green—100 Mbps link 

 Amber—1 Gbps link 

 Right 

 Yellow (blinking)—The appliance
is processing network activity
