 The following tables describe a list of event or incident codes, the event
 origin, its severity, and a description of each event as per the event category.

 Controller INCIDENT Warning Spoke cluster operating in a degraded state. One of the devices in the cluster has failed and is

 DOWN 

 Controller INCIDENT Critical Spoke cluster operation is down. Both devices in the cluster have failed, therefore

 MULTIPLE_ 

 ACTIVE_ 

 DEVICES 

 Controller INCIDENT Critical More than one device is active in the spoke
 cluster. Both devices in the cluster have declared themselves to
 be active. This situation happens when the devices in the cluster are
 not able to communicate with each other. Affects the network
 connectivity to the site. 5.1.1 Device HA

 STATE_ 

 UPDATE 

 Device ALERT Warning Device state changes in spoke cluster. Device changed its state from active to backup or backup
 to active. If the device changed its state to backup, and there is no
 other device eligible to become active, this affects the network
 connectivity at the site. 5.1.1 Device High Availability
