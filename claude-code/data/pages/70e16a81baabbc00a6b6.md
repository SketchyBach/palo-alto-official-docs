 Syslog Severity Reference 

 A reference for the syslog messages by severity. 

 Where Can I Use This? What Do I Need? 

 NGFW (Managed by PAN-OS or Panorama) 

 Support license 

 ( Panorama ) Device management license 

Syslog messages provide crucial insights into the health, performance, and
 security of a system. To help you prioritize and understand these events, syslog
 messages are categorized by severity levels. This categorization is essential for
 effective monitoring, troubleshooting, and incident response. Understanding and properly
 configuring Syslog message severity levels are fundamental for effective system
 administration. It allows organizations to filter out noise, focus on critical events,
 and implement automated alerts based on the severity, ensuring timely responses to
 potential threats and operational issues. 

 The different syslog message severity levels are as follows: 

 Informational System Log Messages . These messages are not critical and
 provide routine announcements of events, such as configuration changes. These messages
 help you track the behaviour of the system. 

 Low Severity System Log Messages . These messages represent minor issues
 that might not need immediate attention but are worth noting. 

 Medium Severity System Log Messages . These messages indicate issues that
 are slightly more significant than the low severity ones, yet are not very critical.
 They might not lead to any immediate crisis, but are worth noting for timely
 investigation to prevent critical failures. 

 High Severity System Log Messages . These messages indicate that something has
 gone wrong and needs immediate attention. While the entire system might not be down, a
 specific function or area is clearly experiencing difficulties, and it needs to be fixed
 to ensure everything runs smoothly. 

 Critical Severity System Log Messages . These messages are the alarms
 that signify a major crisis has occurred. These messages demand immediate and urgent
 action.
