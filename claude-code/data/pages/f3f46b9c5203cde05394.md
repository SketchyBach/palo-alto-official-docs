 Select the Types of Notifications to Send 

 Administrators can select the type of notifications, such as WiFi-related, or
 device-related notifications, that a user receives when he experiences a degradation in
 application experience. 

 Where Can I Use
 This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 Prisma Access license 

 ADEM or Strata Cloud Manager Pro 
 license 

 GlobalProtect or Prisma Access Agent license 

 You can select one or more of the following
types of notifications to send to your users. If you configure notifications
to be sent to a user group, notifications will be enabled for all
users in that group. 

 CPU 

 Memory 

 WiFi Quality 

 Internet Outage 

 Go to Strata Cloud Manager Insights Activity Insights Users tab and change the Scope Selection to
 Prisma Access . 

 Click the Self Serve button. 

 The Self-Serve Notifications page opens. 

 In Self Serve Notification Type ,
select the type of notifications that you want to enable by selecting
the check box next to the notification type. By default, all notification
types are selected. Clear the check box next to the type of notification
you do not want to send and Save your changes. 

 When you disable a notification type, the user does not receive notifications
 about the metric when it hits the configured threshold. Even if you disable
 notifications for a metric, the data still displays in Access
