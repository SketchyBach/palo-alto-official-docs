 Enterprise Data Loss Prevention Features 

 New Enterprise DLP Feature 

 Description 

 New Application Support 

 Requires DLP plugin 3.0.4 or later release 

 Enterprise DLP now supports the following new applications . 

 Firewalls leveraging Enterprise DLP must be running PAN-OS 10.2.4 or
 later release and have Apps & Threats content version 8684-7912
 installed. 

 Google Drive Web 

 Microsoft OneDrive Desktop - Business 

 Expanded Download Support for Existing Applications 

 Requires DLP plugin 3.0.4 or later release 

 Enterprise DLP now supports download inspection for the following
 applications . 

 Requires DLP plugin 3.0.4 or later release and have Apps &
 Threats content version 8684-7912 installed. 

 Box Desktop - Business 

 Microsoft SharePoint Desktop 

 Microsoft SharePoint Web 

 Naver Mail Web 

 Salesforce Web 

 Expanded File Size Support for Existing Applications 

 Requires DLP plugin 3.0.4 or later release 

 Enterprise DLP now supports large file inspection for the following
 applications . 

 Firewalls leveraging Enterprise DLP must be running PAN-OS 10.2.4 or
 later release and have Apps & Threats content version 8684-7912
 installed. 

 Microsoft OneDrive Desktop - Personal 

 Large File Inspection for Box and Web Browsing 

 Requires DLP plugin 3.0.3 or later release 

 Enterprise DLP now supports upload inspection of files up to 100MB in
 size for the Box Web App and Web Browsing
 applications . 

 Proxy Support for Enterprise DLP 

 Requires DLP plugin 3.0.3 or later release 

 Enterprise DLP now supports connectivity to the DLP cloud service
 when the Panorama management server uses a Proxy for its outbound
 internet connection. 

 Support for HTTP/2 Traffic Inspection 

 Requires DLP plugin 3.0.2 or later release 

 Enterprise DLP now supports inspection of file and non-file based
 HTTP/2 traffic. 

 Web Form Data Inspection for Enterprise Data Loss
 Prevention 

 Requires DLP plugin 3.0.1 or later release 

 More data is being exchanged in non-file formats that leverage
 collaboration applications, web forms, Cloud applications, and
 social media. PAN-OS 10.2 supports inspection of non-file format
 traffic to strengthen your security posture and prevent exfiltration
 of sensitive data.
