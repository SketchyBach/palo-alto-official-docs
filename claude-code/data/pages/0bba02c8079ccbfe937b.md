 Supported Ciphers 

 Reference TLS 1.2 and TLS 1.3 ciphers supported in Cortex XSOAR 6.12. 

 Cortex XSOAR supports the following Cipher Suites for TLS1.2 and TLS1.3: 

 TLS ECDHE ECDSA with AES256 GCM SHA384 

 TLS ECDHE RSA with AES256 GCM SHA384 

 TLS ECDHE ECDSA with AES128 GCM SHA256 

 TLS RSA with AES128 GCM SHA256
