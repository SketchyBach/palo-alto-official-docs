 Change App Owner to an Onboarded Application 

 Change an app owner to an onboarded app. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 SaaS Security Posture Management license 

 Or any of the following licenses that include the Data Security license: 

 CASB-X 

 CASB-PA 

 After you onboard a SaaS app, you can change the app owner to manage all posture security
 violations for that specific SaaS app. This owner receives alerts whenever SaaS Security detects a rule violation on that SaaS app. You can modify
 the owner at any time to transfer posture security violations to a new owner. An
 owner must have an account on SaaS Security with the IT App Owner role. 

 Log in to 
 Strata Cloud Manager . 

 Select Configuration SaaS Security Posture Security Applications . 

 You can also assign Application Owners from Settings Type: SSPM . 

 Select the tile for the SaaS Application to which you want to assign all rule
 violations. 

 Click the gear to edit the app settings. 

 Choose an Application Owner or Add
Owner , if the administrator is not listed, then Save .
