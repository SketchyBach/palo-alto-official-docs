 View the Overall Status of Prisma Agents 

 Monitor the overall status of Prisma Agents in the Inventory
 page. 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 NGFW (Managed by Panorama) 

 Check the prerequisites for the deployment you're
 using 

 Contact your Palo Alto Networks account representative to activate the Prisma Agent feature 

 The Endpoint Management
 page contains a dashboard showing the overall status of the Prisma Agents 
 that have been deployed to mobile users in your organization. 

 You can use the information that is displayed on this page to gain visibility into the
 Prisma Agents . The data can help you understand how your end users are
 using the agent and how to improve their experience. 

 To view the dashboard, select Configuration Endpoint Management . 

 When the Prisma Agent is deployed to an endpoint or when an end user
 connects to the gateway using the Prisma Agent , the user's device appears
 in the inventory in the Endpoint Management
 page . The following areas of the dashboard give you a comprehensive view of the status of
 the Prisma Agents : 

 Agent Status —Shows the total number of
 agents that have been deployed, and the number of agents with the following
 statuses: 
 connected —The number of agents that have a tunnel
 connection to the gateway. 

 disconnected —The number of agents that don't have an
 active tunnel connection to the gateway or are signed out of the Prisma Agent user interface. 

 If the
 user signed out of the Endpoint Management using the pacli
 epm signout command, the agent status is
 Offline . 

 offline —The number of agents that have no
 connectivity to the Endpoint Management for the Prisma Agent 
 and no tunnel connection to the gateway. 

 Agent Upgrade Progress — ( macOS and Windows agents only ) Shows the upgrade progress of devices that are defined in an upgrade
 ring . You can see the total number of devices that have completed, failed, or
 pending upgrades. The completed status indicates that the agent is running the
 latest level of the agent shown in the Agent Version 
 field. 

 View Ring Details — ( macOS and Windows agents only ) Select this to show the number of devices that have completed, failed, or pending
 upgrades in each upgrade ring. Expand each ring section to view the agent upgrade
 details for the ring. 

 Agent Version —Shows the version of the Prisma Agent that has been rolled out. 

 Time Range —Sets the time range for which you want to view the
 data in the Devices table. You can view the data in a preset time range or customize
 the time range. The default is to show the data within the Past 30
 Days . 

 Add Filter —Filters the data in the Devices table by column
 heading and allows you to search for specific values for each filter. 

 Devices —Shows information about devices
 that have deployed Prisma Agents in a tabular format. By default, the
 following columns are shown: 

 Column Description 

 Hostname The hostname of the endpoint 

 User The user ID associated with the Prisma Agent 

 OS The operating system that is running on the endpoint 

 OS Version The version of the operating system that is running on the
 endpoint 

 Agent Status The status of the
 Prisma Agent 

 Compliance Status ( macOS and Windows agents only ) If MDM posture
 checks has been enabled, the MDM compliance status of
 the device: compliant ,
 non_compliant , or
 N/A if the device is not enrolled in
 your MDM tenant. 

 Last Sync Time ( macOS and Windows agents only ) The last time the Endpoint Manager synced the device's
 compliance status from your MDM tenant, based on the configured
 Polling Frequency . Shows
 N/A if the device has not been
 synced. 

 Insights ( macOS and Windows agents only ) If the endpoint insights option
 is enabled, a link to view diagnostic
 information about the device. 

 DLP Status ( macOS and Windows agents only ) The status of Endpoint DLP 

 Connected Location The Prisma Access location that the agent was last
 connected to 

 Agent Version The version of the Prisma Agent that is
 installed on the endpoint 

 Public
 IPv4 The IPv4 address assigned to the endpoint by the ISP 

 Private
 IPv4 The IPv4 address assigned to the endpoint by the
 gateway 

 Private
 IPv6 ( macOS and Windows agents only ) The IPv6 address assigned to the endpoint by the gateway 

 If the device is not an IPv6 host, or
 if you did not set up IPv6 dual
 stack support , NA appears
 in the column. 

 Ring ( macOS and Windows agents only ) The upgrade ring that the endpoint device belongs to. Devices
 are upgraded according to which ring that they belong
 to. 

 Last Seen The last time a keep-alive was sent to Prisma Access . 

 You can sort the entries in each column in ascending or descending order.
 To decrease or increase the number of columns shown in the table, or to reorder
 the columns, select the gear icon to manipulate the Table
 Settings . 

 You can reorder the columns in the table or sort the entries in each column
 in ascending or descending order. To narrow the scope of the data shown in the
 table, select the table Settings , and select or deselect
 the columns: 

 By default, only 10 rows of data per page are displayed. You
 can increase the number of rows to 25, 50, or 100 rows per page. 

 You can select up to 20 devices to perform actions on, such as
 upgrade agent, downgrade agent, download HIP Profiles, and download agent
 logs.
