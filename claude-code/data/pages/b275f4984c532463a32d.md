 inspect routing multicast mroute 

 Use the inspect routing multicast mroute command
to inspect the forwarding state of the multicast. 

 Command 

 inspect routing multicast mroute (table | cache)

 Options 

 table Enter table to display the multicast forwarding
route table entries. 

 cache Enter cache to display the entry of multicast forwarding
statistics. 

 Command Notes 

 Role Super, Read Only 

 Related Commands — 

 Introduced in Release 5.6.1 

 Example 

 inspect routing multicast mroute table
 (10.0.1.2,225.1.2.3) Iif: eth1 Oifs: eth3 State: resolved
 (192.168.3.5,226.1.2.3) Iif: eth3 Oifs: eth2 State: resolved
