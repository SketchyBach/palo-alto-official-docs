 What is Cortex Data Security? 

 Learn about Cortex Data Security capabilities and benefits. 

 When managing your data assets in the cloud, you need comprehensive data security to counter data sprawl and complex new risks. Cortex Data Security gives you complete visibility and real-time control by discovering, classifying, protecting, and governing sensitive data across your entire organization. 

 Cortex Data Security is included with your Cloud Runtime Security license giving you access to the following data security capabilities: 

 Data Security Posture Management (DSPM) to discover and assess your data at rest. 

 Data Loss Prevention (DLP) to prevent exfiltration across communication channels. 

 Data Detection & Response (DDR) to monitor real-time activity and stop breaches before they happen. 

 Data Access Governance (DAG) to rightsize access and enforce least privilege across human, non-human, and AI agent identities. 

 For more information see the Cortex Data Security Documentation
