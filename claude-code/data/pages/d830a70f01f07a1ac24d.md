Okta integration

This document provides step-by-step instructions for creating an Okta application that uses Public Key / Private Key authentication for integration with the Koi platform.

Koi integrates to Okta to enable automatic device group management and end user communications. Use the Okta integration to:

Fetches end user emails for notifications on policy violations and item removals

Syncs devices and users from Entra and automatically creates Koi endpoint groups based on Entra departments, assigning devices accordingly.

Prerequisites

Admin access to the Okta Admin Console

Admin-role access to the Koi platform

Create the Application

Log in to the Okta Admin Console

In the left sidebar, go to Applications → Applications

Click Create App Integration

Select API Services

Enter a name for the application (for example, Koi)

Click Save

Configure Authentication with a Key Pair

Open the application you just created

Go to the General tab

In the Client Credentials section, click Edit

Set Client Authentication to Public key / Private key

Under Public Keys, click Add Key

Choose Generate new key

Copy and securely store the private key (JSON format) — this will be used in Koi

Click Save in the Public Keys section

Click Save in the Client Credentials section

Grant Permission Scopes and Assign Read-Only Admin Role

In the application, open the Okta API Scopes tab

Grant consent for the following scopes:

okta.devices.read

okta.users.read

Open the Admin Roles tab

Click Edit assignments

Assign the Read-only Administrator role

Click Save changes

Connect Okta in Koi

Log in to the Koi platform

Go to Settings

Select the Integrations tab

Find the Okta integration and click Connect

Enter your Okta tenant domain (for example: yourtenant.okta.com)

Select OAuth as the authentication type

Enter your Okta App Client ID

Paste the private key (JSON format) you copied earlier

Click Update to complete the setup
