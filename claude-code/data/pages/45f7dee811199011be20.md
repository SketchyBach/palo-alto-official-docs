 Addressed issues in Cortex XDR agent 8.5.1 

 The following issues have been resolved in Cortex XDR agent release 8.5.1 

 Issue 

 Description 

 CPATR-26301 

 (Windows) 

 Fixed an issue with policy recalculation on endpoints having non-ASCII environment variables. 

 CPATR‑26119 

 (Linux) 

 Fixed an issue where in a rare scenario, the SPMD process may demonstrate a high CPU consumption during content update. 

 CPATR-25760 

 Fixed an issue that in rare circumstances may cause the NMAP distributed network scan to function incorrectly. 

 CPATR-25536 

 (Windows) 

 Fixed an issue that in rare cases may cause the print monitor service to halt if no print job node is matched. 

 CPATR-25273 

 (Windows) 

 Support added for Windows 11 24H2 

 CPATR-25268 

 (Windows) 

 Fixed an issue to improve the Cortex XDR agent security and stability posture. 

 CPATR-25063 

 (Windows) 

 Fixed an issue where false-positive alerts may be encountered due to policy reset during an agent upgrade.
