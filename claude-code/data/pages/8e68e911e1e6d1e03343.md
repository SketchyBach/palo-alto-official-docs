 Native IPv6 Support for Prisma Access Service Connections (Panorama) 

 Native IPv6 support for service connections in Panorama 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Panorama Managed) 

 Prisma Access license 

 Prisma Access 6.2 

 Use this procedure to enable native IPv6 support for Prisma Access service
 connections in Panorama. 

 Navigate to Panorama Cloud Services Configuration Service Setup Settings . 

 Select the Settings gear. 

 Enable IPv6 to activate IPv6 capabilities across your Prisma
 Access deployment. 

 Configure the IPv6 address with a subnet. 

 Click Enable IPv6 WAN , and select
 OK . 

 Configure the IKE Profile 

 Navigate to Network Profiles IKE Gateway 

 Add a new or modify an existing IKE gateway. 

 Select the IPv6 
 Address Type and click OK . 

 Configure an IPsec Tunnel 

 Navigate to IPsec Tunnels . 

 Add a new or modify an existing IPsec tunnel. 

 Select the IPv6 Address Type . 

 Ensure Tunnel Monitor is enabled and the
 Destination IP is an IPv6 address.
