 Modify Tags 

 Select Objects Tags to perform any of the
following operations with tags: 

 Click the Name to edit the
properties of a tag. 

 Select a tag in the table and Delete the
tag from the firewall. 

 Clone a tag to duplicate it with the
same properties. A numerical suffix is added to the tag name (for
example, FTP-1). 

 For details on creating tags, see Create and Apply Tags . For information
on working with tags, see View Rules by Tag Group .
