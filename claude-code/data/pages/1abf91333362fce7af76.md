 Addressed Issues for Cortex XDR Collectors 

 The following have been addressed in this release. 

 Issue 

 Description 

 CPATR-18340 

 (Windows) 

 Fixed an issue where in some cases, the XDR collector sent duplicate logs. 

 CPATR-18624 

 (Linux) 

 Fixed an issue where after a successful upgrade the start service failed. 

 CPATR-18615 

 (Windows) 

 Fixed an issue where XDR collector on Windows could not be uninstalled. 

 CPATR-17313 

 Changed the collected file name format to support multiple collected files per second.
