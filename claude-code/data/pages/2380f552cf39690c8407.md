 Incompatible Plugin Installed On Panorama 

 Incident Code 

 INC_NGFW_PANORAMA_PLUGIN_INCOMPATIBLE 

 Severity 

 Warning 

 Category 

 Device 

 Subcategory 

 Management 

 Description 

 This alert is triggered when the plugin installed on Panorama is incompatible
 with the currently running PAN-OS version. 

 Raise Condition 

 This incident is raised when one or more plugins installed on Panorama are found
 to be incompatible with the device's current PAN-OS version. The system
 periodically checks each installed plugin against the official compatibility
 matrix. If any plugin is determined to be unsupported, this incident is created to
 notify you of the potential issue. 

 Clear Condition 

 This incident will automatically clear once the system verifies that all plugins
 installed on Panorama are compatible with the current PAN-OS version. This
 condition is typically met after an incompatible plugin has been updated to a
 supported version or removed from the system.
