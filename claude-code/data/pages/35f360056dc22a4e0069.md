 When entering commands, the path is traced through the hierarchy
as follows: 

 For example, the following command assigns the primary DNS server
10.0.0.246 for the appliance: 

 [edit] 
username@hostname# set deviceconfig system dns-setting servers primary 10.0.0.246 

 This command generates a new element in the hierarchy and in
the output of the following show command: 

 [edit] 
username@hostname# show deviceconfig system dns-settings 
dns-setting { 
 servers { 
 primary 10.0.0.246 
 } 
 }
