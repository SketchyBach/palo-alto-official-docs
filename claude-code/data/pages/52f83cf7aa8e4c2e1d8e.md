 MSSP and Multi-Tenancy Deployment 

 Find Cortex XSOAR 8 SaaS FAQs for MSSP and multi-tenancy deployments. 

 How can enterprises and MSSPs activate a tenant in Cortex XSOAR 8? 

 Cortex XSOAR 8 is available as a single tenant and also as a multi-tenancy deployment for new customers. For information about the migration of existing MSSP and Multi-Tenancy users to XSOAR 8, see the Cortex XSOAR Migration Guide . 

 The Cortex Platform includes a Gateway component that allows customers to manage users and active tenants (same as XDR, XSIAM, and Xpanse). MSSPs and enterprises with multi-tenancy deployments can activate new tenants and manage permissions easily in one place. 

 In a multi-tenant environment, is there an option for some child tenants to be in the cloud and some On-prem? 

 Currently, this capability is not supported. 

 How is data segregated between tenants in SaaS? Does each tenant have its own instance or its own database? 

 Multi-tenancy uses an entirely separate environment per child tenant. Compute, storage, and DB are separated between child tenants. 

 Can multi-tenant SaaS have child tenants On-prem? 

 Multi-tenant SaaS will only support SaaS child tenants. In other words, we will not manage on-premise tenants. 

 Which services do child tenants have? 

 Child tenants have the exact same products/services as the main tenant. For example, if the parent tenant has SOAR only, each child tenant also has SOAR only. If the parent tenant has SOAR and TIM, each tenant also has SOAR and TIM.
