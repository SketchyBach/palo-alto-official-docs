 View Total Number of Notifications Sent to Each User 

 Once Self-Serve is enabled on a user's device, administrators can view the number of
 notifications that were sent to a user. 

 Where Can I Use
 This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 Prisma Access license 

 ADEM or Strata Cloud Manager Pro 
 license 

 GlobalProtect or Prisma Access Agent license 

 View the total number of notifications sent
to each user in the Monitored Mobile Users table
in the User Experience tab on Monitored
Mobile Users page. To do so, 

 Click Strata Cloud Manager Insights Activity Insights Users tab and change the Scope Selection to
 Prisma Access . 

 Click the number below Agent Users . 

 Scroll down to the Access Agent Users table. The
 Self Serve Notifications column in the table displays
 the total number of notifications which the user has received in the selected
 Time Range . Hovering over the number in this column
 will give you a breakdown of the types of notification that the user or group
 has received in the selected Time Range . If the
 Self Serve Notifications column does not display in
 the table, it is an indication that the Self-Serve feature is not enabled .
