 Replace a PA-5400 Series Base Card (BC) 

 Learn how to replace a Base Card in the PA-5400 Series
firewall. 

 The PA-5400 Series Base Card (BC) is not hot-swappable.
In the case of a failure, you must power off the appliance and disconnect
all power sources before removing the BC.
