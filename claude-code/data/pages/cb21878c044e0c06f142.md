 IPv4 Multicast for Advanced Routing Engine 

 Configure IPv4 multicast for the Advanced Routing Engine. 

 PAN-OS 10.2.2 supports IPv4 multicast on the
Advanced Routing Engine. You configure IPv4 multicast using PIM
interface timer profiles and IGMP interface query profiles. 

 You
can also create IPv4 mroutes for
Reverse-Path Forwarding checks if you want unicast packets to take
a different route from multicast packets. 

 Enable advanced routing . 

 Configure a logical router and
add interfaces to it. 

 Configure IPv4 multicast by
configuring PIM and IGMP. 

 Create PIM interface timer profiles . 

 Create IGMP interface query profiles .
