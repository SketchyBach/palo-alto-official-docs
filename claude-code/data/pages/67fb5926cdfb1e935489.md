 Deployment Steps 

 Review the plan and prepare considerations, and then follow the steps in the onboarding checklist to successfully deploy and onboard Cortex XSOAR 8 SaaS. 

 While Cortex XSOAR 8 SaaS is a unified platform, a successful deployment is rarely done all at once. Start with the essential, high-impact activities to get the core platform functional and critical data sources feeding into the system quickly. Once you have completed these steps, set up the less critical but important features.
