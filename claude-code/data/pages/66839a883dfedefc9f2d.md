 dump appdef version 

 Use the dump appdef version command to display the running Appdef,
 content, and Signature file versions of the application. 

 Command 

 dump appdef version 

 Options 

 None 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands 

 Introduced in Release 6.0.1 

 Example 

 dump appdef version
App-def-version : 8547-7317_000003.000050
App-content-config-version : 8490-7054
App-content-sig-version : 8547-7317
