 Notebooks scheduler 

 Schedule Cortex XSIAM Notebook jobs to automate recurring data enrichment. 

 Ensure automatic data enrichment by scheduling Notebook jobs to run immediately or on a schedule. 

 In the Notebooks window, on the left sidebar tab, right-click the file you want to run and select Create Notebook Job . 

 notebook-job.png 

 In the Create Job page, update the required parameters, such as the job name and output formats. 

 Select whether to run the job now or on a schedule. 

 The results of the scheduled job are reflected in the related rules as soon as the job runs.
