 HSM Authentication 

 Select Setup Hardware Security Module and configure
the following settings to authenticate the firewall to the HSM. 

 HSM
Module Authentication 

 Server Name 

 Select an HSM server name from the drop-down,
then select if you want to authenticate and establish trust using
automatic or manually generated certificates. 

 Automatic 

 Manual 
 If you select Manual ,
you need to import and install the HSM server manually generated
certificate. Export the HSM client certificate to install on the
HSM server. 

 Administrator Password 

 Enter the administrator password of the
HSM to authenticate the firewall to the HSM.
