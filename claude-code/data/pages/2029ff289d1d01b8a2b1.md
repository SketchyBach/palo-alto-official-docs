 Features introduced in this release 

 Marketplace Content Changes 

 This section describes the changes in content (integrations, playbooks, and indicators) from Cortex 8.8 to 8.9. 

 Content 

 Description 

 Change Type 

 NetQuest OMX integration 

 Introduced a new integration to manage network traffic flows by handling traffic lists directly in Cortex XSOAR. For more information, see Symantec Email Security Cloud . 

 New 

 CrowdStrike Falcon - T1059 - Command and Scripting Interpreter playbook 

 The new CrowdStrike Falcon Command and Scripting Interpreter playbook automates containment and remediation of command and scripting interpreter alerts based on the MITRE T1059 technique, where attackers abuse command and script interpreters to execute commands, scripts, or binaries. 

 New 

 Cortex XDR by Palo Alto Networks content pack 

 Updated with improved performance, enhanced documentation, and streamlined configurations for a better experience. For more information, see Cortex XDR by Palo Alto Network content pack . 

 Update 

 Crowdstrike Falcon content pack 

 Added Office File Detections (Macro) support, enabling enhanced detection and response for malicious macro-based threats. For more information, see CrowdStrike Falcon content pack .
