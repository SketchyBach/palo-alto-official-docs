 Maintenance releases in Cortex XSOAR 8.13 

 August 10, 2026 (master-8.13.0-8.13.0.16-e159785c) 

 This maintenance release includes the following bug fix: 

 Fixed an issue where the apt package upgrade caused system upgrade to fail. 

 July 13, 2026 (master-8.13.0-8.13.0.15-7c8e92e6) 

 This maintenance release includes the following bug fix: 

 Fixed multiple upgrade and infrastructure issues. 

 One-click sequential upgrades: Select a target version from the textual UI, and Cortex XSOAR automatically calculates and runs all required intermediate updates in order. The log tracks the progress of each step. If an update fails, the process stops, leaving the system on the last successful version. Upgrades cannot be undone.
