 Deployment steps 

 In Cortex XSOAR 8.12 On-prem, follow the core deployment and onboarding steps. 

 While Cortex XSOAR is a unified platform, a successful deployment is rarely done all at once. Start with the essential, high-impact activities to get the core platform functional and critical data sources feeding into the system quickly. Once you have completed these steps, set up the less critical but important features.
