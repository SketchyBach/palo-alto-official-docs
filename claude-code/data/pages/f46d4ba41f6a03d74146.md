 Step 3: Set up authentication 

 Authenticate users through the Customer Support Portal or using SAML SSO. 

 You can create users in the Customer Support Portal or by using SAML Single Sign-On (SSO) in the tenant. After you create users, they authenticate using the following methods: 

 Authenticate through the Customer Support Portal 

 Authenticate by using SAML Single Sign-On (SSO) in the Cortex Xpanse tenant 

 For information about setting up authentication, see User authentication .
