 Supported SaaS Applications with Selective Scanning 

 Learn about the cloud apps and asset types that are supported
with group-based selective scanning. 

 Group-based selective scanning is available on the following cloud apps. Not all cloud apps are
 conducive to selective scanning. A cloud app must integrate with Azure Active Directory
 Services or other Identity Providers (through Cloud Identity Engine ) and must enforce file
 ownership. Many cloud apps are designed to share files with multiple owners, so they
 don’t have the necessary characteristics to work in a selective scanning framework. 

 If you want similar results for Google Drive, use OU scanning.
