 Increase CPUs and Memory for Panorama on Azure 

 How to increase the virtual CPU cores and memory for
a Panorama™ management server on Microsoft Azure. 

 For the minimum CPUs and memory that Panorama™ requires,
see Increase
CPUs and Memory on the Panorama Virtual Appliance . 

 Log in to the Microsoft Azure portal . 

 On the Azure Dashboard, under Virtual machines , select
the Panorama virtual appliance. 

 Select Overview and Stop the
Panorama virtual appliance. 

 Choose the new virtual machine Size and then Select it. 

 Select Overview and Start the
Panorama virtual appliance.
