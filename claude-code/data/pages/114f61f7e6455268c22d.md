 Download Assets for Incidents 

 Learn how to download assets. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 Data Security license 

 Or any of the following licenses that include the Data Security license: 

 CASB-X 

 CASB-PA 

 Data Security enables you to download an asset to inspect it if an incident exists for
 that asset or if an asset was quarantined. For security reasons, Data Security does not enable you to download assets if the asset did not
 violate a policy and no remediation assessment is needed. Additionally, downloading
 an asset is a remediation action, and not all SaaS apps support this action. 

 You can also download an asset even when the asset is quarantined . 

 Log in to 
 Strata Cloud Manager . 

 Verify that your SaaS app supports downloads. 

 To download your asset, select Configuration SaaS Security Data Security Data Assets . 

 Select the Data Asset Name to display the asset’s
 details. 

 Select Actions Download File . 

 After the file compresses ( .zip ), the file downloads to
 your local drive. A decrypt password displays. Use the password to open and
 inspect the file. 

 The Download File option is
 available only for the following three scenarios: 
 When both current and past incidents are available, you can
 download the asset file for either of them. It gives you the same
 asset and content. 

 When either current or past incidents are available, you can
 download the asset file. 

 When past incidents are not listed but are available in a closed
 state, you can download the asset file. 

 When there are no current or past incidents, you don't have the
 Download File option.
