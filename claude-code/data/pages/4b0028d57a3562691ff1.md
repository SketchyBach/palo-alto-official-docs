 Welcome to the Cloud Identity Engine 

 Monitoring 

 Use the Cloud Identity agent to monitor the connection
to the Cloud Identity Engine and the on-premises directory or to
view logs. 

 Use this page to monitor the connection between the
Cloud Identity agent and the Cloud Identity Engine and the connection
between the Cloud Identity agent and your directory. 

 You can also use this page to search or clear the logs. For example,
when the agent initiates the connection to the directory, the following
log is created: 08/16/18 13:13:10:256-0800[Info 138]: Trying to connect to ad.example.com . 

 The complete agent debug logs are available in the CloudIdAgentDebug.log
file in the agent’s installation directory (by default, C:\Program Files (x86)\Palo Alto Networks\Cloud Identity Agent ). 

 Monitoring 

 Cloud Identity Engine Displays the status of the agent’s connection
to the Cloud Identity Engine (Connected or Disconnected). 

 Last Update to Cloud Identity Engine Displays the timestamp for the most recent update
from the agent to the Cloud Identity Engine. 

 Last LDAP Fetch Displays the timestamp for the most recent retrieval
of directory objects from your directory. 

 Log 
 Each log includes a timestamp, the log level
(for example, Info), and the message contained in the log. 

 Search —Search
the logs. 

 Search terms are case-sensitive. 

 Clear Log —Clear the current list of logs.
