 delete high-availability-key 

 Description 

 Delete the peer encryption
key used for high-availability (HA) on the cluster control links
of a WildFire appliance cluster’s controller node. 

 Syntax 

 delete { 
high-availability-key; 
} 

 Options 

 No additional options. 

 Sample Output 

 The highlighted line in
the output shows that encryption isn’t enabled on the HA control
links.
