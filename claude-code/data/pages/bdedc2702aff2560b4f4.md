 inspect dpdk ip-rules 

 Use the inspect dpdk ip-rules command
to inspect the ip address rules in the dpdk stack configured on
the device. 

 Command 

 inspect dpdk ip-rules 

 Options 

 None 

 Command Notes 

 Role Super, Read Only 

 Related Commands 

 inspect dpdk vrf 

 Introduced in Release 5.6.1 

 Example 

 inspect dpdk ip-rules 
 0: from all lookup 255 
 1: from all iif veth-peer-p lookup 254 
 2010: from all iif eth2 lookup 2010 
 2010: from all iif eth1 lookup 2010 
 2010: from all iif sl2 lookup 2010 
 2010: from all iif sl1 lookup 2010 
 2050: from 10.16.8.90 lookup 2050 
 2051: from 10.16.8.66 lookup 2051 
 2100: from all iif eth3 lookup 2100 
 2100: from all to 5.5.5.3 lookup 2100 
 2101: from 5.5.5.3 lookup 2101 
 2401: from 1.1.1.1 lookup 2401
 2402: from 9.9.9.2 lookup 2402
 32000: from all iif eth0 lookup 32000
 32000: from 10.16.8.26 lookup 32000
 32000: from all to 10.16.8.26 lookup 32000
