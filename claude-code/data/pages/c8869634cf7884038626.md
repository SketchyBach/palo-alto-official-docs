 Azure Data Explorer encryption at rest does not use a customer-managed key misconfiguration detected 

 Rule Details 

 Cortex AppSec Rule ID 

 APPSEC2_AZURE_11 

 Category - Subcategory 

 Storage - Encryption 

 Provider 

 AZURE 

 Severity 

 LOW 

 Framework 

 Terraform, Terraform Plan 

 Impact 

 Enabling encryption at rest using a customer-managed key on your Azure Data Explorer cluster provides additional control over the key being used by the encryption at rest. This feature is often applicable to customers with special compliance requirements and requires a Key Vault to managing the keys. 

 How to Fix 

 Resource: azurerm_kusto_cluster, azurerm_kusto_cluster_customer_managed_key 

 Arguments: cluster_id (of azurerm_kusto_cluster_customer_managed_key ) [source,go]
