 Access Experience User Interface

 informing you of possible application experience degradation.

 Enable Self Serve
 Notification 

 When a device, internet, or WiFi issue that may impact the performance of the
 user's applications is detected, a notification describing the issue appears on the
 user's device. Click Review in Access Experience to open the
 Access Experience page. This UI contains further information
 about the issue. 

 On MacOS, the first time an application attempts to display
a notification the operating system will ask the user for permission to do so, if the user select
no this disables notifications for this app in system settings. The user can
enable the notification at any time later on. On Windows, the notifications
are enabled by default. The users can enable/disable notifications
in their system
Settings. 

 The look and feel of the desktop notifications and the Access Experience user interface screens
 depend the brand and theme settings . So, they could
 differ a bit from the images shown in this guide.
