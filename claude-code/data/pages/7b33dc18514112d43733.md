 SD-WAN. 

 Where Can I Use This? What Do I Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 The following tables describe a list of event or incident codes, the event
 origin, its severity, and a description of each event as per the event category. 

 In Strata Cloud Manager → Incidents, these event codes are prefixed with INC_SDWAN_ . For example, SITE_CONNECTIVITY_DEGRADED becomes INC_SDWAN_SITE_CONNECTIVITY_DEGRADED in Strata Cloud Manager.
