 Configure IoT Security Playbooks 

 IoT Security playbooks in Cortex XSOAR 6x enable you to structure and automate many of your third-party security processes. Parse incident information, interact with users, and remediate. 

 IoT Security playbooks enable you to structure and automate many of your third-party security processes. 

 After you install the IoT Security content pack, you can configure integration instance settings to specify jobs that run IoT Security playbooks for third-party systems. For a list of the jobs that the various IoT Security integrations support, see the IoT Security Integration Guide .
