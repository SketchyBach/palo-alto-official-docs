 save wildfire api-key 

 Description 

 Use the save command
to save all API keys on the WildFire appliance to a file. You can
then export the key file for backup purposes or to modify the keys
in bulk. For details on using the WildFire API on a WildFire appliance,
see the WildFire API Reference . 

 Hierarchy Location 

 save 

 Syntax 

 save { 
wildfire { 
api-key to <value>; 
{ 
{ 

 Options 

 * to —
Enter the filename for key export. For example, to export all of
the API keys on the WildFire appliance to a file named my-wf-keys,
enter the following command: 

 admin@WF-500> save wildfire api-key to my-wf-keys

 superuser, deviceadmin
