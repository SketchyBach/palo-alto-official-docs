 Provision the VM-Series Firewall on a Hyper-V Host with PowerShell 

 Learn how to deploy the VM-Series firewall on Hyper-V using PowerShell. 

 Where Can I Use
 This? What Do I Need? 

 Microsoft Hyper-V 

 VM-Series Firewall License (BYOL) 

 Panorama 

 VM-Series plugin 

 Use these instructions to deploy the VM-Series 
firewall on Hyper-V using PowerShell. 

 Download the VHDX file. 

 Register your VM-Series firewall and obtain the VHDX file. 

 Go to https://www.paloaltonetworks.com/services/support . 

 Filter by PAN-OS for VM-Series Base Images and
 download the VHDX file. For example,
 PA-VM-HPV-7.1.0.vhdx . 

 Set up any vSwitch(es) that you will need. 

 Create a vSwitch by using the following commands. Give
the vSwitch a name and choose the switch type. 

 > New-VMSwitch -Name <"switch-name"> -SwitchType <switch-type> 

 Install the VM-Series firewall. 

 Create the new virtual machine and set the memory based on the VM-Series system requirements 
 of your VM-Series model. 

 > NEW-VM -Name <vm-name> -MemoryStartupBytes 4GB -VHDPath <file-path-to-vhdx> 

 Set the processor count based on the VM-Series system requirements 
 of your VM-Series model. 

 > SET-VMProcessor –VMName <vm-name> –Count 2 

 Connect at least one network adapter for the management
interface on the firewall. 

 Connect the default network adapter created during VM creation
to management vSwitch. 

 > connect-VMNetworkAdapter -vmname <vm-name> -Name <"network-adapter-name"> -SwitchName <"management-vswitch"> 

 ( Optional ) Enable MAC address spoofing on Hyper-V
if you are not using Layer 3 with hypervisor assigned MAC address. 

 > Set-VMNetworkAdapter -vmname <vm-name> -Name <"network-adapter-name"> -MacAddressSpoofing On 

 Power on the firewall. 

 For example: 

 > Start-VM -vmname <vm-name>
