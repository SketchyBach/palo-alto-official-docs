 PAN-OS® 10.2.13-h21 addressed issues.

 required to reauthenticate.

 PAN-269254 

 Fixed an issue where high CPU utilization caused GlobalProtect VPN
 tunnels to flap, users to be disconnected, and the CLI to become
 unresponsive. This occurred when a large number of GlobalProtect
 users were actively processing application traffic.
