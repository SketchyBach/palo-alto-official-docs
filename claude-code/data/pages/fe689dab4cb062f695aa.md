 Assign the App Administrator Role 

 If you are the account administrator or if
you are an app administrator for an app, then you can give another
user the App Administrator role for that app. 

 The App Administrator
role gives the user full access to all instances of that app. Users
with this role can also activate and deactivate app instances. 

 Log in to the Activation Console and select Settings ( 

 ) Access Management . 

 Use the sidebar to filter users as needed or search for
users using the search field. Select one or more users and then
click Assign Roles . 

 Select the app for which you want to assign the role. 

 Assign the App Administrator role for All
Instances . 

 Save your changes and then click Yes to
confirm the assignment.
