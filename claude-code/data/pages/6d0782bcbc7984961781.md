 FIPS Approved Ciphers and Algorithms 

 FIPS supports certain ciphers and algorithms. 

 Where Can I Use This? What Do I Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 FIPS and FIPS-CC modes supports the following ciphers and algorithms: 

 SNMP 

 SNMPv3 

 Security Level: ---auth, ---private 

 Auth Type: ---sha 

 Encryption Type: ---aes 

 Cipher suites for TLS connection between ION Device and Controller 

 TLS_ECDHE_RSA-AES256-GCM-SHA384 

 TLS_ECDHE_RSA-AES256-CBC-SHA384 

 TLS_ECDHE_RSA-AES128-GCM-SHA256 

 TLS_ECDHE_RSA-AES128-CBC-SHA256 

 SHA-1 is deprecated under NIST SP 800-131A and is not
 recommended for new deployments. Select SHA-256 or SHA-384 for current FIPS 140-3
 compliance alignment. SHA-1 is documented here for backward compatibility with legacy
 peers only.
