 Troubleshoot Reporting Errors 

 If Panorama fails to generate a report, or the report is missing expected data, its content
 versions (such as the Applications database) might differ from those on the managed
 collectors and firewalls. The content versions on Panorama must be the same as or lower
 than the content versions on the managed collectors and firewalls. For details, see
 Panorama, Log Collector, Firewall, and WildFire
 Version Compatibility .
