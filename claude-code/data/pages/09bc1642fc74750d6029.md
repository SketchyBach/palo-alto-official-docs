 Applications - Application Tests 

 View all the application tests that are
running on mobile user devices or remote sites. To edit a synthetic
test for an app, click the Application Test Name .
To rearrange the order in which the app test names appear in the
table, click the ( 

 ) button next
to the app test and drag the app test to the desired location. 

 Column Name Description 

 Priority The order in which the application tests will
run. Each test gets a priority assigned to it in the order that
it was created. You can change the priority of the tests after you create
the test by dragging-and-dropping any test to the location in the
list where you want it to execute. Be sure to Save your
changes. 

 Application Test Name Name of the application test. 

 Date Created Date when the test was created. 

 Application Name App-ID of the application for which the test
was created. 

 Assigned Mobile User Devices The Mobile User device to which this test has
been assigned. 

 Assigned Remote Sites The Remote Site device to which this test has
been assigned. 

 Excluded Remote Sites When pushing a test to the remote site. if
the remote site branch device has the capacity available to run
the test, the test will be enabled. Otherwise, the remote site gets moved
under the Excluded Remote Sites and the app
test will not be pushed to it. If you absolutely must run the app
test on the remote site device, you can move app test priority by dragging-and-dropping
it to a higher location in the table. Click the ( 

 ) button next
to the app test and drag the app test to the desired location.
