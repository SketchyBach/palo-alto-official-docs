 Azure Manual Onboarding: Subscription Scope 

 Offboarding and resource decommissioning (optional) 

 To decommission all manually created resources, remove them in the following order: 

 Ask Copy 

 # 1. Remove subscription-scoped Cortex role assignments 
 for ROLE in \ 
 " <PLATFORM_BASE_ROLE_NAME> " \ 
 " <DSPM_ROLE_NAME> " \ 
 " Key Vault Crypto Service Encryption User " \ 
 " <ADS_ROLE_NAME> " \ 
 " <REGISTRY_ROLE_NAME> " \ 
 " <AUTOMATION_ROLE_NAME> " \ 
 " <KSPM_ROLE_NAME> " ; do 
 az role assignment delete \ 
 --role "${ ROLE }" \ 
 --assignee " <CORTEX_OBJECT_ID> " \ 
 --scope " /subscriptions/<SUBSCRIPTION_ID> " || true 
 done 

 # 2. Remove RG-scoped Cortex role assignments 
 for ROLE in " <DSPM_RG_ROLE_NAME> " " <ADS_RG_ROLE_NAME> " ; do 
 az role assignment delete \ 
 --role "${ ROLE }" \ 
 --assignee " <CORTEX_OBJECT_ID> " \ 
 --scope " /subscriptions/<SUBSCRIPTION_ID>/resourceGroups/<RG_NAME> " || true 
 done 

 # 3. (If Audit Logs is enabled) Remove the subscription-level diagnostic setting 
 az monitor diagnostic-settings subscription delete \ 
 --name " cortex-activity-logs-export " || true 

 # 4. Delete the shared resource group 
 az group delete --name " <RG_NAME> " --yes --no-wait 

 # 5. Delete every custom role definition created 
 for ROLE_NAME in \ 
 " <PLATFORM_BASE_ROLE_NAME> " \ 
 " <DSPM_ROLE_NAME> " " <DSPM_RG_ROLE_NAME> " \ 
 " <ADS_ROLE_NAME> " " <ADS_RG_ROLE_NAME> " \ 
 " <REGISTRY_ROLE_NAME> " \ 
 " <AUTOMATION_ROLE_NAME> " \ 
 " <KSPM_ROLE_NAME> " ; do 
 az role definition delete --name "${ ROLE_NAME }" || true 
 done
