 Remove Configuration Snippet Through the Strata Multitenant Cloud Manager 

 Learn how to remove Bulk Config Snippets through the Strata Multitenant Cloud Manager 

 Where Can I Use
 This? What Do I Need? 

 Strata Multitenant Cloud Manager 

 Prisma Access license 

 Identity & Access
 role : Multitenant Superuser or Superuser 

 After you assign and push snippets to your tenants, you can remove a
 snippet from an individual tenant. 

 Access the 
 Strata Multitenant Cloud Manager , and select Manage Bulk Configuration . 

 Scroll or search to find the tenant where you want to remove the snippet. 

 Remove Configuration . 

 You can remove a configuration if the previous push
 was a success and the status is synced. You cannot remove a configuration if
 the status is unassigned or in progress.
