 Understand and prioritize CI/CD instance assets 

 Access, review, filter, and prioritize CI/CD instance assets. 

 How to access CI/CD instance assets 

 Under Inventory , select All Assets → Code → CI/CD Instances . 

 The CI/CD Instances page includes a dashboard and an inventory. 

 CI/CD instance dashboard 

 The dashboard displays connected CI/CD providers and their discovered instances. Providers include Jenkins, GitHub Actions, GitLab CI, Azure Pipelines, and CircleCI. 

 Select a provider to filter the inventory table. 

 CI/CD instance asset inventory 

 Select Menu Settings to view additional properties. 

 Property 

 Description 

 Name 

 The instance name discovered through the CI/CD integration. It is the primary asset identifier. 

 Provider 

 The CI/CD platform hosting the instance, displayed with a provider icon. 

 URL 

 A direct link to the CI/CD platform console. 

 Last Observed 

 When the active integration last detected or synchronized the instance. 

 Pipeline Count 

 The number of pipelines hosted by the instance. 

 Filter and prioritize CI/CD instances 

 Use search and filters to narrow the inventory by operational and security metadata. 

 High-priority filtering workflows 

 Use these filters to prioritize remediation: 

 Scope by CI/CD provider: Filter by Provider or select a dashboard provider. This isolates provider-specific misconfigurations. 

 Assess blast radius: Review Pipeline Count to identify instances hosting many pipelines. Prioritize these platforms to reduce risk broadly.
