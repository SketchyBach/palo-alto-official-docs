 AL_SC_PRIMARY_WAN_TUNNEL_DOWN 

 Learn about the AL_SC_PRIMARY_WAN_TUNNEL_DOWN alert. 

 Synopsis 

 The primary WAN tunnel <tunnel-name> for the service connection is down. 

 An alert is raised if in 10 minutes, the primary WAN tunnel for the service
 connection is not detected to be up. 

 Alert Code—AL_SC_PRIMARY_WAN_TUNNEL_DOWN
