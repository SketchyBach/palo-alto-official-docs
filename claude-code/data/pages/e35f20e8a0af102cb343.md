 View and manage Criteria via the tenant (UI) 

 You can view and manage existing Criteria configurations in the criteria inventory table: 

 Navigate to Modules → Application Security → Application Management → Criteria . 

 The criteria table displays all existing criteria with the following information. 

 Property 

 Description 

 Name 

 The display name of the criteria 

 Type 

 The criteria type: Code (VCS-based) or Cloud (tag-based) 

 Application Count 

 The number of applications generated by the criteria 

 Asset Count 

 The total number of assets grouped across all applications generated by the criteria 

 Refresh Status 

 The current processing state: In Progress or Done 

 Created By 

 The user who created the criteria 

 Created At 

 The timestamp when the criteria was created 

 Supported actions 

 The criteria table supports the following actions: 

 Create Criteria : Select New Criteria to open the criteria creation wizard 

 Delete : Remove a Criteria and all applications generated by the criteria: select a criteria row, right-click and then select Delete
