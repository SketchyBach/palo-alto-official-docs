 Onoarding & configuration 

 Configure Cortex Cloud for a FedRAMP deployment. 

 To implement a government-authorized environment, specific steps must be taken during the setup process: 

 Onboarding : Use the cloud onboarding wizard to connect a Government Cloud Service Provider (CSP) environment to Cortex Cloud. 

 Environment selection : During configuration, select the Government option in the Environment menu to ensure the tenant adheres to federal security standards. 

 Scan mode : You can select Cloud Scan or Scan with Outpost . 

 Note: If you choose an outpost scan, you must select an outpost that has the environment type defined as Government to maintain compliance and connectivity.
