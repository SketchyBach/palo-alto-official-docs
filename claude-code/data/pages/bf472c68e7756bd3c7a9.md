 System Requirements 

 Review the system requirements for the Terminal Server
(TS) agent 11.0 release. 

 The system where you install Terminal Server (TS) agent
11.0 has the following minimum requirements: 

 CPU —4 cores 

 Hard disk space —10MB 

 Memory —4GB RAM
