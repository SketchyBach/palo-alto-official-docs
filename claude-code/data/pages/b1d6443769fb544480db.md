 GlobalProtect 6.3.5 Android Addressed Issues 

 The following table lists the issues addressed in GlobalProtect app 6.3.5 Android. 

 Issue ID 

 Description 

 GPC-24657 

 Resolved an issue where the GlobalProtect client on Chromebooks
 frequently disconnections due to StopThreads and TimeoutException
 when connecting to an NLB-enabled gateway. 

 GPC-22689 

 Fixed an issue where Chromebooks were unable to connect to the
 Network Load Balancer (NLB) gateway due to an invalid prefix length.
 This issue occurred because VPN route values were corrupted on
 Chromebooks due to memory constraints before the tunnel setup.
