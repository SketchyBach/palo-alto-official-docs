 What new hardware features are in PAN-OS 10.1? 

 Hardware features in PAN-OS 10.1. 

 New Hardware Feature Description 

 PA-400 Series Firewalls 

 ( The
PA-410 firewall is available for PAN-OS 10.1.2 and later ) 

 The PA-400 Series firewall is optimized for
price and performance. The PA-400 Series provides faster boot times,
higher performance, increased flexibility in deployments, improved SD-WAN
integration, and cloud management. 

 PA-5450 Firewall 

 The PA-5450 firewall is a new high-end modular
appliance that allows you to scale interfaces and data processing
using Networking Cards (NCs) and Data Processing Cards (DPCs) to
fit your deployment needs.
