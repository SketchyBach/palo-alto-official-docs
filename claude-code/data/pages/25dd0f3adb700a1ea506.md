 Set Up the Prisma Agent 

 Configure the Prisma Agent for deployment to endpoints. 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 NGFW (Managed by Panorama) 

 Check the prerequisites for the deployment you're
 using 

 Contact your Palo Alto Networks account representative to activate the Prisma Agent feature 

 After you set up the infrastructure settings that are specific to the Prisma Agent , you can configure the Prisma Agent for
 deployment to your mobile users. 

 You can configure settings such as user authentication settings , Prisma Agent settings , and staged rollout settings . (Staged rollouts are not supported on
 Prisma Agent Linux.) 

 You also can customize some settings globally. These global app
 settings apply to the Prisma Agent across all devices. Other
 agent settings are set by default. You can then customize these options and, based on
 match criteria , target them to specific
 users. The match criteria that you define for agent settings tell Prisma Access the users who should receive the settings.
 For example, you can specify that a rule applies only
 to a test user
 group. 

 Be sure to set up user authentication before you complete the first
 Push Config . 

 The Prisma Agent tab in the Access Agent Setup page shows the current
 configurations. You can add or edit the configurations. 

 On a Prisma Agent and GlobalProtect coexistence tenant, you will need to
 manually configure the Prisma Agent settings. There is no mechanism to
 migrate the GlobalProtect app settings to the Prisma Agent .
