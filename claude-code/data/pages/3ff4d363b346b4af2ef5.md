 Device > Cloud Redistribution > Contributing 

 Configure the firewall to contribute locally learned user or device context to other
 firewalls through the cloud. 

 Add a Contributing entry to specify a data type your firewall
 contributes and the segment to which it contributes the data type. 

 Contributing Settings Description 

 Data Type 

 Choose the type of data to contribute to the cloud: 

 HIP Report —Host Information Profile (HIP)
 data collected from GlobalProtect endpoints 

 IP Port —IP address-to-port-to-username
 mappings 

 IP Tag —IP address-to-tag mappings 

 IP User —IP address-to-username
 mappings 

 Quarantine List —List of potentially
 compromised or non-compliant devices 

 User Tag —Username-to-tag mappings 

 Description Enter a description for the contributing entry (up to 63
 characters). 

 Enable Cloud Redistribution Enables this entry for cloud redistribution. 

 Enable Contributing Enables the firewall to contribute (upload) this data
 type to the cloud. 

 Segment 

 Add a segment Name and
 segment ID to identify the segment to which
 the firewall contributes this data type. To remove a segment entry,
 select it and click Delete .
