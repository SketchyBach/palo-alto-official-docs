 Camera 

 Prisma Browser Desktop Prisma Browser Extension Prisma Browser for Mobile 

 Full support No support No support 

 This feature controls whether or not websites that match the URL, application, or
 category in the rule have access to the device camera. This control isn't affected
 by specific content inspection - the settings in the When contains schedule. To set
 the Camera control: 

 From Strata Cloud Manager , select Configuration Policy Control Sets Data Control Data Leak Prevention 

 Select Camera . 

 Select one of the following options: 

 Allow - the Prisma Browser will
 allow using the camera in specific webpages. 

 Block - the Prisma Browser will
 block using the camera in specific webpages. 

 Click Set .
