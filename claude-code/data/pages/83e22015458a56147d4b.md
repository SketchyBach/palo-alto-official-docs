 Oracle Cloud Infrastructure cloud onboarding 

 Follow the Oracle Cloud Infrastructure onboarding wizard and Cortex XSIAM creates a custom Terraform authentication template to be deployed in Oracle Cloud Infrastructure. 

 Cortex XSIAM onboarding is the process of connecting your Oracle Cloud Infrastructure (OCI) cloud environment to Cortex XSIAM so it can continuously monitor and protect your cloud resources. This process establishes secure, least-privilege access using API Key authentication with an RSA key pair. Cortex XSIAM stores a reference to the private key and uses it to sign API requests to your OCI tenancy. You gain visibility into your cloud infrastructure through resource discovery, IAM permission analysis, and identity security monitoring. 

 The onboarding process provisions the infrastructure in your OCI tenancy required to monitor and analyze your cloud resources. The sections below describe the available capabilities, the resources created, the security model, and the step-by-step onboarding process.
