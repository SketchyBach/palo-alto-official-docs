 Change Preferences for the Dynamic Privilege Access Enabled Prisma Agent 

 After you log in to the Prisma Agent app, you can modify app preferences
 to change the way the app behaves. 

 Where Can I Use This? What Do I Need? 

 Prisma Agent 

 macOS 14 and later or Windows 10 version 2024 and later desktop devices 

 Internet access 

 Use the Prisma Agent preferences window to view information about your
 device and to change options for your agent, such as enabling desktop
 notifications. 

 Launch the Prisma Agent by clicking the Prisma Agent 
 icon 

 from the macOS menu bar or
 Windows taskbar. 

 Click the hamburger menu to open the preferences window. 

 In the preferences window, you can view the following information: 

 Icon Description 

 Your user ID. 

 The Prisma Access location that your device is
 connected to. 

 The IP address of the Prisma Access location. 

 The hostname or IP address for the administrative
 interface (server) that you're connected to. You can
 click the plus ( + ) icon to
 connect to a different server. 

 The project you're signed in
 to. 

 To receive Prisma Agent notifications in the menu bar (on macOS)
 or taskbar (on Windows), Allow desktop notifications .
 This setting is enabled by default. 

 The desktop
 notifications
 will adhere to any "do not disturb" settings that you set at the time of
 installation. The operating system will prompt you to allow notifications
 from Prisma Agent at the time of installation. 

 To understand what data Prisma Agent collects and how the
 information is used, view Our Privacy Policy . 

 To get assistance
 on
 issues that you might encounter with Prisma Agent , click
 Support Resources . 

 If your administrator permits it, you can Sign Out of
 Prisma Agent . 

 If you administrator enabled the feature, you can
 Disable the Prisma Agent so that you can
 switch to the GlobalProtect
 app (if it is installed on your device). 

 View the version of your Prisma Agent . 

 To close the window, click the X .
