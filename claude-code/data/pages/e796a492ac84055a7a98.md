 Multicast Advanced Tab 

 Network > Virtual Router >
Multicast > Advanced 

 Configure the length of time a multicast route remains in the
routing table after the session ends. 

 Multicast Advanced
Settings 

 Description 

 Route Age Out Time (sec) 

 Allows you to tune the duration, in seconds,
for which a multicast route remains in the routing table on the
firewall after the session ends (range is 210-7200; default is 210).
