 Description 

 An unusual process was executed by the AWS Systems Manager agent. Adversaries may use the Systems Manager agent to execute malicious commands on an endpoint. 

 Attacker's Goals 

 Adversaries may execute malicious code using legitimate cloud administration tools. 

 Investigative actions 

 Verify if this is a legitimate script or command being run by an administrator using AWS Systems Manager.
