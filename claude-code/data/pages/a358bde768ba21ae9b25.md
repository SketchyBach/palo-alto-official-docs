Cisco Umbrella Guide

This guide explains how to integrate Koi with Cisco Umbrella SWG using the Bypass mode to direct marketplace traffic to Koi's proxy. Follow the steps below to ensure a smooth and secure configuration.

Prerequisites

Before starting the integration, make sure you have the following:

Access to the Cisco Umbrella Dashboard with admin privileges.

Organizational Root Certificate Authority (CA): Ensure it is installed and trusted by your organization's devices.

List of Marketplace Domains: Provided by Koi.

Proxy IP Address/FQDN + Port: Provided by Koi.

Signed Certificate: The CSR provided by Koi has been signed with your root CA.

Cisco Umbrella SIG Essentials license, or higher tier that supports SWG.

Steps to Integrate

1. Add Marketplace Domains to External Domains

Navigate to Deployments → Configuration → Domain Management.

Select the External Domains tab.

Add each marketplace domain provided by Koi.

Click Save.

This ensures marketplace traffic bypasses Umbrella's SWG and is routed directly to Koi's proxy.

2. Establish Trust

Since marketplace traffic bypasses Umbrella, endpoints connect directly to Koi's proxy. Endpoints must therefore trust Koi's certificate.

For instructions on deploying Koi's CA to your endpoints, see Establishing Trust.

3. Upload a Custom PAC File

Navigate to Policies → Management → Web Policy → Global Settings → Custom Files.

Click Upload PAC File.

Upload the PAC file provided by Koi.

The PAC file is located in your deployment portal under Set up Network → 2. Umbrella Integration.

Click Save.

The PAC file routes marketplace domains to Koi's proxy while leaving all other traffic unaffected.

4. Verify the Integration

From a managed endpoint, access any marketplace domain and navigate to /koi.

You should see Koi's custom page, confirming traffic is being routed correctly.

Summary

By completing these steps, you have successfully configured Cisco Umbrella to integrate with Koi. Marketplace domains bypass Umbrella's SWG and are securely routed to Koi's proxy for enhanced security and control.
