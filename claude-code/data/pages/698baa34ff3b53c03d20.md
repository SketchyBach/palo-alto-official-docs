 Troubleshoot Overlapping Text and Extra Pages 

 Troubleshoot PDF report layout issues in Cortex XSOAR 8 SaaS. 

 When creating or exporting a PDF of a report with long tables and large amounts of text, some text may overlap. You can avoid this by adding a page break after the long text. 

 Note 

 Adding page breaks manually might result in extra blank pages in the PDF. 

 In the report, after any widget that can potentially have a lot of text, click Add Widget . 

 In the Widgets Library section, search for Page Break Widget and click Add . 

 Repeat for other widgets. 

 Click Save .
