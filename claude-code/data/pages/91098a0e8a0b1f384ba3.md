# Unsafe Code Execution

Unsafe Code Execution

Severity

🟠 High (7)

Short Description

Flags plugin or hooks whose command runs dangerous shell operations such as rm, chmod, or curl piped into a shell.

Suggestion

Assume these commands will run, because hooks fire without user action. Verify each operation is necessary and correctly scoped; treat recursive deletion, permission changes, and execution of fetched content as disqualifying unless the publisher documents them clearly.

Information

Where Code Execution flags that a hook runs commands at all, this finding flags the dangerous subset: recursive deletion, permission and ownership changes, process termination, disk operations, disabling security tooling, and downloading remote content directly into a shell interpreter.

Two things make this severe. The operations are irreversible: once they run there is no recovery path, and their effects on data, file permissions, and security tooling outlast the plugin that caused them. And because these are hooks, they execute on agent events with no confirmation step, so commands that would give any engineer pause run without anyone deciding to run them. Commands assembled from remotely fetched content are the sharpest case — what executes is decided by a remote server at the moment the hook fires, the reviewability problem described in Dynamic Context with destructive capability attached.

Risks

Irreversible data loss: Recursive deletion or disk operations destroy data with no recovery path.

Weakened host security: Permission and ownership changes can persist long after the plugin is removed.

Disabled defenses: Commands that stop security tooling or kill monitoring processes blind other controls.

Remote-controlled payload: Commands that execute fetched content run whatever the remote server returns at that moment.

Recommended Actions

Immediate action

Disable the hook or plugin before further analysis; the commands run unattended.

Identify affected devices and check for the specific damage the evidence describes.

Investigate and remediate

Read the evidence to see the exact commands, their targets, and their triggering events.

Where a command executes fetched content, retrieve that content and review what it does.

Verify file permissions and security tooling status on affected devices.

Remove the plugin unless the publisher documents each operation and the scope is demonstrably correct.
