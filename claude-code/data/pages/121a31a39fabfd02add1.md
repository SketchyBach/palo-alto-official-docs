 Data retention policy 

 Learn more about the default retention periods for all Cortex AgentiX licenses and the available retention add-ons. 

 All Cortex AgentiX licenses provide you with six months of default retention for cases and issues data, as well as agentic assistant chats and related artifacts. 

 Cases data is retained according to the Last Updated date. Issue data is retained according to the Observation Time date. Data collected within these dates is kept and displayed for six months. To ensure the accuracy of issues, Cortex AgentiX provides a grace period of up to 31 days for issues displayed in the Issues view, Issues table, and Cases view. 

 You can extend your license retention by purchasing a retention add-on. Each retention add-on provides an additional 31 days of case and issue retention and agentic assistant chats and related artifacts, in addition to the default six months. 

 For more information on your storage license details, see Dataset Management .
