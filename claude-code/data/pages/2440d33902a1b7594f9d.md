 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 Data Security license 

 Or any of the following licenses that include the Data Security license: 

 CASB-X 

 CASB-PA 

 When you first add a cloud app ,
 Data Security goes through a discovery phase where it: 

 Compares
the enabled data patterns and active policy rules against the information
about all users associated with your assets. 

 Gathers metadata for the assets (folder, repository, and table
names and information about the files, such as the owner and collaborators)
and the actual contents of the files. 

 Adds new incidents after it scans the assets. 

 Data Security monitors changes in all of your monitored cloud apps. How soon Data Security identifies incidents depends on a variety of factors, including the volume of
 users and the assets on your SaaS application, and the SaaS application provider’s
 process for queuing and API throttling . 

 Incidents triggered by data asset policy rules also
 appear in the Enterprise Data Loss Prevention (E-DLP) 
 Incident Management dashboard under the
 SaaS API channel. If the data asset policy rule doesn't use Enterprise DLP 
 match criteria, the incident appears without a Data Profile 
 or Report ID in the Enterprise DLP Incident Management
 dashboard.
