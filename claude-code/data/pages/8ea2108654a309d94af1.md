 Onboard Airtable App to Data Security 

 Prerequisites to be completed on Airtable 

 Go to your Airtable account and create a service account
 with administrator access. 

 Go back to the Users tab and select <Your Service Account> ... Edit admin access . 

 Select the Admin checkbox and
 Confirm . 

 Select your service account and generate a personal access
 token. 

 Ensure you select all the Scopes and
 add the <Your Company Name> Partner
 Organization as seen in the screenshot
 below. 

 Copy the token and keep it handy for onboarding later. 

 Select Airtable Admin Panel Settings and ensure that the Enable Change
 Events option is available and enabled. Contact
 Airtable Support team for
 more information. 

 Add Airtable to Data Security 

 Log in to 
 Strata Cloud Manager . 

 ( Recommended ) Add your Airtable domain as an internal domain . 

 Select Configuration SaaS Security Data Security Applications Add Application Airtable . 

 Select Airtable Add New . 

 In the Configuration page, enter the
 following and Connect . 

 Enterprise Account ID—Available in the Airtable admin panel
 below Settings or in the URL. 

 Personal Access Token—The token you created in STEP 1. 

 On successful onboarding, the following message is displayed. 

 Post Onboarding Steps. 

 Click View Onboarding Status 

 The various details about the onboarded Airtable App are
 displayed. 

 ( Optional ) Give a descriptive name to the Airtable
 instance to differentiate this instance of Airtable from other
 instances. 

 Add policy rules. 

 When you add a cloud app, Data Security automatically
 scans the app against the default data patterns and displays any
 match occurrences. As a best practice, consider the business use
 of your app to determine whether you want to Add a New Data Asset Policy Rule 
 to look for incidents unique to Airtable. 

 Configure or edit a data pattern. 

 You can Configure Data
 Patterns to identify specific strings of text,
 characters, words, or patterns to make it possible to find all
 instances of text that match a data pattern you specify. 

 Start Scanning Airtable App. 

 To start scanning the new Airtable app for risks, select Configuration SaaS Security Data Security Applications Airtable View Settings ... Start Scanning . 

 Data Security scans all assets in the associated
 Airtable App and identifies incidents. Depending on the number
 of Airtable users and assets, it might take some time for Data Security to complete the process. However, you can
 Monitor Scan Results on the Dashboard and begin to
 Assess Incidents . Monitoring the progress of the
 scan during the discovery phase enables you to Fine-Tune Policy
 rules to modify the match criteria and ensure better
 results.
