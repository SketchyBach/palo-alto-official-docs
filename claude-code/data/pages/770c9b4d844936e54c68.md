 INC_RN_DNS_SERVER_UNREACHABLE_PER_PA_LOCATION 

 Learn about the INC_RN_DNS_SERVER_UNREACHABLE_PER_PA_LOCATION incident. 

 Incident Code 

 INC_RN_DNS_SERVER_UNREACHABLE_PER_PA_LOCATION 

 Title Template 

 DNS server {target} is unreachable for location {location} for RN 

 Category 

 Network Services 

 Subcategory 

 DNS 

 Description 

 The DNS server is unreachable from the Remote Network for specific Prisma Access locations. This can lead to DNS resolution issues within those specific locations, affecting the ability of users or devices in those locations to resolve domain names to IP addresses for accessing resources. It is important to investigate and address this incident promptly to ensure proper DNS functionality and seamless network access for users within the affected Prisma Access locations. 

 Raise Condition 

 Incident is Raised when 85% of the instances can not reach the DNS server for the last 12 minutes across the PA location 

 Clear Condition 

 Incident is Cleared when instances are able to the DNS server for the last 6 minutes for the PA Location
