 Download and Install the Agent for Android 

 Where Can I Use This? What Do I Need? 

 Prisma Access Agent 

 Android 10 and later versions 

 Internet access 

 Before you can connect to the Prisma Access Agent , you must download and install the
 app from the Google Play Store. 

 Open the Google Play Store app on your Android
 device. 

 From the search results, select Prisma Access Agent . 

 Install the app. 

 When prompted, review and Accept the information for
 which Prisma Access Agent needs access. 

 Once installed, you can find the app icon on your home screen or in your app
 drawer.
