 Agent Configuration Settings overview 

 Manage global agent configuration settings for your Cortex Cloud environment. These endpoints allow you to retrieve and update settings that control agent behavior across content management, auto-upgrades, status timeouts, analysis options, and administrative cleanup. 

 Each configuration category includes dedicated endpoints for retrieving the current configuration and updating the associated settings. 

 Required license: Cortex Cloud Runtime Security or Cortex Cloud Posture Management.
