 delete wildfire api-key 

 Description 

 Delete an API key
from the WildFire appliance. Systems configured to use the API to
perform API functions on the appliance will no longer be able to
access the appliance after you delete the key. 

 Syntax 

 delete { 
wildfire { 
api-key { 
key <value>; 
{ 
{ 
{ 

 Options 

 + key <value> —
The key value for the key that you want to delete. To view a list
of API keys, run the following command: 
 admin@WF-500> show
wildfire global api-keys all 

 Sample Output 

 admin@WF-500> delete
wildfire api-key key <API KEY> 
APIKey <API Key> deleted 

 Required Privilege Level 

 superuser, deviceadmin
