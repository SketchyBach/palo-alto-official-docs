 Low 

 Description 

 A commonly abused process connected to a rare cloud resource. 

 Attacker's Goals 

 Communicate with the attacker's Command and Control (C2) infrastructure. 

 Investigative actions 

 Investigate the actor process connected to the cloud resource. 

 Is this use case usually takes place within the org? 

 Determine if the cloud resource is owned by your organization or a known external entity. 

 Assess whether this communication pattern is expected or not.
