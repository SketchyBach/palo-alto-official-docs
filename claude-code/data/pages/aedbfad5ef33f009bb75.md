 Features introduced in 2026

 Release Highlights 

 The following are the key highlights for this release. 

 FEATURE 

 DESCRIPTION 

 Elevated analyst experience with immersive AI 

 Accelerate time-to-resolution with a redesigned experience that leverages AI summarization, visualized issue relationships, and a Resolution Center to streamline your workflow. Contextual agentic assistance provides side-by-side support, guiding you through every step of an investigation directly within the unified case workspace. 

 Natural language querying 

 Generate and run XQL queries using AI prompts, accelerating threat hunting and investigations without specialized query expertise. 

 Agentic Assistant agents can only create XQL queries if the tenant is in the EU or US region. Agents in all regions can run XQL queries. 

 Cost-effective Cortex Data Lake tier 

 Reduce SOC costs with a flexible ingestion and storage subscription that supports real-time search and correlation for compliance, long-term investigations, and forensics. 

 Advanced Email Security enhancements 

 Assess and manage security posture by watching email threats and response actions unfold in real time from the new, interactive Email Security Command Center.
Available with the Advanced Email Security add-on. 

 Exposure Management enhancements 

 Validate active defenses and calculate true residual risk rather than theoretical vulnerabilities with Security and Compensating Controls. 

 New platform design experience 

 Move through the platform with greater ease and clarity. A refreshed, modern interface introduces a unified design language, delivering a smoother and more intuitive experience across the platform.
