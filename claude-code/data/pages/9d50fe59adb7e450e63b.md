(generate, import, renew, delete, and revoke) certificates, which
are used to secure communication across a network. You can also
export and import the high availability (HA) key that secures the
connection between HA peers on the network. Select Device Certificate Management Certificates Default Trusted Certificate
Authorities to view, enable, and disable
the certificate authorities (CAs) that the firewall trusts.
