 Configure Interfaces 

 A Palo Alto Networks next-generation firewall can operate
in multiple deployments at once because the deployments occur at
the interface level. For example, you can configure some interfaces
for Layer 3 interfaces to integrate the firewall into your dynamic
routing environment, while configuring other interfaces to integrate
into your Layer 2 switching network. The following topics describe
each type of interface deployment and how to configure the corresponding
interface types:
