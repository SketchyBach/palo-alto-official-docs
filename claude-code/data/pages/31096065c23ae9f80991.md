 Known Issues in Release 6.5.3 

 The following table lists the known issues in Prisma SD-WAN ION Device Release 6.5.3. 

 Issue ID Description 

 CGSDW-40451 This issue is resolved in ION version
 6.5.3-b20. MS Teams UDP media traffic is misclassified as STUN. The
 workaround is to create custom MS Teams app. 

 CGSDW-40082 This issue is resolved in ION version
 6.5.3-b20. ServiceLink WAN-to-LAN SSL traffic is denied with Zone-Based
 Firewall (ZBFW). The workaround is to create custom SSL
 app. 

 CGSDW-31611 The fp-rte process might crash due to a timing issue during ION
 device initialization after a reboot or upgrade. The crash results
 in traffic loss and a delay in the ION device's bootup
 process. 

 Known Issues in Release 6.5.2 

 The following table lists the known issues in Prisma SD-WAN ION Device Release 6.5.2. 

 Issue ID Description 

 CGSDW-29960 If overlapping IP addresses are configured on a branch site,
 syslogs are not visible on the DC ION device. 

 CGSDW-29923 The SNMPWALK command from the DC server does not work if
 overlapping IP addresses are configured on the branch site. 

 Known Issues in Release 6.5.1 

 The following table lists the known issues in Prisma SD-WAN ION Device Release 6.5.1. 

 Issue ID Description 

 CGSDW-31654 This issue is resolved in ION version 6.6.1. FC crashes at pan_sml_vm_set_field_flag() within the ml7 library. 

 CGSDW-30747 After adding or removing Prisma Access tags from site configurations, the charon process restarts, unexpectedly triggering an HA switchover. 

 CGSDW-26342 Prefixes received from a DC on the WAN path are being distributed back to the DC via the Standard VPN path causing a traffic loop. 

 CGSDW-26096 A standby DC ION device in a DC cluster does not forward the received traffic on the intra-cluster tunnel.
