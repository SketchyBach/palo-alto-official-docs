 Features introduced in PAN-OS® 9.1.

features introduced with the PAN-OS® 9.1 release, which requires
content release version 8203 or a later version. For upgrade and downgrade considerations and
for specific information about the upgrade path for a firewall ,
refer to the PAN-OS 9.1 New Features Guide .
The new features guide also provides additional information about
how to use the new features in this release.
