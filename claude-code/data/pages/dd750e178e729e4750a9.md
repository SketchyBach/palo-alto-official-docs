 clear routing ospf 

 Use the clear routing ospf command to clear all the open shortest
 path first (OSPF) sessions on a device and used to debug any routing-related issues on
 the device. 

 Command 

 clear routing ospf process ( vrf < process | interface= interface name > ) 

 Options 

 process Enter the process to reset all ospf (all
 vrf). 

 vrf 

 process: Enter process with VRF name to reset given OSPF. 

 interface: Enter the interface name or ID associated with VRF
 name to reset OSPF interface.
