 Create a Custom Report Based on Tagged Tunnel Traffic 

 Create a report to gather information based on the tag you applied to tunnel traffic. 

 Where Can I Use This? What Do I Need? 

 NGFW (Managed by PAN-OS or Panorama) 

 You can create a report to gather information
based on the tag you applied to tunnel traffic. 

 Select Monitor Manage Custom Reports and click Add . 

 For Database, select the Traffic, Threat, URL, Data Filtering,
or WildFire Submissions log. 

 For Available Columns, select Flags and Monitor Tag,
along with other data you want in the report. 

 You can also Generate Custom Reports .
