 Manage your SSH admin password 

 Manage the SSH admin password for Cortex XSOAR 8.11 On-prem. 

 You can change the SSH admin password from the textual UI. Use this password for SSH access or the VM console. 

 Set the password separately on every cluster node. Passwords do not synchronize between nodes. 

 In the textual UI, select Password Management . 

 Select Change admin password on next login . 

 Your current session remains active. The new password takes effect at your next login.
