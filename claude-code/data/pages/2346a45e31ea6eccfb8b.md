 Bind Domain to Sites 

 Learn to bind or map a domain to a site that it enables to access all the endpoints
 within groups or domains. 

 Where Can I Use
 This? What Do I Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 When you bind or map a domain to a site, it
enables you to access all the endpoints within groups or domains. Different
domains can be mapped to different sites, but only one domain may
be mapped per site. 

 Select Configuration Prisma SD-WAN Resources Service & DC Groups . 

 Select a site. 

 Select the appropriate domain from the drop-down next
to each site. 

 Save to update the mapping.
