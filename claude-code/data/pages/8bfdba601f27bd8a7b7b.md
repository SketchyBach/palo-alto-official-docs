 View if Self-Serve is Enabled for a User 

 View if Self-Serve is enabled for a user from
the User Experience tab on Monitored
Mobile Users page. To do so, 

 Open the Monitored Mobile Users page. 

 Click the User Experience tab
if not already open. 

 You should see the following two columns added to the Monitored
Mobile Users table. 

 Self Service
Notifications - for each user listed in the table, this
column tells you whether ADEM Self-Serve is enabled or disabled
by the IT Administrator. 

 Total Notifications - total notifications
which the user has received in the selected Time Range .
Hovering over the number in this column will give you a breakdown
of the types of notification that the user has received in the selected Time
Range . 

 Alternatively,
you can also view this information in the Self Serve tab
by scrolling through the Users list in the Select
Mobile Users or Groups widget. If the name appears in
the list, then Self-Serve is enabled for that user.
