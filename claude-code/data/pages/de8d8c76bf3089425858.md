 ATT&CK Tactic 

 Execution (TA0002), Discovery (TA0007) 

 ATT&CK Technique 

 Command and Scripting Interpreter: AppleScript (T1059.002), System Information Discovery (T1082) 

 Severity 

 Low 

 Description 

 The AppleScript interpreter process was executed via the command line containing a potential system information discovery command. 

 Attacker's Goals 

 Discover system info to facilitate escalation, lateral movement, and defense evasion. 

 Investigative actions 

 Analyze the command line and determine whether it performs any malicious or suspicious actions. 

 Check the events generated by the process or its children for potential malicious behavior. 

 Verify whether the system information being gathered could facilitate further attack stages.
