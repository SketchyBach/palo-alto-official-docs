# Active Directory

Skip To Main Content
Our Products
Active Directory

This topic explains how admins can automate the import of user information from Active Directory to Idira Identity Governance and Administration (IGA).

The CSV is pulled onto an SFTP server hosted by Idira IGA or your organization, and Idira IGA pulls the account information from there. For more information on this process, see Automate CSV syncs with SFTP.


If you want to use one or more AD domains as a directory, contact the support team to receive a PowerShell script necessary to generate a report. See Upload a directory with a CSV for information on how to upload a directory with a CSV.
Complete prerequisites

Ensure that PowerShell is up to date and installed on your server. For more information, see Install PowerShell on Windows, Linux, and macOS.

Ensure that you have admin access to the Microsoft server that contains your domain controller.

Create a service account on Active Directory with domain user access to export user data from AD and read/write access to the directory where the Active Directory script is stored.

Securely save the username and password of the service account for use in a later step.

Create an SSH Public/Private RSA Key:

Run the following command to generate a public/private key in the filepath that you defined. Do not add a passphrase to the key.

ssh-keygen -b 2048 -t rsa -f '/home/...'

Be sure to include the name of the key pair at the end of the filepath.

If you did not define a path, it is stored at /home/user_name/.ssh/ with the name id_rsa.

If you want to use Idira IGA’s SFTP server, open a ticket with our support team that includes the public key file and request an SFTP server.

Securely save the the private key filepath for use in a later step.

Either request creation of an SFTP server by Idira IGA or create your own SFTP server.

Add the application to Idira IGA

Add the On Prem Active Directory to Idira IGA. For more information, see Add an application.

Configure Active Directory

Copy the script below:

ADscript

Open the script in an editor like VS Studio and edit the $DNs = @("DC=yourdomain,DC=com") variable to define what organizational units Idira IGA pulls accounts from.

If an OU is cyberark.com, the line is $DNs = @("DC=cyberark,DC=com").

You can also add multiple comma-separated OUs.
If the OUs are cyberark.com and zsec.io, this parameter is $DNs = @("DC=zsec,DC=io"), @("DC=cyberark,DC=com")

Update parameters to prepare to push the generated export to the SFTP server:

Parameter updates

Parameter

	

Description

	

Instructions




$isSftpEnabled = $false

	

Determines whether the CSV is sent to an SFTP server

	

Set this value to $true.




$sftpHost = "sftp.zillasecurity.com"

	

The hostname of the SFTP server the CSV is sent to

	

If you want to use the Idira IGA SFTP, do not change the default value.

If you want to use your own SFTP server, replace the value with the hostname of your server.




$sftpUsername = "<your domain.com>"

	

The username of the service account that needs to be created on the SFTP server

	

If you want to use the Idira IGA SFTP, go to Settings > Your Domains, and copy the first domain in the list.

Use this value to replace <your domain.com>.




$applicationId = "<application-id>"

	

The application ID of your Active Directory instance in Idira IGA

	

Go to your Active Directory application in Idira IGA and copy the string of characters in the address bar.

https://app.zillasecurity.com/ui/my/applications/1234a567b890c123d456/profile

Replace <application-id> with this value.




$sftpPrivateKeyPath = "<location of your private key>"

	

The full filepath and filename where you stored your SSH private key

	

Replace <location of your private key> with the private key filepath you saved in the prerequisite activities.




$Csvfile = "$path\directory.csv"

	

Setting that is used to change the name of the generated CSV file

	

Optionally, update the CSV file name.

Use task scheduler to automate when the script runs with the service account you created in the prerequisite activities. See How to Automate PowerShell Scripts with Task Scheduler for more details.

Configure Idira IGA

Search for and select the On Prem Active Directory application in Idira IGA .

Use the script you configured to manually generate a CSV.

In Idira IGA, click Sync Now and sync the CSV. For more information, see Sync an application with a CSV file.

When the initial sync is complete, click the gear button next to Sync Now.

Enable the Accounts & Permissions CSV File Upload and check the box to Use SFTP to automate CSV import.
