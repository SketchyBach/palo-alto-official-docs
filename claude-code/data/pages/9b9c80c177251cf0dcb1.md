 Adjust Policy Weights 

 Adjust the weight assigned to each static policy and the ML baseline to control how
 heavily each component contributes to user risk scores. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 Data Security license 

 Or any of the following licenses that include the Data Security license: 

 CASB-X 

 CASB-PA 

 Policy weights give you granular control over how each component of the risk scoring
 model contributes to user risk scores. By adjusting weights, you map the scoring
 system directly to your organization's risk appetite—for example, you can increase
 the weight of impossible travel detection if geographic anomalies are a primary
 concern. 

 Each weight is a value from 1 to 10, where 10 represents the highest impact on the
 risk score. A higher weight causes the corresponding component to contribute more
 heavily to the user's overall risk score . 

 The Policy Weight Management panel displays the current weight
 for each static policy and dynamic policy. Changes to policy weights are recorded in
 the platform's audit logs for compliance tracking. The
 configured weights actively drive the risk impact data shown on a user's activity
 timeline, allowing analysts to see exactly how each policy violation contributes to
 a user's risk score. 

 Select Behavior Threats Policies Policy Weight Management . 

 The Policy Weight Management page displays the current weight assigned to
 each static and dynamic policy. The Use Custom Weights toggle is
 enabled by default. 

 Modify the weights of each static and dynamic policy as per your need. The
 allowed values are: 1 to 10. 

 A higher weight means that violations of that policy contribute more heavily
 to the user's risk score. Consider setting higher weights for policies that
 align with your primary security concerns. If you disable the Use Custom
 Weights toggle, the default policy weight settings are used. 

 Click Apply . 

 The updated weights take effect immediately. Existing user risk scores are
 recalculated using the new weight configuration.
