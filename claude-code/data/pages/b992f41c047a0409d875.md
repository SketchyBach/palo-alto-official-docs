 What is Cortex Data Security? 

 Learn about Cortex Cloud Data Security capabilities and benefits. 

 When managing your data assets in the cloud, you need comprehensive data security to counter sprawl and complex new risks. Cortex Data Security gives you complete visibility and real-time control over these risks to protect your sensitive data everywhere. 

 Cortex Data Security is a unified platform that discovers, classifies, protects, and governs your data across cloud, SaaS, and AI environments. 

 As part of your Cloud Posture Management license, you get the Data Security Posture Management (DSPM) features of Cortex Data Security to discover and assess your data at rest. 

 You can get the full set of Cortex Data Security features with the Data Security Add-on , which unlocks Data Loss Prevention (DLP) to prevent exfiltration across channels and Data Detection & Response (DDR) to monitor real-time activity and stop breaches. 

 For more information see the Cortex Data Security Documentation
