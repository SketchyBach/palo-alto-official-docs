 Related Documentation 

 View the documentation related to the Terminal Server
(TS) agent 10.1 release. 

 Refer to the following PAN-OS® 10.1 documentation on
the Technical Documentation portal at docs.paloaltonetworks.com for more information
about the Palo Alto Networks next-generation firewalls: 

 User-ID Agent Release Notes —Provides
additional release notes, system requirements, new features, changes
to default behavior, addressed issues, and known issues for the
User-ID agent. 

 PAN-OS 10.1 Administrator’s Guide —Provides
the concepts and solutions to get the most out of your Palo Alto
Networks next-generation firewalls. This includes taking you through
the initial configuration and basic set up on your Palo Alto Networks
firewalls. 

 PAN-OS 10.1 Web Interface Reference
Guide —Describes how to administer the Palo Alto Networks
firewall using the web interface. The guide is intended for system administrators
responsible for deploying, operating, and maintaining the firewall. 

 Palo Alto Networks Compatibility
Matrix —Provides operating system and other compatibility
information for Palo Alto Networks next-generation firewalls, appliances, and
agents, including on which operating systems you
can install the TS agent .
