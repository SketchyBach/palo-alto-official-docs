 Create an API Key 

 This article describes how to create your first API key. 

 In Prisma Cloud DSPM, click Preferences , and go to the API tab. 

 Enter a meaningful name and a description for the API, and click Create Key .

 In the pop-up, click Copy API Key to copy the key, and click Done .

 The API key is created and its details are displayed in the API section of the tab. Congratulations. You've successfully created your first API key! 

 For further information, refer to the API endpoints documentation .
