 SASE Health Dashboard 

 Release Date: May 2025 
 | 
 Last Updated: May 2026 

 Monitoring the status and connectivity of a complex SASE deployment can be challenging. The new SASE Health dashboard provides a unified view for monitoring your entire SASE deployment, helping you quickly identify and resolve any issues. The dashboard displays detailed site and data center status and connectivity. It enables you to monitor the status and connectivity of your remote sites and data centers. The dashboard provides a map view showing the locations and status of sites and Prisma Access locations, as well as detailed metrics on on-site connectivity, experience scores across networks, and application availability. The dashboard is accessible through Strata Cloud Manager (SCM). 

 Use the SASE Health dashboard to identify any issues with remote site connectivity or performance. A map view gives you an overview of your network topology, while detailed metrics and trend charts allow you to drill down into specific sites or regions. 

 You need the following licenses to use the dashboard. 

 Prisma Access license managed by Panorama or Strata Cloud Manager. 

 Prisma SD-WAN license for Prisma SD-WAN specific data. 

 ADEM Observability or Strata Cloud Manager license to view certain data, especially for monitored applications and site experience scores. 

 A user role with permission to view the dashboard.
