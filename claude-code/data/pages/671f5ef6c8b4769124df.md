 View Misconfigurations by SaaS App 

 View the SaaS app misconfigurations in the SaaS Security Posture Management dashboard. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 SaaS Security Posture Management license 

 Or any of the following licenses that include the Data Security license: 

 CASB-X 

 CASB-PA 

 From the high-level overview in the Dashboard, you can drill down to view more information about
 the rules that are failing best practice and other security checks. 

 Log in to 
 Strata Cloud Manager . 

 Select Configuration SaaS Security . 

 Navigate to a rule violation. You can navigate to a rule violation through the
 SSPM dashboard, the Security Configurations page, or the Applications
 page. 

 To navigate to a rule violation through the SSPM dashboard, complete the
 following steps: 
 Select Posture Security Dashboard . 

 In the Rules by Status area, locate a failed rule and
 See Details . 

 On the Rule Information page's Settings 
 tab, click the Setting Name for a setting that has a
 violation. 

 To navigate to a rule violation through the Security Configurations
 page, complete the following steps: 
 Select Posture Security Security Configurations . 

 Select the Rules tab. 

 Select a rule that has a failed status. 

 On the Rule Information page, click the Setting Name for a
 setting that has a violation. 

 To navigate to a rule violation through the Applications page, complete
 the following steps: 
 Select Posture Security Applications . 

 View Details on a SaaS app tile to view
 failed rules for the app. 

 On the Security Settings tab, click the
 Setting Name for a setting that has a violation. 

 Take the necessary remediation actions.
