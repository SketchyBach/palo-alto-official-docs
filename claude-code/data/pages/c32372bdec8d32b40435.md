 Theme Color 

 Prisma Browser Desktop Prisma Browser Extension Prisma Browser for Mobile 

 Full support No support No support 

 The Prisma Browser allows users to modify the browser theme color.
 You can choose to let users select their own favorite color if they desire.
 Choose a specific color from a color palette, or enter colors based on the
 following color codes: 

 R G B 

 H S L 

 HEX 

 From Strata Cloud Manager , select Configuration Prisma Browser 
 Policy Controls Browser Customization 

 Select Theme Color . 

 Select one of the following options: 

 Users choose their own - allows users to select
 their own color. 

 Custom color - allows you to set the color scheme. 

 Click Set . 

 Brand Color 

 Prisma Browser Desktop Prisma Browser Extension Prisma Browser for Mobile 

 Full support No support No support 

 You can select a color that will be applied according to all user-facing browser
 elements. This includes dialogs, block pages, and other elements. 

 From Strata Cloud Manager , select Configuration Prisma Browser 
 Policy Controls Browser Customization 

 Select Brand Color . 

 Select one of the following options: 

 Default color – Prisma Browser will use the
 default color for browser elements. 

 Custom color - You can select a custom color for browser
 elements. 

 When selecting an accessible color,
 You should avoid indicative colors, such as red or green.

 For more information on accessible colors, refer to WebAIM . 

 Click Set . 

 Company Logo 

 Prisma Browser Desktop Prisma Browser Extension Prisma Browser for Mobile 

 Full support Full support Full support 

 The Prisma Browser allows you to select your own logo to increase branding
 awareness. The logo appears on the homepage, in messages sent to the users, and
 in the Browser Control Pane. 

 You can add a company logo, or no logo to leave the default Prisma Browser 
 Logo. 

 From Strata Cloud Manager , select Configuration Prisma Browser 
 Policy Controls Browser Customization 

 Select Company Logo . 

 Select one of the following options: 

 No Company Logo - The default Prisma Browser 
 logo will be displayed. 

 Set Company Logo - Drag the logo image or browse
 for it. 

 The logo image must conform to the following
 requirements. 

 File format - PNG or SVG only 

 Recommended width - 600 px 

 File size - up to 1 MB 

 The logo should be transparent (no background). 

 Click Set . 

 The logo will now be displayed on the homepage and all places where the
 logo is used. 

 Company Name 

 Prisma Browser Desktop Prisma Browser Extension Prisma Browser for Mobile 

 Full support Full support Full support 

 You can use the Company Name feature to add the organization's name to the top
 line of the browser. 

 From Strata Cloud Manager , select Configuration Prisma Browser 
 Policy Controls Browser Customization 

 Select Company Name . 

 Select one of the following options: 

 Set name - Enter the name that is to be
 displayed on the top of the homepage. It will appear as The
 <company name> browser - Powered by Palo Alto
 Networks . 

 Display no name - the display will show -
 Secure Browser - Powered by Palo Alto Networks . 

 Click Set . 

 The name will now be displayed on the homepage and elsewhere. 

 Custom Texts 

 Prisma Browser Desktop Prisma Browser Extension Prisma Browser for Mobile 

 Full support Full support No support 

 Custom Texts allows administrators to replace the default text displayed
 in user-facing dialogs, security prompts, and other browser messages with
 organization-specific language. Use this control to add context to policy
 enforcement — for example, explaining why an action is blocked and how
 users can request an exception. This control can also be used to provide
 localized text if required. 

 From Strata Cloud Manager , select Configuration Prisma Browser 
 Policy Controls Browser Customization 

 Select Custom Texts . 

 Select one of the following options: 

 Use default texts - All dialog texts, security checks, and
 other messages use the default, preconfigured text. 

 Customize and edit texts - Configure custom text for
 individual dialog entries. When selected, a sidebar navigation
 panel opens with the following sections: 

 Dialog Texts — Customize the text shown in
 browser action dialogs. Entries are grouped by category (for
 example, Clipboard Controls, File Controls, Identity
 Controls). Use the search bar to filter entries by name or
 text content. Use the category filter to narrow the list to
 a specific control group. 

 Security Checks — Customize the text shown in
 posture security check prompts. Use the search bar to filter
 entries. 

 Other — Customize the link name and URL in the
 Prisma Browser Extension About section.

 The Other section is
 limited to the Prisma Browser Extension. 

 To edit an entry, locate it in the list and click the pencil
 icon. In the Edit Text dialog, modify the Title 
 and Description fields. To revert an entry to its default
 text, click the undo icon next to that entry. 

 Text changes apply to all users covered
 by this profile. The Prisma Browser does not apply text
 customizations to the Prisma Browser for Mobile. 

 Click Set .
