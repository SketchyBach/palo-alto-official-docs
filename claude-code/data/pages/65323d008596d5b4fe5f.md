 Incident Code 

 INC_GLOBALPROTECT_GW_USER_AUTH_TIMEOUT_FAILURES_COUNT_EXCEEDED_ABOVE_BASELINE_ALL_PA_LOCATIONS 

 Title Template 

 Gateway auth timeout failures are higher than twice the baseline 

 Category 

 Network Services 

 Subcategory 

 Authentication 

 Description 

 There has been a higher than normal number of authentication timeout failures when users attempt to authenticate to the GlobalProtect gateway. This could result in user access issues and connectivity problems, as users may be unable to successfully log in to the VPN through the GlobalProtect gateway. 

 Raise Condition 

 Incident is Raised at tenant, when the average authentication timeouts are more than twice the baseline in 45 minutes 

 Clear Condition 

 Incident is Cleared at tenant, when the average authentication timeouts are less than twice the baseline in 45 minutes
