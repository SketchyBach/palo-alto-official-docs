 Remote Repository Server Configurations 

 Reference remote repository server configurations in Cortex XSOAR 6.12. 

 Key 

 Description 

 Default 

 UI.version.control.admin.only 

 Set to true to control access for pushing content from a remote repository. 

 Note 

 This key also removes the Save Version feature, which prevents users, who don't have administration permissions, from pushing content changes to the remote repository. 

 For more information, see Edit and Push Content to a Remote Repository . 

 false 

 ui.version.control.push.partial.packs 

 More granular control of the items in the Content Packs you want to push to production. For more information, see Edit and Push Content to a Remote Repository . 

 false 

 ui.version.control.show.remote 

 Configures a remote repository on a remote machine. For more information, see Configure a Remote Repository on a Development Machine and Configure a Remote Repository on the Production Machine .
