 Prisma SD-WAN Subscription Usage 

 The Prisma SD-WAN Subscription Usage feature offers users access to comprehensive
 reports on both site and tenant bandwidth consumption. 

 Where Can I Use This? What Do I Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 The Prisma SD-WAN Subscription Usage feature offers the
 users access to comprehensive reports on both site and tenant bandwidth consumption.
 This capability allows users to effectively monitor their bandwidth usage and facilitate
 the tracking and trending of monthly bandwidth utilization across all branch sites to
 ensure compliance with licensing agreements. 

 Go to Strata Cloud Manager System Settings Subscription Usage to view a graphical representation of the yearly bandwidth utilization
 (rolling), measured by maximum bandwidth (Mbps) consumed per month across All
 Branch Sites . The feature allows you to view the bandwidth consumption
 for a current month up until the previous month. 

 View the subscription usage of the Top 5 Branch Sites 
 for each month. Select the site name or hover over the chart to view the consolidated
 subscription usage of the sites for any month. Download .CSV files to view detailed
 subscription usage for all branch sites for a tenant and the summary subscription yearly
 usage for consolidated insights. 

 The Top Application Usage During Peak Utilization chart
 displays the bandwidth usage of the top 10 applications for a site during the peak
 utilization period. Select the month and site from the drop-down menu to view the top 10
 applications with the highest bandwidth usage for that time period. 

 Hover over a time interval in the graph to view the top 10 applications for
 that period. Refer to the color legend in the chart to see the list of the top 10
 applications for the selected time period at the site.
