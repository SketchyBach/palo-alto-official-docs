 Rule Details 

 Cortex AppSec Rule ID 

 APPSEC_CICD_360 

 Category - Subcategory 

 Pipeline Configuration - 3rd Party Services 

 Severity 

 CRITICAL 

 Impact 

 An MCP Server configured in the development environment has been archived or explicitly deprecated by its vendor or maintainer. Archived projects receive no security patches, bug fixes, or updates.
