 Mimecast 

 Mimecast 

 Use Mimecast data for Cortex AgentiX. 

 Important 

 This connector is only available for tenants that onboarded after July 26, 2026. For tenants that onboarded before this date, use Marketplace to access the standalone integration. For more information, see Marketplace . 

 The Mimecast platform offers protection against email threats and data leaks while preventing service downtime through email archiving and uptime services. Use this connector to run automation and fetch issues with Mimecast v2. 

 This connector includes the following sub-capabilities (Marketplace integrations link to PAN DEV for more information): 

 MimecastV2 : Mimecast unified email management offers cloud email services for email security, continuity and archiving emails. Please read detailed instructions in order to understand how to set the integration's parameters. This connector is available with any active Cortex XSIAM or Cortex AgentiX license. 

 To configure this connector, follow the steps outlined in the configuration wizard.
