 Panorama Support for Prisma Access 5.1 

 The Cloud Services plugin enables Panorama to manage Prisma Access. 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Panorama) 

 Prisma Access license 

 Minimum Required Prisma Access Version 5.1 Preferred or
 Innovation 

 Panorama Managed Prisma Access 5.1 and 5.1.1 use the Cloud Services Plugin 5.1 
 Cloud Services plugin. No plugin upgrade is required from 5.1 to activate Prisma Access
 5.1.1, but an infrastructure, 5.1 plugin hotfix, or dataplane
 upgrade might be required to unlock the 5.1 features. 

 If you're using Panorama to manage Prisma Access and need to upgrade to the 5.1
 plugin, you need to: 

 Review the required software versions for Panorama to support
 Prisma Access 5.1 Preferred and Innovation 

 Determine the upgrade path you'll need to follow for the Cloud Services
 Plugin 

 Upgrade the Cloud Services Plugin
