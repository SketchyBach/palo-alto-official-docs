 Use Summarizer to Analyze Your Canvas Data 

 Use Summarizer to get instant AI-generated narratives, highlighted insights, and
 data-point drill-downs across your AI Canvas visualizations without writing any
 queries. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 Strata Cloud Manager
 Pro license 

 Prisma Access license 

 Acceptance of the Strata Copilot SEULA for the tenant 

 Reading through multiple widgets and connecting patterns across them takes time and
 expertise. Summarizer eliminates that effort by generating instant natural language
 narratives at every level of your canvas—a canvas-wide overview that describes all
 widgets at once, a widget-level breakdown for a specific visualization, and a
 data-point drill-down that produces a forensic summary for a single value in a
 chart. Each summary surfaces highlighted insights based on recent data changes and
 suggests follow-up prompts to continue your investigation. When you drill into a
 data point, Summarizer also exposes the underlying query code and a direct link to
 open the matching logs in Log Viewer , so you can pivot from high-level patterns to
 raw log evidence in one step. 

 Select Strata Canvas AI Canvas from the Strata Cloud Manager menu, then open a canvas. 

 Click the Summarize canvas icon in the canvas
 toolbar. 

 The Summarizer panel opens on the right side of the canvas. Strata™ Copilot
 automatically begins generating a canvas-wide summary. 

 Review the AI Summary and Highlighted
 Insights sections. 

 AI Summary —A narrative overview describing the
 data displayed across all widgets on the canvas, including the data
 sources queried. 

 Highlighted Insights —A detailed analysis of
 notable trends and changes in your data over the selected time
 range. 

 ( Optional ) Type a follow-up prompt in the Summarizer panel or click
 one of the suggested prompts to dig deeper into a specific finding. 

 Suggested prompts appear at the bottom of each summary. You can select one
 with a click or enter your own question in the prompt bar. To get a summary
 focused on a specific widget, enter the widget title in the prompt bar. 

 Click any bar, row, or value in a chart to drill into a targeted summary for
 that data point. 

 Strata Copilot automatically generates a forensic summary for the selected
 value. The panel displays: 

 Highlighted Insights —Trends and patterns specific
 to the selected data point 

 Data Sources —The log tables queried for the
 summary 

 Query Code —The underlying query used to retrieve
 the data 

 Other Relevant Views —Related canvases that may
 provide additional context 

 ( Optional ) Review the Query Code and click
 Search it in Log Viewer to open Log
 Viewer pre-filtered with the data-point query. 

 Log Viewer opens with the query already applied, showing the raw log records
 that back the summary. You can further refine the query, export results, or
 pivot to a deeper investigation from there. 

 ( Optional ) Expand Other Relevant Views to see
 related canvases. 

 Strata Copilot surfaces canvases from your library that contain similar data
 or context, allowing you to navigate directly to them for a broader
 view.
