 Features introduced in 2025

 Release Highlights 

 Feature 

 Description 

 AgentiX AI Agent Workforce 

 Cortex Agentic Assistant: Go beyond rigid playbooks and command autonomous agents based on over 1.2 billion real-world playbook executions and governed by robust guardrails, to dynamically plan, reason and take action to solve any security challenge. 

 Cortex Agentic Assistant is included in Cortex Cloud. Availability of agentic capabilities may depend on specific licenses and is subject to supported regions. 

 Native MCP support: Now available in Beta, the Cortex MCP Server lets trusted LLM applications securely connect to Cortex Cloud and access data and insights in real time using natural language prompts. 

 Secure the software supply chain from development to deployment 

 With new Trusted Images policies and extended Registry Scanning for platforms like GitLab and Harbor, teams can detect vulnerabilities and secrets early. Our enhanced Agentless Disk Scan (ADS) also provides deeper visibility into all locally attached volumes, improving compliance reporting. 

 Expanded cloud runtime security with new support for self-hosted OpenShift clusters 

 Expanded cloud runtime security to the entire hybrid environment with new support for self-hosted OpenShift clusters. This extended visibility helps teams secure workloads running on-premise, close security blind spots, and ensure consistent controls across both public cloud and private infrastructure. 

 Enhanced API Security Investigation 

 Cortex Cloud now provides complete context into API threats, including attack activity, severity, and associated assets. This new feature empowers teams to rapidly assess risk and accelerate incident response, ensuring better protection for their critical APIs.
