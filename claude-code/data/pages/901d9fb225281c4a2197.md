 What is Cortex Cloud Runtime Security? 

 Learn about Cortex Cloud and the key integrated capabilities. 

 Cortex Cloud Runtime Security helps you secure cloud environments across posture, runtime, and investigation workflows. 

 It brings together workload protection, web and API protection, asset and risk context, and response workflows in one platform. 

 You can use Runtime Security to: 

 Onboard cloud accounts, clusters, registries, and integrations. 

 Detect posture, exposure, identity, data, and workload risks. 

 Investigate issues, prioritize findings, and respond faster.
