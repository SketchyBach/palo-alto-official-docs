 Rule Details 

 Cortex AppSec Rule ID 

 APPSEC_SECRET_378 

 Category 

 Secrets 

 Severity 

 CRITICAL 

 Framework 

 Git 

 Impact 

 Anthropic API keys provide access to Claude AI models and services. Exposed keys could allow attackers to consume your API quota, access conversation history, or use the service for malicious purposes at your expense. This could result in significant financial costs and potential data exposure. Rotate immediately. 

 How to Fix 

 Rotate the Anthropic API key immediately. Review API usage logs for unauthorized activity. Implement rate limiting and usage monitoring to detect anomalies.
