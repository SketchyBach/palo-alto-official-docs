 New Features - Autonomous DEM - 2021 

 ADEM Monitoring for Hybrid Workforce 

 Release Date: n/a 
 | 
 Last Updated: June 2026 

 To optimize user experience and application performance across hybrid work environments both on and off campus, Autonomous DEM (ADEM) now continuously monitors your mobile users . 

 Regardless of whether GlobalProtect® mobile users connect to Prisma® Access from an untrusted network or a trusted network, ADEM continues to provide user experience and application performance monitoring. Once ADEM is enabled when GlobalProtect Clients connect to Prisma Access, the feature seamlessly tracks application performance and provides unified visibility across your entire hybrid deployment.

 ADEM Support for Remote Sites 

 Release Date: n/a 
 | 
 Last Updated: June 2026 

 To gain end-to-end visibility into network and application experience for remote site users, A utonomous DEM (ADEM) is natively integrated with Prisma® SD-WAN . Previously, getting this visibility required separate tools and manual correlation of data from Prisma SD-WAN and Prisma® Access. 

 This comprehensive visibility allows you to quickly isolate which domains and WAN paths are experiencing degraded performance for remote site users and devices. The integration provides segment-wise insights across all WAN paths, including both active and backup connections. 

 This native integration means you can correlate remote site experience data with mobile user and application performance data in a single view. The segment-wise insights show performance across each hop of the WAN path, helping you pinpoint whether degradation originates at the branch, in transit, or at the application layer without switching between monitoring tools.

 Suppress ADEM Update Notifications on Mobile User Devices 

 Release Date: n/a 
 | 
 Last Updated: June 2026 

 To minimize disruptions for end-users, you can suppress all Autonomous DEM (ADEM) update notifications on mobile user devices . Previously, users received system notifications for agent updates. 

 Starting with GlobalProtect® version 5.2.8, administrators have the option to centrally disable these alerts. By suppressing these update notifications, you ensure a seamless background upgrade process for the ADEM agent without interrupting the user's workflow. This capability gives your IT teams full control over organizational communications regarding endpoint monitoring tools, ensuring that users only see critical, actionable coaching alerts. 

 Depending on your management environment, you can configure this suppression behavior in Panorama® Managed Prisma® Access for Mobile Users documentation or Cloud Managed Prisma Access for Mobile Users.
