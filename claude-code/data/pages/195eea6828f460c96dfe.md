Severity

Short Description

Flags publishers lacking installs on the marketplace, suggesting concerns about the publisher's reliability.

Suggestion

Exercise caution with extensions from publishers with low install counts. Consider using extensions from more established publishers if available.

Information

Publishers with low install counts may lack community validation, raising questions about their reliability and development practices.

Risks of Publisher Low Install Count

Limited Validation: A low install count indicates a lack of widespread adoption and scrutiny.

Trust Issues: Users may question the publisher's credibility or experience.

Inconsistent Support: Publishers with low adoption may not have the resources to provide regular updates or support.

Recommended Actions

Investigate the Publisher:

Assess Reliability: Review the publisher’s history and reputation in the marketplace.

Evaluate Alternatives: Look for similar extensions from publishers with higher install counts.

Immediate Action:

Replace If Necessary: Use extensions from more established publishers to reduce risks.

Monitor Closely: Track updates and community feedback for improvements.
