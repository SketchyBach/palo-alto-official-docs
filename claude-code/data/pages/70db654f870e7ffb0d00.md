 View if Self-Serve is Enabled for a User 

 IT Administrators can choose which users' devices have Self-Serve enabled on
 them. 

 Where Can I Use
 This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 Prisma Access license 

 ADEM or Strata Cloud Manager Pro 
 license 

 GlobalProtect or Prisma Access Agent license 

 To view if Self-Serve is enabled for a user: 

 Click Strata Cloud Manager Insights Activity Insights Users tab and change the Scope Selection to
 Prisma Access . 

 Click the number below Agent Users . 

 You can see the following two columns in the Access Agent
 Users table. 

 Self Serve Notifications - total notifications
 which the user has received in the selected Time
 Range . Hovering over the number in this column will
 give you a breakdown of the types of notification that the user has
 received in the selected Time Range . 

 Self Serve Status - for each user listed in
 the table, this column tells you whether ADEM Self-Serve is enabled
 or disabled by the IT Administrator.
