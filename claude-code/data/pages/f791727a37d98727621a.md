 Discard a Session Without a Commit 

 Use the CLI to discard a session that is taking up too many system
 resources. 

 Where Can I Use This? What Do I Need? 

 NGFW (Managed by PAN-OS or Panorama) 

 No prerequisites needed 

 Perform this task to permanently discard a
session, such as a session that is overloading the packet
buffer or on-chip packet descriptor . No commit is required;
the session is discarded immediately after executing the command.
The commands apply to both offloaded and non-offloaded sessions. 

 In the CLI, execute the following operational
command on any hardware model: 

 admin@PA-7050> request session-discard [timeout <seconds> ] [reason <reason-string> ] id <session-id> 

 The
default timeout is 3,600 seconds. 

 Verify that sessions have been discarded. 

 admin@PA-7050> show session all filter state discard
