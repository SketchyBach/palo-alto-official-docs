 Set Commands Changed in PAN-OS 11.2 

 Command line interface 'set' commands that are changed in PAN-OS 11.2: 

 Where Can I Use
 This? What Do I
 Need? 

 NGFW (Managed by PAN-OS or Panorama) 

 No prerequisites needed 

 The following commands are modified in the 11.2 release. 

 The ha1-a|ha1-b options were added to the following
 commands. 

 set deviceconfig high-availability interface ha1 port
set deviceconfig high-availability interface ha1-backup port 

 The hsci option was added to the following commands. 

 set deviceconfig high-availability interface ha2 port
set deviceconfig high-availability interface ha2-backup port
set deviceconfig high-availability interface ha3 port 

 The minimum value for the following commands were changed to 100. 

 set network profiles bfd-profile <name> min-tx-interval
set network profiles bfd-profile <name> min-rx-interval 

 The auto options was changed to value for the following commands. 

 set network interface ethernet <name> link-speed
set network interface ethernet <name> link-duplex 

 The cellular option was added to the following
 command. 

 set network virtual-router <name> routing-table ip static-route <name> path-monitor monitor-destinations <name> source 

 The validate option was removed from the following
 command. 

 set network routing-profile filters prefix-list <name> type ipv4 ipv4-entry <name> prefix entry network 

 The local deep learning option was added and imsi, imei, source
 uuid, dest uuid options were removed from the following command. 

 set shared reports <name> type threat group-by
set shared reports <name> type threat group-by 

 The imsi, imei options were removed from the following commands. 

 set shared reports <name> type wildfire group-by
set shared reports <name> type url group-by
set shared reports <name> type data group-by
set shared reports <name> type traffic group-by
set shared reports <name> type thsum group-by
set shared reports <name> type trsum group-by
set shared reports <name> type urlsum group-by
set reports <name> type wildfire group-by
set reports <name> type url group-by
set reports <name> type data group-by
set reports <name> type traffic group-by
set reports <name> type thsum group-by
set reports <name> type trsum group-by
set reports <name> type urlsum group-by 

 The project name options was added to the following command. 

 set shared reports <name> type globalprotect group-by
set reports <name> type globalprotect group-by 

 The 3 option was set as the max for the following command. 

 set global-protect global-protect-gateway <name> gp-gw-dhcp entry retry-time 

 The 30 option was set as the max for the following command. 

 set global-protect global-protect-gateway <name> gp-gw-dhcp entry dhcp-timeout 

 The alert option was added to the following command. 

 set profiles wildfire-analysis <name> mica-engine-wildfire-rules <name> action
