 Products That Use Autonomous DEM 

 Learn what Palo Alto Networks products support the Autonomoous
DEM service. 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 Prisma Access license 

 Autonomous DEM license 

 Autonomous Digital Experience Management
(DEM) is a service that provides native, end-to-end visibility and
insights for all Prisma Access mobile user traffic. Autonomous DEM
is an add-on service that you can purchase for Prisma Access, and
it is available for: 

 Cloud Managed Prisma Access —Autonomous DEM is currently supported for Cloud Managed Prisma Access mobile user
 deployments . After you purchase the service it is automatically
 available within the Prisma Access app on the hub. 

 Panorama Managed Prisma Access — Autonomous DEM is currently
supported for the Panorama managed Prisma Access Mobile User deployments.
After you purchase the ADEM service it is automatically available within
the Prisma Access app on the hub. Autonomous DEM is supported starting
with the 2.0 innovation and the 2.2 Preferred releases. Refer to this section for details.
After licensing Autonomous DEM, you can manage the service and review
experience scores for your network and your users from the Prisma
Access app on the hub.
