 Monitor User Device Experience 

 The User Devices tab in the NetSecHealth dashboard shows you the
 breakdown of the experience scores of monitored user devices along with device count of
 non-monitored devices. 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 One of these: 
 Prisma Access license and ADEM Observability 

 Strata Cloud Manager Pro 
 license 

The User Devices tab in the NetSecHealth dashboard shows you
 the breakdown of the experience scores of monitored user devices along with device
 count of non-monitored devices. By default, the User Devices tab is selected based
 on if you have a mobile user license or not. If not, this tab will not be displayed.
 The User Devices tab shows the experience score as Good, Fair, and Poor for all user
 devices in the organization. The tab also displays the count of number of users
 associated with the devices, number of devices not monitored by AI-Powered ADEM , and total number of incidents raised for these devices issues. 

 User Devices- Map View Interactions 

 In the map view, the number in the circles correspond to a cluster of user
 devices that are currently connected. A dot represents a single user device. A
 green circle or dot indicates a Good experience score. Likewise, a red one
 indicates a degraded experience score. Degraded experience scores comprise of
 Fair and Poor scores combined. A gray circle or dot indicates non monitored
 devices. This can be for several reasons, such as AI-Powered ADEM not
 being purchased, enabled, or properly configured for that device. 

 Hover over a circle on the map to view a summary of the number of devices
 with good, fair, poor, and unmonitored experiences in that location. 

 You can drill down on any Prisma Access location for a more detailed,
 city-level view. 

 Click on a device to open a detailed side panel with information about the
 end-to-end experience, segments causing degradation (like WiFi, LAN), open
 incidents, and the user's browsing experience. 

 Use the additional filtering options on the right side of the map to view
 the data based on users, data centers (NGFW and Prisma Access), and Prisma
 Access locations. 

 User Details 

 Click the circle to view the list of connected users at a location on the left
 panel. 

 Click the arrow to view the following: 

 All the open Prisma Access and NGFW incidents that have
 impacted this user device. 

 Browsing experience details for that user device. 

 Segment wise impact during the selected time range. 

 All the devices connected to the user ID. 

 Degraded User Experience 

 Select the Degraded User Experience tab from the User
 Devices Map view to open a side panel that lists segments causing issues
 (example, Devices, LAN, ISP). Click on a segment to filter the map to
 show only the user devices impacted by that specific segment. 

 Click the number in the User devices column to view the
 activity of users using the device. 

 View the Prisma Access and NGFW incidents that have impacted
 the user device. 

 User Device Experience Trends 

 View the trend of experience scores of all user devices that
 are connected and monitored during the selected time range. 

 View the network segments, the devices impacted by the
 segments, incidents raised for the issue.
