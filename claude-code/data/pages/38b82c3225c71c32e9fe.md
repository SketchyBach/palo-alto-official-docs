 AI Canvas Best Practices 

 Use Widget Clarification to Build
 Precise Widgets 

 Use Widget Clarification to refine
 your widget queries through a guided conversation before AI Canvas runs them, so your
 results match exactly what you intended. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 Strata Cloud Manager
 Pro license 

 Prisma Access license 

 Acceptance of the Strata Copilot SEULA for the tenant 

 Broad or ambiguous queries can
 produce widgets that don't reflect what you need—asking for "top users with high
 bandwidth" could mean total bytes transferred, bytes sent, bytes received, or
 average bytes per session, across different time windows. Widget Clarification, the
 first workflow powered by the Canvas Intent Engine, prevents that mismatch by
 turning widget creation into a short guided conversation. 

 When you enter a query in the
 Create Widget dialog, Strata™ Copilot acknowledges your request and
 asks a targeted clarifying question. It then offers suggested refined queries you
 can select, or you can type your own refinement directly. After you choose a
 direction, Strata Copilot presents a Proposed Plan that shows
 the exact executing prompt, data sources, query code, and chart type it will
 use—before running anything. You review the plan and either approve it or modify it,
 ensuring every widget is built exactly as you intended. 

 Select Strata Canvas AI Canvas from the Strata Cloud Manager menu. 

 Enter a natural language query in the search field and press
 Enter , or open an existing canvas and enter a query
 in the canvas prompt bar to open the Create Widget 
 dialog. 

 Review the clarifying question and choose a refined query. 

 Strata Copilot responds with Request Understood. and
 asks a targeted question to narrow the scope of your request. Several
 suggested refined queries appear below the question. You can: 

 Click one of the suggested queries to select it. 

 Type your own refinement directly in the prompt bar. 

 Review the Proposed Plan and click Yes,
 Run to generate the widget, or click
 Modify to adjust the plan before running. 

 The Proposed Plan shows a summary of the query intent along with the
 following details before any data is fetched: 

 Executing Prompt —The refined query Strata Copilot
 will run. 

 Data Sources Selected —The log tables the query
 will pull from. 

 Query Code —The underlying query generated from
 your prompt. 

 Chart Type —The visualization format Strata
 Copilot selected, such as Auto , bar, or
 table. 

 Review the generated widget, then click Add to Widget
 Library to save it. 

 The widget details panel on the right displays the full Proposed Plan
 alongside the chart—Executing Prompt, Data Sources Selected, Query Code, and
 Chart Type—so you can verify what was run at any time. 

 A confirmation notification appears when the widget is successfully added to
 your Widget Library .
