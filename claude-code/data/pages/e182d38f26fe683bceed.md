 Addressed Issues in Cortex XDR Agent 8.4 

 Cortex XDR agent 8.4.1 addressed issues 

 The following issues are addressed in this release. 

 Issue 

 Description 

 CPATR-25268 

 (Windows) 

 Fixed an issue to improve the Cortex XDR agent security and stability posture. 

 CPATR‑24594 

 (Windows) 

 Fixed an issue that in rare cases, may impact upgrading from older Cortex XDR agents. 

 CPATR-24120 

 (Linux) 

 Increased the log level of a message that is issued when event collection fails to start. 

 CPATR-22866 

 (Mac) 

 Fixed a rare race of agent process crashing (PMD), triggered by system process crash.
