 Prisma Agent is a remote access solution supported on both Prisma Access and
 Next-Generation Firewall (NGFW) environments. This dual support provides organizations
 with flexibility in their infrastructure choices while maintaining consistent remote
 access capabilities. Learn about the licensing support for Prisma Agent in these
 environments. 

 Prisma Access 

 To use Prisma Agent in your Prisma Access environment, you will need the
 Prisma Access license for mobile users and a Strata Logging Service license with
 proper firewall storage space. If mobile users will be connecting to other
 connected networks, you will need either the Zero Trust Network Access (ZTNA) or
 Enterprise Edition Prisma Access license that will provide the corporate access
 node (CAN) necessary to connect. 

 In the Prisma Access environment,
 you can manage Prisma Agents in two ways: 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 While you can use Panorama to independently manage Prisma
 Access and gateway configurations, Strata Cloud Manager serves as
 the central hub for managing Prisma Agent -specific settings,
 including user authentication, agent configurations, and staged
 rollout configurations. 

 For more information, see Your Prisma Access License . 

 NGFW 

 For information about the Prisma Agent license for NGFW, refer to NGFW Support for Prisma Agent .
