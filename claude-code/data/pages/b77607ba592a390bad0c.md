 Add a Post-Processing Script to the Incident Type 

 Add a post-processing script to an incident type in Cortex XSOAR 6.13. 

 Before you start you need to Create a Post-Processing Script . After you add a post-processing script to the incident type, all incident types will use the post-processing script. 

 Go to Settings → OBJECTS SETUP → Incidents → Types . 

 Select the incident type you want to add the post processing script. 

 Click Edit . 

 In the Post process using field, from the dropdown list, select the script. 

 post-process.png 

 Click Save .
