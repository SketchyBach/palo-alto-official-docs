Explore the end user API guides
Authentication
Idira Identity supports authentication process such as Adaptive MFA, external IDP authentication, social login, along with standards such as SAML and OIDC.
Guides
OAuth 2.0 & OpenID Connect
OAuth 2.0 allows client applications to access to protected resources, and OIDC is an authentication layer on top of OAuth. Idira Identity supports OAuth 2.0 & OpenID Connect protocols.
Guides
User self service
Idira Identity supports user self service actions such as registration, password reset, account unlock, forgot username and MFA enrollment.
Guides
Explore the management API guides
User management
Idira Identity provides APIs to add and manage Idira Idira Identity directory users, Active Directory users connected to the cloud service, and federated users.
Guides
Policy management
Idira Identity provides APIs to add and manage policies, which can define a user's MFA profile and security settings as well as manage endpoint authentication.
Guides
Application management
Idira Identity provides APIs to manage applications and assign users to browser-based apps, native mobile apps, and custom apps for single sign-on (SSO).
Guides
User life cycle management
Manage user life cycles using SCIM outbound and inbound provisioning APIs. Idira Identity also provides APIs to manage privilege accounts and related objects with SCIM APIs.
Guides
Device management
Manage mobile devices using device management APIs. The APIs can be used to enable or disable SSO, delete a device, lock, unlock, power off, wipe, or reboot a device, ping a device etc.
Guides
User behavior analytics
Idira Identity provides APIs to retrieve analytics data and add webhooks to invoke another web service after a security alert or Idira Identity Analytics server event.
Guides
Authenticate to Idira Identity Security Platform Shared Services

To run API calls from your specific service on the ISPSS platform, you'll need to first authenticate to Idira Identity Security Platform Shared Services.

In the ISPSS APIs site, see API token authentication for Idira ISPSS.
