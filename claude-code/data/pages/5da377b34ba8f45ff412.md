 Zoom QSS CloudBlade Integration 

 Release information for the Zoom QSS integration CloudBlade 

 The Zoom QSS CloudBlade integration helps in troubleshooting issues with Zoom application
 performance and reachability in the SD-WAN networks. It allows visibility into Zoom
 application data. Zoom provides application QoS metrics for consumption which can be
 utilised to troubleshoot issues pertaining to zoom service disruptions for users. 

 Zoom QSS CloudBlade Version 1.0.0 

 The following caveat is observed with the Zoom QSS CloudBlade version 1.0.0: 

 Zoom QoS metrics are not available for Linux based hosts. This means that zoom
 meeting data for users on Linux based systems will not be available in the
 dashboards.
