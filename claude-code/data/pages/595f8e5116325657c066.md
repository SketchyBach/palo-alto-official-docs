 Reference A: Objective scope filters 

 The scope defines which assets a vulnerability objective covers. The AppSec Agent (Agentix) maps your prompt to these asset filters. Every vulnerability objective targets code and artifact assets, where the asset category is Repository or Container Image . 

 Scope filter 

 Description 

 Category 

 Asset category: Repository or Container Image. 

 Business Criticality 

 The business criticality of the owning application: Critical, High, Medium, or Low. 

 Business Owner 

 The business owner of the owning application. 

 Business Application Name 

 The name of the owning business application. 

 Provider 

 The asset provider. 

 Is Public Repository 

 Whether the repository is public. 

 Is Archived Repository 

 Whether the repository is archived. 

 Repository Name 

 The repository name. 

 Repository ID 

 The repository identifier. 

 Repository With Deployed Assets 

 Repositories that have deployed assets. 

 Repository With Internet Exposed Deployed Assets 

 Repositories whose deployed assets are internet-exposed. 

 Repository With Deployed Assets Accessing Sensitive Data 

 Repositories whose deployed assets access sensitive data. 

 Repository With Deployed Assets With Privileged Capabilities 

 Repositories whose deployed assets have privileged capabilities. 

 Image Name 

 The container image name. 

 Image Architecture 

 The container image architecture. 

 OS Distribution 

 The operating system distribution of the image. 

 OS Distro Release 

 The operating system distribution release of the image. 

 OS Family 

 The operating system family of the image.
