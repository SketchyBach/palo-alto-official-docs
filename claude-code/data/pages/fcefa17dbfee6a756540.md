 Device > Setup > Quantum 

 Configure QKD profiles to enable quantum key distribution on your
 firewalls. 

 Device Setup Quantum 

 Quantum Key Distribution (QKD) support enables your firewall to use quantum-safe
 cryptography for IPsec VPN connections. A QKD profile specifies a unique connection
 profile to each Key Management Entity (KME) QKD appliance the firewall communicates
 with to retrieve high-quality encryption keys. 

 Field 

 Description 

 Name 

 Enter a descriptive name for the QKD profile. 

 KME URL 

 The URL your firewall uses to connect to the local KME appliance. 

 Local SAE ID 

 The Security Application Entity (SAE) ID assigned to the firewall. 

 Local Certificate 

 The local certificate used to authenticate the firewall to the
 KME. 

 KME CA Certificate 

 The KME's certificate authority certificate. 

 KME Certificate 

 The KME's server certificate used for authentication.
