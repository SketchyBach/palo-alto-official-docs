 INC_ZTNA_CONNECTOR_APP_STATUS_DOWN_PARTIAL 

 Learn about the INC_ZTNA_CONNECTOR_APP_DOWN_PARTIAL incident. 

 Synopsis 

 The incident is raised when an application in the connector-group is
 partially unreachable because some of the tunnels in a connector-group are down or
 some of the connectors cannot probe the application. The incident is cleared when
 the application becomes reachable from all connectors in the connector-group. 

 Incident Code—INC_ZTNA_CONNECTOR_APP_STATUS_DOWN_PARTIAL 

 Severity—Warning 

 For details about incident severity, see Incidents Distribution Over
 Time in Incidents and Alerts Overview .
