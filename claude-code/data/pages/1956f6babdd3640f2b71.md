 Known Issues in Strata Multitenant Cloud Manager 

 TEST Review the open issues in Strata Multitenant Cloud Manager . 

 These are the issues we’re currently working on. If
the list is empty, then there are no issues specific to multitenant dashboards.
You can also check known issues for Common Services . 

 ID Description 

 ADI-31756 When configuring Snippets ( Manage Configuration NGFW and Prisma Access Overview Configuration and expand the Configuration Scope to view the
 Snippets ), the HTTP server configuration has
 an option to configure a password. This causes the commits to fail on
 the firewall due to a key sync issue. 

 ADI-28518 When configuring Snippets from Snippet Overview Security Services Web Security section , the settings link is broken. 

 ADI-24630 When using Snippets, the snippet push fails if the
 security rules have the same name as the snippet. 

 PAMSP-4495 Using Bulk Configuration, when you push a snippet onto a
 tenant without a Prisma Access configuration in the child
 tenant, the status turns to synced . However, if you unassign and
 push the same snippet, the status still shows
 synced instead of
 unassigned . 

 PAMSP-4216 The Multitenant Monitor User role is not able to create or
 edit notification profiles . 

 PAMSP-3082 

 The Onboard a new tenant link does not
 consistently work in the Total Tenants widget
 of the Summary page in the Strata Multitenant Cloud Manager at
 /msp/dashboard . 

 Workaround : To onboard a tenant or subtenant, add tenants from Settings or Common
 Services .
