 Change Between Panorama Management and Cloud Management 

 Change the managed firewall management platform from
a Panorama™ management server to cloud management, and vice versa. 

 Where Can I Use This? What Do I Need? 

 NGFW (Managed by Panorama) 

 Device Management License 

 Panorama superuser role 

 Strata Cloud Manager Essentials or Pro 

 The procedures below describe how to change
the managed firewall management platform from a Panorama™ management
server to cloud management, and how to change from cloud management
to Panorama management. 

 Change from Panorama Management to Cloud Management 

 Log in to the Panorama web
 interface . 

 Remove the log forwarding preferences for the managed
firewall you want to move to cloud management. 

 Select Panorama Collector Groups and click
the collector group that the managed firewall is associated with. 

 Select Device Log Forwarding . 

 Select (check) the managed firewall you want to move
to cloud management and Delete . 

 You can select (check) multiple firewalls when moving more
than one managed firewall to cloud management. 

 Click OK . 

 Commit and Commit
to Panorama . 

 Set the management setting on the firewall. 

 Log in to the firewall web interface . 

 Select Device Setup Management and
edit the Panorama Settings. 

 For Managed By, select Cloud Services . 

 Click OK . 

 Commit . 

 Continue onboarding your firewall to cloud management. 

 Change from Cloud Management to Panorama Management 

 This is also required if downgrading a managed
firewall to PAN-OS 10.2.2 or earlier release where cloud management
of firewalls is not supported. 

 Set the management setting on the firewall. 

 Log in to the firewall web interface . 

 Select Device Setup Management and
edit the Panorama Settings. 

 For Managed By, select Panorama . 

 The Panorama IP and device registration authentication
key you originally added should still be configured. If not, see Add a Firewall as a Managed Device for more information
to add your managed firewall back to Panorama. 

 Click OK . 

 Commit . 

 Restart the management plane on the managed firewall. 

 Log in to the firewall CLI . 

 Restart the management plane. 

 admin> debug software restart process management-server 

 Verify the managed firewall successfully connected to
Panorama. 

 Log in to the Panorama web
 interface . 

 Select Panorama Managed Devices Summary and
verify the managed firewall State is Connected .
