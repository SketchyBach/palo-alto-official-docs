 CLI Commands in Prisma SD-WAN ION Release 5.6 

 Learn more about the CLI commands in Prisma SD-WAN ION
device release 5.6. 

 See the new and updated device CLI commands
in Prisma SD-WAN ION Device Release 5.6. 

 CLI Commands in Prisma SD-WAN ION Device Release 5.6.1 

 Commands Description 

 New 

 clear routing multicast statistics 

 Clears the routing multicast statistics to debug and
 troubleshoot. 

 config cellular modem 

 Configures modem SIM PIN. 

 debug routing multicast log 

 Configure to know the routing multicast log module
 details. 

 debug cellular stats 

 Configure the cellular stats for the device. 

 dump routing multicast config 

 Displays the routing multicast specific
 configurations of a device. 

 dump routing multicast igmp 

 Displays the routing multicast internet group
 management protocol (IGMP) specific configurations of a
 device. 

 dump routing multicast interface 

 Displays the routing multicast interface specific
 configurations of a device. 

 dump routing multicast internal vif-entries 

 Displays the internal vif entries in
 multicast. 

 dump routing multicast mroute 

 Displays the routing multicast mroute specific
 configurations of a device. 

 dump routing multicast pim 

 Displays the Protocol Independent Multicast (PIM)
 routing configurations of a device. 

 dump routing multicast sources 

 Displays the information about multicast
 source(s). 

 dump routing multicast statistics 

 Displays the routing multicast statistics of a
 device. 

 dump routing multicast status 

 Displays the routing multicast status of a ION
 device. 

 dump security-policy config policy-set-stack 

 Displays the security policy set stack configuration
 for a device. 

 dump cellular config 

 Displays the cellular configurations. 

 Continued.. 

 dump cellular stats 

 Displays the statistics of the modem. 

 dump cellular status 

 Displays the cellular status of the modem. 

 dump dpdk cpu 

 Displays the dpdk cpu usage. 

 dump dpdk port status 

 Displays the dpdk port status. 

 dump dpdk interface 

 Displays the all interfaces within the dpdk
 stack. 

 dump dpdk stats 

 Displays the dpdk stats. 

 inspect dpdk ip-rules 

 Presents the ip address rules in the dpdk
 stack. 

 inspect dpdk vrf 

 Presents the dpdk route table for a specific
 vrf. 

 inspect routing multicast interface 

 Presents the forwarding state of the multicast
 enabled interfaces. 

 inspect routing multicast mroute 

 Presents the forwarding state of the
 multicast. 

 inspect security-policy lookup 

 Presents to identify the potential security policies
 for an application flow. 

 inspect security-policy size 

 Presents the size of the security policies for an
 application flow. 

 Updated 

 dump waninterface config 

 Displays the WAN circuit configurations. 

 dump interface config 

 Displays the interface configurations. 

 dump interface status 

 Displays the interface status (port or sub
 interface). 

 dump security-policy config policy-set 

 Displays the security policy sets configuration for a
 device. 

 dump security-policy config zones 

 Displays the configuration of security policy rules
 for zones. 

 dump security-policy config prefix-filters 

 Displays the security policy prefix filter
 configuration. 

 dump config security 

 Displays the security configuration available on a
 device. 

 dump security-policy config policy-rules 

 Displays the security policy rule configuration for a
 device. 

 dump syslog config 

 Displays the syslog configuration. 

 dump syslog-rtr stats 

 Displays the current status of the syslog
 router. 

 debug logging facility 

 Configure to set the log level for a
 component. 

 inspect flow internal 

 Presents the details of flows that match the input
 filter. 

 inspect flow-detail 

 Presents the details on active flows and to debug
 current flows matching the user-specified options. 

 inspect flow brief 

 Presents the brief details for active flows and to
 debug current flows matching the user-specified options. 

 inspect lqm stats 

 Presents the link quality metrics (LQM).
