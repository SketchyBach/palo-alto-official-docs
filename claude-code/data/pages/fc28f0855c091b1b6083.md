 Configure an AS Path List 

 Learn how to configure AS Path Lists in Prisma SD-WAN . Use AS Path Lists
 to filter route maps based on the AS path. 

 Where Can I Use
 This? What Do I
 Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 Use AS Path Lists to filter route maps based on the AS path. A branch or data center ION device
 permits or denies routes based on the order number and AS path regex expressions.
 Configure an AS Path Lists to control importing of BGP routes that came from another
 router. 

 Select Configuration Prisma SD-WAN ION Devices Claimed Configure the device Routing BGP/Peers AS Path Lists Create AS Path List . 

 On the Info screen, enter a name,
optional description, and tags for the AS path list. 

 On the Regexes screen, enter an Order , AS
Path Regex expression, and then select Permit or Deny . 

 If you modify an associated Prefix List , AS
 Path List , or IP Community List , you
 must perform a soft reset on the corresponding BGP peer for the changes to
 take effect on advertised or received routes. The soft reset causes BGP to
 re-evaluate its routing policies for that peer without tearing down the
 BGP/TCP connection. 

 Click Save & Exit .
