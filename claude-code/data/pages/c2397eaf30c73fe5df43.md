 Remote Browser Isolation (RBI) has the following known issues: 

 Issue ID Description 

 ARBI-7796 

 ARBI-7757 

 An issue exists where webpage footers are not visible in the print
 preview in isolation when using Google Chrome on Windows and Safari
 browser on macOS at the default scale (100%). When attempting to
 print a webpage using the Print (with
 Header/Footer) context menu in RBI, the footer that
 should appear at the bottom of the page is missing from the print
 preview. 

 Workaround : Manually change the page size to A4 in the print
 settings to display the footer in the print preview. 

 ARBI-7752 

 An issue exists where Linux-based package files (deb/rpm) are
 displayed or offered for download instead of Windows executables when
 attempting to download applications like Chrome or Zoom through Remote
 Browser Isolation using Microsoft Edge on Windows. 

 ARBI-7721 

 An issue exists where credit card numbers are incorrectly displayed
 in exponential notation ("E+" format) when viewing CSV files in RBI.
 When accessing CSV files containing credit card numbers, long
 numeric strings like credit card numbers (without hyphens) are
 improperly rendered in scientific notation with "E+" format instead
 of displaying the complete numeric value. 

 ARBI-7769 

 ARBI-7657 

 An issue exists where, when viewing substantial CSV files (for
 example files larger than 100 MB) in RBI, users experience
 significant load time, rather than loading quickly as expected. 

 Workaround : Allow your users to download CSV files without
 viewing them by disabling View files in
 Isolation in the isolation profile and permitting
 CSV files to be downloaded in File Extensions for
 Download. 

 ARBI-5089 

 Users of the Microsoft Edge browser on iOS devices can sometimes
 experience audio and video synchronization issues in isolated
 browsing sessions. For example, when switching tabs during playback,
 they might notice audio distortions. 

 ARBI-3376 

 For RBI running on Prisma Access 5.2.1
 Preferred (PAN-OS 10.2.10 dataplane) or earlier, users or user
 groups derived from on-premises Active Directory (AD) are not
 supported. Any users or user groups based on Cloud Identity Engine work
 as expected. 

 ARBI-4199 

 RBI does not fully support Open Authentication
 (OAuth) based authentication in isolation at this time. Single
 sign-on (SSO) authentication that appears in a pop-up requires
 additional user input to complete.
