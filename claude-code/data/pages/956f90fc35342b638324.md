 Cortex XSOAR 6.14 Threat Intel Management 

 Configure Threat Intel Report Types 

 Configure threat intelligence report types in Cortex XSOAR 6.14. 

 Threat intel reports are categorized by type, which determines the layout that is displayed for the report. Cortex XSOAR includes the following out-of-the-box report types from the Threat Intel Reports (BETA) content pack: 

 Campaign 

 Executive Brief 

 Malware 

 Threat Actor 

 Vulnerability 

 You can customize the layout of an existing out-of-the-box report or add new report types. 

 You can create new threat intel report types to support use cases not covered by the out-of-the-box types, which may require different report layouts. For example, you may want to add a new type for a specific threat hunting report that your organization needs, which isn’t covered by one of the out-of-the-box template types. 

 Go to Settings → OBJECTS SETUP → Threat Intel Reports → Types . 

 Add a New Type . 

 Enter a Name and choose the Layout that you want associated with this report type. 

 Save the type.
