 Features Introduced in June 2023 

 Learn what’s new in Prisma SD-WAN in June 2023. 

 New Feature/Enhancement Description 

 Strata Cloud Manager-Redesigned User Experience Starting on June 23, 2023, Prisma SD-WAN customers will begin
 migrating to a freshly redesigned user experience, Strata Cloud Manager . This
 user experience provides many improvements including: 
 Streamlined SASE workflows for provisioning and
 troubleshooting. 

 A common portal across Prisma SD-WAN , cloud-management Prisma
 Access, ADEM, and cloud-managed NGFW. 

 A normalized information model making navigation faster and more
 intuitive across the various product suites. 

 Tenant Service Group (TSG) 
 Migration of Prisma SD-WAN Tenants Transition Prisma
 SD-WAN tenants activated before June 2022 to the Prisma SASE
 platform. 

 Predictive Analytics - 7-Days forecast and Anomaly
 detection Prisma SD-WAN now
 captures the bandwidth anomaly (computed value for each data point if it
 finds a contradiction between the past forecast value and the past
 utilization value for a data point) for the specified time range filter
 and the bandwidth forecast for the next seven days in preview
 mode. 

 New Feature/Enhancement Description 

 ION-1200-C5G-EXP SKU for Japan 
 Introducing a new ION 1200 device
 variant —enterprise small branch with integrated 5G that meets
 5G regulatory requirements in Japan. 
 Device Software Version
 Required: 6.1.3 and later 

 Support for enhanced high availability topologies 
 A used for = control 
 option for Switch Virtual
 Interfaces (SVI) on all switched ports and sub-interfaces
 on routed ports. This allows the standby device to connect to the
 controller through the active device. 
 Device Software Version
 Required: 6.1.3 and later
