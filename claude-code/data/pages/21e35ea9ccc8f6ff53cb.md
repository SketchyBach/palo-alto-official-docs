 Cloud Identity Engine Known and Addressed Issues 

 The following list describes all known and addressed issues for the current release of
 the Cloud Identity Engine. 

 Review the lists below for information on known and addressed issues for the Cloud
 Identity Engine and the Cloud Identity agent. You can also review the release notes for
 related documentation for any associated issues. 

 Known Issues 

 Addressed Issues 

 Known Issues 

 There are no known issues for the current release of the Cloud Identity Engine. For
 more information, refer to the release note links below to determine if there are
 any associated known issues. 

 Addressed Issues 

 The following list describes addressed issues for the current release of Cloud
 Identity Engine and the Cloud Identity agent. 

 With the cloud delivery model, the list of addressed issues is not cumulative. Known
 issues that have been addressed in the last software update are marked below, and
 these issues will be removed from this list when we publish documentation for the
 next software update. 

 Issue ID Version Information Description 

 DRS-6050 Resolved in the August 2025 release Fixed an issue where the sync for Okta directory
 application data did not occur on schedule. 

 DIT-51724 Resolved in agent version 1.8.2 

 Fixed an issue where file truncation occurred due to overpadding
 and encryption. 

 DIT-41356 Resolved in agent version 1.8.2 Fixed an issue where synchronization for all domains
 was not successful. 

 DRS-4466 Resolved in agent version 1.8.2 

 Fixed an issue where the Cloud Identity agent disconnected
 unexpectedly from the Directory Sync Service if the agent sent
 an empty message. 

 DRS-3347 Resolved in agent version 1.8.1 

 Fixed a memory leak issue that caused the Cloud Identity agent to
 respond slowly and in some cases restart unexpectedly.
