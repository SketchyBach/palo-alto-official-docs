 Upgrade Considerations for Panorama Managed Prisma Access (Managed by Panorama) 

 If you're using Panorama to manage Prisma Access , here's what to consider when
 upgrading to Prisma Access 5.2, 5.2.1, or 5.2.2. 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Panorama) 

 Prisma Access license 

 Minimum Required Prisma Access Version 5.2, 5.2.1, or 5.2.2 Preferred or
 Innovation 

 To upgrade your Cloud Services plugin to Prisma Access 5.2, 5.2.1, or 5.2.2, use one of
 the following upgrade paths. To find your current plugin version in Panorama, select Panorama Cloud Services Configuration Service Setup and check the plugin version in the Plugin Alert 
 area. 

 Be sure to follow the minimum Panorama versions for each plugin version
 during the upgrade.

 Upgrade your plugin from Prisma Access 5.1 to Prisma Access 5.2 and
 commit and push your changes.
