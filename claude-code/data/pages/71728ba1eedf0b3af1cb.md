 Global Distribution of Impacted Meetings 

 View the map view of the Prisma Access Locations where users faced impacted Zoom
 experience. 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 Strata Cloud Manager 

 Prisma Access license 

 Autonomous DEM license 

 Zoom QSS license 

 The map in this widget shows you how many Zoom users are connected in each Prisma Access Location. The circle representing each location is color coded to give
 you an overview of the average of all users' experience in that Location. The map makes
 it quick to identify regional issues like ISP outages. Hover over a circle to see the
 number of Mobile Users connected in the geographic location separated by their
 experience scores. Clicking on the number of users takes you to the Monitored
 Mobile Users page where the Monitored Mobile User
 Devices table displays the details for each user in that location.
