 Migrate From Docker to Podman 

 Migrate Cortex XSOAR 6.14 from Docker to Podman on RHEL 8 or later. 

 Although Podman is set up automatically in a new server or engine installation, it is also possible to migrate from Docker to Podman for an existing server or engine. Follow the Podman installation instructions to migrate.
