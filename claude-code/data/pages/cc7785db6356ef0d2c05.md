 ATT&CK Technique 

 Data Manipulation: Stored Data Manipulation (T1565.001) 

 Severity 

 Low 

 Description 

 An AI knowledge base was modified by an identity that typically doesn't interact with knowledge bases. MITRE ATLAS Technique: AML.T0070 - RAG Poisoning. OWASP Top 10 LLM Technique: LLM04 - Data and Model Poisoning. 

 Attacker's Goals 

 Contaminating knowledge base, so that contextual information will be incorrect, biased or harmful. 

 Investigative actions 

 Check the identity that modified the knowledge base. 

 Check recent additions to the knowledge base.
