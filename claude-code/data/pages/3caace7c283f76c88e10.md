 Disable or Delete Signing Keys 

 Disabling a Signing Key prevents it from being used but keeps it in the inventory. You can renew a disabled key later if needed. 

 Deleting a Signing Key permanently removes it from the inventory. Deleted keys cannot be recovered. 

 Disable a Signing Key 

 Sign in to Next-Gen Trust Security. 

 Click Insights > Certificate Inventory > Signing Keys . 

 Select the Signing Key to open its details drawer. 

 Select Disable on the details drawer. 

 After the Signing Key is disabled, it remains in the inventory with a Disabled status. It cannot be used for signing again until it is renewed. 

 Delete a Signing Key 

 Warning : Deleting a Signing Key is permanent and cannot be undone. If you are unsure, disable the key instead to prevent its use while keeping it in the inventory. 

 Sign in to Next-Gen Trust Security. 

 Click Insights > Certificate Inventory > Signing Keys . 

 Select the Signing Key to open its details drawer. 

 Select Delete on the details drawer. 

 Confirm the deletion when prompted, and then select Delete again. 

 The Signing Key is removed from the inventory and cannot be recovered.
