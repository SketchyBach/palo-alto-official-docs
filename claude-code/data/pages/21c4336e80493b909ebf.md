 Purchase a valid Prisma Access license with a Mobile
 User license subscription. 

 Activate Prisma Access and claim the licenses
 that you purchased . 

 Set up Prisma Access . 

 You will also need to activate the licenses for Strata Logging Service and Cloud
 Identity Engine. 

 For Prisma Access Agent licensing and activation on NGFW, review the information in NGFW Support for Prisma Access Agent .

 Linux 9.6 and 10.0 x86_64 and ARM64 26.2 

 For desktop operating systems such as macOS and Windows, you can install the Prisma Access Agent on an endpoint that already has the GlobalProtect app
 installed. The end users can switch between the Prisma Access Agent and
 GlobalProtect app . 

 For Linux distributions, Prisma Access Agent 
 supports the GNOME and KDE desktop environments as well as Wayland and X11 display
 servers. 

 *Support for Fedora 41 was dropped in Prisma Access Agent version 26.2.
