 Prisma SD-WAN Features Introduced in October 2020 

 Learn what’s new in Prisma SD-WAN in October 2020. 

 New Feature Or Enhancement Description 

 New
and Improved Dashboard with Views of Link Quality Metrics The Prisma SD-WAN has a new and improved Dashboard
that displays the Device to Controller Connectivity status, Top
Sites by Alarms list, and Link Quality Metrics for
your sites. The Monitoring Summary and Link Quality
Details tabs provide a summarized and graphical view
of the device connectivity status and link quality metrics of all links
for all sites. 

 Enhanced
Flow Browser with Link to Policy Rules The Flow Detail screen
in the Flow browser shows the Path and QoS policy sets and rules
governing the flow. Starting with release 5.4.3, clicking the Path
or QoS policy rule name will navigate to the policy rule editor
for that rule where it can be viewed or edited. 

 Enhanced
Quick Filters to be Preserved across Activity Pages The Quick Filter is now enhanced to preserve
a filter selection across the Activity tab
pages. The filter criterion set for a specific time frame with selected
applications or sites is retained across Network , Media , Link Quality , Flows , Routing ,
and System pages of the Activity tab. 

 Advanced
Control for ION Initiated Control and Management Connections You can choose to exclude certain circuits
and circuit categories from being used for device initiated connections.
This is possible through the Use for controller connections and Use
for application probes features. You can configure these
features at both the Circuit level and the Circuit Categories level. 

 Device
Software Version Required: 5.4.3 and later 

 SNMP
MIB Update New System OID is added for each Prisma SD-WAN ION
to enhance device monitoring by third party SNMP management tools. Device
Software Version Required: 5.4.3 and later 

 New
Device Connectivity Alarm An alarm DEVICESW_INITIATED_CONNECTION_ON_EXCLUDED_PATH is triggered
when a device initiated connection is on an excluded interface. Device
Software Version Required: 5.4.3 and later
