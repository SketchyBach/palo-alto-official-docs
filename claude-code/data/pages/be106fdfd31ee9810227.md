 Configure AI Skill Security Rules 

 Configure the security rules that determine how AI Skill Security evaluates uploaded
 skills and whether findings produce an Allowed or Blocked verdict. 

 Where Can I Use This? What Do I Need? 

 Prisma AIRS (AI Skill Security) 

 No License required for preview 

 Each AI Skill Security rule is controlled by two toggles that determine whether the
 rule runs during a scan and whether a finding causes the skill to be blocked. For a
 full description of rule settings, see AI Skill Security Rules . Configuration
 changes apply only to subsequent scans — in-flight and completed scans are not
 affected. 

 Log in to Strata Cloud Manager . 

 Select AI Security AI Supply Chain Security Configurations . 

 Customize your rules. 
 Toggle the Enabled and Blocking 
 settings for each rule you want to modify. To update multiple rules at once,
 select them and apply a batch update.
