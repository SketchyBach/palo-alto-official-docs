 Push the Prisma Access Agent Configuration 

 Learn how to push Prisma Access Agent configuration changes to
 the cloud infrastructure. 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 NGFW (Managed by Panorama) 

 Check the prerequisites for the deployment you're
 using 

 Contact your Palo Alto Networks account representative to
 activate the Prisma Access Agent feature 

 After you initially complete the Prisma Access Agent configuration or
 update the configuration, you must push the configuration to Prisma Access. 

 Depending on the type of deployment you have, use one of the following
 choices: 

 For Strata Cloud Manager managed deployments: 
 Log in to Strata
 Cloud Manager and select Configuration NGFW and Prisma Access Configuration Scope Access Agent Setup . 

 For Panorama managed deployments: 
 From the Cloud Services plugin in Panorama, select Panorama Cloud Services Prisma Access Agent Launch Prisma Access Agent . 

 Select Configuration Prisma Access Agent Settings . 

 Configure the infrastructure or agent as needed. 

 Select Push Config Push . 

 Enter a Description for the job. This field is
 required. 

 Select the Global Prisma Access Mobile Users Access Agent container and click Push . 

 Wait for the job to finish and Close the Jobs
 dialog.
