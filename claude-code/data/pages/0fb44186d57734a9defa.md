 Network > Network Profiles > Cellular > APN/DNN Profile 

 Learn how to create and manage multiple APN and DNN profiles for cellular
 interfaces. 

 APN and DNN profiles define the carrier network connection settings for cellular
 interfaces. Create a profile here and then assign it to a cellular interface or
 cellular subinterface (see Network > Interfaces >
 Cellular ). In Panorama, this page is available under
 Templates Network Network Profiles Cellular APN/DNN Profile . 

 Field 

 Description 

 Profile Name 

 Enter a name for the profile using letters, numbers, and hyphens
 only. The name cannot contain spaces or special characters. 

 Type 

 Select the type of cellular network connection this profile
 defines: 

 APN —Configure an access point name for 4G LTE networks.
 Use APN when the firewall connects to an Evolved Packet Core
 (EPC). 

 DNN —Configure a data network name for 5G standalone
 (SA) networks. Use DNN when the firewall connects to a 5G Core
 (5GC). Selecting DNN enables the
 Slice/Service Type and
 Slice Differentiator fields. 

 APN/DNN Name 

 Enter the APN or DNN name as provided by your carrier. 

 PDP Type 

 Select the packet data protocol (PDP) type that the profile
 allows: 

 IPv4 —(Default) The session uses IPv4 addressing
 only. 

 IPv6 —The session uses IPv6 addressing only. 

 IPv4v6 —The session supports both IPv4 and IPv6
 addressing. 

 Authentication Type 

 Select the authentication method for the carrier connection: 

 None —(Default) No authentication is required. 

 CHAP —Use Challenge Handshake Authentication Protocol
 (CHAP). 

 PAP —Use Password Authentication Protocol (PAP). 

 auto —The firewall automatically detects the
 authentication type. If the first attempt fails, it retries
 with the alternate type. 

 Username 

 Enter the Username for carrier
 authentication. Required when
 Authentication Type is
 CHAP , PAP , or
 auto . 

 Password / Confirm Password 

 Enter and confirm the Password for carrier
 authentication. Required when
 Authentication Type is
 CHAP , PAP , or
 auto . 

 ( DNN only ) Slice/Service Type 

 Enter the Slice/Service Type (SST) value to identify the 5G network
 slice this DNN maps to. The range is 0–255. The SST is part of the
 S-NSSAI (Single Network Slice Selection Assistance Information)
 identifier used by 5G SA networks to route traffic to the correct
 network slice. If you don't configure an SST, no network slicing is
 applied to this DNN session. 

 ( DNN only ) Slice Differentiator 

 ( Optional ) Enter the Slice Differentiator (SD) as a 24-bit
 unsigned integer. The SD distinguishes between multiple 5G network
 slices that share the same SST value. Leave this field blank if
 your carrier does not require slice differentiation.
