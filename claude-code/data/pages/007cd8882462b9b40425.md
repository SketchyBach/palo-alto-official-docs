 Upload ZIP file and start async import (v2) 

 post https://api.xdr.us.paloaltonetworks.com /public_api/v2/compliance/standards/import 

 Not yet implemented. 

 Uploads a ZIP file containing one or more standards in the normalized subfolder format and starts an asynchronous import job. 

 Limits: Max ZIP size 50 MB. 

 Requires platform_compliance_edit permission. 

 Required license: Cortex Cloud Runtime Security or Cortex Cloud Posture Management.

 Poll import job status (v2) 

 get https://api.xdr.us.paloaltonetworks.com /public_api/v2/compliance/standards/import/ {job_id} 

 Not yet implemented. 

 Returns the current status of an import job. 

 Status values: pending , processing , completed , failed . 

 Requires platform_compliance_view permission. 

 Required license: Cortex Cloud Runtime Security or Cortex Cloud Posture Management.
