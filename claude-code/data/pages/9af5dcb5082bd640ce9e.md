 Features introduced in 2026 

 February 2026 

 Release Highlights 

 The following are the key highlights for this release. 

 FEATURE 

 DESCRIPTION 

 Reimagined Cloud Command Center 

 Reimagined Cloud Command Center elegantly visualizes risk, providing security teams with actionable insights into cloud assets, critical risks, and active threats, while directing them to the most impactful remediation workflows. 

 Support for Azure AI Foundry 

 Support for Azure AI Foundry provides centralized visibility into all AI assets, automatically uncovering shadow AI and risky configurations. Detect supply-chain risks early, generate a complete AI Bill of Materials (AI-BOM), and apply governance controls for AI development at scale 

 Expanded DSPM coverage for Databricks across AWS, Azure, and GCP 

 Expanded DSPM coverage for Databricks across AWS, Azure, and GCP lets teams identify misconfigurations such as unsecured notebooks, risky downloads, and external data sharing that may lead to data exposure or compliance gaps. 

 New Okta integration 

 New Okta Integration allows for the ingestion of identities and groups, giving teams deeper visibility into identity risk and access relationships. This new integration means customers will now see the correlation between identities, permissions, and data exposure when using Okta. 

 Expanded Non-Human Identity (NHI) protection 

 Expanded Non-Human Identity (NHI) protection provides additional visibility into cloud-managed secrets, their security posture, and their relationships to help teams better identify overexposed and unrotated secrets. 

 AppSec AI agent 

 The agent helps you identify critical issues, assist in creating security policies, and open pull requests to streamline fixes. 

 Automated Application Creation 

 Align security with your organization’s code structure instantly. By applying VCS-based criteria, we provide a source-centric approach to automatically creating applications. 

 AI-powered guardrails 

 Provides targeted prevention by analyzing development and production environments. The system recommends the most effective policies tailored to your specific needs. 

 ASPM cases 

 Reduce remediation time by grouping related risks across the application lifecycle into unified cases, enabling response at scale.
