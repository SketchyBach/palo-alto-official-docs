 Device > Data Redistribution > Collector Settings 

 To configure a connection to a User-ID redistribution
agent, enter a name for the collector and the pre-shared key. 

 Data Redistribution Agent Setup Settings Description 

 Collector Name Enter a Collector Name (up
to 255 alphanumeric characters) to identify the redistribution agent. 

 Collector Pre-Shared Key / Confirm Collector
Pre-Shared Key Enter and confirm the Pre-Shared Key (up
to 255 alphanumeric characters) for the collector.
