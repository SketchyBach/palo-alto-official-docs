 Manually Refresh the Number of Licenses in Use 

 Refresh the number of licenses in use in Cortex XSOAR 6.13. 

 When you audit users and roles, the calculation for the number of licenses currently in use is performed by the system every few hours or when uploading a license. 

 A user with administrator privileges can manually refresh the number of licenses currently in use. This enables you to retrieve immediate feedback on licensing when disabling accounts or removing users, and when provisioning new users. 

 Note 

 The Refresh option only appears when the Users in use exceeds the number of Total users purchased . 

 Go to Settings → About → License . 

 In the Users in use section, click Refresh .
