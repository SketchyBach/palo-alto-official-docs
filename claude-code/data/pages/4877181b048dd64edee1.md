 Deploy Prisma Access Agents Using Jamf Pro 

 Use Jamf Pro to deploy the Prisma Access Agent to enable consistent inspection of
 traffic and enforcement of network security policy on your endpoints. 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 NGFW (Managed by Panorama) 

 Check the prerequisites for the deployment you're using 

 Prisma Access Agent version: 25.1.0.14 

 macOS 14 and later desktop devices 

 Contact your Palo Alto Networks account representative to
 activate the Prisma Access Agent feature 

 Jamf Pro is an Enterprise Mobility Management Platform that enables you to your endpoints
 from a central console. Prisma Access Agent provides a secure connection between the
 gateway and the endpoints that Jamf Pro
 manages. Using Prisma Access Agent as
 the secure connection enables consistent inspection of traffic and enforcement of
 network security policy for threat prevention on your endpoints.

 app using Jamf Pro:
