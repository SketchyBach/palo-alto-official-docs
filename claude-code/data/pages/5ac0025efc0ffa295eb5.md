 Device > Cloud Redistribution 

 Specify the user and device context your firewall contributes to or receives from
 other firewalls through the cloud. 

 Select Device Cloud Redistribution to configure Contributing and Receiving entries for the Host Compliance Service and the User Context Cloud Redistribution Service .
 Contributing entries specify the data types your firewall sends to the cloud and the
 segments (logical groupings of firewalls) to which it contributes that data. Receiving
 entries specify the data types your firewall receives from the cloud and the segments
 from which it receives that data.
