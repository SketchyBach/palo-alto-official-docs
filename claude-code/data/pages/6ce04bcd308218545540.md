 delete wildfire-metadata 

 Description 

 Delete content updates
on the WildFire appliance. For more information on content updates
and how to install them, see request
wf-content . 

 Syntax 

 delete { 
wildfire-metadata update <value>; 
{ 

 Options 

 + update <value> —
Define the content update that you want to delete. 

 Sample Output 

 The output that follows
shows the deletion of an update named: 

 panup-all-wfmeta-2-181.candidate.tgz. 
admin@WF-500> delete wildfire-metadata update panup-all-wfmeta-2-181.candidate.tgz 
successfully removed panup-all-wfmeta-2-181.candidate.tgz 

 Required Privilege Level 

 superuser, deviceadmin
