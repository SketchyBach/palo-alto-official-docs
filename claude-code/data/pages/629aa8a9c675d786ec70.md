 GCP Manual Onboarding Guide - Folder Scope 

 This guide walks you through manually creating the required GCP resources for the Cortex integration using gcloud CLI commands at the Folder scope. Service accounts are created in a host project, IAM bindings are applied at the folder level, and custom roles are created at the organization level.
