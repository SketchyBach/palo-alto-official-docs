 Uninstall the SD-WAN Plugin 

 Uninstall the SD-WAN plugin from the Panorama® management server when it's no
 longer needed. 

 Where Can I Use This? What Do I Need? 

 NGFW 

 Advanced SD-WAN for NGFW 

 Uninstall the SD-WAN plugin to remove the SD-WAN plugin
 from your Panorama management server when it's no longer needed. 

 To uninstall the SD-WAN plugin from the Panorama management
 server, you must remove your SD-WAN plugin configuration from Panorama before you can successfully uninstall the SD-WAN 
 plugin. 

 You may require to uninstall the SD-WAN plugin when you want to
 reconfigure your network architecture, transition to a different SD-WAN solution, or simply clean up unused components in your Panorama setup.
 By following the uninstallation process, you can ensure that all SD-WAN related configurations are properly removed before uninstalling the plugin
 itself. This helps maintain a clean and efficient Panorama environment,
 reducing potential conflicts and simplifying ongoing management. The uninstallation
 process includes steps to remove SD-WAN specific security policies
 and configurations, ensuring a thorough cleanup of your Panorama setup. 

 Log in to the Panorama web
 interface . 

 ( SD-WAN plugin 1.0.2 and later releases only ) Remove
 any security policy rules that allow BGP to run between your SD-WAN hubs and branches. 

 You must remove your SD-WAN plugin configuration from Panorama before you can successfully uninstall the SD-WAN plugin. These steps ensure that all SD-WAN related settings are cleaned up before proceeding with
 the actual plugin uninstallation. 

 Select Panorama SD-WAN Devices BGP Policy and Remove the security policy
 rules. 

 Click OK to save your configuration
 changes. 

 Select Panorama Plugins and select Remove Config for the SD-WAN plugin. 

 Select Commit and Commit
and Push your configuration changes to your managed
firewalls. 

 Uninstall the SD-WAN plugin. 

 Click OK when prompted to continue uninstalling the
 SD-WAN plugin.
