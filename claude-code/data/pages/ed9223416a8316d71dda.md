 Create a report based on a dashboard 

 Create a report based on any dashboard in Cortex Xpanse. 

 Create a report based on an existing dashboard. 

 Save the dashboard as a report template in one of the following ways: 

 Go to Dashboards → Dashboards Manager 

 Right-click the dashboard for which you want to generate a report, and select Save as report template . 

 Or 

 From the dashboard itself, click the options menu ( ) in the upper right corner and select Save as report template . 

 Enter a unique Report Name and an optional Description , and click Save . 

 Go to Reports → Report Templates . 

 Locate your report and take one of the following actions: 

 To run the report without make any modifications, hover over the report name, and select Generate Report . 

 To modify or schedule the report, hover over the report name, and select Edit . 

 After your report completes, you can download it from the Reports → Reports page.
