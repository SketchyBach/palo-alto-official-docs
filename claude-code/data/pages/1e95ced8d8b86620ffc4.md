 Manage Prisma Browser Control Sets 

 Learn how to manage control sets or external controls for Prisma Access Secure Enterprise Browser 
 ( Prisma Browser ). 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 Prisma Browser standalone 

 Prisma Access with Prisma Browser bundle
 license or Prisma Browser standalone license 

 Superuser or Prisma Browser
 Roles 

 Control Sets can be used when you want to save reusable (or legacy) profiles and
 attach them to the rules later. The Conntrol Sets for the Prisma Browser rules
 can also be configured within the body of the individual rule instead when you manage inline policy rules . 

 Create a Policy Profile 

 From Strata Cloud Manager , select Configuration Prisma Browser 
 Policy Profiles 

 Select the Profile (Control) type you will be using and click the + next to
 the group. 

 Enter a name for the Profile and Create . 

 Configure the controls that will be included in the Control Set. 
 It is possible to select more than one control per Control Set: 

 Configure Data Controls 

 Configure Browser
 Security 

 Configure Browser
 Customization 

 After the Profile Controls are configured, Save X
 changes , located on the lower right of the browser. The
 button will "shake" to remind you to save the changes. 

 Attach a Control Set to a Rule 

 After you create Control Sets, you can attach them to rules. When you create a
 new Rule, you can select a preconfigured Control Set (saved profile) instead of
 using the Control step in the rule creation Wizard. 

 Create the rule according to the regular procedure, such as create an Access and Data
 Control Rule . 

 At the Controls step, select the Profile from the Saved profiles
 list. 

 Click Save . 

 To indicate that the Rule is using a Policy Profile, the name of the
 Profile will be displayed in a highlighted background.
