 Verify
the LSVPN Configuration 

 Verify the LSVPN configuration by checking satellite connectivity with the portal and
 gateway, and confirming active VPN tunnel status on each firewall component. 

 Where Can I Use This? What Do I Need? 

 NGFW 

 No separate license required for LSVPN when using NGFWs 

 After configuring the portal, gateways, and satellites, verify that the satellites are able to
 connect to the portal and gateway and establish VPN tunnels with one or more
 gateways. 

 Verify satellite connectivity with portal. 

 From the firewall hosting the portal, verify that the satellites are successfully connecting by
 selecting Network GlobalProtect Portal and clicking Satellite Info in the
 Info column of the portal configuration entry. 

 Verify satellite connectivity with the gateway(s). 

 On each firewall hosting a gateway, verify that satellites
are able to establish VPN tunnels by selecting Network GlobalProtect Gateways and click Satellite
Info in the Info column of the gateway configuration
entry. Satellites that have successfully established tunnels with
the gateway will display on the Active Satellites tab. 

 Verify LSVPN tunnel status on the satellite. 

 On each firewall hosting a satellite, verify the tunnel
status by selecting Network IPSec Tunnels and verify active
Status as indicated by a green icon.
