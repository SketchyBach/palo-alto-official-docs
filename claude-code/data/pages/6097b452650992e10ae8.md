 INC_MU_AUTH_SERVER_UNREACHABLE_ALL_PA_LOCATIONS 

 Learn about the INC_MU_AUTH_SERVER_UNREACHABLE_ALL_PA_LOCATIONS incident. 

 Incident Code 

 INC_MU_AUTH_SERVER_UNREACHABLE_ALL_PA_LOCATIONS 

 Title Template 

 Auth server {target} is unreachable for MU 

 Category 

 Network Services 

 Subcategory 

 Authentication 

 Description 

 The authentication server is unreachable from the MU Gateway across all Prisma Access locations. This widespread issue can result in authentication failures for users or devices in all locations, affecting their ability to securely access resources. It is crucial to investigate and resolve this incident promptly to restore authentication services and ensure secure access for users across all Prisma Access locations. 

 Raise Condition 

 Incident is Raised when 85% of the instances can not reach the auth server for the last 12 minutes across all the locations for the tenant 

 Clear Condition 

 Incident is Cleared when instances are able to the auth server for the last 6 minutes for the tenant
