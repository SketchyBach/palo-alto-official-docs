 Dashboards 

 The dashboards in the Prisma SASE App provide a visual summary of security and
 network activity, including threat intelligence, application usage, license utilization,
 and incident data. 

 The following dashboards are currently available in the ServiceNow app: 

 Threat Dashboard – Visualizes threat data (such as spyware,
 vulnerabilities, and malicious URLs) over time and by severity. 

 Application Dashboard – Provides insights into applications used
 across the network, including those that are risky or consume high volumes of
 data. 

 License Dashboard – Summarizes license utilization across
 tenants to help monitor allocation and consumption. 

 Tenant Resource Dashboard – Displays a real-time count of all
 tenants in the Prisma SASE environment. 

 To view these dashboards, go to Prisma SASE App for ServiceNow Dashboards .
