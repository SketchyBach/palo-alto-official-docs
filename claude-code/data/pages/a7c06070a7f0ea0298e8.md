 License the VM-Series Firewall on Tencent Cloud 

 Where Can I Use This? What Do I Need? 

 Tencent Cloud China 

 VM-Series License (BYOL) 

 VM-Series plugin 

 Panorama 

 The VM-Series firewall on Tencent cloud supports BYOL and PAYG licenses. For
 more information on VM-Series firewall licensing and licensing types, see License Types . 

 Register the VM-Series firewall performing the steps described in Initiate
 VM-Series Firewall Registration procedure. 

 After the firewall registration, log in to the firewall and select
 Device > Licenses . 

 License keys must be installed through the web interface. The firewall does
 not support license key installation through SCP or FTP. 

 Click Manually Upload License . 

 Confirm that the Dashboard displays a valid serial number and that the
 PA-VM license displays in the Device >
 Licenses tab.
