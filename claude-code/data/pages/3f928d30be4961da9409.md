 Android Requirements 

 Learn about requirements for installing Cortex XDR agent app for Android. 

 The Cortex XDR agent app for Android has the following requirements: 

 Requirement 

 Specification 

 Operating system versions 

 To determine the minimum Cortex XDR release for a specific operating system, refer to The Palo Alto Networks Compatibility Matrix. 

 App usage 

 Enable usage data access for the Cortex XDR agent app on the Android endpoint. This is required to enable Cortex XDR to inspect apps for malware.
