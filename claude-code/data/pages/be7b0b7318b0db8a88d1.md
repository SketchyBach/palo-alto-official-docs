 SD-WAN Link Performance Run Now Report 

 View the generated link performance Run Now report.
Click Export XML to export the generated
link performance report in XML format. 

 Field 

 Description 

 Cluster 

 Name of the Cluster for
which the report was generated. 

 Site 

 Name of the Site for
which the report was generated. 

 Link Tag 

 Name of the link tag identifying the physical
link the app used during traffic distribution. 

 Link Name 

 Name of the link. 

 App 

 Name 

 Name of the application that had traffic
traverse the link. 

 Impacted/Total Bytes Per App 

 Number of sessions impacted out of the total
number of sessions within the specified time frame. If the application
is impacted, this helps indicate how extensive the issue is. 

 Per App/Total % 

 Percentage of traffic data for a specific
app over the link out of the total data traversed over the link
for the specified time-frame. 

 Latency 

 Time Under-Performing (min) 

 Total time in minutes the application latency
threshold configured in the path quality profile was exceeded over
the link. 

 Min 

 Minimum latency experienced by the application
over the link. 

 Max 

 Maximum latency experienced by the application
over the link. 

 Avg 

 Average latency experienced by the application
over the link. 

 Jitter 

 Time Under-Performing (min) 

 Total time in minutes the application jitter
threshold configured in the path quality profile was exceeded over
the link. 

 Min 

 Minimum jitter experienced by the application
over the link. 

 Max 

 Maximum jitter experienced by the application
over the link. 

 Avg 

 Average jitter experienced by the application
over the link. 

 Packet Loss 

 Time Under-Performing (min) 

 Total time in minutes the application packet
loss threshold configured in the path quality profile was exceeded
over the link. 

 Min 

 Minimum packet loss experienced by the application
over the link. 

 Max 

 Maximum packet loss experienced by the application
over the link. 

 Avg 

 Average packet loss experienced by the application
over the link.
