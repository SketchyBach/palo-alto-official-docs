 Informational 

 Description 

 Google Workspace authentication information was changed for a user. 

 Attacker's Goals 

 Adversaries may manipulate user authentication information to obtain Persistence or Bypass Multi-Factor Authentication (MFA) controls. 

 Investigative actions 

 Verify if the authentication information change was authorized. 

 Follow further actions done by the user and IP address.
