 CNGFW: Approaching Max Capacity - Security Policies 

 Incident Code 

 INC_CNGFW_SECURITY_POLICIES_MAX_CAPACITY 

 Severity 

 Warning 

 Category 

 Device 

 Subcategory 

 System Resources 

 Description 

 Approaching Max Capacity - Security Policies 

 Raise Condition 

 When Security Policies usage exceed 90% of the capacity of that respective Cloud NGFW resource and stays beyond 90% for five days in a week and
When there are only 1500 or less Security Policies available to be used for five days over a week 

 Clear Condition 

 When Security Policies usage falls below 90% of the capacity of that respective Cloud NGFW resource and stays below 90% for two week and
When there are more than 1500 security policies available to be used for two weeks
