 Connect the Dynamic Privilege Access Enabled Prisma Agent to a
 Different Location 

 If needed, you can connect to a different Prisma Access location after you log in
 to Prisma Agent . 

 Where Can I Use This? What Do I Need? 

 Prisma Agent 

 macOS 14 and later or Windows 10 version 2024 and later desktop devices 

 Internet access 

 After you log in to Prisma Agent , you’re automatically connected to the
 best available Prisma Access location. If you want to change locations, you can
 do so using the Location drop-down. 

 Launch the Prisma Agent by clicking the Prisma Agent 
 icon 

 from the macOS menu bar or
 Windows taskbar. 

 Select a different Location . You can
 Search for a location or choose a location from the
 list. 

 The list of available locations are sorted according to the best experience
 based on response time, availability, and other factors. The location that
 offers the best experience is listed as Best
 Location . 

 If your administrator enabled On Demand mode for the Prisma Agent , click the lock icon to connect to the newly selected
 location. Otherwise, Prisma Agent proceeds to changing
 locations.
