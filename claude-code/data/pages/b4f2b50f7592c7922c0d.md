 Modify Server Configurations 

 Customize and troubleshoot Cortex XSOAR 6.13 with server configuration settings. 

 Cortex XSOAR provides custom server configuration settings that enable you to customize your Cortex XSOAR environment on the server level, according to your needs. You can also use custom server configuration settings in situations where you experience issues or need to troubleshoot situations in your environment. 

 Add or Modify Server Configurations 

 Navigate to Setting > ABOUT > Troubleshooting > Server Configuration . 

 Click Add Server Configuration . 

 Add the Key and Value. 

 Click Save .
