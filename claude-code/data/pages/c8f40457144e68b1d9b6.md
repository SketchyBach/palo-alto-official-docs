 The WildFire™ API lets you programmatically retrieve
WildFire verdicts, samples, packet captures (PCAPs), and WildFire
analysis reports. You can also get a malware test file that you
can use to perform end-to-end testing of how the WildFire public
cloud processes a malware sample:
