 How to Manage Prisma Access 

 There are two ways to manage Prisma Access : Panorama to manage Prisma Access 
 or Strata Cloud Manager. 

 Where Can I Use
 This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 Prisma Access 
 license 

 There are two ways you can manage Prisma Access , so, you must decide how you want
 to manage Prisma Access before you get started: 

 Prisma Access (Managed by Strata Cloud Manager) 

 To manage Prisma Access from the cloud, use Strata Cloud Manager. With
 cloud management, you can quickly onboard branches and mobile users through
 task-driven workflows that allow you to set up and test your environment in
 minutes. Cloud management with Strata Cloud Manager simplifies the onboarding
 process by providing predefined internet access and decryption policy rules
 based on best practices. Quickly set up IPSec tunnels using defaults
 suitable for the most common IPSec-capable devices and turn on SSL
 decryption for recommended URL categories. 

 Strata Cloud Manager Command Center 

 The Strata Cloud Manager Command
 Center page appears when you launch your Strata Cloud Manager.
 This command center helps you in assessing the health of your network,
 better visibility, and an overview of your data. The command center has
 different dashboards to view different types of reports. 

 Prisma Access (Managed by Panorama) 

 Use the Cloud Services plugin on Panorama to set up and manage Prisma Access .
 This is a good option if you're already using Panorama to manage
 next-generation firewalls and you have a common policy that you want to use
 for access to your corporate applications. 

 If you have an existing Prisma Access (Managed by Panorama) deployment and want to migrate to Strata Cloud Manager
 for configuration management, Palo Alto Networks offers an in-product workflow that
 lets you migrate your existing Prisma Access configuration to Prisma Access (Managed by Strata Cloud Manager) ; however, note that you can't migrate from a Prisma Access (Managed by Strata Cloud Manager) deployment to a Prisma Access (Managed by Panorama) deployment. 

 Even if you're using Panorama to manage Prisma Access , you still use
 Strata Cloud Manager for many Prisma Access 
 visibility and monitoring features . 

 Prisma Access (Managed by Panorama) deployments use the Cloud Services plugin, which requires
 active internet connectivity for core functionality. Absence of a network
 connection will result in service failure. Constant internet access is
 recommended to maintain seamless synchronization and uptime. 

 After you decide which management option you want to use, get started by following
 the licensing and activation workflow for the option you've selected (either Strata Cloud Manager or Panorama ). 

 Feature Parity Between Panorama and Cloud
 Management 

 There are some differences between what is supported on Prisma Access (Managed by Panorama) 
 Access and Prisma Access (Managed by Strata Cloud Manager) . For a list of feature support in
 Prisma Access (Managed by Panorama) and Prisma Access (Managed by Strata Cloud Manager) , refer to the
 compatibility matrix .
