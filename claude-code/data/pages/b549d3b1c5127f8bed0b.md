Upload a private item
POST
https://api.prod.koi.security
/api/external/v2/private-items

Uploads a private item for the authenticated customer. The item is scanned and analyzed using the same pipeline as items uploaded through the platform.

Authorizations
bearerAuth
Authorization
string
required
Bearer authentication header of the form Bearer <token>.
Body
multipart/form-data
created_by
string
required

The user who uploaded the private item

item
string · binary
required

The item file to upload (.crx for Chrome, a zip archive or a plain-text SKILL.md file for skills)

marketplace
string · enum
required

The marketplace for the private item

Default: chrome_web_store
Possible values: chrome_web_storeskill
Responses
201

Private item uploaded successfully

No content

400

Missing item file or unsupported marketplace

401

Missing or invalid API key
