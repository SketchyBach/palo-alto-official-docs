 PAN-OS 11.0.2-h2 Addressed Issues 

 PAN-OS® 11.0.2-h2 addressed issues. 

 Issue ID 

 Description 

 PAN-230250 

 Fixed an issue where selected applications serving partial content
 were dropped when Inline Cloud Analysis in Anti-Spyware was
 enabled. 

 PAN-223787 

 ( PA-400 Series and PA-1400 Series firewalls only ) Fixed an
 issue where commits failed with the error message
 Error unserializing profile objects failed to
 handle CONFIG_UPDATE_START . 

 PAN-222957 

 Fixed an issue where managed firewalls did not reflect changes pushed
 by users that were not in a Superuser role. 

 PAN-218107 

 Fixed an issue with ciphers used for SSH tunnels where packet lengths
 were too large, which made the SSH tunnel unstable. 

 PAN-214942 

 Fixed an issue where SD-WAN traffic failed over to a non-member path
 after a flap of an SD-WAN virtual interface. 

 PAN-204868 

 Fixed an issue where disk utilization was continuously high due to
 the log purger not sufficiently reducing the utilization level.
