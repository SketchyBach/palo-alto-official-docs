 Manage your SSH admin password 

 Manage the SSH administrator password in Cortex XSOAR 8.14 On-prem. 

 You can optionally change the SSH admin user password, used to access the node's command line either through an SSH connection or your hypervisor's virtual machine console. This feature enables changing the password without direct shell access. 

 Admin passwords are set individually on each cluster node. There is no automatic sync between nodes, so you must repeat this process independently on each node. 

 In the textual UI menu, select Password Management . 

 Select Change admin password on next login . 

 Your current user session will continue. The SSH password change will be triggered on the next login.
