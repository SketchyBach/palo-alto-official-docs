 AWS Manual Onboarding Guide 

 Overview of the Onboarding Process 

 This document outlines the manual procedures required to connect an AWS account to Cortex. Here is what happens at a high level: 

 ( Phase 1 ) In the AWS onboarding wizard in Cortex, select the security capabilities that you want to enable. Cortex provides you with identifiers (names and IDs) in the onboarding wizard. 

 ( Phase 2 ) You run commands in your AWS account to create the required resources. 

 ( Phase 3 ) Complete the AWS onboarding wizard in Cortex by providing the resulting resource addresses (ARNs). 

 Cortex uses those resources to scan your AWS account for security issues.
