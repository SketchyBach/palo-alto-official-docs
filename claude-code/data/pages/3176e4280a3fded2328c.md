 Changes to Default Behavior in Cortex XDR Agent 7.9 

 Cortex XDR agent now supports Kernel Mode (KM) for Linux RHEL9; User Mode is no longer enforced. Whatever is configured in the profile, is applied. 

 For example, a customer with a default profile (with KM) that had Cortex XDR agent 7.8 was previously using user mode. With the upgrade to agent 7.9 (and content deployment) the agent will run in KM mode. 

 The Open Log File function has been removed from the Windows and macOS user interface.
