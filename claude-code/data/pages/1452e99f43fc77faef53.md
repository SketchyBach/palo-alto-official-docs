 Cortex XSOAR 8.14 On-prem 

 Use a signed certificate instead of SSL verification 

 Use a signed HTTPS certificate instead of SSL verification in Cortex XSOAR 8.14 On-prem MSSP deployments. 

 Self-signed certificates are customizable and cost-effective for internal systems or development environments where external trust is not required, offering independence from third-party certificate authorities. For more information about creating a signed certificate, see HTTPS with a signed certificate . 

 Disable SSL verification for multi-tenant 

 In a multi-tenant setup, if a child tenant has a self-signed certificate, you can disable SSL verification for requests between the parent and child tenant. 

 From the textual UI menu in your VM, select Application Settings . 

 Select Skip SSL Verification for MSSP . 

 Click Apply . 

 Disable SSL verification for content management 

 If you use a remote repository to manage content, you can use a self-signed certificate instead of SSL verification for requests between the development tenant, the remote repository, and the production tenant. Using a self-signed certificate provides encryption and secure communication without the cost and complexity of obtaining a trusted SSL certificate from a certificate authority. 

 From the Textual UI menu in your VM, select Application Settings . 

 Select Skip SSL Verification for Content . 

 Click Apply .
