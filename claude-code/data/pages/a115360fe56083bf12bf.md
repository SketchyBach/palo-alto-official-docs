 Configure NAT Zones 

 Learn how to configure NAT Zones in Prisma SD-WAN . 

 Where Can I Use
 This? What Do I Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 Source and destination zones identify traffic
that is sourced from a zone or destined to a zone, respectively.
Zones must be bound to interfaces for NAT to be effective. Zones
used in NAT policy rules are different than zones used in Prisma
SD-WAN security policy rules. You can configure NAT zones from the
 Prisma SD-WAN web interface. 

 Navigate to Configuration Prisma SD-WAN Policies NAT NAT Zones . 

 Select Add NAT Zone to create
a new NAT zone. 

 Enter a Name and optional Description and Tags for
the NAT zone. 

 Click Create to add the NAT zone. 

 From the ellipsis menu for a NAT zone, you may Edit , View
 Interface Bindings , Delete , and view
 the Audit Logs for a NAT zone. 

 Bind NAT Zones to Interfaces 

 Zones can be attached or bound to individual interfaces at the device-level. To
 bind NAT Zones to interfaces from the Prisma SD-WAN web
 interface. 

 Navigate to Configuration Prisma SD-WAN Policies NAT NAT Zones . 

 From the ellipsis menu for a NAT zone, select View Interface
 Bindings to view NAT zones bound to interfaces for a
 device. 

 Click Bind Interface(s) to create a new interface
 binding. 

 From the Device drop-down, select an ION device.
 From the Interfaces drop-down, select an available
 interface, and click Save .
