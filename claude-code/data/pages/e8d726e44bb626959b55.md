 Learn about the INC_PA_SERVICE_DEGRADATION_SC_CONNECTIVITY incident. 

 Incident Code 

 INC_PA_SERVICE_DEGRADATION_SC_CONNECTIVITY 

 Title Template 

 Prisma Access Service Degradation impacting service connections/data center connectivity for location {location} 

 Category 

 Network Services 

 Subcategory 

 Prisma Access Infrastructure 

 Description 

 There is a degradation in the Prisma Access service related to connectivity with the Security Connector (SC). This degradation may lead to issues or instability in the connection between the Prisma Access infrastructure and the Security Connector. It is important to investigate this incident promptly to determine the cause of connectivity issues and take appropriate steps to restore stable connectivity for efficient operation and security within the Prisma Access environment.
