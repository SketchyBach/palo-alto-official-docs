 Create Notification Templates 

 Notification templates define the content and format of email alerts for system events, such as certificate expiration. Select a notification template when you configure a new or existing notification in the Notification Rules. The system uses the template to generate notifications sent by email or through integrated notification providers. 

 Before You Begin 

 If you plan to use a notification provider such as PagerDuty or Zoom Team Chat, add the provider to Next-Gen Trust Security. For more information, see Notification Provider Integrations . 

 To create notification templates for certificate expiration events, configure the certificate monitoring service. For more information, see Set up certificate expiration notifications . 

 Create a Notification Template 

 Sign in to Next-Gen Trust Security. 

 Click Configuration > Certificate Notifications > Notification Templates . 

 Click New . 

 In Name , enter a name for the notification template. 

 In Event Type , select the event type. 

 In Subject , enter the email subject line. 

 In Severity , select a severity level. 

 Click Editing to create or modify the notification content and reorder widgets as needed. 

 Note: To review the template, use the Preview pane. 

 Click Save . 

 Edit a Notification Template 

 Sign in to Next-Gen Trust Security. 

 Click Configuration > Certificate Notifications > Notification Templates . 

 Select the notification template. 

 Under Details , modify the Name , then click Save . 

 Under Email Content , update the notification content and reorder widgets as needed, then click Save .
