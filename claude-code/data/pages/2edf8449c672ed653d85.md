 Learn how Prisma Access performs dataplane upgrades to help protect your

 Prisma Access performs dataplane upgrades to help protect your organization's end-users,
 business assets, and security posture. 

 Select Configuration Prisma Access Upgrades to stay informed about the Prisma Access upgrade schedule for your
 dataplane upgrade and to select your upgrade preferences. After the upgrade starts, you
 can also monitor the status of the upgrade using Strata Cloud Manager as shown
 below.
