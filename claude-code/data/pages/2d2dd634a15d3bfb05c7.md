 Changes to Default Behavior in 2025 

 Review changes to default behavior in Device Security . 

 Where Can I Use This? What Do I Need? 

 Device Security (Managed by Strata Cloud Manager) 

 (Legacy) IoT Security (Standalone portal) 

 One of the following subscriptions: 

 Device Security subscription

 Precision AI bundle subscription

 Device Security X subscription

 Review the following changes to default behavior in Device Security . 

 Changes to Default Behavior Introduced in December 2025 

 The following table details the changes in default behavior for
 Device Security in Strata Cloud Manager , introduced in December 2025.

 Component Change 

 Recalls 

 When the Medical Device Security vertical is enabled, you can
 filter the Source attribute in the
 Recalls table on the Risks Recalls page.

 Vulnerabilities 

 The Vulnerabilities Overview and
 Vulnerability Instance Details downloads from the
 Vulnerabilities Inventory now support files greater than 10MB.

 Changes to Default Behavior Introduced in October 2025 

 The following table details the changes in default behavior for
 Device Security in Strata Cloud Manager , introduced in October 2025.

 Component Change 

 Integrations 

 Integrating Device Security with Tanium 
 now requires an API token for authentication.
 Existing Tanium integrations that use a username and password
 for authentication no longer work. You need to create new
 integration instances with an API token for authentication,
 and then associate the new instances with your
 Tanium integration jobs.

 Changes to Default Behavior Introduced in September 2025 

 The following table details the changes in default behavior for
 Device Security in Strata Cloud Manager , introduced in September 2025.

 Component Change 

 Device Details 

 We introduced new top-level groupings for all common attributes.
 When viewing the column selector in the Assets Inventory, and
 when viewing the device attributes on the Device Details page,
 you can find all common attributes under the following
 categories:

 Identity

 Security

 Software Components & Vulnerabilities

 Custom Attributes

 Configuration & Network

 Operational Context

 Global Filter 

 In the Assets Inventory global filter, you can now filter by
 VLAN ID and save the filtered view. This lets you apply
 custom attributes and tags to devices based on their VLAN ID.

 Changes to Default Behavior Introduced in August 2025 

 The following table details the changes in default behavior for
 Device Security in Strata Cloud Manager , introduced in August 2025.

 Component Change 

 Integrations 

 Third-party integrations no longer require an add-on license.
 You can activate a free, limited
 cloud-based Cortex XSOAR from the
 integrations page for Device Security in
 Strata Cloud Manager . The free Cortex XSOAR for
 third-party integrations is not available in the
 legacy IoT Security portal.

 IP Endpoints 

 You can download the IP Endpoints inventory using the
 download button next to the Total IP Endpoints value
 in the IP Endpoints Overview widget.

 Reports 

 You can specify the
 Saved Filters/Queries field when
 generating a report on demand, and not only when creating a
 scheduled report.

 Sites 

 Device Security now treats site names as separate if they use
 different upper and lower case letters.

 Changes to Default Behavior Introduced in July 2025 

 The following table details the changes in default behavior for
 Device Security in Strata Cloud Manager , introduced in July 2025.

 Component Change 

 Query Builder 

 You can now copy queries from the Query Builder widget. You can
 use the Copy Query button, or copy the
 query text from the text field.

 Subnets 

 Deleted networks are re-added to the Network inventory if you
 modify or add the network through CSV uploads, API calls,
 third-party integrations, or the web interface.

 Clickable Links 

 Clickable links that previously had temporary chips no longer
 display the temporary chips. The link directly updates the
 global filter.

 Device Security Navigation 

 We have enhanced the Device Security navigation in
 Strata Cloud Manager to make it simpler and more efficient.
 See the table below for a summary of the changes.

 Renamed Vulnerabilities to Risks 
 to better reflect the inclusion of both
 vulnerabilities and other risk factors.

 Simplified navigation by unnesting pages,
 reducing the number of clicks needed to get to
 key information.

 Decluttered the interface with a new More 
 button in the secondary navigation for less common
 pages.

 Relocated Settings by moving
 configuration workflows into their relevant
 top-level sections, such as Assets ,
 Risks , and Alerts .

 Changes to Default Behavior Introduced in June 2025 

 The following table details the changes in default behavior for the
 Device Security portal, introduced in June 2025.

 Component Change 

 Security Alerts 

 When configuring Security Alerts, Device Security no longer
 supports SMS notifications.

 Vulnerabilities 

 The Vulnerability Inventory now shows
 Confirmed as “Yes” if there are any
 confirmed vulnerability instances, even if there are also
 unconfirmed instances.

 Changes to Default Behavior Introduced in March 2025 

 The following table details the changes in default behavior for the
 Device Security portal, introduced in March 2025.

 Component Change 

 Reports 

 Device Security roles with permission to create
 scheduled reports 
 can now send generated reports to non- Device Security users.

 Custom Attributes 

 When defining a custom attribute ,
 you can now use special characters in the attribute value.

 Changes to Default Behavior Introduced in February 2025 

 The following table details the changes in default behavior for the
 Device Security portal, introduced in February 2025.

 Component Change 

 DHCP Syslog for Firewalls 

 When viewing firewall information under Administration Firewalls Firewalls , the Firewall Log Type Status and Firewalls
 tables include information for DHCP syslog.

 Sites Download 

 When you Download the sites from
 Networks Networks and Sites Sites 
 table, you can now select and download all rows in the table,
 not just the rows on the current table page.
