 dump routing multicast sources 

 Use the dump routing multicast sources command
to display the information about multicast source(s). 

 This
command is not available from the release 6.0.1 onward. 

 Command 

 dump routing multicast sources 

 Options 

 None 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands 

 dump routing multicast statistics 

 Introduced in Release 5.6.1 

 Example 

 dump routing multicast sources
 PIM Source entries:
 Address I/F Metric Pref Adv-Hold Neighbor AD Cost
 172.16.3.100 eth2 0 0 0 None 0 0
