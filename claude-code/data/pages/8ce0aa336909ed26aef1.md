 dump app-probe prefix 

 Use the dump app-probe prefix command
to display statistics for prefixes mapped against an application
for each path or port combination. 

 Command 

 dump app-probe prefix application=<name of the application> [server-ip= | path-id= | port= ] 

 Options 

 application Enter an application name to
display prefixes for the application. 

 server-ip Enter a server IP address to display prefixes
mapped to the server. 

 path-id Enter a Path ID to display prefixes mapped
to the path. 

 port Enter a port number to display prefixes mapped
to the port. 

 Command Notes 

 Role Super, Read Only Monitor 

 Related Commands 

 clear app-probe prefix 

 Introduced in Release 5.1.1
