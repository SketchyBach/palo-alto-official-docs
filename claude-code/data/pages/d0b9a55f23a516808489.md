 The User-Agent control appends an additional component to the default
 User-Agent string on Prisma Browser HTTP/S requests for matched applications.
 Use this control to identify Prisma Browser traffic by User-Agent string when
 integrating with third-party services or analytics platforms. 

 To set the User-Agent control: 

 From Strata Cloud Manager , select Configuration Policy Control Sets Data Control Configure Header Modification 

 Select User-Agent . 

 Select one of the following options: 

 Use default User-Agent - The Prisma Browser uses the default User-Agent string without modification. 

 Set an additional User-Agent component - The
 Prisma Browser appends the specified component to the
 default User-Agent string for matched applications. 

 Specify the additional User-Agent component. 

 Click Set .
