 If you're using Panorama as your management platform for Prisma Access , Panorama
 Support for Prisma Agent enables you to manage and configure the Prisma Agent using Panorama . This feature seamlessly integrates
 Panorama managed environments with the Prisma Agent , providing
 a unified approach to secure remote access management. 

 Key components of this solution include: 

 Configuration Management: You can manage Prisma Agent 
 configurations, including app settings, forwarding profiles, authentication
 methods, and global settings, all while continuing to use Panorama for your
 existing infrastructure. 

 Infrastructure Integration: The system inherits infrastructure, gateway, Prisma Access locations, and authentication settings from the Panorama environment, providing ease of configuration. 

 Authentication and User Management: By using authentication from Panorama or
 Cloud Identity Engine, the solution supports advanced authentication methods and
 user group management. 

 Forwarding Profiles: These profiles control traffic routing and enforcement,
 replacing traditional split-tunnel configurations with more granular and
 flexible options. 

 Behind the scenes, services handle the import of Panorama configurations, manage
 configuration snapshots, and integrate with partner services. This architecture ensures
 smooth operation across Panorama, Prisma Access, and on-premises environments. 

 By using this feature, you can use Panorama to effectively manage your Prisma Agent environment alongside your existing Panorama managed
 infrastructure, enhancing their overall security posture and remote access
 capabilities.
