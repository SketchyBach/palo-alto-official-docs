 Export API Key using Secure Copy (SCP) 

 Use this command to export an API key using
secure copy (SCP): 

 Save all API keys to a file to prepare the keys
for export: 

 admin@WF-500# save wildfire api-key to filename 

 For
example: 

 admin@WF-500# save wildfire api-key to my-api-keys 

 To secure copy (SCP) the API key file to an SCP-enabled
server: 

 admin@WF-500> scp export wildfire-api-keys to username@host:path 

 For
example: 

 admin@WF-500> scp export wildfire-api-keys to bart@10.10.10.5:c:/scp/
