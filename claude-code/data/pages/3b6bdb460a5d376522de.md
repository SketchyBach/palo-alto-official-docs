 Native IPv6 Support for Prisma Access Remote Networks (Panorama) 

 Enable native IPv6 support for Prisma Access remote networks in Panorama 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Panorama Managed) 

 Prisma Access license 

 Prisma Access 6.2 

 Use this procedure to enable native IPv6 support for Prisma Access remote networks. 
 Navigate to Panorama Cloud Services Configuration Service Setup Settings . 

 Select the Settings gear. 

 Click the Enable IPv6 checkbox to activate IPv6
 capabilities across your Prisma Access deployment. 

 Configure the IPv6 address with a subnet. 

 Click Enable IPv6 WAN , and select
 OK . 

 Navigate to Panorama Cloud Services Configuration Remote Networks Onboarding and select Add . 

 Click the Enable IPv6 checkbox to activate IPv6
 capabilities across your Prisma Access deployment. 

 Configure an IPSec Tunnel 

 Use the drop-down to add a new or modify an existing IPsec tunnel. 

 Name the IPsec tunnel. 

 Enable IPv6 . 

 Configure an IKE Gateway 

 Use the drop-down to add a new or modify an existing IKE gateway. 

 Name the IKE gateway. 

 Enable IPv6 .
