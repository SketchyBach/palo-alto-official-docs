 Setup Prerequisites for Email DLP 

 Allow the egress IP addresses and outbound SMTP server domains required for
 Enterprise Data Loss Prevention (E-DLP) to deliver Email DLP delivery notifications to email
 senders. 

 Enterprise DLP sends delayed status notifications (DSNs), non-delivery reports
 (NDRs), and permanent delivery failure notifications directly from its outbound mail
 server to the original email sender, rather than through a relay server. To ensure
 senders receive these notifications, you must allow the following Enterprise DLP 
 egress IP addresses and outbound SMTP server domains on your organization's inbound SMTP
 server.
