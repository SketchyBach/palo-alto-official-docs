 Install the PA-220R Firewall 

 Learn about the different ways to install a PA-220R firewall. 

 The PA-220R next-generation firewall ships with the
hardware required to install the firewall on a flat surface or on
a DIN rail. You can also order a wall-mount kit to install the firewall
on a wall or a rack-mount kit to install the firewall in a 19” equipment
rack.
