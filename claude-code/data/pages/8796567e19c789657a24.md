 Configure the Memory Limitation 

 Configure Docker memory limits in Cortex XSOAR 6.13. 

 If swap limit capabilities is enabled, in Cortex XSOAR configure the memory limitation using the following advanced parameters. 

 Select Settings → About → Troubleshooting → Add Server Configuration . 

 Type the following: 

 Key 

 Value 

 limit.docker.memory 

 true 

 docker.memory.limit 

 1g 

 Reset the running containers by typing the following command: 

 /reset_containers
