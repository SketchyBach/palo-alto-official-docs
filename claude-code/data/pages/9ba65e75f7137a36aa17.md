 AL_RN_SITE_LONG_DURATION_EXCEEDED_ CAPACITY 

 Learn about the AL_RN_SITE_LONG_DURATION_EXCEEDED_CAPACITY alert. 

 Synopsis 

 Remote network bandwidth consumption was consistently greater than 100% of the
 capacity for at least 1 hour per day for at least 3 of the last 5 days. 

 This bandwidth alert applies to the per remote network site bandwidth allocation
 model and not to the aggregate bandwidth allocation model. For information about
 bandwidth allocation and how to allocate bandwidth for specific remote network
 sites, see Allocate Remote Network Bandwidth in the
 Prisma Access Administration Guide . 

 Alert Code—AL_RN_SITE_LONG_DURATION_EXCEEDED_CAPACITY 

 Required License 

 Prisma Access 

 Severity 

 Critical
