 Prisma SD-WAN Releases and Upgrades 

 Learn about the Prisma SD-WAN release types, upgrade process, and advance notification timelines. 

 Where Can I Use This? What Do I Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 Prisma® SD-WAN Controller releases and updates provide new features and functionality,
 infrastructure enhancements, and web interface improvements. Palo Alto Networks manages
 controller updates and notifies you in advance so you can plan accordingly. ION device
 software updates are your responsibility; you manage them based on your network
 requirements. 

 You can retrieve the status of all cloud services, including Prisma SD-WAN, along with a
 historical record of service uptime, at the Palo
 Alto Networks SASE status page . You can also sign up for email or text
 notifications to receive advance notice of planned infrastructure updates and real-time
 alerts when Palo Alto Networks creates, updates, or resolves an incident. 

 Prisma SD-WAN Release Types 

 Prisma SD-WAN releases include major releases, maintenance releases, ION device
 software updates, and infrastructure maintenance — each delivering new features,
 optimizations, or fixes to your branch and data center networks. 

 The following release types define how Palo Alto Networks delivers updates, including
 the advance notification timeline for each. To receive notifications, register for
 email or text alerts at the Palo Alto Networks SASE status
 page . 

 Major Release —A major release includes significant new features and
 optimizations. Palo Alto Networks sets the maintenance window and notifies
 you at least 21 days in advance via the Palo Alto Networks SASE status page and through
 Strata Cloud Manager. 

 Maintenance Release —A maintenance release focuses on bug fixes and at
 times introduces new features. Palo Alto Networks sets the maintenance
 window and notifies you at least 21 days in advance via the Palo Alto Networks SASE status page and through
 Strata Cloud Manager. 

 ION Device Software Releases —ION device software releases are
 allocated to your tenant and appear in your Software
 Upgrade options in Strata Cloud Manager. Palo Alto Networks
 does not upgrade your ION devices automatically — you control when upgrades
 occur. For release guidance, see the Prisma SD-WAN ION Software Release
 Guidelines on Live Community and the corresponding Release
 Notes. 

 Infrastructure Maintenance —Infrastructure maintenance delivers
 incremental features and optimizations. In some cases, Palo Alto Networks
 combines a hot fix with infrastructure maintenance. 

 Palo Alto Networks provides advance notification for major, maintenance, and
 infrastructure maintenance releases: 

 Release Type Notification Period 

 Major Release At least 21 days before the release 

 Maintenance Release At least 21 days before the release 

 Infrastructure Maintenance At least 10 days before the maintenance window 

 In addition to scheduled releases, Palo Alto Networks may
 perform urgent upgrades that follow a different notification timeline. See Urgent
 Scheduled Upgrades below for details. 

 Urgent Scheduled Upgrades 

 Palo Alto Networks occasionally performs urgent control plane or infrastructure
 upgrades, such as hot fixes or emergency bug fixes for zero-day vulnerabilities or
 critical web interface issues. Palo Alto Networks makes every effort to notify you
 at least 48 hours before an urgent upgrade; however, in some cases you may receive
 shorter notice. 

 Web Interface and Infrastructure Updates —Palo Alto Networks can deliver
 web interface patches outside of a formal release process to address
 functionality issues when no API or backend changes are required. These updates
 typically occur within CI/CD and Urgent Update windows scheduled every Friday
 and Sunday, 8 PM–2 AM PT (4 AM–10 AM UTC).
