# Theme Running Code

Theme Running Code

Severity

🟠 Medium (5)

Short Description

Flags theme type extensions that run code on the user's machine. Themes should be static JSON files and not execute any code.

Suggestion

Review the extension's behavior and remove it if the code execution is unnecessary or suspicious.

Information

Theme extensions are typically used for visual customization. If they execute code, it may indicate unintended behavior or a potential compromise.

Risks of Theme Running Code

Unintended Behavior: Code execution in themes may introduce unwanted functionality.

System Exploitation: Executing code can lead to privilege escalation or malicious actions.

Reduced Trust: Themes running code deviate from expected behavior, reducing user confidence.

Recommended Actions

Investigate the Item:

Analyze Behavior: Review the purpose of the code being executed and its necessity.

Verify the Publisher: Confirm the extension is from a trusted source.

Evaluate Usage: Assess the impact on systems and users.

Immediate Action:

Remove the Extension: If code execution is unnecessary or risky, remove the theme.

Notify Stakeholders: Inform relevant users or teams about the risks and actions taken.
