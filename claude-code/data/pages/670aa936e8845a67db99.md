 Access Domain Enhancements for Multi-Tenancy 

 Allows Panorama™ administrators to view configuration
and system logs, as well as some firewall functions and tasks, in
multi-tenant environments. 

 To provide further visibility in to multi-tenant
environments, PAN-OS 10.0 introduces the ability for Device Group and Template (DG&T)
admins to view the configuration and systems logs for devices within
their access domain. Additionally, DG&T admins can also view
firewall configuration operations (partial commit, load, and revert),
as well as monitor the Application Command Center (ACC)
to gain additional visibility into the network traffic activity
for devices in the access domain. To gain additional visibility,
both the Panorama management server and the managed device must
both be running PAN-OS 10.0, and the DG&T admin access domain
can only include up to 256 managed devices. The DG&T admin is
unable to view the logs, view configuration operations, or monitor
the ACC for the devices in the access domain if the number of managed
devices in the access domain exceeds 256 devices.
