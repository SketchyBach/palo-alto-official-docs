 The table provides list of GlobalProtect features introduced in PAN-OS

 New GlobalProtect Feature Description 

 SAML/CAS ACS Landing Page Customization 

 You can now customize the SAML/CAS ACS
 landing page displayed on the default browser when you
 are using the SAML/CAS authentication method to authenticate to the
 GlobalProtect app. You can configure to rebrand or debrand the
 SAML/CAS ACS landing page on the default browser by using
 command-line interface (CLI) commands. By default, the feature is
 not enabled for the app. 

 This feature is not available on
 Panorama.
