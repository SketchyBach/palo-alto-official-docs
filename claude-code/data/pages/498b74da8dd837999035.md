 Cortex XSIAM - Analytics 

 Learn how to enable Cortex XSIAM - Analytics, which allows Cortex XSIAM to analyze data from a variety of sensors and develop a baseline to raise analytics alerts. 

 The Cortex XSIAM Analytics engine enables Cortex XSIAM to analyze data from a variety of sensors and develop a baseline to raise analytics alerts when anomalies and malicious behaviors are detected. 

 Prerequisite 

 Before Cortex XSIAM - Analytics can start to analyze your endpoint data, perform the following steps: 

 Configure Cortex XSIAM network parameters to monitor your internal networks. 

 Enable the Analytics Engine. 

 Make sure Cloud Identity Engine is set up. 

 Enable Identity Analytics.
