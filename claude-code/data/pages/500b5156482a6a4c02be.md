 How to back up and restore Cortex XSOAR 

 Back up and restore Cortex XSOAR 8.14 On-prem clusters using on-demand or scheduled backups. 

 You can periodically back up data, configurations, and settings to ensure continuous and efficient operation of your Cortex XSOAR tenant. This minimizes downtime, prevents data loss, and helps you to recover in case of failure, corruption, or rollback. 

 Tip 

 You can directly download older software versions of virtual machine images from Cortex Gateway without relying on engineering assistance, enabling seamless backup and restore operations. 

 You can perform on-demand or scheduled backups and on-demand restore from external storage. 

 If you used backup and restore in Cortex XSOAR 8.8, consider the following; 

 Your NFS server connection will be seamlessly created under Settings & Info → Settings → System → External Storage . 

 Any existing backup schedules will be seamlessly created in the system and will continue to back up at the same scheduled times. If you see an error message that the schedule cannot be converted, contact support. 

 Cortex XSOAR 8.8 backups can be viewed in the Restore tab by choosing the automatically created external storage and the default relative path backups . However, restore between major versions (between 8.8 and 8.9) is not supported. To restore a Cortex XSOAR 8.8 backup, reinstall Cortex XSOAR 8.8 and restore via the CLI.
