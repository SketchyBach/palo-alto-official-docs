 Check Tunnel Status (Cloud Managed CloudBlade) 

 Check the tunnel status of the Cloud managed CloudBlade. 

 If you're using Strata Cloud Manager, go
 to Configuration NGFW and Prisma Access Remote Networks and select the Remote Networks tab. 

 The Tunnel status indicates the operational status of the remote
 network. If the tunnel status shows OK , it indicates that the
 tunnels are established and traffic is flowing. If there are errors or warnings, review
 the system log in Prisma Access . 

 The Config indicates difference between the applied (running)
 configuration and local (candidate) configuration. If you have made a change locally,
 and not yet pushed the configuration, the status shows Out of
 sync . Hover over the status indicator for more detailed information. To
 change the config status to In sync , commit and push the
 configuration to Prisma Access.
