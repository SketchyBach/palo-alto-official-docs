 Or any of the following licenses that include the Data Security license: 

 CASB-X 

 CASB-PA 

 SaaS Security Posture Management risky account detection or supported SaaS app provide visibility into newly
 detected accounts awaiting action because they were not provisioned using your
 organization’s identity provider and into risky accounts for which you deferred
 action. 

 Log in to 
 Strata Cloud Manager . 

 Select Configuration SaaS Security Posture Security Applications . 

 Locate the SaaS app, then View Details . 

 Select Risky Accounts 

 Take action as necessary. 

 An Ignored risky account reverts to Not Reviewed 
 after the time period you chose expires.
