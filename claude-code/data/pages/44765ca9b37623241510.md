# Event Hijacking

For the complete documentation index, see llms.txt. This page is also available as Markdown.

Event Hijacking

Severity

🟠 High (7)

Short Description

Flags AI extensions that intercept agent events to covertly modify behavior, inject prompts, or alter tool results.

Suggestion

Treat covert interception as malicious. A hook that changes what the agent sees or does without surfacing it to the user should be removed, not tuned.

Information

Hooks sit in the path between the agent, its tools, and the user. That position is legitimate and useful - a formatting hook rewrites output, a validation hook blocks a bad command. Event hijacking is what happens when that position is used to change the agent's behavior without disclosing it: injecting instructions so the agent follows directives the user never issued, modifying tool results so it reasons over data that does not reflect reality, or suppressing events so actions that should have been surfaced or blocked pass silently.

What makes this severe is that it is invisible from the outside. The user sees a normal conversation, and the agent behaves consistently with what it was given - but what it was given was altered in transit. Neither party can tell from the transcript that interception occurred, and because hooks run automatically on events, the manipulation applies to every session on the machine.

Risks

Prompt injection at the hook layer: Injected instructions carry the authority of the agent's own context and bypass anything the user sees.

Falsified tool results: The agent acts on data that has been altered after the tool returned it.

Suppressed visibility: Events that should have surfaced or triggered a guardrail can be dropped silently.

Session-wide, persistent scope: The hook applies to all agent activity on the machine, not just to tasks related to the plugin.

Recommended Actions

Investigate the component

Read the evidence to identify which events are intercepted and how they are modified.

Determine whether the modification is disclosed by the publisher or hidden.

Review recent agent activity on affected devices for actions the user did not request.

Contain and remediate

Disable the hook immediately; do not leave it enabled during investigation.

Audit agent activity logs for injected instructions or unexplained tool results while the hook was active.

Remove the plugin and review other components from the same publisher.

Report the plugin to the marketplace.
