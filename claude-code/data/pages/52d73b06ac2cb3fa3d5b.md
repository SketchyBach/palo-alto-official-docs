 Feature Enhancements 

 Application Security 

 FEATURE 

 DESCRIPTION 

 Infrastructure-as-Code (IaC) drift detection 

 Application Security now supports IaC drift detection, allowing you to automatically detect when cloud resources drift from their IaC definitions. This enables identifying configuration changes made directly in runtime that break compliance with your IaC baselines, helping you maintain consistent and secure cloud environments. 

 Compliance support for Infrastructure-as-Code (IaC) 

 Application Security now supports Infrastructure-as-Code (IaC) compliance checks as part of the Posture Management Compliance platform. This enables automated, shift-left verification of cloud configurations against industry standards and regulatory frameworks (such as CIS Benchmarks), ensuring security and compliance before deployment. 

 JFrog Artifactory integration 

 Application Security now supports direct integration with JFrog Artifactory to enhance Software Composition Analysis (SCA). This integration enables the secure resolution of dependencies sourced exclusively from JFrog Artifactory, improving Software Bill of Materials (SBOM) visibility and vulnerability detection accuracy within your application environment. 

 Ingest Snyk SCA data 

 You can now ingest Software Composition Analysis (SCA) vulnerability findings from Snyk into Cortex Cloud. Once the findings are ingested, Cortex Cloud Application Security applies policies to create actionable issues.
