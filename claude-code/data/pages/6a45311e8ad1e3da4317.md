 Assign Domains to Sites 

 Learn how to assign domains to sites in Prisma SD-WAN . Binding a domain is
 essentially mapping a site to a domain, enabling access to all the endpoints within
 groups/domain. 

 Where Can I Use
 This? What Do I Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 Prisma SD-WAN 

 Prisma SD-WAN AppFabric deployed
 at one or more locations. 

 Physical and/or virtual ION devices running
 software versions 5.6.X or higher. 

 Prisma Access Cloud Managed 
 Prisma Access with Aggregate Bandwidth; the
 bandwidth licensing mode must be enabled per compute
 location on the Prisma Access Cloud Managed
 portal. 

 Identification of the IPSec Termination Nodes within
 Prisma Access for connectivity. 

 Ensure that you have Prisma Access (Cloud Managed) and
 Prisma SD-WAN in the same TSG. 

 Binding a domain is essentially mapping a
site to a domain, enabling access to all the endpoints within groups/domain.
Different domains can be mapped to different sites, but only one
domain may be mapped per site. 

 Select Configuration Resources Service & DC Groups . 

 Select Sites . 

 From the drop-down next to each site, select the appropriate domain. 
 To bulk edit all sites, select the Edit All 
 button. 

 Click Save .
