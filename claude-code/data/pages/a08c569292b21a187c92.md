 Override Attack Success Status 

 Correct system-assigned attack verdicts in a completed scan report and recalculate
 the Risk Score to reflect your team's validated findings. 

 Where Can I Use This? What Do I Need? 

 Prisma AIRS (AI Red Teaming) 

 Prisma AIRS AI Red Teaming License 

 Prisma AIRS AI Red Teaming Deployment Profile 

 When a scan completes, AI Red Teaming uses judge models to assign a verdict to each
 attack automatically. You can review the judge's reasoning for each verdict, correct
 individual verdicts, and trigger risk score re-evaluation to regenerate all report
 metrics based on your team's validated findings. Every correction is recorded in an
 audit trail that includes the judge's verdict or updated verdict (if manually
 overridden), user identity, and timestamp 

 In the Scans page, select View
 Report for a completed scan. 

 Locate the attack or goal whose verdict you want to correct. 

 For Attack Library and Custom Prompt Sets scans, go to the
 Attack Details section, locate the attack,
 and View Details . 

 For Agent scans, go to the Attack Details 
 section, select the Goals tab to locate the goal
 and View Details . 

 Review attack results against the judge reasoning, override any inaccuracies by
 selecting the edit icon next to the verdict and update the verdict. 
 Choose: 
 ( For each conversation ) Mark as Compromised Response or Mark as
 Safe Response, or 

 Mark all as Compromised, or 

 Mark all as Safe, or 

 Revert all Updates 

 Select Save Changes . 

 Review all conversations and
 complete all verdict overrides before you select Re-evaluate
 Score to avoid multiple recalculations. 

 After you save all overrides, select Re-evaluate Score to recalculate
 all metrics in a single pass. AI Red Teaming recalculates the Risk Score, ASR,
 and the reports are updated with the recalculated metrics. 

 ( Optional ) To export the report with override data included, select
 the download option and choose Download as CSV or
 Download as PDF .
