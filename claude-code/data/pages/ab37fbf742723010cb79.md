 Vulnerablity Management 

 FEATURE 

 DESCRIPTION 

 Enhancements to vulnerability findings 

 Vulnerability findings now include additional details such as remediation guidance, CVRS score, detected controls and control coverage, and intelligence score sources. Vulnerability findings are also available for XQL queries. These improvements make it easier to prioritize, investigate, and remediate vulnerability findings more easily and confidently. 

 Vendor advisory links in Vulnerability Intelligence 

 Vulnerability Intelligence pages now provide quick access to additional vulnerability technical details and links to vendor advisory sites. 

 Accelerate remediation with resolution actions 

 To expedite issue resolution, Vulnerability Management now features resolution actions. Resolution actions are suggested quick actions, such as creating a ticket, deploying an XDR agent, or notifying users, that can be executed through the UI, AI, automation, or APIs.
