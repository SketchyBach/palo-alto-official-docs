 Create a Custom Report 

 Build a custom security report in AI Canvas by assembling widgets and page layouts,
 then distribute the completed PDF from the Reports page. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 Strata Cloud Manager
 Pro license 

 Prisma Access license 

 Acceptance of the Strata Copilot SEULA for the tenant 

 Use Custom Reports when standard report templates don't include
 the specific data your audience needs. 

 Select Strata Canvas Reports from the Strata Cloud Manager menu. 

 In the Custom Reports section, click the
 Create New card ( + ). 
 You can also click + Create New in the top-right corner
 of the Reports page to open the editor directly. 

 fig 

 Choose whether to start from scratch or select a pre-built template. 

 Enter a name and description for the report in the header toolbar. 

 Add and organize pages in your report: 

 To add a page, click Add Page . 

 To reorder pages, drag the page thumbnails in the bottom navigation
 panel into the order you want. 

 To delete a page, select it and click the Delete
 Page icon. The report requires at least one page. 

 Add widgets to each page from the widget library on the right sidebar. 
 Drag a widget onto the page grid. You can resize, reorder, rename, and remove
 widgets after placing them. Widgets that require user interaction are not
 available because they don't render accurately in PDF output. 

 ( Optional ) Click Create Widget to create a new
 widget using the natural language prompt. 

 In the prompt field, enter a description of the content you want—for
 example, Show top threats by severity and affected
 assets —then click the send arrow. 

 Click the Select Sources + icon in the prompt
 window and select one or more data sources for the widget. 
 Available data sources include 
 Autonomous DEM 

 Cloud-Delivered Security Services (CDSS) for Advanced Threat
 Prevention, Advanced WildFire, and Advanced URL Filtering 

 Prisma Access logs and metrics 

 Prisma Browser 

 Log Viewer data 

 Click Add to Widget Library , then drag the
 widget onto the report page. 

 Configure global filters for the report in the left sidebar. 
 Filters apply to every compatible widget across all pages simultaneously.
 The available filters adjust dynamically based on the widgets present in the
 report. 

 Click Print view to preview the report and click
 Save . 
 The saved report appears in the Custom Reports section of the Reports page,
 where you can download it as a PDF, share it with recipients by email, or
 schedule it for recurring delivery .
