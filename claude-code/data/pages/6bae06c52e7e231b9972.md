 GlobalProtect Gateways Agent Tab 

 Network GlobalProtect Portals <portal-config> Agent 

 Select the Agent tab to configure the
tunnel settings that enable the app to establish a VPN tunnel with
the gateway. In addition, this tab lets you specify timeouts for
VPNs, network services of DNS and WINS, and HIP notification messages
for end users upon matching or not matching a HIP profile attached
to a Security policy rule.
