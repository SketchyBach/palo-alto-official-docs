 Reference C: Scan health values 

 Scan health indicates whether all scanners completed execution. It applies to CI scans, pull request scans, and branch periodic scans. 

 Scan health 

 Meaning for a CI scan 

 Enforcement consequence 

 Next action 

 Completed 

 Every enabled scanner completed execution. 

 The CI status reflects a complete evaluation. 

 Act on the CI status. 

 Partially Completed 

 One or more scanners failed or were skipped. Others succeeded. 

 The build outcome used partial evidence. A Passed result does not establish a clean artifact. 

 Re-run the pipeline after correcting the cause. For a shipped artifact, evaluate the branch against the latest branch periodic scan. Treat that result as the substitute assessment until the pipeline reports Completed . 

 Error 

 The scan failed to complete. 

 No evaluation occurred. The pipeline outcome depends on the CLI exit code and pipeline configuration. 

 Diagnose the pipeline log. Exit code 2 indicates an internal, network, or authentication error. 

 In Progress 

 The scan is executing. 

 The result is not final. 

 Wait for completion. CI scans have no rescan action. 

 Unlike a branch periodic scan, a CI scan has no Rescan action. Re-evaluate by running the pipeline again.
