 Cortex XDR Agent 8.3.2 Addressed Issues 

 The following issues were resolved in this release. 

 Issue 

 Description 

 CPATR-25063 

 (Windows) 

 Fixed an issue where false-positive alerts may be encountered due to policy reset during an agent upgrade. 

 CPATR‑24594 

 (Windows) 

 Fixed an issue that in rare cases, may impact upgrading from older Cortex XDR agents. 

 CPATR-24120 

 (Linux) 

 Increased the log level of a message that is issued when event collection fails to start.
