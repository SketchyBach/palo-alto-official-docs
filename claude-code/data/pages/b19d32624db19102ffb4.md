 CNGFW: Approaching Max Capacity - Service Objects 

 Incident Code 

 INC_CNGFW_SERVICE_OBJECTS_MAX_CAPACITY 

 Severity 

 Warning 

 Category 

 Device 

 Subcategory 

 System Resources 

 Description 

 Approaching Max Capacity - Service Objects 

 Raise Condition 

 When Service Objects usage exceed 90% of the capacity of that respective Cloud NGFW Resource and stays beyond 90% for five days over a week 

 Clear Condition 

 When Service Objects usage falls below 90% of the capacity of that respective Cloud NGFW Resource and stays below 90% for two weeks
