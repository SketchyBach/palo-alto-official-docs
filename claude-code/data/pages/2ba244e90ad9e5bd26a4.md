 Use Prisma SD-WAN Data Center Endpoints 

 Let us learn how to configure data center sites as endpoints. 

 Where Can I Use
 This? What Do I
 Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 All Prisma SD-WAN data center sites can be
configured as endpoints. You cannot delete the endpoints after you
configure them. However, you can uncheck Admin Up option,
which will remove the endpoints from consideration when the system
performs path selection as per the network policy rules. 

 Select Configuration Prisma SD-WAN Resources Service & DC Groups Add Group . 

 Click Add Group and select Prisma
 SD-WAN . 

 Enter a name for the group. 

 Map the data center endpoint to the appropriate group
under each domain. 

 Save the mappings. 

 The endpoints are added to groups and these groups can
be used in policy paths.
