 Review the OS compatibility details for the Terminal
Server (TS) agent 9.1 release.

9.1 and earlier PAN-OS releases that Palo Alto Networks still supports.
To see where you can install TS agents ,
refer to the Terminal Server (TS) agent compatibility information
in the Palo Alto Networks Compatibility
Matrix .
