 Restrict Administrator Access to Commit and Validate Functions 

 Configure administrator role permissions to restrict access to commit and validate
 operations on PAN-OS firewalls for enhanced security control. 

 To restrict access to commit (and revert), save, and
validate functions when creating or editing an Admin Role profile
( Device Admin Roles ),
scroll down to the Commit , Save ,
and Validate options on the WebUI tab.
