 Changes to Default Behavior 

 Familiarize yourself with the changes to default behavior
introduced in the Windows User-ID™ agent 9.1 release. 

 The Windows User-ID Agent 9.1 release has the following
change in default behavior: 

 User-ID 9.1.2 and later releases for Windows no longer create
mappings for machine events by default.
