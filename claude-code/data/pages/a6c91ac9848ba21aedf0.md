 Inline Categorization 

 Select Objects Security Profiles URL Filtering Inline Categorization to enable
and configure real-time web page analysis. 

 Field 

 Description 

 Use the Inline Categorization tab
to enable real-time web page analysis and manage URL exceptions. 

 Real-time URL analysis is available
locally as a firewall-based detection mechanism and in the cloud
as a part of the Advanced URL Filtering service. 

 Enable
local inline categorization —Enables real-time analysis
of URL traffic using firewall-based, machine learning models, to
detect and prevent malicious phishing variants and JavaScript exploits
from entering your network. 

 Enable cloud inline categorization —Enables
real-time analysis of URLs by forwarding suspicious web page contents
to the cloud for supplemental analysis, using machine learning based
detectors that complement the analysis engines used by local inline
ML. 

 Exceptions 

 You can define URL Exceptions for specific
web sites that you do not want analyzed using inline categorization. 

 To
add URL exceptions, you must first define a valid EDL (external dynamic
list) or custom URL category. Click Add to
view and select from the available options.
