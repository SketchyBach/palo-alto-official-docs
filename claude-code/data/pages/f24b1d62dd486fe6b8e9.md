 Application Details 

 In the Applications of the Applications dashboard,
click an application name in the Total Applications table
to open the Application Details page 

 In this dashboard, you can see how many users and remote sites
are monitored for the application and view the performance trend
to see when the experience started to decline. 

 For impacted users and sites, you can also see which segment
of the network is causing the issue, whether it is the users’ local
WiFi network, ISP, or WAN, or the application itself in the case
of Mobile Users. In the case of Remote Sites, you see which segment
starting from the remote site or ISP or WAN is impacted or if last
mile (the application itself) has issues. You can also see if the
issues are isolated to a specific Prisma Access location and use
this information to remediate the issue.
