 Install the ZTP Plugin 

 Install the ZTP plugin on your Panorama™ management server. 

 Where Can I Use This? What Do I Need? 

 NGFW (Managed by Panorama) 

 Device Management License 

 Panorama superuser role 

 Install the ZTP plugin on your Panorama™ management server to register Panorama with the
 ZTP service in order to claim ZTP firewalls for simplified on-boarding. 

 If your Panorama is in a high availability (HA) configuration, install the ZTP plugin and
 register both Panorama HA peers with the ZTP service. 

 Install the ZTP Plugin on Panorama 

 Install the ZTP plugin on your Panorama™ management server to register Panorama
 with the ZTP service in order to claim ZTP firewalls for simplified on-boarding. 

 If your Panorama is in a high availability (HA) configuration, install the ZTP
 plugin and register both Panorama HA peers with the ZTP service. 

 Install the Panorama Device
 Certificate . 

 Log in to the Panorama web
 interface as a s superuser or Panorama administrator
 with access to Panorama plugins ( Panorama Plugins ). 

 Select Panorama Plugins and search for the ztp plugin. 

 Download and Install the most
 recent version of the ZTP plugin 

 Beginning with PAN-OS 12.1.2, you no longer have to manually find and
 download compatible plugin versions before installing them. Now,
 compatible plugins are automatically downloaded with the Panorama image,
 and you can directly install the ones you need. For more information on
 plugin bundling, see Panorama Plugins .
