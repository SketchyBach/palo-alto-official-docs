 New Features Introduced in September 2024 

 Learn more about the new features introduced for the Cloud Identity Engine in
 September 2024, including password rotation for the Cloud Identity agent. 

 The following table provides a snapshot of new features introduced for the Cloud Identity
 Engine app in September 2024. Refer to the Cloud Identity Engine documentation for more
 information on how to use the Cloud Identity Engine. 

 Feature Description 

 Bind password CLI command support for Cloud Identity
 agent To strengthen the security of your Cloud Identity agent,
 you can now optionally configure the agent host by updating the bind
 password at regular intervals (also known as password rotation) using a
 CLI command. Now, when you update the password on the LDAP server, you
 can enter a CLI command on the agent host specifying the new password,
 instead of having to manually update the configuration and restart the
 agent. This new capability allows you to strengthen your security
 posture while simplifying the process. 

 Azure Enterprise App Onboarding URL Configuring and deploying an Azure AD in the Cloud
 Identity Engine using the enterprise app method (previously known as the
 gallery app) is now easier than ever. To simplify deployment for Azure
 Active Directory (AD) in the Cloud Identity Engine, you can now generate
 a URL that allows you to authenticate and simply continue to the next
 step in the deployment process. This new deployment option eliminates
 the need to copy and paste multiple types of information. Now you only
 need to enter your directory ID, open the URL in a new tab or window,
 and log in. Once that is complete, you can close the window and finish
 the configuration process for your Azure directory.
