 View Total Number of Notifications Sent to Each User 

 View the total number of notifications sent
to each user in the Monitored Mobile Users table
in the User Experience tab on Monitored
Mobile Users page. To do so, 

 Open the Monitored Mobile Users page. 

 Click the User Experience tab
if not already open. 

 Scroll down to the Monitored Mobile Users table
widget. The Total Notifications column in
the table displays the total number of notifications which the user
has received in the selected Time Range .
Hovering over the number in this column will give you a breakdown
of the types of notification that the user or group has received
in the selected Time Range . If the Total
Notifications column does not display in the table,
it is an indication that the Self-Serve feature is not enabled .
