 Integrate Device Security with Jira Cloud 

 Integrate Jira Cloud with Device Security to streamline alert and incident 
 management across your organization.

 Integrate Jira Cloud with Device Security to streamline alert and 
 incident management across your organization. Through the integration, you can create 
 Jira tickets for security alerts and vulnerabilities detected in 
 Device Security . After investigating and resolving with Jira , you 
 can sync Jira ticket statuses with Device Security to resolve 
 incidents. This addresses the gap between Device Security monitoring and project 
 management workflows, enabling you to track, assign, and resolve security incidents 
 through your existing Jira Cloud infrastructure and have the status 
 reflected in Device Security .

 Device Security supports integrating only with Jira Cloud . 
 Device Security doesn't support integrating with Jira Data 
 Center.

 For security alerts or vulnerabilities that Device Security discovers in your 
 network, you can configure which Jira projects to send these incidents 
 to, and what type of ticket you want created within the projects. When configuring the 
 integration, define which alerts and vulnerabilities result in Jira 
 tickets, based on criteria such as alert and vulnerability severities. You can choose 
 whether to create Jira tickets for all incidents that match the defined 
 criteria, or to manually create Jira tickets from Device Security 
 for individual incidents.

 The integration supports a synchronized resolution workflow and centralized incident 
 tracking between security, operations, and development teams. When a security analyst 
 discovers an incident in Device Security , they can convert it into a 
 Jira ticket for project management tracking. After the development or 
 security team resolves the ticket in Jira , the integration updates the 
 status of the corresponding alert or vulnerability in Device Security . This 
 synchronization reduces the manual effort needed to keep security dashboards current 
 and helps maintain an accurate view of your network risks.

 Integrating with Jira Cloud requires either a 
 full-featured Cortex XSOAR™ server 
 or the 
 activation 
 of a Device Security free 
 cohosted Cortex XSOAR instance .
