 Extortion 

 ATT&CK Tactic 

 Collection (TA0009) 

 ATT&CK Technique 

 Email Collection: Remote Email Collection (T1114.002) 

 Severity 

 Informational 

 Description 

 A single caller IP read mail items from a single mailbox an unusually high number of times within a short time window. 

 Attacker's Goals 

 An adversary may rapidly access multiple mail items within a short period of time, which can aid in the bulk exfiltration of sensitive email content from a compromised mailbox. 

 Investigative actions 

 Review the sessions originated from the caller IP address. 

 Inspect the user for fresh OAuth grants, new inbox rules, MFA enrolment changes and anomalous logins. 

 Check the IP reputation and revoke active sessions for the user.
