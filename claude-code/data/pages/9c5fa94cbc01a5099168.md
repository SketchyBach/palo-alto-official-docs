 Activate Email DLP 

 Activate the Email DLP license for Enterprise Data Loss Prevention (E-DLP) . 

 On May 7, 2025 , Palo Alto Networks is introducing new Evidence Storage and Syslog Forwarding service IP
 addresses to improve performance and expand availability for these services
 globally. 

 You must allow these new service IP addresses on your network
 to avoid disruptions for these services. Review the Enterprise DLP 
 Release Notes for more
 information. 

 Where Can I Use This? What Do I Need? 

 Data Security 

 One of the following licenses that include the Enterprise DLP license 

 Review the Supported
 Platforms for details on the required license
 for each enforcement point. 

 Prisma Access CASB license 

 Next-Generation
CASB for Prisma Access and NGFW (CASB-X) license 

 Data Security license 

 Email DLP license 

 Learn how to activate Email DLP to prevent sensitive data exfiltration contained in
 outbound emails using AI/ML powered data detections with Enterprise Data Loss Prevention (E-DLP) . 

 Activate Email DLP If Enterprise DLP Is Already Active 

 Contact your Palo Alto Networks sales representative to purchase Email DLP if you
 already have an Enterprise DLP license already active alongside an active Data Security , CASB-PA, or CASB-X license. The Data Security , CASB-PA, or CASB-X licenses include the
 Email DLP license. You don't need to activate Email DLP when activating a Data Security , CASB-PA, or CASB-X license. 

 Learn more how Email DLP works and continue to
 onboard Microsoft Exchange or Gmail to Enterprise DLP . 

 Activate Email DLP for New Strata Cloud Manager Deployments 

 You activate Email DLP for Enterprise DLP during the tenant activation. 

 Data Security —After you purchase Email DLP, activation occurs
 by default when you activate your Data Security license . 

 Verify that the Data Security license activation includes
 Email DLP in the list of
 Add-Ons . 

 CASB and CASB-X —After you purchase Email DLP,
 activation occurs by default when you activate your CASB-X license through Common
 Services . 

 Verify that the CASB and CASB-X license activation
 include Email DLP in the list of
 Add-Ons . 

 Convert Eval Email DLP to Production Email DLP 

 Contact your Palo Alto Networks sales representative to convert your evaluation
 Email DLP add-on to a production Email DLP add-on. Palo Alto Networks automatically
 converts the Email DLP license from an evaluation license to a production license
 does not require you to take any further actions to convert. 

 Learn more how Email DLP works and continue to
 onboard Microsoft Exchange or Gmail to Enterprise DLP .
