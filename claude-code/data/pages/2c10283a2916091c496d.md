 Broker VM 27.0.47 (Major) 

 The Broker VM major 27.0.47 release was released as part of the release of Cortex XDR 3.14. The release is divided into three deployments: April 27, 2025, May 11, 2025, and May 18, 2025. For more information on the changes integrated on this major release, see the Broker VM Version feature in the Cortex XDR 3.14 Release Notes .
