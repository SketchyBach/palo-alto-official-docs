 Licensing PKI 

 PKI is private PKI-as-a-Service to replace your legacy internal PKI, offered as a feature of Next-Gen Trust Security. 

 Through a single implementation, you offload management of your organization's privately trusted X.509 certificates to a continuously available cloud-based service with on-demand scaling and geographic redundancy. 

 Features and benefits 

 Root and issuing CA hierarchies designed to fit your organization's use case. 

 Flexible policies and templates for issuing certificates at scale. 

 Support for Microsoft Active Directory auto-enrollment, all major MDMs including Microsoft Intune and Jamf Pro, and common protocols such as SCEP, EST, ACME, and REST. 

 Support for a broad range of cryptographic algorithms and standards, including post-quantum cryptography. 

 Guidance and support for migrating your current PKI to Zero Touch PKI. 

 Licensing PKI in Next-Gen Trust Security 

 To get started with PKI, sign in to Next-Gen Trust Security and go to System Settings > Certificate Settings > Licensing . Then, click PKI and select the connectors you want to use in your environment to request certificates and deploy them to devices and users. 

 Submit the form to open a request with Palo Alto Networks. We then follow up to scope and provision your PKI. 

 Not using Next-Gen Trust Security? 

 If you're not using Next-Gen Trust Security, please continue to use the legacy Zero Touch PKI user interface. For more information, see the Zero Touch PKI documentation on the Machine Identity Security Docs website.
