 Get Started with the CLI 

 Every Palo Alto Networks device includes a command-line
interface (CLI) that allows you to monitor and configure the device.
Although this guide does not provide detailed command reference
information, it does provide the information you need to learn how
to use the CLI. It includes information to help you find the command
you need and how to get syntactical help after you find it. It also
explains how to verify the SSH connection to the firewall when you
access the CLI remotely, and how to refresh the SSH keys and configure
key options when connecting to the management interface.
