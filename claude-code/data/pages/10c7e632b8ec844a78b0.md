# Configure User Directory

Skip To Main Content
Our Products
Configure User Directory

This topic describes how to configure User Directory in Idira IGA using Standard configuration or Advanced Multi-Directory configuration.

Advanced Multi-Directory is an early access feature. Early access features are made available on a case-by-case basis by request. Early access features might see more frequent updates compared to GA features. Contact Technical Support to enable this feature.

Before you begin

Ensure that you complete the following requirements before you configure your user directory:

Ensure that you have administrator permissions in Idira IGA.

If you use Advanced Multi-Directory, ensure that:

You have contacted Support and have access to the feature.

The feature is enabled in your organization's settings.

Standard configuration

Use Standard configuration when your tenant follows the traditional directory designation flow. Standard configuration works best when your organization uses a single authoritative directory source, or uses multiple sources with clearly separated user populations.

Add a directory application

Sign in to Idira IGA with administrator permissions.

Go to Settings > User Directory > Add Application.

Select the application you want to use as a directory.

Click Designate.

Repeat these steps to add more directory applications if necessary.

Limitations

The following limitations apply when you use the standard user directory configuration:

Microsoft Entra ID (Azure Active Directory), Google Workspace, Okta, and OneLogin can appear in the list before they are synced.

The system only displays other applications when they are eligible and not already synced as a directory source.

Add multiple directories only when the user populations are mutually exclusive.

If account data overlaps between directories, the most recently synced directory can overwrite user data.

Advanced Multi-Directory (Early Access)

Use Advanced Multi-Directory when your organization has multiple source systems where ownership is split. For example, your Human Resources department manages job attributes and an identity provider manages sign-in attributes. Additionally, use this configuration for teams that need clear, predictable ownership of user fields across applications.

Configure applications in User Directory

Sign in to Idira IGA with administrator permissions.

Go to Settings > User Directory.

Click Add Application and add each directory application you want to include.

For each application, click Edit Fields and select the fields that you want the application to own.

Complete field assignments

Field assignments must be complete before directory sync can create or update users.

Each field can be assigned to only one application at a time.

Continue until all of your required fields are assigned.

If you save with incomplete assignments, the configuration is saved, but directory sync user updates remain paused until all fields are assigned.

Reassignment and updates

You can reassign fields later from the same Edit Fields flow. Field ownership changes apply to future sync behavior.

Frequently asked questions
What happens if a field is not assigned in Advanced Multi-Directory?

Directory sync does not create or update users until all required field assignments are complete.

Can one field belong to multiple applications?

No. You can only assign a field to one application at a time.

Can I switch assignments later?

Yes. Administrators can go to Setup > User Directory > Add Application > Edit Fields to update assignments.

How is metadata managed across multiple directory applications?

Metadata is managed as a single assignable field and follows these ownership rules:

In Advanced Multi-Directory, the metadata block can only be assigned to one application at a time.

During sync, Idira IGA pulls metadata from the application that owns the metadata.

If the metadata is unassigned, user updates remain paused until assignments are complete.

If you reassign the metadata ownership, future syncs use the new owning application.

Does removing an application from User Directory delete users?

No. If you remove an application the system stops future directory sync contributions from that application, but does not delete existing users.
