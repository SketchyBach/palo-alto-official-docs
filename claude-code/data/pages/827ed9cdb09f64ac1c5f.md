 View Total Number of CPU or Memory Notifications Sent to
a User 

 When Self-Serve is enabled on a user's device, administrators can view the notifications
 related to each category, such as CPU or memory, that the user receives. 

 Where Can I Use
 This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 Prisma Access license 

 ADEM or Strata Cloud Manager Pro 
 license 

 GlobalProtect or Prisma Access Agent license 

 You can view the total number of CPU notifications
or memory notifications that a specific user has received in a Time
Range that you select on the User Details page.
To do so, 

 Click Strata Cloud Manager Insights Activity Insights Users tab and change the Scope Selection to
 Prisma Access . 

 Click the number below Agent Users . 

 Scroll down to the Access Agent Users table. 

 Click the user’s name in the User Name column
to open the User Details page. 

 Click Experience and scroll down to the
 Device Health Metrics widget. 

 For a Time Range that is less than 2 days, the Memory
 and CPU charts display a dot on the trend line every time the user receives a
 notification. The number under Memory and
 CPU represents the total number of memory or CPU
 notifications that this user received in the specified Time
 Range . 
 Toggle the Show Notifications 
 button to either display or hide the notification metrics.
