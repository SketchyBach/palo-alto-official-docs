 Issue ID 

 Description 

 GPC-24173 

 Fixed an issue where GlobalProtect Linux clients (Redhat and Ubuntu) experienced an unresponsive
 or crashing embedded browser when authenticating to a GlobalProtect
 gateway using SAML, preventing successful connection despite
 successful authentication on the SAML provider side.
