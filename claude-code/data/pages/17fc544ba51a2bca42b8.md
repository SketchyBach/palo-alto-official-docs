 IOT Connection failed 

 Incident Code 

 INC_NGFW_IOT_CONNECTION_FAIL 

 Severity 

 Warning 

 Category 

 Security Services 

 Subcategory 

 IoT Security 

 Description 

 This alert detects a failure in the Palo Alto Networks Next-Generation Firewall
 (NGFW) to establish or maintain a connection with the designated IoT security
 cloud platform. 

 Raise Condition 

 When the firewall is unable to fetch Device ID information from IOT for recent 8
 hours 

 Clear Condition 

 When the firewall is able to fetch Device ID information from IOT for recent 8
 hours
