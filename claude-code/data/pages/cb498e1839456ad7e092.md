 Install the PA-3200 Series Firewall in an Equipment Rack 

 Learn about the different ways to install a PA-3200 Series
firewall in an equipment rack. 

 The PA-3200 Series next-generation firewall ships with
two rack-mount brackets for installation in a two-post or four-post
19” equipment rack. If you install the firewall in a four-post rack,
you can purchase and install the optional four-post rack kit to
secure the firewall to the back rack posts for additional support.
