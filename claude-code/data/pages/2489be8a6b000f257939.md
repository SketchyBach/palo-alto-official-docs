 Create a Jamf Policy for Prisma Access Agent Deployment 

 Learn how to create a Jamf policy for the deployment of Prisma Access Agents . 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 NGFW (Managed by Panorama) 

 Check the prerequisites for the deployment you're
 using 

 Prisma Access Agent version: 25.3.1.14 

 macOS 14 and later desktop devices 

 Contact your Palo Alto Networks account representative to
 activate the Prisma Access Agent feature 

 You can create a Jamf policy that will trigger the
 installation of the Prisma Access Agent to macOS devices that already have the
 Prisma Access Agent configuration profile installed.

 Before you begin, be sure to deploy a unified configuration profile from Palo
 Alto Networks or manually set up and deploy a
 configuration profile . 

 To deploy the Prisma Access Agent , complete the following steps: 

 ( Prerequisite ) Create a Smart Computer Group that identifies those
 users who have the Prisma Access Agent 
 configuration profile 
 installed on their devices. 

 As a best practice, use the Profile Identifier as the
 match criteria for the Smart Computer Group. You can obtain the identifier
 from a macOS device that already has the configuration profile installed,
 such as a test device. 

 Select Computers Search Inventory . 

 Search for the computer that has the Prisma Access Agent profile
 installed. 

 Select the computer name and select Inventory Profiles . 

 Find the Prisma Access Agent profile from the list of profiles,
 and copy the corresponding profile identifier. 

 Create the Smart Computer Group. 

 For the Criteria , select Profile
 Identifier , and paste the profile identifier that you
 copied. For example: 

 Save your settings. 

 Upload the Prisma Access Agent package to Jamf Pro for deployment
 to the managed macOS devices in your organization. 

 If you have not done so, download the Prisma Access Agent
 installation package (.pkg) and configuration file
 (config.json) from Configuration Endpoint Management in Strata Cloud Manager . 

 The Prisma Access Agent installation package
 includes Endpoint DLP , which will
 be installed automatically with Prisma Access Agent as a separate
 application. The Endpoint DLP agent requires a separate license and
 remains inactive until you activate the license. Once activated, the
 agent does not block content until you push policies to the
 endpoint. 

 ( Optional ) Update the Prisma Access Agent deployment configuration in the
 config.json file. 

 For example, you can update the deployment configuration to enable
 pre-logon 
 support or disable the GlobalProtect app (if installed on the
 endpoint) during the installation of the Prisma Access Agent . 

 Put the .pkg and config.json 
 files into a folder and give the folder a meaningful name (such as the
 name of the .pkg ). Zip up the folder. 

 In Jamf Pro, select Settings Computer Management Packages . 

 Click New . 

 Specify the General settings for the
 package. 

 Enter a Display Name for the
 package. 

 Click Choose File , select the package
 that you zipped up, and click Open . 

 Save your settings. 

 Create a policy for deploying the Prisma Access Agent by selecting Computers Policies New . 

 In the General payload, configure the basic settings for
 the policy: 

 Enter a Display Name for the policy and make
 sure that the policy is Enabled . 

 ( Optional ) Select a Category to add the
 policy to. 

 Specify Trigger events that will initiate the
 policy, such as Recurring Check-in . 

 Select the Execution Frequency , such as
 Once per computer . 

 Configure the Packages payload for your new
 policy. 

 Select Packages Configure . 

 Scroll down the list of packages and Add the Prisma Access Agent zip package that you uploaded. 

 Select a Distribution Point . 

 Select the Install action. 

 ( Optional ) Configure the Maintenance 
 payload. 

 Select Maintenance Configure . 

 Select Update Inventory . 

 Set the scope of the policy to the Smart Computer Group that you created in
 step 1 to target those users who have the
 Prisma Access Agent profile installed on their devices. 

 Save the policy. 
 When the macOS endpoints in the Smart Computer Group check in with Jamf Pro
 and meet the trigger in the policy, the policy will run and deploy the Prisma Access Agent to the endpoints along with Endpoint DLP. 

 The Endpoint DLP agent requires a separate license and remains inactive
 until you activate the license.
