 Release Highlights 

 Feature 

 Description 

 AgentiX AI Agent Workforce 

 Cortex Agentic Assistant: Go beyond rigid playbooks and command autonomous agents based on over 1.2 billion real-world playbook executions and governed by robust guardrails, to dynamically plan, reason and take action to solve any security challenge. 

 Cortex Agentic Assistant is included in Cortex Cloud. Availability of agentic capabilities may depend on specific licenses and is subject to supported regions. 

 Native MCP support: Now available in Beta, the Cortex MCP Server lets trusted LLM applications securely connect to Cortex Cloud and access data and insights in real time using natural language prompts. 

 New capabilities for backups and cloud data platforms 

 Comprehensive data and asset security with new DSPM capabilities for both backups and cloud data platforms. New Backup Security Posture Management (BSPM) automatically discovers and analyzes backups to identify sensitive data and security risks, while our new Databricks integration delivers enhanced visibility to protect data, configurations, and data flows. 

 Unified AI Security Posture Management (AI-SPM) 

 New unified AI Security Posture Management (AI-SPM) streamlines AI security from development to production. Cortex Cloud creates an AI Bill of Materials (AI BoM) to identify vulnerabilities in AI software and development dependencies, while also providing deep visibility into AI agents, datasets, and platforms like Azure AI Search. The central AI-SPM dashboard brings together all AI posture and threat detection for a single, comprehensive view. 

 Google Workspace support 

 Enhanced Identity Security by integrating with Google Workspace IdP, giving teams comprehensive visibility into their users, groups, and organizational units.
