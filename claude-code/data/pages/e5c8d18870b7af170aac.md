 Map ADFS Groups to Cortex XSOAR Roles 

 Map ADFS groups to roles in Cortex XSOAR 6.12. 

 Map AD user account group memberships to a Cortex XSOAR server role. 

 Go to Settings → Users and Roles → Roles . 

 Create or edit an existing role, as described in Define a Role . 

 In the SAML Roles Mapping field, specify one or more SAML groups to map to the Cortex XSOAR role. 

 Return to Set up ADFS as the Identity Provider Using SAML 2.0 .
