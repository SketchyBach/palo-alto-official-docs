 Shared Pool Memory Allocation failure 

 Incident Code 

 INC_NGFW_SHARED_POOL_MEMORY_ALLOCATION_FAILURE 

 Severity 

 High 

 Category 

 Device 

 Subcategory 

 System Resources 

 Description 

 Shared pool memory allocation failures can cause critical security and
 application delivery service disruptions. When shared memory pool reaches
 capacity, Layer 7 features cannot allocate required memory, resulting in session
 establishment failures, content inspection failures, SSL/TLS decryption errors,
 application visibility loss, and degraded threat prevention. Multiple Layer 7
 features (URL filtering, threat prevention, SSL decryption, application
 identification, content inspection, DLP, user identification) compete for this
 shared resource. 

 Raise Condition 

 Incident gets generated, If any of the shared mem pool allocation failure
 happens. 

 Clear Condition 

 All the shared mem pool allocation failure is resolved.
