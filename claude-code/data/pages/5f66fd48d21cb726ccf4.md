 To help you understand an event that has occurred, you can review descriptions of log
 events that are related to the management of Prisma Agents . 

 The event IDs and possible associated activities in the following table correspond
 respectively to the values in the Event ID Value 
 ( event_id.value ) in the log
 viewer . 

 The following event IDs are used in the EPM log subtype. 

 Event ID Value Description 

 Agent Hip Indicates an event to download the Prisma Agent host information profile (HIP). 

 Agent Log Indicates an event to download Prisma Agent logs. 

 Agent Logout Indicates an event to log out the Prisma Agent . 

 Agent Remote Shell Indicates a remote shell event on an endpoint that was initiated in
 the Endpoint Management
 page ( Configuration Endpoint Management ). 

 Epm Auth Response Indicates an event for sending an authentication
 response to the Prisma Agent . 

 Epm Cie Token Received Indicates an event for receiving a Cloud Identity
 Engine token for an end user. 

 Epm Cie Token Validation Indicates an event for validating a Cloud Identity
 Engine token for an end user. 

 Epm Gateway Config Request Indicates an event for a Prisma Access location
 configuration request. 

 Epm Gateway Config Response Indicates an event for sending an authentication
 response to the Prisma Agent . 

 HIP
 Check Indicates an event for HIP checks. 

 HIP
 Upload Indicates an event to upload a new HIP to an
 endpoint.
