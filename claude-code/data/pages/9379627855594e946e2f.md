 Cortex XDR agent iOS 9.1 

 View Connection 

 View general and connection information for your Cortex XDR agent app for iOS. 

 View general information and the connection between the iOS device and Cortex XDR or Cortex XSIAM. 

 From the Cortex XDR home screen, select Settings → Managing Server . 

 The screen indicates the iOS device server connection, along with the Cortex XDR or Cortex XSIAM Server Address and Last Connection Time . It shows the last time a check in was performed successfully. 

 Test a forced heartbeat with the server by tapping Check In Now .
