 Secure Internet Traffic from AWS WorkSpace 

 Learn how to secure your users who are accessing the internet and organizational
 resources through AWS virtual machines. 

 Organizations need to rethink their approach to securing their remote
 workers, contractors, hospital staff, and call center users who access the
 internet through Amazon WorkSpace cloud-based virtual machines. These users need
 to be able to access the internet securely and remain protected from
 internet-based threats while the organization maintains complete visibility into
 the internet traffic generated through these cloud-hosted virtual
 machines. 

 Traditional networking models designed for remote
 workers and resources are no longer sufficient in today's complex and innovative
 economy, where the workforce, data, and cloud applications are becoming more
 distributed. Organizations need the flexibility and scalability of cloud
 services, but these services require cloud security solutions that are designed
 to meet their unique needs. 
 Learn more about Prisma SASE and AWS WorkSpace . 

 Using the Palo Alto Networks Strata Cloud Manager , you can provide secure access to the
 internet for AWS WorkSpace using the following methods: 

 Configure a PAC File on AWS WorkSpace Clients
