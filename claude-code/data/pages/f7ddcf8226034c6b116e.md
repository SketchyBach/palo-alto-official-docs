 Links to content pack/ integration details (onboarded prior to July 26, 2026) 

 The G Suite Admin content pack integrates with Cortex XDR to handle various administrative tasks for G Suite or Google Workspace Admin environments. It contains the following integration: 

 Google Workspace Admin : Use this integration to perform actions on IT infrastructure, create users, update settings, and manage other administrative duties. It includes commands for user management, device management (Chrome browser devices), policy management, and data transfer.
