 debug ipfix 

 Use the debug ipfix command
to configure filters to select flow statistics for debugging and
troubleshooting. 

 Command 

 debug ipfix ((create | view | delete) [id=|host1=|host2=|port1=|port2=|protocol=]) 

 Options 

 id Enter a number between 1 and 4 for the filter
ID. 

 host1 Enter the source IP address of the originator
or client for selecting the flow. 

 host2 Enter the destination IP address of the server
for selecting the flow. 

 port1 Enter the source UDP or TCP port of the originator or
client for selecting the flow. This applies only to UDP or TCP connections. 

 port2 Enter the destination UDP or TCP port of the server
for selecting the flow. This applies only to UDP or TCP connections. 

 protocol Enter the IP protocol used for selecting the
flow. 

 Command Notes 

 Role Super 

 Related Commands 

 debug logging facility=ipfix 

 Introduced in Release 5.5.1 

 Example 

 debug ipfix view all
