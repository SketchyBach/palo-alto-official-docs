 6.2.3-c287 Addressed Issues 

 The following table lists the issues that are addressed in GlobalProtect app
 6.2.3-c287. 

 Issue ID Description 

 GPC-20243 Fixed an issue where, when the GlobalProtect app was used with an
 embedded browser, the browser displayed ‘can't reach page’ due to a
 Windows filter driver issue. 

 GPC-20157 Fixed an issue where the gateway location was not correctly displayed
 in the Connections panel. 

 GPC-20143 Fixed an issue where the user was redirected to the Authentication
 page twice on the default browser for both portal and gateway
 authentication when SAML was configured. 

 GPC-19991 Fixed an issue where client certificate authentication between
 embedded browser and IdP (SAML) failed.
