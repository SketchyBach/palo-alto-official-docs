 Cloud AI Infrastructure Analytics 

 ATT&CK Tactic 

 Impact (TA0040) 

 ATT&CK Technique 

 Data Manipulation: Stored Data Manipulation (T1565.001) 

 Severity 

 Low 

 Description 

 A cloud identity modified an AI dataset. MITRE ATLAS Techniques: AML.T0059 - Erode Dataset Integrity, AML.T0018.000 - Backdoor ML Model: Poison ML Model. OWASP Top 10 LLM Technique: LLM04 - Data and Model Poisoning. 

 Attacker's Goals 

 Poison datasets used by ML models. 

 Investigative actions 

 Examine changed datasets and determine which ML models were affected. 

 Investigate any unusual activity originating from the suspected identity.
