 Features Introduced in On-Premises Controller 

 Learn the new features introduced in the various releases of On-Premises
 Controller. 

 On-Premises Controller for Prisma SD-WAN Release 1.3 

 Support for VMWare ESXi Hypervisor. 

 Support for up to 5,000+ ION appliances. 

 Updated Deployment Profiles and API Templates. 

 Faster installations with updated QCOW/VMDK image options. 

 Support for AMD CPU (x86-64) Bulldozer or later and Intel® Xeon® Sandy Bridge or
 later. 

 Support for vION devices. 

 Automated ION on-boarding (from ION image 6.2.3 onwards). 

 Support for SAML and IDP for Operations Console. 

 Support for Controller Upgrade. 

 Backup Dashboard. 

 On-Premises Controller for Prisma SD-WAN Release 1.2 

 Complete functionality of Prisma SD-WAN controller. 

 VM machine on KVM Hypervisor. 

 Operator dashboard for simplified GUI-based installation. 

 Automated support files. 

 Support for a maximum of 1000 ION devices. 

 Support for all ION device models. 

 Support for multinode HA deployment. 

 Support for ZTP bootstrap service to enable enhanced (DNS/DHCP) ION
 onboarding. 

 The bootstrap service requires ION
 6.2.3 software version. The device onboarding process for pre-6.2.3 ION
 version remains the same.
