 Learn about the INC_RN_SITE_LONG_DURATION_CAPACITY_EXCEEDED_THRESHOLD incident. 

 Incident Code 

 INC_RN_SITE_LONG_DURATION_CAPACITY_EXCEEDED_THRESHOLD 

 Title Template 

 Site capacity exceeded {threshold_value}% usage for {initial_days_for_raise} days in the last {alert_evaluation_lookback_window_days} days for Site {site_name} {initial_direction} traffic 

 Category 

 Network and Traffic 

 Subcategory 

 Site/Tunnel 

 Description 

 A Service Connection site within the network has been operating above its designated capacity threshold for a considerable amount of time. Prolonged overutilization of the site's capacity can lead to performance degradation and potential service disruptions for users relying on this service connection. 

 Raise Condition 

 An incident will be raised if the capacity utilization exceeds {{capacity_utilization_threshold}}% for at least {{min_threshold_breach_hours_per_day}} hours per day, consistently for {{min_breach_days_to_raise}} days, within a {{alert_evaluation_lookback_window_days}}-day evaluation window. 

 Clear Condition 

 An incident will be cleared when capacity utilization remains below {{capacity_utilization_threshold}}% for at least {{min_clear_hours_per_day}} hours per day for {{min_days_to_clear}} days within a {{alert_evaluation_lookback_window_days}}-day evaluation window.
