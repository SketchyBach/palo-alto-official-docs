 Detection Modules 

 Cloud 

 ATT&CK Tactic 

 Lateral Movement (TA0008) 

 ATT&CK Technique 

 Remote Services: Direct Cloud VM Connections (T1021.008), Remote Services: Cloud Services (T1021.007) 

 Severity 

 Informational 

 Description 

 An identity connected to a compute instance using serial console access. This may indicate an attacker attempting to move laterally between cloud instances. 

 Attacker's Goals 

 Utilize direct access to virtual infrastructure to pivot through a cloud environment. 

 Investigative actions 

 Verify whether the identity should be making this action. 

 Investigate which actions were performed via serial console access. 

 Variations
