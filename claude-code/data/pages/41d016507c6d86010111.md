 ION 2000 Specification Description 

 I/O 

 Controller 1 x 10/100/1000 RJ-45 

 Console 1 x RJ-45 

 WAN/LAN/Internet 5 x 10/100/1000 RJ-45. Port pair 4/5 have programmable inline fail-to-wire
 (bypass-pair) capability. 

 Power and Mechanical 

 Type/Watts 60W Power Adapter 

 Power Input AC 100~240 V @50~60 Hz 

 Fan cooling Fanless 

 Certifications 

 Certifications IEC 60950-1, cULus, FCC & CE Class B, BIS, CCC, KCC 

 Environmental 

 Operating temperature 32°F to 104°F (0°C to 40°C) 

 Storage temperature -4°F to 158°F (-20°C to 70°C) 

 Operating humidity 5% to 90% (non-condensing) 

 Storage humidity 5% to 95% (non-condensing) 

 Physical 

 Weight 2.64 lbs 

 Dimensions 5.73" x 6.97" x 1.73" 

 Local network access Typically a downstream Layer 2 or Layer 3 Ethernet
switch and/or a Wireless Access Point (WAP). 

 Internet connectivity This connectivity is used to reach the Prisma
SD-WAN controller. It can be in the form of a private connection
by an MPLS network through a corporate data center. It can also
be a public internet connection provided by a local or broadband
connection.
