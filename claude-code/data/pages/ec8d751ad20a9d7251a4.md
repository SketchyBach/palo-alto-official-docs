 clear flow-arp 

 Use the clear flow-arp command
to clear cached address resolution protocol (ARP) entries from the
data plane. 

 Command 

 clear flow-arp 

 Options 

 all Enter all to clear all cached ARP entries from
the data plane. 

 host Enter the host IP address to clear ARP entries
for the specified host from the data plane.
