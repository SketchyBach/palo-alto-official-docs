 War Room Commands 

 createWarRoomEntry 

 createWarRoomEntry 

 Creates a war room entry for the specified issues and/or cases. At least one of 'issue_id' or 'case_id' must be provided. 

 Arguments 
 Arguments 

 Argument Name 

 Description 

 Required 

 issue_ids 

 A comma-separated list of issue IDs for which to create the war room entry. 

 Optional 

 case_ids 

 A comma-separated list of case IDs for which to create the war room entry. 

 Optional 

 content 

 The content for the war room entry. 

 Required 

 Outputs 
 Outputs 

 Core.CortexCreateWarRoomEntry.result string 

 The entry IDs created successfully. 

 Core.CortexCreateWarRoomEntry.errors string 

 A list of errors that occurred during the operation.
