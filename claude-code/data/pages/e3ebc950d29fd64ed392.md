 CORS allows resource to access app services misconfiguration detected in code 

 Rule Details 

 Cortex AppSec Rule ID 

 APPSEC_AZURE_57 

 Category - Subcategory 

 Public Exposure - APIs 

 Provider 

 AZURE 

 Severity 

 LOW 

 Framework 

 ARM, Bicep, Terraform, Terraform Plan 

 Impact 

 Cross-Origin Resource Sharing (CORS) should not allow all domains to access your web application. Allow only required domains to interact with your web app. 

 How to Fix 

 Resource: azurerm_app_service 

 Arguments: cors [source,go] 

 resource "azurerm_app_service" "example" { ... site_config { 

 cors { 

 allowed_origins = ["192.0.0.1"] 

 } }
