 User-ID Agent 11.1 Release Information 

 The following information applies to all current 11.1 User-ID agent releases. 

 Changes to Default Behavior 

 The User-ID Agent 11.1 release has no changes to default behavior. 

 Known Issues 

 There are no known issues associated with the User-ID agent 11.1 release. 

 For recent updates to known issues for a given PAN-OS release, refer to
 https://live.paloaltonetworks.com/t5/Integration-Articles/Critical-Issues-Addressed-in-PAN-OS-Releases/ta-p/52882 . 

 User-ID Agent 11.1.1 Release Information 

 The following information is specific to the User-ID Agent 11.1.1 release. 

 Features Introduced in User-ID Agent 11.1.1 

 The User-ID Agent 11.1.1 release includes the following new features. 

 New Feature 

 Description 

 Windows Server 2025 

 You can now install the User-ID agent on the Windows Server
 2025 operating system. 

 API Security Upgrades and Support for
 Kerberos Authentication 

 Version 11.1.1 of the User-ID agent upgrades the Microsoft
 legacy API with a new and more secure API for reading
 security event logs. The new API also supports Kerberos
 authentication in addition to NTLM. For more information,
 refer to the following documentation .

 User-ID Agent 11.1.1 Addressed Issues 

 The following table lists any issues that are fixed in User-ID agent 11.1.1
 release. 

 Issue Description 

 WINAGENT-1114 Fixed an issue where the User-ID agent did not
 successfully connect to the directory due to differences in the
 security and update patch versions between the agent and the AD.

 WINAGENT-1138 Fixed an issue where the User-ID agent was not
 able to successfully obtain mapping information due to
 differences in the security and update patch versions between
 the agent and the AD. 

 WINAGENT-761 Fixed an issue where the User-ID agent was not
 able to successfully connect to the domain controller due to
 differences in the API versions between the agent and the AD.
