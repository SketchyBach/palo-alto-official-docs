 CPATR-15777 

 (MacOS) 

 *This issue is fixed with 7.7 

 Due to a known issue with Apple drivers, when packet filtering is enabled on the network extension, it may cause network issues. 

 To avoid this, the network extension should be disabled. This will not allow isolation of the endpoint, or run the latest version of Host Firewall.
