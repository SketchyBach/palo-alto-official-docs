 AWS EBS Volume is not encrypted by Key Management Service (KMS) using a Customer Managed Key (CMK) m 

 Rule Details 

 Cortex AppSec Rule ID 

 APPSEC_AWS_212 

 Category - Subcategory 

 Storage - Encryption 

 Provider 

 AWS 

 Severity 

 LOW 

 Framework 

 Terraform 

 Impact 

 This rule identifies Elastic File Systems (EFSs) which are encrypted with default KMS keys and not with Keys managed by Customer. It is a best practice to use customer managed KMS Keys to encrypt your EFS data. It gives you full control over the encrypted data. 

 How to Fix 

 Resources: aws_ebs_volume 

 Arguments: kms_key_id [source,go]
