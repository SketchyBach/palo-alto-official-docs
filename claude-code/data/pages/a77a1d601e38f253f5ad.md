 ION 7000 Front Panel with LEDs 

 Understand the various LEDs on the Prisma SD-WAN ION 
7000 and what it indicates. 

 The ION 7000 LEDs indicate the following
status: 

 Icons Description 

 Displays power status. 

 Blue light—Powered on. 

 No
light—Powered off. 

 Displays controller connectivity status. 

 Blue light—Connected. 

 No
light—Not Connected.
