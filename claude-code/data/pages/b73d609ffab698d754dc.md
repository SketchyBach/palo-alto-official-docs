 Installation Kit Components 

 Check the installation kit components of the ION 9200
device. 

 The ION 9200 device installation kit
contains the following parts and tools to install the device: 

 1x ION 9200 device ships with 2x 450W built in PSU. 

 2x power cord, AC, which varies depending on the country or region. 

 1x Shielded RJ-45 CAT6 Ethernet cable. 

 1x Rack mount kit. 

 2x Adjustable 1RU mounting
brackets (left and right) 

 Rear support brackets 

 13x #6-32 x 5/16” rack-mount screws 

 9x #10-32 x 3/4” rack-mount screws 

 9x #12-24 x 1/2” rack-mount screws 

 8x #10-32 nut cages 

 Sheet, Limited Warranty.
