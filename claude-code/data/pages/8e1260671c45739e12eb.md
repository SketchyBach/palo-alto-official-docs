 Incident Fields 

 APIs for managing incident fields 

 Set tags field 

 post https://hostname /incidentfield/tags/reset/ {id} 

 Sets the select values of a specific tags field. The values passed to the route override the existing select values of the field. To reset the select values pass an empty array. 

 Authorizations 

 api_key 

 Authorization string Required 

 Path parameters 

 id string Required 

 The machine name of the field prefixed with the type. For example indicator_tags or incident_dbotmirrortags 

 Body 

 application/json 

 data string[] Optional 

 Responses 

 200 

 empty 

 No content
