 Get Your Advanced WildFire Public Cloud API Key From the Palo Alto Networks Support
 Portal 

 Follow these steps to retrieve the API key
used to access the WildFire public API using the Palo Alto Networks
Support Portal: 

 Palo Alto Networks recommends token-based API authentication for all
 new and existing WildFire API workflows. Token-based authentication provides
 stronger security through tenant isolation (TSG-ID), service account binding, and
 centralized credential management in Strata Cloud Manager. API key authentication
 and the legacy WildFire portal are being deprecated—you must use Strata Cloud
 Manager to create and manage all WildFire API credentials going forward. Migrate
 your existing API key workflows to token-based authentication to avoid service
 disruption when API key support ends. 

 If you are a WildFire Standalone API user, this
 transition does not apply to you, and you may continue using the CSP to manage
 your API keys. 

 Log in to the Palo Alto Networks Support Portal . 

 Navigate to the WildFire WildFire API Keys page. 

 Select the WildFire public API key that you wish to use. 

 Your account may have more than one WildFire public API key. Choose one
 that is valid and has an Expiration Date that is
 in the future. 

 When you are finished retrieving your WildFire public
API key(s), logout from your Palo Alto Networks Support account.
