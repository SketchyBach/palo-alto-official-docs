 Transition a Standby Server to Active Mode 

 Transition a standby server to active mode in Cortex XSOAR 6.13. 

 If the server is active, when you connect to it, Cortex XSOAR appears as normal. After logging in, if the server is in standby mode, you will reach the This is currently the Backup Server page. 

 On the standby server being transitioned to active mode, from the This is currently the Backup Server page, click Make this the production server . 

 In the Switch Hosts dialog box, in the text box, type Switch Hosts . 

 Cortex XSOAR appears and the host is now active. 

 Note 

 If accounts are showing as offline, follow these steps: 

 Log in to each host server that has been switched to Primary. 

 Go to Settings → About +Troubleshooting → Server Configuration . 

 Edit the Main account server setting to point to the hostname of the now active Cortex XSOAR main host. 

 After these steps, the hosts should display as active on the Account Management page, and connect correctly to the main host. 

 In the backup server environment, go to Settings → About → Troubleshooting . 

 For the External Host Name key, update the value to the host name of the backup server (the new production server). 

 The backup server is unaware of its external host name. 

 After a successful switch, the backup server is now live.
