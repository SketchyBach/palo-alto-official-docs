 Customize the Email When Sending a Report 

 Customize scheduled report emails in Cortex XSOAR 6.13. Change the subject and body. 

 An email is sent to recipients when you schedule a report. You can change the email subject, body, and the body HTML. 

 Select Settings → ABOUT → Troubleshooting → Add Server Configuration . 

 Add the following server configurations: 

 Name 

 Descritption 

 reports.email.subject 

 Changes the subject of the email. Default: Cortex XSOAR Report - <name of the report> 

 reports.email.body 

 Changes the body of the email. Default: Check out the attached Report . 

 reports.email.body.html 

 Changes the body HTML of the email.
