 Detection Modules 

 Cloud 

 ATT&CK Tactic 

 Persistence (TA0003) 

 ATT&CK Technique 

 Create Account: Cloud Account (T1136.003), Create Account (T1136), Account Manipulation: Additional Cloud Credentials (T1098.001) 

 Severity 

 Low 

 Description 

 New cloud identity was created and assigned administrative policy. 

 Attacker's Goals 

 Escalate privileges in cloud environments. 

 Investigative actions 

 Confirm whether this activity was intentional. 

 Check for other API calls that were executed by the identity. 

 Look for any suspicious behavior from the IAM user/role to whom the administrative policy was attached.
