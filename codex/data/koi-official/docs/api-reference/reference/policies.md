## Add items to allowlist

> Adds multiple items to the allowlist. Items that are not yet discovered are accepted as pre-approvals as long as their item\_id is well-formed for the marketplace (a malformed item\_id returns 400); they take effect once the item is observed. A 204 therefore confirms the items were stored (they appear in GET /allowlist), not that they currently match a known extension.

