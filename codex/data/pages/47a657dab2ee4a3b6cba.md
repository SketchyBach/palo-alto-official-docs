 CVE Coverage Status Support for Threat Vault 

 August 01, 2025 

 Investigating vulnerability protection coverage for specific Common Vulnerabilities
 and Exposures (CVEs) often requires time-consuming support requests to determine
 release status. This lack of immediate visibility delays your ability to assess risk
 and confirm protection for emerging threats. 

 You can now query the Threat Vault to view the real-time
 coverage status of CVEs. This feature (which was previously only available as a
 Threat Vault API request ) provides detailed insights, including
 whether a vulnerability is currently under investigation, deemed not applicable by
 the threat research team, or pending release with a specific Threat ID availability
 timeline. For CVEs that have not yet been analyzed, the interface allows you to
 request coverage or analysis directly. 

 By providing immediate access to signature development status, this update eliminates
 the need to open administrative support tickets for coverage confirmation. This
 ensures you have the most current information required to secure your organization
 against new vulnerabilities.
