 INC_MU_IP_POOL_BLOCK_UTILIZATION_ EXCEEDED_THRESHOLD 

 Learn about the INC_MU_IP_POOL_BLOCK_UTILIZATION_EXCEEDED_THRESHOLD
 incident. 

 Synopsis 

 The mobile user IP address pool block is equal to or more than 85% for a theater. 

 Incident Code—INC_MU_IP_POOL_BLOCK_UTILIZATION_EXCEEDED_THRESHOLD 

 Severity—Warning 

 For details about incident severity, see Incidents Distribution Over
 Time in Incidents and Alerts Overview . 

 Required License 

 Prisma Access 

 Details 

 Description 

 Raise condition 

 IP pool block utilization is equal to or more than 85% for a
 theater. 

 Clear condition 

 IP pool block utilization is less than 85% for a theater.
