 Add a User-Defined App 

 Learn how to add a user-defined app for Secure Agentless Access . 

 Where Can I Use This? What Do I Need? 

 Secure Agentless Access (SAA) portal 

 A web browser that supports HTML5 

 SAA credentials 

 If you allow user-defined apps when you set up the , the users
 can manually add an app in the portal. 

 User-defined apps are not visible to other users. SAA 
 automatically applies the default profile for user-defined apps. User-defined apps
 are supported only for RDP, SSH, and VNC connections. 

 Users can manually define the
 following types of apps: 

 RDP 

 SSH 

 VNC

 Add a User-Defined RDP App 

 Learn how to add a user-defined RDP app for Secure Agentless Access . 

 To manually define an RDP app from the SAA portal: 

 Log in to the SAA portal. 

 Click Add App in the User-Defined Apps section. 

 Enter the general details for the app: 

 Select App Type RDP . 

 Enter the App Name . 

 ( Optional ) Select a Keyboard Layout to
 use for the remote RDP app. 

 ( Optional ) Enter an App
 Description . 

 Enter the Destination or FQDN or IP address of
 the app. 

 Enter the Port to use for the app, if different
 from the default port. 

 You can enter only one port between 1-65535. (Default: 3389) 

 ( Optional ) Configure additional settings for the RDP app. 

 ( Optional ) Enter the Domain associated
 with the RDP application. When you configure this field, the system
 applies the domain automatically during authentication, allowing users
 to log in using only their username. 

 Enter the Username and
 Password for the RDP app, and
 Confirm Password . The username and password
 are optional, but you must enter both settings or leave both
 blank. 

 To save the app settings, Create Custom App . 

 You can bookmark an administrator-created app or
 user-created app and launch them later by clicking on the link in the
 bookmark. 

 Add a User-Defined SSH App 

 Learn how to add a user-defined app for Secure Agentless Access . 

 To manually define an SSH app from the SAA portal: 

 Log in to the SAA portal. 

 Click Add App in the User-Defined Apps section. 

 Enter the general details for the app: 

 Select App Type SSH . 

 Enter the App Name . 

 ( Optional ) Enter an App
 Description . 

 Enter the Destination or FQDN or IP address of
 the app. 

 Enter the Port to use for the app, if different
 from the default port. 

 You can enter only one port between 1-65535. (Default: 22) 

 ( Optional ) Configure additional authentication settings for the SSH
 app. 

 Enter a valid Username and
 Password for the app, and confirm the
 password. If you enter a username and don't enter a password, you must
 provide a private key. 

 Enter the Private Key for the app. If the
 private key is encrypted, enter your passphrase. 

 Enter the Passphrase for the app. 

 Enter the Host Key entries for the remote host,
 which you can obtain by running the ssh-keyscan 
 command on the host. Enter one key per line. Lines that begin with
 # are treated as comments. 

 To save the app settings, Create Custom App . 

 You can bookmark an administrator-created app or
 user-created app and launch them later by clicking on the link in the
 bookmark.

 To manually define a VNC app from the SAA portal: 

 Log in to the SAA portal.

 You can enter only one port between 1-65535. (Default: 5900) 

 ( Optional ) Configure additional authentication settings for the VNC
 app. 

 ( Optional ) Enter the User Name and

 password. The username and password are optional, but you must enter
