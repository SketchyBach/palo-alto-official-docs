 Addressed Issues in Cortex XDR Agent 7.8.1 

 The following have been addressed in this release: 

 Issue 

 Description 

 CPATR-17949, CPATR-17950 

 Fixed an issue where exploit protection could cause silent application termination in isolated app containers or process shutdown. 

 CPATR-17806 

 (Windows) 

 Fixed an issue that caused an application to hang due to the agent exploit protection mechanism. 

 CPATR-17802 

 (Windows) 

 Fixed an issue on endpoints using Windows 8.1 and earlier, which resulted in Windows Explorer crashing. 

 CPATR-17779 

 ( macOS ) 

 Fixed an issue on macOS-based endpoints which failed to extract the signature of trusted executables and prevented them from running. 

 CPATR-17609 

 (Windows) 

 Fixed an issue where an operating system bug may lead to an agent process (cyserver) halt during a file version information extraction.
