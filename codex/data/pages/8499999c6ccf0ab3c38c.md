 Track your endpoint tags 

 From the Cortex XDR agent 

 Navigate to the Cytool folder location and open the CLI as an administrator. 

 Cytool Argument: cytool endpoint_tags list . 

 From the Cortex XSIAM management console 

 Navigate to Inventory → Endpoints → All Endpoints → Tags field . 

 All Server and Agent tags associated with the specific endpoint are displayed. Tags created in the XDR agent are displayed with a shield icon. 

 You can filter and search the Tags field to find endpoints that have endpoint tags assigned to them.
