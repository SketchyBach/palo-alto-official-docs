 Configure Notification Templates 

 Customize ADEM Self-Serve notification messages and brand profile to align with your
 organization's brand requirements. 

 Where Can I Use
 This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 Prisma Access license 

 ADEM or Strata Cloud Manager Pro 
 license 

 GlobalProtect or Prisma Access Agent license 

 A role that has
 permission to configure End User Coaching and ADEM
 Self-Serve. 

 ADEM provides a default self-serve notification template that can be fully customized
 to your needs. You can customize event messages to align with your organization’s
 voice and language requirements. You can also update the brand profile to define the
 visual appearance of the notifications to match your organization’s brand
 guidelines. 

 Click Strata Cloud Manager Insights Activity Insights Users . 

 Click Self Serve and select Edit Notification
 Messages . 

 To manage ADEM Self-Serve notification template from the global Self-Serve
 Notifications page, Click Strata Cloud Manager Configuration End User Coaching and edit ADEM Default Template. 

 In the End User Coaching Notifications page in Strata Cloud Manager, you can
 configure the Brand Profile , which defines the visual identity of the
 notifications to match your organization’s brand guidelines. 

 Click Edit on the Brand Profile section. 

 Enter the organization's name, upload the corporate logo, and set the
 theme for the notification UI. 

 Enable Allow for Language Localization if you need to
 provide notification messages in multiple languages. Select the language, review
 and edit the text as required. 

 When language localization is enabled, notifications are delivered in the
 user's device language, provided it is among the supported
 configurations. If the device is set to an unsupported language, the
 notification defaults to English. 

 Expand the event type for which you want to edit the notification
 message. 

 Enter the notification title and message 

 Configure how the notification must appear on the screen. Select any
 one of the following and check the preview 

 Toast - the notification must be a non-intrusive popup
 that auto-dismisses. 

 Modal - the notification must appear in a prominent
 window that requires to be manually dismissed. 

 Click Show Preview to view how the notification
 will appear in user's screen. 

 If you want to undo all the changes and keep the default setting, click
 Reset to Default Values . 

 Click Update to save the changes.
