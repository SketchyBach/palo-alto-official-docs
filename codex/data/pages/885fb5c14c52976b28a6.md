 Push the Prisma Agent Configuration 

 Learn how to push the Prisma Agent configuration changes to the cloud
 infrastructure. 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access 5.1 Innovation 

 Prisma Access 
 license with the Mobile User subscription 

 macOS 14 and later or Windows 10 version 2024 and later desktop devices 

 Role: Superuser 

 After you complete the Prisma Agent configuration or update the
 configuration, you must push the configuration to Prisma Access . 

 Create at least one project before you can push the commit,
 otherwise the commit will fail. 

 Select Configuration NGFW and Prisma Access Configuration Scope Prisma Access Mobile Users Access Agent . 

 Select Push Config Push . 

 Enter a Description for the job. 

 Select the Global Prisma Access Mobile Users Access Agent container and click Push . 

 Wait for the job to finish and Close the Jobs
 dialog.
