 Update Cortex XSOAR 

 Update your Cortex XSOAR 8.13 On-prem tenant. 

 Once Cortex XSOAR is installed and running, you can update the version from the Cortex XSOAR UI. If you encounter issues running the current version, you can update the version from the textual UI menu. 

 Version upgrades include operating system patches. 

 Update from Cortex XSOAR 

 Cortex XSOAR checks several times a day to determine whether there is a new version available and downloads an update file if it is available. If the update file of the new version of the tenant was downloaded successfully to the tenant, an update notification appears in the left menu pane for all admin users. Only administrators receive the update notifications and can perform an update. 

 The notification indicates the new version number that is available and contains a link that opens the About page. 

 You can hide the notification in the main pane for your user so that the next time you log in to the tenant, the notification in the menu pane will not appear until a different new version is available. If a different user logs in to the tenant, the notification will appear. However, the update icon will still appear next to the user's About option providing you with the ability to update the version. 

 When upgrading Cortex XSOAR, you update every version consecutively. For example, if you have installed version 8.11, you update to 8.12 and then 8.13. After you update to version 8.12, you will receive a notification for the next version. 

 You can perform one-click sequential upgrades from the textual UI by selecting a target version, and Cortex XSOAR automatically calculates and runs all required intermediate updates in order. 

 After updating, you can't rollback to a previous version. 

 In the Cortex XSOAR left menu pane, click Details in the update notification, or go to <Your Username> → About . 

 The About page appears with a new banner that indicates that an update is available with the new version number. 

 Click Continue . 

 An Update Available message appears. 

 If you are not going to update now, you can click the Hide the notification from the menu for this release to hide the update notification for this version. The next time you log in to the tenant, the notification will not appear in the main menu of the UI, but an icon will appear in the About option. 

 Click Update to <version number> to proceed with the update process. 

 A message appears indicating that the system will be down while the data and settings are updated. 

 Click Update Now . When the update is done, if this is a major release, a new version message appears. 

 Update from the textual UI 

 If the textual UI is not already open, either launch the web console from your VM or SSH log in from an external terminal. 

 opp-update.png 

 To update to a new version, in the textual UI menu, select Cluster Upgrade . 

 Enter the Upgrade Version .
You can enter a target version that is higher than the currently installed version, even if it is not the next consecutive version. Cortex XSOAR calculates the required upgrade path and updates every intermediate version sequentially, waiting for each version to complete before starting the next. 

 Ensure the version syntax and numbering is correct. For example, master-8.7.0-8.7.0.62-dadf65c3 . 

 Select Upgrade . 

 When you select Upgrade , after the upgrade tasks run an Upgrade completed successfully message displays. However, you need to wait until the upgrade process fully completes (approximately 30 minutes) and then check that you can open the Cortex XSOAR UI.
If the target version requires multiple intermediate updates, the output log displays the status of each version. If an intermediate update fails, the sequence stops at the version where the failure occurred, and Cortex XSOAR remains on the last successfully updated version.
