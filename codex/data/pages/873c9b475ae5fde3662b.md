 Configuration for Installation by JAMF (Administrator Task) 

 Create the iOS App installation package using the Cortex XDR or Cortex XSIAM tenant, and then extract the app link and Distribution ID. 

 In the iOS JAMF MDM, create a mobile device app for Cortex XDR. 

 From Device Mobile Device Apps select New , then click Next 

 Choose App Type App Store app or apps purchased in volume 

 For Search and Upload, select Enter Manually 

 Set a display name, such as Cortex XDR 8.4.0 

 Set the short version that you see in the app store. 

 Set the bundle identifier "com.paloaltonetworks.cortex.ios" 

 Set the app as Free. 

 If available, set the distribution method to Install Automatically . 

 If available, set Automatically Force App Updates if you intend to always keep the app up to date. 

 If available, set Convert Unmanaged App to Managed . 

 If available, set Allow Users to Remove The App to False. 

 Set the App URL to the App link that was received in the installation package, in Step 1. 

 Create the managed app configuration: 

 Download our app configuration spec file Download : 

 App Config Spec File Name: iOSCortexXDR_AppConfigSpec_V1.xml 

 SHA-256: 8f0001398937f0b0ad6eeb72cfd022641557c112bb87e4c466fbffdc2b96c612 

 Use the AppConfig Generator to generate a mobile device app. The AppConfig Generator is a third party tool that assists in the generation of configuration Plist for a mobile app on a device enrolled in an MDM solution. 

 1. Go to https://appconfig.jamfresearch.com/generator. 

 2. Select Browse and upload the App Config Spec File. 

 3. Select Configure , and follow the instructions to fill in the required fields. Submit . 

 4. Select Copy Dictionary and paste the generated dictionary in the app configuration tab of newly created mobile app. 

 5. Paste the dictionary in the App Configuration tab of the newly created mobile device app. 

 Select the scope of app: 

 Add the devices that will receive the app. 

 Save the app settings and wait for the app to be delivered to the managed devices.
