 Set Up High Availability 

 Set up high availability in Cortex XSOAR 6.12. 

 Review the High Availability Overview and Elasticsearch Best Practices . 

 Set up and configure the Elasticsearch cluster and ensure network connectivity between application servers and Elasticsearch. 

 Verify the Elasticsearch cluster meets the minimum sizing requirements for Cortex XSOAR. 

 Create a user or API key for Cortex XSOAR to authenticate with the appropriate permissions. 

 Provision the Cortex XSOAR application servers, ensuring each application server meets the minimum system requirements . 

 Create and mount the shared file system for the Cortex XSOAR application servers. Verify the shared file system meets the minimum requirements. 

 Verify that latency between the application servers, Elasticsearch cluster, and shared file system is 100 ms or below. For optimal performance, 10 ms or below is recommended. 

 Follow instructions for Single Server Elasticsearch installation. 

 Migrate the shared directory if it is not mounted at /var/lib/demisto . 

 (Recommended) - Install a load balancer . 

 Set the following server configurations to the URL of the load balancer under Settings → About → Troubleshooting 

 Base URL 

 External Hostname 

 Install Additional App Servers 

 Validate Additional App Servers 

 Perform the Server Post-Installation Health Check .
