 Upgrade of Cortex XSOAR multi-tenant 

 Upgrade multi-tenant deployments in Cortex XSOAR 8.9 On-prem. 

 Cortex XSOAR offers a seamless process for upgrading both your main and child tenants, providing a convenient and efficient way to manage upgrades within your multi-tenant environment. 

 After the upgrade version is published, you can upgrade via the: 

 Cortex Gateway: From the Gateway, a new activation card for the upgrade of the multi-tenant appears, which includes a Download button. Clicking on the download button, opens a wizard, which prompts you to select the entity to download to, which is the main tenant and the image to download. 

 Tenant: From the tenant, a notification is displayed in the Cortex XSOAR main menu. 

 Note 

 Only admin users can perform the upgrade. 

 Following the upgrade of the main tenant, you can conveniently upgrade all child tenants directly from the Tenant Management page. 

 Task 1. Upgrade main from the tenant: 

 Notification of an available upgrade is displayed in the Cortex XSOAR main menu above Settings & Info . 

 Click through the links to start the upgrade process. 

 During the upgrade, the main tenant is not available until the upgrade is complete. 

 Task 2. Upgrade child tenants: 

 After the upgrade of the main tenant is complete, you can begin upgrading the child tenants. It's important to upgrade the child tenants to the same version as the main tenant to ensure compatibility and avoid potential issues. 

 You can perform a manual upgrade via the child tenant. You cannot upgrade to a version that is higher than the main tenant. 

 You can also upgrade via the Tenant Management table from the main tenant: 

 From the main tenant, in Settings & Info → Settings → Configurations → Tenant Management , the table includes the column Cortex XSOAR Version which shows the version of the child tenant/s. You can select one or more child tenant/s to upgrade and then click Update . 

 Note 

 You can only upgrade a child tenant that is one version back from the main tenant. The upgrade of child tenants that are older than one version is not supported. The indicates that upgrade is not supported. 

 Unauthorized, unpaired, and disconnected cannot be updated. If selected, the Update button is disabled. 

 After the upgrade is complete, the Cortex XSOAR Version shows the new version.
