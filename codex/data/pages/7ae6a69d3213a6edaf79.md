 Chatbot MS Teams CloudBlade Integration 

 Learn about the MS Teams Chatbot CloudBlade integration release notes. 

 Prisma SD-WAN introduces the Prisma SD-WAN 
Chatbot MS Teams CloudBlade that allows efficient collaboration
by giving the end-user access to the Prisma SD-WAN network at any
time from anywhere through the MS Teams Chatbot. 

 Chatbot MS Teams CloudBlade Version 1.0.0 

 This section introduces the new the Chatbot MS Teams CloudBlade: 

 New/Updated Features 

 This version of the CloudBlade supports access to real-time information of Prisma SD-WAN network. 

 Site and device configuration 

 Site health 

 Device inventory 

 Events 

 Metrics on bandwidth utilization, application health, and application
 performance.
