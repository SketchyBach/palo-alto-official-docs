 Where Can I Use This? What Do I Need? 

 Manage Cloud Accounts 

 Onboard and Activate a Cloud Account in Strata Cloud Manager 

 After you successfully onboard the cloud accounts, use the Strata Cloud Manager 
 (cloud icon) to manage the accounts. 

 Log in to Strata Cloud Manager . 

 Navigate to AI Security AI Runtime AI Runtime Firewall . 

 Click the Cloud Account Manager (cloud icon). 

 Enabling sync configuration settings from Strata Cloud Manager to the Prisma AIRS AI Runtime or VM-Series 
 firewall in the cloud account, while disabling stops the sync. 

 To disable a cloud account, click the pause icon 

 . 

 To enable a disabled cloud account, click the enable icon 

 Select the Edit icon to edit an onboarded cloud account & regenerate
 the Terraform template. 

 Click Add Cloud Account to onboard a new cloud account and follow the
 cloud-specific onboarding steps. For details, see how to Onboard and Activate a Cloud Account in Strata Cloud Manager .
