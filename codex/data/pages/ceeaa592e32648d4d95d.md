 Allocate Virtual ION (vION) Devices Through the Strata Multitenant Cloud Manager 

 Learn about allocating a Virtual ION device license through
the Strata Multitenant Cloud Manager . 

 Get a quote for your Virtual ION (vION) device license, and then place an order that includes the
 details for the support and quantity. After your order is fulfilled and you activate
 a Prisma SD-WAN license for your tenant, the
 Strata Multitenant Cloud Manager enables you to manage devices : allocate device licenses, instantiate
 device licenses, and revoke device licenses. 

 To allocate a vION device license to a child
tenant, complete the following steps. 

 In
the parent tenant, select Manage Devices . 

 Select Virtual ION Devices . 

 The Device Summary displays: 

 Total Counts —Displays the devices
allocated to this tenant, based on the tenant selected in the Tenant filter. 

 Allocated to Clients —Indicates the number
of virtual ION device licenses allocated to any of its child tenants. 

 Used by Tenant —Indicates the total number
of virtual ION device licenses used by the currently filtered tenant. At
the top-most, root-level, parent tenant view, this number includes
all device licenses used by all the subsequent parent tenants and
their child tenants in the entire hierarchy. At any subsequent parent-level
view, this number includes the device licenses used only by that
parent and the child tenants in that particular nested hierarchy. 

 Select an ION device model for allocation. (Optional) You
can use the Model filter to select a model. 

 For a device model, under Actions ,
select the Ellipsis , and then Allocate . 

 On the Allocate to Child Tenant pop-up: 

 Enter the number of device licenses to be
allocated to the child tenant in Number of licenses (XX
Licenses available to allocate) . 

 Choose the child tenant name from Allocate
to client . 

 Select Allocate . 

 (Optional) View the vION device license allocation. 

 At the top-most, root-level, parent tenant view, the Allocated
By column is empty because the device license is provisioned
at this level, not obtained by allocation. Existing customers who
have received information about the
transition to a tenant or Tenant Service Group (TSG)
also see the empty column. 

 At any subsequent parent-level or child-level view in the hierarchy, Allocated
By displays the TSG ID of the allocating parent tenant.
