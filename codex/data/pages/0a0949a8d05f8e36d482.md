 Configure the Password Manager 

 Enable enterprise password management for end users in the Prisma Browser. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 Prisma Access with Prisma Browser bundle
 license or Prisma Browser standalone license 

 Superuser or Prisma Browser 
 role 

 Domains *.cyberark.cloud and
 *.idaptive.app allowed in firewall or proxy 

 The Prisma Browser Password Manager is an enterprise-grade password management
 solution built directly into the Prisma Browser . It enables users to securely
 store, organize, and autofill credentials for web applications that are not protected
 by Single Sign-On (SSO). Users can share accounts with colleagues ( Prisma Browser 
 Pro) and import existing credentials from other password managers — all from a side
 panel within the browser. 

 When the Password Manager is first enabled for users who have the Legacy Password
 Manager active, a welcome wizard introduces the new experience and imports existing
 credentials automatically. 

 The Password Manager is available on Prisma Browser Desktop (Windows, macOS, and
 Linux) with both Core and Pro licenses. Credential sharing with colleagues requires
 Prisma Browser Pro. 

 About the Password Manager Control 

 Prisma Browser Desktop Prisma Browser Extension Prisma Browser for Mobile 

 Full support No support No support 

 The Password Manager control and the Legacy Password Manager control are
 independent. Enabling or disabling one does not affect the other. Both appear
 under the Passwords and Autofill section of the browser
 security policy. 

 The Password Manager is disabled by default for all tenants. Administrators
 must explicitly enable it to opt in. 

 Administrators can choose to: 

 Enable the Password Manager while keeping the Legacy Password Manager enabled
 (allows users to access both during transition). 

 Enable the Password Manager and disable the Legacy Password Manager (forces
 full migration). 

 Enable the Password Manager while leaving the Legacy Password Manager enabled
 for export purposes only. 

 To set the Password Manager control: 

 From Strata Cloud Manager , select Prisma Browser Rules Browser Security 

 Select the rule to configure. 

 Locate the Passwords and Autofill section. 

 Under Password Manager , select one of the following
 options: 

 Enable - The Prisma Browser installs
 the Password Manager for end users matching this rule. Users can
 store, autofill, and share credentials from the browser side
 panel. 

 Disable - The Password Manager is not
 available to end users matching this rule. 

 Click Set .
