 Reference H: Permissions 

 Permission 

 Scope 

 Application Security Periodic View 

 View branch periodic scan results. 

 Application Security Periodic View/Edit 

 Trigger a rescan on a branch periodic scan. 

 Application Security PR Scans View 

 View pull request scan results. 

 Application Security CI CD Scans View 

 View CI scan results. 

 A user holding Application Security Periodic View without Application Security Periodic View/Edit can read every scan result and cannot trigger a rescan. When the Rescan control is unavailable on a scan with a health value of Error or Partially (completed), the cause is the missing edit permission.
