 Features Introduced in August 2022 

 Learn what’s coming new in Prisma SD-WAN in August 2022. 

 New Feature/Enhancement Description 

 Support for IPv6 for PPPoE interface Prisma SD-WAN now supports IPv6 for PPPoE interfaces. 
 Device
Software Version Required: 6.1.1 and later 

 Support for Layer 2 Switch Ports in new platforms The new ION 1200 variants ION1200-S, ION 1200-S-C-NA/ROW
and ION 1200-S-C5G-WW support the Layer 2 switches. The Layer 2
switch ports enable connecting multiple devices directly on the
L2 LAN. 
 Device Software Version Required: 6.1.1 and later 

 Support for PoE ports with LLDP-MED (Media
Endpoint Discovery) Endpoints The new ION 1200 variants ION 1200-S, ION 1200-S-C-NA/ROW,
ION 1200-S-C5G-WW and new platform ION 3200 support four 1Gbps RJ45
ports with PoE. The total system PoE power of 90W with a maximum
per port wattage of 60W. LLDP-MED allows a device to determine the
capabilities of a connected device, neighbors, and if these capabilities
are enabled. 
 Device Software Version Required: 6.1.1 and later 

 New Alerts and Alarms New alerts and alarms are introduced to support
the new hardware features such as Layer 2 switch, PoE ports, LLDP,
and IPv6. 
 Device Software Version Required: 6.1.1 and later 

 Enhancement to Multitenant Device Manager Prisma SD-WAN introduces a Sales Order # on
the Device Manager screen in the MSP Portal which can be used to
group all devices in the same order and simplify bulk device allocation
to a tenant. 
 Device Software Version Required: 6.1.1 and
later
