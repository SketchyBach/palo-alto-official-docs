 Learn about the INC_GLOBALPROTECT_GW_USER_AUTH_TIMEOUT_FAILURES_COUNT_EXCEEDED_ABOVE_BASELINE_PER_PA_LOCATION incident. 

 Incident Code 

 INC_GLOBALPROTECT_GW_USER_AUTH_TIMEOUT_FAILURES_COUNT_EXCEEDED_ABOVE_BASELINE_PER_PA_LOCATION 

 Title Template 

 Gateway auth timeout failures are higher than twice the baseline for location {compute_location} 

 Category 

 Network Services 

 Subcategory 

 Authentication 

 Description 

 There has been a higher than normal number of authentication timeout failures when users attempt to authenticate to the GlobalProtect gateway. This could result in user access issues and connectivity problems, as users may be unable to successfully log in to the VPN through the GlobalProtect gateway. 

 Raise Condition 

 Incident is Raised for a location, when the average authentication timeouts are more than twice the baseline for 45 minutes 

 Clear Condition 

 Incident is Cleared for a location, when the average authentication timeouts are less than twice the baseline for 45 minutes
