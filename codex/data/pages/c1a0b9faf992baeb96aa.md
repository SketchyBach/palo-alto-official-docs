 Increase
CPUs and Memory for Panorama on vCloud Air 

 For the minimum CPUs and memory that Panorama
requires, see Increase CPUs and Memory on the Panorama Virtual Appliance . 

 Access the vCloud Air web console and select your Virtual
Private Cloud OnDemand region. 

 In the Virtual Machines tab, select
the Panorama virtual machine and Power Off . 

 Select Actions Edit Resources . 

 Set the CPU and Memory . 

 Save your changes. 

 Select the Panorama virtual machine and Power
On .
