 Customize the Logo 

 Customize full-size and minimized logos in Cortex XSOAR 6.13. 

 By default, the full-size Cortex XSOAR logo displays on the sign-in page, on the navigation bar when expanded, on reports, on the artifact viewer, and on communication task forms and emails. A minimized version of the default Cortex XSOAR logo displays at the top of the navigation bar when it is collapsed. You can replace the default logos with a custom logo to match your organization branding in the Cortex XSOAR platform. 

 If you define a full-size logo, but no minimized logo, no logo will display when the navigation bar is collapsed. 

 Supported file formats: 

 PNG 

 JPEG 

 SVG 

 GIF 

 The minimum recommended image dimensions are 50px height and 50px width. The recommended maximum file size is 100kB. 

 Go to Settings → About → Troubleshooting . 

 Scroll to the Logos section and add the necessary custom logos. You can drag-and-drop the logo file or browse and upload the full sized version and the minimized version of the logo file.
