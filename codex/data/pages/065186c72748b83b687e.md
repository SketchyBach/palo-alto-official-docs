 Platform 

 Getting started with platform model using PAN-OS OpenConfig
plugin. 

 Review the deviation file before using the
 openconfig-platform model to familiarize yourself with supported paths. 

 In the platform model, almost all of the components are custom fields on
 PAN-OS. Each model will vary depending on the hardware and other properties associated
 with that model. 

 For an example of a list of nodes associated with the model, view the graphic below: 

 Power status in OpenConfig for allocated-power and use-power are indicated in watts while
 the PAN-OS user interface displays values in volts. 

 Retrieving Platform Information 

 This
 example gNMI call retrieves platform information for a PA-3260
 firewall. 
 gnmic -a 10.1.1.1:9339 -u admin -p password --skip-verify -e
 JSON_IETF --timeout 300s get --path /components
