 createRCSScan 

 Creates or gets a remediation confirmation scanning (RCS) request. Returns an existing scan if one matches the filters, or creates a new one. 

 Arguments 

 Argument Name 

 Description 

 Required 

 attack_surface_rule_id 

 The attack surface rule ID (service type) from the attack surface service context. 

 Required 

 internal_issue_id 

 The internal ID of the issue associated with the attack surface service. 

 Required 

 service_id 

 The service ID from the attack surface service context. 

 Required 

 Outputs 

 Core.RCSScan.ScanID string 

 The ID of the remediation confirmation scan. 

 pollRCSScan 

 Checks the status of a remediation confirmation scan (RCS) by scan ID. 

 Arguments 

 Argument Name 

 Description 

 Required 

 scan_id 

 The scan ID to poll. 

 Required 

 Outputs 

 Core.RCSPoll.ScanID string 

 The scan ID that was polled. 

 Core.RCSPoll.Status string 

 The scan status (IN_PROGRESS, FAILED_TIMEOUT, FAILED_ERROR, SUCCESS). 

 Core.RCSPoll.Result string 

 The scan result if status is SUCCESS (REMEDIATED, UNREMEDIATED).
