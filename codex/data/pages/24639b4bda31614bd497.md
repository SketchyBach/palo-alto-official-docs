 Features Introduced in Cortex XDR App for Android 

 The Cortex XDR agent app for Android user interface was refreshed in version 8.0. 

 Improved real-time user notifications about malicious apps, allowing the user to stop an application, or uninstall it, if it was detected as malicious. In order to take advantage of these notifications, the user must grant the following additional special permissions to the app: 

 Display over other apps 

 Accessibility access 

 When upgrading from earlier versions of the agent to version 8.x, the name of the endpoint in the Cortex XDR management console will update from "<LastName>-<FirstName>" to "<AndroidID>-<Device Name>".
