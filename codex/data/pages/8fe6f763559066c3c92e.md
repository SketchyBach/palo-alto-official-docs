 Cipher Suites Supported in PAN-OS 10.1 

 Cipher suites supported on firewalls running a PAN-OS®
10.1 release in normal operation mode. 

 The following topics list cipher suites that are supported
on firewalls running a PAN-OS® 10.1 release in normal (non-FIPS-CC)
operational mode. 

 If your firewall is running in FIPS-CC mode, see the list of PAN-OS
10.1 Cipher Suites Supported in FIPS-CC Mode . 

 The ciphers supported in normal operation mode are grouped according
to feature or functionality in the following sections:
