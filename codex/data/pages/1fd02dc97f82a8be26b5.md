 Disconnect the Prisma Access Agent from a Location 

 You can disconnect from a Prisma Access location if the Prisma Access Agent 
 is in On Demand mode. 

 Where Can I Use This? What Do I Need? 

 Prisma Access Agent 

 Minimum Prisma Access Agent version: 

 25.1 (macOS and Windows) 

 25.7 (Linux) 

 macOS, Windows, or Linux
 desktop devices 

 Check the prerequisites for the
 supported OS versions 

 Internet access 

 If your administrator has configured the Prisma Access Agent to run in
 On Demand mode, you can disconnect from a Prisma Access location. 

 If you disconnect from a location, your
 device will not be protected by the same security policies that your organization
 enforces, and you won’t be able to access your organization's private and public
 applications and resources. 

 You cannot disconnect from Prisma Access if
 your agent is running in Always On mode. To see if your agent
 is in Always On mode, hover your cursor over the lock: 

 To disconnect from a Prisma Access location: 

 Launch the Prisma Access Agent by clicking the Prisma Access Agent 
 icon 

 from the macOS menu bar, Windows
 taskbar, or Linux panel . 

 Click the lock icon to disconnect from the location. 

 You are disconnected from the location.
