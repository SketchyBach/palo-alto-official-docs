 Restrict Extension Host Permissions 

 Restrict extension host permissions 

 Prisma Browser Desktop Prisma Browser Extension Prisma Browser for Mobile 

 Full support No support No support 

 This control allows you to restrict Host permissions for extensions. 

 From Strata Cloud Manager , select Configuration Policy Control Sets Browser Security Extensions 

 Select Restrict Extension Host Permissions . 

 Select one of the following options: 

 Enable - Enable restricting Extension Host
 Permissions. 

 Enable for specific domains - Enable restricting host permissions
 for specified domains only. 

 Disable - Disable restricting Extension Host Permissions. 

 Click Set .
