 Customize an Ask Task 

 Customize Ask tasks in Cortex XSOAR 6.12. 

 You can customize the message HTML and CSS for a data collection task. 

 Go to Settings → About → Troubleshooting → Server Configuration . 

 Add the key messages.html.formats.externalAskSubmit , and add the following HTML with your customizations as the value.
