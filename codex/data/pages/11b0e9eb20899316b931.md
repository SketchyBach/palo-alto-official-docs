 Configure how to bypass proxy settings 

 Configure proxy bypass settings for Cortex XSOAR 6.14 with server configuration options. 

 Select Settings → About → Troubleshooting → Add Server Configuration . 

 Add the following key with the relevant value. 

 Key 

 Example Value 

 Description 

 no_proxy 

 *.test.example.com,.example.org,127.0.0.0/8 

 A comma-separated list of URLs to bypass the proxy. 

 Click Save. 

 In the CLI, run /reset_containers for the new proxy settings to take effect.
