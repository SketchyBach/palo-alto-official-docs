Create device groups
POST
https://api.prod.koi.security
/api/external/v2/groups

Creates one or more device groups for the customer. Maximum 9 groups per customer.

Authorizations
bearerAuth
Authorization
string
required
Bearer authentication header of the form Bearer <token>.
Body
application/json
creator
string · max: 255
optional

Identifier to attribute as the creator of the groups (e.g. an email or a service/automation name). Applies to every group in this request.

Example: deploy-bot@acme.com
groups
object · V2CreateGroupInputDto[]
required

List of groups to create

Responses
201

Groups created successfully

application/json
groups

required
