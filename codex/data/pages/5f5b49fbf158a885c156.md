 OCI Cloud Regions 

 You can deploy the VM-Series firewall with any supported PAN-OS® release in all
 Oracle Cloud Infrastructure public cloud regions and government cloud regions . 

 VM-Series firewall on OCI Gov cloud regions is supported only
 with PAN-OS version 11.2.8 or above for FIPS and non-FIPS mode.
