 Snowflake Monitoring Issues 

 IP not allowed to access Snowflake 

 Issue: Network Policies are used to restrict traffic to Snowflake for specific IP addresses and ranges. The Network Policy should be modified to allow access from Prisma Cloud DSPM. 

 Symptom: Error message is generated when trying to access Snowflake from an unauthorized IP address. 

 Solution: In the Snowflake network policy, add a rule to accept access for Prisma Cloud DSPM IPs. For more information refer to Controlling network traffic with network policies . 

 Connection error to snowflake 

 Issue: Network connectivity issue prevents Prisma Cloud DSPM from accessing Snowflake data. 

 Symptom: Error message is generated when trying to access Snowflake. 

 Solution: Contact Snowflake support.
