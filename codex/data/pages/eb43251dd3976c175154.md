 Manage Autonomous DEM 

 Learn how to monitor and manage your
registered Autonomous DEM mobile users and remote sites. 

 When you create a new app test, you can assign it to ADEM remote
sites or all registered ADEM users (default) or choose specific
users to assign a test to, or you can assign the tests to both remote
sites and users. If you have already created a test to be assigned
to all registered ADEM users or remote sites, any tests will automatically
start running on an endpoint or the remote site as soon as it registers
with ADEM. Once a test is started on an endpoint or remote site,
it will send metrics from the app test to the ADEM service every
five minutes.
