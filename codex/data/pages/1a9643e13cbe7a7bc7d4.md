 PAN-OS 10.2.7-h34 Addressed Issues 

 PAN-OS® 10.2.7-h34 addressed issues. 

 After upgrading to this release, all GlobalProtect users will be
 required to reauthenticate. 

 Issue ID 

 Description 

 — 

 Fixes were made to address the following CVEs: 

 CVE-2026-0265 

 CVE-2026-0264 

 CVE-2026-0262 

 CVE-2026-0261 

 CVE-2026-0258 

 CVE-2026-0257 

 CVE-2026-0256 

 CVE-2026-0259 

 CVE-2026-0300 

 CVE-2026-0269 

 PAN-269254 

 Fixed an issue where high CPU utilization caused GlobalProtect VPN
 tunnels to flap, users to be disconnected, and the CLI to become
 unresponsive. This occurred when a large number of GlobalProtect
 users were actively processing application traffic. 

 PAN-223481 

 ( PA-5450 firewalls only ) Fixed an issue where the
 all_pktproc process stopped responding when the
 firewall was on PAN-OS 10.1.9-h3 or a later release.
