 The following list includes all known issues that impact a Network Discovery plugin 1.0
 release. This list includes both outstanding issues and issues that are addressed, as
 well as known issues that apply more generally or that are not identified by a specific
 issue ID. 

 BAN-20570 

 Network Discovery didn't appear in the menu options under
 Device IoT Security after installing the Network Discovery plugin.

 This issue is resolved in Network Discovery plugin 1.0.0. 

 DIT-40176 

 The Network Discovery plugin sticks in running state. Resetting
 the plugin temporarily fixes the issue but eventually returns to and sticks in
 running state. 

 This issue is resolved in Network Discovery plugin 1.0.1.
