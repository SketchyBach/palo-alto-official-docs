 inspect security-policy size 

 Use the inspect security-policy size command
to displays the size of the security policies for an application
flow. 

 Command 

 inspect security-policy size 

 Options 

 None 

 Command Notes 

 Role Super, Read Only 

 Related Commands — 

 Introduced in Release 5.6.1 

 Example 

 inspect security-policy size
 MEMORY USED(APPROX BYTES)
 Zone-Network ID Map Size : 96
 Security Policy Size : 23605854
