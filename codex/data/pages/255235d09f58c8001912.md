 AL_RN_SITE_LONG_DURATION_CAPACITY_ EXCEEDED_THRESHOLD 

 Learn about the AL_RN_SITE_LONG_DURATION_CAPACITY_EXCEEDED_THRESHOLD
 alert. 

 Synopsis 

 The remote network bandwidth consumption was consistently greater than 90% but less
 than 100% of capacity for at least 4 hours per day for at least 3 of the last 5
 days. 

 This bandwidth alert applies to the remote network site bandwidth allocation model
 and not to the aggregate bandwidth allocation model. For information about bandwidth
 allocation and how to allocate bandwidth for specific remote network sites, see
 Allocate Remote Network Bandwidth in the
 Prisma Access Administration Guide . 

 This bandwidth alert applies to the per remote network site bandwidth allocation
 model and not to the aggregate bandwidth allocation model. 

 Alert Code—AL_RN_SITE_LONG_DURATION_CAPACITY_EXCEEDED_THRESHOLD
