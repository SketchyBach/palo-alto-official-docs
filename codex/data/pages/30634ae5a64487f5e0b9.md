 Create profile exceptions 

 Create profile exceptions for trusted or expected activity. 

 For Cortex XDR agent related issues, you can create profile exceptions for Window processes, BTP, and JAVA deserialization issues directly from the Issues table. 

 Identify an XDR Agent issue which has a category of Exploit , right-click and select Manage Issue → Create issue exception . 

 Select an Exception Scope : 

 Global: Apply the exception across your organization. 

 Profile: Apply the exception to an existing profile or click and enter a Profile Name to create a new profile. 

 Click Add to add the scope. 

 (Optional) View your profile exceptions. 

 Go to Inventory → Endpoints → Policy Management → Profiles . 

 In the Profiles table, locate the OS in which you created your global or profile exception and right-click to view or edit the exception properties.
