 Related Documentation 

 Use the following documents to set up and implement
your Prisma Access deployment: 

 Use the Strata Cloud Manager Administration
 guide to manage your Palo Alto Networks Network Security
 infrastructure – your NGFWs and SASE environment – from a single,
 streamlined user interface. 

 Use the Prisma Access Administrator’s Guide to plan,
 install, set up, and configure Prisma Access to secure your network. 

 Use the vendor-specific tasks in the Prisma Access Integration Guide to
 use Prisma Access to configure mobile user authentication and secure your
 public cloud and third-party SD-WAN deployments. 

 Use the Strata Logging Service Administration
 Guide to learn how to activate Strata Logging Service, which you
 need to do before you activate Cloud Managed Prisma Access. 

 Visit docs.paloaltonetworks.com for more information on our products.
