 Enforce policies with C2C 

 Policies can be configured with runtime conditions derived from Code-to-Cloud lineage. For example, blocking a build only when the detected vulnerability affects an asset destined for an internet-facing environment. Policy enforcement consumes the same lineage signal documented throughout this guide but is configured and managed as a separate capability. 

 For information on policies, refer to Unified Application Security policies .
