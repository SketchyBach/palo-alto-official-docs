 View the Entire Command Hierarchy 

 Browse the complete PAN-OS CLI command structure to understand available commands and their organizational hierarchy. 

 Where Can I Use This? What Do I Need? 

 NGFW (Managed by PAN-OS or Panorama) 

 No prerequisites needed

parameters to display the entire command hierarchy in the current
command mode. For example, running this command from operational
mode on a VM-Series Palo Alto Networks device yields the following
