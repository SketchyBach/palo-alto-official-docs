 Supported File Types for Upload or Download in RBI 

 Review the list of supported file types that users can transfer during Remote Browser Isolation sessions. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager Managed Prisma Access 

 Minimum required Prisma Access version: 5.2.1 Innovation
 and Preferred 

 Prisma Access 
 license with the
 Mobile User or Remote Networks license subscription 

 Remote Browser Isolation
 license 

 Remote Browser Isolation (RBI) supports the following types of files for upload or download
 during isolated browsing sessions. The file types are grouped into categories and appear
 in the File Extensions for Upload and File Extensions
 for Download sections in the isolation profile configuration . When you select a category,
 all the file types within the category are permitted for upload or download.
