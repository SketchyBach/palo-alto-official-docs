 What is Cortex XDR multi-tenant? 

 Cortex XDR 3.x 

 MSSP multi-tenant 

 MSSP multi-tenancy allows managed security service providers to ensure strict data segregation along with the flexibility to monitor alerts across tenants and dynamically allocate licenses. 

 Cortex XDR supports pairing multiple Cortex XDR environments with a single main account enabling MSSPs to easily manage security on behalf of their clients. 

 The following license options are available for MSSP multi-tenants: 

 Option 

 Description 

 Central licensing management 

 The MSSP acquires a license for the main tenant (parent account) with resource allocations of total endpoints and/or GB for child tenants. From the main tenant, the administrator can then dynamically create child tenants and allocate the resources among its child tenants. All child tenants are automatically paired to the main tenant and the licenses are all owned by the main tenant. 

 Customer-owned license 

 The MSSP acquires a license for its parent tenant. All end customers must acquire their own licenses in a separate contract. The child tenants must be manually paired to the main tenant.
