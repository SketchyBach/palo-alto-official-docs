 Issue 

 Description 

 GitHub #42367 

 The mentions widget does not work 

 In the War Room, when using the @ to notify a user (such as @admin ), although the user is added to the incident, there is no record of the notification in the Mentions widget in the user's dashboard (My dashboard). 

 Jira XSUP-36386 

 Reports contain empty data 

 (Multi-tenant/MSSP) On the main tenant, empty results are returned when scheduling a report with the Run as roles option. 

 Jira CRTX-87945 

 The user cannot delete incidents from the incident table 

 To view/use the Delete button on the Incidents page, users must have both of the following View/Edit permissions for DATA : 

 Delete incidents 

 Delete (under Incident Table Actions ) 

 If only one is selected, the button does not appear, and the user can’t delete incidents from the incident table. 

 Jira CRTX-168692 

 CIS Level 1 

 CIS level 1 adjustments are not applied after upgrade (only after a clean deployment). 

 ETA for the fix: Mid-May. 

 Jira CRTX-186163 

 Backup and restore fails when trying to pull a patch version that does not exist in the registry 

 During the restore process, the system automatically tries to download a specific patch to match the backed-up version. If that patch does not exist in the registry, the process fails. 

 Jira XSUP-56724 

 Incomplete incident search results 

 When searching for incidents based on indicator values, if there are over 10,000 indicators that match the indicator part of the query, the incident results may be incomplete.
