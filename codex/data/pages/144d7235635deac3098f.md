 Dropbox Access Token detected in code 

 Rule Details 

 Cortex AppSec Rule ID 

 APPSEC_SECRET_314 

 Category 

 Secrets 

 Severity 

 MEDIUM 

 Framework 

 Git 

 Impact 

 The Dropbox Access Token allows API calls to access or manage files on a linked account. 

 Exposure allows an attacker to gain unauthorized access to the linked account, potentially leading to file theft, modification, or deletion of sensitive documents. 

 How to Fix 

 To remediate exposed Auth tokens or Signing Keys: 

 Log in to your Identity Provider or OAuth provider settings. 

 Rotate the compromised Client Secret, Private Key, or Signing Certificate. 

 Update your application configuration with the new credentials. 

 Redeploy your application to ensure the new keys are in effect. 

 Next, remove the secret from your codebase: 

 Locate the exposed secret in your codebase. 

 Replace the hardcoded value with a secure variable or reference. 

 Finally, clean your version control history: 

 Permanently remove the sensitive data from your version control history to ensure it cannot be retrieved. 

 Warning: Rotating signing keys or client secrets will likely invalidate active user sessions or tokens. Be prepared for users to be logged out.
