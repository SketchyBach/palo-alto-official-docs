 Manage dashboards 

 From Dashboards Manager, you can delete, edit, disable, and perform additional management actions on your dashboards. 

 From the Dashboards Manager , you can delete, edit, duplicate, disable, and perform additional management actions on your dashboards. 

 Navigate to Dashboards → Dashboards Manager to view all custom and predefined dashboards. 

 Right-click a dashboard, and select from the following actions: 

 Delete - Permanently delete a dashboard. 

 Edit - Edit an existing dashboard. You cannot edit the default dashboards provided by Palo Alto Networks, but you can save them as new dashboards. 

 Save as new - Duplicate an existing dashboard, and save it with a new name. 

 Disable - Temporarily disable a dashboard. If the dashboard is public, this dashboard is also removed for all users. 

 Set as default - Make the dashboard the default dashboard that displays when you (and other users, if the dashboard is public) log in to Cortex Xpanse . 

 Save as report template - Save the dashboard as a report template.
