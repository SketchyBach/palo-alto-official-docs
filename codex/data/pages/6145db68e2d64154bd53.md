 Add DigiCert One Certificate Authority 

 DigiCert One is a unified certificate management platform that provides centralized management for both public and private certificate authorities (CAs). You can connect DigiCert One to Next-Gen Trust Security to issue, renew, revoke, and manage certificates from your DigiCert One certificate authorities. 

 Note: DigiCert One vs DigiCert CertCentral 

 DigiCert One is DigiCert's newer platform. If your organization uses DigiCert CertCentral, see Using DigiCert instead. 

 Before You Begin 

 DigiCert One account with API access 

 API token from DigiCert One 

 Base URL for your DigiCert One instance 

 At least one active VSatellite for provisioning certificates to DigiCert One 

 In Next-Gen Trust Security, the Superuser role, and Tenant selected in the workspace switcher. Certificate Authorities is available only under Tenant 

 DigiCert One connector has the following limitations: 

 REST API enrollment only : Only certificate profiles configured with REST API enrollment ( enrollment_method: rest_api ) are supported. Profiles using manual or other enrollment methods are automatically filtered out and won't appear in the profile dropdown. This applies to both public and private CA profiles. 

 Business Unit ID : The Business Unit ID is automatically retrieved from the selected profile during request policy creation and cannot be manually specified. 

 Profile availability : Only profiles that support REST API enrollment will be visible when creating request policies. 

 To Add a DigiCert One Certificate Authority 

 Sign in to Next-Gen Trust Security. 

 Click Configuration > Certificate Integrations > Certificate Authorities . 

 Click New > Certificate Authority connector . 

 Enter the Name . 

 Select a VSatellite . 

 In the Certificate Authority Type dropdown, select DigiCert One . 

 Enter the Base URL for your DigiCert One instance. 

 Enter your API Token from DigiCert One. 

 Click Test Connection to validate the connection. 

 (Optional) Select which certificate products to make available for issuance: 

 In Product Options , select the certificate authority products to map to request policies. 

 (Optional) Click Add to include additional products. 

 Click Next . 

 (Optional) Select which certificate products to import from DigiCert One: 

 In the import section, select the certificate authority products to import certificates from. 

 Click Add to include additional products. 

 (Optional) Enable one or more Import options : 

 Include revoked certificates 

 Include expired certificates 

 Select a Seat Type that matches your certificate usage model in DigiCert One (for example, Certificate Management for public certificates or Server Seat for server certificates). 

 (Optional) Enable Scheduled import . 

 Click Create . 

 What's Next 

 After adding the DigiCert One CA, you can: 

 Create request policies to define certificate policies 

 Request certificates using the configured request policies
