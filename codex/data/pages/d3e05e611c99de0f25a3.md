 ADEM data is visible in Strata Cloud Manager . To access the ADEM 
 widgets, log in to Strata Cloud Manager from the hub with your credentials and view the unified visibility data, which
 includes ADEM widgets in the various dashboards. 

 To view ADEM data in Strata Cloud Manager , you must have
 purchased an add-on ADEM license. You can purchase either the ADEM Observability
 license or the AI-Powered ADEM license. For information on these licenses, see autonomous-dem.
