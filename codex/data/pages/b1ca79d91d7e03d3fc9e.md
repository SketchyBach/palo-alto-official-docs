 Create Alert Exceptions 

 You can choose different alert settings for
individual tags by adding the tags as alert exceptions .
Create exceptions so that the alerts you receive for threat samples
are prioritized by tag. 

 Select Alerts Settings . 

 If there are no email or HTTP/HTTPS Alert Actions listed, Define
Alert Actions . 

 Identify the tag type for which you want to create an
alert exception, and click Add Exception . 

 In the Tag field, start typing the tag name, and select
it from the list of tags. 

 Select an alert Action for the tag. 

 Select one of the email or HTTP/HTTPS alert actions
to enable alerts for the tag. 

 Select none to disable alerts for
the tag. 

 Select Enabled? to enable the
alert action for samples in your network that match the tag. 

 Click Save Exception . 

 To change or delete alert exceptions, Edit
Alerts .
