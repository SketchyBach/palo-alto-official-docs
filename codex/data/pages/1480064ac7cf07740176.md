 Set Up the Prisma Agent System Tray Icon on Ubuntu 22.04 

 Install the AppIndicator GNOME extension on Ubuntu 22.04 to enable the Prisma Agent system tray icon before installation. 

 Where Can I Use This? What Do I Need? 

 Prisma Agent 

 Ubuntu 22.04 with the GNOME desktop environment 

 Administrator (sudo) privileges 

 If you're using Ubuntu 22.04, before you install the Prisma Agent , you
 need to set up the system tray icon functionality for Prisma Agent by
 installing the required GNOME extensions. 

 If you're running on a VM, you might need to disconnect GlobalProtect or Prisma Agent from the host system before proceeding. Each user on the
 Linux system needs to complete this configuration individually — these settings apply
 per user account rather than system-wide. 

 Remove any existing AppIndicator extension that might conflict by running the
 following command in the shell: 

 sudo apt remove gnome-shell-extension-appindicator 

 Install the GNOME Extension Manager to easily manage extensions: 

 sudo apt install gnome-shell-extension-manager 

 Apply the changes by logging out of the operating system and logging back in
 again. 

 Install the AppIndicator Support extension. 

 Open the Extension Manager application. 

 Browse the extensions. 

 Enter KStatus in the search bar. 

 Locate AppIndicator and KStatusNotifierItem
 Support in the search results and
 Install the extension. 

 Verify the installation of the AppIndicator Support extension. 

 Go to the User-Installed Extensions section in
 Extension Manager. 

 Confirm that AppIndicator and KStatusNotifierItem
 Support appears in the list of installed extensions and
 the extension is enabled (toggle is in the "on" position). 

 Proceed with the Prisma Agent . 

 The system tray icon should now display properly.
