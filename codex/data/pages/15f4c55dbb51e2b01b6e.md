 LQM Support for Prisma Access VPNs 

 Learn to enable and manage LQM for Prisma Access VPNs. 

 Where Can I Use This? What Do I Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 Prisma SD-WAN 

 Prisma SD-WAN AppFabric deployed
 at one or more locations. 

 Physical and/or virtual ION devices running
 software versions 5.6.X or higher. 

 Prisma Access Cloud Managed 
 Prisma Access with Aggregate Bandwidth; the
 bandwidth licensing mode must be enabled per compute
 location on the Prisma Access Cloud Managed
 portal. 

 Identification of the IPSec Termination Nodes within
 Prisma Access for connectivity. 

 Ensure that you have Prisma Access (Cloud Managed) and
 Prisma SD-WAN in the same TSG. 

 Link Quality Metrics provides the capability to monitor Prisma Access
 circuit connectivity health through the Link Quality Monitoring (LQM) metrics on the
 web interface. When a service endpoint is created using native integration, it's
 automatically set to Prisma Access Remote Networks High Performance (RN-HP). 

 To enable LQM for Prisma Access tunnels (enabled by default): 

 Select Configuration Resources Service & DC Groups Manage Endpoints . 

 On the Endpoints screen, select Standard VPN from the
 drop-down. 

 From the Settings ellipsis menu, select Liveliness Probe 
 for an endpoint. 

 On the Liveliness Probe dialog, enable Prisma Access RN-HP
 LQM for the endpoint. 

 Leverage Prisma Access LQM for All Non-Hub Paths 

 By default, Use LQM for Non Hub Paths 
 is disabled but can be enabled at the circuit or circuit category. 

 Select Configuration Prisma SD-WAN Sites or Data Centers Configurations Internet Circuits Change Circuits . 

 Edit the specific circuit. 

 On the Circuit Information page, under LQM Hubs ,
 select Prisma Access . 

 Refer to Configure Internet
 Circuits for more information.
