 Customize the Login Message 

 Customize the login-page message in Cortex XSOAR 6.13. 

 You can configure a message to appear to users on the login page before every login to Cortex XSOAR. For example, you may want to use this message to display a legal message warning users about the ramifications of unauthorized access. 

 Go to Settings → ABOUT → Troubleshooting . 

 Scroll to the Login Message section and turn on Enable login message . 

 Enter the Message content that you want to display to users. Markdown formatting is supported. 

 Save your changes.
