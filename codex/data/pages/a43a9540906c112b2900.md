 Advanced WildFire Powered by Precision AI™ 

 Advanced WildFire®  Powered by Precision AI  uses high-fidelity data and threat intelligence from the industry’s largest global community and applies machine learning to analyze and block malicious files with AI-Powered Security Models. Deep learning is used to analyze larger volumes of files and enable security models to detect more sophisticated and previously unseen malware variants. With the mass adoption of generative AI by threat actors, security models are now trained on and identify AI-generated threats. 

 What's New 

 20 October 2025 
 You can now select the WildFire region that MacOSX samples are forwarded to for malware analysis on Strata Cloud Manager . This allows global organizations using Advanced WildFire to adhere to and comply with strict regional data requirements when forwarding MacOSX files for analysis. 

 23 April 2025 
 Palo Alto Networks® WildFire® now  supports forwarding, analysis, and prevention of threats contained in email message files (EML)  . EML files are used to store email message contents and typically includes the entirety of a single email in plain text format. Because this includes all contents of the email (including the email headers, message body, attachments, and other MIME components), any malicious contents that can be delivered using those vectors are analyzed by the Advanced WildFire cloud for threats.

 WildFire API Reference 

 The WildFire™ API extends the malware detection capabilities of WildFire through a RESTful XML-based API. Using the WildFire API, you can automate the submission of files and links to WildFire or a WildFire appliance for analysis, and to query WildFire for verdicts, samples, and reports.
