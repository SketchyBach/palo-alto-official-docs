 The Prisma Agent , a next-generation mobile access agent built for today's
 hybrid workforce, delivers secure and convenient access to both enterprise apps and the
 internet, and also simplifies network, IT and security operations for an
 organization. 

 Your end users can use the Prisma Agent to securely access your
 organization's network, resources within the network, SaaS applications, or the internet
 from any location. The Prisma Agent enables your users to easily connect to
 corporate headquarters, data centers, branch offices, or educational institutions where
 Prisma Access is deployed. When they connect to Prisma Access locations
 while working from anywhere, they benefit from the same security policies that protect
 the sensitive resources in your organization's network. 

 In addition, the Prisma Agent can help secure your endpoints from threats
 and malware through Advanced Threat Prevention, Advanced URL Filtering, DNS Security,
 Advanced WildFire, and more. 

 To manage the Prisma Agents that are deployed to mobile users in your
 organization, Prisma Agent provides an Endpoint Management
 page ( Configuration Endpoint Management ) that serves as a single point of control of the agents. There, you can simplify the
 lifecycle management of the
 agents, including deployment, configuration, and visibility into the agents for
 troubleshooting, remediation, and maintenance.
