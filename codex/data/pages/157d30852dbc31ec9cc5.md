# Release Information

Cortex XSOAR combines security orchestration, incident management, and interactive investigation into a seamless experience. The orchestration engine is designed to automate security product tasks and weave in human analyst tasks and workflows.

To install this version, see the following:

* [Single Server Installation](https://docs-cortex.paloaltonetworks.com/r/Cortex-XSOAR/6.13/Cortex-XSOAR-Installation-Guide/Single-Server-Installation)
* [Multi-Tenant Installation](https://docs-cortex.paloaltonetworks.com/r/Cortex-XSOAR/6.13/Cortex-XSOAR-Installation-Guide/Multi-Tenant-Installation)

If upgrading from an earlier version including how to install and download, see [Upgrade Your Installation](https://docs-cortex.paloaltonetworks.com/r/Cortex-XSOAR/6.13/Cortex-XSOAR-Installation-Guide/Upgrade-Your-Installation).

This Cortex XSOAR version introduces several new features and fixes existing issues. The release notes describe these changes, as well as any known issues.

* [New Features](/xsoar-6-release-notes/6.13/new-features.md)
* [Addressed Issues](/xsoar-6-release-notes/6.13/addressed-issues.md)
