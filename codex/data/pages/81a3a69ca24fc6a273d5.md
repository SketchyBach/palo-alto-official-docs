 Panorama Support for Prisma Access 4.2 Preferred 

 The Cloud Services plugin enables Panorama to manage Prisma Access. 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Panorama) 

 Prisma Access license 

 Minimum Required Prisma Access Version 4.2 Preferred 

 Panorama Managed Prisma Access 4.2 uses the Cloud Services Plugin 4.1 Preferred 
 Cloud Services plugin. If you are running 4.1, no upgrade is required. 

 If you're using Panorama to manage Prisma Access and need to upgrade to the 4.1
 plugin, you need to: 

 Review the required software versions for Panorama to support
 Prisma Access 4.1 Preferred 

 Determine the upgrade path you'll need to follow for the Cloud Services
 Plugin 

 Upgrade the Cloud Services Plugin
