 Manually Remediate Incidents 

 Learn how to manually remediate incidents on Data Security . 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 Data Security license 

 Or any of the following licenses that include the Data Security license: 

 CASB-X 

 CASB-PA 

 By now you’ve chosen the remediation approach that works best for your organization. For a manual
 approach, use the following workflow to remediate the identified incidents: 

 Assess the new incidents, and use
the WildFire Report if necessary. 

 Close incidents that aren’t a threat to your organization. 

 Assign the incidents to other administrators on your team, if
necessary. 

 Quarantine assets that are threats. 

 Modify the incident status for the remaining incidents that
are threats.
