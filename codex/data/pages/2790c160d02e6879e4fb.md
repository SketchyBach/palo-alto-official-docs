 Set up Cortex XDR for Integration 

 Set up Cortex XDR for integration with Device Security through
 Cortex XSOAR .

 Where Can I Use This? What Do I Need? 

 Device Security (Managed by Strata Cloud Manager) 

 (Legacy) IoT Security (Standalone portal) 

 One of the following subscriptions: 

 Device Security subscription for an advanced
 Device Security product (Enterprise Plus,
 Industrial OT, or Medical)

 Device Security X subscription

 One of the following Cortex XSOAR setups:

 A free, cohosted, limited-featured
 Cortex XSOAR instance

 A full-featured Cortex XSOAR server

 When integrating Device Security with Cortex XDR , you need to generate
 a Cortex XDR API key and key ID. Use the key and key ID in addition to the
 Cortex XDR URL to allow Device Security to retrieve device information from
 Cortex XDR .

 Generate an API key. 

 Generate a Cortex XDR API key the same way for both a direct API
 integration and a third-party Cortex XSOAR integration. Depending on the
 method you use to integrate Device Security with Cortex XDR , only
 the security level of the API key you generate differs.

 For more details about creating an API key in Cortex XDR , see
 Get Started with Cortex XDR APIs .

 Log in to Cortex XDR and select Settings Configurations Integrations API Keys .

 Select + New Key , enter the following settings,
 and then Generate :

 API Security Level : Standard 

 XSOAR Security Level : Advanced 

 Roles : Instance Administrator 

 Views : Endpoint Administration 

 If you do not plan to import data through XQL,
 a Viewer role is sufficient.

 Copy the API key and note its key ID. 

 Copy the API key into a secure location and then
 click Done .

 In the API Keys table, find the number in the ID 
 column for the key you generated, and copy the ID number into a
 secure location.

 Copy the URL of the XDR server. 

 Return to Settings Configurations Integrations API Keys in Cortex XDR , right-click your API key, and then
 View Examples .

 Copy the CURL Example URL to a secure location.

 This contains your unique FQDN:
 https://api-<fqdn> 

 Continue to Set up Device Security for Cortex XDR API Integration or
 Set up Device Security and XSOAR for Cortex XDR Integration to configure
 Device Security to integrate with Cortex XDR .
