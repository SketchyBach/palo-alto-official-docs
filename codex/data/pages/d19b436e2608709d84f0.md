 Tech Support Dump Utility 

 Tech support dump utility. 

 Where Can I Use
 This? What Do I Need? 

 Prisma SD-WAN 

 Prisma SD-WAN 

 Tech support dump utility captures the information that is required to troubleshoot
 an issue offline. This utility is invoked on the Controller and captures the
 following information from the Controller and the ION device. 

 Service configuration of all the services running on the controller. 

 Last two log files of each service. 

 Thread dump of critical services. 

 Operator console audit logs. 

 System audit logs with all the commands executed on the system. 

 Navigate to Monitor Dashboard Tech Support Logs . 

 Click Generate Log . 

 Select the file name to download the log file.
