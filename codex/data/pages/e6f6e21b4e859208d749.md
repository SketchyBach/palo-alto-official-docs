 Customize Cellular Firmware 

 Learn about the customized cellular firmware. 

 Where Can I Use
 This? What Do I
 Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 The ION device and the modem store multiple carrier-specific firmware
 files. The firmware specific to AT&T, T-Mobile, and Verizon along with Generic
 (PTCRB and/or GCF certified) are pre-loaded on the modem and the ION device storage.
 The appropriate firmware is loaded on the modem based on the inserted SIM. 

 The Firmware page displays the current firmwares available on
 the modem and the current recommended firmware and version. 

 New modem firmware is available for
 ION 1200-C5G-WW and ION 1200-S-C5G-WW . 

 From the ellipsis menu, select Configure the Device and
 select Configure Interface Firmware to customize. 

 Click Customize Firmware to update the firmware. 

 Select Carrier Firmware and the corresponding version
 and click Next . 

 For Download and Update Time select whether you want to
 update the selected firmware Now or
 Later . 

 ( Optional ) Configure the Advanced 
 settings. 

 Save the changes.
