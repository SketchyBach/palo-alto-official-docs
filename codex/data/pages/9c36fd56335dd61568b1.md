 Microsoft 

 Microsoft Active Directory 

 Use Microsoft Active Directory data with Cortex Cloud. 

 Important 

 This connector is only available for tenants that onboarded after July 26, 2026. For tenants that onboarded before this date, use Marketplace to access the standalone integration. For more information, see Marketplace . 

 This connector is available with any active Cortex XSIAM, Cortex Cloud Posture Security, Cortex Cloud, Cortex Cloud Runtime Security, Cortex XDR, or Cortex AgentiX license. 

 Access and manage Active Directory users, contacts, and computers. Run Active Directory queries, manage users, and add or remove users and computers from groups.
