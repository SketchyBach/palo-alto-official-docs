 Addressed Issues in Cortex XDR Agent 8.3-CE 

 Cortex XDR agent 8.3.100-CE addressed issues 

 The following issues were resolved in this release. 

 Issue 

 Description 

 CPATR-23540 

 (Linux) 

 Fixed an issue that may prevent agents upgrading through P2P on Linux. 

 CPATR-23516 

 (Windows) 

 Improvement made to the Cortex XDR agent security and stability posture. 

 CPATR-23499 

 (windows) 

 Fixed an issue where a short time lapse may have been encountered, in certain VPN solutions, before endpoint management recognized the real-time protection status of the XDR agent after the machine boots up. 

 CPATR-23443 

 (windows) 

 Fixed a compatibility issue with 3-party applications and Cytray.exe 

 CPATR-23360 

 (Linux) 

 Fixed an issue that may be encountered when running a clean installation with a package manager on a specific system configuration, where the clean installation may be seen as an upgrade. 

 CPATR-23265 

 Fixed an issue so that files with special characters in the filename may be deleted with the destroy command. 

 CPATR-23053 

 Fixed an issue that may prevent agents from connecting when DNS resolution encounters high latency. 

 CPATR-22565 

 (Windows) 

 Improvement made to the Cortex XDR agent security and stability posture. 

 CPATR-20233 

 Fixed an issue to ensure that an interrupted scheduled scan will resume scanning as close to the scheduled timeframe as possible.
