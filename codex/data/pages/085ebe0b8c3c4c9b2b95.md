 How to review errors in Cortex Data Security 

 Review errors 

 To review errors in Cortex Data Security, do the following: 

 In the lower left part of the screen, click Settings → Data Sources. 

 On the Data Sources screen, click a cloud service provider or other data source and then click the View Details link. Alternatively, you can click the Error button near the top of the screen. This button displays the data sources that have errors. 

 In the Cloud Instances screen, click the Instance Name link. A screen displaying the instance name and related information opens. 

 In the Security Capabilities list, click Data Security Scanning to display the Errors pane with the details of the errors that were found. 

 Click Add Filters to create a filter that displays the assets you want to review. 

 Click an asset row to display a popup window with information about the error and a raw error string that you can copy. 

 Error table columns 

 Column Name 

 Description 

 Asset Name 

 The technical name of the asset. 

 Error Name 

 An explanation of the error. 

 Timestamp 

 The date and time when the error was found. 

 Region 

 The geographical location of the asset with the error. 

 Asset Type 

 The type of asset, such as an Amazon S3 bucket or an RDS database.
