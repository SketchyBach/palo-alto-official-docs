 Welcome to the Prisma AIRS administration guide. Now that you
 have successfully onboarded your Prisma AIRS security
 platform, follow this administration guide to learn how to deploy Prisma AIRS AI Runtime Network intercept and VM-Series firewalls. 

 The guide covers how to configure traffic routes, secure your workloads by creating
 security policy rules, and monitor threat logs. 

 This guide is for you if you're working with securing your complete architecture.
 Whether you're an IT professional security practitioner, developer, system
 administrator, or business leader, follow this guide to understand, deploy,
 configure, or manage Prisma AIRS and VM-Series 
 firewalls. 

 The guide covers securing diverse workloads including AI applications, containers,
 virtual machines, and serverless functions with the appropriate security platform
 based on your specific requirements. 

 Prisma AIRS AI Runtime 

 Prisma AIRS AI Runtime is a purpose-built, centralized,
 comprehensive AI security platform designed to secure the entire AI attack
 lifecycle. Prisma AIRS protects all AI and traditional
 applications, agents, models, and datasets enterprises build or use. 

 Prisma AIRS Comprehensive Security 

 Prisma AIRS provides security across three critical
 layers: in the code , at runtime , and in the cloud . It
 secures: 
 Your workloads , deployed in public, private, and hybrid clouds,
 with easy configurations and traffic routing. 

 All network traffic , including inbound, outbound, and east-west
 traffic in your cloud environment. 

 Kubernetes clusters and containerized applications. For detailed
 steps on securing container traffic, including pod-to-pod communication
 in private clouds, refer to the Secure Container Traffic in Private Cloud documentation. 

 AI and traditional applications running on virtual machines,
 containers, or cloud-native platforms. 

 Key Components 

 Prisma AIRS offers a comprehensive multi-layered
 security solution that addresses the full AI security lifecycle through these
 components: 

 Prisma AIRS AI Runtime: Network Intercept :
 An inline security intercept that provides real-time, AI-powered network
 protection. Monitors your cloud network architecture for AI-specific and
 conventional network attacks. 

 Prisma AIRS AI Runtime: API Intercept :
 Secures your AI model, AI applications, AI data, and AI agents by
 embedding Security-as-Code directly into your source code. The APIs scan
 prompts and model responses to identify potential threats
 programmatically and provide actionable recommendations. 

 AI Model
 Security : Scans all the AI models thoroughly for vulnerabilities
 and secures it before deployment to production environments. Implements
 security guards at the model registry level and establishes robust
 pre-deployment validation processes to prevent compromised models from
 reaching distribution. 

 AI Red Teaming : Prisma AIRS Provides automated AI Red Teaming
 that you can use for scanning your AI applications or agents for
 security vulnerabilities.

 Before you Begin 

 Start with activation and onboarding section to set up Prisma AIRS licenses , create a
 deployment profile in the customer support portal, meet minimum prerequisites,
 and onboard your cloud account for asset discovery. Then move on to the Discover Your Cloud Resources page to assess the risks and see what you're protecting. 

 Get Started 

 Each section in the administration guide provides step-by-step instructions to
 deploy, configure, push security policy rules to the firewall, and monitor the
 traffic logs generated by Prisma AIRS AI Runtime: Network
 intercept or VM-Series firewall. 

 Whether you're securing a single AI application or protecting an entire
 enterprise AI and legacy ecosystem, this guide will help you configure Prisma AIRS AI Runtime: Network intercept or VM-Series firewall to meet your specific security needs.
