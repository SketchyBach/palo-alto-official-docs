 Severity 

 Informational 

 Description 

 An identity updated a CloudTrail trail configuration. 

 Attacker's Goals 

 Evade detection by limiting collected data. 

 Investigative actions 

 Review the activity of the identity that modified the trail's configuration. 

 Check which trail is affected by this change. 

 Verify whether a new destination has been set for log archiving.
