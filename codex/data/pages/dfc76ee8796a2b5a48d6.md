 Switch to a Different Project 

 You can switch to a different project to access the network and organizational
 resources defined for that project. 

 Where Can I Use This? What Do I Need? 

 Prisma Agent 

 macOS 14 and later or Windows 10 version 2024 and later desktop devices 

 Internet access 

 If you're assigned to multiple projects in your organization, you can switch to
 another project to access the network and resources associated with that
 project. 

 If the project you're trying to switch to is accessible from a different server,
 you will need to switch to that server 
 first. 

 Launch the Prisma Agent by clicking the Prisma Agent 
 icon 

 from the macOS menu bar
 Windows taskbar. 

 Select a different Project . You can
 Search for a location or choose a location from the
 list. 

 You must be assigned to the project that you're switching to. 

 If your administrator enabled On Demand mode for the Prisma Agent , click the lock icon to switch projects. Otherwise,
 Prisma Agent proceeds to switching projects. 

 Each time you switch projects, Prisma Agent disconnects from the
 current project and connects to the newly selected project. You might be
 prompted to Open the Prisma Agent 
 again.
