 Generate a Report 

 Learn how to generate a SaaS Agent Security report to share with your SaaS Agent Security team and your executive management team. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 SaaS Agent Security license 

 Or any of the following licenses that include the SaaS Agent Security license: 

 CASB-X 

 CASB-PA 

 SaaS Security Posture Management license 

 From the SaaS Agent Security dashboard, you can generate a report that
 provides a high-level snapshot of your organization's AI security posture. The
 report summarizes the greatest agent risks detected across all the agentic platforms
 that you have onboarded to SaaS Agent Security . While the SaaS Agent Security dashboard helps you identify risks and offers
 instructions and actions for remediation, a SaaS Agent Security report
 provides a point-in-time summary that you can share outside of your security team.
 SaaS Agent Security generates this report as a PDF file, which you can
 download and share with interested parties, such as your chief information security
 officer and other executives. For example, you might share a report as part of a
 periodic status check-in to highlight the agents in use in your organization and the
 security risks they pose. In this way, the report serves as a useful communication
 tool between your security team and other stakeholders in your organization. The
 report fills a common visibility gap faced by leaders who require a unified,
 cross-platform view of installed agents and their associated risk levels. 

 SaaS Agent Security generates a report based on the current data displays
 in the SaaS Agent Security 
 dashboard . If security administrators recently made changes to agentic
 platforms and you want that captures in the report, wait at least one hour since the
 most recent change before generating the report. The ensures the SaaS Agent Security dashboard and report both display the most current
 data. 

 The report includes the following summary information: 

 The most frequently accessed agents across all agentic platforms. 

 The most risky agents across all agentic platforms. These are the agents where
 SaaS Agent Security detected the most risks. 

 For each agentic platform, the most risky agents and the top risk types that SaaS Agent Security detected. 

 Log in to 
 Strata Cloud Manager . 

 Select AI Security SaaS Agents . 
 In the AI
 Security menu, the SaaS Agents item is
 located in the AI AGENT SECURITY section. 

 In the upper-right corner of the SaaS Agent Security dashboard, click
 the download icon. 

 SaaS Agent Security begins generating the report. It might take a
 few minutes to generate the report. When the report is ready, it will
 display in your browser.
