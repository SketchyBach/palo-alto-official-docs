 Customize the SOC Name 

 Customize the SOC name in Cortex XSOAR 8 SaaS. 

 The default name that appears in the survey header is Your SOC team . Follow these steps to customize the name of the SOC. 

 Go to Settings & Info → Settings → System → Server Settings → Server Configuration → Add Server Configuration . 

 Add the soc.name server configuration, and the display name of your SOC as the value. 

 This name is used in the default message and email of the communication tasks, and the web survey for all communication tasks.
