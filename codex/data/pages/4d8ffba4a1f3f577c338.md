 C2C tab (app level) 

 Review Code-to-Cloud coverage and lineage across an application's assets. 

 The Topology Graph is located in the Business Applications side card. The graph visualizes the entire path to production — Code → Build → Deploy → Run — for the assets grouped into that business application, showing how the application's repositories, pipelines, images, and runtime resources are interconnected. Use the Topology Graph when assessing a business application's overall traceability posture. 

 For more information on Business Applications, refer to Application assets .
