 Upgrade Considerations for Panorama Managed Prisma Access 

 If you're using Panorama to manage Prisma Access, here's what to consider when
 upgrading to Prisma Access 5.1. 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Panorama) 

 Prisma Access license 

 Minimum Required Prisma Access Version 5.1 Preferred or
 Innovation 

 Palo Alto Networks will perform an infrastructure upgrade for 5.1 Preferred.
 Optionally, you can choose to upgrade your dataplane to 11.2 to unlock the
 5.1 Innovation features. The 5.1 release uses the 5.1 Cloud Services plugin. After you
 download and install the Cloud Services plugin 5.1, you receive all 5.1 Preferred features and all other Prisma Access features
 to date, including all previous Preferred and Innovation features ; however, a dataplane
 upgrade to PAN-OS 11.2 is required to unlock the 5.1 Innovation features. 

 To find the dates for the infrastructure upgrade, check the calendar in the Prisma SASE status page , which shows you when infrastructure upgrades
 occur. 

 To find the dates for the dataplane upgrade for your deployment, be sure that you
 have subscribed to Insights alerts from Prisma
 Access . Emails sent from Insights inform you of the time of the upgrade and its progress after
 it begins. 

 To upgrade your Cloud Services plugin to Prisma Access 5.1, use one of the following
 upgrade paths. To find your current plugin version in Panorama, select Panorama Cloud Services Configuration Service Setup and check the plugin version in the Plugin Alert 
 area. 

 Be sure to follow the minimum Panorama versions for each plugin
 version during the upgrade.
