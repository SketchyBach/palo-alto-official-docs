 Configure the Run Time for Panorama Reports 

 Panorama generates reports daily at the time
you specify. Panorama deletes any expired reports after generating
the new reports. 

 Select Panorama Setup Management and
edit the Logging and Reporting Settings. 

 Select Log Export and Reporting and
set the Report Runtime to an hour in the
24-hour clock schedule (default is 02:00; range is 00:00 [midnight]
to 23:00). 

 Select Commit Commit
to Panorama and Commit your
changes.
