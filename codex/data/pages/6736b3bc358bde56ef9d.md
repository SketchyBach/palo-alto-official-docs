 Description 

 A Soft Delete configuration was disabled on a cloud storage account. Soft delete allows a deletion of a blob or a container to be restored. Disabling it will impair the ability of the cloud environment to recover in disaster scenarios. 

 Attacker's Goals 

 Impair the ability of the cloud environment to recover in disaster scenarios. 

 Investigative actions 

 Check if the identity intended to disable soft delete for this storage account. 

 Check if the identity performed additional malicious operations in the cloud environment.
