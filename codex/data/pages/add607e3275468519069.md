 Reference A: Trust Level bands 

 This appendix lists the Trust Level bands derived from the Trust Score. Cortex Cloud recalculates the Trust Level whenever the artifact's Trust Score changes. 

 Trust Level 

 Trust Score range 

 Very High Trust 

 90 < Score ≤ 100 

 High Trust 

 75 < Score ≤ 90 

 Medium Trust 

 50 < Score ≤ 75 

 Low Trust 

 Score ≤ 50
