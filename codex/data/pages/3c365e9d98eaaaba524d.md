 Suspicious Kubernetes pod token access 

 Synopsis 

 Field 

 Value 

 Activation Period 

 14 Days 

 Training Period 

 30 Days 

 Test Period 

 N/A (single event) 

 Deduplication Period 

 1 Day 

 Required Data 

 XDR Agent with eXtended Threat Hunting (XTH) 

 Detector Tags 

 Kubernetes - AGENT, Kubernetes Credentials Theft Analytics 

 ATT&CK Tactic 

 Credential Access (TA0006) 

 ATT&CK Technique 

 Unsecured Credentials: Credentials In Files (T1552.001) 

 Severity 

 Medium 

 Description 

 A Kubernetes pod has accessed the access token of another pod. This could indicate potential unauthorized access or a security breach within the cluster. 

 Attacker's Goals 

 Gain access to the Kubernetes environment. 

 Investigative actions 

 Look for additional suspicious activities. 

 Verify if the exposed credentials were used to access the API server. 

 Investigate which operations were used against the Kubernetes cluster with the exposed credentials.
