 View VLAN Pairing Key 

 EXplains how and where you can view the VLAN attachments pairing key 

 Where Can I Use
 This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Tenant or Tenant Service
 Group (TSG) 

 Role : Multitenant
 Superuser or Superuser 

 The pairing key is a unique key that lets a service provider identify and connect to
 your Virtual Private Cloud (VPC) network and associated Cloud Router. The service
 provider requires this key to complete the configuration of your VLAN attachment.
 The pairing key is valid only for 28 days. 

 To view the pairing key value: 

 Select Telcos SP Interconnects , and select the desired interconnect. 

 Copy the pairing key.
