 Uncommon Launch Agent persistency was registered or modified 

 Synopsis 

 Field 

 Value

 30 Days

 1 Day 

 Required Data 

 XDR Agent 

 Detector Tags 

 Generic Persistence Analytics 

 ATT&CK Tactic 

 Persistence (TA0003) 

 ATT&CK Technique 

 Create or Modify System Process (T1543), Create or Modify System Process: Launch Agent (T1543.001) 

 Severity 

 Informational 

 Description 

 An uncommon Launch Agent persistence mechanism was registered/modified on the system. 

 Attacker's Goals 

 Establish persistent access to the compromised host by registering malicious code. 

 Investigative actions 

 Analyze the persistency item and determine whether it performs any malicious or suspicious actions. 

 Analyze the registered process and determine whether it performs any malicious or suspicious actions. 

 Check the events generated by the process for potential malicious behavior.
