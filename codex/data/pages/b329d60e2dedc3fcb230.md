 inspect security-policy lookup 

 Use the inspect security-policy lookup command
to identify the potential security policies for an application flow. 

 Command 

 inspect security-policy lookup (src-network-id= | dst-network-id= | srcv4= | dstv4= | srcport= | dstport= | prot-no=) 

 inspect security-policy lookup (src-network-id= | dst-network-id= | srcv4= | dstv4= | srcv6= | dstv6= | srcport= | dstport= | prot-no=) 

 Options 

 None 

 Command Notes 

 Role Super, Read Only 

 Related Commands — 

 Introduced in Release 5.6.1
