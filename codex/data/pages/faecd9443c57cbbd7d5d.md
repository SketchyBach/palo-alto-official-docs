 Data Centers and Third-Party Service Providers 

 Learn about the data centers and third-party service providers. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 Prisma SD-WAN license 

 Physical and virtual ION devices running software versions
 6.4.1 or higher 

 Palo Alto Networks engages third-party providers that act as sub-processors in
 order to provide Prisma SD-WAN. These following sub-processors are required to provide
 an equivalent level of protection of data as Palo Alto Network provides. 

 Sub-processor Name Personal Data Processed Service Type Location 

 AWS Personal data such as user name, email address, domain, IP address,
 session information IaaS Provider (cloud hosting) Australia, Ireland, Singapore, UK, USA 

 GCP Personal data such as user name, email address, domain, IP address,
 session information IaaS Provider (cloud hosting) Australia, Canada, France, Germany, India, Indonesia, Israel, Japan,
 Netherlands, Qatar, Saudi Arabia, Singapore, Switzerland, Taiwan, UK,
 USA 

 Customer Support Locations

 around the globe. For more information on these locations, please refer to the Support Services, Customer Success and Focused
 Services Privacy Data Sheet .
