 INC_RN_SITE_CAPACITY_PREDICTION 

 Learn about the INC_RN_SITE_CAPACITY_PREDICTION incident. 

 Incident Code 

 INC_RN_SITE_CAPACITY_PREDICTION 

 Title Template 

 RN site capacity is expected to increase over capacity 

 Category 

 Network and Traffic 

 Subcategory 

 Site/Tunnel 

 Description 

 A Service Connection site is predicted to reach or exceed its capacity within a specified timeframe based on current traffic and usage patterns. Proactively addressing this prediction can help prevent performance degradation and service disruptions. 

 Raise Condition 

 Incident is Raised when site capacity is predicted to exceed 90% usage for at least 14 days of the next 28 days 

 Clear Condition 

 Incident is Cleared when site capacity will not breach 90% usage for at least 14 days of the next 28 days
