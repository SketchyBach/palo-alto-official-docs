 TS Agent 9.1.5 Addressed Issues 

 Issue Description 

 WINAGENT-890 

 Fixed an issue where the User-ID agent and TS agent certificates
 were set to expire on November 18, 2024. With this fix, the
 expiration date has been extended to January 2032. 

 TS Agent 9.1.4 Addressed Issues 

 The TS agent 9.1.4 release has no updates or addressed issues. The TS agent 9.1.4
 release was provided to maintain parity with the User-ID™ agent 9.1.4 release. 

 TS
Agent 9.1.3 Addressed Issues 

 Issue Description 

 WINAGENT-677 

 Fixed an issue where a FIPS-CC mode firewall
was unable to establish a connection to the Terminal Server (TS)
agent. 

 TS Agent 9.1.2 Addressed Issues 

 The TS agent 9.1.2 release has no updates or addressed issues. The TS agent 9.1.2
 release was provided to maintain parity with the User-ID™ agent 9.1.2 release. 

 TS Agent 9.1.1 Addressed Issues 

 Issue Description 

 WINAGENT-638 

 ( Citrix PVS only ) Fixed an issue
where during failover, the Terminal Server (TS) agent host became unresponsive
during restart and needed to be restarted manually even when the Detach
agent driver at shutdown option was enabled. 

 TS Agent 9.1.0 Addressed Issues 

 This TS agent 9.1.0 release has no updates or addressed issues. The TS agent 9.1.0 release was
 provided to maintain parity with the User-ID™ agent 9.1.0 release.
