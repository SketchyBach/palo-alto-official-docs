 Activate Data Security 

 Follow these steps to set up Data Security and begin monitoring your sanctioned
 SaaS apps. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 Data Security license 

 Or any of the following licenses that include the Data Security license: 

 CASB-X 

 CASB-PA 

 Activate the Data Security License on the Activation Console 

 This procedure assumes you only need to activate the Data Security 
 license and that all prerequisite licenses are active and have successfully set
 up your Strata Cloud Manager as needed. 

 After activation, log in to the SaaS Security web interface to add your
 sanctioned SaaS apps and configure a policy to suit your needs for SaaS
 visibility and granular enforcement across all user, folder, and file activity
 within the managed SaaS apps. 

 Click the link provided to you by Palo Alto Networks when you purchase the
 Data Security subscription. 

 Enter your Palo Alto Networks Customer Support Portal (CSP)
 Email Address . This email address must match the
 email address that received the link to activate Data Security . 

 In the Manage Subscriptions page, choose the product
 you want to activate and Activate . 

 On the activation page, specify the tenant, region and Activate
 Now to begin activating Data Security . 

 After the activation is complete, you will receive the following email.
 Also, you can either View Details of the subscription
 or Launch your Data Security instance from
 the Manage Subscriptions page.
