 Known Issues in ION Device Release 6.1.1 

 Learn about the known issues in ION Release
6.1.1. 

 The following list includes outstanding
known issues specific to ION release 6.1.1. 

 Issue ID Description 

 CGSDW-8389 tunnels configured manually will
not support ADEM. 

 CGSDW-10819 On switching platforms, multicast packets,
 such as an LLDP packet, received on one interface of a bypass pair will
 loop between the two interfaces of the bypass pair. The workaround is to
 upgrade the device to version 6.1.2 or higher. 

 CGSDW-12698 Network reachability for WAN to LAN traffic failing for
 non-CGNX sites. 

 CGSDW-12733 DPD with IKEv2 on Standard VPN does not bring the tunnel
 down based on the configuration on the DPD timer. 

 CGSDW-14432 The fp-rte process crashes when
 fetching information on security policy counters and app stats.
