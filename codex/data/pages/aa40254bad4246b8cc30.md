 inspect wanpaths 

 Use the inspect wanpaths command
to inspect the VPN WAN paths from the controller and displays all
VPN WAN paths on a device sent by the controller. 

 Command 

 inspect wanpaths ( all | site-id = site id | path-id = path id | vrf-name= | vni= ) 

 Options 

 all Enter all to display all VPN paths for a device. 

 site-id Enter the site-id to display the VPN path for
a specific site. 

 vrf-name Enter the vrf name to filter VPN paths between this
 device and a specific remote site. Release 6.3.1 

 vni Enter the vni to filter VPN paths between this device
 and a specific remote site. Release 6.3.1 

 path-id Enter the path-id to display a specific VPN
path. 

 Command Notes 

 Role Super, Read Only 

 Related Commands — 

 Introduced in Release 4.4.1
