 Use the Prisma Agent App on managed devices on iOS. 

 Where Can I Use This? What Do I Need? 

 Prisma Agent 

 iOS 16 and later versions 

 Internet access 

 If your iOS endpoint is managed by a mobile device management (MDM) system, your
 administrator may have automatically pushed the Prisma Agent to your endpoint
 and configured the agent. 

 Open the Prisma Agent app by tapping the Prisma Agent app icon
 ( 

 ). 

 The agent gets connected based on the connect method configured by your Prisma Agent administrator through mobile device management (MDM) software only . Prisma Agent supports the following connect
 methods: 

 Always-On 
 In an Always-On configuration, Prisma Agent automatically connects as soon as you log in. 

 On-Demand 
 In an on-demand configuration, you
 must manually connect Prisma Agent through the application.
 Traffic is routed through the Prisma Agent app only after you
 initiate and establish the connection. 

 Automatic Configuration 
 Per-App 
 In a per-app configuration,
 your administrator can configure the managed apps that will
 route traffic through Prisma Agent . When you access
 the managed app, Prisma Agent will automatically
 connect and only traffic for the managed apps your
 administrator has configured under the configuration profile
 will be routed through Prisma Agent . 

 On-Demand Connect Rules 
 In an on-demand
 connect rules configuration, while you can manually initiate
 a connection to the Prisma Agent , administrators can
 also configure Prisma Agent to connect automatically
 when you access a specific domain. 

 After a first-time installation, the Prisma Agent does not
 automatically connect to Prisma Access, even if your administrator
 configured Always On mode. You must log in to complete your initial
 enrollment, which includes entering the server address that you have
 obtained from your IT administrator. The enrollment process is similar
 to Use the Prisma Agent App for iOS (Unmanaged Devices) . 

 After this first login, Always On mode takes effect and the agent
 connects automatically on subsequent logins.
