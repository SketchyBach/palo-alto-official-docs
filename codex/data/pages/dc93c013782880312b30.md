 Changes to Default Behavior 

 Familiarize yourself with the changes to default behavior
introduced in the Windows User-ID™ agent 10.0 release. 

 The Windows User-ID Agent 10.0 release has the following
change in default behavior: 

 User-ID 10.0.2 and later releases for Windows no longer create
mappings for machine events by default.
