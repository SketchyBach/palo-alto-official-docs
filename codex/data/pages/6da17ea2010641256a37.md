# Data Exfiltration Instruction

Data Exfiltration Instruction

Severity

🔵 Low (2)

Short Description

Flags AI extensions that instruct the agent to send workspace data, source code, secrets, or AI chat conversations to external services or URLs.

Suggestion

Identify the destination and confirm it is a service you intend to send data to. Many components legitimately call external APIs. Remove or replace the component if the destination is undisclosed or unapproved.

Information

This finding covers instructions that send data outward — telemetry, workspace metadata, file contents, or conversation context transmitted to an external endpoint. It is scoped to lower-sensitivity data flows; when the analyzer identifies high-sensitivity material such as credentials, private messages, or bulk source code, it raises Sensitive Data Exfiltration Instruction instead, at a higher severity.

Outbound data flow is normal for a large share of useful components — documentation lookups, package registry queries, and error reporting all send something outward. The concern is destinations you did not choose and did not disclose: an endpoint that is not the component's documented service, particularly a raw IP address, a URL shortener, or a domain unrelated to the publisher.

Risks

Undisclosed destinations: Data may reach a third party the organization never evaluated or approved.

Aggregation: Individually harmless metadata becomes revealing when collected across many sessions and users.

Compliance exposure: Workspace content leaving the environment can breach data residency or contractual obligations.

Scope drift: What starts as anonymous telemetry can widen to file contents in a later version.

Recommended Actions

Investigate the component

Read the evidence to identify the destination endpoints and the data being sent.

Verify each destination against the publisher's documented services.

Check the publisher's privacy policy for a matching disclosure.

Contain and remediate

Block unapproved destinations at the network or proxy layer.

Disable optional telemetry where the component supports it.

Remove the component if data is sent to an undisclosed or unapproved destination.
