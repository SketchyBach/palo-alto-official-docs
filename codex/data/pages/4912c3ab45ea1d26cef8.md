 Strata Cloud Manager uses the Unified Incident Framework to
 centralize incident management and provide a more contextual experience. The
 product-specific alerts and incidents are now located under Incidents . The previous Alerts & Incidents
 dashboard remains available in read-only mode for reference. 

 In Strata Cloud Manager , select Incidents Prisma Access ServiceNow Audit Log to view the ServiceNow Audit Log . This table shows
 each incident ID and the ServiceNow operations performed on each Incident, such as
 create, update, and delete. View the timestamp, which shows when an Incident operation
 started, the operation's status, and a message about this operation. See Integrate ServiceNow with Strata Access for
 information about ServiceNow and how to integrate it into your SASE environment.
