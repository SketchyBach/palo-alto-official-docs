 XSOAR 6.13 Multi-Tenant 

 Disable Propagation Labels 

 In Cortex XSOAR 6.13, disable propagation labels and automatically sync tenant content. 

 By default, propagation labels are enabled. When you disable propagation labels, content is automatically synced from the main account to tenant accounts. 

 In the main account, go to Settings → About → Troubleshooting . 

 In the Server Configuration section click +Add Server Configuration . 

 Set the selective.propagation.enabled key to false .
