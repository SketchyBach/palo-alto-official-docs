 Features Introduced in 2025 

 November 2025 

 Release Highlights 

 Feature 

 Description 

 Flexible Customization for Analytics Rules 

 Align detection rules with your organization's unique risk profile. You can now easily adjust the severity of the alerts generated by our powerful, built-in analytics rules. 

 XDR Agent for Windows on ARM64 

 Extend agent deployments to Windows devices running on ARM64 architecture, including Microsoft Surface devices. 

 ML-Based JScript File Examination 

 Enhance your defense against script-based threats with a new machine-learning protection module for the XDR Agent on Windows, trained to analyze and block malicious JScript files before they can execute or when written to disk. 

 Malicious LDAP Query Protection 

 Identify and block malicious reconnaissance activity targeting Windows Domain Controllers. Customers with the ITDR add-on can now use the XDR agent for real-time prevention against attack techniques used by tools like BloodHound's SharpHound collector. 

 Forensics for Linux 

 Forensic customers can now run complete investigations across Windows, macOS, and Linux, with deeper artifact collection and analysis from Linux endpoints.
