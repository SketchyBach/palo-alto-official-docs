 What's an IOC? 

 Notice 

 Managing IOCs requires a Cortex XDR Pro license. 

 Indicators of compromise (IOCs) enable Cortex XDR to generate issues about known malicious objects on endpoints across the organization. You can load collections of IOCs from threat-intelligence sources into Cortex XDR or define them individually. 

 Note 

 Cortex XDR supports a maximum of 4,000,000 IOCs. 

 You can define the following types of IOCs: 

 Full path 

 File name 

 Domain 

 Destination IP address 

 MD5 hash 

 SHA256 hash 

 After you load or define IOCs, the tenant checks for matches in the xdr_data dataset that contains all the information collected about the endpoints and the network. Cortex XDR looks for IOC matches in all data collected in the past and continues to evaluate any new data it receives in the future. 

 Issues for IOCs are identified by the source type of the IOC.
