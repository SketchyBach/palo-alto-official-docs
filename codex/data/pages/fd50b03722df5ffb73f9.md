 PAN-OS 10.1.14-h13 Addressed Issues 

 PAN-OS® 10.1.14-h13 addressed issues. 

 Issue ID Description 

 PAN-269155 

 Fixed an issue where an OOM condition occurred, which caused
 processes to stop responding. 

 PAN-265434 

 Fixed an issue where the flow process restarted with the error
 message SIGABRT __GI_raise __GI_abort __libc_message
 malloc_printer . 

 PAN-257960 

 Fixed an issue where ICD's virtual memory continuously increased due
 to an increase in unknown IP addresses, which resulted in high
 management plane CPU utilization. 

 PAN-256867 

 Fixed an issue where the logrcvr process stopped
 responding while processing session logs for forwarding to the
 LFC. 

 PAN-245428 

 Fixed an issue where FIB entries aged out and were incorrectly
 removed after an HA failover event.
