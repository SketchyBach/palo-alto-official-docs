 Release Notes for Cortex XDR App for Android 

 Release notes for Cortex XDR agent app for this Android release. 

 Features Introduced in Cortex XDR App for Android 

 Cortex XDR agent App for Android Version 9.0.1 

 This release contains the following update: 

 Mandatory update: This release includes an essential connectivity update to ensure uninterrupted and secure connectivity to Cortex XDR. 

 Cortex XDR agent App for Android Version 9.0.1 

 This release contains the following updates: 

 Bug fix: Resolved an issue with rare 410 responses (reregistration) 

 General bug fixes and tweaks 

 Mandatory connectivity improvements 

 Cortex XDR agent App for Android Version 9.0 

 This release includes the following new feature: 

 Share any suspicious URL directly to the Cortex XDR app for an instant security verdict. 

 Changed Features 

 Cortex XDR agent App for Android Version 9.0 

 This release includes the following change: 

 From Cortex XDR agent for Android version 9.0 and later, the part of the module which performs local analysis on the Android device itself is deprecated. APK analysis will be handled only by Wildfire.
