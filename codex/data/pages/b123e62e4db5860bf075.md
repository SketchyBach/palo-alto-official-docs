 VM-Series on Google Cloud Platform - Supported GCP Instance Types 

 This table outlines the compatibility and technical requirements for deploying the
 VM-Series firewall on specific Google Cloud Platform (GCP) compute
 infrastructure. 

 GCP Instance Family Supported Instance Types Minimum PAN-OS Version Notes 

 Compute Optimized (C-Series) C3, C4 (Standard, High-CPU, High-Mem) 

 11.2.8 or later 

 12.1.5 or later 

 High-performance instances for compute-bound workloads. 

 General Purpose (N2) N2, N2D 10.1 or later Standard migration path for older N1 deployments. 

 For VM-Series deployments on Google Cloud, gVNIC support is
 required for C4 instances. A minimum version of PAN-OS 12.1.5 or
 later (or 11.2.8 or later in the 11.2 branch) is required to ensure
 full compatibility with these instance families. 

 In the C-Series, only Standard C3, C4 instances are supported.
