 service.

 ADEM or Strata Cloud Manager Pro

 ( Browser-Based Real User Monitoring (RUM) ) Prisma Access Browser

 Autonomous Digital Experience Management (ADEM) provides native, end-to-end visibility and insights for all
 Prisma Access mobile user traffic. ADEM is an add-on service
 that you can purchase for Prisma Access , and it is available for: 

 Prisma Access Managed by Strata Cloud Manager — Autonomous DEM is currently supported
 for Cloud Managed Prisma Access mobile user
 deployments . After you purchase the service it is automatically
 available within the Strata Cloud Manager app on the hub. 

 With Strata Cloud Manager , you can review ADEM data in the all new Command Center or in Activity Insights . 

 Prisma Access Managed by Panorama — Autonomous DEM is currently supported for the
 Panorama-managed Prisma Access Mobile User deployments. After you purchase
 the ADEM service it is automatically available within the Prisma Access app
 on the hub. Autonomous DEM is supported starting with the 2.0 innovation
 and the 2.2 Preferred releases. Refer to this section for details. After
 purchasing and provisioning the Autonomous DEM license on Panorama, you can
 manage the service and review experience scores for your network and your users
 from Strata Cloud Manager . 

 Prisma Access Browser — Install the ADEM Browser Plugin on Prisma Access Browser 
 to enable Browser-Based Real User Monitoring (RUM) , which gives you insight into users' real-time
 interactions with web applications.
