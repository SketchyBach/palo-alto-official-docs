 Windows Features 

 Describes the new features introduced in Cortex XDR agent 8.7 release. 

 The following section describes the new features that were introduced in Cortex XDR agent 8.7 releases according to the supported agent operating systems. 

 Windows Features 

 The following features were added to Cortex XDR agents running on Windows endpoints: 

 Feature 

 Description 

 Protection against security bypass techniques 

 Enhanced protection for Windows-based endpoints ensures your organization is safeguarded against malicious actors attempting to bypass Windows built-in security controls. Protecting endpoints from the latest malicious tactics. 

 Protection against malicious ASP and ASPX files 

 For Windows-based endpoints, you can now configure Cortex to analyze ASP and ASPX files, and prevent malicious ones from being written to your endpoints’ file system. 

 Performance improvements 

 Enhanced performance when running SQL queries.
