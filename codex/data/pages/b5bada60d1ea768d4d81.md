 Approaching Max Capacity - Dataplane CPU 

 Incident Code 

 INC_NGFW_CAPACITY_DATAPLANE_CPU 

 Severity 

 Warning 

 Category 

 Device 

 Subcategory 

 System Resources 

 Product 

 Supported on NGFWs and VM-Series firewalls. 

 Description 

 The data plane (DP) CPU usage has been consistently high over time and is
 approaching the maximum capacity that the device can support. 

 Raise Condition 

 This incident is triggered when the highest daily average DP CPU usage exceeds 90%
 on five or more days within the last seven-day period 

 Clear Condition 

 This incident is cleared when the highest daily average DP CPU usage is less than
 90% for two weeks
