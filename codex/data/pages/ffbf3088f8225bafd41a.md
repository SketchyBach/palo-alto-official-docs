 Cortex XDR Agent App for iOS Requirements 

 Learn about requirements for the Cortex XDR Agent app for iOS. 

 The Cortex XDR Agent app for iOS has the following requirements. 

 Requirement 

 Specification 

 Operating system versions 

 This version of Cortex XDR Agent requires iOS 16.0 or later on the mobile device. In general, to determine the minimum Cortex XDR release for a specific operating system, refer to the The Palo Alto Networks Compatibility Matrix. 

 Device permissions 

 Device permissions are required for correct operation of the Cortex XDR Agent app. 

 Notifications 

 Location 

 (only mandatory for stationary iOS-based devices mapped to a policy that raises events when a device is moved from its designated location) 

 Background App Refresh (enabled by default. May be off in low power mode) 

 Enable Extensions 

 These extensions can be enabled during onboarding. They are optional, and the user controls whether to use them: 

 SMS/Call reporting 

 Call blocking and identification 

 SMS filtering 

 Cortex XDR widget 

 When the Network Shield module is not used, use the Cortex XDR widget on the device, to ensure correct app behaviors. 

 Note 

 If any of the required permissions on the iOS device are turned off, Cortex XDR shows Partially Protected on the Home screen.
