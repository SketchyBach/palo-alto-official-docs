 Installation Kit Components 

 Check the installation kit components of the ION 5200 device. 

 The ION 5200 device installation kit contains the following parts and tools
 to install the device: 

 1x ION 5200 device ships with 2x 450W built in PSU. 

 2x power cord, AC, which varies depending on the country or region. 

 1x USB 2.0 to RJ45 Console cable. 

 1x Shielded RJ-45 CAT6 Ethernet cable. 

 1x Velcro 

 1x Rack mount kit. 

 2x 1RU mounting ears (left and right) 

 2x Adjustable 1RU mounting brackets (left and right) 

 2x Rear support brackets 

 13x #6-32 x 5/16” rack-mount screws 

 9x #10-32 x 3/4” rack-mount screws 

 9x #12-24 x 1/2” rack-mount screws 

 8x #10-32 nut cages
