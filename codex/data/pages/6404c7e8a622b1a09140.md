 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Tenant or Tenant Service
 Group (TSG) 

 Role : Multitenant
 Superuser or Superuser 

 The SP Interconnect page provides a consolidated view of all configured
 interconnects, including key information such as interconnect type, associated tenants,
 and current operational status. This view helps you quickly monitor the health and
 connectivity state of each interconnect. 

 In addition, you can view summary information showing the number of interconnects per
 cloud service provider (such as GCP or AWS) and how many of them are currently active.
 This helps you track deployment distribution and monitor overall connectivity status
 across cloud environments. 

 To access the page, navigate to Telcos SP Interconnect . You can view the following details for each interconnect: 

 Fields Description 

 Name Name of the Interconnect 

 Type Indicates the physical or logical link method used to
 establish connectivity between the Service Provider (SP) network and
 Prisma Access: Dedicated or Partne r. 

 Usage Indicates how the interconnect resource is consumed and
 partitioned across customer environments: Per-Tenant or
 Shared . 

 Tenant Name Name of the tenant associated with the interconnect 

 Tenants Count Number of tenants associated with the interconnect. 

 Resources Details of the resources, such as the number of VLAN
 attachments present and the IP pool type. 

 Compute Region The compute region where the interconnect is
 deployed. 

 Status Interconnect status: Active or Inactive 

 Cloud Provider Cloud providers: AWS or GCP 

 Actions Delete the interconnect
