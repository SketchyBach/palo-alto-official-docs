 Reference B: Essential filtering rules 

 When constructing Unified Asset Inventory filters, follow these rules to avoid blank tables. 

 Rule 1: The Boolean AND trap 

 When selecting multiple values in Development Cycle Stages , use the OR operator. 

 The system assigns each asset one furthest-reached stage. An asset cannot simultaneously have Build and Runtime as its furthest stage. Using AND returns an empty table. 

 Rule 2: Empty ( NULL ) values represent untraced assets 

 A blank Development Cycle Stages field means the periodic background job has not calculated lineage yet. 

 An untraced Not Contains filter cannot match blank fields before the tracing job runs. The Code-to-Cloud Coverage dashboard counts empty or NULL values as untraced.
