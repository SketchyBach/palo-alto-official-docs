 PA-800 Series Electrical Specifications 

 The following table describes PA-800
Series firewall electrical specifications. 

 Specification Value 

 Power supplies 
 PA-820 firewall—One fixed AC 200W power supply. 

 PA-850 firewall—Two AC 450W power supplies. One power supply
is redundant. 

 Input voltage 100-240VAC (50-60Hz) 

 Power consumption 
 PA-820 firewall 

 Average—41W 

 Maximum—120W 

 PA-850 firewall 

 Average—64W 

 Maximum—240W 

 Maximum current consumption 
 PA-820 firewall—1.0A@100VAC, 0.5A@240VAC 

 PA-850 firewall—2.0A@100VAC, 1.0A@240VAC 

 Maximum inrush current 
 PA-820 firewall—0.4A@230VAC, 0.96A@120VAC 

 PA-850 firewall—1.0@230VAC, 1.84A@120VAC
