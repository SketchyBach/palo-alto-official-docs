 Device Security Known Issues in August 2025 

 Issue ID Description 

 DIT-59602 

 Security Policy Rules have duplicate source or destination
 IP addresses when creating Security Policy Rules from
 Strata Cloud Manager Manage Configuration IoT Policy Recommendation .

 Workaround 

 To create Security Policy Rules in Strata Cloud Manager , always
 access Strata Cloud Manager Insights Device Security Policies . There are two possible
 Policies tab, depending on if you use
 Strata Cloud Manager or PAN-OS and
 Panorama for firewall management.

 Device Security Known Issues in July 2025 

 Issue ID Description 

 DIT-57056 

 Policy Recommendations can be out of sync in Strata Cloud Manager 
 when viewing Strata Cloud Manager Manage Configuration IoT Policy Recommendation . It is not recommended to use that page for
 Policy Recommendations

 Workaround 

 To view Policy Recommendations in Strata Cloud Manager , always
 access Strata Cloud Manager Insights IoT Security Policies . There are two possible
 Policies tab, depending on if you use
 Strata Cloud Manager or PAN-OS and
 Panorama for firewall management.
