 Known issues in Network Discovery plugin 3.0. 

 Where Can I Use This? What Do I Need? 

 NGFW (Managed by PAN-OS or Panorama) 

 One of the following subscriptions: 

 Device Security subscription

 Precision AI bundle subscription

 Device Security X subscription

 The following list includes all known issues that impact a Device Security 
 Network Discovery plugin 3.0 release. This list includes both
 outstanding issues and issues that are addressed, as well as known issues that apply
 more generally or that are not identified by a specific issue ID.

 BAN-25724 

 DIT-63601, PAN-303996 

 The neighbor discovery and data refreshment jobs failed to discover endpoints.

 This issue is resolved in Network Discovery plugin 3.0.1. 

 BAN-25638 

 DIT-64256 

 The Network Discovery plugin failed to identify the new Device Security license.

 This issue is resolved in Network Discovery plugin 3.0.1. 

 BAN-22750 

 The Network Discovery plugin reports all timestamps as Pacific Time, instead of
 the firewall's configured time zone.
