 LLDP Overview 

 LLDP allows the firewall to send and receive Ethernet
frames containing LLDP data units (LLDPDUs) to and from neighbors.
The receiving device stores the information in a MIB, which can
be accessed by the Simple Network Management Protocol (SNMP). LLDP
enables network devices to map their network topology and learn
capabilities of the connected devices, which makes troubleshooting
easier—especially for virtual wire deployments where the firewall would
typically go undetected in a network topology.
