 show cluster all-peers 

 Description 

 On a WildFire appliance
cluster controller node, display the status of all WildFire appliance
cluster members, including the WildFire appliance mode (controller
or worker), connection status, and application service status. 

 Hierarchy Location 

 show cluster 

 Syntax 

 all-peers; 

 Options 

 No additional options.
