 Addressed issues in Cortex XDR agent 8.6 release for Windows, macOS, and Linux. 

 The following issues were resolved in this release. 

 Feature 

 Description 

 CPATR-26119 

 (Linux) 

 Fixed an issue where in a rare scenario, the SPMD process may demonstrate a high CPU consumption during content update. 

 CPATR-25760 

 Fixed an issue that in rare circumstances may cause the NMAP distributed network scan to function incorrectly. 

 CPATR-25549 

 (Windows) 

 Fixed an issue that may cause the driver verifier to function incorrectly. 

 CPATR-25536 

 (Windows) 

 Fixed an issue that may cause the print monitor service to halt if no print job node is matched. 

 CPATR-25295 

 (Linux) 

 Improvement made to the Cortex XDR agent security and stability posture. 

 CPATR‑25268 

 (Windows) 

 Fixed an issue to improve the Cortex XDR agent security and stability posture. 

 CPATR-25193 

 (Linux) 

 Fixed an issue that may occur after AWS Kubernetes Bottlerocket cluster is upgraded to 1.30. 

 CPATR-25063 

 (Windows) 

 Fixed an issue where false-positive alerts may be encountered due to policy reset during an agent upgrade. 

 CPATR-25048 

 (Linux) 

 Fixed an issue to improve the output of the Cytool scan query command. 

 CPATR-24965 

 (Linux) 

 Fixed an issue where a finish scan report may not have been sent to the server on the completion of a scan. 

 CPATR-24856 

 Fixed an issue where on rare occurrence of an ungraceful agent shutdown, the agent may not report some agent settings accurately, and would report defaults instead.
