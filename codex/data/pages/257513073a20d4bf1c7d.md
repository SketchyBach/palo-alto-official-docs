 Known Issues in ION Device Release 6.1.6 

 Learn about the known issues in ION Release
 6.1.6. 

 The following list includes outstanding known issues specific to Prisma
 SD-WAN ION release 6.1.6. 

 Issue ID Description 

 CGSDW-7806 The DHCP Relay chooses the secondary IP address instead
 of the primary IP address for sending a DHCP request. 

 CGSDW-15027 Incorrect SNMP interface bandwidth reported after a
 software upgrade from ION device version 5.6. 

 CGSDW-15967 High memory consumption by the ADEM process causes ION
 device reboot. 

 CGSDW-16922 The fp-rte process crashes after a
 software upgrade to ION device version 6.1.5-b7. 

 CGSDW-18905 First flow of direct VNC traffic gets denied as the
 server port in the ION app-def is 0-0. 

 CGSDW-19237 FC crashes due to stack corruption in ION 5200. 

 CGSDW-19357 When a DC ION receives routes for a /32 prefix from both
 the underlay and overlay, the DC ION tries to split the route and thus
 the BGP route selection process fails. 

 CGSDW-19707 ADEM tests are not being performed on Prisma Access
 tunnels.
