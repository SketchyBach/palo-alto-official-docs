 Onboard SaaS Agents 

 Learn about onboarding SaaS agents in Prisma AIRS. 

 Where Can I Use This? What Do I Need? 

 Prisma AIRS AI Runtime Security 

 Prisma AIRS AI Runtime:
 Network Intercept Prerequisites and Limitations

 A SaaS agent fails to appear in the dashboard if the tenant does not have the
 appropriate license: 

 In addition, the Onboard AI Agent Platform section of the
 Onboard Cloud Account screen displays no SaaS agents: 

 Onboard a SaaS Agent 

 If a SaaS license has been associated with a tenant, it appears in the SCM
 dashboard; to determine if a SaaS license was configured: 

 Log into Strata Cloud Manager (SCM) . 

 In SCM, select Insights > AI Agent Security > SaaS
 Agents. 

 To configure the SaaS agent, select the SaaS Agent 
 icon: 

 If the tenant has the appropriate SaaS license, you can onboard a
 new SaaS agent cloud account at any time by selecting the
 Cloud Account icon in the upper right
 portion of the AI Agent Discovery 
 dashboard: 

 Click Add Cloud Account : 

 Use the Onboard Public Cloud Account page to
 onbouard your SaaS agent: 

 After you have successfully onboarded your SaaS agent you can use the SCM
 dashboard to configure it. 

 In the SaaS Agent Security page, use the Recommendations
 section to configure actions for the agent:
