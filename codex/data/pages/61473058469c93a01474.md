 Configure an IP Community List 

 Configure an IP Community List in Prisma SD-WAN. Use IP community lists to filter route
 maps based on community settings a branch or data center ION device permits or denies
 routes. 

 Where Can I Use
 This? What Do I
 Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 Configure a filter community list to reference in a BGP route to match on BGP community
 attributes of routes that you want to control in the same way. You can also
 reference a community list in a BGP route map to remove communities from routes that
 meet the match criteria or to match BGP communities in routes that you want to
 redistribution using a Redistribution route map. Use IP community lists to filter
 route maps based on community settings. Based on the community string, a branch or
 data center ION device permits or denies routes. 

 A community list can have multiple rules; routes are evaluated against the rules in
 sequential order. When a route matches a rule, the deny or permit action on occurs
 and the route isn’t evaluated against subsequent rules. 

 Select Configuration Prisma SD-WAN ION Devices Claimed Configure the device Routing BGP/Peers IP Community Lists Create IP Community List . 

 On the Info screen, enter a name,
optional description, and tags for the IP Community list. 

 On the Entries screen, specify
a Community String and then select Permit or Deny . 

 If you modify an associated Prefix List , AS
 Path List , or IP Community List , you
 must perform a soft reset on the corresponding BGP peer for the changes to
 take effect on advertised or received routes. The soft reset causes BGP to
 re-evaluate its routing policies for that peer without tearing down the
 BGP/TCP connection. 

 Click Save & Exit .
