 AI Detection & Response in Cortex XDR 

 Collect prompt logs 

 Collect prompt logs for AI-driven detection and response. 

 Cortex XDR collects prompt logs from your cloud accounts using existing data collectors. Currently, AWS and Azure are supported by Cortex XDR for prompt log collection. At this time, GCP does not have a storage solution for AI prompts that allows Cortex XDR to ingest them. 

 For details on dataset retention, see Cortex XSIAM product licenses .
