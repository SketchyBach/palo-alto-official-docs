 How to submit a content feature request in Cortex XSOAR 6x. 

 You can submit content feature requests to your Account Team or Customer Success Team. 

 To ensure we fully understand your needs, include the following information: 

 For a new integration or integration enhancement: 

 Product details 

 Name and version of the product you want to integrate with. 

 The deployment type for the product (SaaS, Hybrid, On-premise). 

 API documentation and specific needed API calls (if available). 

 Use case details for the new integration or integration enhancement 

 High-level description of what you want to achieve. For example, While analyzing a phishing incident, I would like to utilize the integration to detonate the attached file . 

 Specific workflows or tasks the integration will support. 

 Examples of relevant incidents or commands. 

 Integrations that will be used as part of the use case. 

 For a new use case request 

 Describe the use case flow. 

 Provide a list of integrations you would like to be supported as part of the use case (if available). 

 Describe what data needs to be extracted or what actions are to be triggered. 

 Share any relevant flow charts or example playbooks you may have created.
