 DR Scenario: Unrecoverable Standby Server Failure 

 Replace an unrecoverable standby server in a Cortex XSOAR 6.14 live backup environment. 

 In the event of an unrecoverable standby server failure (flooding, fire, meteor impact, hardware failure, etc.), follow these steps. 

 Before you begin, ensure that you Configure the Live Backup Environment . 

 Obtain the new server that will serve as your new standby server according to your requirements. 

 Do not install until step 2. 

 Follow the procedure for Configure the Live Backup Environment using the newly-active server as the primary host, and by copying its files and data to the newly-built Cortex XSOAR server. Confirm that Live Backup is working. 

 Test the new server by following the steps in DR Scenario: Testing the DR Environment .
