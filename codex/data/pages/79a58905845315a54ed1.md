release available specifically for SD-WAN 1.0.2 plugin customers.
This release is required for the SD-WAN 1.0.2 plugin. 

 Issue ID 

 Description 

 PAN-144073 

 Fixed an issue where on the Panorama management server,
hub and branch firewall latency, jitter, and packet loss data was
not updated when monitoring SD-WAN link performance ( Panorama SD-WAN Monitoring ).
