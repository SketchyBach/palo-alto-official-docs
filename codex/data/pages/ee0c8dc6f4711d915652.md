 Release Highlights 

 The Cortex XSIAM 3.2 release includes the following highlights: 

 Feature 

 Description 

 Advanced Email Security 

 (Requires a Cortex XSIAM Premium, Cortex XSIAM Enterprise, or Cortex XSIAM NG SIEM license) 

 Stop sophisticated email attacks in real time with AI-based intent analysis and automated response - catching what other tools miss. 

 AI-Powered Exposure Management 

 (Requires a Cortex XSIAM Premium, Cortex XSIAM Enterprise, or Cortex XSIAM NG SIEM license) 

 Cut vulnerability noise by up to 99% with AI-driven risk prioritization and automated remediation spanning the entire enterprise. 

 Generic Webhook Integration Enhancements 

 Easily ingest external data without custom APIs, using a simplified setup and support for header-based authentication. 

 Ticket Synchronization 

 Seamlessly integrate with ticketing systems such as Jira and ServiceNow to improve collaboration across security and cloud development teams. 

 Enhanced Analytics Insights 

 (Requires a Cortex XSIAM Premium, Cortex XSIAM Enterprise, or Cortex XSIAM NG SIEM license) 

 View the full list of detections behind the analytics and behavioral indicators of compromise (BIOCs) directly in the Cortex XSIAM console, so you can instantly understand why alerts were triggered. 

 Extended Scope-Based Access Control (SBAC) 

 Adhere to your company’s security policies by specifying which groups of assets users can access and what actions they can perform.
