 Customize Incident Settings by Code Level 

 Learn how to customize incident settings by code. 

 Where can I use
 this? What do I need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 AI-Powered ADEM license 

 Autonomous DEM license 

 Prisma Access license 

 Strata Cloud Manager uses the Unified Incident Framework to
 centralize incident management and provide a more contextual experience. The
 product-specific alerts and incidents are now located under Incidents . The previous Alerts &
 Incidents dashboard remains available in read-only mode for reference. 

 Select Customize for this incident category. 

 Select Open Advanced Settings to customize Incident
 Codes at the bottom of the widget. All incidents in this
 category appear by incident code. 

 Select an individual incident code, and select
 Customize . 

 Under Incident Generation Settings Incident Generation , select Enable Incident ,
 Disable Incident , or Disable for a Time
 Range . Then select one of the following: 

 Use the drop-down to see available remote networks, and select the ones
 you want this customization to apply to. 

 Use the drop-down to select one or more notification profiles to
 associate with this customization. 

 Select Save Customization . The remote networks
 incidents category lists all customizations to the category and to
 incidents. 
 Once you have customized incident codes, you can't make
 changes to the category. 

 If needed, select Revert
 to Default in the code to reset the code to default.
 You can then customize at the category level again, if
 needed.
