 Cheat Sheet: Manage Prisma Access by Using Panorama 

 Learn how to use Panorama to manage your Prisma Access deployment 

 Where Can I Use This? What Do I Need? 

 Panorama 

 Prisma Access License 

 You can manage your Prisma Access deployment using either Panorama or Strata
 Cloud Manager. 

 The set of supported features is not identical across Prisma Access managed by
 Panorama and Prisma Access managed by Strata Cloud Manager. Refer to the compatibility metrics to determine which
 features are supported with each option. This helps you decide on the management
 interface. 

 Important: You cannot switch management interfaces after you activate
 your Prisma Access license. Therefore, determine your interface choice before you
 start. 

 For a comprehensive overview of Prisma Access features and management options,
 refer to Prisma Access Overview .
