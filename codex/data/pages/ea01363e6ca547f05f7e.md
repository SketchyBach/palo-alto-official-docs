 Upgrade ION 9000 Firmware for Device Version 5.6.x 

 Upgrade ION 9000 firmware. 

 If you have ION 9000 data center devices on
software version Release 5.6.x, upgrade the firmware driver that
is impacted due to enabling of the DPDK, by following the below
mentioned steps. 

 From the CLI toolkit commands, stop the FC. Execute
the following command: 
 debug process stop name=fc 

 debug process stop name=fc
9K# debug process stop name=fc
Do you really want to stop fc [y/n]: y
fc: stopped 

 From the CLI toolkit command, execute the following command
to upgrade the device firmware: 
 ion9000 upgrade-x722-fw 

 9K# ion9000 upgrade-x722-fw
Will upgrade from 4.11 to 5.10
This will take about 20 minutes and then reboot the device

DO NOT INTERRUPT THIS COMMAND ONCE IT STARTS
Do not log out, shut down, or hit control-C.
Ensure power is not removed during this process.

Agree [Y/N]? Y
