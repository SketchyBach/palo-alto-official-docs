 Onboard a Hellonext App to SSPM 

 Connect a Hellonext instance to SSPM to detect posture risks. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 SaaS Security Posture Management license 

 Or any of the following licenses that include the Data Security license: 

 CASB-X 

 CASB-PA 

 In August of 2023, Hellonext was renamed to featureOS.
 Although the Hellonext interface was rebranded as featureOS, the following
 instructions still apply. 

 For SSPM to detect posture risks in your Hellonext instance, you must onboard your
 Hellonext instance to SSPM. Through the onboarding process, SSPM logs in to
 Hellonext using administrator account credentials. SSPM uses this account to scan
 your Hellonext instance for misconfigured settings. If there are misconfigured
 settings, SSPM suggests a remediation action based on best practices. 

 To onboard your Hellonext instance, you complete the following actions: 

 Collect Information for Connecting to Your Hellonext Instance 

 Connect SSPM to Your Hellonext Instance 

 Collect Information for Connecting to Your Hellonext Instance 

 To access your Hellonext instance, SSPM requires the following information, which
 you will specify during the onboarding process. 

 Item Description 

 Email ID The login email address of a Hellonext administrator account.

 Password The password of the Hellonext administrator account. 

 Organization name The name of the Hellonext organization that SSPM will scan
 for misconfigured settings. 

 As you complete the following steps, make note of the values of the items
 described in the preceding table. You will need to enter these values during
 onboarding to access your Hellonext instance from SSPM. 

 Identify the Hellonext administrator account that SSPM will use to access
 your Hellonext instance. 

 ( Required Permissions ) To enable SSPM to scan your Hellonext
 organization, the account must have administrator access. 

 Identify your Hellonext organization name. 

 Using Hellonext, you can create more than one organization. During
 onboarding, SSPM prompts you for the name of the organization to scan.
 If you want to scan multiple organizations, you can onboard each one
 separately. To view a list of your Hellonext organizations, complete the
 following steps: 

 Open a web browser to the Hellonext login page at portal.featureos.app/auth/signin and log
 in as an administrator. 

 Locate your profile icon and select <profile-icon> 
 Switch Organization . 

 Connect SSPM to Your Hellonext Instance 

 By adding a Hellonext app in SSPM, you enable SSPM to connect to your Hellonext
 instance. 

 Log in to 
 Strata Cloud Manager . 

 Select Configuration SaaS Security Posture Security Applications Add Application and click the Hellonext tile. 

 Under posture security instances, Add Instance or,
 if there is already an instance configured, Add New 
 instance. 

 Choose the option to Log in with Credentials . 

 Enter the administrator login credentials and the organization name, and
 Connect .
