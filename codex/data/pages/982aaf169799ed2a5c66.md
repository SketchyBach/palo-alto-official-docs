 BFD-STD-MIB 

 Use the Bidirectional Forwarding Detection (BFD) MIB
to monitor and receive failure alerts for the bidirectional path
between two forwarding engines, such as interfaces, data links,
or the actual engines. For example, you can check the bfdSessState object
to see the state of a BFD session between forwarding engines. In
the Palo Alto Networks implementation, one of the forwarding engines
is a firewall interface and the other is an adjacent configured
BFD peer. 

 RFC 7331 defines this MIB.
