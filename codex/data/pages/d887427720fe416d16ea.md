 Persistence (TA0003), Privilege Escalation (TA0004) 

 ATT&CK Technique 

 Create or Modify System Process: Systemd Service (T1543.002) 

 Severity 

 Low 

 Description 

 An uncommon service was started using systemctl or service processes. 

 Attacker's Goals 

 Attackers may create systemd services to run malicious payloads. 

 Investigative actions 

 Check whether the executing process is benign and if this was a desired behavior as part of its normal execution flow.
