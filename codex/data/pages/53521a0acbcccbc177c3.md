 clear app-probe prefix 

 Use the clear app-probe prefix command
to clear prefixes mapped on an application for each path or port
combination. 

 Command 

 clear app-probe prefix ( application = | server-ip= | path-id= | port= ) 

 Options 

 application Enter an application name to
clear prefixes for the application. 

 server-ip Enter a server IP address to clear prefixes mapped
to the server. 

 path-id Enter a Path ID to clear prefixes mapped to
the path. 

 port Enter a port number to clear prefixes mapped
to the port. 

 Command Notes 

 Role Super 

 Related Commands 

 Introduced in Release 5.1.1 

 Example 

 clear app-probe prefix application=ftp
