 Zero trust network access (ZTNA) application object incident settings let you
 create custom incident configurations scoped to individual application objects. Instead
 of applying a single alert rule across every ZTNA Connector, you can select the specific
 application objects you want to monitor, set their severity and notification preferences
 independently, and suppress alerts for noncritical applications altogether. Strata™
 Cloud Manager retrieves the list of available application objects directly from your
 ZTNA application inventory, so the objects you see in the incident settings configuration reflect your
 current deployment. 

 A custom incident setting for a ZTNA application object follows the same
 precedence hierarchy as other custom settings in the Unified Incident Framework.
 Object-level settings take effect only for the INC_ZTNA_CONNECTOR_APP_STATUS incident
 code and apply to the specific application objects you select. If an object-level
 setting doesn't exist for a given application, the higher-level setting (such as a
 product-level or domain-level rule) applies instead. You can configure object-level
 settings alongside existing product-level and domain-level settings without
 conflict.
