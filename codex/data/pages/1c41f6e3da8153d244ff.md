 Severity 

 Informational 

 Description 

 A lolbin was executed with uncommon commandline by a scheduled task. 

 Attacker's Goals 

 Attackers may attempt to gain persistence, privilege escalation or proxy execution on the endpoint using scheduled tasks. 

 Investigative actions 

 Review the lolbin's command line executed by the schedule task. 

 Investigate the specific scheduled task execution chain. 

 Investigate how the scheduled task was created and the actor who created it.
