 Download and Install the Prisma Agent for iOS on Unmanaged Devices 

 Download and install the Agent on unmanaged devices for iOS. 

 Where Can I Use This? What Do I Need? 

 Prisma Agent 

 iOS 16 and later versions 

 Internet access 

 Before you can connect to the Prisma Agent , you must download and install the
 app from the App Store. 

 Open the App Store. 

 Search for Prisma Agent . 

 From the search results, select Prisma Access Agent . 

 Install the app. 

 When prompted, Sign In with Apple ID.
