 Addressed Issues in Prisma SD-WAN Controller 

 Learn about the Addressed Issues in Prisma SD-WAN . 

 The following table lists the addressed issues in Prisma SD-WAN . 

 Issue ID Description 

 September 2026 

 CGSDW-33146 Resolved an issue to stabilise VPN link status monitoring in Strata
 Cloud Manager by implementing status dampening algorithms, effectively
 throttling high-frequency link flap updates. 

 August 2026 

 CGSDW-40034 Resolved an issue where adding a WAN interface to a site-level
 security zone binding was not possible. 

 CGSDW-40102 Resolved an issue with the system metrics API to return values for
 disk utilization, CPU usage, and memory usage on SD-WAN devices. With
 this fix, new version of the system metrics API is introduced. 

 CGSDW-40268 Resolved an issue where previewing or downloading reports on the
 Aggregate Bandwidth Usage page failed with a rendering error, causing
 the page to remain in an error state until the browser was
 refreshed. 

 CGSDW-40238 Resolved an issue where the Bandwidth Upgrade Recommendation, Circuit
 Utilization Threshold, and Guest Wireless Circuit Threshold reports
 failed to generate. 

 CGSDW-40273 Resolved an issue where the Save button on the cellular modem
 firmware upgrade page was unresponsive, preventing users from applying
 firmware updates on ION devices. 

 CGSDW-39965 Resolved an issue where the Remote Access option appeared disabled
 for most devices in the ION Devices list, even though the devices were
 accessible in the individual device view. 

 CGSDW-39891 Resolved an issue where element shells and interface entries were not
 cleaned up when a device was declaimed during an incomplete RMA
 process. 

 CGSDW-40642 Fixed an issue where for sites configured with over 10 WAN
 interfaces, the Current Health and Current Overlay Health columns in the
 Circuit Connectivity and Health section on the Site Summary tab
 previously showed NA. 

 July 2026 

 CGSDW-39924 Resolved an issue where switching a site from Branch to Branch
 Gateway mode failed with error BRANCH_GATEWAY_CONFLICTS_WITH_WAN_LAG
 when a LAG interface configured with used-for: LAN was present on the
 device. 

 CGSDW-39144 Resolved a user interface display issue where the DHCP Scopes list
 page rendered the last entry as partially cut off when 17 or more DHCP
 scopes were configured, making it inaccessible without zooming
 out. 

 CGSDW-38479 Resolved a typo in the Performance Policy rule creation page where
 "View Actions and Depdendencies" was corrected to "View Actions and
 Dependencies." 

 CGSDW-38520 Resolved an issue where LQM metrics were not displayed or were
 incorrect in circuit views because the user interface queried stats
 using wan interface ID as a path filter, which was not fully supported
 by the Stats API. Updated the user interface to align with WAN interface
 filter support in the metrics APIs. 

 CGSDW-30118 Resolved a scalability issue with the Topology API that caused
 failures or degraded performance for large tenants with many devices.
 The API was restructured to support scale, improving reliability for
 high-scale deployments. 

 June 2026 

 CGSDW-39230 Resolved an issue in the reports where the site uptime LQM percent
 calculation used a static duration value instead of a dynamic one,
 resulting in incorrect uptime percentages. 

 CGSDW-39082 Resolved an issue where Day 2 operations using site templates
 incorrectly removed Easy Onboarding / CloudBlade managed service link
 interfaces from element security zones when interface_ids was an empty
 list in the template. 

 CGSDW-38938 Resolved an issue where disabling SNMPv2 from the device-level
 configuration failed with error SNMPCONFIG_COMMUNITY_STRING_REQUIRED
 because the user interface was sending a null community string in the
 snmpagents API payload. 

 CGSDW-38817 Resolved an issue where a Stub link that was up was incorrectly shown
 as "Nascent" in the Site Summary table when there were no AnyNet links
 and only a Stub link associated with the circuit. 

 CGSDW-38658 Resolved an issue where assigning a port with used-for: Controller on
 an ION 3200 device failed with an error requiring LLDP TxRx to be
 disabled, due to incorrect LLDP handling logic for controller
 ports. 

 CGSDW-37609 Resolved an issue where the operator name was not displayed in the
 Audit Logs Compare modal. 

 CGSDW-29528 Resolved an issue where the user interface did not include the
 supported_base_software_version attribute in PUT requests to the appdefs
 v2.6 API. The interface now passes null for POST and echoes back the
 GET-retrieved value for PUT, aligning with the API contract. 

 May 2026 

 CGSDW-38405 Resolved an issue in the Incidents filter where selecting Show
 Resolved did not enable the Suppressed and Acknowledged checkboxes,
 preventing users from filtering by those states. 

 CGSDW-38229 Resolved an issue in the Insights backend where tunnel status and
 metrics were not computed because the event_time attribute was missing
 from the pubsub message metadata for node type 157. 

 CGSDW-38140 Resolved an issue where Directory Service membership delta sync
 failed for users with user_group_ids set to null in MongoDB. The fix
 ensures user_group_ids is initialized as an empty array instead of null,
 allowing the sync to complete successfully. 

 CGSDW-36658 Resolved an issue where element shells created during SASE onboarding
 via site templates were being incorrectly synced to Orion. Element
 shells are now excluded from Orion sync as expected. 

 CGSDW-36495 Resolved an issue where Remote Network High-Performance routing
 configuration was reset to defaults when a user edited and saved it in
 Strata Cloud Manager. 

 CGSDW-35878 Resolved an issue where a device software upgrade failed with a
 NullPointerException in the HA control interface VLAN lookup, and added
 element shell validation checks to prevent stale HA configurations from
 causing upgrade failures. 

 April 2026 

 CGSDW-38248 Resolved an issue where downloading a CSV from the Device List page
 failed silently when either the Online or Offline status filter was
 selected individually. 

 CGSDW-38153 Resolved a cosmetic user interface issue where the pagination
 next-page arrow button in the NAT interface bindings table incorrectly
 moved along the scrollbar instead of staying in a fixed
 position. 

 March 2026 

 CGSDW-37747 Resolved an issue in site templates where creating a subinterface or
 other logical interface on a port channel interface caused the
 bound_interfaces to be lost during the parent interface reset
 step. 

 CGSDW-37062 Resolved an issue where RMA device replacement failed for service
 links created by PA CloudBlade using PSK authentication, because the PSK
 secret was not correctly copied from the old device configuration to the
 replacement device during the RMA process. 

 CGSDW-36960 Resolved an issue where the Prisma SD-WAN tab in Insights > Branch
 Sites disappeared after refreshing the browser page. 

 CGSDW-36629 Resolved an issue where an ION device remained stuck in the
 inventory_get_complete state in the GUI during an RMA operation,
 preventing the RMA workflow from progressing. 

 February 2026 

 CGSDW-37500 Resolved an issue where selecting Site Local Time as the timezone
 when scheduling a software upgrade on an ION device did not correctly
 apply the local time, causing the upgrade to be scheduled in the wrong
 time zone. 

 CGSDW-36864 Resolved an issue where DC circuit reports were missing from WAN
 Clarity Reports because the ConfigSync framework was populating the
 anynet_link_id field with the id value instead of the correct al_id
 field from AnynetLinkDOV3, causing JOIN conditions in report queries to
 return no rows. 

 CGSDW-36040 Resolved an issue where saving a cellular interface configuration on
 an ION device running software version 5.6.13-b3 failed. 

 CGSDW-35799 Resolved an issue where the NETWORK_ANYNETLINK_DOWN and
 NETWORK_ANYNETLINK_DEGRADED events displayed only the source site in the
 Impacted Objects panel instead of both connected sites, and corrected
 the event description message to remove the redundant site name
 suffix. 

 CGSDW-34958 Resolved an issue where removing a Prisma Access tag from a site in
 Strata Cloud Manager failed due to an overly strict site name validation
 check that incorrectly rejected the update. 

 January 2026 

 CGSDW-36744 Resolved an issue where Prisma Access Easy Onboarding tunnel creation
 failed with a schema validation error when a secondary BGP parameter was
 included in the request payload, even though users had not explicitly
 modified the BGP configuration. 

 CGSDW-35733 Resolved an issue in the Flow Browser where path selection details,
 including the chosen path, available paths, and excluded paths, were not
 displayed consistently or with sufficient detail to understand the path
 preference reason. 

 CGSDW-35670 Resolved an issue where the port panel and device interfaces for the
 ION 1200-C-ROW model were not visible in the Devices > Interfaces
 section of Strata Cloud Manager. 

 CGSDW-36089 Resolved an issue where configuring the Allow SASE Connectivity IKE
 group with GCM-based encryption did not offer None as a hash algorithm
 option, which is required for GCM and caused the configuration to
 fail. 

 December 2025 

 CGSDW-35906 Resolved an issue where the Insights > Prisma SD-WAN Applications
 page failed to load on navigation or became stuck indefinitely when the
 browser page was refreshed. 

 CGSDW-35649 Resolved an issue where the View Policy Set link in the software
 upgrade and downgrade confirmation modal, shown when incompatible
 applications are detected, no longer opened the policy set in a new
 window. 

 CGSDW-35584 Resolved an issue where the NAT Stack drop down appeared empty when
 editing path policies for multiple sites simultaneously in Strata Cloud
 Manager. The default NAT Stack policy is now pre-selected in the drop
 down when available. 

 November 2025 

 CGSDW-35668 Resolved an issue where Circuit Health and Overlay status were
 reported incorrectly in Strata Cloud Manager. 

 CGSDW-34242 Resolved an issue where Prisma SD-WAN Portal Probe Point Metrics were
 incorrectly displaying N/A instead of the actual metric values in Strata
 Cloud Manager. 

 CGSDW-33208 Resolved an issue where an internet circuit already assigned to one
 interface could be re-assigned to a bypass pair interface. The user
 interface now filters out in-use circuits, and the backend no longer
 allows duplicate circuit assignments for bypass pair interfaces.
