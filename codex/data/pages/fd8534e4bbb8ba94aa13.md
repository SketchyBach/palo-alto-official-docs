 Addressed Issues in Prisma SD-WAN Controller 

 Learn about the Addressed Issues in Prisma SD-WAN . 

 The following table lists the addressed issues in Prisma SD-WAN . 

 Issue ID Description 

 CGSDW-38675 Resolved an issue where the GET /snmpagents API
 returned the SNMP community string in cleartext. SNMP configuration
 fields now enforce a strict character validation policy to prevent
 command injection. The fields accept only alphanumeric characters and
 select symbols ( ! , @ ,
 # , % , ^ ,
 * , - , _ ,
 + , = , : ,
 . , , , ? ,
 / , ~ ). Existing configurations
 with restricted characters continue to function, but the system enforces
 the new validation rules when you modify these settings. 

 CGSDW-38379 Resolved an issue where the GET API response
 returned the default Element user password for newly claimed devices in
 cleartext. The API now masks this default password. You must change the
 default Element user password before you use the device. 

 CGSDW-34644 Resolved an issue where the report image and file downloads failed on
 the Reports page when the Site name includes a parenthesis character "("
 or ")". 

 CGSDW-33565 Resolved an issue where the ION device showed incorrect version
 number on the Claimed Devices page on the Prisma SD-WAN controller. The
 software version showed correctly on the device Basic info page. One had
 to refer to the Basic info page for the correct device software
 version. 

 CGSDW-30422 Resolved an issue where while updating route map entries, the
 Community String field would not allow values between 65500 and
 65529. 

 CGSDW-30239 Resolved an issue where after upgrading to device software version
 6.4.x, BGP sessions remained down until the user selects
 Update Source from the web interface. 

 CGSDW-22597 Resolved an issue where the DNS Server IP was accepting a
 multicast IP address. 

 CGSDW-29863 Resolved an issue where filtering by incidents was not updating the
 list of sites for Monitor>Branch Sites in the Map view. 

 CGSDW-29475 Resolved an issue where the app acceleration policy rule creation was
 not working. 

 CGSDW-29332 Resolved an issue where the TSG ID for a migrated tenant was giving
 an error. 

 CGSDW-29118 Resolved an issue where the
 supported_base_software_version in PUT payload for Appdefs
 was resulting in an error. 

 CGSDW-28726 The hardware ID is now available during machine recovery
 in case the device ID is not available. 

 CGSDW-28571 Resolved an issue where BGP peer status was not displayed
 for devices with software version lower than 6.2. 

 CGSDW-28431 Device deallocation is now successful for a device which
 is in an assigned state and disconnected. 

 CGSDW-28392 Resolved an issue wherein the default rule set was being
 prepended with the text SDWAN that was causing the Simple Default Rule
 Stack to be treated as Advanced. 

 CGSDW-25961 Resolved an issue where multiple device software versions
 having the same SHA hash resulted in incorrect software version
 representation on the web interface. 

 CGSDW-22248 Resolved an issue where VPN routes of a branch were being
 advertised to a connected Branch Gateway site even when the VPNs to the
 branch were down. 

 CGSDW-22018 Resolved an issue where there required an additional
 check for TSG ID during the tenant creation process to avoid failures
 during tenant creation. 

 CGSDW-20899 Resolved an issue where Site Onboarding was not
 successful when a circuit is already attached to a Prisma SD-WAN only
 site and a Prisma Access license is added later. 

 CGSDW-20171 Resolved an issue where the connection status on the PA
 web interface showed Connect to Prisma Access ,
 even when a site is already connected to PA. 

 CGSDW-20672 Resolved an issue where it was unable to allocate more
 than 200 devices to a tenant onboarding to SCM using the magic
 link. 

 CGSDW-19630 Resolved an issue where certificate and keys were not
 being stored in the controller for IPsec profiles. 

 CGSDW-19660 Resolved an issue where creating a child tenant under the
 Prisma SD-WAN parent added VFF licenses to the parent.
