 Push custom content to production tenant 

 post https://api-yourfqdn /xsoar/public/v1/vc/changes/uncommitted/commit 

 Use the response from Get a list of content available to be pushed to production to customize what content you want to push to the production tenant. Use that customized content as the request in this API. Once this is performed successfully, that content should no longer appear when running Get a list of content available to be pushed to production .
