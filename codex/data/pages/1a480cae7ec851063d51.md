 View and Manage SLR Terraform Templates 

 View and manage SLR Terraform templates in Strata Cloud Manager . 

 Where Can I Use This? What Do I Need? 

 Prisma AIRS AI Runtime Security Risk
 Assessment in AWS 

 Deploy Security Lifecycle Review (SLR) for AWS 

 Log in to Strata Cloud Manager . 

 Navigate to Insights Prisma AIRS Prisma AIRS AI Runtime: Network intercept . 

 Click on the deployment shield icon at the top right corner. 

 The SLR Monitoring tab lists the SLR deployments with the following
 details: 

 Terraform template name. 

 Deployment Type. This is the SLR deployment type: 
 GWLB-based centralized deployment is indicated as
 "AWS_SLR_CENTRALIZED". 

 Per application VPC-based deployment is indicated as
 "AWS_SLR_DEDICATED". 

 Cloud service provider, which the SLR will monitor. 

 Stata Cloud Manager Region . 

 Application : Count of applications installed. 

 Created : The SLR report creation date. 

 SLR deployment Status indicating if the SLR firewall is
 deployed. 

 Actions : You can download and delete the SLR report and view
 the associated firewalls. 

 Refer to the View and Manage SLR Reports
