 Bootstrap the Firewall 

 Bootstrap a Palo Alto Networks firewall with initial configuration settings and
 management connectivity for PAN-OS deployment. 

 Where Can I Use This? What Do I Need? 

 NGFW (Managed by PAN-OS or Panorama) 

 No prerequisites needed 

 Bootstrapping speeds up the process of configuring and
licensing the firewall to make it operational on the network with
or without Internet access. Bootstrapping allows you to choose whether
to configure the firewall with a basic configuration file (init-cfg.txt)
so that it can connect to Panorama and obtain the complete configuration
or to fully configure the firewall with the basic configuration
and the optional bootstrap.xml file.
