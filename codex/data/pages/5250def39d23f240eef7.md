 Manually Delete Assets 

 Manually delete assets that contain sensitive information. 

 This feature is currently available only for the ChatGPT
 Enterprise and Slack Enterprise apps. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 Data Security license 

 Or any of the following licenses that include the Data Security license: 

 CASB-X 

 CASB-PA 

 As an administrator, you can manually delete an asset that contains sensitive
 information. 

 Log in to 
 Strata Cloud Manager . 

 Select Configuration SaaS Security Data Security Data Assets . 

 Select the asset. 

 Click Actions Delete . 

 The Delete Asset action is
 permanent. You can’t restore the deleted asset.
