 Prisma Access for Networks Region List 

 Lists all the Prisma Access regions and the corresponding CloudBlade tag
 names. 

 Where Can I Use This? What Do I Need? 

 Supported CloudBlades: 

 Prisma Access for Networks (Managed by Panorama) 

 Prisma Access for Networks (Cloud Managed) 

 Prisma SD-WAN 

 Prisma Access 

 Supported Cloud Plugin Versions 

 Prisma Access for Networks (Managed by Panorama) CloudBlade versions 3.x.x and
 later 

 Prisma Access for Networks (Cloud Managed) CloudBlade versions 3.x.x and
 4.x.x 

 As of publication of this document, the following regions are available for
 Prisma Access for Networks. These regions can change and are dynamically updated by the
 CloudBlade. To use a new region, simply enter its short name at the end of a
 PRISMA_REGION: interface tag. 

 You can see the latest list of available regions and their respective compute regions
 under Prisma Access Regions on the Status
 Monitor tab of the CloudBlade.
