 Cortex XSOAR 6.13 Multi-Tenant 

 Move a Tenant to a Different Host 

 Move a tenant to a different host in a Cortex XSOAR multi-tenant deployment. Backup the tenant first. 

 Moving a tenant to a different host might risk data loss. Back up the tenant server before moving to a different host. Accounts can only be moved from Elasticsearch hosts to Elasticsearch hosts or from BoltDB hosts to BoltDB hosts. 

 In Cortex XSOAR, go to Settings → ACCOUNT MANAGEMENT . 

 Select the tenant that you want to move. 

 Click the Change host button. 

 Select the new host or high availability group and click Move .
