 Create, Assign, and Configure a WAN Multicast Configuration Profile 

 Learn how to create a WAN multicast configuration profile in Prisma SD-WAN . Create a global WAN multicast configuration profile. 

 Where Can I Use
 This? What Do I
 Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 Create a global WAN multicast configuration
profile. Specify the data center site which will be the source for
the multicast traffic. 

 Select Configuration Prisma SD-WAN Profiles and Templates Multicast Create Peer Group Profile . 

 Enter a Name for the multicast
profile. 

 (Optional) Enter Tags and Description . 

 For Source Site Selection , select
a data center site as the multicast source from the list of sites. 

 You can view data center sites having devices
with a software version 6.0.1 or later by clicking the View
sites with device software version 6.0.1 or newer check
box. 

 (Optional) Select Receive traffic
from branch side sources to receive multicast traffic
from another branch site. 

 This option is available only for sites using device versions
6.1.1 or later. 

 A branch site can receive multicast traffic sourced
by another branch site only through a connected data center site.
 Prisma SD-WAN does not support direct branch-to-branch VPNs for
multicast traffic. 

 Click Save . 

 (Optional) View the multicast profiles associated
with a data center site by selecting Manage or Monitor ,
then Sites Select
a Data Center Site Configurations WAN . 

 Assign WAN Multicast Configuration Profiles to Branch Sites 

 Associate a WAN multicast profile with a branch site to specify the source for
 multicast traffic. 

 Select Configuration Prisma SD-WAN Branch Sites . 

 Select a site and click Configurations . 

 Select a profile from the WAN Multicast 
 drop-down. 

 (Optional) Select No profile (multicast
 disabled) , if you want to disable multicast for the
 site. 

 Configure a Multicast Source at a Branch Site 

 Configure a source for multicast traffic at a branch site. 

 Select Configuration Prisma SD-WAN Branch Sites Select a Site WAN Multicast Configurations . 

 On the Site Multicast Configuration screen, click
 Add Entry . 

 You can add a maximum of 64 entries. 

 Enter the Multicast Group Prefix . 

 These are the multicast group prefixes for which the site sources
 multicast traffic. 

 Enter the Source Address for multicast
 traffic. 

 This is the address which sources the multicast traffic. 

 Click Save .
