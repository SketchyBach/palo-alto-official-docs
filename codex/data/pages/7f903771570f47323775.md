 Password-Protected Files in Isolation 

 Open password-protected OOXML files, Office documents, and encrypted archives
 directly within your RBI session without downloading them to the
 endpoint. 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Panorama or Strata Cloud Manager) 

 Minimum required Prisma Access version: 5.0 Innovation 

 Prisma Access 
 license with the
 Mobile User or Remote Networks license subscription 

 Remote Browser Isolation
 license 

 View Files in Isolation is enabled in
 the isolation profile 

 Remote Browser Isolation (RBI) lets you open password-protected Office documents and encrypted
 archives directly within the remote session without downloading the files to the
 endpoint. RBI provides a secure password dialog within the remote
 viewer, accepts your password, and decrypts the file within the remote container before
 rendering it. The temporary decrypted files are cleaned up automatically when the
 session ends. 

 RBI supports three categories of protected files: OOXML Office
 files, legacy Office formats, and encrypted archives through the Archive
 Viewer . 

 Microsoft Office Files 

 RBI supports Office Open XML files (Word
 .docx , Excel .xlsx , and PowerPoint
 .pptx ) and Word 97-2003 .doc , Excel
 97-2003 .xls , and PowerPoint 97-2003
 .ppt files. When you open a password-protected Office file in an
 RBI session, the remote document viewer detects the
 encryption before rendering the file and displays a Password
 Required dialog. 

 Enter the file password and click Unlock . RBI transmits the password securely to the remote environment,
 decrypts the file, and renders the document. RBI does not store
 or log the password after the decryption. If the password is incorrect, the
 Password Required dialog reappears and you can re-enter the
 password or click Cancel . You can attempt to retry up to 5
 times. 

 If View Files in
 Isolation is disabled, you can download archive files
 directly to your system, provided the Download Files 
 option is enabled. 

 Archive Files 

 When you download an encrypted archive in an RBI session, a
 password prompt displays inside the Archive Viewer file explorer. Enter the archive
 password to allow RBI to decrypt the archive within the remote
 container and display its contents. If the password is incorrect, the prompt
 reappears with an error and you can retry. 

 Ensure that
 your browser's pop-up blocker is disabled for the site you are browsing to open
 Archive Viewer in a new tab.
