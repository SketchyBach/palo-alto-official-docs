 Delete a custom detection rule 

 Delete a Cortex XSIAM custom cloud workload detection rule that is no longer required. 

 Navigate to Posture Management → Rules & Policies → Rules → Cloud Workload . 

 In the Cloud Workload Rules page, click the rule you want to delete. 

 In the Details page, click the More Options icon ( ⋮ ) and then select Delete . 

 In the confirmation message, click Delete .
