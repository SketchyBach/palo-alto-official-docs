 Legacy Dashboard to Summary and Insights Widget Mapping 

 Use this reference to locate widgets and data points from the previous Monitor, Insights, and Summary dashboards in the current Summary and Insights page. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 Multitenant hierarchy with one or more child tenants 

 The previous Monitor, Insights, and Summary dashboards have been consolidated into the domain-specific Summary and Insights page. Use the tables below to find where your widgets and data points from the old dashboards are located in the new layout. 

 SASE Tab — Widget Mapping 

 The following widgets from the previous SASE tab are now located in these sections of the new page:
