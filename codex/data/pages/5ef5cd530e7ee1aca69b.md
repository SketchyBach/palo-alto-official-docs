 A full-featured Cortex XSOAR server

 BlueCat Internet Protocol Address Management (IPAM)
provides a means for managing the IP address space of a network.
When you integrate Device Security through Cortex XSOAR with BlueCat
IPAM, you can import all the IP address blocks and subnets (called blocks and networks in
the BlueCat product) into Device Security and then display them on
the Networks page. 

 Through integration with BlueCat, Device Security can learn the
following types of information about the IP address blocks and subnets
on the network: 

 Prefix (for example, 10.1.0.0/16) 

 Type : Block or Subnet 

 Name (if configured on BlueCat) 

 Gateway (subnets only) 

 For a full list of attributes that Device Security can learn through the
 integration, see
 BlueCat Attribute Reference .

 Integrating with BlueCat requires either a
 full-featured Cortex XSOAR™ server 
 or the
 activation of a Device Security 
 free
 cohosted Cortex XSOAR instance .
