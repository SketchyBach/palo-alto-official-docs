 Cortex Cloud Posture 

 Link Cortex Cloud to Prisma Cloud 

 Link your Cortex Cloud and Prisma Cloud tenants before migrating. 

 To link your Cortex Cloud tenant to a Prisma Cloud tenant, first obtain the Access Key from Prisma Cloud, and then paste it in the Link Tenant section of the Upgrade Helper to establish the link. 

 Obtain the Prisma Cloud tenant access key 

 Log in to your Prisma Cloud tenant as an administrator. 

 Go to Settings → Enterprise Settings . 

 Click Generate Token in the Cortex Cloud Tenant Linking section. 

 Copy the Access Key . 

 Link from Cortex Cloud 

 Log in to Cortex Cloud as an administrator. 

 Navigate to Settings → Configurations → Upgrade Helper . 

 Click Create Link in the Link Tenant section. 

 Enter the Prisma Cloud Access Key . 

 Review the details of the Prisma Cloud tenant, such as Tenant Name, Tenant ID, and Region. 

 Click Connect .
