 Migration to Hosted Service 

 Migrate Cortex XSOAR 6.12 Hosted Service (EoL) from an on-prem deployment to hosted service 

 When migrating from an on-premise deployment to hosted service, Palo Alto Networks provides you with instructions to package and upload all required files. After the upload is complete, a new hosted instance is created with your data. 

 Note 

 Migration from on-premise to hosted deployment is only supported when the on-premise deployment is the latest Cortex XSOAR version. 

 Note 

 Migration from hosted service to an on-premise deployment is not supported.
