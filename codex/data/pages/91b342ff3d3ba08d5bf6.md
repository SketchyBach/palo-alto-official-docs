 inspect system vrf 

 Use the inspect system vrf command to inspect all the kernel VRF
 link information for a device and used to debug any routing-related issues on the
 device. 

 Command 

 inspect system vrf ( all | vrf-name= vrf name ) 

 Options 

 all Enter all to display status of all the kernel VRF
 link information for a device. 

 vrf-name Enter a VRF name to display a particular kernel VRF
 link information for a device. 

 Command Notes 

 Role Super, Read Only 

 Related Commands — 

 Introduced in Release 6.3.1 

 Example 

 inspect system vrf all
