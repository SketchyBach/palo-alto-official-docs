 Where Can I Use This? What Do I Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 The new Prisma® SD-WAN device-based licensing model simplifies deployment,
 enhances transparency, and expands capabilities. This model transitions to a
 device-centric approach, linking new SKUs directly to the hardware families and the
 number of deployed physical or virtual devices. These SKUs activate a range of features,
 including core SD-WAN functionalities, advanced security services, IoT Security,
 Autonomous Digital Experience Management (ADEM), and Secure Logging Service (SLS). For
 more information, refer to the Prisma SD-WAN Licensing Guide . 

 Devices are categorized into sizing families (very small, small, medium, and
 large) for standardized, predictable, and scalable licensing. Licenses can be procured
 based on these sizing families and managed at the tenant level within the Strata Cloud
 Manager (SCM). This centralized control enables flexible allocation, either partially or
 fully, to parent or child tenants, optimizing resource utilization across organizational
 units. The initial activation process is initiated via a unique magic link that
 orchestrates provisioning through the SCM to the Prisma SD-WAN controller. 

 Each Tenant Service Group (TSG) can have only one active software subscription
 contract. Once activated, any modifications to that contract will be managed through the
 amend process, and any license quantity updates will automatically flow to SCM, where
 the additional capacity can be allocated as needed.
