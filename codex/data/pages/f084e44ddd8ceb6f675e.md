 Show Commands Removed in PAN-OS 12.2 

 Command line interface 'show' commands that are removed in PAN-OS 12.2: 

 The following commands are no longer available in the 12.2 release. 

 show deviceconfig setting cloud-host-compliance
show template <name> config deviceconfig setting cloud-host-compliance
show template <name> config deviceconfig setting ctd url-cloud-detection
show template <name> config deviceconfig setting panos-shield params
show template <name> config deviceconfig setting panos-shield params <name>
show template <name> config deviceconfig setting panos-shield params <name> value
show template <name> config deviceconfig setting panos-shield params <name> value value-str-arr
show template <name> config deviceconfig setting panos-shield params <name> value value-str-arr <name>
show template <name> config network interface cellular <name> apn-profile
show template <name> config network interface cellular <name> apn-profile <name>
show template <name> config network interface ethernet <name> fec
show template-stack <name> config devices <name> deviceconfig setting cloud-host-compliance
show template-stack <name> config devices <name> deviceconfig setting ctd url-cloud-detection
show template-stack <name> config devices <name> deviceconfig setting panos-shield params
show template-stack <name> config devices <name> deviceconfig setting panos-shield params <name>
show template-stack <name> config devices <name> deviceconfig setting panos-shield params <name> value
show template-stack <name> config devices <name> deviceconfig setting panos-shield params <name> value value-str-arr
show template-stack <name> config devices <name> deviceconfig setting panos-shield params <name> value value-str-arr <name>
show template-stack <name> config devices <name> network interface cellular <name> apn-profile
show template-stack <name> config devices <name> network interface cellular <name> apn-profile <name>
show template-stack <name> config devices <name> network interface ethernet <name> fec
