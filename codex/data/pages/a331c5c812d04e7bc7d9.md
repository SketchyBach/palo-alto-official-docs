 How to get started with SaaS Security Posture Management (SSPM). 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 SaaS Security Posture Management license 

 Or any of the following licenses that include the Data Security license: 

 CASB-X 

 CASB-PA 

 SaaS Security Posture Management (SSPM) helps detect and remediate misconfigured settings in
 sanctioned SaaS apps through continuous monitoring. SSPM provides a remediation workflow
 that helps you remediate and prioritize misconfigured settings detected on your SaaS
 apps and detects risky user accounts by identifying user accounts that were not
 provisioned using your organization’s identity provider.
