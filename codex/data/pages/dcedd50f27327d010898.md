 Summary - Experience 

 Summary Dashboard 

 Monitor the digital experience of users and remote sites
in your Secure Access Service Edge (SASE) environment and quickly
assess if there are any network-wide or system-wide issues you should
be looking into. The granularity of the data displayed on the Summary depends
on the Time Range you have selected. 

 The Summary dashboard is meant to give
you an overall view of the experience across all users, remote sites,
and applications and is an aggregate of data across the entire organization.
Select or define a custom Time Range to view
the data for only the time window selected. You can also use the
search bar to quickly find a specific user, remote site, or application. 

 Filter (click 

 ) the data shown
in the widgets in this dashboard using the following filters: 

 Application 

 Prisma Access Location 

 If you are a SASE customer and have purchased both Mobile Users and Remote
Networks ADEM licenses and have created application
monitoring tests for both, you see an integrated view on the Summary page.
You see a Mobile User Experience card and
a Remote Site Experience card. If you click
on the Mobile User Experience card, the data displayed
in the widgets underneath will be data associated with Mobile Users
only. Likewise, clicking on the Remote Site Experience will
display data specific to the Remote Site only in the widgets below. 

 You see the experience and the associated data only for the type
of deployment for which you have the license. 

 The Summary dashboard displays the data
in three tabs: 

 View the average of the application segment score for
all mobile users and remotes sites (based on the licenses you have
purchased), a time series graph of the experience scores, and top
20 applications with lowest and highest experience scores in the Experience tab tab. 

 The Performance Trends
for Mobile Users tab gives you an overview of the application
experience score trend for mobile user devices along with the application
and network performance metrics. 

 The Performance Trends
for Remote Sites tab shows you the application experience
score trend for monitored remote sites along with the application
and network performance metrics across segments.
