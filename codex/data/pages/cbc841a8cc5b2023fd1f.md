 To activate SASE Private Location, reach out to your Palo Alto
 Networks account representative, who will contact the Site
 Reliability Engineering (SRE) team and submit a request. 

 To delete the SASE Private location components, complete these steps. 

 Delete a SASE Private Location Mobile Users Instance

 Delete a SASE Private Location Mobile Users Instance 

 To delete a mobile user SASE Private Location for a
 mobile users deployment, complete the following steps. 

 Go to Configuration NGFW and Prisma Access , select the Prisma Access configuration scope, and select
 GlobalProtect . 

 Select the GlobalProtect tab; then, select Global App Settings Manual Gateway Selection . 

 Deselect the SASE private location and Save 
 your changes. 

 Return to the GlobalProtect Setup and click the gear to edit the
 Prisma Access Locations . 

 Select a region; then change the view to List view. 

 Find the SASE private location, deselect it, and
 Save your changes. 
 You
 can only delete one location at a time (deleting multiple locations
 at the same time is not allowed). 

 Push Config to save your GlobalProtect
 configuration changes. 

 Make sure that GlobalProtect is in the push scope. 

 Wait for the push operation to complete. 

 Begin the deletion of the SASE private location by going to Configuration NGFW and Prisma Access , selecting the Prisma Access 
 configuration scope, and deleting the SASE private location. 

 Configure the Prisma Access
 Infrastructure . 

 Click the gear to configure the Prisma Access Private
 Locations settings. 

 Select the SASE private location and Delete 
 it. 

 Confirm the deletion. 

 Push Config , making sure that you have
 selected the Prisma Access configuration scope. 

 Delete a SASE Private Location Remote Network (Local Inspection Node) 

 To delete a mobile user SASE Private Location for a
 local inspection node (remote network), complete the following steps. 

 Go to Configuration NGFW and Prisma Access , select the Prisma Access configuration scope, and
 select Prisma Access Infrastructure . 

 Find Prisma Access Private Locations and click the gear to edit the
 settings. 

 Select the private location and Delete it. 

 Delete the Local Inspection Node. 

 Go to Configuration NGFW and Prisma Access , select the Prisma Access configuration scope, and
 select Remote Networks . 

 Go to the Local Inspection Node tab and
 Delete the Local Inspection Node. 

 Push Config to push your changes.
