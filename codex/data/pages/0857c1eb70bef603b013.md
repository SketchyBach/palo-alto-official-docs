 Get Your Advanced WildFire Public Cloud API Key From the WildFire Portal 

 Follow these steps to retrieve the API key
used to access the WildFire public API using the WildFire portal: 

 Palo Alto Networks recommends token-based API authentication for all
 new and existing WildFire API workflows. Token-based authentication provides
 stronger security through tenant isolation (TSG-ID), service account binding, and
 centralized credential management in Strata Cloud Manager. API key authentication
 and the legacy WildFire portal are being deprecated—you must use Strata Cloud
 Manager to create and manage all WildFire API credentials going forward. Migrate
 your existing API key workflows to token-based authentication to avoid service
 disruption when API key support ends. 

 Log in to the WildFire portal. 

 Visit https://wildfire.paloaltonetworks.com/ 

 Get the API key(s) 

 Your account may have more than one WildFire API
key. Choose one that is valid and has an Expiration that
is in the future. 

 Select Account on
the navigation bar at the top of the page. 

 Your API key or
keys appear under My WildFire API Keys .
