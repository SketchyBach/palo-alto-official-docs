 PAN-OS 10.2.10-h30 Addressed Issues 

 PAN-OS® 10.2.10-h30 addressed issues. 

 Issue ID 

 Description 

 PAN-301222 

 Fixed an issue where DNS Security logs incorrectly displayed a sinkhole action for benign DNS categories due to the firewall saving the drop or sinkhole action in session flags without discarding the session. 

 PAN-291653 

 Fixed an issue where the GlobalProtect host ID field was intermittently blank in traffic logs on
 Prisma Access, even when the user was connected and had the correct
 host ID information. This occurred when the IP address to host ID
 entry expired and the entry was re-inserted without the dataplane
 flag being set. 

 PAN-195264 

 Fixed an issue where the login lifetime countdown timer reset when using an authentication override cookie to log in to the gateway.
