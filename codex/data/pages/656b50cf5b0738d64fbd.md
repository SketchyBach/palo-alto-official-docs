 Cortex XSOAR 6.14 Multi-Tenant 

 Forward Server Configurations to Tenant Accounts 

 Forward server configurations from the main account to tenants in Cortex XSOAR 6.14 multi-tenant deployments. 

 Server configurations that you forward from the main account are made available on all tenant accounts. You cannot specify a subset of tenant accounts in which to make the server configurations available. 

 In the main account, go to Settings → ABOUT → Troubleshooting . 

 In the Server Configuration section click Add Server Configuration . 

 Key 

 Value 

 server.config.forward.tenants 

 A comma-separated list of server configurations to forward to all tenants. For example, server.config.1 , server.config.2 , server.config.3 

 Click Save .
