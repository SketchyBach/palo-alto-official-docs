 Description 

 A security object was deleted in Google Workspace Admin Console. 

 Attacker's Goals 

 Adversaries may modify or disable security rules to avoid detection of their activities. 

 Investigative actions 

 Investigate the security object name deleted and whether it was intended. 

 Check if the user was recently granted new elevated permissions that allowed them to delete security rules. 

 Follow other administrative or suspicious actions performed by this user around the same time.
