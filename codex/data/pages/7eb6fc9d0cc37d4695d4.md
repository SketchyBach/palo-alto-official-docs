 dump vpn ka VpnID 

 Use the dump vpn ka VpnID command to display the detailed Keep-alive information about specific VPN. 

 Command 

 dump vpn ka VpnID= vpn id 

 Options 

 None 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands — 

 Introduced in Release 5.4.1 

 Example 

 dump vpn ka VpnID=15915113777470065
 vep_id=15915113777470065 local_shim=100.64.1.227 remote_
 shim=100.64.1.228 state=UP
 ka_interval=1000 msec, ka_count=3

 local: active=True usable=True core_peering_up=True fc_up=True
 remote: active=False usable=False core_peering_up=True fc_up=True
