 SCM Pro License Expiration 

 Incident Code 

 INC_NGFW_SCM_PRO_LICENSE_EXPIRY 

 Severity 

 Warning 

 Category 

 Device 

 Subcategory 

 Management 

 Description 

 This alert indicates that the device’s Strata Cloud Manager (SCM) Pro license has
 expired or is nearing its expiration date. If expiry date is within 30 days, then
 a critical alert will be raised. 

 Raise Condition 

 This incident is raised to provide an advance warning that SCM Pro license is
 nearing its expiration date. If expiry is within 30 days from the current date
 then an incident is raised. 

 Clear Condition 

 This incident will be automatically cleared once the SCM Pro license has been
 successfully renewed or updated. The condition is met when the system verifies
 that the new license expiration date is more than 30 days in the future.
