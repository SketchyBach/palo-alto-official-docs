 APIs for content packs 

 Get metadata for all installed content packs 

 get https://api-yourfqdn /xsoar/public/v1/contentpacks/metadata/installed 

 Retrieve the metadata for all of the content packs installed in the system. 

 Responses 

 200 

 OK 

 application/json 

 id string Optional 

 Content pack ID 

 currentVersion string Optional 

 Current version number 

 name string Optional 

 Content pack name 

 lastInstallDate string Optional 

 Last date the content pack was installed. 

 updateAvailable boolean Optional 

 Whether there is an update to the content pack available. 

 propagationLabels string[] Optional 

 userIsSubscribedToNotifications boolean Optional 

 Whether the user is subscribed to receive notifications for this content pack.
