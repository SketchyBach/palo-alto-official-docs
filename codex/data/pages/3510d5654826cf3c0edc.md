 Cortex XSOAR 8.12 On-prem 

 Configure the Global Risk Threshold 

 In Cortex XSOAR 8.12 On-prem, configure the global SLA risk threshold. 

 By default, the risk threshold is 72 hours. You can change the threshold by adding a parameter to the system settings. 

 Note 

 When changing the server configuration, the new value does not affect existing fields retroactively. It affects new fields that you create. 

 Navigate to Settings & Info → Settings → System → Server Settings → Server Configuration → + Add Server Configuration . 

 Add the following server configuration. 

 In the key field, enter sla.risk.threshold . 

 In the value field, enter the number, in hours, to which to set the risk threshold. 

 Click Save .
