 inspect ipfix collector-stats 

 Use the inspect ipfix collector-stats command
to present status information for IPFIX collectors. This command
displays details of operation and error conditions including misconfiguration
or interactions with other modules, and data loss. 

 Command 

 inspect ipfix collector-stats 

 Options 

 None 

 Command Notes 

 Role Super, Read Only 

 Related Commands — 

 Introduced in Release 5.5.1
