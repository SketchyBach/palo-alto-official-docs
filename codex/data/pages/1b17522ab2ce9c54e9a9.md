 View Page Transactions for a User 

 View and filter the complete list of pages that Browser-Based RUM monitored
 for a user on a selected application domain, and drill into any page to investigate its load
 performance. 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 Prisma Access license 

 ADEM or Strata Cloud Manager Pro 
 license 

 ( Browser-Based Real User Monitoring (RUM) ) Prisma Browser 
 license 

 The All Pages section appears in the Real User
 Monitoring (RUM) tab of a user's application experience page when you
 select a domain. It shows every page on the selected domain that Browser-Based RUM recorded for the user during the configured time range, giving you a complete picture
 of browser activity rather than only pages that exceeded a threshold. 

 Each page appears as a card that shows the page URL, the time the user accessed it, and
 its experience score. Select any page card to open the Page Load Performance view, where you can examine the full waterfall
 breakdown of the page load and its root cause analysis. 

 Impacted Pages Only Filter 

 Use the Impacted Pages Only filter to narrow the page list to
 pages with Poor or Fair experience scores. This filter is useful when
 you need to focus your investigation on pages that degraded user experience without
 scrolling through pages that performed well. 

 When the filter is active, only pages with a Poor or Fair experience score appear in
 the list. Clear the filter to return to the full All Pages 
 view. 

 Page Card Fields 

 Each page card in the All Pages section displays the
 following information: 

 Field Description 

 Timestamp The date and time when the user navigated to the page. 

 Page URL The full URL of the page the user loaded. Select the card to open
 the Page Load Performance 
 view for that transaction. 

 Experience Score The score that ADEM assigned to the page
 transaction based on its load performance metrics. Good 
 scores appear in green, Fair in orange, and Poor in
 red. 

 Page Load Time The total elapsed time for the page to fully load, from
 navigation start to the browser load event. 

 Browser The browser that the user was running when the page
 loaded.
