 GlobalProtect App 6.2.8-h13 (6.2.8-c1045) Windows and macOS Addressed Issues 

 Lists the issues addressed in GlobalProtect 6.2.8-h13 (6.2.8-c1045). 

 The following table lists the issues addressed in GlobalProtect app 6.2.8-h13 (6.2.8-c1045)
 Windows and macOS. 

 Issue ID 

 Description 

 GPC-27179 

 Fixed an issue where GlobalProtect portal registration was prevented during SAML authentication
 hand-off, which caused agents to remain disconnected despite
 successful authentication with an identity provider. This occurred
 because an internal data buffer became corrupted during the
 authentication token hand-off, which led to the loss of session
 identity. With this fix, the authentication token is correctly
 processed, allowing agents to register with the portal. 

 GPC-27177 

 Fixed an issue where GlobalProtect Host Information Profile (HIP) reports had an invalid XML
 format. With this fix, HIP reports are generated with the correct
 XML structure.
