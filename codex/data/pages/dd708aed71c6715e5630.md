 Add a Desktop App Peripheral to Endpoint DLP 

 Manually add a desktop app peripheral to Enterprise Data Loss Prevention (E-DLP) for protection
 using Endpoint DLP. 

 Obtain the Microsoft OneDrive and Google Drive domains that you want to
 enforce. 

 Log in to 
 Strata Cloud Manager . 

 Select Configuration Data Loss Prevention Settings Peripheral Configuration and Add Peripheral . 

 Choose Desktop App from the Peripheral Type
 dropdown. 

 Configure the details for the desktop app peripheral you're adding. 

 The desktop app peripheral Name and App
 Type are required. 

 Name —Name of the desktop app peripheral. The
 Name is displayed in Strata Cloud Manager 
 when managing your Endpoint DLP configuration and in your Enterprise DLP incidents. 

 App Type —Select a supported desktop
 app . 

 ( Optional ) Domain Name —Enter a domain
 name to restrict enforcement to a specific corporate instance of the
 app. For example, enter your organization's domain to target only
 company-managed accounts. 

 ( Optional ) Description —Description
 of the desktop app peripheral. 

 Click Save . 

 Create a Peripheral Group to group multiple desktop app peripherals and apply the same
 security enforcement. 

 You must create peripheral groups to create an Endpoint DLP policy rule .
