 Set Up the Prisma Agent System Tray Icon on Red Hat Enterprise
 Linux 

 Install the AppIndicator GNOME extension on Red Hat Enterprise Linux to enable the
 Prisma Agent system tray icon before installation. 

 Where Can I Use This? What Do I Need? 

 Prisma Agent 

 Any supported RHEL distribution with the GNOME desktop
 environment 

 Administrator (sudo) privileges 

 Prisma Agent 26.2 

 Before you install the Prisma Agent on Red Hat Enterprise Linux (RHEL),
 you need to set up the system tray icon functionality for Prisma Agent by installing the required GNOME extensions. 

 Enable the EPEL repository in the Terminal: 

 sudo dnf install epel-release 

 Install the GNOME Extension Manager to easily manage extensions: 

 sudo dnf install gnome-shell-extension-appindicator 

 Apply the changes by logging out of the operating system and logging back in
 again. 

 Install the AppIndicator Support extension. 

 Open the Extensions application. 

 Search for the AppIndicator and KStatusNotifierItem
 Support extension. 

 Enable the extension by toggling it on. 

 Proceed with the Prisma Agent . 

 Verify the functionality by confirming the Prisma Agent system
 tray icon appears correctly in the GNOME top bar, providing access to the Prisma Agent app.
