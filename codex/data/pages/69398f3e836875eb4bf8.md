 dump lldp config 

 Use the dump lldp config command to
view the LLDP configuration of a selected interface or all the interfaces. 

 Command 
 dump lldp config
<all> dump lldp config interface=9 

 Options 

 Interface ID Enter the interface ID to display LLDP configuration
for a specific interface. 

 All Enter all to display LLDP configuration for
all interfaces. 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands — 

 Introduced in Release 6.0.2
