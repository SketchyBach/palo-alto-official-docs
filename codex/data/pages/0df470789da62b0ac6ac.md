 Skip Software Version Upgrade 

 You can now skip software versions when upgrading PAN-OS. 

 In PAN-OS 11.0, you can now skip up to three software versions when upgrading or downgrading
 standalone devices or Panorama managed devices running PAN-OS 10.1 or a
 later release . This feature builds on the Simplified Software Upgrade process introduced
 in PAN-OS 10.2, which includes capabilities such as a multi-image download option and a
 pre-install validation check, to make the upgrade process even faster.
