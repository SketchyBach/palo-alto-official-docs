 Delete SaaS Apps Managed by SSPM 

 Offboard SaaS apps for SSPM. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 SaaS Security Posture Management license 

 Or any of the following licenses that include the Data Security license: 

 CASB-X 

 CASB-PA 

 When you delete a cloud app, SaaS Security Posture Management (SSPM) purges all related cloud app data from
 SSPM, removes the cloud app from the Dashboard, and relinquishes permissions to
 access the cloud app. 

 Delete a cloud app if
your organization no longer uses the cloud app and you have no need
to view the misconfigurations that SSPM detected for the cloud app. 

 Log in to 
 Strata Cloud Manager . 

 Select Configuration SaaS Security Posture Security Applications . 

 Locate the tile for the SaaS Application you want to
offboard, then View Details . 

 Click the gear to edit the app settings. 

 Click Delete Instance . 

 Delete after confirmation.
