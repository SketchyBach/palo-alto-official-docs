 Copy issues 

 Copy issue details, rows, or URLs for sharing and analysis in Cortex XSIAM. 

 You can copy issue text into memory and paste it into an email. This is helpful if you need to share or discuss a specific issue with someone. If you copy a field value, you can also paste it into a search or begin a query. 

 How to copy an issue value 

 From the Issues page, right-click the issue you want to send. 

 Select one of the following options: . 

 Copy text to clipboard 

 Copy entire row 

 Copy issue URL 

 Cortex XSIAM saves the copied text to memory. 

 Paste the URL into an email or use it as needed to share the information.
