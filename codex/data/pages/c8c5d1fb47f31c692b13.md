 Call Quality Monitoring for Browser-Based Applications 

 Release Date: August 2026 
 | 
 Last Updated: August 2026 

 To easily identify whether video or audio degradation originates from a user's device, local network, or application platform, Autonomous DEM (ADEM) now supports Browser-Based Call Quality Monitoring . This feature helps in troubleshooting application experience issues for browser-based unified communications and contact center platforms with real-time visibility into active sessions. 

 The ADEM browser extension starts monitoring automatically when it detects an active WebRTC session on a supported application domain, such as Dialpad, Genesys Cloud CX, Five9, RingCentral, Cisco Webex, or Google Meet. This feature correlates real-time WebRTC telemetry with endpoint health signals, such as CPU utilization and memory pressure, to provide automatic root-cause attribution across device, network, and application segments. Centralized dashboards display a network-wide view of call performance and geographic distribution, enabling you to isolate site-specific network issues from widespread platform outages. This automatic tracking helps you resolve performance bottlenecks before they impact operations.

 Page Load Performance and Device Metrics for Browser-Based Applications 

 Release Date: August 2026 
 | 
 Last Updated: August 2026 

 To easily investigate page load delays by phase and eliminate guesswork when troubleshooting bottlenecks in network connection, server response, or client-side rendering, Autonomous DEM introduces Page Load Performance Waterfall . 

 The ADEM browser extension automatically captures standard timing data for every full page load and organizes it into sequential phases, including network connection, response waiting times, and rendering. An integrated root-cause engine analyzes this data to generate natural-language explanations of performance lags and suggest targeted remediation steps. 

 Additionally, enhanced device visibility now displays separate hardware metrics for memory, CPU, and disk, alongside trend charts that update every 30 seconds. These correlated insights help you quickly determine whether device resource constraints contributed to a slow page load.
