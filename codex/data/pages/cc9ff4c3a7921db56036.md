 Create an Endpoint DLP USB Peripheral Group 

 Create a USB peripheral group to apply the same data loss prevention enforcement to
 multiple USB devices at once. 

 Log in to 
 Strata Cloud Manager . 

 Select Configuration Data Loss Prevention Settings Peripheral Configuration . 

 Add USB peripheral devices to Enterprise DLP . 

 In the Onboarded Peripherals , select USB
 Device . 

 Select one or more USB devices and click Add/Create
 Group . 

 Add the selected USB devices to a peripheral group. 

 Add to USB Group 

 Select this option if you already created a USB peripheral group and
 want to add the selected devices to an existing peripheral
 group. 

 To add the selected USB peripherals to an existing peripheral group,
 choose the target Group from the
 dropdown. 

 Create USB Group 

 Select this option if no USB peripheral group exists or if you want
 to create and add the selected USB devices to a new peripheral
 group. 

 Enter a peripheral group Name to add the
 selected USB devices to a new peripheral group. 

 Click Save . 

 Push your new peripheral group configuration to the Prisma Agent . 

 Select Endpoint DLP Policy Push Policies and click Push Policies . 

 ( Optional ) Enter a Description for the
 Endpoint DLP policy push. 

 Review the Push Policies scope to understand the changes included in
 the Endpoint DLP configuration push. 

 Click Push . 

 Create an Endpoint DLP Policy Rule .
