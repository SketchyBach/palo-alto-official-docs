 Verify Prisma Agent Configuration Profiles on macOS 

 Verify that the Prisma Agent configuration profiles are correctly applied on enrolled
 macOS endpoints. 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 NGFW (Managed by Panorama) 

 The basic Prisma
 Agent configuration profiles deployed to managed
 endpoints 

 ( Optional ) The Endpoint DLP
 configuration profile deployed, for organizations
 using Endpoint DLP 

 After deploying configuration profiles through Microsoft Intune, you can confirm on
 the endpoint itself that the profiles were received and applied correctly. macOS
 displays all active MDM-managed profiles in System Settings under Device Management,
 where you can inspect the payloads each profile contains. 

 On the macOS endpoint, open System Settings , search for
 Profiles , and select Device
 Management . 

 Locate the basic Prisma Agent configuration profile and, if your organization
 uses Endpoint DLP, the Endpoint DLP configuration profile in the profile
 list. 

 Double-click each profile and review its settings to confirm the correct
 payloads were applied.

 profile.
