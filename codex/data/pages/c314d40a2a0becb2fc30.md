 GCP Memorystore for Redis does not use intransit encryption misconfiguration detected in code 

 Rule Details 

 Cortex AppSec Rule ID 

 APPSEC_GCP_97 

 Category - Subcategory 

 Public Exposure - Encryption And Protocols 

 Provider 

 GCP 

 Severity 

 LOW 

 Framework 

 Terraform 

 Impact 

 This rule identifies the GCP Memorystore for Redis that are configured with disabled in-transit data encryption. It is recommended that these resources will be configured with in-transit data encryption to minimize risk for sensitive data being leaked.
