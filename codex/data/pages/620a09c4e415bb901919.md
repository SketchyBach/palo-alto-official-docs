 VM-Series Firewall Amazon Machine Images (AMI) 

 Find the AMI IDs for the PAN-OS® versions and licensing
options in supported regions. 

 The two most recent versions—2.0 and 2.1—of the CFT
for auto scaling the VM-Series firewall on AWS and the VM-Series
Auto Scale Template are supported on all supported PAN-OS releases. 

 Please use the AWS CLI to find the AMI
IDs for automating your deployment of VM-Series firewalls.
(For convenience, we captured the list of PAN-OS Images for AWS GovCloud .)
