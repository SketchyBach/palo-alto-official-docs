 Unified User Groups via Cloud Identity Engine 

 Release Date: April 2026 
 | 
 Last Updated: May 2026 

 To provide more granular visibility and consistent monitoring across your hybrid workforce, ADEM now directly integrates with the Cloud Identity Engine (CIE) to surface user groups within the ADEM dashboards . By listing user groups directly from CIE and those configured on SASE secure service, ADEM gives you a complete set of user group names for more precise user experience monitoring and filtering experience data across your entire organization. This unified approach maintains consistent visibility across Application Experience, Activity Insights, and Access Experience Management dashboards.
