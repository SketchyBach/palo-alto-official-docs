 Informational Alerts 

 Learn about informational alerts, which notify you about upcoming software upgrades
 and status for upgrades that are in progress or completed.

 Strata Cloud Manager uses the Unified Incident Framework to
 centralize incident management and provide a more contextual experience. The
 product-specific alerts and incidents are now located under Incidents . The previous Alerts &
 Incidents dashboard remains available in read-only mode for reference. 

 In Strata Cloud Manager , select Incidents Prisma Access Informational Alerts to view data about the Informational Alerts in
 your Prisma Access environment. 

 Informational Alerts notify you about upcoming software upgrades and status for
 upgrades that are in progress or completed. Select any row to see more information
 about the Alert. You can filter this table by Time Range or
 Alert Name . 

 The Informational Alerts table includes details about open
 Informational Alerts. 

 Alert Name —Unique alert name. 

 Alert Code —Unique incident code. 

 Generated —Date and time Prisma Access generated
 the incident. 

 Notifications Sent —The notifications sent about this
 alert. 

 ID —Unique alert ID.
