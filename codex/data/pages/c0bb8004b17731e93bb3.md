 Manage Autonomous DEM Agent Upgrades 

 Decide whether to manually upgrade your Autonomous DEM agents or SD-WAN remote
 sites, or upgrade them automatically. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 ADEM 

 Prisma Access license 

To manage upgrades from within the Autonomous DEM user interface: 
 To ensure optimal performance and security, Autonomous DEM agents are updated regularly. When a new version becomes available, a
 notification appears on the Access Experience Management page. Autonomous DEM 
 provides you with the flexibility to control the rollout of these updates, allowing you to
 validate new versions within your network before a full deployment. 

 You can manage
 your agent upgrades using one of the following three methods: 

 Canary Upgrade : Use this option to
 deploy the update to a specific subset of users first. This allows you to validate the new
 version in your production environment before rolling it out globally. 

 Automatic Upgrade: If no action is taken, ADEM automatically upgrade agents 30
 days after the update notification is first issued.
