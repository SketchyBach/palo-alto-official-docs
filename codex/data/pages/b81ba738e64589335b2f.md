 Use the Compromised Hosts Widget in the ACC 

 Where Can I Use This? What Do I Need? 

 NGFW (Managed by PAN-OS or Panorama) 

 Support license 

 ( Panorama ) Device management license 

 The compromised hosts widget on ACC Threat Activity , aggregates the Correlated Events and sorts them by severity. It displays the source IP
 address/user who triggered the event, the correlation object that was matched and the
 number of times the object was matched. Use the match count link to jump to the match
 evidence details. 

 For more details, see Use the Automated Correlation Engine and Use the Application Command Center .
