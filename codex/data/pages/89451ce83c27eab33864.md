 Required control plane ports 

 A Kubernetes cluster consists of a control plane and one or more worker nodes. For Cortex XSOAR, in standalone (one VM), the VM acts as both the control plane and a worker node. In multi-node clusters, the first three nodes act as both control plane and worker nodes, and any additional node added acts as a worker node. 

 The following ports are required for a control plane. They are open only between the nodes in the cluster. For standalone, none of these ports are required.
