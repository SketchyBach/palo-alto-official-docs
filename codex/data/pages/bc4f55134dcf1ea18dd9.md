Entra ID Integration
Overview

The Entra integration connects Microsoft Entra ID (formerly Azure AD) with Koi to enable automatic device group management and end user communications. Use the Entra integration to:

Fetches end user emails for notifications on policy violations and item removals

Syncs devices and users from Entra and automatically creates Koi endpoint groups based on Entra departments, assigning devices accordingly.

Note: Entra integration is supported on Windows machines only. Groups will be synced from Entra once a day.

Prerequisites

Admin access to the Microsoft Entra admin center.

Admin-role access to the Koi platform.

Requirements
Entra Credentials

You will need to provide the following credentials to Koi:

Item
Description

Tenant ID

The directory (tenant) ID from the Entra admin center — a GUID (e.g., 5434b0e3-efba-4f47-8c82-72d8db789b12)

Client ID

The Application (client) ID from the app registration

Client Secret

A client secret generated in the app registration's Certificates & secrets section

Additional Requirements

Devices must be enrolled/registered in Entra ID

Device IDs must be present on the devices (Entra device registration)

Users must have the department field populated in Entra

Setup
1. Register an Application in Entra

Go to entra.microsoft.com

Navigate to Entra ID → App registrations → New registration

Name the app (e.g., "Koi Entra Group Sync")

Set Supported account types to "Accounts in this organizational directory only"

Click Register

2. Generate Credentials

Copy the Application (client) ID from the app overview page

Go to Certificates & secrets → New client secret

Add a description (e.g., "Koi group sync integration") and pick an expiry

Copy the secret Value immediately — it is only shown once

3. Grant API Permissions

Go to API permissions → Add a permission → Microsoft Graph → Application permissions

Add the following permissions:

Device.Read.All

User.Read.All

Click Grant admin consent for [tenant name]

4. Enter Credentials in Koi

Log in to the Koi portal

Navigate to Settings → Integrations → Endpoint Groups → Entra ID

Enter your Tenant ID, Client ID, and Client Secret

Save to complete the integration

How It Works

Once connected, Koi will periodically sync with Microsoft Graph to:

Fetch all devices and users from Entra

Match Entra devices to Koi devices by device ID

Automatically create groups based on user departments and assign devices accordingly. Each device is only associated with one Koi group.
