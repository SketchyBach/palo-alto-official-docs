 Quarantine Devices Using Host Information 

 GlobalProtect allows you to quarantine compromised devices, block users from logging
 in, restrict traffic, and redistribute quarantine information using Panorama. 

 Where Can I Use This? What Do I Need? 

 NGFW (managed by Panorama) 

 Prisma Access (managed by Panorama) 

 GlobalProtect Gateway license or Prisma Access license with the
 Mobile User subscription 

 GlobalProtect allows you to either manually or automatically add
compromised devices to a quarantine list. After you quarantine the
device, you can block users from logging
into the network from that device using GlobalProtect. You
can also restrict traffic to a compromised device, from a compromised
device, or both. If you use a Panorama appliance, you can also redistribute the quarantined
device information to other next-generation firewalls. Use
the following topics to learn how to quarantine a device, including
the GlobalProtect subscription license requirements, and how to
redistribute the quarantine information.
