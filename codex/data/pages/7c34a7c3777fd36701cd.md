 Learn to delete a service definition from Panorama 

 Where Can I Use
 This? What Do I Need? 

 VMware NSX 

 VM-Series Firewall License (BYOL) 

 Panorama 

 VM-Series plugin 

 Panorama plugin for NSX 

 Complete the following procedure to delete
a service definition from your NSX-T configuration on Panorama. 

 Log in to Panorama. 

 For a security-centric deployment, delete the steering
rules and steering policy associated with the service definition
to be deleted. 

 Select Panorama VMware NSX-T Network
Introspection Rules . 

 Select the steering rules to be deleted. 

 Click Delete . 

 Select Panorama VMware NSX-T Network
Introspection Policy . 

 Select the steering policy to be deleted. 

 Click Delete . 

 Commit your changes. 

 Delete the VM-Series firewalls deployed in NSX-T that
are associated with service definition to be deleted. 

 Delete the membership criteria associated with the service
definition. 

 Select Panorama VMware NSX-T Membership
Criteria . 

 Select the criteria to be deleted. 

 Click Delete . 

 Unlink the service definition from the service manager
with which it is associated. 

 Select Panorama VMware NSX-T Service
Managers . 

 Click the service manager name. 

 Select the service definition. 

 Click Delete . 

 Click OK . 

 Commit your changes to Panorama.
