 Define the Okta Application to authenticate Cortex XSOAR 

 Define an Okta application to authenticate Cortex XSOAR 6.13. 

 You need to define the Okta application to use it in Cortex XSOAR. 

 Before you start, you need to create a group as described in Create Okta Groups for Cortex XSOAR Users . 

 Log in to Okta and click Admin . 

 Select Applications → Applications → Add Application . 

 okta-add-app.png 

 Click Create New App . 

 okta-new-app.png 

 From the Create a New Application Integration window, in the Platform field, select Web . 

 In the Sign on method field, select SAML 2.0 . 

 okta-new-int.png 

 Click Create . 

 From the General Settings section, in the App name field, type a name for the application and click Next . 

 In the SAML Settings section, add the following parameters: 

 The GENERAL parameters 

 The ATTRIBUTE STATEMENTS parameters. 

 The GROUP ATTRIBUTE STATEMENTS parameters 

 For information about the parameters, see SAML Settings for the Okta Application . 

 Click Next . 

 Select the following options: 

 okta-feedback.png 

 Click Finish . 

 When setting up the integration in Cortex XSOAR, you need to add the setup instructions and Identity Provider metadata. 

 okta-setup.png 

 Continue with Configure the SAML 2.0 Integration for Okta .
