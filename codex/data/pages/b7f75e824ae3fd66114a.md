 Active Response License 

 Review Active Response licensing options and start a 60-day free trial. 

 Active Response is an add-on module, which means you must purchase a separate license for it in addition to the Expander license. 

 Expander customers can try out the Active Response module for 60 days for no additional cost. After the 60-day free trial ends, Active Response will be deactivated. To purchase a license for the Active Response module, contact your Palo Alto Networks account representative. 

 Start Your Active Response Free Trial 

 In Expander, select Settings → Cortex XPANSE License . 

 navigate-to-license.png 

 On the License screen, click the link in the Active Response card to start your free trial. 

 start-free-trial-license.png 

 Refresh your Expander instance to see the functionality that is available as part of your Active Response free trial. 

 To begin using Active Response, see Set Up Active Response for instructions on how to configure automation integrations and remediation path rules.
