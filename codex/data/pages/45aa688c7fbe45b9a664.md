 Panorama Commit Operation is Slow 

 Incident Code 

 INC_NGFW_SLOW_PANORAMA_COMMIT_OPS 

 Severity 

 High 

 Category 

 Device 

 Subcategory 

 Management 

 Description 

 This alert indicates performance issue where the centralized management system
 for Palo Alto Networks firewalls takes an excessive amount of time to apply
 configuration changes. 

 Raise Condition 

 There is a one to one relationship between this alert and corresponding broad
 based incident. An incident is raised if 50% of commit operations take 8 or more
 minutes in 24 hours duration. It shall clear if 75% of commit operations take less
 than 8 minutes in a 24 hours duration. 

 Clear Condition 

 This incident is raised when a significant slowdown is detected in the time it
 takes to commit configuration changes. The system has determined that 50% or more
 of all commit operations over the last 24 hours have each taken longer than 8
 minutes to complete. This indicates a persistent performance issue with the
 configuration management plane. 

 Probable Root Cause Incident 

 "INC_NGFW_CONFIG_LOCK_TIMEOUT_PARTIAL_COMMIT", 

 "INC_NGFW_MGMT_EXCESSIVE_API_CALLS", 

 "INC_NGFW_SLOW_COMMIT_AFTER_DEQUEUEING"
