 Manage User and User Groups 

 Manage the user and user groups for real user monitoring. 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 Prisma Access license 

 ADEM or Strata Cloud Manager Pro 
 license 

 Prisma Browser license 

 ADEM Plugin for Prisma Access Browser 

 When monitoring is disabled at the user or user group level, data
 collection stops for those specific entities across all domains and supported
 browsers. 

 Granular monitoring configurations for specific users are only
 supported for Prisma Access ADEM customers. For customers utilizing Real User
 Monitoring exclusively through the Prisma Browser, their user list is not
 tracked in this table and they cannot configure individual user’s monitoring
 status. 

 Understanding the User and User Groups Table 
 To manage these settings,
 click Insights Application Experience Your Organization Manage Monitoring Settings Browser-based Real user monitoring and expand the User Monitoring section. 

 Managing User Monitoring Statuses 
 The User Monitoring Statuses
 follow a strict organizational hierarchy: 

 Group Exclusion Overrides: If a User Group is
 set to Excluded , that setting automatically cascades to
 all individual users within that group. 

 Locked Status: You cannot manually set an individual user to
 Included if their overarching User Group is excluded. The
 status drop down for those specific users will be disabled. 

 Managing User and User Group Status 

 Search: Use the search bar to find individual
 users by their Username or to locate specific User
 Groups . 

 Change Status: Use the Monitoring Status 
 drop down next to a user or group to select Included or
 Excluded . 

 Bulk Update: Select the check boxes next to
 multiple user or user group names, then use the Include for
 monitoring or Exclude for monitoring 
 buttons. 

 You can update a
 maximum of 100 users or user groups at a time.
