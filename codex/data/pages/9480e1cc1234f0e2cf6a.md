 PAN-OS 9.1 Administrative Session Cipher Suites 

 List of cipher suites supported for administrative sessions
on firewalls running PAN-OS® 9.1 in normal operation mode. 

 The following table lists the cipher suites for administrative
sessions that are supported on firewalls running a PAN-OS® 9.1 release
in normal (non-FIPS-CC) operational mode. 

 If your firewall is running in FIPS-CC mode, see the
list of PAN-OS
9.1 Cipher Suites Supported in FIPS-CC Mode .
