 Configure VLAN Interface and Static MAC Address 

 Configure VLANs for Layer 2 switch interfaces and understand the VLAN and interface
 limits supported by each firewall model. 

 Where Can I Use This? What Do I Need? 

 NGFW (Managed by PAN-OS or Panorama) 

 PAN-OS 12.2.2 or a later release 

 PA-500 Series: PA-550, PA-560, PA-545-POE, PA-555-POE 

 PA-1500 Series: PA-1510-POE,
 PA-1520-POE, PA-1530-POE 

 No additional license required 

 The VLAN interface provides Layer 3 routing capabilities (IPv4 and IPv6) for all Layer 2
 and Layer 2 switch interfaces belonging to that VLAN, allowing them to communicate with
 Layer 3 networks. To associate VLAN interface for the VLAN, select Network VLANs . 

 To control MAC address reachability, add static MAC entries to the MAC table specifying
 the interface through which a particular MAC address is reachable. Static entries take
 precedence over dynamically learned interface-to-MAC mappings.
