 Upgrade to Cortex XDR 5 

 Integrated Cloud Posture capabilities 

 (Requires the Cloud Runtime Security or Cloud Posture Management add-on.) 

 Cortex XDR 5 is your unified platform for end-to-end security operations, seamlessly integrating cloud posture with SOC operations. Powered by AI, automation, and data, it delivers proactive and reactive security from code to runtime, detection, and response. 

 If you’re already using Cortex XDR with Cloud, the transition to the latest version expands your license to include Cloud Posture capabilities, delivering end-to-end protection with built-in prevention and detection. 

 For more information, review the Cloud Posture Management and Cloud Runtime Security documentation, see Cortex Cloud documentation .
