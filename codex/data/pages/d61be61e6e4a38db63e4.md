 ADEM Settings - Health Score Profiles 

 Here’s where you can view the domain health score details that ADEM generates. 

 Column Name Description 

 Domain Health Score Metric Name Lists the domains for which ADEM calculates
 health score metrics. Click on a Domain name in this column to view
 its metrics. These metrics include the lower and upper thresholds
 and how much the numbers impact the total experience score when they
 cross the thresholds. These metrics are not editable. 

 Type Domain Type 

 Associated Use Case The dashboard or widget on which the calculated experience score
 displays.
