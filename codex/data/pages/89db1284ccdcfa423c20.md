 Troubleshoot the Integration Process and Standard VPNs 

 Monitor the CloudBlade integration process and view common troubleshooting
 scenarios. 

 Where Can I Use This? What Do I Need? 

 Supported CloudBlades: 

 Prisma Access for Networks (Managed by Panorama) 

 Prisma Access for Networks (Cloud Managed) 

 Prisma SD-WAN 

 Prisma Access 

 Supported Cloud Plugin Versions 

 Prisma Access for Networks (Managed by Panorama) CloudBlade versions 3.x.x and
 later 

 Prisma Access for Networks (Cloud Managed) CloudBlade versions 3.x.x and
 4.x.x 

 The Prisma SD-WAN controller configures the on-premise Panorama system and remote
 networks, which in turn configures and modifies the Prisma Access for Networks
 CloudBlade instances and VPNs. Understanding this integration process is key in
 resolving problems or issues as they occur. 

 All application and path metrics are collected and reported, and application monitoring
 alarms and alerts are generated for Standard VPNs. To troubleshoot Standard VPNs, you
 can view Alerts and Incidents, and Connectivity of Standard VPNs at the site level. You
 can view Activity charts to identify possible issues with the VPN. In addition, you can
 use device toolkit commands to view Standard VPN statistics, status, and summary.
