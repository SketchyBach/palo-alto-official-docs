 SSPM Feature Updates (June 2025) 

 Release Date: June 2025 
 | 
 Last Updated: July 2026 

 We are regularly improving and enhancing functionality in SaaS Security Posture Management (SSPM) . Some enhancements for June 2025 include the following enhancements: 

 New Microsoft Teams Connector : We have introduced an improved Microsoft Teams connector. This new connector uses a Microsoft Entra (formerly Azure) service principal to access the Microsoft Graph API for scans. This connector replaces an earlier connector that also used the Microsoft Graph API (removed in May 2025) and a connector that used data extraction techniques for scans (removed in June 2025). This new connector enables SSPM to detect significantly more application settings. 

 Third-Party Plugin Scans for Microsoft Teams : The 3rd Party Plugins page in SSPM displays a table of all the third-party plugins installed in instances of certain marketplace apps. We have added support for Microsoft Teams. 

 Added Identity Support : The Identity Security component of SSPM uses information from an instance of a supported application and, optionally, your identity provider to give you visibility into account risks. As part of an ongoing effort to support more applications, we now provide account risk information for the following additional applications:
