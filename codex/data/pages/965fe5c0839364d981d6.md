 Debug Commands 

 Debug commands enable users to debug and troubleshoot
interfaces, devices, and routing. This command option is available
only to the Super and Read Only user roles. 

 The debug command enables you to leverage debugging
commands such as tcpdump and reboot and also to debug and troubleshoot
interfaces, devices, and routing. Only SUPER users are allowed to
execute Debug commands.
