 Onboard a Convo App to SSPM 

 Connect a Convo App instance to SSPM to detect posture risks. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 SaaS Security Posture Management license 

 Or any of the following licenses that include the Data Security license: 

 CASB-X 

 CASB-PA 

 For SSPM to detect posture risks in your Convo instance, you must onboard your Convo
 instance to SSPM. Through the onboarding process, SSPM logs in to Convo using
 administrator account credentials. SSPM uses this account to scan your Convo
 instance for misconfigured settings. If there are misconfigured settings, SSPM
 suggests a remediation action based on best practices. 

 SSPM gets access to your Convo instance by using Okta SSO credentials that you
 provide during the onboarding process. For this reason, your organization must be
 using Okta as an identity provider. The Okta account must be configured for
 multi-factor authentication (MFA) using one-time passcodes. 

 To onboard your Convo instance, you complete the following actions: 

 Collect Information for Accessing Your Convo Instance 

 Connect SSPM to Your Convo Instance 

 Collect Information for Accessing Your Convo Instance 

 To access your Convo instance, SSPM requires the following information, which you
 will specify during the onboarding process. 

 Item Description 

 User email An email address of an Okta user account.

 (Required Permissions) The user must be a
 Convo administrator. 

 Password The password for the Okta user account. 

 Okta Domain The Okta subdomain for your organization. The
 subdomain was included in the login URL that Okta assigned to
 your organization. 

 MFA Secret Key A key that is used to generate one-time passcodes
 for multi-factor authentication. 

 As you complete the following steps, make note of the values of the items
 described in the preceding table. You will need to enter these values during
 onboarding to access your Convo instance from SSPM. 

 Identify the Okta user account that SSPM will use to access your Convo
 instance. The user must be a Convo administrator. SSPM needs this
 administrator access to monitor your Convo instance. 

 To access the administrator account using Okta
 credentials : 

 Identify your Okta subdomain . 

 Generate and copy an MFA
 secret key . 

 Connect SSPM to Your Convo Instance 

 By adding a Convo app in SSPM, you enable SSPM to connect to your Convo
 instance. 

 Log in to 
 Strata Cloud Manager . 

 Select Configuration SaaS Security Posture Security Applications Add Application and click the Convo tile. 

 Under posture security instances, Add Instance or,
 if there is already an instance configured, Add New 
 instance. 

 Choose the option to Log in with Okta . 

 Enter the user credentials, Okta domain, and MFA secret key for accessing
 your Convo instance and Connect .
