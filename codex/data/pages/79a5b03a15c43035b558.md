 dump servicelink stats 

 Use the dump servicelink stats command
to display statistics on standard VPNs. 

 Command 

 dump servicelink stats (
 sldev = |
 slname =)

 Options 

 sldev Enter the standard VPN number to view the statistics
for a standard VPN. 

 slname Enter the standard VPN interface name to view
the statistics for a standard VPN. 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands 

 dump servicelink summary 

 dump servicelink status 

 Introduced in Release 4.7.1 

 Example 

 dump servicelink stats slname=sl1
