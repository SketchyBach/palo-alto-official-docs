 Integrate Device Security with Philips Focal Point 

 Integrate Device Security with Philips Focal Point to enrich the asset
 inventory with device attributes for connected medical equipment. 

 Where Can I Use This? What Do I Need? 

 Device Security (Managed by Strata Cloud Manager) 

 (Legacy) IoT Security (Standalone portal) 

 One of the following subscriptions: 

 Device Security subscription

 Precision AI bundle subscription

 Device Security X subscription

 One of the following Cortex XSOAR setups:

 A free, cohosted, limited-featured
 Cortex XSOAR instance

 AND 

 A free Cortex XSOAR Engine (on-premises integration)

 A full-featured Cortex XSOAR server

 Philips Focal Point is a hospital patient monitoring network management platform that
 provides a centralized, near real-time overview of patient monitoring devices and other
 connected medical equipment on your network. Integrating Focal Point with
 Device Security lets Device Security discover and enrich device records for
 medical equipment that Focal Point manages, giving you a more complete picture of your
 connected device inventory.

 Device Security uses the integration to import devices and device attributes from
 Focal Point. Device Security learns about devices such as hosts, monitors, access
 points, and AP controllers. For each device, Focal Point sends network identity
 information such as hostnames, IP and MAC addresses, as well as hardware details
 including firmware versions and serial numbers. The integration also ingests Focal Point
 specific attributes to Device Security , such as the connected host for endpoints,
 and each device's zone path, which reflects the domain, institution, and zone hierarchy
 within Focal Point to which the device belongs.

 Philips Focal Point uses SNMP to communicate with users' environments and to export
 asset data. Integrating Device Security with Philips Focal Point requires configuring
 your Philips Focal Point server with SNMP v2c for SNMP crawling.

 For a full list of attributes that Device Security can learn through the
 integration, see
 Philips Focal Point Attribute Reference .

 Integrating with Philips Focal Point requires either a
 full-featured Cortex XSOAR server , or the
 activation 
 of a Device Security free
 cohosted Cortex XSOAR instance 
 and a free Cortex XSOAR engine.
