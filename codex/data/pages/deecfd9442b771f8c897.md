using the API, see Work With Objects (REST API) or Create a Security Policy Rule (REST API) .

 Action Example of Query Parameters in URL 

 List 

 GET https://<firewall or Panorama IP>/restapi/v11.0/<resource URI>?location=location&output-format=json 

 Create 

 POST https://<firewall or Panorama IP>/restapi/v11.0/<resource URI>?location=location&name=name 

 Edit 

 PUT https://<firewall or Panorama IP>/restapi/v11.0/<resource URI>?location=location&name=name 

 Delete 

 DELETE https://<firewall or Panorama IP>/restapi/v11.0/<resource URI>?location=location&name=name 

 Rename 

 POST https://<firewall or Panorama IP>/restapi/v11.0/<resource URI>:rename?location=location&name=name &newname=newname 

 Move 

 POST https://<firewall or Panorama IP>/restapi/v11.0/<resource URI>:move?location=location&name=name &where=<move to>
