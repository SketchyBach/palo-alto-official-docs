 Get started with Cortex XSIAM APIs 

 Using the Cortex XSIAM APIs, you can integrate Cortex XSIAM with third-party apps or services to ingest alerts, manage incidents, and automate investigation and response programmatically. The APIs let you build integrations that extend Cortex XSIAM across your security operations workflows. 

 Before you can begin using Cortex XSIAM APIs, you must generate the following items in Cortex XSIAM: 

 Value 

 Description 

 API Key 

 The API Key is your unique identifier used as the Authorization:{key} header required for authenticating API calls. Depending on your desired security level, you can generate two types of API keys, Advanced or Standard, from Cortex XSIAM. 

 API Key ID 

 The API Key ID is your unique token used to authenticate the API Key. The header used when running an API call is x-xdr-auth-id:{key_id} . 

 FQDN 

 The FQDN is a unique host and domain name associated with each tenant. 

 Cortex XSIAM API URIs are made up of your tenant's FQDN, the API name, and endpoint path. For example, https://api-{fqdn}/xsiam/public/v1/{endpoint_path}/.
