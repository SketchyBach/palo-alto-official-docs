 Issues Addressed in Prisma Agent 25.6 

 Review the issues addressed in Prisma Agent 25.6. 

 The following table lists the issues addressed in Prisma Agent version
 25.6. 

 Issue ID Description 

 PANG-8845 

 Fixed an issue where the Prisma Agent would stop
 sending HIP reports after the user's session token expired.
 Although the agent successfully obtained a new session token, it
 failed to resume HIP report submissions. The agent now continues
 to send HIP reports after reauthentication. 

 PANG-8200 

 Fixed an issue where running the pasrv debug 
 command in Debug mode caused the Prisma Agent daemon to crash. This command is no longer
 supported and has been removed from the agent.
