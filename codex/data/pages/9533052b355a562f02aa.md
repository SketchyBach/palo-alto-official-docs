 AL_ZTNA_CONNECTOR_APP_STATUS_DOWN_PARTIAL 

 Learn about the AL_ZTNA_CONNECTOR_APP_STATUS_DOWN_PARTIAL alert. 

 Synopsis 

 The alert is raised when an application in the connector-group is partially
 unreachable because some of the tunnels in a connector-group are down or some of the
 connectors cannot probe the application. The alert is cleared when the application
 becomes reachable from all connectors in the connector-group. 

 Alert Code—AL_ZTNA_CONNECTOR_APP_STATUS_DOWN_PARTIAL

 Prisma Access
