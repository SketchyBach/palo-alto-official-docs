 A successful SSO sign-in from TOR 

 Synopsis 

 Field 

 Value 

 Activation Period 

 14 Days 

 Training Period 

 30 Days 

 Test Period 

 N/A (single event)

 1 Hour 

 Required Data 

 Requires one of the following data sources:
AzureAD OR Azure SignIn Log OR Idira OR Duo OR Okta OR OneLogin OR PingOne 

 Detection Modules 

 Identity Analytics 

 ATT&CK Tactic 

 Initial Access (TA0001), Command and Control (TA0011) 

 ATT&CK Technique 

 Proxy: Multi-hop Proxy (T1090.003), Valid Accounts (T1078) 

 Severity 

 High 

 Description 

 A successful sign-in from a TOR exit node. 

 Attacker's Goals 

 Gain initial access to organization and hiding itself. 

 Investigative actions 

 Block all web traffic to and from public Tor entry and exit nodes. 

 Search for additional logins from the same user around the alert timestamp.
