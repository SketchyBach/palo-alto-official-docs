 INC_RN_SECONDARY_TUNNEL_DOWN 

 Learn about the INC_RN_SECONDARY_TUNNEL_DOWN incident. 

 Synopsis 

 The remote network secondary WAN tunnel is down. 

 Incident Code—INC_RN_SECONDARY_TUNNEL_DOWN 

 Required License 

 AI-Powered ADEM 

 Remediation 

 Review the remote peer device for any error logs that correlate with this
 incident. 

 Review system logs for the impacted site and interpret the Strata Access Location VPN
 system log errors . 

 Check with your networking team for any recent changes to the remote device,
 such as routing changes, recent change controls related to this site, or tunnel
 configuration changes. 

 Take a packet capture on the remote VPN peer or in-path devices to confirm
 reachability between the Prisma Access location and the remote peer. 
 Perform a ping or traceroute from
 the impacted site. 

 If you don't observe any IKE or ping responses, you
 can try to rekey the tunnel from the remote site. 

 Check with your ISP for any recent outages or issues pertaining to this network
 path.
