 dump user-id status 

 Use the dump user-id status command to display the status of the
 User-ID service and its functionality. 

 Command 

 dump user-id status 

 Options 

 None 

 Command Notes 

 This command is applicable for Data Center ION devices only. 

 Role Super, Read Only, Monitor 

 Related Commands — 

 Introduced in Release 6.2.1 

 Example 

 dump user-id status
User-ID service running
User-ID functionality is active
