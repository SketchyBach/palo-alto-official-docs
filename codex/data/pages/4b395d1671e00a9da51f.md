 Send Logs 

 Learn how to send logs from the Cortex XDR Agent app for iOS to Palo Alto Networks for analysis. 

 Send logs from the Cortex XDR Agent app for iOS to Palo Alto Networks for analysis. 

 From the home screen, select Settings → Generate Support File . 

 The support file is generated locally, and is accessible by the user using your device's Files app. From there you can copy/send/share the support zip file. 

 Administrators can request and retrieve the support file using Cortex XDR or Cortex XSIAM, using either the All Endpoints page or the incident response Action Center . As a result of the request, the Cortex XDR agent app for iOS will generate the support file and will automatically upload it to Cortex XDR or Cortex XSIAM.
