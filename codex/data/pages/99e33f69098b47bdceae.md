 Reports Tab Migration 

 As of 23 April 2025, SaaS Risk Assessment and GDPR Reports have been moved to Strata Cloud Manager . New
 reports can be generated only from Strata Cloud Manager Reports . 

 Historical SaaS Risk Assessment reports will be available for download in Data Security till 31 July 2025. To view your historical reports, select Strata Cloud Manager SaaS Security Data Security Reports .
