 Compliance Controls 

 Rule Association 

 Controls can optionally include a rule_ids array when being created or updated. When provided on create, the given rules are associated with the newly created control. When provided on update, the control's existing rule associations are completely replaced by the provided list. 

 Required license: Cortex Cloud Runtime Security or Cortex Cloud Posture Management.
