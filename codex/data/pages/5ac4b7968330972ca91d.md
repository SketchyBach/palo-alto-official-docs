 inspect system arp 

 Use the inspect system arp command
to inspect the address resolution protocol (ARP) table and displays
the ARP cache for all or a specific interface. 

 Command 

 inspect system arp ( all | interface= interface name ) 

 Options 

 all Enter all to inspect the entire ARP cache. 

 interface Enter interface to inspect the ARP cache for
a specific interface name or ID. 

 Command Notes 

 Role Super, Read Only 

 Related Commands — 

 Introduced in Release 4.4.1

 inspect system arp all
