 USB Flash Drive Support 

 Configure USB flash drive support for Palo Alto Networks firewall bootstrap
 operations and initial device setup procedures. 

 Where Can I Use This? What Do I Need? 

 NGFW (Managed by PAN-OS or Panorama) 

 No prerequisites needed 

 The USB flash drive that bootstraps a hardware-based
Palo Alto Networks firewall must support one of the following: 

 File Allocation Table 32 (FAT32) 

 Third Extended File System (ext3) 

 The firewall can bootstrap from the following flash drives with
USB2.0 or USB3.0 connectivity:
