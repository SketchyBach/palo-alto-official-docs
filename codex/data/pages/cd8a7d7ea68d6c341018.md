 GCP KMS crypto key is anonymously accessible misconfiguration detected in code 

 Rule Details 

 Cortex AppSec Rule ID 

 APPSEC2_GCP_6 

 Category - Subcategory 

 Public Exposure - Encryption And Protocols 

 Provider 

 GCP 

 Severity 

 MEDIUM 

 Framework 

 Terraform, Terraform Plan 

 Mapped CSPM/KSPM Rule 

 4b718a26-51ce-47d3-bb0a-1ba56d4a528f 

 Impact 

 It is recommended that the IAM policy on Cloud KMS cryptokeys should restrict anonymous and/or public access. Granting permissions to allUsers or allAuthenticatedUsers allows anyone to access the dataset. Such access might not be desirable if sensitive data is stored at the location. In this case, ensure that anonymous and/or public access to a Cloud KMS cryptokey is not allowed.
