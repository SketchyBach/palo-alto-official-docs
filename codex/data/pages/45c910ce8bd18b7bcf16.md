 5G Security 

 Topics related to 5G security on supported next-generation
firewalls. 

 You can enable three types of security on supported firewalls to protect 5G
 networks: network slice security, equipment ID security, and subscriber ID security. 

 For platform support and capacity information, see the Compatibility Matrix .
