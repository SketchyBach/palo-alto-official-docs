 Enable Prisma Agent 

 Enable self-service onboarding for Prisma Agent with flexible activation,
 deactivation, and 60-day data retention for seamless deployment management. 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Panorama) 

 NGFW (Managed by Panorama) 

 Check the prerequisites for the deployment you're
 using 

 Before you can onboard your users to Prisma Agent , you must enable Prisma Agent . After you enable Prisma Agent , you can configure the agent and
 push the configuration to your endpoints, and the Prisma Agents that are
 installed on the endpoints will be able to send traffic to the gateway.

 To enable Prisma Agent : 

 Launch the Prisma Agent configuration interface. 

 For Panorama Managed Prisma Access deployments: 

 From Panorama, select Panorama Cloud Services Prisma Access Agent Launch Prisma Access Agent . 

 Navigate to the Prisma Agent Setup page by selecting
 Configuration Prisma Access Agent Settings . 

 For Panorama Managed NGFW deployments: 

 Log in to Strata Cloud
 Manager as the administrator. 

 Navigate to the Prisma Agent Setup page by selecting
 Configuration Prisma Access Agent Settings . 

 Enable Prisma Access Agent . 

 Set up the Prisma Agent domain name. 

 In the Infrastructure tab, select the
 Domain Name settings. 

 Add a hostname to the Domain Name for the
 service that the Prisma Agent connects to. This domain name
 is sometimes called the server name or Endpoint Manager FQDN. 

 By default, users can access the service using an FQDN based on the
 hostname and the epm.gpcloudservice.com 
 domain. This FQDN will be published to the public domain name
 servers. You cannot change the
 epm.gpcloudservice.com domain. 

 Save the domain name setting. 

 Continue to Set Up the Infrastructure for Prisma Agents . 

 Disable Prisma Agent 

 You can disable Prisma Agent if your enterprise fleet no longer uses it or
 you have ended your trial of Prisma Agent . 

 When you disable Prisma Agent , the system preserves your configuration
 data for 60 days, allowing you to re-enable the service with your previous
 settings intact. During deactivation, all Prisma Agent -specific pages are
 hidden from the navigation menu. Disabling the agent will affect all connected
 agents and will deactivate agents. 

 Launch the Prisma Agent configuration interface. 

 For Panorama Managed Prisma Access deployments: 

 From Panorama, selecting Panorama Cloud Services Prisma Access Agent Launch Prisma Access Agent . 

 Navigate to the Prisma Agent Setup page by
 selecting Configuration Prisma Access Agent Settings . 

 For Panorama Managed NGFW deployments: 

 Log in to Strata Cloud
 Manager as the administrator. 

 Navigate to the Prisma Agent Setup page by
 selecting Configuration Prisma Access Agent Settings . 

 In Infrastructure , select the settings icon in the
 Setup section. 

 Disable Prisma Access Agent and
 Save your setting. 

 Confirm that you want to disable the Prisma Agent . 

 Select Push Config Push to Push the Prisma Agent Configuration .
