 Enable the Access Agent 

 Learn how to enable the Access Agent as a mobile user connection type. 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access 5.1 Innovation 

 macOS 14 and later or Windows 10 version 2024 and later desktop devices 

 Prisma Access 
 license with the Mobile User subscription 

 Role: Superuser 

 Before you can onboard your users, you must enable Access
 Agent as a mobile user connection type using Strata Cloud Manager .
 After you enable the connection type, the Prisma Agents installed on
 mobile user devices will be able to send traffic to Prisma Access . 

 Before you begin to enable the Prisma Agent , ensure that you Authorize User Group Mapping in Cloud Identity Engine for Dynamic Privilege Access . 

 Select Configuration NGFW and Prisma Access Configuration Scope Prisma Access Mobile Users . 

 Enable the Access Agent. 

 Explicit Proxy is not supported for Prisma Access
 Agent. 

 Click Access Agent Setup to begin onboarding your mobile
 users. 

 The Access Agent Setup page appears.
