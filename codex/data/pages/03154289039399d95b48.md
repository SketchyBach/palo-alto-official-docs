 The following issues have been resolved in Cortex XDR agent release 8.7.1 

 Issue 

 Description 

 CPATR-29517 

 (Linux) 

 Fixed an issue to limit the number of open LevelDB file descriptors. 

 CPATR-29361 

 (Windows) 

 Fixed an issue to improve the stability posture of Cortex XDR agent. 

 CPATR-29351 

 (Mac) 

 Fixed an issue to correctly manage the number of open external files, to limit the impact on resources. 

 CPATR-29343 

 (Windows) 

 Fixed an issue that may occur on Windows 10 32-bit system that are older than 20H1.

 (Windows) 

 Fixed an issue that may have seen user-session events dropped.

 (Windows) 

 Fixed a rare issue that may arise on rare occasions when using the RPC tracking capability.

 (Windows) 

 Fixed an issue where ActiveScriptMarker may have been unable to retrieve script’s content.

 (Linux) 

 Fixed an issue to improve the Cortex XDR agent stability posture.

 (Windows) 

 Fixed an issue to improve and stabilize device control.
