 Enable and Configure ADEM Self-Serve 

 As an IT administrator, you
can do the following with ADEM Self-Serve: 

 Enable or disable
ADEM Self-Serve. 

 Set the threshold for
when a notification is sent to the users. 

 Select the users and
user groups for whom you want to roll out this feature. 

 Once ADEM Self-Serve is enabled for one or more users or
user group, you can view or edit the
Self-Serve related metrics for users from the Monitored
Mobile Users page in the ADEM UI. Any modifications
you make will be logged in the audit log. 

 By default,
ADEM Self-Serve is disabled. As an IT administrator, you can enable the
feature.
