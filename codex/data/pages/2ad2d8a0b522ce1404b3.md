 New Features - Autonomous DEM - May 2024 

 Access Experience: Modular Agent for ADEM and App Acceleration 

 Release Date: May 2024 
 | 
 Last Updated: June 2026 

 You could not upgrade the ADEM agent independently of GlobalProtect® or use it for capabilities beyond ADEM monitoring without deploying separate components— Access Experience Management replaces the ADEM Agent with a modular design that supports ADEM, App Acceleration, and additional capabilities from a single agent based on your activated license. Out-of-band upgrades let you update the agent on its own schedule without waiting for your next GlobalProtect release. As you license additional features, the modular design lets you activate them without redeploying GlobalProtect. 

 You can control Access Experience Agent deployment through three configuration options: install the agent on endpoints that need monitoring or acceleration, uninstall it from endpoints where you no longer need those capabilities, or retain the last agent state with no action. These options give you precise control over which endpoints run Access Experience, and you can adjust the deployment scope as your organizational requirements change without modifying your GlobalProtect configuration. 

 This separation between the agent lifecycle and GlobalProtect releases benefits teams managing large endpoint deployments. You no longer need to coordinate Access Experience updates with GlobalProtect release windows, and you can enable or disable ADEM monitoring independently of VPN configuration changes. When additional capabilities become available under your license, you can activate them for specific user populations without affecting your GlobalProtect deployment.

 Enhancements for ADEM 

 Release Date: May 2024 
 | 
 Last Updated: June 2026 

 ADEM Agent is now modularized and called Access Experience . Access Experience can be used for multiple features based on the license activated, such as ADEM and App Acceleration. Other enhancements include: 

 An agent out-of-band upgrade. 

 New Access Experience Agent configuration options for GlobalProtect version 6.3 and above: 
 Install —Install the agent on the endpoint. 

 Uninstall —Uninstall the agent from the endpoint. 

 No Action —Retain the last agent state.
