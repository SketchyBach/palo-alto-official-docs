 Strata Logging Service Addressed Issues 

 List of fixed issues in Strata Logging Service . 

 Here are Strata Logging Service issues that we’ve fixed. 

 Issue ID 

 Description 

 PAN-107852 

 Fixed an issue where the PA-7000 Series or the PA-5200 Series
 firewalls that are sending logs to Strata Logging Service , caused a delay in viewing the latest logs on Panorama. 

 APO-1646 Fixed an issue where, on Panorama, you cannot view the
 virtual system information in the logs for firewalls with multiple
 virtual systems, when the firewall is configured to send logs to the
 Strata Logging Service . 

 DIT-2422 

 Fixed an issue where Strata Logging Service shows endpoint
 logs from XDR as 0 MB, but XDR data is being received. 

 PAN-103008 

 Fixed an issue where, if your Panorama is managing firewalls running
 PAN-OS 8.0 that are sending logs to the Strata Logging Service and you have enabled Secure Client Communication, the TLS
 communication with the Strata Logging Service cannot be
 established successfully unless you use the default
 certificates. 

 PAN-100333 

 Fixed an issue where, if you deploy a new Panorama virtual appliance
 running version 8.1.2, or you have not enabled the Strata Logging Service before you upgraded the Panorama
 appliance to 8.1.2, Panorama cannot establish a connection with the
 Strata Logging Service . 

 APL-14490 

 Fixed an issue where the option to toggle log ingestion or storage for devices in the Strata Logging Service app did not function. 

 APPORTAL-477 Fixed the display issue on the Strata Logging Service Status page on the
 hub. The amount of storage space used in the EU region is now displayed
 accurately. 

 CYR-2924 
 The logs on Panorama displayed the message:
Unable to connect to API gateway. 
 This issue is fixed. 

 APO-1639 Fixed the data display issue on the ACC on
Panorama and ACC data on a firewall. 

 APO-1630 Fixed the status and the erroneous warning message that informed you about zero
 days remaining in the minimum log retention day threshold for the Strata Logging Service status on Cloud Services Status Status . 

 APO-1485 
 Fixed an issue where firewalls would occasionally disconnect from Strata Logging Service . 

 APO-1179 The Application Usage widget on  ACC Network Activity no
longer displays value as 1.84E Exabytes. 

 APO-1111 Addressed the issue that caused the ACC on
Panorama 8.0.6 to not display any data in the  ACC  widgets. 

 APO-945 Addressed the issues that caused duplicated
or missing logs on firewalls that were sending logs to the Americas
region. This issue occurred for logs from Oct 23 to Oct 30, 2017. 

 APO-888 Fixed an issue that caused incomplete sessions
to display on  ACC Network Activity . 

 PAN-885 Added support for forwarding logs from the PA-5200 Series and the PA-7000 Series
 firewalls to the Strata Logging Service . 

 APO-770 Resolved the issue that caused the key findings
and application details in the SaaS Application Usage PDF report
to be incomplete. 

 APO-764 The Cloud Services plugin no longer displays
an error after account verification that connectivity to the GlobalProtect
cloud service is temporarily unavailable. 

 APO-649 The Application using Non-Standard
Ports widget on the  ACC  now
includes only applications on non-standard ports. 

 APO-374 When refreshing firewall licenses from  Panorama Device Deployment License , Panorama will fail
to fetch the licenses if you have submitted multiple refresh requests.
To prevent this from happening, do not submit a second refresh request
until the first refresh has completed. 

 PAN-89544 The ACC on Panorama
no longer reports No data to display for graphs. 

 PAN-85265 Strata Logging Service now supports service routes. Firewalls and Panorama
 can use either the management port or a dataplane port to send
 communicate with the Strata Logging Service .
