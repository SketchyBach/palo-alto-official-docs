 Changed Features 

 These features have been modified or removed in this release. 

 FEATURE 

 DESCRIPTION 

 Access Management 

 Role setting transition : Role permissions for Report Templates, Scripts, Playbooks, and Saved Queries have changed to allow for managing access at the individual custom object level. 

 “Restricted” access : All newly created custom objects are now Restricted by default, meaning only the user who created them can access them. The access can then be changed to Public for those customers who do not require per-object access. 

 Owner-only deletion : Only the object Owner (the user who created them) or an Administrator can delete a custom object; Editors cannot.
