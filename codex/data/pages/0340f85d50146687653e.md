 PA-7500 Series Firewall Installation 

 Learn how to install the PA-7500 Series Firewall. 

 The PA-7500 Series firewall is a modular system that requires you to install
 several components, such as interface cards, during the installation process. Due to the
 weight of the firewall, we recommend that you first install the firewall appliance into the rack and
 then install the interface cards . After the firewall
 is installed in the rack (with all components installed), connect power, verify that the
 interface cards are functioning, and then connect the network and management cables. 

 The PA-7500 Series firewalls ship with racking equipment and cables that enable
 you to install the firewall in your deployment environment.
