 Learn about the Prisma Access CloudBlade Integration release 3.1 1 release
 information. 

 This document contains the Prisma Access for Networks
(Cloud Managed) CloudBlade, Version 3.1.1 release notes. 

 Features Introduced in Prisma Access CloudBlade 3.1.1 

 The new feature in the Prisma Access for Networks (Cloud Managed)
 CloudBlade version 3.1.1 includes Autonomous Digital Experience Management (DEM),
 which is a service that provides native, end-to-end visibility and application
 performance in your Secure Access Service Edge (SASE) environment. Autonomous DEM
 functionality is natively integrated into the Prisma SD-WAN ION
 device. 

 An ADEM enabled SD-WAN site can monitor all WAN paths (active and backup) based on
 forwarding policies configured on Prisma SD-WAN . It can monitor Prisma Access path, Secure Fabric path as well as Direct access path.

 Addressed Issues in Prisma Access CloudBlade 3.1.1 

 The following is an addressed issue in Prisma Access for Networks (Cloud Managed)
 Release 3.1.1. 

 ISSUE ID DESCRIPTION 

 CGCBL-788 Resolved an issue where tagging port(s) during
 new on-boarding caused existing tunnels to be reset or edited,
 resulting in traffic disruptions. The CloudBlade assigned
 identifiers used for existing tunnels to the newly created
 tunnels; hence new identifiers were created/assigned for
 existing tunnels.
