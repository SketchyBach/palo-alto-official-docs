 Describes the new features introduced in Cortex XDR agent 8.5 release. 

 The following section describes the new features introduced in Cortex XDR agent 8.5 release according to the supported agent operating systems. 

 Features Introduced in Cortex XDR Agent 8.5 

 General Features 

 The following features were added to Cortex XDR agents running on all endpoints: 

 Feature 

 Description 

 Endpoint tag removal 

 Endpoint tags that were assigned via Cytool or during installation, can now be removed via the management console. 

 Security 

 Cortex XDR agent 8.5 applies an improved security posture. 

 Forensics 

 Cortex XDR now supports Web History searches in Forensic Hunts. Browsers supported are Chrome, Edge, Firefox, Internet Explorer, and Safari along with custom searches for any Chromium-based browser.

 Feature 

 Description 

 Operating systems 

 Support for the following Linux operating systems has been added to Cortex XDR agent 8.5: 

 RedHat Enterprise Linux 9.4 x86_64 and aarch64 

 Ubuntu 22.04 aarch64
