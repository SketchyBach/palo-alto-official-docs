 dump switch vlan-db 

 Use the dump switch vlan-db command
to display the available VLANs on the switch and which members are
part of the VLAN programmed in the device. 

 Command 
 Dump switch vlan-db 

 Options 

 None 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands — 

 Introduced in Release 6.0.2
