 Known Issues— ADEM Agent for Prisma SD-WAN Remote Sites 

 Review the open issues in Remote Network Autonomous Digital Experience Management
 (ADEM) agents. 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 Prisma Access license 

 ADEM or Strata Cloud Manager Pro 
 license 

 GlobalProtect or Prisma Access Agent license 

 Here are the issues we’re currently working on. 

 Autonomous DEM Agent 3.6.40 

 ID Description 

 DEM-13278 Device model and hostname are not displayed on the
 branch site experience page. 

 DEM-12423 Network performance trend charts (latency, jitter,
 and packet loss) are missing for internet paths on the branch site
 experience page. 

 CGSDW-38932 The ADEM agent fails to operate correctly when the
 tenant ID configured in the ADEM backend does not match the SD-WAN
 tenant ID that the ION device is registered under, causing agent
 registration and authorization failures. 

 DEM-14646 The ADEM agent unexpectedly restarts when an
 unhandled error occurs on its background scheduled-test timer,
 causing repeated gaps in reported telemetry. 

 DEM-14650 When the ADEM portal reconnect takes longer than the
 standard 5-minute polling interval, the ADEM agent fails to catch
 up, missing two consecutive poll cycles. This leaves a 10-minute gap
 in experience score telemetry while the dashboard continues to
 display a normal status. 

 CGSDW-40767 On ION devices, HTTPS synthetic tests for specific
 destinations are reported as SSL failures on public-direct WAN paths
 and the application experience score shows as unavailable.
