 Add a Service Chain 

 This section describes ways to add a service chain. 

 Where Can I Use
 This? What Do I Need? 

 VMware NSX 

 VM-Series Firewall License (BYOL) 

 Panorama 

 VM-Series Plugin 

 Panorama plugin for NSX 

 A service chain is a grouping of services
set in logical sequence. When traffic is redirected to the service chain,
it moves through each service in the order you configure. 

 Select Security Network Introspection Settings Service
Chains Add Chain . 

 Enter a descriptive Name and Description ( optional )
for your service chain. 

 Select the Service Segment that
you applied when you deployed the VM-Series firewall. 

 Set the forward path. The service chain is a logical
sequence of service profiles, so traffic moves through the services
in the order you specify as the forward path. 

 Select Set Forward
Path Add Profile in Sequence . 

 Select a service profile. The service column is populated
automatically based on the service profile you select. 

 Click Add . 

 ( Optional ) If you have other partner service
profiles in your NSX-T environment, click Add Profile
in Sequence to add them to this service chain. 

 You can select only one service profile per service
definition. 

 Click Save when you have finished
adding service profiles. 

 In the Reverse Path column, check Inverse
Forward Path for return traffic
to move through the service chain in reverse order. 

 ( Optional ) If other partner service profiles
are selected, set a reverse path. 

 Select the same VM-Series service profile set in the Forward Path. 

 Select Set Reverse
Path Add Profile in Sequence . 

 Select a service profile. The service column is populated
automatically based on the service profile you select. 

 Click Add . 

 ( Optional ) If you have other, service profiles
in your NSX-T environment, click Add Profile in Sequence to
add them to this service chain. 

 Click Save when you have finished
adding service profiles. 

 Set the Failure Policy — Allow or Block .
This defines the action NSX-T takes if a service profile fails. 

 Click Save .
