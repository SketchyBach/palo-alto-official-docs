 Panorama > Collector Groups 

 Each Collector Group can have up to 16 Log Collectors,
to which you assign firewalls for forwarding logs. You can then
use Panorama to query the Log Collectors for aggregated log viewing
and investigation. 

 The predefined Collector Group named default contains the
predefined Log Collector that is local to the Panorama management
server.
