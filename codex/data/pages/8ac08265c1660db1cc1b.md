 Autonomous DEM Zoom Integration 

 ADEM provides a unified dashboard that displays near real-time Zoom meeting quality
 statistics and a root-cause analysis for any poor performing Zoom meeting
 minutes. 

 Video call traffic is very sensitive to network conditions. Performance issues that might
 not impact web browsing can be felt by users on video calls. In order to help
 administrators debug, monitor, and proactively identify the performance issues impacting
 Zoom users in their organization, ADEM has partnered with Zoom to provide the first
 per-minute root-cause analysis on the market. 

 To enable the Automomous DEM Zoom Integration feature, you will need to purchase a Zoom
 Quality of Service Subscription (QSS) license from Zoom. QSS provides a datafeed with
 call performance telemetry for every minute of every call in your organization. ADEM
 correlates this data with the endpoint, WiFi, LAN, and ISP performance data ADEM
 generates in order to pinpoint the issues causing any observed call degradation. 

 This integration provides minute-by-minute analysis of all of the Zoom calls in a
 customer's network. ADEM also rolls these insights up at the organization level so that
 customers can find the service delivery segment most impacting users. 

 The Zoom performance monitoring is restricted to the participants within the organization
 only. If a Zoom call has participants attending from outside the customer's organization
 (do not belong to the tenant being monitored), their data will not be analyzed or stored
 by ADEM. 

 Zoom integration is supported only for the TSG id migrated Prisma Access tenants.
