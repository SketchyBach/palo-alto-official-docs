 View Microsoft Teams Application Experience Data 

 View information to measure and report on any major changes in Microsoft Teams use or
 end-user experience. 

 Where Can I Use
 This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 Prisma Access license 

 ADEM or Strata Cloud Manager Pro 
 license 

 GlobalProtect or Prisma Access Agent license 

 The Microsoft Teams Application Experience page offers a
 network-wide view of the number of Microsoft Teams meetings and meeting minutes during
 the selected time range, and the total number of Microsoft Teams users in these meetings
 during the selected time range. You can use this information to measure and report on
 any major changes in Microsoft Teams use or end-user experience, as well as identify any
 emerging major issues that can affect users across your organization. 

 To view the Microsoft Teams application experience across your entire organization: 

 Go to Insights Application Experience Application Domains . 

 From Application Domains , select
 teams.microsoft.com . 

 Experiences 

 See an overview of this application's mobile user and remote site experiences during
 the time range you select. 

 Mobile User Experience —See the number of monitored mobile
 user devices in this application and whether their experiences are Good 
 (green), Fair (orange), or Poor (red), the application test being
 used, and the application target. The score at the right represents the overall
 performance metrics for monitored mobile user devices and applications across
 the service delivery path. 

 Remote Site Experience —See the number of monitored remote
 sites in this application and whether their experiences are Good (green),
 Fair (orange), or Poor (red), the application test being used,
 and the application target. The score at the right represents the overall
 performance metrics for monitored remote sites and applications across the
 service delivery path. 

 Microsoft Teams User Experience Summary 

 View the overall Microsoft Teams performance impact, including: 

 Total number of minutes ADEM users spent in meetings. 

 Total number of meetings during the time range selected. 

 Total number of users in Microsoft Teams meetings during the past month. 

 Percentage of users and meetings with issues. 

 ADEM Users 

 See the percentage of ADEM users in your organization who are using Microsoft
 Teams. 

 Microsoft Teams Poor Performance Root Cause 

 See a network-wide view of meetings performed poorly by
 Device , Local Network Performance ,
 Wi-Fi , and Internet Performance .
 To the right, you can identify how many meetings had Audio , Video , or
 Screen Sharing issues, and how many meetings these issues affected. 

 Users Experiencing Impacted Meetings 

 The Users Experiencing Impacted Meetings table lists users who are
 experiencing the highest proportion of poor-performing meetings. 

 Order —Users with issues, in descending order. 

 User Name —Microsoft Teams username. 

 Impacted Meetings —The number of meetings with issues that this user
 experienced. 

 Most Common Root Cause —Local Network, internet, Wi-Fi, or Device. 

 Remedy —Suggestion to fix the issue. 

 Global Distribution of Impacted Users 

 View a worldwide map that shows the locations of users who are having a poor
 experience. Each location has the number of users in a circle that denotes the
 percentage of users whose experiences are Good (green) or Poor (red). Slide
 Show Only Impacted Users to the right to view only users
 who are having a poor experience. Select a location to view the number of impacted
 users and meetings wolrldwide, and zoom in to a location to view impacted users and
 meetings at specific sites within the location.
