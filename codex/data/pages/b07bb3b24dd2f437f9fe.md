 Network Channels Client Versions 

 Version history of the Network Channels client
 ( panw-network-client Helm chart), including new features and fixes for
 each release. 

 Where Can I Use This? What Do I Need? 

 Prisma AIRS (AI Red Teaming) 

 Prisma AIRS AI Red Teaming License 

 Prisma AIRS AI Red Teaming Deployment Profile 

 When you create a Network Channel or upgrade the client using the
 procedures in Networks Channels Management , you specify the
 panw-network-client Helm chart version to deploy. The following
 table lists all available versions and the new features and bug fixes introduced in each
 version. 

 Version New Features Fixes 

 1.4.3 

 NA 

 Security patches —This release updates the Network Channels
 client's Go runtime, Go dependencies, and base operating-system
 image to address published vulnerabilities. There are no functional
 or configuration changes. 

 1.4.2 

 NA 

 SSL certificate verification for custom target adapters —When
 you disable SSL certificate verification in the Helm chart, it now
 applies to traffic sent to custom targets through the adapter
 sidecar. 

 1.4.0 

 Custom target adapters —Integrate custom targets by running
 your own adapter scripts alongside the
 Network Channels client. Enable the optional adapter sidecar in the
 Helm chart (disabled by default), and the client securely routes
 custom-adapter traffic through the tunnel. 

 More reliable automated upgrades —Automated upgrades that reuse
 your existing configuration no longer fail when the adapter sidecar
 option isn't set. 

 1.3.3 

 NA 

 Custom CA certificate startup fix —If you configured a
 custom CA certificate, your deployment could become unresponsive
 during startup in version 1.3.2. This version resolves the
 issue. 

 Security patches —This version addresses vulnerabilities
 in the network channel client. 

 1.3.0 

 WebSocket target support —The Network Channels client can now
 proxy WebSocket-based targets through the tunnel, in addition to
 HTTP/REST targets. 

 NA 

 1.2.3 

 Custom CA certificates —Run the Network Channels client behind
 a TLS-intercepting firewall by supplying your own CA certificate,
 either inline or from an existing secret. 

 NA 

 1.2.0 

 Proxy configuration —Configure HTTP/HTTPS/no-proxy settings and
 additional environment variables for the Network Channels client
 directly in the Helm chart, for deployments that egress through a
 corporate proxy. 

 NA 

 1.0.4 

 Network Channel Client Initial Version —Deploy the client
 inside your network to connect your private targets to AI Red
 Teaming over a secure outbound tunnel, with no inbound ports
 required. 

 NA
