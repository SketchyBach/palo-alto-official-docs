 Cortex XDR Agent 8.8 Release Information 

 Features introduced in Cortex XDR agent 8.8 

 Describes the new features introduced in Cortex XDR agent 8.8 releases. 

 The following section describes the new features introduced in Cortex XDR agent 8.8 releases according to the supported agent operating systems. The release is divided into three deployments, 27 April 2025, 11 May 2025, and 18 May 2025. 

 General features 

 The following is added to Cortex XDR agents. 

 Feature 

 Description 

 Performance 

 General performance improvements for policy calculation. 

 Enhancements made to improve VDI performance. 

 Cipher-Suite for ENS Spain 

 Added support of Cipher-Suite for ENS Spain. 

 Recommended alert/issue exceptions 

 To enable you to refine your BTP alert/issue exceptions, Cortex XDR/XSIAM now automatically generates more rule exception parameters based on alert/issue information and Cortex XDR/XSIAM recommendations. 

 Linux features 

 The following is added to Cortex XDR agents running on Linux endpoints. 

 Feature 

 Description 

 Enhanced ML model for detecting malicious Linux executables 

 Advanced high-accuracy detection of malicious Linux executables using a local analysis model that leverages big data, ML, and threat analysis across both on-premise and cloud environments. 

 APISec on Agent 

 Enhancements and improvements are provided for API security functions. 

 Windows features 

 The following is added to Cortex XDR agents running on Windows endpoints. 

 Feature 

 Description 

 VBscript support 

 Strengthened defense against advanced threats by using an ML-based protection model for the XDR Agent on Windows that can detect and prevent adversary techniques using VBscript files at the execution stage. 

 Mac features 

 The following is added to Cortex XDR agents running on Mac endpoints. 

 Feature 

 Description 

 Cytool commands 

 Additional macOS cytool commands have been made available.
