 Prisma Agent provides secure connectivity for end users accessing corporate
 resources through Panorama managed environments.
 This guide walks you through the setup process, from initial configuration to
 deployment and validation for Panorama Managed Prisma Access or NGFW
 deployments. For
 Panorama managed deployments, the agent integrates with existing Panorama
 infrastructure to deliver consistent security policies and centralized management
 for remote access scenarios. 

 For detailed requirements, see: 

 Prisma Agent Prerequisites

 Get Started with Prisma Agent for Panorama Managed Deployments 

 Configure and deploy the Prisma Agent in environments managed by Panorama for
 secure remote access connectivity. 

 Follow these steps to start configuring and deploying Prisma Agents in
 Panorama Managed Prisma Access or NGFW deployments. 

 Enable the Prisma Agent . 

 If you don’t already have Strata Cloud Manager, enable it for managing
 Prisma Agent configurations: 
 Follow the instructions in NGFW Support for Prisma Agent . 

 Enable Prisma Agent . 

 Configure the infrastructure settings. 

 Launch the Prisma Agent configuration interface. 

 For Panorama Managed Prisma Access deployments: 

 From Panorama, selecting Panorama Cloud Services Prisma Access Agent Launch Prisma Access Agent . 

 Navigate to the Prisma Agent Setup page by
 selecting Configuration Prisma Access Agent Settings . 

 For Panorama Managed NGFW deployments: 

 Log in to Strata Cloud
 Manager as the administrator. 

 Navigate to the Prisma Agent Setup page by
 selecting Configuration Prisma Access Agent Settings . 

 Configure the Prisma Agent Domain Name 
 (also known as the Endpoint Manager FQDN) as specified here: 
 Set Up the Infrastructure for Prisma Agents 

 Configure the following settings in Panorama: 

 Prisma Access
 Locations 

 Gateways 

 Client DNS 

 Client IP Pool 

 These configuration appears as read-only in the Prisma Agent 
 configuration interface. 

 Configure user authentication so that only legitimate Prisma Agent users
 have access to your services and applications. 

 Set up Prisma Agent User
 Authentication 

 Configure Prisma Agent components. 

 Agent Settings: Configure basic agent parameters using Set Up the Prisma Agent . 

 Gateways: Set up gateway configurations following Configure Gateways for the Prisma Agent . 

 Staged Rollouts: Configure agent upgrade phases using Staged Rollouts for Prisma Agents . 

 Global Settings: Configure application-wide settings using Configure General Global Settings for
 the Prisma Agent . 

 For external or NGFW gateways, enable the Authentication Override
 Cookie and ensure the same certificate is used across all gateways
 using Configure a Certificate to
 Decrypt the Authentication Override Cookie . 

 Forwarding Profiles: Set up traffic management using Set Up Forwarding Profiles to Manage
 Agent Traffic . 

 Deploy and validate the agent. 

 Download the Agent Package: Get the installation package using
 Download the Prisma Agent
 Package . 

 Install the Agent: Deploy the agent on client
 devices using Install the Prisma Agent or Deploy the Prisma Agent using
 MDM software . 

 Verify Functionality : Test agent connectivity and functionality
 using one of the following methods: 

 Prisma Agent for
 Desktop Devices. 

 Check the status of the agent, Endpoint Manager, and tunnel
 using the Prisma Agent commands
 (PACli) .
