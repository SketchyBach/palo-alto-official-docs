# Code Execution Instruction

For the complete documentation index, see llms.txt. This page is also available as Markdown.

Code Execution Instruction

Severity

🔵 Low (2)

Short Description

Flags AI extensions that instruct the agent to execute shell commands on the host system.

Suggestion

Expect this on most development-oriented skills and commands — running commands is usually the point. Use the evidence to confirm the commands fit the component's stated purpose, and rely on the agent's own confirmation settings as the enforcement layer.

Information

A skill, command, subagent, or rule that tells the agent to run shell commands is describing intent in natural language. Nothing executes until the agent chooses to act on the instruction, and in most configurations the user still sees a confirmation prompt before the command runs — which is why the severity is the lowest in this set.

Most development components legitimately fall into this category: build helpers, test runners, git workflows, and environment setup all instruct the agent to run commands, so the finding is largely informational. Attention is warranted when the commands do not match the component's stated purpose, or when the component also carries Safety Instruction Override (which tries to remove the confirmation step) or Unsafe Code Execution Instruction (destructive commands).

Risks

Scope creep: Commands unrelated to the component's stated purpose signal that it does more than it advertises.

Confirmation fatigue: Frequent prompts train users to approve without reading, which weakens the main control on this behavior.

Combined findings: Paired with a safety-override or destructive-command finding, the confirmation step can no longer be relied on.

Silent evolution: A later version can broaden the commands with no change to the component's description.

Recommended Actions

Investigate the component

Read the evidence and check that each command is consistent with the component's stated purpose.

Look for other findings on the same component, particularly Safety Instruction Override and Unsafe Code Execution Instruction.

Contain and remediate

Keep agent confirmation prompts enabled for shell execution.

Restrict the agent's permission allowlist to the command families the component actually needs.

Remove the component if its commands are unrelated to what it claims to do.
