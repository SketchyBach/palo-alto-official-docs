 Data Types 

 The Data Types page displays your inventory from the perspective of data types - IP addresses, email addresses, billing information, PII details, etc. From this page, you can see where each of your data types is stored, how many assets of that type Prisma Cloud DSPM has discovered, what are the risk levels associated with it, etc. You can also access a map view of the active regions in which these data types are stored.
