 Configure the Agent to Use the Default System Browser for SAML Authentication
 (iOS) 

 Configure Prisma Agent to use the default system browser for SAML authentication on
 iOS endpoints using MDM software or Strata Cloud Manager. 

 On iOS endpoints, you configure the default system browser for SAML authentication
 through MDM software before enrollment, or through Strata Cloud Manager agent
 settings after enrollment. 

 Configure the default system browser using one of the following methods. 

 MDM software (before enrollment). Push the following key-value
 pair to your iOS devices using your MDM software: 
 use_external_browser_for_auth: true 

 When the MDM key is present, Prisma Agent uses the default browser
 from the first login. When the MDM key is not present, Prisma Agent
 uses the embedded browser for the initial enrollment. After
 enrollment, the Strata Cloud Manager agent setting takes effect on
 subsequent logins. 

 ( Strata Cloud Manager only ) Strata Cloud Manager agent
 settings (after enrollment). Follow the Strata Cloud Manager agent
 settings steps in Windows and macOS. The default system
 browser takes effect after the agent receives the configuration on
 subsequent logins. 

 If you use the default system browser for SAML
 authentication, browser tabs accumulate if not closed after
 authentication.
