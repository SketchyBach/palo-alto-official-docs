 Distribution to Fabric 

 Prisma SD-WAN now supports Automated Asymmetry Correction, distribution to fabric
 option to ensure that all prefixes learned at the DC site are distributed to all Branch
 Sites. 

 Where Can I Use
 This? What Do I Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 The Distribution to Fabric feature ensures that prefixes
 learned at the Data Center (DC) site are distributed to the Branch Sites, optimizing
 network reachability. This functionality applies specifically to routes learned
 via BGP and OSPF on the DC LAN. Global Static routes and
 site prefixes are, by default, distributed to Branch Sites through the
 Controller and do not depend on this configuration. Use this feature to specify
 which Branch Sites should receive the dynamically learned prefixes for more targeted
 route distribution. 

 Select Configuration Prisma SD-WAN Data Centers , and select a site from the list of Data Center sites. 

 Select the Sites . If you want to distribute the fabric,
 click Save .
