 Setting Up the GlobalProtect App 

 The GlobalProtect app is an application that is installed
on the endpoint (typically a laptop) to support GlobalProtect connections
with portals and gateways. The app is supported by the GlobalProtect
service (PanGP Service). 

 Make sure you select the correct installation option for
your host operating system (32-bit or 64-bit). If you are installing
on a 64-bit host, use the 64-bit browser and Java combination for
the initial installation. 

 To install the app, open the installer file and follow the on-screen
instructions.
