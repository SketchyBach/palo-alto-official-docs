 User Management 

 Invite and manage users in Cortex XSOAR 6.12. 

 After you setup your email integration, you can add users to your Cortex XSOAR environment by sending an invitation. When inviting a user, you can select the role that you want to assign the user. 

 In the Users tab, you can do the following: 

 Edit the role for each user. 

 You can also set multiple roles and set the user as a default admin . 

 Reset the Password 

 If the user's account has been locked, for example, too many login attempts, you can lock or unlock the user. 

 Remove a user permanently 

 Temporarily disable or enable a user.
