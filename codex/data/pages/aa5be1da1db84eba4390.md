 dump device date 

 Use the dump device date command
to display the current date and time displayed in coordinated universal
time (UTC) on the Prisma SD-WAN ION device. 

 Command 

 dump device date 

 Options 

 None 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands 

 dump device info 

 dump device status 

 Introduced in Release 4.4.1 

 Example 

 dump device dateMon Mar 20 08:20:21 UTC 2017
