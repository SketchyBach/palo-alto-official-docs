 Create Notifications in the Notification Rules 

 In the Notification Rules, you can add custom notifications for system events such as certificate expirations or resource health changes and send them via email or through integrated notification providers. 

 Before You Begin 

 If using a notification provider such as PagerDuty or Zoom Team Chat, add it to Next-Gen Trust Security . 

 If sending certificate expiration notifications, configure the certificate monitoring service . 

 To Create a New Notification 

 Sign in to Next-Gen Trust Security. 

 Click Configuration > Certificate Notifications > Notification Rules . 

 Click New . 

 In Event Details , add the following. 

 The notification Name . 

 The Event that triggers the notification. You cannot change the event later. 

 Event Description 

 Certificate Expiration Sends a notification when a certificate nears expiration. Link the notification to a threshold defined by the certificate monitoring service . 

 cert-manager Certificate Resource Health Sends a notification when a cert-manager certificate resource switches to healthy or unhealthy status. Learn more 

 cert-manager Issuer Health Sends a notification when a cert-manager-related issuer switches to healthy or unhealthy status. Learn more 

 VSatellite Health Sends a notification when a specific VSatellite switches to healthy or unhealthy status. Learn more 

 Filters to refine the notification; for example, a specific application or Kubernetes cluster. Define these with an Operator and Value and click Add Filter to save. 

 Note: To receive certificate expiration notifications, the applications you select must be monitored by the certificate monitoring service . Ideally, you should monitor all applications in a policy and use filters to exclude applications you don't want notifications for. 

 Any Advanced Criteria using Common Expression Language (CEL) . To learn more, see Advanced filter criteria . 

 Click Continue. 

 In Delivery Channel Details , choose the channel to send notifications through. 

 Email : Select at least one primary, CC, or BCC recipient. You can select users or groups. 

 Note: If Email is selected, select a Notification Content Template to use custom email notifcations. 

 Zoom Team Chat : Select a previously configured Zoom Team Chat integration. 

 PagerDuty : Select a previously configured PagerDuty integration. 

 Click Save. 
The new notification appears in the Notification Center.
