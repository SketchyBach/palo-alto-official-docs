 Known Issues in ION Device Release 6.1.3 

 Learn about the known issues in ION Release 6.1.3. 

 The following list includes outstanding known issues specific to Prisma
 SD-WAN ION release 6.1.3. 

 Issue ID Description 

 CGSDW-12113 Branch backup ION device displays as partially online
 following Hood maintenance. 

 CGSDW-12698 Network reachability for WAN to LAN traffic failing for
 non-CGNX sites. 

 CGSDW-12733 DPD with IKEv2 on Standard VPN does not bring the tunnel
 down based on the configuration on the DPD timer. 

 CGSDW-12855 TCP socket between TCPProxy and FC is broken post
 TCPProxy restart. The workaround is to restart the FC. 

 CGSDW-14432 The fp-rte process crashes when
 fetching information on security policy counters and app stats. 

 CGSDW-14456 The fc-cp process crashes in the
 new primary device post HA failover. 

 CGSDW-14980 Custom applications with L3/L4 prefixes are not detected
 when used in security policies.
