 Deploy the Prisma Access Agent 

 Learn how to deploy Prisma Access Agents to secure the endpoints in your mobile
 workforce. 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 NGFW (Managed by Panorama) 

 Check the prerequisites for the deployment you're
 using 

 Contact your Palo Alto Networks account representative to
 activate the Prisma Access Agent feature 

 After you configured the Prisma Access Agent , you can download and deploy the Prisma Access Agent to a large number of endpoints using third-party mobile device
 management (MDM) software. Your end users can benefit by having the Prisma Access Agent installed automatically on their devices. 

 If you require your users to access your organization's network and resources based
 on the projects that they are assigned to, see configure the Prisma Access Agent for Dynamic
 Privilege Access . 

 To begin, you will need to: 

 Download the agent package 

 View the supported mobile device management (MDM)
 vendors 

 Deploy Prisma Access Agents using Jamf
 Pro 

 Deploy Prisma Access Agents using Microsoft
 Intune 

 Also be aware of the optional agent deployment configurations and the Prisma Access Agent 
 processes that need to be allow listed on
 your deployments .
