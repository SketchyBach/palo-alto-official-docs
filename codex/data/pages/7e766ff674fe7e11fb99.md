 Provision Certificates to Radware Alteon 

 You can provision a certificate to an existing SSL server on your Radware Alteon ADC, or you can use Next-Gen Trust Security to create a new SSL virtual server setting. Note, the virtual server with configured Virtual Services must already exist. The steps below walk you through both scenarios. 

 In the Next-Gen Trust Security toolbar, click Machines . 

 Click the checkbox next to the Radware Alteon ADC machine where you'll install the certificate. 

 Click Provision a certificate . 

 From the Choose a certificate from the inventory field, begin typing the certificate name you want to provision. Click the certificate when you see it listed. 

 Verify that you've selected the correct certificate by reviewing the Subject DN, Validity, and Fingerprint. 

 In the Server Certificate ID field, enter your Server Certificate from Radware. If not provided, the certificate serial number will be used. 

 In the SSL Policy ID field, enter the identifier of the SSL policy to which the certificate will be associated. You can provide the name of an existing SSL Policy, which will be overwritten. 

 In the Virtual Server ID field, enter the identifier of the virtual server where the certificate will be installed. 

 In the Virtual Service Port field, enter the port number. 

 If you don't want the certificate to be pushed when you save, toggle the Push upon saving slider to No . 

 Click Save . 

 Note: You can schedule your provisions daily, weekly, or monthly. Learn more 

 After saving, the certificate is pushed to the Radware Alteon ADC and bound to the specified virtual server, and an installation is created on the Installations tab.
