 Upgrade the Enterprise DLP Plugin 

 Upgrade the Panorama plugin for Enterprise data loss
prevention (DLP). 

 Upgrade the Enterprise data loss prevention
(DLP) plugin version installed on your Panorama™ management server. 

 See
the Palo Alto Networks Panorama Plugin
Compatibility Matrix and review the minimum PAN-OS version
required for your target Enterprise DLP plugin version. 

 Log in to the Panorama web interface . 

 Upgrade the Enterprise DLP plugin version on Panorama. 
 For Panorama in a high availability (HA) configuration, repeat
this step on the Panorama HA peer. 

 Select Panorama Plugins and Check
Now for the latest dlp plugin
version. 

 Download and Install the
latest version of the Enterprise DLP plugin. 

 After the new plugin version successfully installs,
view the Panorama Dashboard and verify in
the General Information widget that the Plugin DLP version
displays the Enterprise DLP plugin version you upgraded to. 

 ( Upgrading from Enterprise DLP 1.0.4 or 1.0.5 only )
Reset the Enterprise DLP plugin. 

 For Panorama in a high availability (HA) configuration,
repeat this step on the Panorama HA peer 

 This step is required to ensure data
filtering profiles that contain an EDM dataset synchronized from
the DLP app on the hub are read-only on Panorama. You must restore
the read-only status of these data filtering profiles on Panorama
to ensure there are no future synchronization issues if you edit
the data profile on the DLP app or clone the data filtering profile
on Panorama. 

 Log in to the Panorama CLI . 

 Reset the Enterprise DLP plugin. 
 admin> request plugins dlp reset 

 ( Best Practices ) Upgrade the Enterprise DLP
plugin on your managed firewall. 

 Upgrade the Enterprise DLP plugin version on your managed
firewall to the same version you upgraded the Enterprise DLP plugin
on Panorama. 

 Select Panorama Device Deployment Plugins and Check
Now for the latest dlp plugin
version. 

 Download and Install the
same Enterprise DLP plugin version you installed on Panorama. 

 Select one or more managed firewalls leveraging Enterprise
DLP for which you want to upgrade the plugin version. 

 Click OK .
