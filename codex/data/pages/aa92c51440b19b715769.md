 AWS AMIs are not encrypted by Key Management Service (KMS) using Customer Managed Keys (CMKs) miscon 

 Rule Details 

 Cortex AppSec Rule ID 

 APPSEC_AWS_204 

 Category - Subcategory 

 Storage - Encryption 

 Provider 

 AWS 

 Severity 

 LOW 

 Framework 

 Terraform 

 Impact 

 This rule identifies AMIs which are encrypted with default KMS keys and not with Keys managed by Customer. It is a best practice to use customer managed KMS Keys to encrypt your EFS data. It gives you full control over the encrypted data.
