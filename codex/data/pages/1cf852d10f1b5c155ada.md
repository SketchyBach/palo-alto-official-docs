 INC_SC_SITE_LONG_DURATION_EXCEEDED_CAPACITY 

 Learn about the INC_SC_SITE_LONG_DURATION_EXCEEDED_CAPACITY incident. 

 Incident Code 

 INC_SC_SITE_LONG_DURATION_EXCEEDED_CAPACITY 

 Title Template 

 Site capacity exceeded {threshold_value}% usage for {initial_days_for_raise} days in the last {alert_evaluation_lookback_window_days} days for Site {site_name} {initial_direction} traffic 

 Category 

 Network and Traffic 

 Subcategory 

 Site/Tunnel 

 Description 

 A Service Connection site within the network has been operating beyond its capacity for a prolonged period. This extended overutilization can lead to performance degradation and potential service disruptions for users relying on this connection. 

 Raise Condition 

 Incident is Raised when site capacity exceeded 100% usage for at least 3 days in the last 5 days for at least 1 hours a day in the given direction 

 Clear Condition 

 Incident is Cleared when site capacity didn't exceeded 90% usage in the last 8 days for at least 1 hours a day in the given direction
