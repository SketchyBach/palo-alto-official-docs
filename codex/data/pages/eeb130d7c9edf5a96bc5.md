 config bypass pair interface delete 

 Use the config bypass pair interface delete command
to remove bypass pairs configured on interfaces and to remove default
bypass pairs for unclaimed ION 2000 and ION 3000 devices. 

 Command 

 config bypass pair interface= interface number delete 

 Options 

 None 

 Command Notes 

 Role Super 

 Related Commands 

 dump bypass-pair config 

 Introduced in Release 5.0.1 

 Example 

 config bypass-pair 4 delete
