 Supported web browsers 

 Review supported browser versions and performance requirements for Cortex Cloud. 

 Cortex Cloud supports the following web browsers: 

 Browser 

 Version 

 Chrome 

 95.x and later 

 Firefox 

 93.x and later 

 Safari 

 13.x and later 

 Microsoft Edge 

 81.x and later 

 Prisma Browser 

 Latest version 

 Note 

 Cortex Cloud is optimized for best performance using the HTTPv2 protocol. If you are using a non-supported browser version or a network middleware that uses a protocol other than HTTPv2, you may experience slowness in loading and response times between the browser and the Cortex Cloud service. 

 Consult with your browser or middleware vendor to see how to update the protocol.
