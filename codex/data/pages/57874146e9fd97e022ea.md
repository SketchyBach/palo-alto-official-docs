 Addressed issues in Cortex XDR agent 8.1.2 

 The following issues have been addressed in this release. 

 Issue 

 Description 

 CPATR‑22124 

 (Linux) 

 Fixed an issue to prevent a potential vulnerability in the GNU C library's dynamic loader within the Cortex XDR agent image. 

 CPATR‑21933 

 (Linux) 

 Fixed an issue to enable Cortex XDR agents to be deployed in environments in which Pod Security Admission controller enforces Pod Security Standards. 

 CPATR-21870 

 (Windows) 

 Fixed an issue that may lead to agent upgrade failure on non-US locale OS editions 

 CPATR-21465 

 (Linux) 

 Fixed an issue on RHEL 8 and RHEL 9-based endpoints that may prevent the Cortex XDR agent from starting correctly. 

 CPATR-21447 

 (Windows) 

 Fixed an issue that may occur during large workload processing on high-performance endpoints. 

 CPATR-21445 

 (Linux) 

 Fixed an issue that may lead to agent processes timeout. 

 CPATR-21331 

 (Windows) 

 Fixed an issue that may lead to high CPU resources on Windows Server endpoints. 

 CPATR-21262 

 (Linux) 

 Fixed an issue that may occur in rare cases on Linux Oracle 6-based endpoints where the operating system distribution type was not detected correctly. 

 CPATR-21125 

 (Linux) 

 Fixed a rare issue that caused Cortex XDR agent installation to fail. 

 CPATR-20816 

 Fixed an agent stability issue that may occur after multiple cases of endpoint hardboot or by file system failures.
