 Severity 

 Informational 

 Description 

 A service principal was removed from Azure. This indicates a change in access permissions and may indicate malicious activity. 

 Attacker's Goals 

 Evade defensive measures by deleting a possibly malicious service principal. 

 Investigative actions 

 Check the Azure Active Directory audit logs for the details of the removed service principal.* Check the Azure role assignments to identify which resources were impacted by the removal of the service principal.
