 ION 3000 Front Panel with LEDs 

 The ION 3000 front panel indicates the status of the
device using LEDs. 

 The ION 3000 LEDs indicate the status
of the disk, power, and the controller connectivity: 

 Icons Description 

 Displays disk status. 

 Orange light (Blinking)—Disk Activity. 

 Displays controller connectivity status. 

 Blue light—Connected. 

 Red
light—Not Connected 

 Displays power status. 

 Green light—Powered on. 

 No
light—Powered off.
