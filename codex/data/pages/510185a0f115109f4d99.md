 Operating System (OS) Compatibility 

 Review the OS compatibility details for the Terminal Server
(TS) agent 10.2 release. 

 The Terminal Server (TS) agent is compatible with PAN-OS®
10.2 and earlier PAN-OS releases that Palo Alto Networks still supports.
To see where you can install TS agents , refer
to the Terminal Server (TS) agent compatibility information in the Palo Alto Networks Compatibility
Matrix .
