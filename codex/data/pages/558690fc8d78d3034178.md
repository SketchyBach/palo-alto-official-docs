 dump radius statistics 

 Use the dump radius statistics command
to view the RADIUS server statistics of a selected interface or
all interfaces. 

 Command 
 dump radius statistics 

 Options 

 Interface ID Enter the interface ID to display RADIUS server statistics
for a specific interface. 

 All Enter all to display RADIUS server statistics
for all interfaces. 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands — 

 Introduced in Release 6.0.2
