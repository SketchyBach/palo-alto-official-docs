 dump device conntrack count 

 Use the dump device conntrack count command
to display the number of current internal kernel level connections.
A high conntrack count impacts device performance and traffic forwarding. 

 Command 

 dump device conntrack count 

 Options 

 None 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands — 

 Introduced in Release 5.1.11 

 Example 

 dump device conntrack countconntrack count : 177 (max: 327680)
