 ATT&CK Technique 

 Cloud Storage Object Discovery (T1619), Cloud Infrastructure Discovery (T1580) 

 Severity 

 Informational 

 Description 

 An identity attempted to discover cloud objects within storage buckets. This might be an attempt by an adversary to find sensitive data stored in cloud storage, which could lead to data theft. 

 Attacker's Goals 

 Access sensitive data stored in cloud infrastructure. 

 Investigative actions 

 Check the identity's role designation in the organization. 

 Identify which storage buckets were enumerated and whether they contained sensitive information.
