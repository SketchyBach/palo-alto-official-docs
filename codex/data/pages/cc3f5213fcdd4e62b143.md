 Manually Quarantine Assets 

 Lean how to manually quarantine an asset in Data Security . 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 Data Security license 

 Or any of the following licenses that include the Data Security license: 

 CASB-X 

 CASB-PA 

 If you chose not to automatically quarantine an asset when you specified match
 criteria in your asset policy ,
 you can always manually quarantine the asset after Data Security discovers
 the incident. 

 Log in to 
 Strata Cloud Manager . 

 Select Configuration SaaS Security Data Assets All Assets Data Asset Name . 
 The asset details page is displayed. 

 Select Actions . 

 Choose between the two quarantine folders (Admin Quarantine and
 User Quarantine).
