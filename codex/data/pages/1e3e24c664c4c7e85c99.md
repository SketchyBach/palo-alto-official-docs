 Aggregate Group Members on Multiple Cards 

 On a PA-7050 or PA-7080 firewall that has an AE group
of interfaces that are spread over multiple cards, enable handling
of fragmented IP packets. 

 If you have a PA-7050 or PA-7080 firewall
that has an aggregate interface group of
interfaces that you located on different line cards, it is a best
practice to configure the firewall so that it can handle fragmented
IP packets it receives on multiple interfaces of the AE group that
are spread over multiple cards. To do so, use the following CLI
operational command. 

 Access the CLI . 

 Use the following operational command: set ae-frag redistribution-policy hash
