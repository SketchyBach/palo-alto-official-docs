 SD-WAN Link Performance Alert 

 Incident Code 

 INC_NGFW_SDWAN_UNHEALTHY_LINK 

 Severity 

 Warning 

 Category 

 Network and Traffic 

 Subcategory 

 SD-WAN 

 Description 

 Poor link performance will affect applications sending traffic
 through the links. Link performance is inferred from Jitter, Latency
 and Packet loss. 

 Raise Condition 

 This incident is triggered when any of the following SD-WAN link
 metrics continuously exceed monitoring thresholds for at least one
 hour: 

 Latency >= 300ms 

 Packet Loss >= 15% 

 Jitter >= 25ms 

 Clear Condition 

 The incident is cleared when all SD-WAN link metrics (packet loss,
 latency, and jitter) return to levels below the raise thresholds for
 at least 2 hours.
