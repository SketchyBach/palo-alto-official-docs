 Feature Enhancements 

 Data Security 

 FEATURE 

 DESCRIPTION 

 Customize the cadence of the data classification of on-premise file shares 

 Align your data classification frequency with your specific business requirements for on-premise file shares. You can now configure a custom cadence for scanning and classifying data. We added flexible cadence settings for all local file repositories. 

 Use Cloud Scan deployment for Azure storage blobs and database 

 Streamline your security operations by using Azure Cloud Scan for your storage and database assets. You can now classify data in storage blobs and self-managed databases using this deployment mode, providing a more unified way to manage your cloud security. We expanded Azure Cloud Scan support to include these existing Azure integrations.
