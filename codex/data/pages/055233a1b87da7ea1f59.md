 XDR_DATA Fields by Actor 

 DST Causality Actor 

 The DST Causality actor is the process identified by the operation system on the remote host as the process that performed an action that was responsible for the entire chain of execution.

 INTEGER 

 Type of Causality Actor: Local = 1. The actor is a local process.
RemoteRpcNamedPipe = 2. The actor is a remote procedure call (RPC) over a named-pipe/SMB connection.
RemoteRpcHttp = 3. The actor is a remote procedure call (RPC) over a remote HTTP connection.
RemoteRpcTcp = 4. The actor is a remote procedure call (RPC) over a TCP connection.
RemoteFileSmb = 5. The actor is a remote file operation over a SMB.
