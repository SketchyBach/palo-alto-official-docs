 Context Switch 

 In the header of every Panorama web interface page,
you can use the Context drop-down above the
left-side menu to switch between the Panorama web interface and
a firewall web interface. When you select a firewall, the web interface
refreshes to show all the pages and options for the selected firewall
so that you can manage it locally. The drop-down displays only the
firewalls to which you have administrative access (see Panorama
> Access Domains ) and that are connected to Panorama. 

 You can use the Filters to search for firewalls by Platforms
(model), Device Groups, Templates, Tags, or HA Status. You can also
enter a text string in the filter bar to search by Device Name. 

 The icons of firewalls that are in high availability (HA) mode
will have colored backgrounds to indicate their HA state .
