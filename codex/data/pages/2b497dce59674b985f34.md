 INC_GP_CLIENT_VERSION_UNSUPPORTED 

 Learn about the INC_GP_CLIENT_VERSION_UNSUPPORTED incident. 

 Synopsis 

 There are devices in the network using a GlobalProtect version lower than 5.0, 5.1,
 or 5.2. 

 Incident Code—INC_GP_CLIENT_VERSION_UNSUPPORTED 

 Severity—Warning 

 For details about incident severity, see Incidents Distribution Over
 Time in Incidents and Alerts Overview . 

 Details 

 Description 

 Raise condition 

 There are devices in the network using a GlobalProtect version
 lower than 5.0, 5.1, or 5.2. 

 Clear condition 

 There are no devices in the network using a GlobalProtect version
 lower than 5.0, 5.1, or 5.2.
