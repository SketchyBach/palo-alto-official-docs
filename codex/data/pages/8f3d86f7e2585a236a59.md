Workspace ONE Guide

Learn how to configure Koi into your environment with Workspace ONE UEM.

This document provides step-by-step instructions on integrating Koi into your environment with Workspace ONE UEM.

Configuration Guide

Prerequisites

Access to your Workspace ONE UEM console.

The configuration script provided by Koi.

Internet access from managed devices.

Integrations Steps

In the Workspace ONE UEM console, navigate to Resources > Scripts.

Click on "Add ∨" at the top left of the screen. Choose macOS or Windows.

Choose a Name and Description for the script.
Example: "Configure Koi".

Click Next.

Set the Language to Bash for macOS or PowerShell for Windows.

Set the Execution Context to System.

Copy and paste the Koi configuration script from your dashboard into the Code window.

Click Next, then click Save, and then Save again.

In the Scripts list, check the new script you just created, and click Assign.

Click New Assignment.

Choose a name for the assignment.
Example: "Koi MacOS Devices" or "Koi Windows Devices".

For Select Smart Group, click in the search box. From the list of Assignment Groups that appear, select the appropriate group.
You can create a group under Groups & Settings > Groups > Assignment Groups.

Click Next.

Click Run Periodically and set the desired cadence.

Click Add.

Click Save & Publish and then Publish.
