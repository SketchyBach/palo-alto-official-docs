 dump user-id ip-user-mapping 

 Use the dump user-id ip-user-mapping command to display the IP
 address to user mapping learnt from the controller. 

 Command 

 dump user ip-user-mapping ( all | ip-address ) 

 Options 

 all Enter all to display all the IP
 address to user mappings on the device. 

 ip-address Enter an IP address to display the user mapping for the
 IP address. 

 Command Notes 

 This command applies only to branch ION devices. 

 Role Super, Read Only, Monitor 

 Related Commands — 

 Introduced in Release 6.2.1 

 Example 

 dump user-id ip-user-mapping all
