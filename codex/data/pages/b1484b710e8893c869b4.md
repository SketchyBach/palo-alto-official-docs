 Trust and Remove Trusted Skills 

 Trust a scanned skill to allow it through future scans regardless of findings, or
 remove trust to re-evaluate it against your configured security rules. 

 Where Can I Use This? What Do I Need? 

 Prisma AIRS (AI Skill Security) 

 No License required for preview 

 After reviewing a skill, you can choose to trust it. Trusting a skill records
 approval for the exact fingerprint of that skill bundle, so all subsequent scans of
 the same skill version pass automatically, even if blocking vulnerabilities are
 found. Use this for confirmed false positives or risks your organization has
 accepted as acceptable. Future changes to the skill produce new fingerprints and
 must be evaluated and re-trusted separately. 

 Trust a Skill 

 You can trust a skill from the scan results page or from the Trusted Skills List
 in Configurations. 

 Open the completed skill scan you want to trust. 

 Select Trust this Skill . 

 Alternatively, select AI Security AI Supply Chain Security Configurations , then navigate to Trusted Skills
 List . 

 Search by skill name or fingerprint and select the skill to
 trust. 

 ( Optional ) Enter a reason for trusting the skill. 

 Confirm the trust action. 

 Remove a Trusted Skill 

 Remove trust from a skill to re-evaluate it against your rules on the next scan.
 The next scan uses your current rule configuration instead of automatically
 allowing the skill. 

 Select AI Security AI Supply Chain Security Configurations , then navigate to Trusted Skills
 List . 

 Search for the skill by name or fingerprint. 

 Select the remove icon next to the skill.
