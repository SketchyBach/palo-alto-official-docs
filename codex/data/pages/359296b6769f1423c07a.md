 INC_PA_SERVICE_DEGRADATION_SC_ CONNECTIVITY 

 Learn about the INC_PA_SERVICE_DEGRADATION_SC_CONNECTIVITY incident. 

 Synopsis 

 The INC_PA_SERVICE_DEGRADATION_SC_CONNECTIVITY incident is raised when the service
 connection cluster is down. This incident indicates a Palo Alto Networks
 infrastructure issue, which the SRE team is working to resolve. 

 Incident Code—INC_PA_SERVICE_DEGRADATION_SC_CONNECTIVITY 

 Severity—Critical 

 For details about incident severity, see Incidents Distribution Over
 Time in Incidents and Alerts Overview . 

 Required License 

 Prisma Access 

 Details 

 Raise condition 

 A service connection infrastructure issue occurred. 

 Clear condition 

 The service connection infrastructure issue is resolved.
