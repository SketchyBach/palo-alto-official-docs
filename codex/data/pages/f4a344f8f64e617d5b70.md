 Manage automation rules 

 Procedure of how to manage the automation rules of Cortex XDR as needed, which includes to edit, save as new, disable, delete or copy. 

 Notice 

 This functionality requires a Cortex XDR Pro license. 

 Danger 

 Before you create or manage automation rules, go to Settings → Configuration → Automation Settings and configure the settings for Endpoint Action Limit Thresholds and Automation Rules Notifications . 

 You can add or edit an automation rule to trigger an action when the alert matches the condition of the rule created. 

 Note 

 Automation rules trigger only upon the initial ingestion of an issue. Subsequent updates will not re-trigger the rule, even if the issue still meets the criteria. 

 Navigate to Incident Response → Response → Automation and select Automation Rules . 

 Click Add Automation Rule , or to edit and existing rule hover over the rule and select the edit icon. 

 Define rule name and conditions: 

 Enter a rule name and set the rule status. 

 From the Alerts table, use the filter to retrieve the criteria to define the condition of the automation rule. 

 Click Next . 

 From list, select the relevant action to initiate when the alert condition is triggered. 

 In the Exclude Endpoints page, select the endpoints to exclude and click Next . 

 Note 

 This option is only accessible to Action type Endpoint Response . 

 In the Summary page, verify the settings and click Done . 

 Manage the automation rule, as needed. Right-click a rule to see the available actions.
