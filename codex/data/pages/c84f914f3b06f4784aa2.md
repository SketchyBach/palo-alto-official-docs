 Example User View of Notification 

 When users encounter issues, such as
high CPU or memory utilization and/or WiFi or internet issues, a
notification as shown in the image below pops up on their device explaining
the problem. 

 Clicking on the notification opens the Application Experience UI ,
where they can see details about the notification. 

 Refer to the use cases that
are supported for each notification category (Device, WiFi, and
Internet).
