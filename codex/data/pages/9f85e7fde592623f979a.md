 Terminal Server (TS) Agent 

 Review support information about the Terminal Server
(TS) agent and where you can install the agent. 

 You install the Terminal Server (TS) agent on a domain
server that is running a supported operating system (OS) and then
report username-to-port mapping information to PAN-OS® firewalls.
