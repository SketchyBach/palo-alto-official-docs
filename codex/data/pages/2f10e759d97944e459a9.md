 dump flow-acceptance-criteria 

 Use the dump flow-acceptance-criteria command to check the Site
 Protection Profile (SPP) configurations, summary, run-time memory usage, and global SPP
 counters. 

 Command 

 dump flow-acceptance-criteria { config | summary { src ip= | vni= } | memory-stats 

 Options 

 config Enter config to display the site protection profile
 configurations. 

 summary Enter the summary (src ip and vni id) to check the current site
 protection profile summary for a selector, which dumps the current
 active flow count and number of flows dropped so far. 

 memory stats Enter memory stats to check the run-time memory usage used by the
 SPP module. 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands 

 Introduced in Release 6.6.1 

 Example 

 dump flow-acceptance-criteria config 
Flow Acceptance Criteria Enabled: True 
Concurrent Flow Threshold Percentage: 1% 

 dump flow-acceptance-criteria summary src-ip=10.1.1.1 10 vni=100 
Flow Acceptance Criteria enforced : True 
Active flow count: 1000 
Total drop count: 345 

 When VNI is 0 

 dump flow-acceptance-criteria summary src-ip=10.3.241.66 
Flow Acceptance Criteria Enforced: False 

 dump flow-acceptance-criteria memory-stats 
Hash table size: 64 bytes 
Exception filter trie size: 440 bytes
