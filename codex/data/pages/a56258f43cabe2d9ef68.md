 About Incident Settings 

 Learn about incident categories and incident codes. 

 Where can I use this? What do I need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 AI-Powered ADEM license 

 Autonomous DEM license 

 Prisma Access license 

 You can view incident categories and incident codes allowed by your AI-Powered ADEM , ADEM Observability, or Prisma Access license. 

 There are four types of incident policy rules: 
 Category and code level default—Implicit. 

 Category and code level custom—Customize the Incidents you want to receive at
 the category and incident code level. 

 You have several Incident categories, which you can view and modify according to your
 license.
