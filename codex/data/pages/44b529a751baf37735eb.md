 Supported MIBs 

 The following table lists the Simple Network Management
Protocol (SNMP) management information bases (MIBs) that Palo Alto
Networks firewalls, Panorama, and WF-500 appliances support. You
must load these MIBs into your SNMP manager to monitor the objects
(system statistics and traps) that are defined in the MIBs. For
details, see Use
an SNMP Manager to Explore MIBs and Objects .

 Supported MIBs 

 Standard —The Internet Engineering Task
Force (IETF) maintains most standard MIBs. You can download the
MIBs from the IETF
website . 

 Palo Alto Networks firewalls, Panorama,
and WF-500 appliances don’t support every object (OID) in every
one of these MIBs. See the Supported MIBs links for an overview
of the supported OIDs.
