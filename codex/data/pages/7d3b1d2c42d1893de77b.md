 Device Activity Dashboard 

 Monitor CPU, memory, disk, and interface metrics for branch and data center ION
 devices using the Device Activity Dashboard. 

 Where Can I Use
 This? What Do I Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 Prisma® SD-WAN provides system-related information — including CPU utilization, free
 memory, free disk space, interface bandwidth utilization, interface dropped packets, and
 interface errors — for both branch and data center ION devices. 

 To view the Device Activity Dashboard, select Insights ION Devices Device Activity . 

 The Interfaces filter lets you narrow down traffic by interface.
 You can view the interfaces list based on different Top Interface filters, such as Bytes
 (RX and TX), Errors (RX and TX), Packets (RX and TX), and Dropped Packets (RX and TX).
 The top 10 interfaces matching the filter are listed. 

 Device List 

 Prisma SD-WAN provides device-related information, including the Device
 distribution by software version widget and the Prisma SD-WAN
 Devices inventory, for both branch and data center ION devices. 

 To view the Device Activity Dashboard, select Insights ION Devices Device List . 

 The Device distribution by software version dashboard widget
 provides a centralized view of the software versions deployed across your managed
 devices. This visualization helps you assess your network's compliance and security
 posture by categorizing devices into specific software builds. Use this widget to identify devices running older software versions and prioritize upgrade candidates. 

 The Prisma SD-WAN Devices inventory page provides a detailed
 list of your deployed ION devices, offering real-time insights into their
 operational state and software compliance. This interface helps you manage your
 fleet by surfacing critical status information, such as connectivity, model details,
 and software lifecycle stages. Devices nearing end-of-life (EOL) or end-of-support (EOS) dates display notification badges, alerting you to plan for hardware refresh or software upgrades before support expires.
