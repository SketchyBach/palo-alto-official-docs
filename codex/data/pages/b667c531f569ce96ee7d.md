 Network > GlobalProtect > Gateways 

 Select Network GlobalProtect Gateways to
configure a GlobalProtect gateway. A gateway can provide VPN connections
for GlobalProtect apps or for GlobalProtect satellites. 

 From the GlobalProtect Gateway dialog, Add a
new gateway configuration or select an existing gateway configuration
to modify it.
