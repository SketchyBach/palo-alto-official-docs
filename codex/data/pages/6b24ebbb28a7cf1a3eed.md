 AbuseIPDB 

 Use AbuseIPDB data with Cortex XSIAM. 

 Important 

 This connector is only available for tenants that onboarded after July 26, 2026. For tenants that onboarded before this date, use Marketplace to access the standalone integration. For more information, see Marketplace . 

 This connector is available with any active Cortex XSIAM, Cortex Cloud, Cortex Cloud Runtime Security, Cortex XDR, or Cortex AgentiX license. 

 Use the AbuseIPDB integration to report and identify IP addresses that have been associated with malicious activity online. Check, report, and get block lists of the top malicious IPs. 

 This connector includes the following sub-capabilities (Marketplace integrations link to PAN DEV for more information): 

 AbuseIPDB
