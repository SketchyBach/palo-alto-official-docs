 Deploy CN-Series Firewall with Terraform Templates 

 Requirements for a CN-Series deployment using Terraform. 

 Where Can I Use This? What Do I Need? 

 CN-Series deployment 

 CN-Series 10.1.x or above Container Images 

 Panorama running PAN-OS 10.1.x or above version 

 Terraform 0.13.0 or above 

 The CN-Series deployment repository
contains Terraform plans to deploy a GKE, EKS, or AKS cluster. These
plans ensure the cluster node sizing and Container Network Interfaces
(CNIs) support a CN-Series firewall deployment within the cluster.
The repository also provides a CN-Series firewall deployment plan
and a sample PHP guestbook application that you can secure with
the firewall.
