 Enable SD-WAN with Auto VPN 

 Create an SD-WAN cluster using Auto VPN that enables you to create SD-WAN configurations automatically. Create SD-WAN clusters
 for complex network environments using Auto VPN. 

 Where Can I Use This? What Do I Need? 

 NGFW 

 Advanced SD-WAN for NGFW 

 Auto VPN enables you to create SD-WAN cluster to connect multiple
 LANs.
 Auto VPN is an automated process for configuring the VPN tunnel that helps you to deploy
 and manage an SD-WAN environment easily. With Auto VPN, SD-WAN creates the tunnels and adds the corresponding interfaces
 automatically when you configure the SD-WAN .
 Auto VPN allows you to quickly and easily build VPN tunnels for your network topology.

 With Auto VPN, you can
 create:. 
 ( Panorama ) either hub and spoke or mesh topology based on your network
 requirements 

 ( Strata Cloud Manager ) hub and spoke topology based on your network
 requirements 

 Using Auto VPN will be beneficial to you when your topology has more branches. Without
 Auto VPN, you will be required to configure each SD-WAN firewall manually
 along with the routing configurations. 

 ( Strata Cloud Manager ) With Auto VPN, you can now create Cellular, Sub
 Interface, and Aggregate Interface configurations. 

 With Auto VPN, you can create multiple VPN clusters easily as per your network topology
 requirements. With Auto VPN, you can also add or delete the branch or hub firewalls from
 the existing cluster easily. Without Auto VPN, you may have to perform these tasks
 manually and there are chances for misconfiguration while updating the existing cluster
 configuration. 

 ( Panorama ) 
 You can also
 add a single SD-WAN hub or branch firewall or use a CSV
 to bulk import multiple SD-WAN hub and branch firewalls.

 preferred authentication type
