 Content Packs 

 APIs for content packs 

 Upload Pack 

 post https://hostname /contentpacks/installed/upload 

 Upload Pack to the Server. Can be used to upload a Pack for an offline scenario or a Pack that hasn't been released. 

 Authorizations 

 api_key 

 Authorization string Required 

 Body 

 multipart/form-data 

 skipVerify string Optional 

 If true will skip pack signature verification. Use when uploading a custom or dev pack. 

 skipValidation string Optional 

 if true will skip validation, use when migrate existing custom content to packs. 

 file string Optional 

 file 

 Responses 

 200 

 The pack was successfully uploaded 

 No content
