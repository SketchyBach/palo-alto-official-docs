 Set the Default Theme for New Users 

 Set the default theme for new users in Cortex XSOAR 6.13. 

 By default, the color theme for new users is light. When you add the following server configurations, the selected theme is the one applied to all new users. Each user can change the theme in their user preferences. 

 Go to Settings → About → Troubleshooting . 

 In the Server Configuration section, click Add Server Configuration . 

 Key: default.theme 

 Value: Can be dark , darkula , or light
