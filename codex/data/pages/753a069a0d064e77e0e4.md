 Onboard Amazon Web Services 

 Follow the AWS onboarding wizard, and Cortex Data Security creates a custom authentication template to be executed in AWS. 

 Use the cloud onboarding wizard to integrate an Amazon Web Services (AWS) environment with Cortex Data Security. The onboarding wizard requires minimal configuration to set up the integration. To complete the minimum configuration, define the scope of the AWS accounts and specify the scan mode. Alternatively, configure the advanced settings for full control of the onboarding process. 

 Cortex Data Security generates an authentication template based on the configuration settings. The template establishes trust with AWS and creates the required resources. For account scope, you can choose to deploy the template using CloudFormation or Terraform. For organization and organizational unit scope, CloudFormation is used. Execute the template to complete the onboarding process. Executing the template notifies Cortex Data Security of the execution details. Cortex Data Security then creates a new cloud instance.
