 XDR_DATA Fields by Actor 

 DST Action Actor 

 The DST Action actor is the receiving process for actions performed remotely from one host to another.

 dst_actor_process_signature_product

 dst_actor_process_signature_status 

 INTEGER 

 Signature status of the process: Signed = 1
SignedInvalid = 2
Unsigned = 3
FailedToObtain = 4
WeakHash = 5. Means that MD5 is used as the hash algorithm.
Unsupported = 6. This means signature was not calculated.
InvalidCVE2020_0601 = 7. This means the executable is malicious and is trying to exploit the windows vulnerability CVE2020-0601
Deleted = 8. Means that the file was deleted by the time the agent tried to calculate signature. 

 dst_actor_process_signature_vendor

 dst_actor_remote_pipe_name

 dst_actor_remote_port

 Relevant when the actor is a remote actor, where the type is RemoteRpcTcp. 

 dst_actor_thread_thread_id 

 INTEGER 

 An identifier of the operating system (OS) thread responsible for the event. 

 dst_actor_type 

 INTEGER 

 The type of actor: Local = 1. The actor is a local process.
RemoteRpcNamedPipe = 2. The actor is a Remote Procedure Call (RPC) over a named-pipe/SMB connection.
RemoteRpcHttp = 3. The actor is a Remote Procedure Call (RPC) over a remote HTTP connection.
RemoteRpcTcp = 4. The actor is a Remote Procedure Call (RPC) over a TCP connection.
RemoteFileSmb = 5. The actor is a remote file operation over SMB.
