 Monitor IP Pool Usage 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Tenant or Tenant Service
 Group (TSG) 

 Role : Multitenant
 Superuser or Superuser 

 The IP Pool Usage view helps you track and analyze how IP pools are utilized
 across your deployment. You can compare the number of IP addresses configured versus
 those in use and review detailed usage statistics by location or region. This data
 provides valuable insights for capacity planning and proactive resource management. 

 IP pool usage data is available only for shared interconnects . 

 The visual indicators on this page show the current utilization status of each
 IP pool, helping you quickly identify when action might be required. The usage
 percentage is color-coded to represent the health and capacity level of the pool: 

 Green — Optimal utilization; no action required. 

 Orange — 60–80% utilized; monitor usage trends and plan for
 future expansion. 

 Red — Above 80% utilized; consider adding more IP addresses to prevent
 resource exhaustion. 

 Use this data to monitor IP pool consumption patterns, anticipate capacity constraints,
 and ensure seamless connectivity across all regions.
