 AI Assist for Troubleshooting Application Experience 

 Autonomous DEM AI Assist feature within Strata Cloud Manager helps to diagnose
 and troubleshoot user’s application experience issues in your environment. 

 Where Can I Use This? What Do I Need? 

 Prisma® Access (Managed by Strata Cloud Manager ) 

 NGFW (Managed by Strata Cloud Manager) 

 Strata Cloud Manager Pro Licence 

 Strata Copilot™ AI Assist for ADEM diagnoses
 and resolves user-related issues through an AI-driven intelligence process. The AI
 Assist provides a holistic view of user application experience by consolidating metrics
 into a single, clear narrative. 

 The AI Assist performs multi-step iterative and parallel analysis, correlating telemetry
 from the following endpoints and network paths, determines root causes, and provide
 actionable remediation recommendations: 

 User - User profile, activity patterns, and historical experience data 

 Device - Device model, operating system, resource utilization (CPU, memory,
 disk) 

 Browser - Browser type, extensions, and performance metrics 

 Network (Wi-Fi, LAN, GlobalProtect®) - Local network connectivity and
 performance 

 Prisma Access - Secure access connectivity and tunnel performance 

 Applications - Application-specific metrics including page load times and
 response times 

 When you enter natural language queries or select any pre-suggested queries, the AI
 Assist initiates an automated investigation to identify root causes and provide
 actionable remediation recommendations. 

 Note: AI troubleshooting investigations complete within 5 minutes, with intermediate
 updates streamed to your Co-Pilot panel every 30 seconds.
