 Default Security Groups and Rules 

 Learn about AI Model Security Security Groups, which have one-to-one relationships with Model Sources and establish security controls for model scans. 

 Where Can I Use This? What Do I Need? 

 Prisma AIRS (Model Security) 

 Prisma AIRS Model Security License 

 AI Model Security leverages Security Groups to enable you to establish and configure your
 Model Security controls. Security Groups have a one-to-one relationship with Model
 Sources and this association is permanent once set. 

 Each Model Source provides specialized metadata that is used in rules and security
 validation processes. 

 AI Model Security supports one default Security Group per source and these security
 groups are already created for you. 

 AI Model Security includes a default Security Group for every source type. You can
 create additional custom security groups through the Strata Cloud Manager user
 interface, the Python SDK, or the CLI.
