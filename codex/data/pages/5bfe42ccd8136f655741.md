 Features Introduced in 2025 

 July 2025 

 Changed features 

 The Cortex XSIAM 3.2 release includes the following changes to existing functionality: 

 Component 

 Area 

 Description 

 Issue counts 

 Issues 

 Improved FW issue count labels 

 FW issue deduplication now shows up to 1,000 issue counts. To simplify visualization, larger quantities display as 1000+. 

 User Name Field 

 Cases 

 Expanded Character Limit for Case User Name Field 

 The character limit of the Case User Name field has been increased to accommodate longer user names and improve search functionality. 

 Broker VM 

 Agent installer and content caching 

 When using the Broker VM for the agent installer and content caching, you must use a minimum of an 8-core processor and increase the disk requirement to 1024 GB, instead of the previous 512 GB minimum requirement.
