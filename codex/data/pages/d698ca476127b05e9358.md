 Traps App 5.0 for Android 

 Install Traps App for Android 

 Use this workflow to install Traps 5.0 for Android. 

 To install the Traps app, you must Create an Installation Package from the Traps management service and obtain the download link. This link contains the distribution ID required to associate the app with your Traps management service tenant. You can send this link to your end users to have them install the Traps app. 

 Obtain the link for your Android distribution package and send the link to your end users. 

 Instruct the end user to perform the following steps: 

 From the Android endpoint, open the custom download link for the Traps app. 

 This opens the Traps app in the Google Play. Do not attempt to open the link in a browser. 

 Install the app and follow the on-screen prompts to complete installation. 

 Open the app when installation completes. 

 (Android 5.1 and later releases) Grant access to Traps to monitor apps. 

 If additional permissions are required for your Android version, the Traps app prompts you to Permit usage access . 

 Note 

 This setting may have a different name depending on your Android version. 

 Exit the Traps app usage settings and then return to the Traps app. 

 Activate the Traps app for Android. 

 Enter the First name and Last name of the end user, and the user’s Company email address and then click ACTIVATE . 

 The Traps management service uses this information to identify the endpoint. 

 Tip 

 If activation fails, Traps displays a notification with a link to manually supply the custom package URL or distribution ID. For example, if your custom package URL is https://play.google.com/store/apps/details?id=com.paloaltonetworks.trapsa&referrer=123456abcdef , you can specify the entire URL, or, you can specify only the distribution ID which is the string following referrer= in the URL (for example, 123456abcdef). To retry activation, click ACTIVATE BY URL and supply the required information. 

 (Optional) Configure additional app settings. 

 From the Summary page, select the Traps menu at the top left and then select Settings . From this area, you can configure settings such as your preferred Language and preferences for Notifications that Traps displays.
