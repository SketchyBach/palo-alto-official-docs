 CLI Quick Start 

 Learn the basic CLI commands for the IPS Signature Converter. 

 Where Can I Use
 This? What Do I Need? 

 NGFW (Managed by Panorama) 

 Advanced Threat Prevention (for enhanced feature
 support) or Threat Prevention License 

 See the list of basic commands below
for the intrusion prevention system (IPS) Signature Converter plugin
on Panorama™. For more information about how to use the command
line interface (CLI), see how to Get Started with the CLI . 

 To do this... Start here... 

 Convert, import, check performance impact,
and configure the properties of signatures 
 request plugins ips-signature-converter 

 Set the type, default action, or severity of
a signature 
 request plugins ips-signature-converter set-properties <line numbers> 

 View information about your converted signatures 
 show plugins ips-signature-converter 

 Delete all signatures (does not delete signatures
that you imported to Panorama) 
 clear plugins ips-signature-converter all
