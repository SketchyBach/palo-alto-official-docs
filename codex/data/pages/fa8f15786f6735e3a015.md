 Issue ID 

 Description 

 NETVIS-2039 

 The Strata Cloud Manager Command Center doesn't correctly display your
 currently active AI Access Security in the
 Security Subscription widget. 

 LST-15102 and LST-15123 

 Adding an NGFW to Strata Cloud Manager and then
 activating the AI Access Security license causes the NGFW to no longer display in Strata Logging Service . This is a display issue and does not
 impact log forwarding functionality. However you cannot move the NGFW to a different Strata Logging Service 
 tenant. 

 Workaround : When onboarding your NGFW , do so in
 the following order. 

 Onboard your NGFW to Strata Logging Service . 

 Add NGFW to Strata Cloud Manager . 

 Activate AI Access Security .
