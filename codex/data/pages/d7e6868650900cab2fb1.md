 ID The ID of the Cloud NGFW resource. 

 Ingestion Rate 

 The rate, in logs per second, at which Strata Logging Service is ingesting logs from a Cloud
 NGFW resource. This is a sum across all devices with the same
 resource ID. 

 ( Non-qualifying users
 only ) Storage Used 

 The amount of your Strata Logging Service storage capacity
 that the Cloud NGFW resource is using. This is a sum across all
 devices with the same resource ID. 

 Last Contact Time The last time that the Cloud NGFW resource
