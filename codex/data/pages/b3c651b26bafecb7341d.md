 Cortex XSOAR 6.14 Multi-Tenant 

 Add Propagation Labels to an Existing Tenant Account 

 Add propagation labels to tenant accounts to control content synchronization in Cortex XSOAR 6.14. 

 The propagation labels that you add to the tenant account determine which content items are eligible for syncing. This information is intended for existing tenant accounts. You can also add propagation labels when you add a tenant to a host . 

 If you want to create new propagation labels, or add existing ones, ensure that you have the necessary permissions . 

 In Cortex XSOAR, go to Settings → Account Management → Accounts . 

 Choose the tenant that you want to add propagation labels to and click Roles and propagation . 

 Select existing propagation labels or type new propagation labels.
