 Account Discovery (T1087), Permission Groups Discovery (T1069), Cloud Service Discovery (T1526) 

 Severity 

 Informational 

 Description 

 An unusual command which may be related to an IAM recon enumeration was executed by a non-user identity. 

 Attacker's Goals 

 Collect information on the cloud environment, including IAM users, groups, roles, and policies. 

 Investigative actions 

 Check if the API call was made by the identity. Check if there are additional unusual API calls from the identity.
