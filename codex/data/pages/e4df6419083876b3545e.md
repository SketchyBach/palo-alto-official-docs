 Addressed Issues in Cortex XDR Agent 8.3 

 Cortex XDR agent 8.3.0 addressed issues 

 The following issues were resolved in this release. 

 Issue 

 Description 

 CPATR-22755 

 (Windows) 

 Fixed an issue that may cause user applications to get sharing violation errors when opening Office documents that have macros or portable executable files. 

 CPATR-22682 

 (Windows) 

 Fixed an issue that may affect the collection of process-related forensics information. 

 CPATR-22636 

 (Windows) 

 Fixed an issue where consuming clipboard events may cause agent stability issues. 

 CPATR-22536 

 (Windows) 

 Fixed an issue where policy consumption may cause application startup delays. 

 CPATR-22409 

 (Linux) 

 Fixed an issue where containers may not be displayed in the user interface. 

 CPATR-22407 

 (Linux) 

 Fixed an issue where the upgrade flag is provided for clean install. 

 CPATR-22247 

 (Windows) 

 Fixed an issue that may impact endpoints that do not support the BMI2 instruction set. 

 CPATR-22228 

 (Windows) 

 Fixed an issue that may impact the system while accessing files on non-NTFS file systems. 

 CPATR-22202 

 Fixed an issue where for some alerts, the username field may not be populated. 

 CPATR-22095 

 (Linux) 

 Fixed an issue that may impact known vulnerable processes protection for VSFTPD connections. 

 CPATR-21870 

 (Windows) 

 Fixed an issue that may lead to agent upgrade failure on non-US locale OS editions. 

 CPATR-21825 

 (Windows) 

 Fixed an issue where persistent hash caching may cause system deadlocks during volume dismounting. 

 CPATR-21619 

 (Windows) 

 Fixed an issue that may be encountered when upgrading an endpoint. 

 CPATR-21216 

 (Linux) 

 Fixed an issue to improve performance when processing a large volume of process executions. 

 CPATR-21014 

 (Mac) 

 Fixed issues related to the device control bypass. 

 CPATR-19876 

 (Windows) 

 Improvement made to the Cortex XDR agent security and stability posture. 

 CPATR-18631 

 (Windows) 

 Updated the agent console's functionality to depend on updated versions of the .NET framework. 

 CPATR-3703 

 (Windows) 

 Fixed an issue so that quarantined files with an unknown WildFire verdict may now be uploaded to WildFire for inspection.
