 Notify Users When an Engine Disconnects 

 Configure engine disconnect notifications in Cortex XSOAR 6.12. 

 You can specify which Cortex XSOAR users receive an email notification when an engine disconnects. 

 Go to Settings → About → Troubleshooting . 

 In the Server Configuration section, add the following key and value. 

 Key 

 Value 

 engines.notification.users 

 A comma-separated list of Cortex XSOAR users. For example, user1,user2,user3
