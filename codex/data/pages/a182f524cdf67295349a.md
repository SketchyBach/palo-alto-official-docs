 dump ml7 mctd version 

 Use the dump ml7-mctd version command to display the library
 and content version of the App IDs. 

 Command 

 dump ml7-mctd version 

 Options 

 None 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands 

 Introduced in Release 6.4.1

 dump ml7-mctd version
