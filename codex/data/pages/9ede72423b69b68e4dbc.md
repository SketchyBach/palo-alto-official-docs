 Possible Brute Force in universal authentication 

 Synopsis 

 Field 

 Value 

 Activation Period 

 14 Days 

 Training Period 

 30 Days 

 Test Period 

 1 Hour 

 Deduplication Period 

 1 Day 

 Detection Modules 

 Identity Analytics 

 ATT&CK Tactic 

 Credential Access (TA0006), Resource Development (TA0042) 

 ATT&CK Technique 

 Brute Force (T1110), Brute Force: Password Guessing (T1110.001), Compromise Accounts: Cloud Accounts (T1586.003) 

 Severity 

 Informational 

 Description 

 An abnormally high amount of authentication attempts via universal authentication were seen within a short period of time. This may indicate a brute-force attack. 

 Attacker's Goals 

 An attacker is attempting to gain access to an account secured with MFA. 

 Investigative actions 

 Check the legitimacy of this activity and determine whether it is malicious or not. 

 Check if the user usually logs in from this country. 

 Check whether a successful login was made after unsuccessful attempts.
