 User-ID Agent 10.2.4 Addressed Issues 

 Issue Description 

 WINAGENT-1006 

 Fixed an issue where after upgrading to version 10.2 or later,
 the User-ID agent did not obtain the mapping from syslog
 messages. This issue has been resolved so that the User-ID agent
 version 10.0 and later collects one IP-User mapping per log when
 monitoring syslog senders. 

 User-ID Agent 10.2.3 Addressed Issues 

 Issue Description 

 WINAGENT-804 

 Fixed an issue where if LDAP proxy was enabled for a User-ID
 agent that was configured to redistribute data and the group
 mappings cache was updated (either due to an automatic update or
 a manual update using the CLI debug user-id refresh
 group-mapping all), the firewall retrieved and displayed an
 incomplete list of group members. 

 User-ID Agent 10.2.2 Addressed Issues 

 Issue Description 

 WINAGENT-890 

 Fixed an issue where the User-ID agent and TS agent certificates
 were set to expire on November 18, 2024. With this fix, the
 expiration date has been extended to January 2032. 

 User-ID Agent 10.2.1 Addressed Issues 

 Issue Description 

 WINAGENT-830 

 Fixed an issue where the Windows Server would restart unexpectedly when the credential service
 was initiated. 

 The fix requires Windows Server 2019. If
 you're unable to use Windows Server 2019 as the agent host,
 use an alternate credential phishing
 prevention method , such as Group
 Mapping or IP User
 Mapping . 

 User-ID
Agent 10.2.0 Addressed Issues 

 This User-ID agent 10.2.0 release has no updates or addressed issues. The User-ID agent 10.2.0
 release is available to maintain parity with Terminal Server (TS) agent 10.2.0
 releases.
