 dump cellular stats 

 Use the dump cellular stats command
to display the statistics of the modem. 

 Command 

 dump cellular status
 cwan1 

 Options 

 all Enter all to display statistics for all modems. 

 interface Enter the modem name to display statistics
for a specific modem. 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands 

 Introduced in Release 5.6.1
