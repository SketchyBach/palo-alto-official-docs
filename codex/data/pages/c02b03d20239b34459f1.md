Audit Logs
List audit logs
GET
https://api.prod.koi.security
/api/external/v2/audit-logs

Retrieves a paginated list of audit logs

Authorizations
bearerAuth
Authorization
string
required
Bearer authentication header of the form Bearer <token>.
Query parameters
actions
string · enum[]
optional

Filter audit logs by action(s)

Example: ["created","remediation_executed"]
categories
array[]
optional

Filter audit logs by category (user, system, endpoint)

Example: ["user","system"]
created_at_gte
string · date-time
optional

Creation timestamp greater than or equal to (inclusive) for filtering audit logs (ISO 8601)

Example: 2024-01-01T00:00:00.000Z
created_at_lte
string · date-time
optional

Creation timestamp less than or equal to (inclusive) for filtering audit logs (ISO 8601)

Example: 2024-12-31T23:59:59.999Z
object_types
array[]
optional

Filter audit logs by object type (policy, item, device, guardrail, notification)

Example: ["policy","item"]
page
number · min: 1
optional

Page number for pagination

Default: 1
Example: 1
page_size
number · max: 500
optional

Number of results per page

Default: 100
Example: 100
sort_direction
string · enum
optional

Sort direction

Example: asc
Possible values: ascdesc
types
string · enum[]
optional

Filter audit logs by type(s). Can be a single type or an array of types

Example: ["remediation","policies"]
