 New Features Introduced In March 2026 

 Find out more about the features introduced in the March 2026 release of the Cloud
 Identity Engine. 

 The following table provides a snapshot of new features introduced for the Cloud Identity
 Engine app in March 2026. Refer to the Cloud Identity Engine documentation for more
 information on how to use the Cloud Identity Engine. 

 Feature Description 

 Custom Attribute Enhancements 

 Custom attribute 
 functionality was enhanced to allow you to use these them in filter
 criteria for attribute-based Cloud Dynamic User Groups (CDUGs). In
 addition, you can create these groups based on selective attributes.
 This enhancement allows you to specify all applicable (scalar, non
 time-based, and non id-based) attributes in the filter criteria. 

 Forward Logs to Strata Logging Service 

 The Cloud Identity Engine (CIE) now supports automated
 log forwarding to the Strata Logging
 Service (SLS) . This integration provides granular visibility
 into Directory Sync and Administrative Audit events. By centralizing
 this telemetry in SLS, administrators can move beyond minimal service
 insights to efficiently troubleshoot synchronization errors, monitor
 real-time sync progress, and gather the evidence required for internal
 compliance audits.
