 Features Introduced in 2024 

 April 2024 

 Release Highlights 

 The Cortex XDR 3.10 and Agent 8.4 releases include the following highlights: 

 FEATURE 

 DESCRIPTION 

 In-product support case creation 

 Simplify the process of creating a support case by submitting a ticket directly in Cortex XDR. This allows all the relevant context to be included, such as the option to record the console, upload relevant logs, and in certain cases create and send the agent tech support file (TSF) for the selected endpoint. 

 Multi-role API keys 

 You can now create API keys with multiple roles to improve operational efficiency and allow dynamic RBAC management of API keys. The API key permissions have the aggregated permissions of the roles associated with it.
