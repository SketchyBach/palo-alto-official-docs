 Rule Details 

 Cortex AppSec Rule ID 

 APPSEC_SECRET_377 

 Category 

 Secrets 

 Severity 

 CRITICAL 

 Framework 

 Git 

 Impact 

 GitHub Fine-Grained Personal Access Tokens provide scoped access to GitHub resources. While more secure than classic tokens, exposed fine-grained tokens can still grant attackers access to repositories, workflows, packages, or other GitHub resources based on their permissions. Revoke immediately and review access logs. 

 How to Fix 

 Revoke the exposed GitHub Fine-Grained PAT immediately. Review the token's access logs in GitHub settings. Generate a new token with minimal required permissions and store it securely.
