 Chatbot CloudBlade for Slack 

 Learn about the Chatbot CloudBlade for Slack release notes. 

 Prisma SD-WAN introduces the Chatbot
CloudBlade for Slack version which provides instant SD-WAN visibility.
The Chatbot interactively queries analytics on any device and from
any location without logging into a corporate network. 

 Chatbot CloudBlade for Slack Version 1.0.0 

 This section introduces the Chatbot CloudBlade for Slack: 

 New Features 

 You can access information on SD-WAN site health, on-site and device
 configuration, device inventory, event notifications, metrics on
 bandwidth utilization, application health, and application
 performance. 

 The chatbot supports NLP (Natural Language Processing) for commands,
 which helps in having an interactive discussion with the Bot rather than
 a fixed set of static commands. 

 You can enable the Alerts/Alarms Notifications 
 field to generate slack notifications for the chatbot supported alarms
 and alerts from the SD-WAN controller. You must choose from the
 drop-down list of event codes you wish to configure, and the chatbot
 sends notifications only for those alarms or alerts with event
 codes.
