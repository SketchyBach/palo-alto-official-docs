 Asset Compliance overview 

 REST API for retrieving compliance results for an asset. Use this endpoint to retrieve compliance standard and control results for a specific asset ID, with optional filtering, sorting, and pagination. 

 Required licenses: This feature is included in XDR with the Cloud Runtime Security or Cloud Posture Security add-ons.
