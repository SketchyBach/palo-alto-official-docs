 Install Cortex XDR Agent App 7.1 for Android 

 Use this workflow to install Cortex XDR 7.1 for Android. 

 To install the Cortex XDR app, first Create an Agent Installation Package from Cortex XDR and obtain the download link. This link contains the distribution ID required to associate the app with your Cortex XDR tenant. Send this link to your end users to install the Cortex XDR app. 

 Obtain the link for your Android distribution package and send the link to your end users. 

 Instruct the end user to perform the following steps: 

 From the Android endpoint, open the custom download link for the Cortex XDR app. 

 This opens the Cortex XDR app in the Google Play Store. Do not attempt to open the link in a browser. 

 Install the app and follow the on-screen prompts to complete installation. 

 Open the app when installation completes. 

 (Android 5.1 and later releases) Grant access to Cortex XDR to monitor apps. 

 If additional permissions are required for your Android version, the Cortex XDR app prompts you to Permit usage access . 

 Note 

 This setting may have a different name depending on your Android version. 

 Exit the Cortex XDR app usage settings and then return to the Cortex XDR app. 

 Activate the Cortex XDR app for Android. 

 Enter the First name and Last name of the end user. 

 Note 

 Cortex XDR uses these names to comprise the endpoint name by adding a separating dash: < firstname > — < lastname > 

 . 

 Next, enter the user’s Company email address and then click ACTIVATE . 

 Cortex XDR uses this information to identify the endpoint. 

 Tip 

 If activation fails, the Cortex XDR app displays a notification with a link to manually supply the custom package URL or distribution ID. For example, if your custom package URL is https://play.google.com/store/apps/details?id=com.paloaltonetworks.trapsa&referrer=123456abcdef , you can specify the entire URL, or, you can specify only the distribution ID which is the string following referrer= in the URL (for example, 123456abcdef). To retry activation, click ACTIVATE BY URL and supply the required information. 

 (Optional) Configure additional app settings. 

 From the Summary page, select the Cortex XDR menu at the top left and then select Settings . From this area, you can configure settings such as your preferred Language and preferences for Notifications that Cortex XDR displays.
