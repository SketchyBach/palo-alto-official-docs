 47 Dataplane Cores Support for VM-Series and CN-Series Firewalls 

 Add up to 47 dataplane cores on VM-Series and CN-Series
firewalls. 

 Starting PAN-10.2, VM-Series and CN-Series
firewalls support a maximum of 47 dataplane cores. Increasing the
number of dataplane cores improve performance. 

 For VM-Series, if you have NUMA performance optimization enabled
with custom dataplane core settings, the NUMA setting takes precedence. 

 For
example, for a 64 CPU VM with NUMA performance optimization enabled and
47 dataplane core setting, the NUMA settings take precedence. The command— show
plugins vm_series dp-cores displays— Current DP cores:31
configured custom DP cores: 47 (Current total cores: 64) . 

 For
more information, see Enable NUMA Performance Optimization
on VM-Series .
