 Prisma Access and Associated Services Processing Locations 

 Learn the country of processing for Prisma Access and its associated
 services. 

 Where Can I Use
 This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 Prisma Access license 

 Prisma Access offers a local experience in more than 100 locations
 worldwide and maps each location to a security compute location based on optimized
 performance and latency. 

 If you have a requirement to limit compute locations to specific countries, see
 the country mapping for each Prisma Access
 location and deploy only those locations that are associated with those
 countries during Prisma Access configuration. 

 The following table provides you with the country processing location for Strata Logging Service regions, Strata Cloud Manager (for Prisma Access (Managed by Strata Cloud Manager) , Prisma Access Insights , Autonomous DEM , SaaS Security Inline , and Device Security . 

 Location mappings shown with a dash (—) indicate that Device Security is not supported
 in that Strata Logging Service region. For example, if you select a Strata Logging Service region of Saudi Arabia, Device Security cannot receive
 logging metadata from the firewall. Palo Alto Networks recommends that you select other
 regions that are supported by both Strata Logging Service and Device Security .
