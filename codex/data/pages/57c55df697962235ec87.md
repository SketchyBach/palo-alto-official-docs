 Step 2: Set up users and roles 

 Set up users, roles, groups, and user scope as part of the onboarding process. 

 After activating your Cortex Xpanse tenant, you can begin to assign users to roles. Cortex Xpanse uses role-based access control (RBAC) to manage roles with specific permissions for controlling user access. RBAC helps manage access to Cortex Xpanse components, so that users, based on their roles, are granted minimal access required to accomplish their tasks. 

 You can set up and manage user roles in the following locations: 

 Cortex Gateway: Set up and manage roles and permissions for multiple tenants linked to the same Customer Support Portal account. Roles and permissions are applied across all tenants and all Cortex products. You can exclude different tenants or different Cortex products. For more information, see Cortex Gateway Administrator Guide . 

 Cortex Xpanse tenant: Set up and manage users, roles, groups, and user scope for a specific Cortex Xpanse tenant only. For details, see Users and roles 

 You can assign roles directly to users or create user groups and assign roles to those groups. We recommend creating user groups (with a user role), and assigning users to those user groups rather than creating direct roles for each user. For a list of predefined roles and detailed steps to assign users to roles and create user groups, see Users and roles .
