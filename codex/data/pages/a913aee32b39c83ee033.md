 Provide Granular Access to Global Settings 

 Configure granular administrator access privileges for global firewall settings in
 PAN-OS to control which admins can modify system-wide configurations. 

 To define what global settings and administrator has
access to, when creating or editing an admin role profile ( Device Admin Roles ),
scroll down to the Global option on the WebUI tab.
