 Features Introduced in PAN-OS 8.1 

 Features introduced in PAN-OS® 8.1 

 The following topics describe the new features and new
hardware introduced with the PAN-OS® 8.1 release, which requires
content release version 769 or a later version. For upgrade and downgrade considerations and
for specific information about the upgrade path for a firewall , refer
to the Upgrade section of the PAN-OS 8.1 New Features Guide . The new
features guide also provides additional information about how to
use the new features in this release.
