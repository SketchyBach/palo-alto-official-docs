 dump vpn status 

 Use the dump vpn status command
to display the information for a virtual private network (VPN) link. 

 Command 

 dump vpn status ( VpnID= | VpnLinkID= ) 

 Options 

 VpnID Enter the VPN ID to display the information
for that particular ID. 

 VpnLinkID Enter the VPN link ID to display the information
for that particular link ID. 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands — 

 Introduced in Release 5.0.1
