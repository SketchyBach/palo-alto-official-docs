 Rancher Cluster Deployment 

 You can deploy Rancher in following two
steps: 

 Prepare a Linux host with supported Linux distribution and
4GB of memory. Install a supported version of Docker on
the host. 

 Start the server. 

 To install and run Rancher, run the
following Docker command on your host: 

 $ sudo docker run --privileged -d --restart=unless-stopped -p 80:80 -p 443:443 rancher/rancher 

 After a successful deployment, you can access Rancher server
UI and set up a password for the admin user. To access the Rancher
server UI, open a browser and go to the hostname or address where
the container was installed. You will be guided through setting
up your first cluster.
