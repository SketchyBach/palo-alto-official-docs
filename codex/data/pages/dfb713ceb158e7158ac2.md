 Credentials from Password Stores (T1555), Steal Application Access Token (T1528) 

 Severity 

 Informational 

 Description 

 Sensitive Microsoft Teams cookies files were accessed. 

 Attacker's Goals 

 Attacker may access credentials files and steal application access tokens to gain remote access. 

 Investigative actions 

 Investigate the actor process to determine if it was used for legitimate purposes or malicious activity. 

 Review the host for any additional unusual activity. 

 Investigate the Graph API calls followed by the user that might be related.
