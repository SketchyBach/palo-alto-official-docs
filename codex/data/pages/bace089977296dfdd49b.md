 dump syncd status 

 Use the dump syncd status command to display the current syncd
 configuration. This command shows whether the service is currently running or
 stopped. 

 Command 

 dump syncd status 

 Options 

 None 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands 

 config syncd 

 Introduced in Release 6.6.1 

 Example 

 dump syncd status
================================================================================
 SYNCD STATUS
================================================================================

 Configuration : ENABLED
 Persists across reboot: Yes

 Service Status : RUNNING (PID: 19456)

===============================================================================
