 High Packet Buffer Utilization 

 Incident Code 

 INC_NGFW_PACKET_BUFFERS_USAGE 

 Severity 

 High 

 Category 

 Device 

 Subcategory 

 System Resources 

 Description 

 This Incident indicates that a network device's temporary memory
 (buffers) is nearly full due to traffic holding in queue to be
 processed or transmitted. This typically signals network congestion
 or a sudden spike in traffic. 

 Raise Condition 

 When the average packet buffer utilization on one or more dataplanes
 exceeds 85% for 20 minutes OR anomalous surge in packet buffer usage
 exceeding a lower threshold of 40% utilization. 

 Clear Condition 

 When the average packet buffer utilization drops below the 85%
 threshold or below 40% for anomaly detection and remains in that
 state for 8 hours.
