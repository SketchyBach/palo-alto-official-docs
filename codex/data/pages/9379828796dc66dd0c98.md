 TS Agent 10.2.4 Addressed Issues 

 This TS agent 10.2.4 release has no updates or addressed issues. The TS agent 10.2.4
 release was provided to maintain parity with the User-ID agent 10.2.4 release.

 This TS agent 10.2.3 release has no updates or addressed issues. The TS agent 10.2.3
 release was provided to maintain parity with the User-ID agent 10.2.3 release. 

 TS Agent 10.2.2 Addressed Issues 

 Issue Description 

 WINAGENT-890 

 Fixed an issue where the User-ID agent and TS agent certificates
 were set to expire on November 18, 2024. With this fix, the
 expiration date has been extended to January 2032.
