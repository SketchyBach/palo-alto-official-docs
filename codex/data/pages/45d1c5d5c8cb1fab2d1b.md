 New Features - AI Access Security - September 2025 

 AI Access Security Dashboard for Prisma Browser 

 Release Date: September 2025 
 | 
 Last Updated: May 2026 

 Prisma Browser is embedded with AI Access Security and provides comprehensive GenAI app visibility, access control, data, and threat protection for Prisma Browser standalone customers. This integration delivers the most comprehensive catalog of GenAI apps with leading data classification and real-time threat defense. 

 As a Prisma Browser standalone security administrator, you can now access AI Access Security under the Insights menu to monitor third party AI application usage through Prisma Browser with detailed analytics. The GenAI Apps monitoring feature provides detailed application metrics including total, allowed, and blocked GenAI applications, enabling administrators to maintain comprehensive oversight of AI tool usage within their organization. Additionally, the Unique GenAI Users tracking capability offers visibility into user access patterns, allowing administrators to drill down into individual user activities and review specific GenAI applications that have been allowed or blocked for particular users through the enhanced Events page filtering system. 

 Security enhancements include advanced threat detection capabilities that monitor and block malicious URLs and files specifically within GenAI applications. The system now provides detailed threat analytics through the Threats Detected widget, categorizing security incidents by malware type including malicious websites and file-based threats. Data protection has been significantly strengthened through the new Data Transfers monitoring system, which leverages Enterprise Data Loss Prevention (E-DLP) profiles to detect sensitive data incidents across various activities including file uploads and downloads, clipboard operations, content sanitization, screen sharing, and printing activities. 

 You can now perform deep inspection of activities performed by users who attempt to share context with AI Applications including uploads, pasting, typing, and screen sharing. Customers can deploy a large range of mitigations and controls including encrypted asset handling where only the browser maintains decryption keys, protected asset management for controlled copy-paste operations between sanctioned applications, and just-in-time access controls featuring user warnings, business justification requirements, and admin approval workflows. This comprehensive integration ensures that organizations can safely leverage GenAI tools while maintaining strict security and compliance standards. 

 The integration of AI Access Security with Prisma Browser delivers significant benefits to your organization's security framework. The solution provides minimal overhead with seamless deployment and rapid time to value, allowing you to quickly realize the benefits without complex implementation processes. Real-time protection capabilities offer advanced defense against evasive threats, ensuring your organization stays protected against the latest AI-related security risks. Complete visibility is achieved through the most comprehensive GenAI app catalog and monitoring capabilities available in the market. Just-in-time controls leverage leading data classification technologies with dynamic access controls, providing the right level of protection at the right time based on real-time risk assessment.
