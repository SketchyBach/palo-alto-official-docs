 Remediate SaaS App Misconfigurations 

 Take action in SaaS Security Posture Management to remediate SaaS app misconfigurations. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 SaaS Security Posture Management license 

 Or any of the following licenses that include the Data Security license: 

 CASB-X 

 CASB-PA 

 After you browse the posture security alerts on the Dashboard and investigate the
 misconfigurations that SaaS Security Posture Management (SSPM) detected, you can take action. If
 automated remediation is available, you can remediate the non-compliance with a
 single click. Otherwise, you can follow the steps for manual remediation. You can
 also modify the suggested value for the setting. 

 As you remediate posture security risks, consider the following best practices for
 efficient remediation: 

 Remediate all Open incidents with
 High severity first. 

 Resolve the violations that are eligible for automatic remediation before manual
 remediation. 

 Resolve the violations related to the SaaS apps that are critical to your
 organization. 

 If you choose to manually remediate, change the setting directly on the
 misconfigured SaaS app. 

 Log in to 
 Strata Cloud Manager . 

 Select Configuration SaaS Security Posture Security . 

 Navigate to the misconfigured setting. 

 Remediate the risk that the incident poses to your organization. From the
 setting that is in Violation, take one of the following actions: 

 If automated remediation is available, click the
 Remediation button. Optionally, to prevent
 app administrators from changing the setting, position the
 Drift Prevention toggle to the on position. 

 Follow the manual remediation instructions to modify the setting value
 in the SaaS app. 

 Modify SSPM's suggested value for the setting. Select the icon for the
 suggested value, and specify an override value.
