 New Features - Prisma SD-WAN - April 2025 

 Flow Details 

 Release Date: April 2025 
 | 
 Last Updated: May 2026 

 Flows give insights into various network flows, such as branch-to-branch, branch-to-data center, and branch-to-third-party VPN connections. This view helps identify network issues, understand traffic routing, and assess how network policies impact specific flows. 

 Flow details improve visibility into network traffic by offering end-to-end session details. They allow you to visualize a flow’s path across multiple sites and network segments, enhancing troubleshooting, traffic analysis, and network optimization. 

 You can leverage flow details to diagnose network problems that span multiple sites or involve many segments. This feature minimizes the time and effort required to correlate information from various sources, accelerating problem resolution and enhancing network management. 

 Additionally, flow details support network security audits and compliance checks by providing information about flow paths, security policies, and traffic characteristics, ensuring network traffic aligns with security policies and regulatory requirements.
