 dump app probe history 

 Use the dump app-probe history command to display details of
 application probing on a device. 

 Command 

 dump app-probe history (all | application= | server-ip= | count) 

 Options 

 all Enter all to display probing statistics for all
 applications. 

 application Enter an application name to
 display probing statistics for the application. 

 server-ip Enter a server IP address to display probing
 statistics for applications on the server. 

 count Enter count to display the total application probe
 (entry and exist) on the server. 

 Command Notes 

 Role Super, Read Only, Monitor
