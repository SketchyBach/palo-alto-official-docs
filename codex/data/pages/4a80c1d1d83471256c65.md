 Deprecation Notice: Cortex XSIAM 2.x APIs 

 The documentation for the Cortex XSIAM 2.x APIs has been deprecated and will no longer be maintained. Customers should use the latest Cortex Platform API documentation for ongoing development and integration activities. 

 The current Cortex Platform API documentation provides coverage for Cortex XSIAM 2.x functionality through direct endpoint mappings and successor APIs across Platform API services. The mappings below highlight notable API transitions where legacy Incident and Alert workflows have been consolidated into the Cases and Issues services.
