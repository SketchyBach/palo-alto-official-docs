 Edit a Widget 

 Edit widgets in Cortex XSOAR 6.12. 

 You can edit an existing widget in the dashboard or report, or in the Widgets Library . If editing a widget in the Widgets Library ,it is available to all users. If editing a widget directly in a dashboard or a report, the original widget in the Widgets Library is unaffected. 

 Not all widgets are editable, such as system widgets. 

 Create or edit a dashboard or report . 

 To edit the widget in a dashboard or report, from the widget, select the gear icon → Edit Widget . 

 If the widget is not in a dashboard or report, you need to add the widget. 

 To edit the widget in the Widgets Library , by following the procedure in Create a Widget using the Widget Builder . 

 Click Save . 

 If you are editing the widget in the dashboard or report, the widget appears in the dashboard or report. You can then adjust the size and move the widget as required.
