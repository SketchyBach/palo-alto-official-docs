 Reference C: Scan health values 

 Scan health indicates whether all scanners completed execution during a scan. It applies to pull request scans, CI scans, and branch periodic scans. 

 Scan health 

 Meaning for a pull request scan 

 Enforcement consequence 

 Next action 

 Completed 

 Every enabled scanner completed execution against the diff 

 The PR status reflects a complete evaluation of the change 

 Act on the PR status 

 Partially 

 One or more scanners failed or were skipped while others succeeded 

 The PR status was determined on partial evidence. A Passed result does not establish that the change is clean 

 Treat the merge as ungoverned. Diagnose integration health, and consider enabling Fail PR on scan error 

 Error 

 The scan failed to complete 

 No evaluation occurred. The merge proceeds unless Fail PR on scan error is enabled 

 Diagnose the cause in the data source instance health view 

 In Progress 

 The scan is currently executing 

 The status check reports a pending state in the VCS 

 Wait for completion. No rescan action exists 

 Note: Pull request scans offer no Rescan action. Re-evaluation occurs when a new commit is pushed to the pull request.
