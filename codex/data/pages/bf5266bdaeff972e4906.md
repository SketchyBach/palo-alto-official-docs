 Add Advanced Path or QoS Stacks 

 Lets learn how to add Advanced Path or QoS Stacks in Prisma SD-WAN . 

 Where Can I Use
 This? What Do I
 Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 Advanced Path and QoS Set Stacks comprise
Path Policy Sets and Quality of Service (QoS) Policy Sets which in
turn comprise Policy Rules. 

 Select Configuration Prisma SD-WAN Policies Paths (or QoS) Path Stacks (or QoS Stacks) Advanced . 

 Add Stack . 

 Enter a Name for the stack. 

 Assign the policy sets to the stack by selecting from
the Policy Set drop-down. 

 Save to add the stacks.
