 Monitor Upgrades Through the ASC Support View 

 Learn how to monitor tenant upgrades in the ASC Support View . 

 Where Can I Use This? What Do I Need? 

 Strata Multitenant Cloud Manager 

 Strata Multitenant Cloud Manager 

 Prisma Access license or SASE bundle license 

 An Identity & Access
 role with upgrade access, such as:
 Multitenant Superuser or Superuser 

 If you have the necessary roles, you can view tenant versions and upgrade details. To
 view this information, access the ASC Support View and select Monitor Upgrades . 

 Use the filter to display any tenant where you are assigned a role. 

 You can use the table settings to show, hide, or rearrange columns. 

 This screen offers the following widgets: 

 Widget 

 Description 

 Tenant name 

 Displays your tenant names. 

 TSG ID 

 Displays your tenant service group IDs. 

 Current version 

 Displays your Prisma Access versions, such as:
 PANOS-10.0.8-c1188.saas . 

 Next upgrade locations 

 The locations of the upgrade, such as: US East,
 Singapore, Ireland . 

 Next upgrade date 

 The date of the next upgrade, such as:
 2023-06-10 

 Next upgrade window 

 The time window of the next upgrade, such as
 Tuesday, 11:30 AM - 03:30 PM
 (CST) . 

 Upgrade version 

 The version of the next Prisma Access upgrade, such as:
 PANOS-10.2.4-ch39.saas .
