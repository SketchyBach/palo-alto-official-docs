 Bypass DNS Security Subscriptions Services and Disable WildFire Configuration in Panorama 

 When the Panorama auth key expires, your Cloud NGFW on Azure resource displays an
 Unhealthy or Degraded status. Force-create a new auth key to restore
 connectivity. 

 Bypass DNS Security Subscriptions Services in Panorama 

 To learn more about bypassing the DNS security subscriptions services in
 Panorama, refer to disable DNS security configuration 
 and manage your billing. 

 Disable WildFire Configuration in Panorama 

 Following are the steps to disable WildFire configurations in Panorama: 

 Remove Security Profiles: Go to Policies >
 Security , open your security rules, and set WildFire Analysis
 action to None under the Actions tab. 

 Clear Forwarding Settings: Go to Device >
 Setup > WildFire , and uncheck session info or forwarding
 settings. 

 Remove Log Forwarding: Go to Objects > Log
 Forwarding , edit profiles , and delete any WildFire log
 forwarding rules. 

 Disable Update Schedules: Go to Device > Dynamic
 Updates > WildFire , and remove or disable the recurring
 download and install schedule. You can also turn off update schedules via
 the CLI. For more information, see How to Disable WildFire
 Updates . 

 Commit Changes: Click Commit to push your
 configuration.
