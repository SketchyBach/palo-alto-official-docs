 Monitor App and Link Performance for All VPN Clusters 

 Click any widget to get an overview of all VPN clusters
for the desired health state. Additionally, you can use the Sites and
time frame for filtering to view VPN clusters based on link notifications,
latency deviations, jitter deviations, packet loss deviations, or
impacted applications within a specified period of time. 

 Field 

 Description 

 Sites 

 Name of the SD-WAN hub or branch firewall. 

 VPN Cluster 

 Name of the VPN cluster the SD-WAN hub or
branch belongs to. 

 Profile 
 Specifies whether the site is a hub or branch firewall. 

 Links 
 The number of links configured for the SD-WAN
site. 

 Link Notification 
 View the link notifications for an SD-WAN site
with degraded app or link health. 

 Latency 

 Displays the latency health status of the
tunnel. Can be Impacted , Warning ,
or OK . 

 Jitter 

 Displays the jitter health status of the
tunnel. Can be Impacted , Warning ,
or OK . 

 Packet Loss 

 Displays the packet loss health status of
the tunnel. Can be Impacted , Warning ,
or OK . 

 Apps 
 Total number of applications configured for
the SD-WAN site. 

 Impacted Apps 
 Number of impacted applications at the SD-WAN
site. 

 Error Correction Type 

 Specifies the type of forward error correction
applied for one or more applications. If empty (blank), then no
error correction was applied. 

 FEC —Forward
Error Correction 

 PD —Packet Duplication
