 PAN-LC-MIB.my 

 PAN-LC-MIB.my contains definitions of managed objects
that Log Collectors (M-Series appliances in Log Collector mode)
implement. Use this MIB to monitor the logging rate, log database
storage duration (in days), and disk usage (in MB) of each logical
disk (up to four) on a Log Collector. For example, you can use this
information to determine whether you should add more Log Collectors
or forward logs to an external server (for example, a syslog server)
for archiving.
