 Release Updates 

 Learn about new features and known issues related to AI Powered Autonomous DEM. 

 Welcome to the AI Powered Autonomous Digital Experience Manager (DEM) Release Notes.
 Here’s where you can learn about the latest features related to AI Powered
 Autonomous DEM and the known issues the team is working on to improve your
 experience.

 Autonomous DEM is a service that provides native
 end-to-end visibility and performance metrics for real application traffic in your
 Secure Access Service Edge (SASE) environment. Autonomous DEM functionality is
 natively integrated into the GlobalProtect app, 
 Prisma SD-WAN device, and Prisma Access and therefore does not
 require you to deploy any additional appliances or agents. Because of this native
 integration, the ADEM service enables synthetic tests for applications you specify, from
 the endpoint, from the Prisma SD-WAN device, and from deployed Prisma Access locations in your environment.
