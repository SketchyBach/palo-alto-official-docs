 How Often ADEM Runs Synthetic Tests 

 To monitor an application, ADEM runs the synthetic tests at frequent
 intervals. 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 Strata Cloud Manager 

 Prisma Access license 

 Autonomous DEM license 

 The table below shows the interval between test runs and the frequency at which the test
 result is sent to the ADEM portal. Note that it takes about 10 to 15 minutes to show the
 data in the ADEM portal from the time the user logs in. 

 From To Test Type Frequency 

 Access Experience Agent LAN ICMP ping 

 Every 30 seconds. 

 The agent collects up to 30 measurements, when sending to
 the portal it separates these into 1 minute chunks and creates a
 min/max/avg for each value sampled) so a max of 5 samples will be
 sent to the portal. This is common for all ICMP tests. 

 Access Experience Agent Prisma Access Gateway ICMP to ping private tunnel IP 

 Every 30 seconds. 

 The agent collects up to 30 measurements, when sending to
 the portal it separates these into 1 minute chunks and creates a
 min/max/avg for each value sampled) so a max of 5 samples will be
 sent to the portal. This is common for all ICMP tests. 

 Access Experience Agent Prisma Access Gateway ICMP to ping gateway public IP 

 Every 30 seconds. 

 The agent collects up to 30 measurements, when sending to
 the portal it separates these into 1 minute chunks and creates a
 min/max/avg for each value sampled) so a max of 5 samples will be
 sent to the portal. This is common for all ICMP tests. 

 Access Experience Agent Prisma Access Gateway ICMP to ping gateway public IP with incrementing TTLs to discover the
 hops along the path 

 Every 30 seconds. 

 Results sent to DEM portal, contains average delay, jitter
 and loss for each discovered hop in the path. 

 These path traces can be ICMP or TCP based. For the ICMP
 case the sampling comments above are not applicable. 

 Access Experience Agent Any IP or domain ICMP ping 

 Every 30 seconds. 

 The agent collects up to 30 measurements, when sending to
 the portal it separates these into 1 minute chunks and creates a
 min/max/avg for each value sampled) so a max of 5 samples will be
 sent to the portal. This is common for all ICMP tests. 

 Access Experience Agent Any IP or domain ICMP ping 

 Every 30 seconds. 

 The agent collects up to 30 measurements, when sending to
 the portal it separates these into 1 minute chunks and creates a
 min/max/avg for each value sampled) so a max of 5 samples will be
 sent to the portal. This is common for all ICMP tests. 

 Access Experience Agent Any IP or domain HTTP/S 

 Every 5 minutes. 

 Results sent to the DEM portal every 5 mins, and contains
 HTTP/S timing metrics. 

 Prisma Access Any IP or domain ICMP 

 Every 30 seconds. 

 Results sent to DEM portal, contains average delay, jitter
 and loss comprising up to 30 measurements. 

 Prisma Access Any IP or domain ICMP 

 Every 30 seconds. 

 Results sent to DEM portal, contains average delay, jitter
 and loss for each discovered hop in the path. 

 Prisma Access Any IP or domain HTTP/S 

 Every 5 minutes. 

 Results sent to the DEM portal every 5 mins, and contains
 HTTP/S timing metrics.
