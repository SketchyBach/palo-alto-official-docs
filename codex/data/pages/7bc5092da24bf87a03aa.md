 Usage Explorer 

 Usage Explorer dashboard for view Cloud NGFW consumption. 

 Where Can I Use This? What Do I Need? 

 Cloud NGFW for AWS 

 Cloud NGFW subscription 

 Palo Alto Networks Customer Support Account (CSP) 

 AWS Marketplace account 

 User role (either tenant or administrator) 

 The Usage Explorer dashboard provides a fast and convenient way to determine Cloud NGFW
 consumption for a tenant for Pay-as-You-Go (PAYG) and credit-based subscriptions
 (purchased using a contract). This information displays a daily consumption that
 includes insights on your average consumption and how it correlates with Cloud NGFW
 credits that are associated with the tenant. 

 The Usage
 Explorer feature is currently available as a preview. 

 To access the Usage Explorer: 

 Connect to the Cloud NGFW console. 

 In the console, select Usage Explorer . 

 The Usage Explorer includes options for displaying consumption over a period of time and
 allows you to download a CSV file to capture relevant data for future inspection. Daily
 consumption history is provided in a table that includes the following fields: 
 Period - Represents the time frame for the Cloud NGFW consumption. 

 Dimension - Used to identify billing for a Cloud NGFW. A dimension refers to an
 add-on (for example, Threat Prevention). 

 Consumed Units - The amount of the resource consumed by the tenant during the
 billing period. This field is relevant to the PAYG subscription model. 

 Consumed as Credits - The amount of the resource consumed by the tenant during
 the billing period. This field is relevant to the PAYG subscription model. 

 You can only filter on supported dimensions. The
 Add filter option does not currently work at this preview
 release. 

 Use the Period field to display consumption over a specified period of time. When
 using this option, consider that filtering consumption over longer periods of time could
 cause delays when displaying data: 

 By default, the Usage Explorer displays consumption
 data for the past 30 days. 

 Using the Dimensions field, you can alter the Usage Explorer display to show only
 those add-on dimensions that are part of your subscription. You can filter on all
 dimensions, or, select a dimension from the drop-down menu: 

 The Usage Explorer display differs depending on the
 Cloud NGFW tenant subscription model, either as PAYG or as a contract.
