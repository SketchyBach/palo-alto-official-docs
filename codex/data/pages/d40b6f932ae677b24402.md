BGP 

 Configuring Border Gateway Protocol (BGP) requires you to configure Basic
BGP Settings to enable BGP and configure the Router ID and
AS Number as described in the following table. In addition, you
must configure a BGP peer as part of a BGP peer group. 

 Configure the remaining BGP settings on the following tabs as
