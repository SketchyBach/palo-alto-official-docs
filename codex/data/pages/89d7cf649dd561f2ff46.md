 Cloud Identity Configuration 

 Configure the connection between the Cloud Identity agent
and the Cloud Identity Engine. 

 Use this page to configure the connection between your
on-premises Cloud Identity agent and the cloud-based Cloud Identity
Engine. 

 Directory Sync Configuration 

 Agent Status 
 Displays the agent’s status: “Agent is running”
or “Agent is stopped” 

 Start/Stop 
 Restarts the agent if it’s stopped or stops the agent if it’s running (for example, if you need
 to stop the agent from communicating with the Cloud Identity
 Engine). 

 Cloud Identity Engine 
 Enter the URL of the endpoint that will
receive the directory information. 

 To determine the
 endpoint for your region, refer to the Cloud Identity
 Engine documentation . 

 Proxy Server IP and Port (optional) 
 Enter the IP address and port number (in <IP_Address> : <Port> format,
where <IP_Address> represents the IP address of
the proxy server and <Port> represents the
port number) for your proxy to allow the Cloud Identity agent to
use a secure mTLS connection to tunnel the agent traffic through
the proxy server.
