 Clone SAML Identity Provider Configuration Through Common Services 

 Learn how to configure a Security Assertion Markup Language
(SAML) provider by cloning an existing configuration through the Common Services . 

 After you add an identity federation and
you choose to configure a Security Assertion Markup Language (SAML)
provider by cloning an existing SAML configuration, you complete
the following steps. 

 Use one of the various ways to access 
 Common Services Identity & Access . 

 Configure a SAML provider by cloning an existing SAML configuration from Common Services Identity & Access Identity Federations . 

 Select Configure
Identity Provider . 

 Select Clone IDP Configuration . 

 Make changes as needed and select Next . 

 The Configure Identity Provider button is replaced with
the Login URL and Assertion Consumer Service URL that you configured.
These are disabled by default. Select Actions Enable .
