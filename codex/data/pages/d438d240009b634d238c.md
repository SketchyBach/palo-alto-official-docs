 getCmdAnalyticsPrevalence 

 Gets the prevalence of one or more process command lines. 

 Arguments 

 Argument Name 

 Description 

 Required 

 process_command_line 

 A comma-separated list of process command lines. 

 Required 

 Outputs 

 Core.AnalyticsPrevalence.Cmd.process_command_line string 

 The process command line. 

 Core.AnalyticsPrevalence.Cmd.value boolean 

 Whether the item is prevalent. 

 Core.AnalyticsPrevalence.Cmd.data.global_prevalence.value unknown 

 The prevalence value. 

 Core.AnalyticsPrevalence.Cmd.data.global_prevalence.description string 

 A description of the prevalence metric. 

 Core.AnalyticsPrevalence.Cmd.data.local_prevalence.value unknown 

 The prevalence value. 

 Core.AnalyticsPrevalence.Cmd.data.local_prevalence.description string 

 A description of the prevalence metric. 

 Core.AnalyticsPrevalence.Cmd.data.prevalence.value unknown 

 The prevalence value. 

 Core.AnalyticsPrevalence.Cmd.data.prevalence.description string 

 A description of the prevalence metric.
