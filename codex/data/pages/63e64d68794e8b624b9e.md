 Activate Quantum-Safe Security with Secure-Flex Credits 

 Learn how to activate Quantum-safe Security using Secure-Flex Credits. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 Secure-Flex Credits 

 Superuser role 

 Network Administrator role 

 The Quantum-Safe Security license from Palo Alto Networks offers a robust
 framework for identifying, ranking, and addressing cryptographic vulnerabilities to
 ensure readiness for post-quantum transitions. This license enables the Quantum-Safe
 Security app, which integrates with Strata Cloud Manager (SCM) to offer a range of
 capabilities for managing your quantum-safe journey. 

 Use the following procedure to activate the Quantum-Safe Security license using
 Secure-Flex Credits. 

 Open the purchase confirmation email containing your Order
 ID , Credit ID , and Credit
 Quantity . 

 Click Login to Get Started to log into the Activation
 console to activate Quantum-safe Security. 

 Click Activate on the Quantum-safe Security tile. 

 Specify the Tenant from the drop-down. 

 Select a region from the drop-down. If the selected tenant already has a region
 associated, this option is grayed out. 

 You cannot change regions after activation. 

 Select the number of Inventory Assets to scan to assess
 Quantum safety. The assets are set in increments of 40 and the minimum number of
 assets is 4,000. 

 Review your selections and Agree to the Terms and
 Conditions . 

 Click Activate Now .
