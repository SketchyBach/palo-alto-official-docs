 Features Introduced in Cortex XDR App for Android 

 This release contains the following updates: 

 Cortex XDR agent App for Android Version 9.1 

 This release includes the following new features: 

 Access security events faster : Take immediate action on security threats with a redesigned, high-visibility home screen. We updated the Android app to show security alerts the moment you open it, allowing you to view and investigate event details with a single tap. This streamlined interface ensures you never miss a critical update and can respond to risks faster. 

 Mandatory update: This release includes an essential connectivity update to ensure uninterrupted and secure connectivity to Cortex XDR. 

 Changed Features 

 Cortex XDR agent App for Android Version 9.1 

 This release includes the following change: 

 The Home page of the app now displays latest events. Scan results are now accessible from the app's menu.
