 Create a text widget 

 Create a text-based widget to present information in a dashboard or report. Markdown is supported for formatting. 

 You can use a widget to display formatted text in dashboards and reports. 

 Add a text-based widget to a dashboard 

 Go to Dashboards & Reports → Dashboard Manager and create a new dashboard or right-click to edit an existing custom dashboard. 

 If you are creating a new dashboard, enter a dashboard name. 

 If you are creating a new dashboard, choose a dashboard type or create a new dashboard from scratch. 

 From the Widgets Library , drag the Free Text widget to your dashboard. 

 Add your custom text to the Free Text widget. 

 (Optional) To enable Markdown, click the vertical menu for the widget and select Use Markdown . 

 Click Next . 

 Choose your dashboard options and Generate dashboard. 

 Add a text-based widget to a report template 

 Note 

 From the dashboard manager, you can right-click an existing dashboard and choose Save as report template . You can also add text-based widgets directly to new or existing report templates, as described below. 

 Go to Dashboards & Reports → Report Templates and create a new template or right-click to edit an existing custom template. 

 If you are creating a new report template, enter a report template name. 

 If you are creating a new report template, choose a report template type or create a new report template from scratch. 

 From the Widgets Library , drag the Free Text widget to your dashboard. 

 Add your custom text to the Free Text widget. 

 (Optional) To enable Markdown, click the vertical menu for the widget and select Use Markdown . 

 Click Next . 

 Choose your report builder options and Save Template .
