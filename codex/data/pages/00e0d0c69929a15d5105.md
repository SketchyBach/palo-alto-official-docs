 Ports Used for Web Proxy 

 Network ports used by the PAN-OS web proxy feature for explicit proxy
 traffic. 

 Network ports used by firewalls and Panorama for web proxy functions. 

 Destination Port 

 Protocol 

 Description 

 8080 

 TCP 

 Used to listen for explicit proxy. Exposed on the listening
 interface. 

 6081 

 UDP 

 Used by Geneve protocol to encapsulate all user traffic.
