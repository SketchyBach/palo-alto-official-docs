 Changes to default behavior in SD-WAN plugin 3.3.1. 

 ( SD-WAN plugin 3.3.1 and later 3.3 releases ) In the earlier SD-WAN plugin
 releases, all the SD-WAN logs were added in to one single log file,
 plugin_sd_wan.log . 

 The SD-WAN logs are now categorized based on the events and added into the following new
 log files: 

 plugin_sd_wan_config.log —Contains general configuration log
 messages. 

 plugin_sd_wan_config_prisma_access.log —Contains Prisma access
 cloud configuration-related log messages. 

 plugin_sd_wan_daemon_mdb_udpate.log —Contains log messages from
 mongo database related to monitoring. 

 plugin_sd_wan_install.log —Contains install and other utility
 log messages. 

 plugin_sd_wan_monitoring.log —Contains monitoring log
 messages.
