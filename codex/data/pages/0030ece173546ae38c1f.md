 Cortex Cloud Posture Management Release Information 

 Cortex Cloud Posture Management is a comprehensive security solution offering proactive cloud security and compliance of your cloud environments. It helps you maintain a secure posture by enabling real-time investigation and remediation of cloud security issues from a single platform through a unified data lake. Cortex Cloud Posture Management is comprised of several modules, each targeting a different aspect of your cloud environment: Cortex Cloud Identity Security, Cortex Cloud Data Security, Cortex Cloud AI Security, and Cloud Workload Protection (CWP).
