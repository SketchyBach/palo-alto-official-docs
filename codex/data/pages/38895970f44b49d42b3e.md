 User-ID Agent 9.1 Addressed Issues 

 Want to know if there are any addressed issues related
to the Windows User-ID™ agent 9.1 release? 

 The following table lists any issues that are fixed
in Windows User-ID™ 9.1 releases. 

 User-ID Agent 9.1.5 Addressed Issues 

 User-ID Agent 9.1.4 Addressed Issues

 User-ID Agent 9.1.0 Addressed Issues 

 For recent updates to addressed issues for a given PAN-OS®
release, refer to https://live.paloaltonetworks.com/t5/Integration-Articles/Critical-Issues-Addressed-in-PAN-OS-Releases/ta-p/52882 . 

 User-ID Agent 9.1.5 Addressed Issues 

 Issue Description 

 WINAGENT-890 

 Fixed an issue where the User-ID agent and TS agent certificates
 were set to expire on November 18, 2024. With this fix, the
 expiration date has been extended to January 2032. 

 User-ID Agent 9.1.4 Addressed Issues 

 Issue Description 

 WINAGENT-830 

 Fixed an issue where the Windows Server
would restart unexpectedly when the credential service was initiated. 

 The
fix requires Windows Server 2019. If you are unable to use Windows
Server 2019 as the agent host, use an alternate credential phishing prevention
method , such as Group Mapping or IP
User Mapping . 

 User-ID Agent 9.1.3 Addressed Issues 

 Issue Description 

 WINAGENT-753 

 Fixed an issue that occurred after importing
the certificate to the User-ID agent where the MDM service started
but disconnected from the firewall after a few seconds. 

 User-ID Agent 9.1.2 Addressed Issues 

 Issue Description 

 WINAGENT-697 

 Fixed an issue where the firewall did not
receive group member information if an LDAP proxy was enabled for
the User-ID agent. 

 WINAGENT-671 

 Fixed an issue where if the Windows User-ID
agent was configured as a syslog listener and handled the syslog
login and logout messages at the same time, the User-ID agent was
unable to delete the user mapping. 

 WINAGENT-654 

 Fixed an issue for the User-ID Credential
Service where an LDAP bind failure occurred after enabling the LDAP
over SSL Require Signing feature on the domain
controller. 

 WINAGENT-632 

 Fixed an issue where a memory leak caused
the credential service to crash on Windows Server 2016. 

 User-ID Agent 9.1.1 Addressed Issues 

 Issue Description 

 WINAGENT-511 

 Fixed an issue where the User-ID integration
with the AirWatch MDM did not extract the device state for all managed
mobile devices. 

 WINAGENT-557 

 Fixed an issue where integrating the User-ID
agent with AirWatch mobile device manager (MDM) for compiling GlobalProtect
host information profile (HIP) reports pertaining to mobile devices
resulted in the agent not sending updated HIP reports in real-time
following an update from the MDM. 

 WINAGENT-587 

 Fixed an issue when importing the bloom
filter where the User-ID credential agent failed to decode characters
with umlauts (such as ä, ö, or ü). 

 User-ID Agent 9.1.0 Addressed Issues 

 This User-ID agent 9.1.0 release has no updates or addressed
issues. The User-ID agent 9.1.0 release was provided to maintain
parity with Terminal Server (TS) agent 9.1 releases.
