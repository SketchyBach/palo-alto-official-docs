 AL_SC_SITE_DOWN 

 Learn about the AL_SC_SITE_DOWN alert. 

 Synopsis 

 All tunnels for the service connection site are down. 

 An alert is raised if in 10 minutes, no tunnels for the service connection site in
 the location are detected to be up. 

 Alert Code—AL_SC_SITE_DOWN

 Prisma Access
