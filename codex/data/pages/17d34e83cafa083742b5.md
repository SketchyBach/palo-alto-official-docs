 Issue 

 Description 

 CPATR-17723 

 (Windows) 

 Fixed an issue caused by the signature verification check on Windows 7 and Windows Server 2008 R2 with extended support updates, which results in problems with the clipboard capturing functionality, and may lead to a system halt due to a stack corruption issue in Microsoft Windows signature verification driver.
