 Service Provider Interconnect Locations 

 Contains details of the locations or regions related to Service Provider
 Interconnect. 

 Service Provider Interconnect (SPI) regions and locations are independent of Prisma
 Access deployment regions. Prisma Access for Service Provider Interconnect supports a
 defined set of regions and locations based on the selected cloud service provider, such
 as Google Cloud Platform (GCP) or Amazon Web Services (AWS). 

 These region corresponds to the cloud compute region where the Service Provider
 Interconnect infrastructure is deployed.
