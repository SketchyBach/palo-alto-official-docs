 Request a New Feature 

 Request a new feature for Enterprise Data Loss Prevention (E-DLP) . 

 On May 7, 2025 , Palo Alto Networks is introducing new Evidence Storage and Syslog Forwarding service IP
 addresses to improve performance and expand availability for these services
 globally. 

 You must allow these new service IP addresses on your network
 to avoid disruptions for these services. Review the Enterprise DLP 
 Release Notes for more
 information. 

 Where Can I Use This? What Do I Need? 

 NGFW (Managed by Panorama or Strata Cloud Manager) 

 Prisma Access (Managed by Panorama or Strata Cloud Manager) 

 Prisma Browser 

 Enterprise Data Loss Prevention (E-DLP) license 

 Review the Supported
 Platforms for details on the required license
 for each enforcement point. 

 Or any of the following licenses that include the Enterprise DLP license 

 Prisma Access CASB license 

 Next-Generation
CASB for Prisma Access and NGFW (CASB-X) license 

 Data Security license 

 Enterprise Data Loss Prevention (E-DLP) supports many features designed to strength your security posture and
 prevent exfiltration of sensitive data. However, you can submit a feature request to
 Palo Alto Networks if there are features or functionality that Enterprise DLP 
 does not yet support, or for Next-Generation
CASB for Prisma Access and NGFW products that use Enterprise DLP . Some examples of requests you can submit are: 

 New features and
 functionality 

 Support for a new application 

 Support for a new file type 

 New predefined data patterns and
 profiles 

 Acceptance of new feature requests are not guaranteed. Palo Alto Networks prioritizes
 features with the most votes and higher impact. 

 Log in to the Data Security Feature Request Portal 
 using your Palo Alto Networks Customer Support Portal (CSP) credentials. 

 Add a New Feature Request . 

 Enter the feature request information. 

 Enter a descriptive Feature Name to help our Enterprise DLP experts quickly identify your feature request. 

 Feature requests with descriptive names help Palo Alto Networks
 quickly asses which features can have a large impact to most
 users. 

 For the CASB Product Component , enter
 Enterprise DLP . 

 In the Please add more details section, provide
 as much detail as possible regarding your feature request. 

 For example, you can provide details about how the feature would be
 used and why. 

 Enter the Customer Name . This can be your
 personal name, your organization, or both. 

 ( Recommended ) List the Use Cases(s) 
 that this feature request addresses. 

 Along with the additional details you provide, this helps Palo Alto
 Networks identify feature request with the highest impact to the
 security posture of Enterprise DLP users. 

 Fill out the remaining optional feature request fields as needed. 

 Add Feature Request . 

 Your new feature request is now listed in the All
 Ideas list where other Enterprise DLP users can vote and
 express for feature requests.
