 Known Issues in ION Device Release 6.1.4 

 Learn about the known issues in ION Release 6.1.4. 

 The following list includes outstanding known issues specific to Prisma
 SD-WAN ION release 6.1.4. 

 Issue ID Description 

 CGSDW-14432 The fp-rte process crashes when
 fetching information on security policy counters and app stats. 

 CGSDW-15257 After upgrading a data center ION device to software
 version 6.1.2, some of the Reachable Prefixes out
 of the Received Prefixes for a peer are displayed
 as Filtered Prefixes . 

 CGSDW-15868 High memory utilization due to the ADEM application is
 causing the system to run out of memory. 

 CGSDW-15970 When rebooting the active device in an HA configuration
 on the 2000 platform, the bypass pair of the active device does not pass
 traffic during reload. 

 CGSDW-15988 On upgrading the device software, a parent interface with
 more than 20 subinterfaces flaps, resulting in flapping of the IP
 addresses of the subinterfaces. 

 CGSDW-16005 The app-engine crashes while
 sending continuous TCP traffic on the 2000 platform. 

 CGSDW-16031 There is a delay in bringing down the BGP peer of a data
 center ION device when the remote end of the interface is shut
 down.
