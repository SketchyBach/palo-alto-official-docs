 dump flow count-summary 

 Use the dump flow count-summary command
to display the total concurrent flows and fps for monitoring purposes. 

 Command 

 dump flow count-summary 

 Options 

 None 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands 

 Introduced in Release 5.4.1

 dump flow count-summary
 FLOW STATS INFO at :2020-05-13 18:20:42
