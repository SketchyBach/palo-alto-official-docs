 Manage Policy for Unsanctioned SaaS Apps 

 Collaborate with your network administrator to block traffic for SaaS app and user
 activity using Security policy rules on SaaS Security Inline . 

 Where Can I Use This? What Do I Need? 

 NGFW (Managed by Panorama or Strata Cloud Manager) 

 Prisma Access (Managed by Panorama or Strata Cloud Manager) 

 SaaS Security Inline license 

 NGFW or Prisma Access license 

 Or any of the following licenses that include the SaaS Security Inline license: 

 CASB-X 

 CASB-PA 

 SaaS Security Inline enables you to collaborate with your NGFW administrator
 to block traffic for SaaS app and user activity using Security policy rules on SaaS Security Inline by creating SaaS policy rule recommendations. However,
 before you create SaaS policy rule recommendations, consider collaboration and
 authoring guidelines for effective
 workflow and rulebase management.
