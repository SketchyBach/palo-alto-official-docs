 getXQLLibraries 

 Gets a list of saved XQL library queries. XQL library queries are reusable named queries that can be referenced from other XQL queries. 

 Arguments 

 Argument Name 

 Description 

 Required 

 extra_data 

 Whether to include extra data in the response. possible values: true, false Possible values are: true, false. 

 Optional 

 xql_query_name 

 The name of the XQL query to retrieve. 

 Optional 

 xql_query_tag 

 The tag of the XQL query to retrieve. 

 Optional 

 Outputs 

 Core.xqlLibraries.xql_query_name string 

 The name of the XQL query. 

 Core.xqlLibraries.xql_query string 

 The XQL query content. 

 Core.xqlLibraries.xql_query_tags string 

 The tags of the XQL query. 

 createXQLLibraries 

 Creates and saves an XQL library query, a reusable named query that can be referenced from other XQL queries. 

 Arguments 

 Argument Name 

 Description 

 Required 

 override_existing 

 Whether to override existing queries. possible values: true, false Possible values are: true, false. 

 Optional 

 xql_query 

 The XQL query content. 

 Required 

 xql_query_name 

 The name of the XQL query. 

 Required 

 xql_query_tag 

 The tag of the XQL query. 

 Optional 

 Outputs 

 There are no outputs for this command. 

 deleteXQLLibraries 

 Deletes a saved XQL library query. Any other query still referencing the deleted library query will fail. 

 Arguments 

 Argument Name 

 Description 

 Required 

 xql_query_name 

 The name of the XQL query to delete. 

 Optional 

 xql_query_tag 

 The tag of the XQL query to delete. 

 Optional 

 Outputs 

 There are no outputs for this command.
