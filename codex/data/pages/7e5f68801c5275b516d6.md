 Browser History 

 Browser history control 

 Prisma Browser Desktop Prisma Browser Extension Prisma Browser for Mobile 

 Full support No support No support 

 The Prisma Browser allows you manage the ability to delete the browser
 history. 

 From Strata Cloud Manager , select Configuration Policy Control Sets Browser Security Privacy 

 Select Browser History . 

 Select one of the following options: 

 Enable - browser history is saved. 

 Disable - browser history is not saved, and tab
 syncing is disabled. This setting cannot be changed by users. 

 Block Deletion - browser history and download history cannot
 be deleted. 

 Click Set .
