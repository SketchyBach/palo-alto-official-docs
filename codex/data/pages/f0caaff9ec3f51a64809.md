 file tailf log 

 Use the file tailf log command
to debug logs as it allows users to tail and follow logs as they get
updated. 

 Command 

 file tailf log
 <name of the log> 

 Options 

 None 

 Command Notes 

 Role Super, Read Only 

 Related Commands — 

 Introduced in Release 4.6.1
