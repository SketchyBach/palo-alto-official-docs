 ATT&CK Technique 

 Boot or Logon Autostart Execution: Registry Run Keys / Startup Folder (T1547.001) 

 Severity 

 Low 

 Description 

 Microsoft Office adds a value to a registry entry (run keys, startup folders) to establish persistence. 

 Attacker's Goals 

 Gain persistence on the host using the Window's autostart Mechanism. 

 Investigative actions 

 Check the registry key and determine what process it'll run. 

 Check whether the executing process is benign and if this was a desired behavior as part of its normal execution flow.
