# Traps Agent 5.0 for Windows

To uninstall, use, and upgrade the Traps agent 5.0 on Windows endpoints, follow the instructions in this section.

The Traps agent protects Windows endpoints by preventing known and unknown malware from running on those endpoints and by halting any attempts to leverage software exploits and vulnerabilities. The Traps agent enforces Security policy for your organization as defined in Cortex XDR. When a security event occurs on an endpoint, the Traps agent collects forensic information about that event that you can use to analyze the incident.
