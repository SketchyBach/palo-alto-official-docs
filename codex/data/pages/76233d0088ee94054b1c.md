 Integrate Device Security with Tenable Security Center 

 Enhance vulnerability management for IoT devices by integrating Device Security with
 Tenable Security Center through Cortex XSOAR to launch scans and import
 vulnerability data.

 Where Can I Use This? What Do I Need? 

 Device Security (Managed by Strata Cloud Manager) 

 (Legacy) IoT Security (Standalone portal) 

 One of the following subscriptions: 

 Device Security subscription

 Precision AI bundle subscription

 Device Security X subscription

 One of the following Cortex XSOAR setups:

 A free, cohosted, limited-featured
 Cortex XSOAR instance

 AND 

 A free Cortex XSOAR Engine (on-premises integration)

 A full-featured Cortex XSOAR server

 Integrating Device Security with Tenable Security Center enhances your
 vulnerability management capabilities for IoT devices. After integrating, you can learn
 device details and vulnerability details from Tenable Security Center . Additionally, you can
 launch Tenable Security Center scans directly from Device Security to get deeper insights
 on vulnerabilities for a particular device. If you also integrate with a CMMS,
 Device Security can send the detected vulnerabilities as work orders, providing a
 seamless way to assess and monitor vulnerabilities in your IoT environment. Once
 configured, this integration lets you initiate scans and import vulnerability data.
 By integrating these platforms, you gain comprehensive visibility into potential
 security risks across your IoT infrastructure.

 When you initiate a vulnerability scan from Device Security , it sends a command
 through Cortex XSOAR to Tenable Security Center . You can view the scan results on
 the Vulnerability Scans Reports page, making it easy to access
 and review the findings. Device Security automatically incorporates all
 vulnerabilities discovered during these scans into the device details and
 vulnerability pages, updating devices' risk score assessments .
 By centralizing this information within Device Security , you get a holistic view of
 your security posture so you can make more informed decisions about risk mitigation
 for your infrastructure.

 For a full list of attributes that Device Security can learn through the
 integration, see
 Tenable SC Attribute Reference .

 Integrating with Tenable Security Center requires either a
 full-featured Cortex XSOAR server ,
 or a free, cohosted Cortex XSOAR cloud instance, which you can activate from the
 Device Security Integrations page.
