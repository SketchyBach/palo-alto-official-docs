 Manage Devices Through the Strata Multitenant Cloud Manager 

 Learn about managing devices through the Strata Multitenant Cloud Manager . 

 If you activate a SASE license or a Prisma SD-WAN license for your tenant and
 allocate a hardware device , the Strata Multitenant Cloud Manager enables you to manage Prisma SD-WAN devices. 

 The Virtual ION
Devices screen displays information about Virtual
ION (vION) devices. 

 The Devices screen
displays information for the current tenant. Use Tenant to
select and display information for another tenant. 

 You can specify
a State to display summary information about
devices in a specific status (default display is All ). 

 You can specify
a Model to display summary information about
devices of a specific type. 

 Device Summary displays the following
information. 

 Widget 

 Description 

 Available for allocation 

 Displays the total inventory of devices
available for allocation, both claimed and unclaimed, for the selected
tenant and its children. 

 Return devices requested 

 Displays the total number of devices requested for return for the selected tenant and its
 children. 

 Revoked 

 Displays the total number of devices revoked
for the selected tenant and its children. 

 Device Claimed 

 Displays the total number of devices claimed
for the selected tenant and its children. 

 Device Unclaimed 

 Displays the total number of devices unclaimed
for the selected tenant and its children. 

 Devices by Region displays the following
information. 

 Widget 

 Description 

 Search 
 Search for serial number or model to refine
your results. 

 More Actions 
 Bulk actions for use on devices with the
same state. Select multiple devices to see available actions. 

 Allocate 
 Bulk actions for use on devices with the
same state. Select multiple devices to allocate to a tenant. 

 Region 

 Displays tabs for each region and the number
of devices in parenthesis per region. 

 Order Association Date 

 Displays the date when the order was associated
to the region. 

 Model 

 Displays the device model. 

 Serial number 

 Displays the serial number of the device. 

 Device State 

 Displays the state of the device. 

 Allocated to 

 Displays the tenant where the device is
allocated. 

 Actions 

 Offers the following actions, depending
on the current state: 

 Allocate devices 

 Return devices 

 Re-allocate devices 

 Revoke devices 

 Previous 

 Manage Services 

 Next 

 Allocate Hardware Devices
