 Prisma AIRS Licenses 

 Learn what is required to activate and onboard your Prisma AIRS license. 

 Where Can I Use This? What Do I Need? 

 Prisma AIRS 

 Palo Alto Networks Customer Support Portal 

 Software NGFW Credits 

 Access to the Palo Alto Networks Customer Support Portal 

 Prisma® AIRS™ uses a bring-your-own license (BYOL) model. You retrieve an authcode from
 the Palo Alto Networks Customer Support Portal and apply it when deploying your Prisma
 AIRS capability. All Prisma AIRS capabilities — AI Runtime Security, AI Supply Chain
 Security, and AI Red Teaming — are funded using Software NGFW credits. 

 To use Software NGFW credits, you fund a credit pool and then create a deployment profile
 to configure one or more Prisma AIRS deployments. All deployments created with a
 deployment profile share the same authcode. 

 For Prisma AIRS API intercept, credit usage is calculated in monthly tokens (billions) where
 each token is equal to four characters. At the end of each calendar month, your token
 quota resets.
