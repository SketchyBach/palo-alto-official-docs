 Update the HSF Offline License Profile 

 Update an existing offline license profile to apply capacity changes, subscription
 updates, or vCPU adjustments to your HSF cluster. 

 Where Can I Use This? What Do I Need? 

 Prisma AIRS 

 Software NGFW Credits 

 HSF subscription license 

 Software Firewall License plugin installed on Panorama 

 Software Firewall Orchestration plugin installed on
 Panorama 

 Customer Support Portal deployment profile with Air Gap
 licensing enabled 

 Panorama Air-Gap License JSON file 

 Use this procedure to update an offline license profile after you change the number
 of vCPUs, increase the node count, or add subscriptions in the Customer Support
 Portal. You update the deployment profile in Customer Support Portal first, download
 a new Air-Gap License JSON file, and then apply the changes in both the Software
 Firewall License plugin and the Software Firewall Orchestration plugin on
 Panorama. 

 Update the deployment profile in Customer Support Portal. 

 Log in to the Customer Support Portal and open the deployment profile
 associated with the license profile you want to update. 

 Make your changes — for example, update the number of vCPUs, increase
 the number of firewalls, or add a subscription — in the deployment
 profile. 

 Download the updated Panorama Air-Gap License JSON file. 

 Update the license profile in the Software Firewall License plugin. 

 In Panorama, select Panorama Plugins SW Firewall License Offline License . 

 Select the offline license profile used by your HSF cluster. 

 Click Edit . 

 Click Browse and select the updated Air-Gap
 License JSON file you downloaded in the previous step. 

 Click OK and commit the change to
 Panorama. 

 Update the desired firewall or vCPU count in the orchestration plugin. 

 In Panorama, select Panorama Plugins SWFW Orchestration Deployments . 

 Open the HSF deployment and update the vCPU count to match the new
 value from your Customer Support Portal profile. 

 Commit the changes to Panorama, then click Update
 Deployment to apply the changes to the cluster. 

 If you modify a subscription in the Customer Support Portal,
 execute request license fetch <authcode> on
 individual nodes to retrieve the updated licenses.
