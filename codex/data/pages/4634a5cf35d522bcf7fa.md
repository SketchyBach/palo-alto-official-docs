 System Requirements 

 Review the system requirements for the Windows User-ID™
agent 11.0 release. 

 The system where you install the Windows-based User-ID™
agent 11.0 release has the following minimum requirements: 

 CPU —4 cores 

 Hard disk space —10MB 

 Memory —4GB RAM
