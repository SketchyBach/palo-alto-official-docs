 Set up Mist AI for Integration 

 Configure HPE Juniper Networking Mist AI to provide Cortex XSOAR with 
 administrator privileges and API access for integration with Device Security .

 Where Can I Use This? What Do I Need? 

 Device Security (Managed by Strata Cloud Manager) 

 (Legacy) IoT Security (Standalone portal) 

 One of the following subscriptions: 

 Device Security subscription for an advanced
 Device Security product (Enterprise Plus,
 Industrial OT, or Medical)

 Device Security X subscription

 One of the following Cortex XSOAR setups:

 A free, cohosted, limited-featured
 Cortex XSOAR instance

 AND 

 A free Cortex XSOAR Engine (on-premises integration)

 A full-featured Cortex XSOAR server

 It's assumed you already have a HPE Juniper Networking Mist AI setup. When integrating 
 Mist AI with Device Security and Cortex XSOAR , you need to 
 provide Cortex XSOAR with access to a user account that has administrator 
 privileges.

 Log in to your Juniper Mist with an account that has 
 administrator privileges.

 Optional If you want to limit the integration to only some sites in 
 your organization, follow the Juniper Mist Management Guide 
 instructions to add accounts for portal users .

 Juniper Mist creates administrator roles by sending 
 email invitations. You may need to set up a system email, or else invite the 
 administrator in charge of integrating Mist AI with 
 Device Security .

 For the account you create, assign the sites or site groups that you want to 
 give Device Security visibility to. Ensure that the account has at least an 
 Observer role or a more privileged role .

 Optional If you created a user account for Cortex XSOAR , 
 switch to that user account in the Juniper Mist .

 Follow the Juniper Mist Automation Guide instructions to 
 create API tokens .

 If you created a user account to limit the sites and site groups, create a 
 user token. Otherwise, create an organization token.

 After you generate the API token, save the Key in a secure location as you 
 need it to configure Device Security and Cortex XSOAR for 
 integration.
