 debug time sync 

 Use the debug time sync command
to manually force the clock to synchronize with the specified time
source. It is used only in troubleshooting scenarios and does not
need to run during normal operations. 

 Command 

 debug time sync [ntp | cts | any] 

 Options 

 ntp Enter ntp to synchronize with time.nist.gov.
This is the default source. 

 cts Enter cts to synchronize with controller.cgnx.net. 

 any Enter any to synchronize with time.nist.gov
or with controller.cgnx.net. First, try the network time protocol
(NTP) and then the controller time source (CTS).
