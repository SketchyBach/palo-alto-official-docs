 AppSec Objectives with Agentix 

 Track objectives 

 The AppSec Objectives tab is the central entry point for authoring and tracking every objective in the tenant. The AppSec Objectives tab sits in the Application Security navigation beneath the AppSec Dashboard tab. The tab presents the insight widgets, the tracking table, and, when no objectives exist yet, the starter-prompt empty state. 

 Assess objective posture 

 The insight widgets above the objectives table summarize the state of all objectives in the tenant so you can assess overall posture before drilling into a specific goal. 

 Widget 

 What it shows 

 Objectives 

 The total count of objectives, the count with a remediation rate below 50 percent, the count missing detection (detection rate below 100 percent), and the count missing prevention (prevention rate below 100 percent). 

 Open cases 

 The open cases associated with objectives, aggregated by severity (critical, high, medium, and low). 

 Objectives by owner 

 The count of objectives grouped by owner — the user who created each objective — so you can see how objectives are distributed across owners and identify who is accountable for each goal. 

 Read the objectives table 

 The objectives table lists every objective in the tenant. Each row is a single objective, and selecting a row opens that objective dashboard. The table combines dashboard attributes with AppSec-specific calculated metrics. 

 Column 

 Description 

 Name 

 The objective name 

 Description 

 The objective description 

 Status 

 The dashboard status of the objective: Enabled , Disabled , or Deleted 

 Sharing 

 Whether the objective dashboard is Public or Restricted 

 Owner 

 The user who created the objective 

 Remediation Rate 

 The percentage of matching issues that are resolved. See Reference C: Metric calculations 

 Open Cases 

 The open cases with open issues matching the objective scope and condition, with severity flags for critical, high, medium, and low 

 Detection Rate 

 The share of the scope and condition that produces issues. See Reference C: Metric calculations 

 Prevention Rate 

 The share of the scope and condition that is blocked by PR or CI actions. See Reference C: Metric calculations 

 Scope 

 The asset filters that define which assets the objective covers 

 Conditions 

 The issue filters that define which issues the objective tracks 

 Open an objective dashboard 

 Select any row in the objectives table to open the dashboard for that objective. The dashboard widgets are pre-filtered to the objective scope and condition, so the dashboard shows only the data relevant to that goal. Use the dashboard to review the underlying issues, cases, and trends that drive the objective metrics. 

 Delete an objective 

 Delete an objective when its goal is no longer tracked. Deleting an objective removes both the objective and its dashboard. 

 In the Application Security navigation, select the AppSec Objectives tab. 

 Locate the objective in the objectives table. 

 Right-click > Delete . 

 Results: Cortex Cloud removes the objective dashboard and then removes the objective from the tracking table. 

 Caution: Deleting an objective removes its dedicated dashboard. This action cannot be undone. Re-create the objective through the AppSec Agent (Agentix) to restore tracking for the goal.
