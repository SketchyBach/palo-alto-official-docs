 What's New in Network Discovery 3.0.1 

 Network Discovery plugin 3.0.1 supports PAN-OS 12.1, and provides
 parity with all features in Network Discovery plugin 2.2.3 
 and earlier.

 Review the new feature introduced in Network Discovery plugin 3.0.1 for parity with
 Network Discovery plugin 2.2.3.

 New Feature Description 

 SNMP Crawling Neighbor Discovery Enhancement 

 PAN-OS 12.1.2 and later 12 releases 

 Network Discovery now provides an option to include IP phones
 in the neighbor discovery topology when doing SNMP crawling.
 By default, Network Discovery excludes all IP phones from
 neighbor discovery, but includes IP phones as endpoints.

 You can include IP phones during neighbor discovery by
 configuring an sdb version from the CLI in root mode.

 sdb cfg.platform.iot-neighbor-discovery.skip-ip-phones=False 

 What's New in Network Discovery 3.0.0 

 Network Discovery plugin 3.0.0 supports PAN-OS 12.1, and provides
 parity with all features in Network Discovery plugin 2.2.2 
 and earlier. Network Discovery plugin 3.0.0 doesn't introduce any new features.

 To install Network Discovery plugin 3.0.0, review the
 Upgrade/Downgrade Considerations .
