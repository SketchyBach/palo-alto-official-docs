 Recommended Software Versions for Prisma Access 6.1.1 Preferred and
 Innovation 

 There are two Prisma Access 6.1.1 versions: 

 6.1.1 Preferred runs a PAN-OS 11.2.7-h10 dataplane. 

 6.1.1 Innovation runs on a PAN-OS 12.1.5 dataplane. 

 For Prisma Access 6.1.1 features, Palo Alto Networks recommends
 that you upgrade your Prisma Access to the following versions 
 before installing the plugin.
