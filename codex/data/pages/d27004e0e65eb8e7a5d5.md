 show high-availability control-link 

 Description 

 Show WildFire appliance
cluster high-availability (HA) statistics for the HA control link
between the primary and backup controller nodes, including the number
of different types of messages transmitted and received on the HA
control link, connection failures, and ping activity. 

 Hierarchy Location 

 show high-availability 

 Syntax 

 control-link { 
statistics; 
} 

 Options 

 > statistics —Display
WildFire appliance cluster controller node HA control-link statistics.
