 Reference B: Essential filtering rules 

 When constructing filters in the Unified Asset Inventory UI, keep these two system rules in mind to avoid blank tables: 

 Rule 1: The Boolean AND trap 

 When selecting multiple stages under the Development Cycle Stages filter, you must use the OR operator. 

 Why: The system assigns exactly one furthest-reached stage value to each asset. An asset's furthest stage cannot simultaneously be both Build and Runtime. Filtering with AND will always result in an empty table 

 Rule 2: Empty (NULL) values represent Untraced 

 If an asset's Development Cycle Stages field is blank, it means lineage has not yet been computed by the periodic background job [12]. 

 Note: An untraced filter using Not Contains cannot match these blank fields until the tracing job executes. The Code-to-Cloud Coverage dashboard automatically counts empty/NULL values as untraced.
