 View Application Experience for Monitored Users on NGFW 

 You can use ADEM to gain visibility into the application experience of mobile users
 connecting to the internet through an NGFW Gateway. 

 Where Can I Use
 This? What Do I Need? 

 Strata Cloud Manager 

 ADEM or Strata Cloud Manager Pro 
 license 

 GlobalProtect or Prisma Access Agent license 

 NGFW running 
 PAN-OS 11.1.9 or a later version 

 PAN-OS 11.2.6 or a later version 

 For holistic visibility into application experience on your network, Autonomous Digital Experience Management (ADEM) can monitor the end-to-end application experience of users
 connecting to next-generation firewalls (NGFWs), in addition to users connecting to
 Prisma Access . 

 ADEM provides insights into the application experience
 of mobile users connecting to an NGFW with a GlobalProtect Gateway installed. This
 enables you to view the number of user devices running synthetic tests through your
 NGFW Gateway as well as the number of users impacted at that segment of the service
 delivery path. 

 To view the experience of mobile users connecting to an NGFW Gateway: 

 If you have not already, configure a GlobalProtect Gateway on
 an NGFW associated with the same tenant 
 as ADEM. 

 From Strata Cloud Manager , select Insights Application Experience . 

 With Mobile User Experience selected, scroll to
 Application Performance Root Cause . 
 If you have users accessing apps through an NGFW
 Gateway , you'll see it represented as a service delivery
 segment. 

 If users are accessing apps through other paths as well, such as
 Prisma Access or directly through the internet,
 you’ll also see those segments. 

 A segment’s health determines its color: 

 Green - Good 

 Yellow - Fair 

 Red - Poor 

 If the NGFW Gateway ’s health status is fair or poor,
 you may want to investigate the device.
