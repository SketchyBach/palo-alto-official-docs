 dump routing routemap 

 Use the dump routing routemap command
to display the information in a route map. Information displayed
includes AS path ids, community ids, ip nexthop and prefix ids. 

 Command 

 dump routing routemap (all | name)

 Options 

 all Enter all to see information for all route
maps. 

 name Enter a route map name to see routing information
for the routemap. 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands — 

 Introduced in Release 5.0.1 

 Example 

 dump routing routemap all
