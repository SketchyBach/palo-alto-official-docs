 dig dns 

 Use the dig command to display
domain information groper (Dig) for querying domain name system
(DNS) servers. It helps troubleshoot DNS problems along with displaying
answers from the queried name servers. 

 Command 

 dig
 <interface> 
 <server address> 
 <hostname> 

 Options 

 None 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands — 

 Introduced in Release 5.2.1 

 Example 

 dig controller1 8.8.8.8 google.com
 ; <<>> DiG 9.10.3-P3 <<>> -b 192.168.200.3 @8.8.8.8 google.com
 ; (1 server found)
 ;; global options: +cmd
 ;; Got answer:

 ;; QUESTION SECTION:;google.com. IN A

 ;; Query time: 28 msec
 ;; SERVER: 8.8.8.8#53(8.8.8.8)
 ;; WHEN: Tue Feb 04 22:23:59 UTC 2020
 ;; MSG SIZE rcvd: 55
