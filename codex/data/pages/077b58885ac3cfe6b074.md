 Use AutoFocus with the Palo Alto Networks Firewall 

 Here are ways that you can use AutoFocus with
a Palo Alto Networks firewall: 

 Use AutoFocus threat intelligence to
assess firewall artifacts. 

 On the firewall, open the AutoFocus Intelligence Summary for artifacts
in your firewall logs to view their pervasiveness and risk. Click
on any of the artifacts in the summary window to launch an AutoFocus
search for it. 

 This feature is supported
with firewalls running PAN-OS 7.1 or later release versions. 

 Use AutoFocus to search for artifacts in firewall traffic. 

 In AutoFocus, Set Up Remote Search to
specify which artifacts to look for in your firewall logs. The firewall
web interface opens in a new window in Unified log view. The Unified log entries
are filtered based on the remote search artifacts. 

 This feature is supported with firewalls
running PAN-OS 7.1 or later release versions. 

 You can
use Panorama to remotely search for artifacts in firewalls that
are not connected to AutoFocus and/or are running PAN-OS 7.0 and
earlier. 

 Use AutoFocus indicators to enforce security policy on
the firewall. 

 Export AutoFocus
Artifacts (such as IP addresses, URLs, or domains) to support
a dynamic block list (PAN-OS 7.0 or earlier)
or an external dynamic list (PAN-OS 7.1 and
later).
