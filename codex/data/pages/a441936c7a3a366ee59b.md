 LACP 

 Getting started with LACP using PAN-OS OpenConfig plugin. 

 Review the deviation file before using the
 openconfig-lacp model to familiarize yourself with supported fields. 

 When using the LACP model with PAN-OS firewalls: 

 Defaults for LACP configurations are: Interval: Slow, Mode: Passive, and system
 priority: 32768 

 A Set --delete command sets values back to default configuration. 

 Aggregate interfaces are only retrievable from the interface level. 

 Setting LACP Configuration 

 This example gNMI request sets LACP mode to active for aggregate ethernet interface
 1. 

 gnmic -a 10.1.1.1:9339 set --update /lacp/interfaces/interface[name=ae1]/lacp-mode:::string:::ACTIVE
 -u admin -p password -e JSON_IETF --timeout 30s 

 A successful set request returns: 

 {
 "timestamp": 1619038358429553698,
 "time": "2021-04-21T13:52:38.429553698-07:00",
 "results": [
 {
 "operation": "UPDATE",
 "path": "lacp/interfaces/interface[name=ae1]/lacp-mode"
 }
 ]
 } 

 Retrieving LACP Configurations 

 This example gNMI request retrieves the previously enabled LACP configurations for
 aggregate ethernet interface 1. The rest of the settings are the default
 settings: 

 gnmic -a 10.1.1.1:9339 get --path
 /lacp -u admin -p password -e JSON_IETF --timeout 30s
