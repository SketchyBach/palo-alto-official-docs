 A third-party utility was copied to a different location

 ATT&CK Tactic 

 Stealth (TA0005) 

 ATT&CK Technique 

 Masquerading: Rename Legitimate Utilities (T1036.003) 

 Severity 

 Informational 

 Description 

 To evade detection, attackers may copy a third-party utility executable to a different location. 

 Attacker's Goals 

 Detection avoidance via file rename. 

 Investigative actions 

 Check whether the executing process is benign and if this was a desired behavior as part of its normal execution flow. 

 Check the destination path of the third-party utility and try to see if it's benign.
