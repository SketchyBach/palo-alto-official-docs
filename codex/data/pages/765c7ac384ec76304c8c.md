 dump sensor type 

 Use the dump sensor type command
to display the information from sensor logs. Information displayed
includes the values for voltage sensors, eight core temperatures,
board temperature sensors, temperature of line card i350CPU, and
fan speeds. 

 Command 

 dump sensor type= (all | temperature | voltage | fan)
 <start date= YYYY-MM-DD> <end date=YYYY-MM-DD > 

 Options 

 all Enter all to display information for all sensors. 

 temperature Enter temperature to display information for temperature
sensors. 

 voltage Enter voltage to display information for voltage sensors. 

 fan Enter fan to display information for fans. 

 Command Notes 

 Role Super, Read Only, Monitor
