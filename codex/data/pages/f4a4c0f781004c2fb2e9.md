 Prompt log collection in AWS 

 Configure Cortex XSIAM to collect prompt logs from AWS for AI Detection & Response. 

 Amazon Bedrock allows you to save prompt logs to Amazon S3 or Amazon CloudWatch. For details on how to configure invocation logging using CloudWatch Logs or Amazon S3, see the AWS documentation: Model invocation logging . 

 Ingest prompt logs from Amazon S3 

 For instructions on ingesting prompt logs from Amazon S3, see Ingest generic logs from Amazon S3 . In step 7, select Prompt logs as the log type. 

 Ingest prompt logs from Amazon CloudWatch 

 For instructions on ingesting prompt logs from Amazon CloudWatch, see Ingest logs from Amazon CloudWatch . In step 1.d, select Prompt logs as the log type.
