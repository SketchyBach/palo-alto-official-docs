 Install the On-Premises Controller 

 Understand Installation Workflow 

 Understand the installation workflow before beginning to install the On-Premises
 Controller for Prisma SD-WAN. 

 Where Can I Use This? What Do I Need? 

 Prisma SD-WAN 

 Prisma SD-WAN 

 The initial installation workflow is as follows: 

 Order Prisma SD-WAN License 

 Download and Activate the Controller Image 

 Hardware and Software Preparation 

 Installation Prerequisites 

 Install the On-Premises Controller 

 Order Prisma SD-WAN License 

 There is no licence required for On-Premises Controller for Prisma SD-WAN, similar to
 the Prisma SD-WAN Cloud Controller. However, to download, install, activate, and use
 the on-premises controller, a user needs to order Prisma SD-WAN licences (ION linked
 usage licences and Support licences) that are associated with Prisma SD-WAN ION
 devices. 

 Users with ION hardware devices, an active throughput subscription, and an active
 support subscription can deploy the on-premises controller. 

 Download and Activate the Controller Image 

 Customer Support Account (CSP) maintains the Prisma SD-WAN ION device
 serial numbers and images. After it’s published to your account, you will receive
 the CSP notification to download the On-Premises Controller for Prisma SD-WAN image. 

 You will receive a magic link to initiate the Common Services onboarding. During
 activation, the admin selects the corresponding CSP where the on-premises
 controller-managed IONs reside. Serial numbers for the registered Prisma SD-WAN devices are maintained under the CSP account and are
 ready for activation on the on-premises controller deployment. 

 To download the on-premises controller image, from the CSP home page, navigate to Assets IONs Controller Download .
