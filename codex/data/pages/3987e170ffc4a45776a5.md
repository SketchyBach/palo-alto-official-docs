 dump config network 

 Use the dump config network command
to display the network specific configurations of a device. Information
includes interface details such as Interface ID, type of interface,
whether the interface is used for public or private WAN, admin state
of the interface along with IP configuration. 

 Command 

 dump config network 

 Options 

 None 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands 

 dump-support details 

 Introduced in Release 4.7.1

 dump config network
