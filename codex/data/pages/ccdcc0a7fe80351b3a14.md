 PAN-332220 

 On PA-7500 Series, PA-5500 Series, PA-3500 Series, PA-1500 Series, PA-500 Series, PA-54R
 Series, and PA-52R Series NGFW , the NGFW becomes
 unresponsive when you run the following
 command: 

 debug dataplane ip-defense test process 

 PAN-333126 

 Advanced IP Defense ( Monitor Logs Threat ) displays the AIPD DIRECT-TO-IP (NO DNS) column
 instead of the AIPD DNS SEEN [DIRECT-TO-IP DETECTION] . 

 PAN-331449 

 Advanced IP Defense logs ( Monitor Logs Threat ) display N/A in the AIPD
 DIRECT-TO-IP (NO DNS) column for connections that are correctly
 identified as direct-to-IP. 

 PAN-328819 

 In the Advanced IP Defense profile ( Objects Security Profiles Advanced IP Defense ), the DIRECT-TO-IP (NO DNS) column
 displays Not In-Use even when the profile has a
 Direct-to-IP rule configured. 

 PAN-326663 

 When the Advanced IP Defense cloud connection is interrupted, the show
 ip-defense status command returns error op command for
 client aipdd timed out as client is not available and does not
 complete.
