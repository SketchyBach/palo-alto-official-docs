 APIs for managing reports 

 Get latest report by ID 

 get https://hostname /report/ {id} /latest 

 Get the latest report by its ID. 

 Note: To get the report, it must be a scheduled report with recipients. 

 Authorizations 

 api_key 

 Authorization string Required 

 Path parameters 

 id string Required 

 the ID of the report to get 

 Responses 

 200 

 Return a report file 

 No content

 HTTP 

 Ask Copy

 Host: hostname 
 Authorization: YOUR_API_KEY 
 Accept: */* 

 200 

 Return a report file 

 No content
