 Upgrade to Cortex XDR 5 

 Additional features and enhancements 

 Cortex XDR 5 includes the following additional features and enhancements: 

 Dashboard and report enhancements 

 The following improvements make dashboard and report widgets more flexible, interactive, and customizable. 

 Create script-based widgets to display relevant third-party data and streamline complex calculations, empowering your employees with insightful information at a glance. 

 Create rich text and enhance readability with new markdown formatting for text-based widgets. 

 Optimize time tracking with the ability to measure and present time duration in widgets, using the single value chart option. 

 Refresh individual widgets on demand, while gaining visibility with an improved last updated status. 

 For more information, see Fine-tune dashboards and reports .
