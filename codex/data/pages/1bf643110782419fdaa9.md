 SASE Summary Dashboard 

 The Strata Multitenant Cloud Manager offers a SASE Summary screen
that provides a quick look at the status of all your SASE tenants. 

 If you activate a Prisma Access license and a Prisma SD-WAN license at the parent-level of your tenant hierarchy, the
 SASE Summary screen displays a high-level summarized status
 of all your SASE tenants. 

 The SASE Summary screen displays information
for the current tenant. Use Tenant to select and
display information for another tenant. 

 The tenant Region is displayed for your convenience. Select a
 region of your choice. 

 You can also specify a Time range for
which to display summary information (default display is for the
previous 7 days). 

 The SASE Summary screen offers you the
following widgets: 

 Widget 

 Description 

 Total Tenants 

 Displays the total number of tenants configured
for the selected tenant. This number includes the current tenant
plus all child tenants. 

 Depending on your active licenses,
also displays the number of tenants allocated per each license type:
Prisma SASE, Prisma Access , and Prisma SD-WAN . 

 You can also Onboard
a new tenant as a child of the currently displayed tenant. 

 Prisma SD-WAN Critical
 Incidents 

 Multitenant— Displays the total number of critical incidents 
 from
 Prisma SD-WAN for the selected tenant and its children during the
 reporting period. You can hover over the chart segments to view the
 number of critical incidents 
 per
 tenant. 

 Single tenant— Displays the total number of critical incidents 
 for the
 selected tenant. Also shows the number of critical security alerts
 per each alarm code. 

 View Prisma SD-WAN 
 critical Incidents to display the 
 Prisma SD-WAN Incidents 
 monitoring page. 

 Prisma Access Incidents 

 Multitenant— Displays the total number of critical incidents from Prisma Access for the selected tenant and its
 children during the reporting period. You can hover over the chart
 segments to view the number of critical incidents per tenant. 

 Single tenant— Displays the total number of critical incidents 
 for the
 selected tenant. Also shows the number of critical security alerts
 per each alert type. 

 View Prisma Access 
 Incidents to display the 
 Prisma Access Incidents 
 monitoring page. 

 Application Volume 

 Displays the total number of user sessions
from Prisma Access for the selected tenant and its children during
the reporting period. Also displays the percentage of user sessions
per each of the applications with the most usage. You can hover
over the chart segments to view the number of user sessions compared
to the total user sessions for each application. 

 View application info to display the Application monitoring page. 

 Risky Applications 

 Displays the total number of risky applications
from Prisma Access for the selected tenant and its children during
the reporting period. You can hover over the chart segments to view
the number of applications per risk category. 

 View application info to display the Application monitoring page. 

 Unblocked Security Threats 

 Multitenant— Displays the total number of
unblocked threats from Prisma Access for the selected tenant and
its children during the reporting period. You can hover over the
chart segments to view the number of unblocked threats per tenant. 

 Single
tenant— Displays the total number of unblocked threats for the
selected tenant. You can hover over the chart segments to view the
number of unblocked threats per threat level. 

 View
security threats to display the Threat monitoring page.
