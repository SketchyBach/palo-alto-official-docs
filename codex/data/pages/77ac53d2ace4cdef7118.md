 Prisma SD-WAN Features Introduced in May 2020 

 Learn what’s new in Prisma SD-WAN in May 2020. 

 Feature Description 

 Enhanced CloudBlades Management and Monitoring The CloudBlades configuration screen has been moved
from the top-right menu to a top-level tab and enhanced with the
following changes: The ability to view the functional status of
all CloudBlades in a single screen with hover text to quickly diagnose
issues.For CloudBlade versions that have support, the ability to
view detailed information specific to the action CloudBlade performs
under the monitor screen for each CloudBlade. For example, the Email Notifications
for Alarms-Alerts CloudBlade version 1.3 will have the ability to
show statistics around how many emails have been sent and for which
alarms/alerts.The ability to filter the card view based on the configuration state
of each CloudBlade.
