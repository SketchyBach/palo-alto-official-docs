 dump routing multicast config 

 Use the dump routing multicast config command
to display the routing multicast specific configurations of a device. 

 Command 

 dump routing multicast config ( all | brief | interface | rp | wanpeers ) 

 Options 

 all Enter all to know all the routing multicast
specific configurations of a device. 

 brief Enter brief to know the brief routing multicast specific
configurations of a device. 

 interface Enter interface to know the interfaces on which multicast
traffic is forwarded or replicated. 

 rp Enter rp to display the address of the Rendezvous Point
(RP) in the network. 

 wanpeers Enter wanpeers to know the wanpeer details
of the routing multicast. 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands 

 dump routing multicast status 

 Introduced in Release 5.6.1

 dump routing multicast config all
