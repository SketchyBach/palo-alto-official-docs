 Upgrade 5G Cellular Firmware 

 Learn how to upgrade the 5G cellular firmware. 

 View the firmware details. 

 Select Device Cellular Firmware . For Panorama, select Panorama Device Deployment Cellular Firmware . 
 This retrieves the existing available cellular firmware from the Palo
 Alto Networks update server. 

 Click Check Now . 
 This updates the existing data with the latest available cellular
 firmware from the Palo Alto Networks update server. 

 (Optional) To view more details about the firmware upgrade, select the
 version number in the Version column. 

 (Optional) To check if a cellular interface configuration is available
 and to verify firmware details, select the cellular interface and click
 here . 

 Select the Cellular Interface and
 Confirm that you want to view the current
 firmware details for the interface. 

 Close the window when you are done viewing the
 firmware details. 

 Download the firmware upgrade. 

 Download the firmware upgrade and
 Close the window when the download is
 complete. 

 Check the status of the download to verify completion by selecting
 Tasks . For the Job ID ,
 click Download in the Type 
 column. Ensure that Status is
 Completed and Close 
 the window. 

 To confirm the download is ready for installation, verify the checkmark
 in the Downloaded column. 

 Install the firmware upgrade. 

 For Panorama, select Panorama Device Deployment Cellular Firmware . 

 In the Action column, click
 Install . 

 Select the Cellular Interface where you want to
 install the firmware upgrade and Confirm your
 selection. 

 For Panorama, select the Cellular
 Interface and the Name of the
 device groups where you want to install the firmware update, then
 Confirm your selection. 

 (Active-active HA configuration only) If you have an active-active HA
 configuration, select the Sync to HA Peer option
 and Confirm your selection. 

 Check the installation status by clicking Tasks .
 For the Job ID , click Firmware
 Install in the Type column.
 Ensure that Status is
 Completed and Close 
 the window. 

 (Optional) Delete any unnecessary upgrades. 
 If you download a firmware upgrade that you don't need or don't want to
 install, delete the firmware upgrade by completing the following steps. 

 In the Action column, click
 Delete for the firmware upgrade you want to
 delete. 

 Confirm that you want to delete the firmware
 upgrade. 

 Close the window. 

 Verify the deletion of the firmware upgrade by confirming that the
 checkmark does not display in the Downloaded 
 column and that the available Action is
 Download (not Delete 
 or Install ). 

 (Optional) Create a schedule for the firmware download and installation. 
 If you want to download and install the firmware upgrade for a specific time
 (for example, during a period of low user activity), you can create a schedule
 for the firmware upgrade download and installation by completing the following
 steps. 

 In the Scheduled Operations column, click
 Schedule . 

 Specify the Date and the
 Time that you want the firmware upgrade
 download to occur. 

 Specify the Action you want to schedule. 

 Download Only —Download the firmware
 upgrade. 

 Download And Install —Download the
 firmware upgrade and install it. If you select this option,
 specify the Interface where you want to
 install the firmware upgrade. 

 (Panorama only) For Panorama, select the Devices 
 and the Interface where you want to install the
 upgrade. 

 (Active-active HA configuration only) If you have an Active-active HA
 configuration, select Sync to peer . 

 Commit your changes. 

 (Optional) If you want to delete a schedule for the firmware upgrade,
 click Delete Schedule , then click
 OK and Commit your
 changes.
