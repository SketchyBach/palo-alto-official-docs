 Viewing Statistics and Event Logs 

 Next-Gen Trust Security provides the ability to view the number of signings that a particular Signing Key has performed. In addition, all events related to code signing are logged in the event log. 

 Viewing Numbers of Signings 

 The Signing Key inventory includes two columns related to signing counts: 

 Signings Last 24 hours 

 Total Signings 

 You can view these numbers in the inventory at Insights > Signing Keys . These numbers are also included in the General Properties tab of individual Signing Keys. 

 Viewing Event Logs 

 The event log includes entries for all relevant code signing events. To access the event log, click System Settings > Event Logs . 

 All Code Signing events are logged under the Event Type CodeSign . 

 The following events are logged as part of the CodeSign event type: 

 Certificate assigned 

 Certificate request failure 

 Key pair deleted 

 New key pair created 

 Signing Key created 

 Signing Key updated 

 Signing Key(s) deleted 

 Signing Succeeded 

 See the event log documentation for instructions on filtering the event log and saving filters.
