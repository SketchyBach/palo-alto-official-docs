 Show Commands Introduced in PAN-OS 11.1 

 Command line interface 'show' commands that are new in PAN-OS 11.1: 

 Where Can I Use This? What Do I Need? 

 NGFW (Managed by PAN-OS or Panorama) 

 No prerequisites needed 

 The following commands are new in the 11.1 release. 

 show network interface ethernet <name> layer3 units <name> pppoe
show network interface ethernet <name> layer3 units <name> pppoe static-address
show network interface ethernet <name> layer3 units <name> pppoe passive
