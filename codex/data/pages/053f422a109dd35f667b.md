 What OS Versions are Supported with GlobalProtect? 

 The GlobalProtect app is supported on various devices and it's recommended to use the
 latest releases. Older versions are still supported on their respective operating
 systems. 

 The GlobalProtect app is supported on common desktops, laptops, tablets, and smartphones. We
 recommend that your end users install only supported releases of the GlobalProtect app
 on their endpoints. The minimum GlobalProtect app release varies by operating
 system. 

 To determine the minimum GlobalProtect app release for a specific operating system, refer
