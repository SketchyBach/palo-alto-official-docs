 Deploy in Cloud NGFW Console 

 Learn about the different options for deploying and managing Cloud NGFW for
 AWS. 

 Where Can I Use This? What Do I Need? 

 Cloud NGFW for AWS 

 Cloud NGFW subscription 

 Palo Alto Networks Customer Support Account (CSP) 

 AWS Marketplace account 

 User role (either tenant or administrator) 

 Cloud NGFW for AWS offers multiple options for deploying NGFW resources and managing
 Security policy rules. 

 Unlike traditional virtual firewall appliances that must be manually deployed and managed
 on virtual machines, a Cloud NGFW is a fully managed service. This approach simplifies
 deployment, automates scaling, and provides seamless integration with your cloud
 network. You can deploy Cloud NGFW resources from the dedicated Cloud NGFW tenant
 console, which you access after subscribing to the service through the AWS
 Marketplace. 

 You can perform end-to-end configuration within the Cloud NGFW console, from
 instantiating the firewall resource to registering with Panorama or Strata Cloud Manager
 and streaming logs and metrics to AWS destinations such as Amazon CloudWatch.
