 What Prisma Access Versions Are Supported for Prisma Agent

 For desktop operating systems such as macOS and Windows, you can install the Prisma Agent on an endpoint that already has the GlobalProtect app
 installed. The end users can switch between the Prisma Agent and
 GlobalProtect app . 

 For Linux distributions, Prisma Agent 
 supports the GNOME and KDE desktop environments as well as Wayland and X11 display
 servers. 

 *Support for Fedora 41 was dropped in Prisma Agent version 26.2. 

 Container traffic enforcement on Linux requires kernel 5.11 or later ( Prisma Agent 26.3 ). Run uname -r to
 check your kernel version. Arch Linux ARM (aarch64) endpoints may need to verify BTF support and recompile the
 kernel before using this feature.
