 New Broker VM image 

 Experience improved security and system stability with our new Broker VM image. New Broker VM deployments now run on a modern operating system (Debian 13) to ensure long-term support. While currently available for new setups, we are finalizing a migration path for existing brokers in a future update. 

 This feature will be available in your tenant starting February 22, 2026.
