 Severity

 Description 

 A previously provisioned DB cluster (RDS) was deleted. When a DB cluster is being deleted, all automated backups for that DB cluster are deleted and can't be recovered. 

 Attacker's Goals 

 Destruction of data. 

 Investigative actions 

 Check which cluster was deleted. 

 Check if there are any manual backups for that cluster (as they are not affected by this action).
