 inspect lqm stats 

 Prisma SD-WAN continuously monitors latency, packet loss, and jitter in both directions
 to detect and analyze one-way circuit issues in real time. This granular insight
 enhances network visibility, allowing for faster problem isolation and proactive
 remediation. By pinpointing asymmetric network degradation, Prisma SD-WAN enables
 intelligent path selection, ensuring optimal application performance while reducing
 troubleshooting complexity for IT teams. 

 Use the inspect lqm stats command to inspect the link quality metrics
 (LQM). Statistics displayed provide visibility into RTT latency, packet loss, latency,
 jitter, and MOS score. These metrics can be used to support path selection failover
 decisions such as One Way Latency and Round Trip Latency. 

 Command 

 inspect lqm stats (all | path-id=
 <Path ID> |
 path type )

 Options 

 all Enter all to inspect statistics for all interfaces. 

 path-id Enter the Path ID to inspect statistics for
the path. 

 path-type Enter the Path Type to inspect statistics for
the path. Release 5.6.1 

 Command Notes 

 Role Super, Read Only

 Introduced in Release 5.2.1
