 dump device info 

 Use the dump device info command
to display the details on the device. The device id is a unique identifier for
the device. Additional information includes firmware and hardware
versions, the manufacturer’s name, and model name and serial number
of the device. 

 Command 

 dump device info 

 Options 

 None 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands 

 dump device status 

 Introduced in Release 4.4.1 

 Example 

 dump device info
