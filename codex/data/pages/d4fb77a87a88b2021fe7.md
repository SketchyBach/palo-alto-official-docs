 The new login controls for Access and Data Control Rules 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 Prisma Browser standalone 

 Prisma Access with Prisma Browser bundle
 license or Prisma Browser standalone license 

 Superuser or Prisma Browser 
 role 

 Select Login Form to configure this method: 

 Use the feature as follows: 

 The Login Controls sub-page allows you to control logging into the applications
 and websites using the Prisma Browser . Use the feature as follows: 

 Select the Login Form . 

 In the Control form-based login page, select the following login
 type: 

 Allow - Allow login to the selected sites
 using any username and password. 

 Block - Block login to the selected
 sites. 

 Allow specific email domains - Allow login
 to the selected sites with usernames that are from specific
 email domains only. 

 Block specific email domains - Block login to the
 selected sites with usernames that are from specific email
 domains only. 

 In the Email domains tab, enter the email domains that will be
 used. 

 This step is only available if you selected
 Allow specific email domains , or Block specific email
 domains . 

 Enter the email domain in the form "@example.com." 

 Click Add email domain . 

 Repeat as needed. 

 In the Prompt tab, select one of the following options: 

 None: No prompt is needed for this rule. 

 Pop-up notification - Select one of the
 following options: 

 Warn and allow to proceed anyway -
 Users will receive a warning but they can proceed
 anyway. 

 Warn and allow to proceed anyway with a
 reason - Users will receive a warning but they
 can proceed if they provide a reason. 

 Permission Request – You will
 receive a message requesting permission. 

 Bypass timeframe – Indicate how long any bypass will
 be valid. 

 MFA - Require users to complete an additional authentication
 (such as a PIN code, Passkey, or IdP authentication) before allowing
 form login to the scoped websites. Configure the authentication factor
 used under Browser Security >
 Browser Hardening > Authentication Factor then select
 this option. 

 Set the Account Protection – Ensure that login is only possible
 from the browser by protecting the password during password reset. 

 Enable account protection for shared accounts: Users will
 be able to use shared accounts without needing to share the same
 actual password All shared accounts will have the same password
 protection. 

 If you want to configure a custom Dialog text that will appear
 when the user is blocked, you can enter the message title and
 description here. 

 Click Set . 

 Select Next: Data controls .
