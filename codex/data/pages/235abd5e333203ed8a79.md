 Diagnose Panorama Suspended State 

 If Panorama is in a suspended state, check for the following
conditions: 

 Serial numbers —Verify that the serial number on
each Panorama virtual appliance is unique. If the same serial number
is used to create two or more instances of Panorama, all instances
using the same serial number will be suspended. 

 Mode —If you deploy the Panorama virtual appliance in a high availability (HA)
 configuration, verify that both HA peers are in the same mode: Panorama mode or
 Management Only mode. 

 HA priority —Verify that you have set the HA priority
setting on one peer as Primary and the other as Secondary .
If the priority setting is identical on both peers, the Panorama
peer with a higher numerical value in serial number is placed in
a suspended state. 

 Panorama software version —Verify that both Panorama
HA peers are running the same Panorama software version (major and
minor version number).
