 Configure Software Integrity Checks 

 Configure when to run software integrity checks. 

 Where Can I Use This? What Do I Need? 

 NGFW 

 PAN-OS 12.1 and later 

 Software integrity checks run automatically at boot time and periodically then every
 day at 1:30 am in the device’s local timezone. You can configure the checks to run
 at a time of your preference. After configured, the time you set replaces the
 default 1:30 am run. 

 Schedule a software integrity check using the CLI. 
 set deviceconfig setting management common-criteria
 self-test-schedule software-integrity start-time <time in hh:mm
 format> 

 Commit your changes. 

 Select Monitor Logs System . 

 View the completed software integrity check.
