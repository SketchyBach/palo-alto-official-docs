 Access through SSH 

 Access the Prisma SD-WAN ION CLI commands through SSH. 

 Once you define the user role and device access, log in to the ION device through
 SSH with a user name (Login ID) and password. 

 Enter ssh username@<ip address> 

 Enter <password> 

 You now have access to the CLI commands.
