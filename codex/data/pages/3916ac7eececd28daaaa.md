Export to CSV

Learn how to export

Use Export on the Inventory page to download your current inventory view as a CSV file.

How to export

Open Inventory in any inventory view, including All Items, Extensions, and MCP Servers.

Apply any filters or query you want included in the export.

Click the download icon in the table toolbar (Export to CSV).

Choose an export level:

Unique item: one row per unique item.

Instance: one row per installed instance, including item and endpoint details.

Click Export.

The export runs in the background. After it completes, download the CSV from Latest exports, The export reflects your current inventory filters and view, only matching items are included.

When using the Use Case interface, the Inventory tab is split into Agentic AI, Non-binaries, and App Control. The same export option is available in each view.

Export policies to CSV

Open Governance, then select Policies to open the Policies page.

On the Policies page, select the Policies tab in the top navigation bar.

Select the Control policies sub-tab.

Select one or more policies on the current page using the checkboxes in the first column.

Upon row selection, the standard toolbar transitions to a contextual selection bar containing relevant actions.

Click the download icon on the right (Export selected policies to CSV).

The CSV downloads immediately. It includes policy metadata only: name, action, scopes, status, and dates. It does not include inventory or policy-impact data.

When the Use Case toggle is enabled, the same export option is available from the Control policies sub-tab. Only selected policies on the current page are included. Alert policies do not currently support export functionality.
