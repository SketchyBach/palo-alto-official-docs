 Troubleshoot Device Management License Errors 

 Troubleshoot the Device Count License Error for Panorama
management servers when the number of managed firewalls exceeds
the device management license limit. 

 After upgrading to PAN-OS 8.1, the Panorama
virtual appliance will check if a device management licenses has
been successfully installed. If a device management license has
not been successfully installed, or the number of firewalls managed
by the Panorama virtual appliance exceeds the device management
license limit, you have 180 days to install a valid device management
license. If no valid device management license has been installed,
the following alert appears each time you log in to the Panorama
web interface: 

 If the
number of firewalls managed by the Panorama virtual appliance exceeds
the device management license limit, the following alerts appears
each time you log in to the Panorama web interface:

install a valid device management license:

or your authorized reseller to purchase the appropriate device management
license.
