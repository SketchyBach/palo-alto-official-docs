 PagerDuty Notifier CloudBlade Integration 

 Learn how to integrate PagerDuty Notifier capabilities in Prisma SD-WAN
 CloudBlade. 

 Where Can I Use This? What Do I Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 PagerDuty Notifier CloudBlade 

 The PagerDuty Notifier CloudBlade is an integration solution that
 connects your Prisma SD-WAN environment with PagerDuty's incident management platform.
 This integration enhances your network operations team's ability to respond quickly to
 network events by leveraging PagerDuty's notification capabilities alongside your
 existing Prisma SD-WAN infrastructure. 

 While Prisma SD-WAN already provides email notifications for incidents and
 alerts, as well as ServiceNow integration through CloudBlade automation, the PagerDuty
 CloudBlade provides another layer of operational efficiency. When any alarms are
 triggered within your SD-WAN environment, this integration automatically creates
 corresponding incidents in PagerDuty, enabling you to take advantage of PagerDuty's
 alerting features, including text and email notifications to team members. 

 With this integration, you can configure various aspects of the PagerDuty incident
 creation process, including which service groups and event codes should trigger
 incidents, how frequently the system should poll for events, and how many times failed
 API calls should be retried. 

 The Status Monitor feature of the CloudBlade provides insights through multiple
 views: 
 including statistics on tickets created and resolved. 

 detailed information about specific events and their corresponding tickets. 

 comprehensive error reporting to help troubleshoot any issues that may
 arise. 

 PagerDuty CloudBlade Infrastructure 

 Based on the flowchart, the process describes an automated system for incident
 management between an SD-WAN system and a PagerDuty service. 

 After the PagerDuty Notifier Cloudblade is successfully installed and configured, it
 performs the following tasks to automate the process of managing incidents between
 your SD-WAN environment and PagerDuty. 

 Extracts the configuration parameters
 received from the CloudBlade during its initial setup. 

 Queries for SD-WAN Incidents (alarms) based on the event codes defined when
 configuring the CloudBlade. 

 For each new SD-WAN Incident detected, the CloudBlade automatically creates a
 corresponding PagerDuty Incident, ensuring no new alarms go unacknowledged. 

 If an existing SD-WAN Incident is marked as Resolved , the CloudBlade
 identifies its associated PagerDuty Incident and automatically resolves it. 

 These steps are continuously repeated after a configurable poll interval,
 ensuring real-time synchronization between SD-WAN and PagerDuty. 

 Prerequisites 

 Before you configure the PagerDuty CloudBlade, your PagerDuty instance should be
 configured and ready for integration. 

 Create the necessary full-access API key for the Prisma SD-WAN integration by
 navigating to the API Access Keys page within your PagerDuty
 account settings. After creating the key, copy and securely save it, as this key
 will not be accessible again. If the key is lost, you must create a new one. 

 Configure an email address to associate the
 PagerDuty account to which the notifications can be sent. 

 Create at least one service directory in PagerDuty
 to forward incidents from Prisma SD-WAN, and assign an Escalation Policy 
 to the Service. 

 While you can change the name of the Service Directory in
 PagerDuty, CloudBlade integrations require using the Service Directory
 ID instead of its name.
