 New Features Introduced in October 2023 

 Learn more about the new features introduced in October 2023 for the Cloud Identity
 Engine, including enhancements for the log viewer. 

 Feature Description 

 Log Viewer Enhancements 

 You can now display the data for SAML requests and responses as well
 as JSON web tokens (JWTs) using the log viewer in the Cloud
 Identity Engine. When you view the log details, you can see the data
 sent and received by the Cloud Identity Engine to your IdP. This
 information can help troubleshoot any connection issues you may
 encounter.
