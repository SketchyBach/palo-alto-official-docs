 Get started with XQL 

 XQL is the Palo Alto Networks Cortex Query Language used in Cortex XDR. 

 XQL is the Cortex Query Language. It allows you to form complex queries against data stored in Cortex XDR. This section introduces XQL, and it provides reference information on the various stages, functions, and aggregates that XQL supports.
