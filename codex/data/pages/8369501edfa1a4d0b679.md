 inspect fib-leak 

 Use the inspect fib-leak command to inspect the forwarding
 information base (FIB) table, to display FIB leak entries, and to debug path selection
 issues. 

 Command 

 inspect fib-leak (dest-vrf = destination vrf name ) 

 Options 

 dest-vrf Enter all to display information on all destination
 VRF types of FIBs. 

 Command Notes 

 Role Super, Read Only 

 Related Commands 

 Introduced in Release 6.3.1

 inspect fib-leak dest-vrf=green
