 Install a PAN-OS Software Patch 

 Install critical bug and Common Vulnerability and Exposure (CVE) fixes for Next-Gen
 firewalls. 

 Where Can I Use This? What Do I Need? 

 Next-Gen Firewall 

 Support license 

 PAN-OS 10.2.8 or later release 

 PAN-OS 12.1.4-h3 or later releases for hotfix patching 

 Outbound intenet access 

 Review the release notes for your target release and then use the following procedure
 to install a PAN-OS software patch to address bugs and Common Vulnerability and
 Exposures (CVE) in the PAN-OS release currently running on your Next-Gen firewall.
 Installing a PAN-OS software patch applies fixes to bugs and CVEs without the need
 to schedule a prolonged maintenance and allows you to strengthen your security
 posture immediately without introducing any new known issues or changes to default
 behaviors that may come with installing a new PAN-OS release. Additionally, you can
 revert the currently installed software patch to uninstall the bug and CVE fixes
 applied when you installed the software patch. 

 A system log is generated ( Monitor Logs System ) when a PAN-OS software patch is installed or reverted. An outbound
 internet connection is required to download the PAN-OS software patch from the Palo
 Alto Networks Customer Support Portal. 

 Install 

 Revert 

 Install 

 Install critical bug and Common Vulnerability and Exposure (CVE) fixes when your
 Next-Gen firewalls has outbound internet access. 

 Log in to the firewall web
 interface . 

 Select Device Software and Check Now to retrieve the latest
 PAN-OS software patches from the Palo Alto Networks Update Server. 

 Check (enable) Include Patch to display all available
 PAN-OS software patches. 

 ( PAN-OS 12.1 and later ) When Include Patch is
 enabled, Preferred Releases and Base
 Releases are disabled and automatically unchecked. 

 Locate the software patch for the PAN-OS release currently installed on your
 Next-Gen firewall. 

 A software patch is denoted by a Patch label
 displayed alongside the Version name. A patch will be
 one of three types: hot, warm, or cold, with each type resulting in a
 different automatic action after applied. 
 HOT : The web interface is refreshed. 

 WARM : One or more software processes are restarted. 

 COLD : The firewall reboots. 

 View More Info to review the software patch details such
 as the critical bug and CVE fixes and whether the Next-Gen firewall needs to be
 restarted for the fixes to be applied. 

 Download the software patch. 

 ( HA only ) Check (enable) Sync to HA Peer and Continue
 Download to download the PAN-OS software patch. 

 Click Close after the software patch successfully
 downloaded. 

 Install the software patch. 

 After the software patch has successfully installed, click
 Close . 

 Apply the software patch. 

 Click Apply when prompted to confirm you want to apply
 the installed PAN-OS software patch to the Next-Gen firewall. 

 A status bar is displayed showing the current progress of the PAN-OS software
 patch application. After the patch is applied, the corresponding action to
 its patch type (see Step 4) will occur. Click Close 
 after the patch is successfully applied. 

 ( HA only ) Install the PAN-OS software patch on the firewall HA peer. 

 Log in to the firewall web
 interface of the HA peer. 

 Select Device Software 
 Check Now . 

 Install the software patch. 

 Reboot the firewall if required. 

 Revert 

 Revert the critical bug and Common Vulnerability and Exposure (CVE) fixes applied by
 installing the PAN-OS software patch on your Next-Gen firewall. 

 Log in to the firewall web
 interface . 

 Select Device Software and locate the PAN-OS software patch you want to revert. 

 Revert the software patch. 

 ( PAN-OS 11.1 and earlier ) This action will revert the software patch
 to the base version. 

 ( PAN-OS 12.1 and later ) This action will revert the software patch
 to the previously applied version. To revert the software patch to the base
 version, see Step 6. 

 Click Revert when prompted to confirm you want to revert
 the installed PAN-OS software patch on the Next-Gen firewall. 

 A status bar is displayed showing the current progress of the PAN-OS software
 patch application. After the patch is applied, the corresponding action to
 its patch type: 
 HOT : The web interface is refreshed. 

 WARM : One or more software processes are restarted. 

 COLD : The firewall reboots. 

 Click Close after the patch is successfully
 applied. 

 ( PAN-OS 12.1 and later ) ( Optional ) Repeat steps 2 through 4
 to revert the software patch to the base version.
