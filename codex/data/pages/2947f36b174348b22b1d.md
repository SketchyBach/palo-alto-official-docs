 Dashboard 

 The Dashboard widgets show general firewall or Panorama™
information, such as the software version, status of each interface, resource
utilization, and up to 10 entries for each of several log types;
log widgets display entries from the last hour. 

 The Dashboard
Widgets topic describes how to use the Dashboard and describes
the available widgets.
