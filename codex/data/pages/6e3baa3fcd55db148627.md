 Clone an Existing Role 

 Learn how to use an existing role as a template for creating
a new one. 

 If the role you want to create is similar
to an existing role, you can use the existing role as a template by
cloning it. To clone a custom role, you must have one of the common roles :
Account, App, or Instance Administrator. 

 You
cannot clone the App or Instance Administrator roles. 

 Log in to the hub and select 

 Access
Management . 

 Select the app for which you want to clone a role. 

 Not all apps support
custom role creation. If the app does support custom role creation,
and you have administrator privileges, you will see Manage
Roles when you select it. 

 Select Manage Roles . 

 Select the dropdown of the role you want to clone. 

 Click Clone . 

 To see the permissions that the role grants, click View
Role if that role is a predefined app role or Edit
Permissions if it is a custom role. 

 To modify the name, description, and permissions of your
cloned role: 

 Select the dropdown of your cloned role. 

 Select Edit Permissions . 

 Change the ROLE LABEL , DESCRIPTION ,
or PERMISSIONS . 

 Save your changes. 

 To assign your new role, select it when you assign roles for app
instances .
