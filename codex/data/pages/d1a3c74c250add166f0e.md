 WildFire Qatar Cloud 

 A new WildFire regional cloud is now available in Qatar. The WildFire Qatar cloud
 provides the best of both worlds for Palo Alto Networks customers located in Qatar —
 customers can now utilize the WildFire cloud-based threat analysis and prevention
 engine, while ensuring that files submitted for analysis stay in the country to
 address data location concerns. Note that certain metadata connected to submitted
 samples, as described in the WildFire Privacy Datasheet , are shared
 with our other regionals clouds. While submissions stay within the borders of Qatar,
 customers still benefit from the global security intelligence and updates based on
 the network effect of Palo Alto Networks 42,000+ WildFire customers. Sensitive data
 and submissions are restricted from leaving Qatar when using the WildFire cloud
 threat analysis service. Samples submitted to the WildFire Qatar cloud and the
 resulting malware analysis, signature generation and delivery occur and remain
 within the borders of Qatar. 

 Any firewall with basic WildFire service enabled can forward
 PE (portable executables) samples to the WildFire Qatar cloud for analysis, while
 users with an active Advanced WildFire or standard WildFire subscription can forward
 all supported file types . You can access the
 WildFire Qatar portal using your support account credentials to manually upload
 files for analysis and view WildFire analysis reports. 

 You can submit samples to the WildFire Qatar cloud from the WildFire appliance,
 WildFire Qatar portal, through the WildFire API, and all Palo Alto Networks
 platforms that support the WildFire security subscription integration. 

 Submit samples to the WildFire Qatar cloud from the firewall. 

 Log in to the firewall and select Device > Setup >
 WildFire and edit General
 Settings . 

 Enter the URL for the WildFire Qatar cloud:
 qatar.wildfire.paloaltonetworks.com 

 Click OK to save your settings. 

 Submit locally-discovered malware or sample reports to the WildFire Qatar cloud
 for additional analysis. 

 Enable a WildFire appliance to submit locally-discovered malware or sample
 reports to the WildFire Qatar cloud for additional analysis and signature
 distribution: 

 Connect the WildFire appliance to the WildFire Qatar cloud by
 entering the following command from the WildFire appliance CLI: 

 admin@WF-500# set
deviceconfig setting cloud-server qatar.wildfire.paloaltonetworks.com 

 Enter the following command to submit malware to the WildFire Qatar
 cloud: 

 admin@WF-500# set
deviceconfig setting wildfire cloud-intelligence submit-sample yes 

 Manually submit samples to the WildFire Qatar cloud using the WildFire Qatar
 portal. 

 You can manually submit samples to the WildFire Qatar cloud using the
 WildFire Qatar portal: https://qatar.wildfire.paloaltonetworks.com. 

 After uploading files or URLs to the WildFire Qatar portal, you can also view
 the WildFire analysis verdict and report for the sample. 

 Submit samples through the WildFire API 

 Use the following resources to submit samples through the WildFire API to the
 WildFire Qatar cloud: 

 Submit a file:
 https://qatar.wildfire.paloaltonetworks.com/publicapi/submit/file 

 Submit a file through a URL:
 https://qatar.wildfire.paloaltonetworks.com/publicapi/submit/url 

 Submit a URL:
 https://qatar.wildfire.paloaltonetworks.com/publicapi/submit/link 

 Submit multiple URLs:
 https://qatar.wildfire.paloaltonetworks.com/publicapi/submit/links 

 To get information about your file submissions to
 the WildFire Qatar cloud, you must also use the base URI that
 corresponds to the WildFire Qatar cloud. Example:

 https://qatar.wildfire.paloaltonetworks.com/publicapi/get/verdict
