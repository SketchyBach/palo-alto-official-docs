 Prisma Access CloudBlade Release 3.1.6 

 Prisma Access CloudBlade Integration Release 4.0.0 

 Learn about the Prisma Access CloudBlade integration with Prisma SD-WAN version 4.0.0
 release information. 

 This document contains the Prisma Access for Networks (Panorama managed) CloudBlade,
 version 4.0.0 release notes. 

 Features Introduced in Prisma Access CloudBlade 4.0.0 

 The following are the new/updated features introduced in Prisma Access 
 CloudBlade: 

 Starting with version 4.0.0, notifications shown in the
 Messages tab on the CloudBlade configuration screen will be
 seen on the Status Monitor . The status monitor provides
 information on the CloudBlade, SD-WAN sites, tunnel status, list of Prisma Access regions, and CloudBlade events. This could be helpful
 in identifying and troubleshooting various scenarios. 

 Starting with version 4.0.0, the Prisma Access for Networks (Panorama
 Managed) CloudBlade integration provides Panorama High Availability (HA)
 support. 

 Compatibility of CloudBlade 4.0.0 and Prisma Access 

 The following table lists the minimum required Prisma Access and Prisma Access
 Cloud Plugin versions with CloudBlade version 4.0.0. 

 CloudBlade Version Prisma Access Version Cloud Plugin Version 

 4.0.0 
 Prisma Access 

 Supported versions for the Cloud Plugin are
 4.1.0-H38 , 4.0.0-H72 , and 3.2.1-H83
 . 

 Upgrade or Downgrade Considerations in Release 4.0.0 

 When you downgrade the CloudBlade from version 4.0.0 to version 3.1.6 with
 Panorama High Availability (HA), disable the CloudBlade integration on a passive
 Panorama instance and set the SD-WAN authorization key with any value to avoid
 unnecessary updates.
