 Troubleshoot Template or Device Group Push Failures 

 Resolve template or device group push failures due to disabled Panorama template or
 device group objects on the firewall. 

 Where Can I Use This? What Do I Need? 

 Panorama 

 Device Management license 

 Support license 

 Troubleshoot the ability for your managed firewalls to receive template and device
 groups configuration changes from Panorama management server is disabled on the
 firewall. 

 Log in to the firewall web
 interface . 

 Select Device Setup Management and edit the Panorama Settings. 

 Review the Panorama Policy and Object and
 Device and Network Template settings. 

 The example below depicts these Panorama Settings configured to block
 Panorama-pushed device group and template configurations. 

 Click each setting to enable device group and template configuration pushes
 from Panorama. 

 Click OK when prompted to enable Panorama Policy and
 Objects and Device and Network Template settings. The example below depicts
 these Panorama Settings configured to allow Panorama-pushed device group and
 template configurations. 

 Log in to the Panorama Web Interface 
 and push the configuration changes from Panorama.
