 Ports Used for DNS Proxy 

 Network ports used by the DNS proxy feature, including encrypted DNS-over-TLS and
 DNS-over-HTTPS listening ports. 

 The firewall and Panorama use the following ports for DNS proxy functions. 

 Destination Port 

 Protocol 

 Description 

 53 

 TCP/UDP 

 Port used to listen on interfaces associated with the DNS proxy
 feature. 

 443 

 TCP 

 Port used to listen to DNS-over-HTTPS (Encrypted DNS Proxy
 feature). 

 853 

 TCP 

 Port used to listen to DNS-over-TLS (Encrypted DNS Proxy
 feature).
