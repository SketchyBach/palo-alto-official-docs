 Incorrect Port Speed Configured - PA-850 

 Incident Code 

 INC_NGFW_PA850_INCORRECT_PORT_SPEED 

 Severity 

 Warning 

 Category 

 Network and Traffic 

 Subcategory 

 Interface 

 Description 

 This alert triggers when a PA-850 has an incorrect port speed configured for the
 installed SFP type. 

 Raise Condition 

 This incident is raised if a log message indicating that the PA-850 has an
 incorrect port speed configured for the installed transceiver is detected at least
 one within a one-hour window. 

 Clear Condition 

 This incident is cleared when the log message indicating that the PA-850 has an
 incorrect port speed configured for the installed transceiver is no longer
 detected for at least one hour.
