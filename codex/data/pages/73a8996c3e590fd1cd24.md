 Reference C: Dashboard filters by view 

 This appendix lists the supported filters per dashboard view. Default filters appear pinned to the dashboard header on first load; non-default filters are available from the Add filter picker. ENUM filters with no values in the live data set are dropped from the response, and filters spanning more than one lineage hop are deferred in this release.
