 Maintenance releases 

 Cortex XDR includes a number of features that are updated with every Cortex XDR Release. The Broker VM and XDR Collectors are released with their own version number, and can include additional changes that are integrated in a separate maintenance release. 

 The latest Broker VM and XDR Collectors version is the only one to receive the critical bug fixes and security patches released. Therefore, we highly recommend upgrading to the latest version released. For more information about previous maintenance releases, see Previous maintenance releases
