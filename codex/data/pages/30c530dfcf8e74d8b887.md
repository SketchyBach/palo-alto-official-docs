 PAN-OS 11.0.3-h12 addressed issues. 

 Issue ID 

 Description 

 PAN-253317 

 ( VM-Series firewalls on Microsoft Azure environments only )
 Fixed an issue where you were unable to log in to the firewall after
 a private data reset. 

 PAN-246960 

 Fixed an issue where firewalls failed to fetch content updates from
 the Wildfire Private Cloud due to an Unsupported
 protoco l error. 

 PAN-244648 

 ( PA-5200 Series only ) Fixed an issue where the firewall did
 not boot up after a factory reset, and, with FIPS mode enabled, the
 firewall rebooted into maintenance mode. 

 PAN-238769 

 ( VM-Series firewalls in FIPS-CC mode only ) Fixed an issue
 where upgrading Panorama caused all locally created Security policy rule
 actions to Deny.
