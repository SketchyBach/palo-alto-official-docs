 Access to scripts 

 Manage access to automation scripts with object-level roles in Cortex AgentiX. 

 Access to scripts is managed at the object level. This protects custom automation code and sensitive logic. 

 For how object-level access affects visibility and execution, see Manage access to playbooks and scripts . 

 Script access roles 

 When a script is shared, users receive one of these access levels: 

 Owner : Has full control over the script and its permissions. 

 Editor : Can view and modify the script code and settings. 

 Viewer : Can view the code and use the script. They cannot make changes.
