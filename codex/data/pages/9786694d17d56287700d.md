 update Object 

 Contains the information required to update IP address-to-device mappings . This JSON object has the
 following fields: 

 Field Description 

 ip IP address of the device. 

 updateTime A Unix timestamp that represents when the last update to the mapping
 occurred. 

 category Device type. Example: Printer 

 vendor Device vendor. Example: SHARP Corporation 

 model Device model. Example: MX-6070N 

 os Device operating system. Example: ThreadX 5 

 osFamily Family to which the OS of the device belongs. Example: ThreadX
 RTOS 

 profile Device profile. Example: Sharp Printer
