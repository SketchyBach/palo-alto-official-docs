 Hide Sensitive Data from Extensions 

 Hide Sensitive data control 

 Prisma Browser Desktop Prisma Browser Extension Prisma Browser for Mobile 

 Full support No support No support 

 This control allows you to prevent extensions from accessing cookies, authorization,
 and other data sent by the browser. 

 From Strata Cloud Manager , select Configuration Policy Control Sets Browser Security Extensions 

 Select Hide Sensitive Data fro Extensions . 

 Select one of the following options: 

 Enable - Prevent the extensions from accessing
 cookies and authorization data sent by the browser. 

 Disable - Allow the extensions to access cookies and
 authentications. 

 Click Set .
