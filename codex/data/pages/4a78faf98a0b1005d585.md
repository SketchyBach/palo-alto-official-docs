 Use the Prisma Agent App for iOS (Unmanaged Devices) 

 Use the Prisma Agent App on unmanaged devices. 

 Where Can I Use This? What Do I Need? 

 Prisma Agent 

 iOS 16 and later versions 

 Internet access 

 To connect the app to the unmanaged devices, you must complete the
 following steps. 

 After a first-time installation, the Prisma Agent does not
 automatically connect to Prisma Access, even if your administrator configured
 Always On mode. After this first login, Always On mode takes effect and the
 agent connects automatically on subsequent logins. 

 Open the Prisma Agent app by tapping the Prisma Agent app icon
 ( 

 ). 

 Read the disclosure about the information Prisma Agent may collect or
 access on your device and click Continue to acknowledge
 and accept the message. 

 Enable Prisma Agent notifications on your endpoint. A notification
 permission dialog appears on the app. Allow Prisma Agent to send you notifications. 

 If you Don’t Allow Prisma Agent to send you
 notifications, you will not receive any alert or notification when you face
 any issues related to app connectivity. 

 Enter the server address that you have obtained from your IT administrator and
 the connection is initiated automatically. 

 ( Prisma Agent 26.3 ) If you're unable to
 connect and need to share logs with your IT administrator, tap
 ? in the top-right corner of the enrollment page.
 This opens a share sheet with a log archive that you can share via AirDrop,
 Messages, Mail, or other apps. 

 Allow Prisma Agent to add the VPN configuration
 to your endpoint. This setting enables Prisma Agent to provide secure
 access for your device. 

 Enter the credentials that you use to authenticate and access the iOS devices
 such as password, passcode, biometric credentials and so on. For example, enter
 the iPhone passcode to authenticate to the device. 

 ( Prisma Agent 26.3 ) If your organization uses LDAP
 authentication, enter your login credentials when prompted: 

 In the Login field, enter the username or email
 address you use for LDAP authentication. 

 Enter your Password and tap
 Login . 

 Enter your organization credentials to authenticate to the app. 

 ( Prisma Agent 26.3 ) If your
 administrator configured Prisma Agent to use the default system browser for
 SAML authentication, your default browser — such as Safari — opens instead
 of the embedded browser. After you authenticate, tap
 Open in the prompt that appears to return to the
 Prisma Agent app. 

 After authentication is complete, the connection is established and the app
 displays the status as Connected . 

 Tap Disconnect on the app when you no longer need to
 access the resources through Prisma Agent .
