 Install Cortex XSOAR on a VM deployed on KVM 

 Install Cortex XSOAR 8.13 On-prem on KVM. 

 The following procedure describes the steps for deploying a qcow2 image on Kernel-based Virtual Machines (KVM) and then installing Cortex XSOAR on your deployed virtual machines. 

 The IPs of all VMs (nodes) in a cluster, as well as the virtual IP, must be on the same subnet; they currently cannot be split across subnets. 

 Complete the following tasks: 

 Task 1. Download the QCOW2 image and license from Cortex Gateway 

 Task 2. Deploy your virtual machine on KVM 

 Task 3. Configure tenant network and IP settings for each node 

 Task 4. Configure NTP servers 

 Task 5. (Optional) Configure proxy settings 

 Task 6. Establish trust between all nodes in a cluster 

 Task 7. Install Cortex XSOAR on your VM 

 Task 8. Verify you can log into Cortex XSOAR
