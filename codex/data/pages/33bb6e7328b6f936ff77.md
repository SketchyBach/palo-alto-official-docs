 Setup Incident Policies 

 Let us learn about the Prisma SD-WAN Incident policies. Incident
 policy framework provides user defined control over system generated alerts and incidents in
 the network. 

 Where Can I Use This? What Do I Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 Incident policy framework provides user-defined control over system
 generated alerts and incidents in the network. You can use incident policy rules to
 suppress or escalate incidents that arise during a scheduled time period and can also
 change the default priority of system generated incidents to a priority level that is
 more aligned with the your business requirements. 

 The incident policy rules can be applied to a set of network resources like
 sites, devices, interfaces, circuits, BGP peers, etc or can be matched to be applied on
 specific incident codes. Incident policy rules allow you to manage alerts and incidents
 for better visibility into network issues and for quicker troubleshooting. 

 Read on to know about configuring incident policies.
