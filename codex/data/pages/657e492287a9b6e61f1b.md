 New Feature/Enhancement Description 

 Strata Cloud Manager-Redesigned User Experience Starting on June 23, 2023, customers
 will begin migrating to a freshly redesigned user experience, Strata Cloud Manager . This
 user experience provides many improvements including: 
 Streamlined SASE workflows for provisioning and
 troubleshooting. 

 A common portal across ,
 cloud-management Prisma Access, ADEM, and cloud-managed
 NGFW. 

 A normalized information model making navigation faster and
 more intuitive across the various product suites. 

 Tenant Service Group (TSG) 
 Migration of Tenants Transition Prisma
 SD-WAN tenants activated before June 2022 to the Prisma
 SASE platform. 

 Predictive Analytics - 7-Days forecast and Anomaly
 detection now captures the bandwidth anomaly (computed value
 for each data point if it finds a contradiction between the past
 forecast value and the past utilization value for a data point) for
 the specified time range filter and the bandwidth forecast for the
 next seven days in preview mode. 

 Features Introduced in Release 6.1.1 

 Learn about the new features and enhancements for Release 6.1.1. 

 New Feature/Enhancement Description 

 Predictive Analytics for 
 (Preview) 

 now supports deep visibility into
 the health of sites and applications. The predictive analytics
 dashboard provides proactive monitoring to ensure exceptionally
 high service levels. Predictive Analytics helps users to: 

 Identify sites, applications, and links that are
 experiencing poor performance over a certain period. 

 Predict sites that will reach high capacity utilization
 in the future. 

 Gain insights into the top 10 sites whose bandwidth
 utilization increased in the previous 30 days. 

 Support for Branch Side Source (BSS)
 multicast supports Branch Side
 Source (BSS) multicast, which allows receivers at a branch site to
 receive multicast traffic from other branch site sources over the
 WAN. 
 Device Software Version Required: 6.1.1 and
 later 

 Supports IPv4v6 dual stack on Cellular interfaces for
 some use cases now supports for
 Cellular WAN, dual-stacked IPv4v6 is supported. For VPN underlay
 IPv4 or IPv6 is supported. For LAN to WAN direct internet traffic
 and device-to-controller connectivity on cellular interface IPv4 is
 supported. 
 Device Software Version Required: 6.1.1 and
 later 

 Data Center Multicluster has supported data
 center clusters for logical groupings of devices for data center
 sites. This release provides administrators visibility and control
 over horizontal scaling of data center clusters.
