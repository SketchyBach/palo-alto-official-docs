 Feature Description 

 Next-Generation Firewalls for Zero Touch
Provisioning 

 ( PAN-OS 9.1.3 ) 

 Zero Touch Provisioning (ZTP) is an SD-WAN
functionality that ensures a safe and hands-free on boarding of
new firewalls. ZTP functionality is supported on the following ZTP
firewalls: 

 PAN-PA-220-ZTP 

 PAN-PA-220R-ZTP 

 PAN-PA-820-ZTP 

 PAN-PA-850-ZTP 

 PAN-PA-3220-ZTP 

 PAN-PA-3250-ZTP 

 PAN-PA-3260-ZTP 

 See the Panorama Plugin for Zero Touch
Provisioning for more information on the Panorama functionality
for ZTP.
