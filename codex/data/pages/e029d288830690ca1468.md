 What's New in Network Discovery 1.0.1 

 Review the new features introduced in Network Discovery plugin 1.0.1. 

 New Feature Description 

 CLI support to specify a Network Discovery protocol 

 PAN-OS 11.1.0 and later 11.1 releases 

 You can now use the CLI to specify a single network discovery
 protocol (CDP, LLDP, or both). This new CLI option reduces the
 number of queries and network discovery job runtime. 

 set deviceconfig plugins snmp-network-discovery
 discovery-protocol 

 What's New in Network Discovery 1.0.0 

 Review the new features introduced in Network Discovery plugin 1.0.0. 

 New Feature Description 

 Learn about devices from switches using SNMP Network
 Discovery 

 PAN-OS 11.1.0 and later 11.1 releases 

 When firewalls don’t receive traffic from all devices on the
 network, they can still gather IP address-to-MAC address
 bindings and additional network data by using SNMP to query
 switches and other forwarding devices throughout the
 network. The firewalls then forward the data through the logging
 service to IoT Security for analysis.
