 Defense Impairment (TA0112) 

 ATT&CK Technique 

 Disable or Modify System Firewall: Cloud Firewall (T1686.001) 

 Severity 

 Low 

 Description 

 A cloud identity has modified the ingress rules to allow unfamiliar ip addresses SSH or RDP access. 

 Attacker's Goals 

 Obtaining persistency persistence by creating a direct, reliable backdoor that allows them to remotely control the system without needing to re-exploit it. 

 Investigative actions 

 Investigate any unusual activity originating from the suspected identity and any activity performed from the newly added ip addresses.
