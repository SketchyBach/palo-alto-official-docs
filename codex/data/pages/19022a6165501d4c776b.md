 Data Security Notifications 

 Review Data Security notification when traffic you upload or download contains
 sensitive data and generate an Enterprise Data Loss Prevention (E-DLP) incident. 

 When you generate an Enterprise Data Loss Prevention (E-DLP) 
 incident when traffic you upload or download
 contains sensitive data and matches an Enterprise DLP 
 data profile , you receive a notification on
 your screen. 

 Your device receives the following notification when an Enterprise DLP incident is
 generated. 

 Notification Text What It Means 

 Your file <file-name> uploaded to <application> was
 blocked due to company policy on sensitive data. 

 You uploaded a file that contains sensitive data to an
 application. 

 The content posted within <application> may contain sensitive
 information and was blocked due to company policy. You entered sensitive data in a web form ( non-file based ) traffic in an
 application. 

 Below are examples of alerts for file based and non-file based Enterprise DLP 
 incidents. 

 Clicking on the notification opens the Access Experience User
 Interface (UI). It provides details about the DLP incident. You can view a summary of
 all the Enterprise DLP incidents you generated by clicking Data
 Security . A list of all incidents are displayed as well as their current
 resolution status. Each Data Security notification displays for 7 days. 

 A green ( 

 ) status symbol means that you have
 reviewed the data security incident and that your data
 security administrator either approved or denied your exemption
 request . No further action is required. 

 An orange ( 

 ) status symbol means that you submitted
 an exemption for the traffic that generated the DLP incident. No further is
 required. 

 A red ( 

 ) status symbol means that the Data
 Security notification is pending and requires your review. 

 Display of the snippet of the matched traffic that generated the Enterprise DLP incident isn't currently supported and No
 policy violation snippets were published with this
 notification is displayed instead.
