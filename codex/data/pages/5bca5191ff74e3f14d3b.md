 Use the VM-Series CLI to Swap the Management Interface on KVM 

 Learn how to use the VM-Series CLI to swap management interfaces on KVM. 

 Where Can I Use
 This? What Do I Need? 

 KVM 

 VM-Series Firewall License (BYOL) 

 Panorama 

 VM-Series plugin 

 By default, the VM-Series firewall assigns the first interface (eth0) as the
 management interface. However, in some deployments, the first interface must be
 pre-mapped to a public IP address. Therefore, the management interface must be
 assigned to a different interface. Assigning a public IP address to the management
 interface is a security risk. 

 Alternatively, you can enable management interface swap as part of the init-cfg.txt File when
 bootstrapping. 

 Log in to the VM-Series firewall CLI and enter the following command: 

 set system setting mgmt-interface-swap enable yes 

 Confirm that you want to swap the interface and use the eth1 dataplane
 interface as the management interface. 

 Reboot the firewall for the swap to take effect. Use the following
 command: 

 request restart system 

 Verify that the interfaces have been swapped. Use the following command: 

 debug show vm-series interfaces all
