 Phase 2: Platform service accounts 

 This phase creates the main service account used by Cortex to monitor your GCP resources. 

 Note: All GCP resources that support labels must include the following labels: 

 managed_by=paloaltonetworks 

 Any additional labels you configured in the GCP onboarding wizard in Cortex. 

 To add a label to a GCP resource, use the label flag: 

 Ask Copy 

 --labels managed_by=paloaltonetworks, < your_ke y > = < your_valu e > 

 2.1 Create the Platform Service Account (Required) 

 Create a service account that Cortex will use as the primary identity for accessing your resources. 

 Ask Copy 

 gcloud iam service-accounts create < PLATFORM_SA_NAM E > \ 
 --display-name= " Cortex Platform Service Account " 

 Where <PLATFORM_SA_NAME> is your chosen service account ID (e.g., cortex-platform). 

 2.2 Grant predefined managed roles to the Platform Service Account (Required) 

 Module: Assets Discovery 

 Bind the following predefined roles to the platform service account: 

 Ask Copy 

 gcloud projects add-iam-policy-binding < PROJECT_I D > \ 
 --member= " serviceAccount:<PLATFORM_SA_NAME>@<PROJECT_ID>.iam.gserviceaccount.com " \ 
 --role= " roles/cloudfunctions.viewer " 

 gcloud projects add-iam-policy-binding < PROJECT_I D > \ 
 --member= " serviceAccount:<PLATFORM_SA_NAME>@<PROJECT_ID>.iam.gserviceaccount.com " \ 
 --role= " roles/container.clusterViewer " 

 gcloud projects add-iam-policy-binding < PROJECT_I D > \ 
 --member= " serviceAccount:<PLATFORM_SA_NAME>@<PROJECT_ID>.iam.gserviceaccount.com " \ 
 --role= " roles/storage.objectViewer " 

 gcloud projects add-iam-policy-binding < PROJECT_I D > \ 
 --member= " serviceAccount:<PLATFORM_SA_NAME>@<PROJECT_ID>.iam.gserviceaccount.com " \ 
 --role= " roles/firebaserules.viewer " 

 gcloud projects add-iam-policy-binding < PROJECT_I D > \ 
 --member= " serviceAccount:<PLATFORM_SA_NAME>@<PROJECT_ID>.iam.gserviceaccount.com " \ 
 --role= " roles/viewer " 

 Where: 

 <PLATFORM_SA_NAME> is the platform service account name 

 <PROJECT_ID> is the ID of the GCP project you are onboarding to Cortex 

 After running the last command, the following prompt is displayed: 

 Choose "None" by entering 2.
