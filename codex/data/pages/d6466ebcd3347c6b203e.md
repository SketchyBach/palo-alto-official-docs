 Issue ID 

 Description 

 PAN-119745 

 A security-related fix was made to address
the Netflix Linux kernel TCP SACK vulnerability ( PAN-SA-2019-0013 / CVE-2019-11477,CVE-2019-11478,CVE-2019-11479,
and CVE-2019-5599). 

 PAN-118869 

 A security-related fix was made to address
an issue where the php-debug log incorrectly displayed non-sanitized
data ( PAN-SA-2019-0019 / CVE-2019-1575). 

 PAN-107239 

 A security-related fix was made to address
cleartext passwords and keys that were visible in the logs for XML
API calls ( PAN-SA-2019-0019 / CVE-2019-1575).
