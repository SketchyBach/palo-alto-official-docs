 Tag Visibility 

 There are three types of tag visibility: 

 Private —Visible only to your organization (more
specifically, only to users associated with same support account
as tag author). 

 Public —Visible to all AutoFocus users. Public tag
details include the name of the organization that created the tag. 

 Public Anonymously —Visible to all AutoFocus users.
However, tags that are anonymously made public do not reveal the
organization name in the tag details. 

 For tags you create, you can set the visibility of the tag and
change it at any time. 

 Private tags and samples can be made public, with the option
to revert the tag or sample back to a private status at any time.
