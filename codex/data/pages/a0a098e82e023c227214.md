 *When you launch the VM-Series firewall corresponding to this plan, it automatically
 learns the underlying Azure VM's compute resources and unlocks itself to the right
 VM-Series model (VM-300, VM-500, or VM-700). 

 **You can launch the VM-Series firewall model corresponding to this plan on an Azure VM
 size that provides more resources than the minimum requirements. However, the firewall
 will not be able to take advantage of additional memory or CPU cores. If you launch the
 firewall model on an Azure VM size that does not meet the minimum requirements, the
 firewall will boot in maintenance mode. 

 VM-Series now offers support for Azure v6 instances, beginning with PAN-OS 12.1.2 and
 subsequent versions. The following are the recommended instance types. 

 When creating the VM, you must set the security type to Standard. Trusted Launch
 security type is not currently supported.
