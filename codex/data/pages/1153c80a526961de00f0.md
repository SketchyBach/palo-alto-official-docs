 dump software status 

 Use the dump software status command
to display the software status. Information displayed includes the
software id, which is a unique identifier of the software version
currently running on the device. 

 Command 

 dump software status

 Options 

 None 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands — 

 Introduced in Release 4.4.1 

 Example 

 dump software status
 CurrentVersion : 4.4.1-pre-b38
