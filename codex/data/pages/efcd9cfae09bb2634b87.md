 Additional DNS Proxy Actions 

 After configuring the firewall as a DNS Proxy, you can
perform the following actions on the Network DNS Proxy page to manage DNS
proxy configurations: 

 Modify —To modify a DNS proxy,
click into the name of the DNS proxy configuration. 

 Delete —Select a DNS proxy entry and
click Delete to remove the DNS proxy configuration. 

 Disable —To disable a DNS proxy, click
into the name of the DNS proxy entry and clear the Enable option.
To enable a DNS proxy that is disabled, click into the name of the
DNS proxy entry and select Enable .
