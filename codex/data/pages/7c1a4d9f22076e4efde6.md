 ATT&CK Technique 

 Phishing: Spearphishing Link (T1566.002), User Execution: Malicious File (T1204.002) 

 Severity 

 Informational 

 Description 

 The email contains unusual file-sharing link(s) for mailbox owner. 

 Attacker's Goals 

 Deliver malware or exfiltrate data via auto-download file-sharing links. 

 Investigative actions 

 Analyze the linked file(s) to determine if they pose any security risk. 

 Check the sender's communication history within the organization. 

 Analyze the file reputation using sandbox or threat intelligence sources. 

 Verify whether similar links were sent to other users.
