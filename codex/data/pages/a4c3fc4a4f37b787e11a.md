 Manage the HSM Deployment 

 View HSM configuration settings and detailed operations information, download support
 files, or remove HSM connections. 

 You can perform the following tasks to manage your HSM deployment: 

 View HSM configuration settings. 

 This view displays the HSM provider, firewall source address, HSM client
 version on the firewall, whether the master key is secured by the HSM, and
 if the firewall is connected and authenticated to the HSM. The fields that
 display vary based on the configured provider. 

 Select Device Setup HSM . 

 Display detailed HSM information. 

 This view displays information regarding the HSM servers, HSM high
 availability status, and HSM hardware. 

 Select Show Detailed Information from the Hardware
 Security Operations section. 

 Export the Support file. 

 A test file is created to help customer support when addressing a problem
 with an HSM configuration on the firewall. 

 Select Export Support File from the Hardware Security
 Operations section. 

 Reset the HSM configuration. 

 This option removes all HSM connections to the firewall. All authentication
 procedures must be repeated after resetting the HSM configuration. 

 Select Reset HSM Configuration from the Hardware
 Security Operations section.
