 Upgrade Broker VM 

 Upgrade Broker VM to the latest supported version. 

 Learn more about upgrading the Broker VM from the Cortex Cloud management console. 

 If your Broker VM was deployed using an image downloaded before February 22, 2026 (running Ubuntu 20.04 or earlier), you must reinstall the broker with a new image (running Debian 13 or later) before you can upgrade to the latest version. For more information, see Migrating to a New Broker VM Image . 

 Select Settings → Configurations → Data Broker → Broker VMs. 

 In either the Brokers or Clusters tab, locate your Broker VM, right-click, and select Upgrade Broker version. Upgrading your Broker VM takes approximately 5 minutes. 

 Important 

 After a Broker VM upgrade, your broker may require a reboot to finish installing important updates. A notification about this will be sent to your Cortex Cloud console Notification Center.
