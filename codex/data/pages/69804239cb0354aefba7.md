 getDatasetsManagement 

 getDatasetsManagement 

 Returns a list of datasets, optionally filtered by name. 

 Arguments 

 Argument Name 

 Description 

 Required 

 dataset_name 

 Filter to return only datasets whose name contains this value. If not provided, all datasets are returned. 

 Optional 

 limit 

 The maximum number of datasets to return. Ignored when 'all_results' is true. Default is 50. 

 Optional 

 all_results 

 Whether to return all results. When true, the 'limit' argument is ignored. Possible values are: true, false. Default is false. 

 Optional 

 Outputs 

 Core.Datasets.name string 

 The name of the dataset. 

 Core.Datasets.id number 

 The unique identifier of the dataset. 

 Core.Datasets.type string 

 The type of the dataset (e.g. SYSTEM, RAW). 

 Core.Datasets.is_active string 

 Whether the dataset is active. 

 Core.Datasets.is_visible string 

 Whether the dataset is visible. 

 Core.Datasets.data_tier string 

 The data tier of the dataset. 

 Core.Datasets.created_by string 

 The creator of the dataset. 

 Core.Datasets.created_at number 

 The creation timestamp (epoch milliseconds). 

 Core.Datasets.modified_at number 

 The last modification timestamp (epoch milliseconds).
