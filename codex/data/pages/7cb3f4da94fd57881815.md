 clear dhcprelay stat 

 Use the clear dhcprelay stat to
clear the DHCP relay statistics. A successful execution of the command
does not show any output. Failure in execution of the command displays
dhcprelay clear stat failed and it occurs if the DHCP relay is not
in operation. 

 Command 

 clear dhcprelay stat 

 Options 

 None 

 Command Notes 

 Role Super
