 Ports Used for Routing 

 Network ports and protocols used by PAN-OS firewalls for routing functions including BGP,
 OSPF, RIP, and other routing protocols. 

 The firewall and Panorama use the following ports for
routing functions. 

 Destination Port 

 Protocol 

 Description 

 179 

 TCP 

 Port used by BGP to connect to peers. 

 3784 

 3785 

 4784 

 UDP 

 Ports used by BGP to connect to peers. 

 520 

 UDP 

 Port used for RIPv2. 

 89 

 IP 

 Port used for OSPF and OSPFv3. 

 103 

 IP 

 Port used for Protocol Independent Multicast
(PIM). 

 639 

 TCP 

 Port used by MSDP to connect to peers.
