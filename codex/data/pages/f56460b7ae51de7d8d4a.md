 Using the Signing Key Inventory 

 Use the Signing Key inventory to view and manage your current Signing Keys. 

 From the inventory page, you can: 

 Create new Signing Keys 

 View all Signing Keys within your TSG 

 Open the details drawer for a Signing Key 

 Enable, renew, disable, or delete a Signing Key 

 The inventory includes robust filtering and view options to help you find and organize information. 

 Open the inventory by selecting Insights > Signing Keys . 

 Create New Signing Keys 

 The inventory page is the first stop when creating new Signing Keys. See creating new Signing Keys for more information. 

 Viewing Signing Keys 

 All Signing Keys in the inventory are shown within the context of your TSG. Users can view the Signing Keys within the TSGs they have access to. 

 Details Drawer 

 Select a Signing Key to open its details drawer, which slides out from the right side of the screen. The drawer shows information about the selected Signing Key while keeping the inventory visible on the left. 

 Information is organized into tabs. Review all tabs to see complete details. 

 Select X in the upper-right corner to close the drawer. 

 Column Menu 

 Select Columns at the top of the inventory to control which columns are visible. 

 For visible columns, hover over a column name to open a context menu (three stacked dots). Depending on the column type, you can: 

 Filter by this column to display Signing Keys that match specific criteria. 

 Sort the visible records by this column. 

 Pin a column to the right or left side to keep it visible while scrolling horizontally. 

 Manage or hide columns to customize the display. Column settings reset when you leave the page. 

 Searching and Filtering 

 If you manage many Signing Keys, use the Search box to find specific keys. You can search across multiple columns, including Name , ID , Status , and Last Modified By . 

 Select Filters to build complex queries across multiple columns. You can combine filters to refine results. 

 The filter menu lets you display only the Signing Keys that match the criteria you select in the Column , Operator , and Value fields. 

 Enable, Renew, Disable, or Delete a Signing Key 

 For any Signing Key, select the action button on the right side of the row to enable, disable, renew, or delete it. These same options are available from the Signing Key details drawer.
