 Monitor SaaS Policy Rule Recommendations 

 Learn how to monitor SaaS policy rule recommendations
on SaaS Security Inline. 

 Where Can I Use This? What Do I Need? 

 NGFW (Managed by Panorama or Strata Cloud Manager) 

 Prisma Access (Managed by Panorama or Strata Cloud Manager) 

 SaaS Security Inline license 

 NGFW or Prisma Access license 

 Or any of the following licenses that include the SaaS Security Inline license: 

 CASB-X 

 CASB-PA 

 Whether you create a new recommendation or update an active recommendation ,
the request displays a status: 

 Platform 

 Status 

 Prisma Access (Managed by Strata Cloud Manager) 

 When Prisma Access (Managed by Strata Cloud Manager) successfully detects the enabled 
 policy rule recommendation, Prisma Access (Managed by Strata Cloud Manager) indicates
 Synced ; otherwise, the policy rule
 status is blank. 

 NGFW (Managed by Panorama) 

 Prisma Access (Managed by Panorama) 

 When one or more NGFW or Panorama successfully receives the enabled 
 policy rule recommendation, the SaaS Security web interface
 indicates Synced ; otherwise, the policy
 rule status is blank. 

 The most common resolution to a policy rule recommendation that is for the NGFW 
 administrator or Prisma Access administrator to
 refresh/fetch the latest data because neither Panorama 
 nor the NGFW cache any policy recommendations.
 Synced does not mean that your NGFW administrator imported the recommendation as
 a rule and saved it to the rulebase. 

 Log in to 
 Strata Cloud Manager 

 Select Configuration SaaS Security Discovered Apps Policy Recommendations . 

 Observe the status icon in Synced column.
