# Sensitive Data Exfiltration Instruction

Sensitive Data Exfiltration Instruction

Severity

🟡 Medium (6)

Short Description

Flags AI extensions that instruct the agent to collect, transmit, or leak sensitive information — credentials, API keys, tokens, PII, or internal documents — to an external destination without a clear legitimate need or user consent.

Suggestion

There is rarely a legitimate reason for a component to ask the agent to send credentials or internal documents anywhere. Verify the destination and the business need; if either is missing, remove the component.

Information

This is the instruction form of Sensitive Data Exfiltration. A skill, command, subagent, or rule tells the agent to gather high-sensitivity material — credentials, API keys, tokens, personal data, or internal documents — and send it to an external destination.

The severity is lower than the executable variant because execution is not guaranteed — the agent may decline, and reading credential files or making outbound network calls often triggers a confirmation prompt. Those mitigations are behavioral rather than structural, which is what to check first: a component carrying both this finding and Safety Instruction Override is trying to remove the control that would otherwise stop it, and should be treated at the severity of the executable variant.

Risks

Credential exposure: If the agent complies, keys and tokens reach an external party in usable form.

Agent-mediated bypass: The agent's file access can reach material the component could not read on its own.

Weakened by co-occurring findings: A safety-override finding on the same component removes the confirmation step this relies on.

Consent gap: Users approving a file read may not realize its contents are being transmitted externally.

Recommended Actions

Investigate the component

Read the evidence to identify what data the agent is told to gather and where to send it.

Check for a co-occurring Safety Instruction Override finding.

Review agent activity logs for evidence that the instruction was actually followed.

Contain and remediate

Rotate any credentials the agent may have accessed while the component was active.

Block the destination endpoints and keep confirmation prompts enabled for credential file access.

Remove the component and report it to the marketplace.
