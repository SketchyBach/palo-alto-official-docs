 PAN-GLOBAL-TC-MIB.my 

 PAN-GLOBAL-TC-MIB.my defines conventions (for example,
character length and allowed characters) for the text values of
objects in Palo Alto Networks enterprise MIB modules. All Palo Alto
Networks products use these conventions. This MIB doesn’t contain
objects for you to monitor; it is required only for referencing
by other MIBs.
