 Prisma Access Summary Dashboard 

 The Strata Multitenant Cloud Manager offers a Prisma Access 
Summary screen that provides a quick look at the status of all your
 Prisma Access tenants. 

 Where Can I Use This? What Do I Need? 

 Strata Multitenant Cloud Manager 

 Prisma Access license or SASE bundle license 

 Identity & Access
 role : Multitenant Superuser or Superuser 

 If you activate a SASE license or a Prisma Access license for your tenant, the
 Prisma Access tab displays a high-level summarized status
 of all your Prisma Access tenants. You can view the
 status in multiple views. 

 Summary 

 Map View 

 Summary 

 The Summary tab displays information for the
 current region and tenant. Use Region to select and display
 information for another region. Use Tenant to select and
 display information for another tenant. 

 You can specify a Time range for displaying the summary
 information (default display is for the previous 7 days). 

 The Summary screen offers you the following widgets: 

 Widget 

 Description 

 Total Tenants 

 Displays the total number of tenants configured for the selected
 tenant. This number includes the current tenant plus all child
 tenants. 

 Also displays the total bandwidth allocated for all tenants and
 the number of users created for all tenants. 

 You can also Onboard a new tenant as a
 child of the currently displayed tenant. 

 Total Threats 

 Displays the total amount of threat traffic and the blocked
 threats seen for the selected tenant and its children during the
 reporting period. 

 View threat details to display the Threat
 monitoring page. 

 Total Applications 

 Displays the number of applications accessed by the selected
 tenant and its children, and if this number is trending up or
 down. Also displays both the total number of risky applications
 blocked and unblocked, and the trend for each. 

 View application usage details to display
 the Application monitoring page. 

 Top Tenants with Unblocked Threats 

 Displays the regions with the highest number of unblocked threats
 for the selected tenant and its children during the reporting
 period. Displays both the number of unblocked threats and the
 total number of threats per region. 

 View threat details to display the Threat
 monitoring page. 

 Top Tenants with Risky URLs 

 Displays the regions with the highest number of unblocked URLs
 and the number of risky URLs per region for the selected tenant
 and its children during the reporting period. 

 View URL details to display the Threat
 monitoring page. 

 Top Tenants using Risky Applications 

 Displays the regions using the highest number of risky
 applications and the number of risky apps for the selected
 tenant and its children during the reporting period. 

 View application usage details to display
 the Application monitoring page. 

 Total Network Alerts 

 Displays the total number of network alerts raised for the
 selected tenant and its children during the reporting period.
 Also displays the number of critical, high, and medium alerts as
 a percentage of the total number of alerts seen. 

 A network alert indicates that some aspect of the tenant's
 monitored network is unreachable or is non-functioning. 

 View alert details to display the Alerts
 monitoring page. 

 Network Alert Distribution 

 Displays the number of network alerts raised for the selected
 tenant and its children during the reporting period, distributed
 per license type. 

 View alert details to display the Alerts
 monitoring page. 

 Service Connectivity 

 Displays the network availability status for the selected tenant
 and its children during the reporting period. It is color coded
 to represent the number of sites that are up or down. 

 View alert details to display the Alerts
 monitoring page. 

 Network Inventory 

 Displays the total number of remote networks and
 the total number of mobile user gateways for the selected tenant
 and its children during the reporting period.

 View all tenants to display the
 Manage tenants and license information page. 

 Licenses Expiring in n days 

 Displays the number of licenses that will expire for the selected
 tenant and its children within the reporting period. 

 View current consumption to display the
 details for those licenses expiring within the reporting period.

 License Distribution 

 Displays the distribution of license types for the selected
 tenant and its children during the reporting period. Also
 displays the utilization type as a percentage of the total
 utilization. 

 Allocate licenses to tenants to display
 the details for those licenses expiring within the reporting
 period. 

 Capacity Management 

 Displays the license capacity for the selected tenant and its
 children during the reporting period; displays both the capacity
 available out of the total. 

 View license details to display the
 details for those licenses expiring within the reporting period.

 Map View 

 The Map View tab displays information for the
 current Strata Logging Service region and tenant. Use Strata Logging Service 
 Region to select and display information for another region. Use
 Tenant to select and display information for another
 tenant. 

 The Map View screen offers you the following widgets: 

 Widget 

 Description 

 Total Tenants 

 Displays the total number of tenants configured for the selected
 tenant. This number includes the current tenant plus all child
 tenants. 

 Total Allocated Users 

 Displays the total number of allocated users in a Strata Logging Service region for
 the selected tenant. 

 Total Allocated Bandwidth 

 Displays the total amount of allocated bandwidth in a Strata Logging Service region
 for the selected tenant. 

 Deployments 

 Displays the number of total instances, total sites down, and
 total sites up for the following services. Hover over a location
 on the map to view the metrics for that location. 

 Remote networks sites (RN) 

 Mobile users (MU) 

 Service connections (SC) 

 Select a location on the map to view the following metrics. 

 Total tenants per compute location 

 Number of MU users at a location 

 View Details as a shortcut to monitor service
 connectivity . 

 Security 

 Displays the amount of total threats, unblocked threats, and
 blocked threats per each compute location. Hover over a location
 on the map to view the metrics for that location. 

 Select a location on the map to view the following metrics. 

 Tenants 
 Total tenants with deployments 

 Total sites 

 Total users

 monitor
 tenant threats . 

 Threat insight 
 Total threats 

 Total blocked threats 

 Total unblocked threats 

 Threat distribution by type 

 View Details as a shortcut to
 monitor
 tenant threats . 

 Top risky users
