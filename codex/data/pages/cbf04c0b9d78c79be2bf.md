 Traps Agent 5.0 for Mac 

 Uninstall the Traps Agent for Mac 

 From the Traps management service you can uninstall the Traps agent on an endpoint. You can also uninstall the agent from the endpoint directly. On Mac endpoints, you can use the Mac installation program (in this case, the Traps Installer) to uninstall a program. After you uninstall the agent, the endpoint is no longer protected by your company’s security policies and the license returns to the pool of available licenses. 

 Run the Traps installer to uninstall the Traps agent. 

 Click OK through any prompts.
