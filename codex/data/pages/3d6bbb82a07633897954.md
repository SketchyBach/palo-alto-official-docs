 Monitor the PagerDuty Notifier CloudBlade Integration 

 View to monitor, manage and troubleshoot PagerDuty incidents in Prisma
 SD-WAN. 

 Where Can I Use This? What Do I Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 PagerDuty Notifier CloudBlade 

 To monitor the status of events, go to Configuration Prisma SD-WAN CloudBlades PagerDuty Notifier and select Monitor . 

 The General Information tab provides a summary of the
 following options: 

 Option Description 

 Cloud Blade Enabled? If the Cloud Blade is enabled in Prisma SD-WAN. 

 Last Error Reported by Cloud Blade Most recent error message from the CloudBlade, if any. This indicates
 the error seen in the last attempt only. 

 Time Taken (seconds) Total time taken by the CloudBlade to forward incidents from SD-WAN
 to PagerDuty. Higher values may indicate excessive data volume or API
 slowness. 

 Number of PagerDuty Service Directories Reported Total number of PagerDuty service directories retrieved from
 PagerDuty. 

 Number of PagerDuty Priorities Reported Total number of priorities (e.g., critical, high, low) retrieved from
 PagerDuty. 

 Number of PagerDuty Service Services Configured Number of PagerDuty services specifically configured for this
 integration. 

 Number of Service Directories Matched Count of service directories successfully matched between PagerDuty
 and CloudBlade. 

 Number of Unique SDWAN Event Codes Monitored Total number of Prisma SD-WAN event codes monitored. 

 Number of SDWAN Sites Blocked Number of Prisma SD-WAN sites blocked by the pd_block 
 tag. 

 Number of SDWAN Devices Blocked Number of Prisma SD-WAN devices currently blocked by the
 pd_block tag. 

 The SD-WAN Events Code Summary tab details the status of
 specific SD-WAN event codes as they relate to PagerDuty incidents. 

 Options Description 

 Code Monitored Prisma SD-WAN event code. 

 First PagerDuty Incident Date and time the first PagerDuty incident triggered for a specific
 event code. 

 Recent PagerDuty Incident Date and time of the most recent PagerDuty incident for the event
 code. 

 PD Incidents Computed Total number of PagerDuty incidents computed for this event
 code. 

 PD Incidents Created Total number of PagerDuty incidents created for this event
 code. 

 PD Incidents An incident represents a problem or an issue that needs to be
 addressed and resolved. 

 The SD-WAN Event Codes Frequency tab breaks down how often
 specific Prisma SD-WAN event codes occur over different time intervals. The table
 displays a cumulative count of incidents for each event code across time frames
 ranging from minutes to several days. This view helps you identify which event codes
 occur most frequently and when the incidents happen. 

 The CloudBlade Events tab provides a detailed activity log
 for the PagerDuty Notifier. It displays internal events in chronological order,
 including the event code, time, severity level, and description. The log also
 indicates whether resolution is required and provides context for monitoring and
 troubleshooting. The CloudBlade retains only the most recent 1,000 events at any
 time. 

 The PagerDuty Incidents tab provides a detailed log of all
 incidents generated by the PagerDuty Notifier. It serves as an audit trail, showing
 each incident’s unique ID, associated PagerDuty service, creation time, triggering
 event type, resolution status, and resolution timestamp. 

 The SDWAN Event Codes Summary tab provides a high-level
 summary of Prisma SD-WAN events, with columns for the Event ID, Event Code, Service
 ID, and Status.
