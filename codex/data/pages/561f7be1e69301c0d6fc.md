 Mobile Password Saving 

 Mobile Password saving control 

 Prisma Browser Desktop Prisma Browser Extension Prisma Browser for Mobile 

 No support No support Full support 

This feature determines whether the browser will be able to save passwords for
 websites. 

 From Strata Cloud Manager , select Configuration Policy Control Sets Browser Security Passwords and Autofill 

 Select Password Saving . 

 Select one of the following options: 

 Allow - Users will be able to save passwords in the
 browser. 

 Block - Users will be restricted to save passwords in the
 browser. 

 Click Set .
