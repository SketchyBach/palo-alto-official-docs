 listIssues 

 Returns a list of issues and their metadata, filtered by built-in arguments or by a JSON filter object supplied via filter_object/custom_filter. Multiple filter arguments are concatenated using the AND operator, while arguments that support a comma-separated list of values use an OR operator between each value. Returned list issues if no arguments are provided. 

 Arguments 

 Argument Name 

 Description 

 Required 

 issue_ids 

 A comma-separated list of unique issue IDs. 

 Optional 

 severity 

 A comma-separated list of issue severities. Possible values are: low, medium, high, critical. 

 Optional 

 filter_object 

 A JSON string representing a raw filter object. If provided, this overrides all other filter arguments. 

 Optional

 A custom filter. When this argument is used, the other filter arguments are not relevant.

 updateIssue 

 Updates the properties of an issue. This command does not provide an explicit indication of success. 

 Arguments 

 Argument Name 

 Description 

 Required 

 id 

 Issue ID to update. 

 Required 

 assigned_user_mail 

 Email address of the user to assign the issue to. 

 Optional 

 severity 

 Change the severity of an issue. Possible values are: low, medium, high, critical. 

 Optional 

 name 

 Change the issue name. 

 Optional 

 occurred 

 Change the occurred time of an issue. Supports different time formats, for example: 3 days ago, 2017-09-27T10:00:00+03:00. 

 Optional 

 phase 

 Change the phase of an issue. Possible values are: Triage, Investigation, Containment, Response. 

 Optional 

 type 

 Change the type of an issue. 

 Optional 

 description 

 Change the description of an issue. 

 Optional 

 status 

 Change the status of an issue. Possible values are: New, In Progress, Resolved - Known Issue, Resolved - Duplicate Issue, Resolved - False Positive, Resolved - other, Resolved - True Positive, Resolved - Security Testing, Resolved - Dismissed, Resolved - Fixed, Resolved - Risk Accepted. 

 Optional 

 link_cases 

 A comma-separated list of case IDs to link the issue to. 

 Optional 

 unlink_cases 

 A comma-separated list of case IDs to unlink the issue from. 

 Optional 

 Outputs 

 There are no outputs for this command.

 getRawAlerts 

 Returns the full original alert data that caused the creation of the specified issues.

 Arguments 

 Argument Name 

 Description 

 Required 

 issue_ids 

 A comma-separated list of issue IDs to retrieve the original alerts for. 

 Required 

 events_from_decider_format 

 Whether to return the events_from_decider context output as a dictionary (the raw API response) or as a list (improved for playbook automation). Possible values are: list, dict. Default is dict. 

 Optional 

 dynamic_analysis 

 Whether to additionally return the dynamic analysis of each issue under Core.DynamicAnalysis, alongside the original alert data under Core.OriginalAlert. Possible values are: true, false. Default is false. 

 Optional 

 Outputs 

 Core.OriginalAlert.internal_id unknown 

 The internal ID of the alert.

 getHealthIssues 

 Returns a list of tenant health issues based on the provided filter criteria.

 Arguments 

 Argument Name 

 Description 

 Required 

 severity 

 A comma-separated list of severity levels to filter by. Possible values are: info, low, medium, high, critical, unknown. 

 Optional 

 type 

 A comma-separated list of issue types to filter by. Possible values are: Ingestion, Collection, Parsing, Event Forwarding, Correlation, Permissions, Discovery, Registry, Agentless Disk Scanning, Data Security Scanning, Automation. 

 Optional 

 time_frame 

 Returns health issues whose insert timestamp is greater than or equal to this value. Accepts a relative value (e.g. "7 days ago"), an absolute ISO date (e.g. "2024-01-01T00:00:00Z"), or epoch milliseconds. Default is 7 days ago. 

 Optional 

 filter_object 

 A JSON string representing a raw filter object. If provided, this overrides all other filter arguments. 

 Optional 

 limit 

 The maximum number of health issues to return. Default is 50. 

 Optional 

 page_size 

 The number of health issues to return per page. When set, manual pagination is used and limit is ignored. 

 Optional 

 page 

 The page number to return, starting from zero. When set, manual pagination is used and limit is ignored. 

 Optional 

 Outputs 

 Core.HealthIssue.issue_name string 

 The name of the health issue. 

 Core.HealthIssue.timestamp number 

 The time the health issue was inserted (epoch milliseconds).
