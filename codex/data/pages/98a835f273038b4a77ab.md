 Set Commands Introduced in PAN-OS 11.1 

 Command line interface 'set' commands that are new in PAN-OS 11.1. 

 Where Can I Use This? What Do I Need? 

 NGFW (Managed by PAN-OS or Panorama) 

 No prerequisites needed 

 The following commands are new in the 11.1 release: 

 set deviceconfig setting ctd decode-filter-max-depth <1-7>
set network interface ethernet <name> layer3 ipv6 dhcp-client v6-options duid-type <duid-type-llt|duid-type-ll>
set network interface ethernet <name> layer3 units <name> ipv6 dhcp-client v6-options duid-type <duid-type-llt|duid-type-ll>
set network interface ethernet <name> layer3 units <name> pppoe
set network interface ethernet <name> layer3 units <name> pppoe enable <yes|no>
set network interface ethernet <name> layer3 units <name> pppoe authentication <CHAP|PAP|auto>
set network interface ethernet <name> layer3 units <name> pppoe static-address
set network interface ethernet <name> layer3 units <name> pppoe static-address ip <value>
set network interface ethernet <name> layer3 units <name> pppoe username <value>
set network interface ethernet <name> layer3 units <name> pppoe password <value>
set network interface ethernet <name> layer3 units <name> pppoe create-default-route <yes|no>
set network interface ethernet <name> layer3 units <name> pppoe default-route-metric <1-65535>
set network interface ethernet <name> layer3 units <name> pppoe access-concentrator <value>
set network interface ethernet <name> layer3 units <name> pppoe service <value>
set network interface ethernet <name> layer3 units <name> pppoe passive
set network interface ethernet <name> layer3 units <name> pppoe passive enable <yes|no>
set network interface aggregate-ethernet <name> layer3 ipv6 dhcp-client v6-options duid-type <duid-type-llt|duid-type-ll>
set network interface aggregate-ethernet <name> layer3 units <name> ipv6 dhcp-client v6-options duid-type <duid-type-llt|duid-type-ll>
set network interface vlan ipv6 dhcp-client v6-options duid-type <duid-type-llt|duid-type-ll>
set network interface vlan units <name> ipv6 dhcp-client v6-options duid-type <duid-type-llt|duid-type-ll>
set network logical-router <name> vrf <name> multicast pim rp local-rp static-rp group-list <value>|<validate>|<None>
set network logical-router <name> vrf <name> multicast pim rp local-rp candidate-rp group-list <value>|<validate>|<None>
set network logical-router <name> vrf <name> multicast pim rp external-rp <name> group-list <value>|<validate>|<None>
