 Device > Cloud Redistribution > Receiving 

 Configure the firewall to collect user or device context from other firewalls through
 the cloud. 

 Add a Receiving entry to define the data type your firewall
 receives and the segments from which it receives that data type. 

 Receiving Settings Description 

 Data Type 

 Choose the type of data to receive from the cloud: 

 HIP Report —Host Information Profile (HIP)
 data collected from GlobalProtect endpoints. 

 IP Port —IP address-to-port-to-username
 mappings 

 IP Tag —IP address-to-tag mappings 

 IP User —IP address-to-username
 mappings 

 Quarantine List —List of potentially
 compromised or non-compliant devices 

 User Tag —Username-to-tag mappings 

 Description Enter a description for the receiving entry (up to 63
 characters). 

 Enable Cloud Redistribution Enables this entry for cloud redistribution. 

 Enable Receiving Enables the firewall to receive (download) this data type
 from the cloud. 

 Segment 

 Add a segment Name and
 segment ID to identify the segment through
 which the firewall receives the selected data type. To remove a
 segment entry, select it and click
 Delete .
