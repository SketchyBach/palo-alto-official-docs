 Notification Server Configurations 

 Reference notification server configurations in Cortex XSOAR 6.12. 

 Key 

 Description 

 Default 

 content.notification.enabled 

 Set to true to enable notification for new content updates. 

 false 

 content.notification.users 

 Notifies all users by email when there is a content update available (comma separated user names in Cortex XSOAR). 

 N/a 

 message.ignore.failedFetchIncidents 

 Whether to ignore failed fetch incident messages. For more information, see Receive Notification on an Incident Fetch Error . 

 false 

 message.ignore.incidentChanged 

 Whether to disable notifications when an incident is changed. 

 false 

 message.ignore.incidentStatusChanged 

 Whether to disable notifications when an incident status is changed. 

 false 

 message.ignore.incidentOpened 

 Whether to disable notifications, when an incident is opened. 

 false 

 message.ignore.incidentAssigned 

 Whether to disable notifications when an incident is assigned. 

 false 

 message.ignore.investigationClosed 

 Whether to disable notifications when an incident is closed. 

 false 

 message.ignore.assign 

 Whether to disable notifications when a to do task is assigned to you. 

 false 

 message.ignore.mentionNew 

 Whether to disable notifications when a user is mentioned (@username), if the user is not already part of the incident. 

 false 

 message.ignore.mentionOld 

 Whether to disable notifications when a user is mentioned (@username), if the user is already part of the incident. 

 false 

 Messages.Formats.MessageType 

 Changes the email body when using plain text. For more information, see Change the Email Subject . 

 N/a 

 Messages.HTML.Formats.MessageType 

 Changes the email body when using HTML. For more information, see Change the Email Subject . 

 N/a 

 Messages.Subject.Formats.assign 

 Changes the subject of an email when assigned an incident in the format, {{.username}} added you to investigation {{.invName}}.\nPlease log in and review . For more information, see Change the Email Subject . 

 N/a 

 Messages.Subject.Formats.TaskCompleted 

 Changes the subject of an email when a task is completed. For more information, see Change the Email Subject . 

 N/a 

 module.health.notification.time.format 

 The date format for the notifications sent when the percentage of indicators fetched limit is reached, as defined in create.indicators.limit.by.total.amount.warning.percentage server configuration. 

 The default format is: (UnixDate = Mon Jan _2 15:04:05 MST 2022 ) 

 module.health.notification.users 

 List of names in CSV format. For example, user1,user2,user3 . For more information, see Receive Notification on an Incident Fetch Error . 

 N/a 

 server.notification.using.send-mail 

 Select which email sender should send the notification. For more information, see Configure System Notifications . 

 N/a
