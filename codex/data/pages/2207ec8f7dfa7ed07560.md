 Priority Alerts 

 Learn about priority alerts that require an Prisma Access license. 

 Where can I use this? What do I need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 Prisma Access license 

 Strata Cloud Manager uses the Unified Incident Framework to
 centralize incident management and provide a more contextual experience. The
 product-specific alerts and incidents are now located under Incidents . The previous Alerts & Incidents
 dashboard remains available in read-only mode for reference. 

 Priority Alerts describe the status of your Prisma Access environment, especially if
 something isn't working as expected. When Prisma Access generates an incident, it
 also generates a correlated alert, and it notifies you after it resolves the alert. Some
 alerts let you know about issues that the Prisma Access team is working on; others
 let you know about issues that you can resolve with a configuration update. 

 To view data about priority alerts in Strata Cloud Manager , select Incidents & Alerts Prisma Access Incidents & Alerts Priority Alerts . 

 The section lists priority alerts , which require a Prisma Access license.
