 Features Introduced in 2023 

 January 2023 

 This section describes the main features of the Cortex XSOAR 8.1 release. 

 Release Highlights 

 XSOAR 8 is redesigned to deliver improved performance and reliability, and is now highly scalable, based on revamped architecture. While based on Cortex XSOAR 6x, there are small changes from that version, which is detailed in title_title . 

 This is a SaaS-only release. For more information about XSOAR 8, see Cortex XSOAR 8 FAQs . 

 This section describes the new features of the Cortex XSOAR 8.1. 

 Integration into the Cortex platform: 

 Unified look and feel 

 Uses the platform's storage engines 

 Simplified deployment and onboarding 

 Consistent user management 

 Improved performance and reliability 

 High scalability based on revamped architecture that utilizes cloud features 

 Built-in Git Repository for sharing data between development and production instances 

 Feature Enhancements 

 XSOAR 8.1 also includes the following new features that were also part of the v6.10 release: 

 Communication task links in context data 

 Quiet Mode for manual tasks 

 Improved handling of grid fields
