 Install ION 3000 

 Install the ION 3000 with an existing router or by replacing
the existing router. Weigh your options and then decide how you
want to install the ION 3000. 

 The Prisma
SD-WAN ION 
3000 can be installed in two different modes—in analytics or control
mode with an existing router or in the control mode by replacing
the router. By installing the ION with an existing router, you can
physically insert the ION 3000 into a network, thereby reducing
interruption and insertion planning to a minimum. Or you can install
the ION 3000 to replace an existing router, especially in environments where
routers are not already present or required.
