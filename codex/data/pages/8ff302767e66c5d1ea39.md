 Re-allocate Devices Through the Strata Multitenant Cloud Manager 

 Learn about re-allocating a device through the Strata Multitenant Cloud Manager . 

 If you activate a SASE license or a Prisma SD-WAN license for your tenant,
 the Strata Multitenant Cloud Manager enables you to manage devices . 

 To
re-allocate a device, complete the following steps. 

 Select Manage Devices . 

 In Devices by Region , multiple regions
are listed where the you can manage your client tenant devices. 

 Select the region from where the device needs to be allocated
to the client tenant. 

 (Optional) Use the filters or Search to
refine your results. 

 Select the device state To Return from
the State drop-down. 

 The device must be marked To Return by
the client tenant for the MSP to re-allocate the device. 

 Re-allocate the device to a client
tenant. 

 Select the device from the list and click Re-allocate from
the ellipsis menu. 

 From the Re-allocate Device window,
select a Tenant available to the MSP. 

 Confirm to Re-allocate the
device. 

 The re-allocated device is now listed in the client tenant’s
inventory in an Unclaimed state.
