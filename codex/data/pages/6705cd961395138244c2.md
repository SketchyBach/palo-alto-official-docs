 Supported Apps 

 Web apps that Enterprise Data Loss Prevention (E-DLP) can inspect, with inspection types, direction,
 file size limits, and minimum version requirements. 

 The following table lists the web apps and operational parameters supported
 by Enterprise Data Loss Prevention (E-DLP) . Check the Supported File Types to see which file
 types Enterprise DLP can inspect across all apps. You can also look up individual
 apps in the Palo Alto Networks Applipedia . 

 Some apps require a Minimum Version Requirement , a minimum PAN-OS version or Apps & Threats content release version. Some apps
 require App-ID Cloud Engine (ACE) for App-ID identification. 

 Non-File Inspection requires PAN-OS 10.2.3 or later. 

 Max File Size larger than 20 MB requires PAN-OS 10.2.4 or
 later (10.2 release), or PAN-OS 11.0.2 or later. 

 Download Direction requires PAN-OS 10.2.4 or later (10.2
 release), or PAN-OS 11.0.2 or later. 

 To upgrade Panorama or Strata Cloud Manager : 

 For Panorama , upgrade 
 Panorama and managed firewalls to the Minimum
 Version Requirement or later. 

 For Prisma Access (Managed by Panorama) , upgrade Panorama to the
 Minimum Version Requirement and ensure
 your Prisma Access 
 tenants run the
 Minimum Version Requirement or
 later. 

 For Strata Cloud Manager , complete a PAN-OS software upgrade 
 in the Strata Cloud Manager infrastructure to the
 Minimum Version Requirement or later.
 You can view the Software Version in
 the Strata Cloud Manager 
 Overview . 

 Review the Compatibility Matrix for
 minimum plugin versions required for your target upgrade. 

 To use Gmail, disable the Quick UDP Internet Connection (QUIC) protocol in
 Chrome. Specify chrome://flags/ in the Chrome
 Experimental QUIC Protocol , and select
 Disabled .
