 Onboard a Crowdin Enterprise App to SSPM 

 Connect a Crowdin Enterprise instance to SSPM to detect posture risks. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 SaaS Security Posture Management license 

 Or any of the following licenses that include the Data Security license: 

 CASB-X 

 CASB-PA 

 For SSPM to detect posture risks in your Crowdin Enterprise instance, you must onboard your Crowdin Enterprise
 instance to SSPM. Through the onboarding process, SSPM logs in to Crowdin Enterprise using
 administrator account credentials. SSPM uses this account to scan your Crowdin Enterprise
 instance for misconfigured settings. If there are misconfigured settings, SSPM
 suggests a remediation action based on best practices. 

 SSPM gets access to your Crowdin Enterprise instance by using Okta SSO credentials that you provide during the
 onboarding process. For this reason, your organization must be using Okta as an
 identity provider. The Okta account must be configured for multi-factor
 authentication (MFA) using one-time passcodes. 

 To onboard your Crowdin Enterprise instance, you complete the following actions: 

 Collect Information for Accessing Your Crowdin Enterprise Instance 

 Connect SSPM to Your Crowdin Enterprise Instance 

 Collect Information for Accessing Your Crowdin Enterprise Instance 

 To access your Crowdin Enterprise instance, SSPM requires the following information, which you
 will specify during the onboarding process. 

 Item Description 

 User An email address of an Okta user account.

 Required Permissions: The user must be a Crowdin Enterprise
 administrator. 

 Password The password for the Okta user account. 

 Okta Domain The Okta subdomain for your organization. The
 subdomain was included in the login URL that Okta assigned to
 your organization. 

 MFA Secret Key A key that is used to generate one-time passcodes
 for multi-factor authentication. 

 Organization Domain The custom domain for accessing the Crowdin
 Enterprise instance. You specify this domain when you log in to
 Crowdin Enterprise, and it is included as part of the URL after
 you log in. 

 As you complete the following steps, make note of the values of the items
 described in the preceding table. You will need to enter these values during
 onboarding to access your Crowdin Enterprise instance from SSPM. 

 Identify the Okta user account that SSPM will use to access your Crowdin Enterprise
 instance. The user account must have administrator privileges in Crowdin Enterprise. SSPM
 needs this administrator access to monitor your Crowdin Enterprise instance. 

 Remember which account you will use to access your Crowdin Enterprise instance
 through Okta SSO authentication from SSPM. You will provide the
 login credentials to SSPM during the onboarding process. 

 To access the administrator account using Okta
 credentials : 

 Identify your Okta
 subdomain . 

 Generate and copy an MFA
 secret key . 

 Make note of your Crowdin Enterprise organization domain. 
 You specify this domain when you log in to Crowdin Enterprise. After you
 log in to Crowdin Enterprise, the organization domain is a unique subdomain
 included in the Crowdin Enterprise URL. The URL format is
 <subdomain> .crowdin.com. 

 Connect SSPM to Your Crowdin Enterprise Instance 

 By adding a Crowdin Enterprise app in SSPM, you enable SSPM to connect to your
 Crowdin Enterprise instance. 

 Log in to 
 Strata Cloud Manager . 

 Select Configuration SaaS Security Posture Security Applications Add Application and click the Crowdin Enterprise tile. 

 Under posture security instances, Add Instance or,
 if there is already an instance configured, Add New 
 instance. 

 Enter the user credentials, Okta domain, MFA secret key, and organization
 domain for accessing your Crowdin Enterprise instance, and
 Connect .
