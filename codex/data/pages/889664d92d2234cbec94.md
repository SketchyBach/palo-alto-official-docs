 API Use Policy 

 Cortex Xpanse API Use Policy. 

 The Cortex Xpanse Expander API provides customers with flexibility in how they use, consume, and store the data Cortex Xpanse makes available to them. In order to maintain consistency of the API’s performance across Cortex Xpanse’s customer base, we reserve the right to rate limit a customer’s API calls and throughput. If you have any concerns about API performance or you require additional bandwidth, contact your Customer Success Manager.
