 XDR Collectors 1.5.1 (Major) 

 Aug 13, 2025 Release 

 The following table describes the changes integrated on the XDR Collectors major release for Windows 1.5.1.2048 and Linux 1.5.1.1950 that was released as part of the release of Cortex XSIAM 3.2 on Aug 13, 2025. This version replaces the previous version released on July 29, 2025 as the major version for the release. 

 FEATURE/ISSUE 

 DESCRIPTION 

 CPATR-32150 

 An issue where after upgrading the XDRC Collectors caused connection failures when a proxy configuration was in use is now fixed. 

 July 29, 2025 Release 

 The XDR Collectors major release for Windows 1.5.1.2019 and Linux 1.5.1.1919 was released as part of the release of Cortex XSIAM 3.2 on July 29, 2025. 

 The following table describes the changes integrated for this release: 

 FEATURE/ISSUE 

 DESCRIPTION 

 CPATR-29911 

 An issue where the XDR Collectors service failed to start after an upgrade or clean install is now fixed. 

 CPATR-29958, CPATR-30504 

 Cortex XSIAM has upgraded the XDR Collectors to use Linux Python 3.13.1 and Windows Python 3.12.11 on 32-bit or 64-bit. 

 CPATR-30309 

 Cortex XSIAM has upgraded the XDR Collectors Windows VC Runtime from version 14.16.27033.0 to 14.42.34438.0. 

 CPATR-31148, XSUP-52026 

 An issue where the XDR Collectors sent a wrong upgrade failed message when no upgrade action was initiated is now fixed.
