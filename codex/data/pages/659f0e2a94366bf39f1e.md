 Unmaintained MCP Server is detected in IDE 

 Rule Details 

 Cortex AppSec Rule ID 

 APPSEC_CICD_373 

 Category - Subcategory 

 Pipeline Configuration - 3rd Party Services 

 Severity 

 HIGH 

 Impact 

 An MCP Server configured in a developer's IDE has not received updates or security patches for more than 180 days. Unmaintained software is vulnerable to known exploits and may contain unpatched CVEs.
