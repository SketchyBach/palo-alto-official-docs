 Terraform workflow for Compliance assessments 

 Automate recurring compliance audits for your Infrastructure-as-Code (IaC) repositories and CI/CD assets. As new Asset Groups are provisioned, Terraform automatically schedules audits and configures report distribution. 

 Prerequisites : Requires an existing Asset Group ID and the target Compliance Standard ID 

 Configuration : Use the cortexcloud_compliance_assessment_profile resource 

 How it works : You define the target standard, the assets to scan, and the automated reporting schedule using standard Cron syntax. 

 For more information, refer to Manage resources .
