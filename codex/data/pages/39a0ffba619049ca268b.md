 Hotfix Release - August 25, 2024 

 The table below lists the bug fixes and enhancements in the August 25, 2024 hotfix release. 

 Issue or Enhancement 

 Issue Type 

 Description 

 XPSUPPORT-2942 

 Bug Fix 

 Fixed a bug that resulted in some services not being discovered for Azure endpoints. 

 XPSUPPORT-2915 

 Bug Fix 

 Fixed a bug that impacted performance of the Get All Owned IP Ranges API endpoint when using next_page_token. 

 XPSUPPORT-2659 

 Bug Fix 

 Fixed the has_bu_overrides filter on the Get All Owned IP Ranges API endpoint. 

 EXPANDR-10694 

 Bug Fix 

 Fixed a bug that caused a discrepancy between alert counts displayed in the Open Attack Surface Alerts by Type widget and the number of alerts displayed when you click the hyperlink in the widget. 

 EXPANDR-10318 

 Bug Fix 

 Fixed a bug that created an incorrect overall value in the Mean Time to Resolution widget. 

 EXPANDR-9936 

 Bug Fix 

 Fixed a bug that caused the Potential Violations by BU dashboard to not load. 

 EXPANDR-9308 

 Bug Fix 

 Fixed a bug that caused ASM Overview Reports to fail to generate. 

 EXPANDR-8307 

 Bug Fix 

 Corrected a typo that appeared in the Asset Attribution Evidence for Prisma Cloud Resources. 

 EXPANDR-6903 

 Enhancement 

 Monthly and Quarterly Premium Customer Success Reports were renamed Monthy ASM Overview and Quarterly ASM Overview.
