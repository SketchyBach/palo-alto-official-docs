 getBIOCRules 

 Returns a list of BIOC rules based on the provided filter criteria. 

 Arguments 

 Argument Name 

 Description 

 Required 

 rule_id 

 The ID of the BIOC rule to filter by. 

 Optional 

 name 

 The name of the BIOC rule to filter by. Supports partial matching. 

 Optional 

 indicator 

 The indicator text of the BIOC rule to filter by. Supports partial matching. 

 Optional 

 severity 

 The severity level. Supports predefined values or the 'SEV_XXX_NAME' format (e.g., SEV_050_CRITICAL). Possible values are: info, low, medium, high, critical, unknown. 

 Optional 

 type 

 The category type of the BIOC rule. Possible values are: Collection, Credential Access, Discovery, Dropper, Evasion, Execution, Exfiltration, File Privilege Manipulation, File Type Obfuscation, Infiltration, Lateral Movement, Other, Persistence, Privilege Escalation, Reconnaissance, Tampering. 

 Optional 

 status 

 The status of the BIOC rule. Possible values are: Enabled, Disabled, Detection Disabled, Prevention Disabled. 

 Optional 

 is_xql 

 Whether the BIOC rule uses XQL. Possible values are: true, false. 

 Optional 

 comment 

 The comment on the BIOC rule to filter by. Supports partial matching. 

 Optional 

 status 

 The status of the BIOC rule. 

 Optional 

 mitre_technique_id_and_name 

 The MITRE technique ID and name to filter by. Supports partial matching. 

 Optional 

 mitre_tactic_id_and_name 

 The MITRE tactic ID and name to filter by. Supports partial matching. 

 Optional 

 filter_json 

 A JSON-encoded filter object to append additional filter conditions.

Example: [{"field":"rule_id","operator":"EQ","value":1}]. 

 Optional 

 filter_object 

 A JSON-encoded webapp filter object. When provided, overrides all other filter arguments.

Example: {"AND":[{"SEARCH_FIELD":"RULE_NAME","SEARCH_TYPE":"CONTAINS","SEARCH_VALUE":"test"}]}. 

 extra_data 

 Whether to include extra data in the response. Possible values are: true, false. 

 Optional 

 limit 

 The maximum number of results to return. Ignored when 'page' or 'page_size' is provided. Default is 50. 

 Optional 

 page_size 

 The number of results to return per page. When provided, manual pagination is used and 'limit' is ignored. 

 Optional 

 page 

 The page number to retrieve (0-based). When provided, manual pagination is used and 'limit' is ignored. 

 Optional

 Required

 Required 

 is_xql 

 Whether the BIOC rule uses XQL. Possible values are: true, false. 

 Optional

 A comment for the BIOC rule. 

 Optional 

 status 

 The status of the BIOC rule. 

 Optional 

 indicator 

 The indicator pattern of the BIOC rule. 

 Required 

 mitre_technique_id_and_name 

 The MITRE technique ID and name.

 The MITRE tactic ID and name.
