 User Identification 

 User Identification (User-ID™) is a Palo Alto Networks®
next-generation firewall feature that seamlessly integrates with
a range of enterprise directory and terminal services to tie application
activity and policies to usernames and groups instead of just IP
addresses. Configuring User-ID enables the Application Command Center
(ACC), App Scope, reports, and logs to include usernames in addition
to user IP addresses.
