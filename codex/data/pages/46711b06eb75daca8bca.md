 Deploy the Prisma Agent 

 Learn how to deploy Prisma Agents to secure the endpoints in your mobile
 workforce. 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager)

 Check the prerequisites for the deployment you're
 using 

 Contact your Palo Alto Networks account representative to activate the Prisma Agent feature 

 After you configured the Prisma Agent , you can download and deploy the Prisma Agent to a large number of endpoints using third-party mobile device
 management (MDM) software. Your end users can benefit by having the Prisma Agent installed automatically on their devices. 

 After the Prisma Agent is deployed to an endpoint for the first time,
 users must log in to the agent to complete their initial enrollment. The agent does
 not automatically connect to Prisma Access on first installation, even when Always
 On mode is configured. After this first login, Always On mode takes effect and the
 agent connects automatically on subsequent device logins. 

 If you require your users to access your organization's network and resources based
 on the projects that they are assigned to, see configure the Prisma Agent for Dynamic
 Privilege Access .
