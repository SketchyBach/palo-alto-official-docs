 In addition to coordinating with Palo Alto Networks next-generation firewalls,
 Device Security supports bidirectional integrations with many third-party systems.
 Device Security gathers device data, network data, security posture, and
 vulnerability information from third-party systems to enrich its own inventory and
 capabilities. At the same time, Device Security shares information back to those systems,
 augmenting their databases and services with contextual awareness of all device types,
 including IoT, OT, Medical IoT, and IT devices. Device Security can integrate with

 Device Security integrates with these third-party applications through
 Cortex XSOAR . You can use either a free, cohosted
 Cortex XSOAR instance or a full-featured
 Cortex XSOAR server deployed either on premises or in the cloud.

 Device Security with a free, cohosted
 Cortex XSOAR instance – This cohosted, limited-featured
 Cortex XSOAR can be activated in Device Security in
 Strata Cloud Manager at no additional cost.

 Device Security with a full-featured Cortex XSOAR 
 server – When using a full-featured Cortex XSOAR server,
 you must install a Device Security content pack. The content pack provides
 Cortex XSOAR with all the third-party integration instance settings,
 playbooks, and jobs that Device Security configures. Optionally, you can
 create custom playbooks for your integrations.

 The Device Security FedRAMP solutions must use a
 full-featured Cortex XSOAR server deployed on premises.

 Learn about using Cortex XSOAR to enable third-party integrations that
 Device Security supports.
