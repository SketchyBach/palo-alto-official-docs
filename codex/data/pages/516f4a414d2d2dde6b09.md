 GlobalProtect 6.3.3-h11 (6.3.3-c1016) Windows and macOS (Preferred) Known Issues 

 Lists the known issues in GlobalProtect app 6.3.3-h11 (Preferred). 

 The GlobalProtect app 6.3.3-h11 (Preferred) (6.3.3-c1016) release includes performance
 and bug fixes. 

 The following table lists the known issues in GlobalProtect app 6.3.3-h11 (Preferred)
 (6.3.3-c1016) Windows and macOS. 

 Issue ID 

 Description 

 GPC-26563 

 When your GlobalProtect client disconnects from Prisma Access, it
 does not restore the previously configured proxy PAC file Script
 address on your client machine. This occurs when Prisma Access
 pushes a different PAC file location during the connection, and upon
 disconnect, GlobalProtect does not revert to the original Script
 address.
