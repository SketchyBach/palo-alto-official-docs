 Set Commands Changed in PAN-OS 9.1 

 Command line interface 'set' commands that are changed in PAN-OS 9.1: 

 The following commands are modified in the 9.1 release. 

 ha1-a and ha1-b 
 are added, and dedicated-ha1 is removed, as options to:

 set deviceconfig high-availability interface ha1 port 
set deviceconfig high-availability interface ha1-backup port

 hsci is added, and dedicated-ha2 
 is removed, as options to:

 set deviceconfig high-availability interface ha2 port 
set deviceconfig high-availability interface ha2-backup port 

 hsci is added is as an option to:

 set deviceconfig high-availability interface ha3 port 

 user is added as an option to:

 set network shared-gateway <name> log-settings profiles <name> match-list <name> actions <name> type tagging target

set shared log-settings userid match-list <name> actions <name> type tagging target

set shared log-settings iptag match-list <name> actions <name> type tagging target

set shared log-settings hipmatch match-list <name> actions <name> type tagging target

set shared log-settings correlation match-list <name> actions <name> type tagging target

set shared log-settings profiles <name> match-list <name> actions <name> type tagging target

set vsys <name> log-settings profiles <name> match-list <name> actions <name> type tagging target

 dynusergroup_name is added as an option to:

 set shared reports <name> type thsum group-by 
set shared reports <name> type urlsum group-by 
set vsys <name> reports <name> type thsum group-by
set vsys <name> reports <name> type urlsum group-by
