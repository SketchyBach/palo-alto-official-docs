 Use an External Dynamic List in Policy 

 An external dynamic list (formerly called dynamic block
list) is a text file that you or another source hosts on an external
web server so that the firewall can import objects—IP addresses,
URLs, domains—to enforce policy on the entries in the list. As the
list is updated, the firewall dynamically imports the list at the
configured interval and enforces policy without the need to make
a configuration change or a commit on the firewall.
