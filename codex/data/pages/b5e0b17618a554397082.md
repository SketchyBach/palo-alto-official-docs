 Fix a Microsoft Installer Conflict 

 Where Can I Use This? What Do I Need? 

 Windows endpoints only 

 GlobalProtect app version 6.1 or later 

 If you Enforce GlobalProtect for
Network Access in a GlobalProtect portal agent configuration,
and then you upgrade a Windows endpoint to a newer version of the
GlobalProtect app, installation can fail and the enforcement configuration
can block all traffic. 

 This issue is caused by an OS limitation
that occurs when multiple Microsoft installer ( msiexec.exe )
instances run simultaneously on a Windows endpoint. You must use
the following procedure to resolve the Microsoft installer conflict: 

 Restart the endpoint. 

 Stop all third-party installers that are running in the
background. 

 Press Ctrl+Alt+Delete ,
and then click Task Manager. 

 In the Task Manager , locate all third-party msiexec programs
that are currently running (for example, msiexec command line - Google Search ). 

 Select the third party installer, and then click End
Task to stop the installer. 

 Restore the existing version of GlobalProtect, and then
upgrade to the newer version of the app. 

 ( Optional ) If necessary, re-install
the existing (older) version of GlobalProtect to repair it. This
step is required if the upgrade continues to fail. 

 Allow the upgrade to proceed as expected.
