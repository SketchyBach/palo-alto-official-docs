 Broker VM 28.0.96 (Major) 

 The Broker VM major 28.0.96 release was released as part of the release of Cortex XDR 3.15. The release is divided into three deployments: July 20, 2025, August 3, 2025, and August 10, 2025. For more information on the changes integrated on this major release, see the Broker VM Version feature in the Cortex XDR 3.15 Release Notes .
