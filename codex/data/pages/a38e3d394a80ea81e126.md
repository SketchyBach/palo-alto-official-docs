 Unified Logs 

 Combine and correlate multiple security log types into a single, unified table within
 your Strata™ Cloud Manager Log Viewer. 

 Unified Logs aggregates data from up to five log types into a single table in the Log
 Viewer. This allows you to correlate data across log categories, such as
 Firewall/Network. 

 Unified Logs do not currently support log forwarding. 

 Log Categories group related log types. Log Types are data streams generated by
 system functions, including: 

 AI Security Logs 

 Application Security 

 Authentication 

 network-dns-security-log.html 

 DNS Security (Resolver and SDWAN and Panos 12.1 or later) 

 Decryption 

 File 

 Firewall Traffic 

 GlobalProtect 

 HIP Match 

 IPtag 

 Remote Browser Isolation 

 SCTP 

 SD-WAN Traffic 

 Threat 

 Tunnel 

 URL 

 UserID 

 The Unified Log View uses a single, correlated table to display data from multiple
 sources. Instead of viewing separate logs, the system merges overlapping fields to
 provide a consistent view across different network functions. 

 Primary Sort : The system automatically sorts all log entries by Time
 Generated. 

 Secondary Sort : If multiple entries share the same timestamp, the system
 sorts them based on the order you selected the log types. 

 Column Hierarchy : The table follows a strict display order, starting with
 Index columns (DETAILS, timestamp, and Log Type), followed by Overlapping
 columns common to your selection, and finally Type-specific columns. 

 Launch Strata Cloud Manager and click Log
 Viewer . 

 Choose Network to expand the list of network log types.
 Select Unified Log to open the log selection modal
 window. 

 Select the checkboxes next to the specific logs you want to combine (for
 example, select SD-WAN Traffic, Threat, URL, GlobalProtect, and UserID). 

 The Unified Log view
 accommodates a maximum of 5 concurrently active log filters. Selecting
 additional items requires you to clear an existing selection
 first. 

 Click Apply to save your combined profile selections.
