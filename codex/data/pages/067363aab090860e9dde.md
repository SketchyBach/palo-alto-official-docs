 Three ways of accessing the Prisma SD-WAN ION CLI commands. 

 Access the Prisma SD-WAN ION device CLI
commands in three different ways. Access through secure socket shell
(SSH), assign a static IP address, or log in through the Prisma
SD-WAN web interface (remote access).
