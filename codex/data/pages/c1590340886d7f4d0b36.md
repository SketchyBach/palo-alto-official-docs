 Reference A: Checkmarx troubleshooting 

 Connection test fails 

 Cause 

 Resolution 

 Invalid API key 

 Verify the Checkmarx One API key is correct and active. Generate a new API key from Checkmarx One → Settings → Identity and Access Management → API Keys if needed 

 Wrong tenant URL 

 Verify the tenant URL matches the Checkmarx One region. Use the Supported Checkmarx One regions table to confirm the correct base URL 

 Insufficient API key scope 

 Verify the API key has read access to projects, scans, and results in the Checkmarx One tenant 

 Network connectivity 

 Verify Cortex Cloud can reach the Checkmarx One tenant URL. Check firewall rules, proxy configurations, and the configured egress path 

 No findings appear after setup 

 Cause 

 Resolution 

 No projects mapped 

 Verify at least one Checkmarx project is mapped to a Cortex Cloud repository on the Select Projects step of the integration wizard. Only mapped projects are ingested 

 Wrong scan type enabled 

 Verify the correct scan type (SAST or SCA) is enabled for the type of Checkmarx One projects in the tenant 

 No completed Checkmarx scan 

 Verify the mapped Checkmarx projects have at least one completed scan in Checkmarx One. Cortex Cloud ingests results only from completed scans 

 Initial polling cycle not complete 

 Wait for the initial ingestion to finish. Check the Integration Health field in the instance details panel for progress 

 Missing SAST findings 

 Cause 

 Resolution 

 Checkmarx SAST scanner not enabled 

 Verify the Checkmarx SAST scanner is licensed and enabled in the Checkmarx One tenant 

 SAST scan type not enabled in Cortex Cloud 

 Verify the SAST scan type is enabled on the Select Issue Types step of the Checkmarx integration wizard 

 No SAST projects in Checkmarx One 

 Verify the mapped Checkmarx projects have SAST scans configured, not only SCA scans 

 Missing SCA findings 

 Cause 

 Resolution 

 Checkmarx SCA scanner not enabled 

 Verify the Checkmarx SCA scanner is licensed and enabled in the Checkmarx One tenant 

 SCA scan type not enabled in Cortex Cloud 

 Verify the SCA scan type is enabled on the Select Issue Types step of the Checkmarx integration wizard 

 No SCA projects in Checkmarx One 

 Verify the mapped Checkmarx projects have SCA scans configured, not only SAST scans
