 View Device Location Information 

 View the physical location of devices in the Device Security portal. 

 Where Can I Use This? What Do I Need? 

 Device Security (Managed by Strata Cloud Manager) 

 (Legacy) IoT Security (Standalone portal) 

 One of the following subscriptions: 

 Device Security subscription

 Precision AI bundle subscription

 Device Security X subscription

 One of the following Cortex XSOAR setups:

 A free, cohosted, limited-featured
 Cortex XSOAR instance

 A full-featured Cortex XSOAR server

 When Device Security successfully integrates with Aruba AirWave , the
 device location information learned through the integration appears in the Device
 Details page. Devices with location information will have a Device Location tab on their
 Device Details page. The freshness of the location information depends on how often you
 schedule the integration jobs to run when you
 configure the integration for Device Security 
 and Aruba AirWave .

 On the Devices page in the Device Security portal, you can find devices learned
 through the Aruba AirWave integration by filter search or query. 
 With filter searching, specify Aruba AirWave as the source. When using
 the query engine, enter an AP Location in the query search. The AP Location specifies
 the access point location learned from the Aruba AirWave integration.

 For devices added up updated through the Aruba AirWave integration,
 their Device Details page displays the Device Location tab in addition to any other
 information learned from the integration. The Device Location tab displays two
 widgets on the Device Details page: Last Known Location and Device Location Map.

 Last Known Location : The Last Known Location section lists the device's
 location and information about the access point that last saw the device's traffic.
 The Device Security and Aruba AirWave integration uses a device's
 access point to determine the device's physical location.

 Clicking on the SSID Information field brings up the devices inventory for all
 devices connected to the same access point. Clicking on either the AP MAC or AP
 Name field brings up the access point's Device Details page. Clicking on the AP
 Location field brings up the devices inventory for all devices with that AP location.

 Device Location Map : The Device Location Map section displays the device's
 location on a floor plan map imported from Aruba AirWave . You can
 zoom in or out on the floor plan map, or snap-to-fit within the widget display.
