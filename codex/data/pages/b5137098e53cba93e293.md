 Cortex XSOAR 6.13 

 Limit Available CPU 

 Limit Docker CPU resources in Cortex XSOAR 6.13. 

 Follow these instructions to set the advanced parameters to configure the CPU limit. 

 Select Settings → About → Troubleshooting → Add Server Configuration . 

 Type the following: 

 Key 

 Value 

 limit.docker.cpu 

 true 

 docker.cpu.limit 

 1.0 (Optional) Default is 1.0 if not specified. 

 Reset the running containers by running the /reset_containers command.
