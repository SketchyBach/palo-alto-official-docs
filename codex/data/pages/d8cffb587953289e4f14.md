 Deploy Prisma Agents to macOS Endpoints Using Jamf Pro 

 Learn how to deploy the Prisma Agent package to macOS endpoints using
 Jamf Pro. 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 NGFW (Managed by Panorama) 

 Check the prerequisites for the deployment you're
 using 

 Minimum Prisma Agent version: 25.3.1.14 

 macOS 14 and later desktop devices 

 Contact your Palo Alto Networks account representative to activate the Prisma Agent feature 

 Jamf Pro is a mobile device management (MDM) tool that enables you to configure and
 deploy software to macOS endpoints from a central console. After you download the Prisma Agent package and configuration file from the Endpoint Management
 page ( Configuration Endpoint Management ), you can use Jamf Pro to deploy the agent to macOS endpoints. 

 To deploy the Prisma Agent , complete the following tasks: 

 Push the required GoDaddy CA certificates to your macOS endpoints using a
 certificate payload in a Jamf Pro configuration profile before deploying the
 Prisma Agent . 

 If the Go Daddy Root Certificate Authority - G2 certificate is not
 in the endpoint's trusted root store, the Prisma Agent fails
 to enroll with the Endpoint Manager. See CA Certificate Requirements for Endpoint Manager
 Enrollment for details. 

 In Jamf Pro, select Computers Configuration Profiles and
 click New . 

 In the General payload, choose
 Computer Level as the level. This ensures
 the certificate is installed in the System Keychain and is trusted
 system-wide. 

 Add a Certificate payload and upload the
 Go Daddy Root Certificate Authority - G2 certificate
 file. 

 Click the Scope tab and assign the profile
 to the device groups targeted for Prisma Agent 
 deployment. 

 Click Save . 

 Create a second profile using the same process for the Go Daddy
 Secure Certificate Authority - G2 intermediate
 certificate. 

 Confirm that both profiles show a
 Completed status before
 proceeding. 

 Deploy configuration profiles that define how Prisma Agents are
 configured using one of the following methods: 

 ( Recommended ) Use one of the following configuration profiles
 provided by Palo Alto Networks: 
 V3 configuration
 profiles : Compatible with all versions of Prisma Agent for macOS 

 V2_1 configuration
 profiles : Only compatible with Prisma Agent 
 25.6 or earlier versions 

 Manually create configuration profiles using one of the following
 procedures: 
 Manually Create Configuration Profiles (V3) for Prisma Agent based on the V3
 configuration profiles 

 Manually Create a Configuration Profile (V2_1) for Prisma Agent if you don't want to configure
 the V3-based configuration profiles 

 Create a Jamf policy that
 will trigger the installation of the Prisma Agent on enrolled macOS
 devices.
