 Advanced filters in SaaS Security Inline enable you to display Discovered Applications from different
 security angles and track new and emerging SaaS apps using the Application Dictionary . 

 Use
filters to search by: 

 Risk —Identify
risky SaaS apps that need to be blocked. 

 Category —Identify a competing SaaS app
that’s more secure and that’s a suitable replacement. 

 Tags —Display SaaS apps by the default tags you’ve
assigned. 

 Rules —Display the SaaS policy rule recommendations that
you applied to individual SaaS apps. 

 Custom Tags —Display SaaS apps by the custom tags you’ve
assigned.
