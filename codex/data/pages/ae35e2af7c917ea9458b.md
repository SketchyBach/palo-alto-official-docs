 Supported Languages 

 Natural languages that Enterprise Data Loss Prevention (E-DLP) data patterns support for detecting
 sensitive data, including English and non-English languages. 

 Enterprise Data Loss Prevention (E-DLP) supports inspection of sensitive data in English and non-English
 languages for traffic forwarded from the following enforcement points and services: 

 Prisma Access (Managed by Panorama or Strata Cloud Manager) 

 NGFW (Managed by Panorama or Strata Cloud Manager) 

 Prisma Browser 

 SaaS Security (API and Inline) 

 Email DLP 

 Endpoint DLP 

 For example, Enterprise DLP can inspect and block an outbound email if sensitive
 data is written in Japanese plaintext characters directly in the email subject or body.
 However, Enterprise DLP can't inspect and block an outbound email if sensitive data
 is written in Japanese characters in a document that relies on a custom
 document type for detection. 

 Review the languages Enterprise DLP supports, the supported file types,
 and the detection methods for each.
