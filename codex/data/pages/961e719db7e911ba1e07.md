 New Features - Autonomous DEM - 2022 

 ADEM Tier 1 Support Role 

 Release Date: n/a 
 | 
 Last Updated: June 2026 

 To restrict helpdesk access strictly to read-only monitoring data without exposing configuration settings, Autonomous DEM (ADEM) introduces the Tier 1 Support role . When you assign the Tier 1 Support role to a user, that user can log in and view all ADEM dashboards and monitoring data needed to assist end users with experience issues. These users cannot modify any configuration or access other applications in the Prisma® Access ecosystem, which prevents unintended changes during support activities and limits the blast radius if credentials are compromised. 

 This role is particularly useful for tiered support organizations where frontline helpdesk personnel need to identify and escalate issues without the ability to make system changes. By aligning data access to job function, you can extend ADEM's visibility to a broader support team while maintaining control over who can modify your environment.

 Accurate Mobile User and Device Tracking 

 Release Date: n/a 
 | 
 Last Updated: June 2026 

 To ensure accurate counts and detailed per-device visibility when users share devices or log in from multiple endpoints, Autonomous DEM (ADEM) now tracks monitored users as unique user/device combinations . Previously, tracking unique users rather than combinations made it difficult to accurately reflect how your workforce actually used endpoints. 

 This enhanced visibility allows you to view experience and performance data for specific devices independently. For example, if two users are each logged in to three devices, ADEM displays a device count of 6 and a user count of 2. Each unique user/device combination is tracked separately, ensuring that metrics accurately represent real-world usage patterns without conflating shared devices or multiple logins. As detailed in the Monitored Mobile Users documentation, this approach provides granular insights into user session quality without requiring you to view all associated devices simultaneously.

 Autonomous DEM Self Serve 

 Release Date: n/a 
 | 
 Last Updated: June 2026 

 To reduce high volumes of helpdesk tickets for application experience issues, Autonomous DEM (ADEM) introduces Self Serve capabilities. Previously, IT helpdesk teams often received high volumes of tickets that end users could resolve themselves with the right guidance. Autonomous DEM Self-Serve reduces this ticket load by empowering end users to identify and fix issues that fall within their own purview. 

 Autonomous DEM Self Serve detects and provides guided remediation for the following conditions: 

 CPU and memory issues impacting application experience —Detects high CPU or memory utilization conditions and notifies mobile users with guided remediation steps. 

 WiFi issues impacting application experience —Detects poor WiFi quality, changes in WiFi connections, or disconnect conditions, and notifies mobile users with guided remediation steps. 

 Internet issues impacting application experience —Detects internet disconnect conditions for wired and wireless connections and notifies mobile users with guided remediation steps.

 Standalone Autonomous DEM Agent Downloads 

 Release Date: n/a 
 | 
 Last Updated: June 2026 

 To upgrade the Autonomous DEM (ADEM) agent independently of the GlobalProtect® app and on your own schedule, you can now download the agent installation package directly from the Customer Support Portal (CSP) . Previously, upgrading the agent required upgrading the GlobalProtect app, coupling two separate update cycles and preventing you from pushing agent updates independently. 

 You can deploy the agent you download from the CSP using your existing deployment methods, such as an MDM solution. This decoupled upgrade path is useful when you need to deploy a specific agent version to address a monitoring issue without rolling out a GlobalProtect update across your environment. As detailed in the Manage Autonomous DEM Agent Upgrades documentation, this standalone approach gives you more control over your endpoint monitoring without affecting how users connect through Prisma® Access.

 Synthetic Tests for Mobile User Groups 

 Release Date: n/a 
 | 
 Last Updated: June 2026 

 To easily scale monitoring coverage for larger user groups without manually configuring individual tests, Autonomous DEM (ADEM) introduces synthetic application tests for mobile user groups . You can now create application tests that target individual mobile users, mobile user groups, or both, giving you flexible monitoring coverage that scales automatically as your group membership changes. 

 When you configure a synthetic test for a mobile user group, the test runs automatically on all devices belonging to every user in that group. If a user is removed from the group, the test stops running on their devices automatically. When new users join the group, the test starts on their devices without any manual reconfiguration. This automatic scope management keeps your test coverage aligned with your actual user population and reduces maintenance overhead. Tests apply only to groups currently used in security policies. 

 You can filter test results by individual mobile users or by mobile user groups to get flexible visibility into experience data at both the individual and group level. The Custom option lets you select a single user, a group, or a combination of both for each test.
