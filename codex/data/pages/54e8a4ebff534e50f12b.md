 Authentication failures detected 

 Incident Code 

 INC_NGFW_AUTH_FAILURES 

 Severity 

 Warning 

 Category 

 Network Services 

 Subcategory 

 Authentication 

 Description 

 This incident is triggered when the number of authentication failures suddenly
 spikes. The failures are associated with connection issues to authentication
 servers or services such as LDAP, RADIUS, TACACS, Kerberos, SAML, etc. 

 Raise Condition 

 When we see an anomalous rise in Authentication failures from its average
 baseline for more than 4 hours. 

 Clear Condition 

 When we do not see anomalous rise in Authentication failures from its average
 baseline for more than 4 hours.
