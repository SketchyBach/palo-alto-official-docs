 Description 

 An AWS network ACL rule was created with a specific rule number. 

 Attacker's Goals 

 Deleting an ingress rule may allow an attacker to gain persistence in the cloud environment. Deleting an egress rule may enable data exfiltration. 

 Investigative actions 

 Check the VPC affected by this change. 

 Verify the rule number (as rules are applied in order). 

 Determine whether the rule is ingress or egress.
