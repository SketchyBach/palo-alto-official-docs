 CloudConnector Plugin 

 The CloudConnector plugin extends Panorama with the ability to communicate securely
 with Strata Cloud Manager and participate in SCM-Panorama Configuration Sync. 

 Where Can I Use This? What Do I Need? 

 Panorama 

 Panorama registered to the Customer Support Portal
 (CSP) with an SCM license 

 Root user SSH access to the Panorama CLI 

 Panorama running PAN-OS 10.2 or later 

 CloudConnector plugin version 3.1 or later 

 The CloudConnector plugin is a Panorama ® plugin that establishes and
 maintains a secure channel between your Panorama appliance and Strata Cloud Manager
 (SCM). After you install and configure the plugin, it allows SCM to share snippet-based
 configurations directly to Panorama, keeping your on-premises and cloud-managed policies
 synchronized without manual intervention. 

 The plugin provides the following capabilities: 

 SCM-Panorama Configuration Sync — Enables Strata Cloud Manager to synchronize
 snippet configurations to Panorama device groups and templates. 

 Secure communication — Uses a Thermite device certificate to authenticate all
 traffic between Panorama and Strata Cloud Manager. 

 Regional endpoint routing — Connects to the correct SCM admin cluster URL for
 your deployment region.
