 SaaS Agent Security Licenses 

 Review the SaaS Agent Security licenses to understand which license is
 right for you. 

 SaaS Agent Security Standalone license 

 You can activate a SaaS Agent Security Standalone license using Software NGFW
 Credits/Deployment Profile only. SaaS Security Posture Management is included by default in this
 license. 

 SaaS Agent Security license availability by default 

 SaaS Agent Security is available by default when you purchase any one of the
 following licenses: 

 CASB-X license 

 CASB-PA license 

 SaaS Security Posture Management Standalone license 

 These licenses are activated using a Magic Link. You don't need to take additional steps
 to activate SaaS Agent Security . 

 SaaS Agent Security license and Prisma AIRS 

 You also have the option to activate SaaS Agent Security (using the deployment
 profile) when you activate the Prisma AIRS license. SaaS Security Posture Management license is available by default when you activate SaaS Agent Security . 

 You can begin using SaaS Agent Security to safely onboard SaaS Agentic
 Platforms that are used to develop SaaS Agents.
