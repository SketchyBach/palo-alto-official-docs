 Changes in Panorama default behavior in PAN-OS 8.1 

 Feature 

 Change 

 Templates and Template Stacks You must assign managed devices
to a template stack instead of a template. 

 Templates and Template Stacks 
 A maximum of 8 templates can
be assigned to a template stack. 

 Device Groups 
 You can only view the template configuration
for a device group if devices in the device group, and the template,
are associated with the same template stack.
