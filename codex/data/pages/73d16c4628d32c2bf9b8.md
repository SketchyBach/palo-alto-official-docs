 Working with Custom CA Connectors in the Certificate Authorities Inventory 

 When working with the custom CA connectors, there are several things you can do. This topic discusses several features of custom CA connectors. 

 Tip: Before you begin - You need to have created a custom CA connector before the information in this topic will be useful. 

 You can find existing custom CA connectors in Next-Gen Trust Security by going to Settings > Certificate Authorities , and then reviewing the list to find CAs with the subtitle Connector CA . 

 The details panel for a custom CA connector has four tabs corresponding to the wizard's four steps that you used to create the CA connector . 

 The Administration tab lets you change the name of the connector and which VSatellite it uses for connection. 

 The Information tab controls how Next-Gen Trust Security connects to your CA account. 

 The Issuance tab controls how certificates are created by your custom CA. 

 The Import tab controls the settings used to import certificates from the CA. 

 To Run a Certificate Import Manually 

 Locate the custom CA connector in the Certificate Authorities list. 

 Click the Import tab. 

 Review the existing import settings, and make changes, if needed. 

 Click Import . 

 To Schedule a Certificate Import 

 Locate the custom CA connector in the Certificate Authorities list. 

 Click the Import tab. 

 Enable the Scheduled import setting and set the schedule. 

 Enter the UTC time when you want the import to occur. For reference, the current UTC time is displayed. 

 Tip: When selecting the Month option - If you select the Month option, you will specify the day of the month to run the import. If you select a value like 31, the job will only run on months with the specified number of days and will not run on months without. 

 Click Save .
