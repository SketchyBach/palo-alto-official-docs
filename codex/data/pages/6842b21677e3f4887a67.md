 Secure Traditional VPC Traffic 

 Deploy Managed AIRS for AWS to secure traditional VPC traffic without managing
 underlying infrastructure. 

 Where Can I Use This? What Do I Need? 

 Managed AIRS for AWS 

 Access to Strata Cloud Manager (SCM) 

 With Managed AIRS for AWS, you will not be be managing infrastructure. When you deploy
 Managed AIRS for AWS resources in the Strata Cloud Manager console, the deployed
 resources automatically register as devices in Strata Cloud Manager. You can then author
 policies for the registered resources using the following workflow:
