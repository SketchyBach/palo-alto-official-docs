 Increased Configuration Size for Panorama 

 Increased configuration file size to optimize performance
for M-Series and Panorama™ virtual appliances. 

 The total configuration file size of
Panorama™ M-Series and virtual appliances is an important piece
of the performance metric when determining which M-Series appliance
or the minimum amount of virtual resources you need to allocate
on your Panorama virtual appliance to ensure that you meet your
Security requirements. PAN-OS 10.0 increases the total configuration
file size of the Panorama management server in Management Only mode
to better optimize your appliance and to support larger configuration
file sizes. Increasing the total configuration file size of the Panorama
management server helps reduce the performance impact on the Panorama
management server when performing configuration changes, commits, and
pushes to managed firewalls. 

 The increased configuration file size
for Panorama is supported only in Management Only mode. 

 The
Panorama M-Series and virtual appliances in Panorama mode and the
M-100 appliance do not support this increased configuration file
size.

file size based on your Panorama M-Series appliance or the resources
you allocate to your Panorama virtual appliance.
