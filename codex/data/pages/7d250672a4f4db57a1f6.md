 Monitor Prisma Access Hub-Spoke Performance 

 Monitor the performance of your Prisma Access Hub-Spoke
deployments by clicking any widget to get an overview of all VPN
clusters for the desired health state and then selecting Prisma
Access Hub-Spoke from the VPN Clusters list. Additionally, you
can use the Sites and time frame filters
to view Prisma Access Hub-Spoke deployments based on link notifications,
latency deviations, jitter deviations, packet loss deviations, or
impacted applications within a specified period of time. 

 Field 

 Description 

 Sites 

 Name of the SD-WAN Prisma Access deployment. 

 Profile 
 Specifies Prisma Access deployment is a hub or branch firewall. 

 Region 

 Location of the Prisma Access Deployment. 

 Tenant 

 Tenant name for the Prisma Access deployment. 

 IPSec Termination Node 

 Name of the IPSec Termination Node associated
with the remote network secured by the Prisma Access deployment.
Up to four (4) IPSec Termination Nodes may be displayed. 

 Links 
 The number of links configured for the SD-WAN
site. 

 Link Notification 
 View the link notifications for an SD-WAN site
with degraded app or link health. 

 Latency 

 Displays the latency health status of the
tunnel. Can be Impacted , Warning ,
or OK . 

 Jitter 

 Displays the jitter health status of the
tunnel. Can be Impacted , Warning ,
or OK . 

 Packet Loss 

 Displays the packet loss health status of
the tunnel. Can be Impacted , Warning ,
or OK . 

 Apps 
 Total number of applications configured for
the SD-WAN site. 

 Impacted Apps 
 Number of impacted applications at the SD-WAN
site. 

 Error Correction Type 

 Specifies the type of forward error correction
applied for one or more applications. If empty (blank), then no
error correction was applied. 

 FEC —Forward
Error Correction 

 PD —Packet Duplication
