 Run backup and restore operations from the CLI 

 Run backup and restore operations in Cortex XSOAR 8.8 On-prem from the CLI. 

 Run the following commands from your CLI to perform backup and restore operations. Backup can take several minutes. 

 Command 

 Description 

 help 

 Shows a help menu on all available subcommands. You can also apply the --help flag on the subcommands to get more detailed specific information. 

 sudo /home/viewer/sbin/backup-cli --help 

 Output: 

 Backup and restore operations Usage: cortex-cli backup-restore [command] Available Commands: backup Backup operations install Install backup components nfs-check Run NFS connectivity test restore Restore operations schedule Schedule operations Flags: -h, --help help for backup-restore Global Flags: --config string Path to configuration file --verbose Display verbose output 

 nfs-check 

 Checks if an NFS share can be mounted and verifies storage requirements for backup. 

 sudo /home/viewer/sbin/backup-cli nfs-check [nfs-server-ip] [nfs-path] [size-limit (GB)] 

 Example: 

 sudo /home/viewer/sbin/backup-cli nfs-check 1.1.1.1 /some/path/to/nfs/ 1024 

 schedule create 

 Configures an automated backup schedule for the creation and removal of old backups. Only one (or zero) backup schedule can run at any given time. 

 The schedule syntax is in crontab notation ( https://crontab.guru/ ) which must be in quotes (see the example). Backup retention time is provided in units of days. For example, 5 for keeping each backup for five days before it is automatically deleted. 

 sudo /home/viewer/sbin/backup-cli schedule create [schedule cron expression] [ttl in day units] 

 Example: 

 sudo /home/viewer/sbin/backup-cli schedule create "30 13 * * *" 5 

 Example output: 

 schedule show 

 Shows the details of an existing scheduled backup. 

 sudo /home/viewer/sbin/backup-cli schedule show 

 Example output: 

 schedule delete 

 Deletes the existing backup schedule. 

 sudo /home/viewer/sbin/backup-cli schedule delete 

 backup list 

 Prints a list of all backup attempts and their statuses. 

 sudo /home/viewer/sbin/backup-cli backup list 

 Example output: 

 delete 

 Deletes an existing backup by name. 

 sudo /home/viewer/sbin/backup-cli backup delete [backup-name] 

 Example: 

 sudo /home/viewer/sbin/backup-cli backup delete xsoar8-7-0-12-20240819050051 

 restore 

 Runs a system restore from a previous backup. 

 Backups can be restored only if the current version of Cortex XSOAR is the same version as the backup. 

 You can copy the backup name from the backup list. 

 Caution 

 Rolling back to an existing restore point will shut down Cortex XSOAR for several minutes. 

 sudo /home/viewer/sbin/backup-cli restore [backup-name] 

 Example: 

 sudo /home/viewer/sbin/backup-cli restore xsoar8-7-0-12-20240818050050 

 history 

 Prints a history of all attempted restore operations. 

 sudo /home/viewer/sbin/backup-cli restore history

 uninstall 

 Removes all backup components and disconnects from the configured NFS server. 

 Warning 

 Running uninstall deletes existing backup data. 

 To reconfigure NFS access details on the Cortex XSOAR cluster side, run the uninstall command and then run the install command. 

 sudo /home/viewer/sbin/backup-cli uninstall
