 Install Cortex XSOAR on a VM deployed on AWS 

 Install Cortex XSOAR 8.9 On-prem on an AWS virtual machine. 

 The following procedure describes the steps for deploying an OVA image on AWS and then installing Cortex XSOAR on your deployed virtual machines. 

 Important 

 To deploy your virtual machine on AWS you must run the AWS Migration Tool to convert the OVA file to AWS AMI format, and the migration tool must be run in a region that officially supports it. Check the AWS documentation for the most up-to-date list of supported regions.
