 Troubleshoot Prisma Agents 

 Learn how to use the features in the Endpoint Management
 page to troubleshoot issues with the Prisma Agent . 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 NGFW (Managed by Panorama) 

 Check the prerequisites for the deployment you're
 using 

 Contact your Palo Alto Networks account representative to activate the Prisma Agent feature 

 As you monitor the health of the Prisma Agents that are deployed to end
 users in your organization, you might detect issues that require remediation. The Endpoint Management
 page ( Configuration Endpoint Management ) simplifies troubleshooting by offering centralized controls that you can use to
 troubleshoot Prisma Agents . 

 When a user encounters a connectivity problem or other problem with the Prisma Agent ,they can try to fix the issue if a resolution is provided in
 the notification. However, if they still can’t resolve the problem, they will contact
 you for assistance. 

 You can troubleshoot Prisma Agent issues by taking action on specific
 endpoints, such as: 

 Download agent logs 

 Download
 Host Information Profile (HIP) reports to verify HIP policy enforcement,
 so that only endpoints that meet enterprise security requirements are allowed to
 access corporate resources and applications. 

 With permission from the end user, open remote
 shells and complete diagnostic tasks on an endpoint (macOS and Windows agents only) 

 Run Prisma Agent commands on an endpoint 

 You can also isolate issues on macOS and Windows agents by: 

 Upgrading the Prisma Agent outside of the staged rollout upgrade process 

 Downgrading the agent for
 troubleshooting 

 Stopping and restarting the staged rollout of Prisma Agents if you encounter ring upgrade problems and need to resolve the
 them.
