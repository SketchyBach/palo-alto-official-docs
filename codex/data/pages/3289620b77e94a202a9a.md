 clear high-availability 

 Description 

 Clear high-availability
(HA) control link statistics information and transitions statistics
on the controller node of a WildFire appliance cluster. 

 Syntax 

 create { 
high-availability { 
control-link { 
statistics; 
} 
transitions; 
} 
} 

 Options 

 > control-link> —
Clear HA control-link statistics. 

 > transitions> —
Clear HA transitions statistics (events that occur during HA switchovers). 

 Sample Output 

 After you clear control-link
or transition statistics, the WildFire cluster resets all values
to zero (0).
