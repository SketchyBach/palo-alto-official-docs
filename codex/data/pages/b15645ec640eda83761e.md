 Features introduced in 2026 

 February 2026 

 Changed Features 

 These features have been modified or removed in this release. 

 FEATURE 

 DESCRIPTION 

 Broker VM 

 The Broker VM Pathfinder applet is now deprecated. 

 Marketplace 

 The following user interface changes have been implemented: 

 Marketplace is now relocated to: Settings > Configurations > Marketplace 
- The Automation & Feed Integrations page is now replaced by the Data Sources & Integrations page ( Settings > Data Sources & Integrations ) 

 Microsoft Office 365 data collector 

 Collecting security alerts using the Use Microsoft Graph API v2 (Beta) option now uses the v2 GA API endpoint . 

 Microsoft is deprecating the Legacy Alerts (v1) API in April 2026 . To avoid ingestion failure for instances currently using the Legacy Alerts (v1) checkbox, switch to the Use Microsoft Graph API v2 (Beta) and verify your custom content (correlation rules, parsing rules, and dashboards) to ensure compatibility with Microsoft’s new alerts schema.
