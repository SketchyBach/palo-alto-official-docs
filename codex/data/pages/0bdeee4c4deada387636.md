 Key Points About Access and Roles 

 Read-only access : Auditor, View Only Administrator, Internal View Only
 Administrator, Tier 1 Support, ADEM Tier 1 Support, SOC Analyst, Deployment
 Administrator, and IAM Administrator roles can view AI Canvas content but cannot
 create, edit, or delete items. 

 Full access : Business Administrator, Data Security Administrator,
 Internal Superuser, MSP Superuser, Network Administrator, Security
 Administrator, Superuser, and Web Security Administrator roles have complete
 access to all AI Canvas features. 

 Custom roles : Custom roles are not supported for AI Canvas access
 control. 

 Service entitlements : AI Canvas role assignment is also dependent on the
 specific Palo Alto Networks services and applications included in your license
 entitlements.
