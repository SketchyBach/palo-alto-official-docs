 Download a Site Snapshot 

 Learn how to download a site snapshot. 

 Where Can I Use
 This? What Do I Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 Export your site configurations in a yaml file representing the current state of a
 specific site on request. This captures an existing site's configuration as a
 baseline, which you can then use for replication, backup, or modification. For
 snapshot export, the site must have a physical device assigned or be a blank site.
 Snapshots cannot be generated for sites with a device shell. 

 Navigate to the Configuration Prisma SD-WAN Branch Sites or Data Centers . 

 Select a site and from the ellipsis menu, select Download Site
 Snapshot . 

 You cannot generate snapshots for sites with a device shell. Your
 site must have a physical device assigned or be a blank site to successfully
 generate a snapshot. If you attempt to download from a site with an element
 shell, you will receive an error, 'Export Snapshot not allowed on the site
 having element shell'. 

 Monitor the job status, which appears in the Download Site Snapshot
 Status tab on the Site Snapshots page. 

 Download the generated yaml file to your local system. You can now review,
 edit, or use this file for importing new sites. 

 Check Site Snapshot Job Status 

 Site Snapshots history page includes Import Site Snapshot
 Status for a new site creation and Download Site
 Snapshot Status for snapshot yaml generation. Both Import and
 Export operations maintain distinct job statuses to indicate their progress and
 outcome. A warning status indicates that your site might have been created, but
 certain post-deployment actions, such as device assignment, may have failed. A
 failed status can occur due to configuration issues, interface problems,
 overlapping parameters, or conflicts. Proactive monitoring allows you to detect
 issues early and ensures your desired configuration state is achieved. 

 Navigate to Configuration Profiles and Templates Site Snapshots . 
 This page reviews the history and status of all Site Snapshot import and
 download operations. 

 Select the appropriate tab - Import Site Snapshot
 Status or Download Site Snapshot
 Status . 

 Review the Status column for job results. 

 A warning status could mean that your site was created, but device
 assignment failed. For failed or warning jobs, review the
 Status Description for troubleshooting.
