 INC_ZTNA_CONNECTOR_CPU 

 Learn about the INC_ZTNA_CONNECTOR_CPU incident. 

 Incident Code 

 INC_ZTNA_CONNECTOR_CPU 

 Title Template 

 ZTNA connector {connector_name} average CPU utilization exceeds 90% over 30 mins 

 Category 

 Device 

 Subcategory 

 System Resources 

 Description 

 There has been a higher than normal CPU utilization observed on a specific ZTNA (Zero Trust Network Access) Connector. This could lead to increased latency and degraded performance for users connecting through this ZTNA Connector, as its processing capacity is heavily utilized. 

 Raise Condition 

 ZTNA connector Average CPU utilization in last 30 minutes exceeds 90% 

 Clear Condition 

 ZTNA Connector Average CPU utilization in last 30 minutes has dropped below 85%
