 Change Prisma Agent App Settings 

 After you log in to the Prisma Agent , you can modify app settings to change
 the way the agent behaves. 

 Where Can I Use This? What Do I Need? 

 Prisma Agent 

 Minimum Prisma Agent version: 

 25.1 (macOS and Windows) 

 25.7 (Linux)

 desktop devices

 Use the Prisma Agent settings window to view information about your
 device and to change options for your agent, such as enabling desktop
 notifications. 

 Open the Prisma Agent by clicking the 

 icon from the macOS menu bar, Windows
 taskbar, or Linux panel . 

 Click the options icon to open the settings window.
