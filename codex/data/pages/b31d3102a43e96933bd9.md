 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 NGFW (Managed by Panorama) 

 Android 10 and later version 

 You must add the Prisma Access Agent app to Microsoft
 Intune to deploy the Prisma Access Agent to any users or endpoints. 

 Before you begin, ensure that the endpoints are enrolled with
 Microsoft Intune . 

 Click Apps All Apps Create . 

 Set App type to Managed Google Play
 app and click Select . 

 Search and select the Prisma Access Agent app in the App
 store. 

 Click Refresh to display the newly added app. 

 Click Review and Create to add the Prisma Access Agent 
 App to Microsoft Intune. 

 To use certificates for authentication, refer to the Certificates section in the Microsoft
 Intune documentation.
