 Generate a token and review possible authentication errors

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 Data Security license 

 Or any of the following licenses that include the Data Security license: 

 CASB-X 

 CASB-PA 

 For the API client to authenticate to Data Security , you must provide the Client ID and Client Secret generated
when you registered the API client to Data Security and configure
the client to retrieve an OAuth token. All requests must use the
region-specific host with https : 

 VPC1 (US)— https://api.aperture.paloaltonetworks.com 

 AP1 (APAC)— https://api.aperture-apac.paloaltonetworks.com 

 EU1 (EU)— https://api.aperture-eu.paloaltonetworks.com 

 UK (UK)— https://api.aperture-uk.paloaltonetworks.com 

 INDIA
 (IN1)— https://api.in1.prisma-saas.paloaltonetworks.com 

 AUSTRALIA
 (AU1)— https://api.au1.prisma-saas.paloaltonetworks.com 

 UK
 (UK2)— https://api.uk2.prisma-saas.paloaltonetworks.com
