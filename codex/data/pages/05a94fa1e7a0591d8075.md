 Firewall Disconnected from Strata Logging Service 

 Incident Code 

 INC_NGFW_SLS_DISCONNECTED 

 Severity 

 Warning 

 Category 

 Device 

 Subcategory 

 Management 

 Description 

 The connection between FW and Strata Logging Service has been lost. 

 Raise Condition 

 Raised if no logs are received by Strata Logging Service within a 20-minute
 interval. 

 Clear Condition 

 Cleared if logs are being received by Strata Logging Service within a 5-minute
 interval.
