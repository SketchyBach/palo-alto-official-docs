 Configure
the GlobalProtect Portal for LSVPN 

 Step-by-step procedure to configure the portal and satellites along with some usage
 samples. 

 Where Can I Use This? What Do I Need? 

 NGFW 

 No separate license required for LSVPN when using NGFWs 

 The GlobalProtect portal provides the management functions
for your GlobalProtect LSVPN. Every satellite system that participates
in the LSVPN receives configuration information from the portal,
including information about available gateways as well as the certificate
it needs in order to connect to the gateways. 

 The following sections provide procedures for setting up the
portal: 

 Configure the Portal —In LSVPN
 deployments, the GlobalProtect portal serves as a critical infrastructure component
 that centralizes management, authentication, and connection coordination for
 satellite devices. This centralized system acts as the core orchestrator of remote
 network access, providing a sophisticated mechanism for controlling and monitoring
 distributed network connections. The portal provides a comprehensive framework for
 authenticating satellite devices, coordinating connection policies, and establishing
 secure communication channels. 

 Define the Satellite Configurations —In
 LSVPN deployments, a satellite configuration provides the essential connection
 parameters that enable GlobalProtect satellites to establish secure VPN tunnels with
 your network's gateways. These configurations act as a blueprint, specifying which
 gateways a satellite can connect to, what certificates it should use, and how
 frequently it should refresh its configuration. 
 The satellite configuration serves
 as a bridge between your GlobalProtect portal and the remote satellite devices,
 ensuring that each satellite receives the precise network access and security
 settings required for its specific deployment context. 

 GlobalProtect Portal for LSVPN Prerequisite Tasks 

 Before configuring the GlobalProtect portal, you must complete the following
 tasks: 

 Create Interfaces and Zones for the LSVPN on the interface where you’ll
 configure the portal. 

 Enable SSL Between GlobalProtect LSVPN Components by creating an SSL/TLS
 service profile for the portal server certificate, issuing gateway server
 certificates, and configuring the portal to issue server certificates for
 the GlobalProtect satellites. 

 Configure the Portal to Authenticate Satellites by setting up local database
 authentication and defining the authentication profile that the portal will
 use to authenticate satellites.
