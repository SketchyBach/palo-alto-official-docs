 Cortex XSOAR 6.13 

 Duo for Single Sign-On 

 Configure Duo single sign-on in Cortex XSOAR 6.13. 

 Note 

 Duo requires an authentication source - Active Directory or a SAML Identity Provider. You must configure the Single Sign-On authentication source in Duo before you can authenticate Cortex XSOAR users. For our example, we use a SAML 2.0 identity provider. 

 You can authenticate Cortex XSOAR users using Duo Single Sign-On. You need to define Cortex XSOAR in your Duo account, and create a SAML 2.0 instance in Cortex XSOAR by completing the following procedures: 

 Create Duo Groups for Cortex XSOAR Users 

 Define Duo to authenticate Cortex XSOAR 

 Configure the SAML 2.0 Integration for Duo 

 Map Duo Groups to Cortex XSOAR Roles
