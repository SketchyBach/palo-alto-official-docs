 Prisma Agent 26.1.2 Known Issues 

 Review the known issues in Prisma Agent 26.1.2. 

 Prisma Agent version 26.1.2 has the following known issue: 

 Issue ID Description 

 PANG-11429 When a Host Information Profile (HIP) report is generated by a Prisma Agent connected via an IPSec/SSL tunnel to a gateway with an IPv6
 address, the report fails to be sent to the gateway. The HIP report is
 successfully sent to Endpoint Manager but fails to reach the gateway due
 to a connection error.
