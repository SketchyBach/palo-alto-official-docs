 AI Access Security 
 Insights Dashboard 

 Use the AI Access Security Insights dashboard to filter
 and analyze GenAI app usage on your network. Discover risks by use
 case, risky app, app users, and plugins to understand which GenAI
 apps are being used and by whom.

 AI Access Security 
 Recommendations 

 AI Access Security Recommendations give your network
 security administrators clear calls to action to strengthen your
 security posture when allowing GenAI app usage on your network.
 Recommendations include GenAI app classification, best practices
 checks, data loss prevention, and onboarding guidance.

 Viewed on Strata Cloud Manager

 Generate a comprehensive overview of your organization's GenAI app
 usage and security posture in PDF format. The report includes an

 data protection metrics.

 Application Filters for GenAI
 Apps 

 Application filters dynamically group GenAI applications based on
 attributes you define. Use application filters in your Security
 policy rules to control access to GenAI apps based on app attributes
 rather than explicitly listing individual apps. 

 √ 

 √ 

 Moderate 

 Custom Security Policy Rules for
 GenAI Apps 

 Create custom Security policy rules to control GenAI app usage and
 prevent exfiltration of sensitive data to sanctioned GenAI apps. Use
 tags, source, user groups, and other parameters to build targeted
 policy for GenAI apps in your organization. 

 √ 

 √ 

 Moderate 

 Modify Default GenAI App Access
 Policy Rule 

 Modify the predefined AI Access Security Default GenAI App
 Access policy rule in Strata Cloud Manager to control GenAI app
 usage across your enterprise out of the box. 

 — 

 √ 

 Moderate 

 Tag GenAI Apps 

 Apply Sanctioned, Unsanctioned, or Tolerated tags to GenAI apps to
 reflect whether each app is approved within your organization. Tags
 are written to the predefined Application-Tagging snippet and inform
 policy enforcement and reporting. 

 √ 

 Configured on Strata Cloud Manager 

 √ 

 Moderate 

 View GenAI App Risk
 Scores 

 Review risk scores assigned to each GenAI app based on compliance,
 identity access management, security, privacy, and GenAI-specific
 attributes. Risk scores range from 1 (low risk) to 5 (high risk) and
 help you prioritize which apps require action. 

 √ 

 Viewed on Strata Cloud Manager
