 Create a Sectigo Certificate Manager (VSatellite) Configuration 

 Next-Gen Trust Security supports integration with Sectigo Certificate Manager (VSatellite), allowing you to manage certificate issuance, import existing certificates, and revoke certificates through your Sectigo Certificate Manager CA account. 

 Before You Begin 

 Prerequisites: 

 You must have the Superuser role in Next-Gen Trust Security to create CA connectors. 

 A deployed VSatellite that can resolve the Sectigo service address to an IP address. Learn more about VSatellite 

 As a Sectigo administrator, ensure your account has the following settings: 

 Admin type : Select API 

 An API key 

 Certificate requests : Select Automatically approve certificate requests under Edit Standard Admin 

 For more information on managing your Sectigo administrator accounts, see Managing administrators . 

 Create the Sectigo Certificate Manager (VSatellite) Configuration in Next-Gen Trust Security 

 Before you complete these steps, be sure to read the entire Create custom CA connector topic, including the pre-requisites and notes. 

 Click Configuration > Certificate Integrations > Certificate Authorities . 

 Click the New button, then click Add Certificate Authority connector . 

 Specify the Connection information. 

 Enter a Name that will be used as the display name for the CA connector you are creating. 

 Select the VSatellite that can resolve the hostname to the IP address of your Sectigo CA server. 

 Select Sectigo Certificate Manager (VSatellite) as the Certificate Authority Type . 

 Click Next . 

 Provide the Information needed to connect to your Sectigo account. 

 In the Service Address field, enter the URL for the Sectigo CA server. 

 For example: cert-manager.com 

 If you have a custom URL associated with your account, you can enter it here. 

 Enter your Customer URI . 

 This is the last part of your Web Admin Console URL. 

 Example: If your Web Admin Console were https://cert-manager.com/customer/MyCustomerName , your Customer URI would be MyCustomerName . 

 Enter your Username and Password you use to log in to your Sectigo account. 

 Click Test Connection to verify that VSatellite can test the connection to your account.
When VSatellite has connected to Sectigo you will see a confirmation box with a green check mark, and a message that the connection was successful. 

 Click Next . 

 Specify the Issuance options by specifying the product offerings to include. 

 In Product Options , select the products you want to use on a request policy. 

 How do I know which product options to select? In this step, we recommend you select all products that you might want to use with Next-Gen Trust Security. You can restrict which products are available when you create the request policy. Selecting them here makes them available for request policies that use this CA connector. You can easily modify this at a later point by editing the CA connector settings. 

 Click Add . 

 It's easy to miss this step, so be careful. You want to see all the selected product options visible in the Name box before you continue. 

 Click Next . 

 (Optional) Specify the Import settings. 

 The rest of these steps are to set up the import of certificates, which is optional. If you don't want to set up import steps, click Create . 

 In the Import options section, specify if you want to include revoked or expired certificates. 

 To schedule importing certificates from Sectigo server, enable the Scheduled import option, then select the scheduling options. 

 Tip: Selecting a scheduled import frequency - When you import certificates from Sectigo, the Sectigo API does not allow you to filter the import to only download updates, so every import will import the entire inventory of certificates in your account. This may be a significant number, especially if you include revoked or expired certificates. Because this can take a significant amount of time, you may want to decrease the frequency of your scheduled import. Many customers have found that a weekly scheduled import is sufficient. 

 Click Create . 

 You will see your new Sectigo CA in the Certificate Authority list. 

 What's Next? 

 Now that you have created a new CA connector, you need to create a request policy that uses this new CA connector. 

 Once you have created a request policy, users in your TSG can begin requesting certificates using this CA connector. If you want to share the request policy with child TSGs, you can do so from the request policy settings.
