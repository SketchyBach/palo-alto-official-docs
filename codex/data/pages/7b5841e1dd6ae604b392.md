 IT View of End User Notification Statistics 

 After you have set up ADEM Self-Serve and added the Mobile Users
and user groups that you want to send notifications to, you
can view the user notification statistics over a Time
Range that you select. You can also go back to the Monitored
Mobile Users page and make edits to the Self-Serve related
areas. You can view the following: 

 Self-Serve-related
metrics for all users 

 Whether Self-Serve
is enabled for a user 

 Total number of notifications
sent to each user 

 Total CPU or memory
related notifications sent to a user 

 Total Number of WiFi
Notifications Sent to a User
