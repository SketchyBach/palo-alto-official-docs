 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 Prisma SD-WAN Sites represent branch offices and data centers that form part
 of your wide-area network (WAN). 

 Branch sites are where users—and potentially local services—are
 located. The Prisma SD-WAN solution is the primary WAN gateway, managing all
 inbound and outbound traffic to ensure secure, reliable, and optimized
 connectivity. 

 Data centers are central hubs for hosting enterprise applications
 and services, facilitating inter-site communication. They enable seamless
 connectivity between branches, internet, and third-party services. Prisma SD-WAN
 data center deployments integrate smoothly with existing network infrastructure
 and are responsible for managing all branch-level connections. 

 The Prisma SD-WAN solution provides a complete separation of
 the control and data planes. If a branch device loses connectivity with the controller,
 the ION device can continue to function independently. If the ION device loses
 connectivity with the controller, it still maintains the Prisma SD-WAN 
 secure VPNs and rotates the unique session keys for each VPN every hour for up to 72
 hours. 

 ION devices are available in both hardware and software form factors that
 meet the needs of any location and any deployment scenario. You can deploy Prisma SD-WAN ION devices in Analytics Mode and Control Mode. 

 To deploy Prisma SD-WAN , set up your branch, data center
 sites and claim, assign, and configure the ION devices for your sites.

 ION device by following the Returned Merchandise Authorization (RMA) wizard, and how to
 upgrade the ION device software:
