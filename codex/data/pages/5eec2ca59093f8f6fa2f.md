 Learn Rendezvous Points (RPs) Dynamically 

 RP is a multicast-enabled device or node in the network that serves as a meeting point
 for multicast traffic in the network. Enable BSM for the ION device to learn RPs dynamically
 in Prisma SD-WAN . 

 Where Can I Use
 This? What Do I
 Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 Enable BSM for the ION device to learn RPs
dynamically. Use this feature for ION devices running software versions
6.0.1 or higher. 

 Select Configuration Prisma SD-WAN ION Devices Claimed Configure the device Routing Multicast Global Configuration . 

 Select Enable BSM . 

 Ensure that the RP and the multicast source are
reachable via specific routes (learned via static or dynamic routes)
as they cannot be resolved using default routes. 

 (Optional) Select Multicast RP Configuration to check the
RP addresses. 

 A
static RP configured on a branch site takes precedence over a static
RP configured at a data center site. 

 Field Description 

 RP Address Displays the IP address of the static RP or
the dynamically learnt RP. 

 Type 
 BSR —Indicates that
the RP is learnt dynamically via BSM. 

 Static —Indicates
that the RP is configured statically. 

 Name Displays the name given to a static RP. This
field will be blank for a dynamically learnt RP. 

 Address Displays the multicast group IP addresses to
which the RP caters.
