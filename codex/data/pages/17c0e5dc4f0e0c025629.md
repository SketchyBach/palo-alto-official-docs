 Importing Certificates from DigiCert 

 Next-Gen Trust Security provides the ability to import certificates from DigiCert. 

 If you are using a VSatellite connection to your DigiCert account, you can import certificates to Next-Gen Trust Security manually, or automatically on a schedule. 

 Note: Before you begin, make sure you have created a DigiCert CA . 

 Manually Import Certificates from DigiCert 

 Sign in to Next-Gen Trust Security. 

 Click Configuration > Certificate Integrations > Certificate Authorities . 

 Locate the certificate authority with the certificates you want to import, then click it to show the details. 

 Click Import . 

 The Status field changes to Running . You will need to refresh the page to see when this process finishes. 

 Imported certificates will be available in the inventory. Use the Imported from filter option to find certificates imported from this certificate authority. 

 Note: You can modify other options on the details page of the DigiCert CA. However, be aware that if you change the settings to disable Include Expired Certificates , it will not remove any existing certificates from your inventory. Any new expired certificates would not be imported after you disabled the related setting.
