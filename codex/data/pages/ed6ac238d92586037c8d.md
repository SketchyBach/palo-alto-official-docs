 inspect app-map 

 Use the inspect app-map command
to display the application ID to IP, port, or protocol mapping cache. 

 Command 

 inspect app-map 

 Options 

 detail Enter detail to display details
of app-map entries. 

 summary Enter summary to display brief
details of app-map entries. 

 filter Set a filter to display filtered
app-map entries using the following parameters: 

 srcv4 Enter the source IP address. 

 dstv4 Enter the destination IP address. 

 srcv6 Enter the source IP address. Release
 6.2.1 

 dstv6 Enter the destination IP address. Release
 6.2.1 

 srcport Enter the source port. 

 dstport Enter the destination port. 

 prot-nm Tab to select UDP, TCP, or ICMP. 

 prot-no Enter a protocol number ranging from 0 - 255. 

 Command Notes 

 Role Super, Read Only 

 Related Commands 

 clear app-map-dynamic 

 Introduced in Release 5.0.3
