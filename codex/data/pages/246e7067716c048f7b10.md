 Cortex MCP Server 

 The Cortex MCP Server lets you access Cortex's features directly within your Large Language Model (LLM) apps. Built on the Model Context Protocol (MCP), it enables you to query your Cortex tenant and conduct investigations using natural language, manage cases and issues with built-in tools, and create custom tools for your own workflows. It is provided as a downloadable file that you can install on a local machine or in a container and use with any MCP-compatible client. 

 Note: For more information, see the Cortex MCP Server documentation .
