 IPSec VPN Tunnel Management 

 Network > IPSec Tunnels 

 The following table describes how to manage your IPSec VPN tunnels. 

 Fields
to Manage IPSec VPN Tunnels 

 Add 

 Add a new IPSec VPN
tunnel. See IPSec
Tunnel General Tab for instructions on configuring the new
tunnel. 

 Delete 

 Delete a tunnel that
you no longer need. 

 Enable 

 Enable a tunnel that
has been disabled (tunnels are enabled by default). 

 Disable 

 Disable a
tunnel that you don’t want to use but are not, yet, ready to delete. 

 PDF/CSV 

 Export the IPSec Tunnel configuration in PDF/CSV format.
You can apply filters to customize the table output and include
only the columns you need. Only the columns visible in the Export
dialog are exported. See Export Configuration Table Data .
