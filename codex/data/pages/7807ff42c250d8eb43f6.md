 Prisma SD-WAN China 

 Learn about the Prisma SD-WAN China Controller support and features not supported in
 this release. 

 Palo Alto Networks announces the release of Prisma SD-WAN China Controller, a
 native SD-WAN orchestration solution hosted in mainland China. Designed specifically for
 globally distributed enterprises that require a local Controller presence in China. The
 solution provides a dedicated tenant infrastructure with operations completely
 independent from global controllers, allowing you to easily deploy and manage China
 branch sites.
