 Back up and Restore Cortex XSOAR 

 Back up and restore Cortex XSOAR 8.8 On-prem clusters. 

 Periodically backing up your environment enables you to back up and recover data such as incidents, playbooks, integrations, users, configurations, and settings. This is an efficient way to recover in case of a failure or data corruption or if you need to roll back to a previous minor version. 

 Note 

 Backups to a Network File System (NFS) server are supported. We strongly advise against using VMWare Snapshots, as they can significantly degrade disk performance and may cause the system to become unresponsive and require a restart.
