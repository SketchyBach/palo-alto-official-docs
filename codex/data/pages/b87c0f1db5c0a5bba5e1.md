 Manage Focused Workflows with Visions 

 This procedure guides you through selecting and managing task-focused views to
 optimize your workflow. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 The visibility of specific visions and the items within them is
 determined by your entitlements (SKU) and Role-Based Access
 Control (RBAC) permissions. 

 To access and utilize Visions, your Strata Cloud Manager tenant
 must have at least one vision-enabled product SKU provisioned. 

 Each of these licenses includes access to Strata Cloud Manager : 

 Prisma® Access 

 AIOps for NGFW Premium 

 Strata Cloud Manager (Essentials or Pro) 

 Quantum Security Subscription 

 Next-Gen Trust Security (formerly CLM) 

 Prisma Browser 

 The features and capabilities available to you in Strata Cloud Manager depend on which license(s) you are using. 

 Log in to Strata Cloud Manager . 

 Select the Visions switcher, located beneath the Strata Cloud Manager logo in the left navigation. This opens the
 Visions panel, listing all available visions to
 you. 

 Select a vision. This applies the filter and immediately transforms the Strata Cloud Manager user interface to align with the chosen vision. 

 Verify the transformed user interface. Confirm that the interface has updated
 to the focused experience: 

 The application header changes color. 

 The left navigation automatically hides irrelevant menus, displaying
 only the categories relevant to your vision. 

 The default landing page for the selected vision appears: 

 Quantum Resilience : The default landing
 page is Insights Security Quantum-safe Security . 

 Next-Gen Trust Security : The default
 landing page is Insights Certificate Insights 47-Day Readiness . 

 Secure Browser : The default landing page
 is Configuration Prisma Browser . 

 Use the global search bar to find pages or settings. 

 Contextual Results : The search prioritizes results relevant to
 your active vision. 

 Global Results : If a result belongs to a different vision or the
 global view, it will be visually distinguished. Selecting these results
 will automatically switch you back to the See Everything 
 view. 

 Restore the full navigation. 

 Select the Visions switcher. 

 Select See Everything . 
 This action restores the full and unfiltered Strata Cloud Manager 
 navigation and dashboard.
