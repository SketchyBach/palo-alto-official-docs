 User-ID Agent 11.0.4 Release Information 

 This User-ID agent 11.0.4 release has no new features or addressed issues. The
 User-ID agent 11.0.4 release was provided to maintain parity with the PAN-OS 11.0.4
 feature release. 

 User-ID Agent 11.0.3 Release Information 

 The following information is specific to the User-ID Agent 11.0.3 release. 

 User-ID Agent 11.0.3 Addressed Issues 

 The following table lists any issues that are fixed in User-ID agent 11.0.3
 release. 

 Issue Description 

 WINAGENT-1121 

 Fixed an issue where after upgrading to the 11.0.2 version of
 the User-ID agent, the policy rules for the User-ID AppID
 (paloalto-userid-agent) traffic were not matched correctly,
 resulting in dropped traffic. 

 User-ID Agent 11.0.2 Release Information 

 The following information is specific to the User-ID Agent 11.0.2 release. 

 User-ID Agent 11.0.2 Addressed Issues 

 The following table lists any issues that are fixed in User-ID agent 11.0.2
 release. 

 Issue Description 

 WINAGENT-1072 

 Fixed an issue that disrupted the User-ID credential agent
 access to the local LDAP server after a Windows Server
 reboot. 

 WINAGENT-1031 

 Fixed a memory leak issue in User-ID agent caused by
 mismatched certificate between NGFW and User-ID agent,
 preventing the agent from functioning. 

 WINAGENT-1002 

 Fixed an issue that caused the credential phishing service to
 fail when special characters were used in the name of an
 Active Directory object. 

 WINAGENT-981 

 Fixed an issue that caused the User-ID credentials agent 11.0
 to randomly crash when running on Window Server 2019. 

 User-ID Agent 11.0.1 Release Information 

 The following information is specific to the User-ID Agent 11.0.1 release. 

 User-ID Agent 11.0.1 Addressed Issues 

 The following table lists any issues that are fixed in User-ID agent 11.0.1
 release. 

 Issue Description 

 WINAGENT-890 

 Fixed an issue where the User-ID agent and TS agent
 certificates were set to expire on November 18, 2024. With
 this fix, the expiration date has been extended to January
 2032. 

 WINAGENT-886 

 Fixed an issue where if the Active Directory (AD) object
 contained unsupported characters, the Credential Service
 stopped unexpectedly.
