 System Settings: Access Experience Management 

 Learn how to manage Autonomous DEM users and remote sites 

 Where Can I Use
 This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Either one of these licenses: 

 Prisma Access license 

 ADEM Observability license or AI-Powered ADEM license 

 Use the Access Experience Management page to manage your
 Autonomous DEM users and remote sites. View the audit logs to see which administrators
 have authenticated to Prisma Access during the selected Time
 Range . 

 Refer to the Manage Autonomous DEM Agent Upgrades to learn
 about the Upgrade Options.
