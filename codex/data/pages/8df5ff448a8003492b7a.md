 Onboard a Kanban Tool App to SSPM 

 Connect a Kanban Tool instance to SSPM to detect posture risks. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 SaaS Security Posture Management license 

 Or any of the following licenses that include the Data Security license: 

 CASB-X 

 CASB-PA 

 For SSPM to detect posture risks in your Kanban Tool instance, you must onboard your Kanban Tool
 instance to SSPM. Through the onboarding process, SSPM logs in to Kanban Tool using
 administrator account credentials. SSPM uses this account to scan your Kanban Tool
 instance for misconfigured settings. If there are misconfigured settings, SSPM
 suggests a remediation action based on best practices. 

 SSPM gets access to your Kanban Tool instance by using Okta SSO credentials that you provide during the
 onboarding process. For this reason, your organization must be using Okta as an
 identity provider. The Okta account must be configured for multi-factor
 authentication (MFA) using one-time passcodes. 

 To onboard your Kanban Tool instance, you complete the following actions: 

 Collect Information for Accessing Your Kanban Tool Instance 

 Connect SSPM to Your Kanban Tool Instance 

 Collect Information for Accessing Your Kanban Tool Instance 

 To access your Kanban Tool instance, SSPM requires the following information, which you
 will specify during the onboarding process. 

 Item Description 

 User An email address of an Okta user account.

 Required Permissions: The user must have
 either Account administrator or Account owner permissions in
 Kanban Tool. 

 Password The password for the Okta user account. 

 Okta Domain The Okta subdomain for your organization. The
 subdomain was included in the login URL that Okta assigned to
 your organization. 

 MFA Secret Key A key that is used to generate one-time passcodes
 for multi-factor authentication. 

 Instance Host The hostname for accessing your Kanban Tool
 instance. The instance hostname is a unique subdomain included
 in the Kanban Tool URL. 

 As you complete the following steps, make note of the values of the items
 described in the preceding table. You will need to enter these values during
 onboarding to access your Kanban Tool instance from SSPM. 

 Identify the Okta user account that SSPM will use to access your Kanban
 Tool instance. The user must have either Account administrator or Account
 owner permissions in Kanban Tool. SSPM needs this permission to monitor your
 Kanban Tool instance. 

 Remember which account you will use to access your Kanban Tool
 instance through Okta SSO authentication from SSPM. You will provide
 the login credentials to SSPM during the onboarding process. 

 To access the administrator account using Okta
 credentials : 

 Identify your Okta
 subdomain . 

 Generate and copy an MFA
 secret key . 

 Make note of your organization's Kanban Tool instance hostname. 

 Make note of your organization's Kanban Tool instance hostname. After you
 log in to Kanban Tool, the instance hostname is a unique subdomain
 included in the Kanban Tool URL. The URL format is
 <instance_host> .kanbantool.com. 

 Connect SSPM to Your Kanban Tool Instance 

 By adding a Kanban Tool app in SSPM, you enable SSPM to connect to your Kanban Tool
 instance. 

 Log in to 
 Strata Cloud Manager . 

 Select Configuration SaaS Security Posture Security Applications Add Application and click the Kanban Tool tile. 

 Under posture security instances, Add Instance or,
 if there is already an instance configured, Add New 
 instance. 

 Enter the user credentials, Okta domain, and MFA secret key for accessing
 your Kanban Tool instance and Connect .
