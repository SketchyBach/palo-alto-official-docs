 Install the PA-400 Series Firewall 

 Learn to install a PA-400 Series firewall on a flat surface, wall, or 19-inch equipment
 rack. 

 The PA-400 Series next-generation firewall ships with the hardware required to
 install the firewall on a flat surface or on a wall. For select models, you can also
 order a rack mount kit to install the firewall in a 19-inch equipment rack.
