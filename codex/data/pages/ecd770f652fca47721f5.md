 DHCP Overview 

 Network > DHCP 

 Dynamic Host Configuration Protocol (DHCP) is a standardized
protocol that provides TCP/IP and link-layer configuration parameters
and network addresses to dynamically configured hosts on a TCP/IP
network. An interface on a Palo Alto Networks firewall can act as
a DHCP server, client, or relay agent. Assigning these roles to
different interfaces allows the firewall to perform multiple roles.
