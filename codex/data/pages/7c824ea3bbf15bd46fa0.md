 IT View of End User Notification Statistics 

 If the ADEM Self-Serve is enabled on a user's device, the IT administrator can monitor
 the notifications that the user receives. 

 Where Can I Use
 This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 Prisma Access license 

 ADEM or Strata Cloud Manager Pro 
 license 

 GlobalProtect or Prisma Access Agent license 

 After you have set up ADEM Self-Serve and added the Mobile Users and user groups that you want to
 send notifications to, you can view the user notification statistics over a
 Time Range that you select. You can also go back to the Insights Activity Insights Users page and make edits to the Self-Serve related areas. You can view the
 following: 

 Self-Serve-related
metrics for all users 

 Whether Self-Serve
is enabled for a user 

 Total number of notifications
sent to each user 

 Total CPU or memory
related notifications sent to a user 

 Total Number of WiFi
Notifications Sent to a User
