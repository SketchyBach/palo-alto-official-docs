 dump routing route 

 Use the dump routing route command
to display the routes learned from BGP peers. 

 Command 

 dump routing route ( vni= | peer-ip = Peer IP ) 

 Options 

 vni Enter vni value to display routes learned from specific BGP peers. 

 peer-ip Enter an IP address to display routes learned from a specific BGP peer. 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands — 

 Introduced in Release 5.0.1 

 Example 

 dump routing route prefix=3001:10:2:202::2
Routes learnt from view 1 for prefix 3001:10:2:202::2:
View/Vrf 1 is unknown
