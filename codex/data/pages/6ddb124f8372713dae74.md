 ION 1000 Front Panel with LEDs 

 The LED lights on the Prisma SD-WAN ION 1000 indicates
the status of various parameters. 

 The
 Prisma SD-WAN ION 1000 LEDs indicate the following status: 

 Icons Description 

 Displays disk status. 

 Orange light (Blinking)—Disk activity. 

 Displays controller connectivity status. 

 Green light—Connected. 

 Red
light—Not Connected. 

 Displays power status. 

 Green light—Powered On. 

 No
light—Powered Off.
