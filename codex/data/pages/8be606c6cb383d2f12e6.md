 Set up IGEL UMS for Integration 

 Configure IGEL UMS to enable integration with Device Security and 
 Cortex XSOAR .

 It's assumed you already have IGEL Universal Management System 
 ( IGEL UMS ) set up. The integration relies on 
 IGEL UMS version 6.07 or higher and the IGEL 
 Management Interface (IMI) API V3. Ensure that your IGEL UMS 
 solution meets the 
 IMI API V3 Prerequisites .

 When integrating IGEL UMS with Device Security and 
 Cortex XSOAR , you need to provide Cortex XSOAR with access to 
 an IGEL account that has administration permissions. 
 Cortex XSOAR uses the account to poll IGEL for 
 information about endpoints.

 For more information about creating and managing IGEL UMS 
 administrator accounts, see 
 Administrator Accounts in the IGEL UMS .

 Log in to your IGEL UMS console.

 Go to System Administrator Accounts to bring up the Administrator accounts popup.

 Select New to bring up the New Administrator pop 
 up, and from there configure the new administrator account.

 Cortex XSOAR will need the administrator account and password 
 you create to call the IMI API.

 Enter a username for the account.

 Create a password for the account.

 Confirm the password.

 Select Allow all to save the new account 
 and ensure it has the permissions needed for the integration.
