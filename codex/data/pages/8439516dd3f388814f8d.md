 Configure IoT SNMP Start Nodes 

 Learn how to configure IoT SNMP start nodes in Prisma SD-WAN . 

 Where Can I Use
 This? What Do I
 Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 Device Security license 

 Prisma Access Remote Networks license 

 You can configure a branch site ION device or a DC ION device as a start
 node for the discovery process. In this configuration you can specify a list of IP
 addresses (IPv4) that can be used as the start address for network discovery and
 subsequent device discovery. 

 Each site supports a maximum of 128 such starting endpoints. It also
 supports a scope (per starting address) that limits the discovery to a set of
 devices within the specified scope. The IP addresses configured in the list should
 be reachable from the ION devices that are associated with the site. 

 Select Configuration Prisma SD-WAN Branch Sites <Name of the site> . 

 In the IOT Device Visibility section, under
 IoT SNMP Start Nodes , click Configure IoT
 SNMP Start Nodes . 

 Click Add Start Node and add a
 Name and a Start Node . 

 Start Node is the IP address that the ION device uses as a
 starting point for network and device discovery. 

 (Optional) Enter a Description and
 Tags . 

 (Optional) Enter separate subnets for Subnets
 Scope . 

 A maximum of eight subnets can be entered per start node. This
 limits the discovery to a set of devices within the specified scope. 

 Click Save .
