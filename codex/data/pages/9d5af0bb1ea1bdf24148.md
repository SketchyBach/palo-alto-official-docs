 External Data Management 

 FEATURE 

 DESCRIPTION 

 Unified data onboarding experience 

 Save time and reduce complexity by managing all data sources and Marketplace integrations from a single, streamlined location. We renamed the Data Sources page to Data Sources & Integrations to eliminate the need for multiple portals when configuring content like correlation rules, dashboards, and playbooks. This unified workflow creates a more efficient experience for managing all your ingestion and automation needs. Note : This change merges the functional scope of existing permissions. Users, user groups, and API keys with View/Edit permissions for either Data Sources or Integrations now have full access to manage both on the unified page. Review your administrative assignments to ensure they align with this expanded access. 

 Enhanced Okta data source 

 Gain deep visibility into identities and permissions with our enhanced Okta data source integration. This update provides comprehensive insights into users, groups, and applications, specifically highlighting the permissions granted to Okta users in cloud environments. By centralizing group memberships and access details, you can more effectively monitor and secure your identity landscape.
