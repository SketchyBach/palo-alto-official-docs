 CVE-2025-31324 - SAP NetWeaver Visual Composer playbook 

 This playbook addresses CVE-2025-31324, a critical vulnerability in SAP NetWeaver Visual Composer that allows unauthenticated remote code execution. By providing automated detection, threat hunting, and remediation steps, this playbook helps organizations protect their business-critical SAP systems from active exploitation and potential data breaches.
