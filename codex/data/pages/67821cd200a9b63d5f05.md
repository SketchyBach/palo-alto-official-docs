 Cloud Identity Agent User Interface 

 Describes the user interface of the Cloud Identity agent. 

 The following table describes the components of the
agent user interface and their functions. 

 Pane/Component Description 

 File 
 Debug —The Cloud
Identity agent generates logs for events of the selected severity
level and above. The levels, from highest to lowest, are: Error, Warning,
Information (default), Debug, and Verbose. For example, if you select
Debug, the logs will display debug, information, warning, and error
events. If you select None, the Cloud Identity agent does not log
events at any level. 

 Exit —Closes the Cloud Identity agent
window but continues to connect to the Cloud Identity Engine. Before exiting,
a confirmation popup notifies you of any uncommitted changes. 

 Help 
 Contents —Displays
the help system for the Cloud Identity agent. 

 About —Displays a window with the Palo
Alto Networks website, copyright date, and the version of the Cloud Identity
agent currently installed on the server. 

 Save Save the configuration changes to the Cloud Identity
agent without applying them. If changes are saved but not applied,
they are automatically applied the next time the agent starts. 

 Commit Apply the configuration changes to the Cloud Identity
agent. After you commit the changes, the agent restarts and your
changes are applied to the configuration. 

 Exit Closes the Cloud Identity agent window but continues
to connect to the Cloud Identity Engine. Before exiting, a confirmation
popup notifies you of any uncommitted changes. 

 Cloud Identity Configuration Configure the connection to the Cloud Identity Engine
and view whether the agent is currently running. For more information,
see Cloud Identity Configuration . 

 LDAP Configuration Configure the connection to one or more directory server
sources. For more information, see LDAP Configuration . 

 Monitoring View the logs and the agent’s connection status
to the Cloud Identity Engine. For more information, see Monitoring .
