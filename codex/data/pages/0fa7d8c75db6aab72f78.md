 Activate Device-Based Prisma SD-WAN License for a New User 

 Learn how to activate device based Prisma SD-WAN license for a new user. 

 Where Can I Use
 This? What Do I Need? 

 Prisma SD-WAN (Managed by Strata Cloud Manager ) 

 Prisma SD-WAN 

 You can activate the Prisma SD-WAN license on the Prisma SD-WAN
 Hub using a magic link that is typically received via an
 email. 

 Access the magic link provided by your accounts team. 

 Log in to the Strata Cloud Manager using your credentials. The system
 automatically directs to the License Activation page. 

 The page lists all the licenses assigned to you. Of these licenses,
 you can assign all or partial licenses. 

 Select a Customer Support Account . 

 Specify the tenant for the license to be activated. For a new user, you will
 need to create a new tenant. 

 Select a Region . 

 In the Assign Prisma SD-WAN License section, allocate
 all or a partial number of licenses. 

 Review the license details and confirm terms and conditions. 

 Select Activate License 

 Upon successful activation, the Prisma SD-WAN Hub provisions or
 updates the tenant with the new license details. This process may take some
 time.
