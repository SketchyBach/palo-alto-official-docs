 dump controller status 

 Use the dump controller status command
to display the status of the ION device’s connection to the controller
such as connected, partially connected, or not connected. 

 Command 

 dump controller status 

 Options 

 None 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands — 

 Introduced in Release 4.4.1 

 Example 

 dump controller status
