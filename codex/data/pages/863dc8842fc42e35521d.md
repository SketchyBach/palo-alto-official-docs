 Undeploy an HSF Cluster 

 Instructions to undeploy an HSF Cluster. 

 Where Can I Use This? What Do I Need? 

 Prisma AIRS 

 Software NGFW Credits 

 HSF subscription license 

 To undeploy a HSF cluster, select the HSF cluster and click Undeploy .
 Should the initial attempt to undeploy fail, the user may re-engage the button,
 prompting the plugin to initiate a retry of the deletion workflow. 

 Undeploy triggers the following actions: 

 ​​Delicenses the virtual machines. 

 Removes virtual machines, dummy port groups, and vSwitches created
 by the plugin. 

 Deletes Panorama configurations established by the plugin for the
 deployment. 

 Disassociates devices from Device Groups (DG), Template
 Stacks (TS), and Log Collector Groups (LCG). 

 Deletes Device Groups (if plugin-created). 

 Deletes Template Stacks (plugin-created). 

 Deletes clusters (plugin-created). 

 Removes devices listed under managed devices. 

 Commits changes. 

 Removes the corresponding database entry in the plugin for the
 deployment.
