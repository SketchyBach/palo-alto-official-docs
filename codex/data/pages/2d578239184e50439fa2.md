 INC_RN_DNS_SERVER_UNREACHABLE_ALL_PA_LOCATIONS 

 Learn about the INC_RN_DNS_SERVER_UNREACHABLE_ALL_PA_LOCATIONS incident. 

 Incident Code 

 INC_RN_DNS_SERVER_UNREACHABLE_ALL_PA_LOCATIONS 

 Title Template 

 DNS server {target} is unreachable for RN 

 Category 

 Network Services 

 Subcategory 

 DNS 

 Description 

 The DNS server is unreachable from the Remote Network across all Prisma Access locations. This widespread issue can lead to DNS resolution failures for users or devices in all locations, impacting their ability to resolve domain names to IP addresses for accessing resources. It is critical to investigate and address this incident promptly to restore DNS functionality and ensure seamless network access for users across all Prisma Access locations. 

 Raise Condition 

 Incident is Raised when 85% of the instances can not reach the DNS server for the last 12 minutes across all the locations for the tenant 

 Clear Condition 

 Incident is Cleared when instances are able to the DNS server for the last 6 minutes for the tenant
