Create an inventory report
POST
https://api.prod.koi.security
/api/external/v2/reports

Creates an async report job. Returns report_id to poll for status. When completed, download_url is available in the status response.

Authorizations
bearerAuth

string
required
Bearer authentication header of the form Bearer <token>.

application/json
filters
object · InventoryFilterRuleGroupDto

report_type
string · enum
required

Report type: unique item (one row per extension) or instance (one row per installed instance)

Example: inventory_by_extension
Possible values: inventory_by_extensioninventory_by_instanceagent_activity_logs

Get report status
GET
https://api.prod.koi.security
/api/external/v2/reports/
{report_id}

Retrieves the status of a report. When status is completed, download_url contains a presigned link (expires in 12 hours).
