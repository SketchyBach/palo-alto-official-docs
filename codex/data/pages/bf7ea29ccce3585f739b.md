 What’s New in the Activation ConsoleHub 

 Role Migration Notes 

 If you used the Activation Console (previously called the Cloud Services
portal) prior to April 2019, these are role management changes of
which you should be aware. 

 If you were a user of the Activation Console or if you managed the activation
of Application Framework apps prior to April 2019, then you will
experience significant changes with how you manage user roles. For
Application Framework apps, you no longer manage user roles in the
Customer Support Portal. Instead, you manage these roles in the
Cloud Services Portal. Additionally, the list of roles has changed.
In some cases, roles are collapsed in to a single role, while in
other cases, the list of roles available for an app has changed.
Also, some, but not all, Application Framework apps and services
names have changed. 

 For a description of the new Role Management user interface,
see Manage App Roles .

 Role Management
Changes 

 Prior to April, 2019, you managed all roles in
the Customer Support Portal. Now you manage roles specific to Cortex
apps and other properties using the Activation Console . All other role management remains
in the Customer Support Portal. 

 Where you previously had
a role that was specific to an app (for example, the Magnifier role),
you now have a single role (Instance Administrator) that is granted
to a user for a specific app. 

 Some apps (for example, Cortex
XDR) implement a constellation of roles that you can grant to a
user. These roles are managed in the Activation Console , but you should refer to
the product documentation for the app to obtain details on these
app-specific roles.
