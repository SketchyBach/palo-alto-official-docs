 View Device Metrics for Prisma Browser 

 The ADEM Browser Extension collects endpoint hardware specifications and browser
 resource metrics, displayed as device attributes and dynamic health trend charts. 

 Where Can I Use This? What Do I Need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 Prisma Access license 

 ADEM or Strata Cloud Manager Pro 
 license 

 ( Browser-Based Real User Monitoring (RUM) ) Prisma Browser 
 license 

 When the ADEM Browser extension is active on a user's browser, it collects two categories
 of metrics: static hardware attributes gathered once at session start and dynamic
 browser resource metrics gathered every 30 seconds. Static attributes appear in the
 Device Details view on the User
 Details page. Dynamic metrics appear as trend charts in the
 Device Health Metrics section under Synthetic
 Trends . 

 Device Details 

 The Device Details view displays six hardware specification
 cards in a single row. The previous Hardware card is
 replaced by separate CPU , Memory , and
 Disk cards. Browser Type and Browser Version are combined
 into a single Browser card. 

 Card / Field Description 

 DEVICE — Device Name Hostname of the monitored endpoint. 

 OS — OS Version Full operating system version string including the
 build number. For example, macOS 15.2 (24C101) or
 Windows 11 23H2 (22631.4890) . 

 CPU — CPU Model Processor model name as reported by the operating
 system. For example, Apple M2 or Intel Core
 i5-1235U . If unavailable, displays as
 Unknown . 

 CPU — CPU Cores Number of logical CPU cores available to the
 operating system, including hyperthreading virtual cores. Virtual
 machines report the core count allocated to the VM. 

 MEMORY — Total RAM Total physical memory installed on the device,
 rounded to the nearest whole GB. 

 DISK — Hard Disk Total Total capacity of the primary OS volume (normally
 C:\ on Windows, / on macOS). External drives,
 network drives, and secondary volumes are excluded. 

 DISK — Hard Disk Free Available space on the primary OS volume. On macOS
 with APFS, purgeable space counts as free. 

 BROWSER Browser type and version. 

 Static metrics are collected once at session start and updated when a change is
 detected on the device. 

 Device Health Metrics 

 The Device Health Metrics section of Synthetic
 Trends includes four new browser resource trend charts alongside the
 existing Memory, CPU, Battery, Disk Usage, and Disk Queue Length charts. Select a
 metric's check box to show or hide its trend chart. 

 Metric Description 

 Tabs Open Count of all open browser tabs across all windows of
 the current browser instance. 

 Browser Windows Count of distinct browser windows open, including
 incognito and private windows. Each browser application (for
 example, Prisma Browser and Chrome running simultaneously) is
 counted separately. 

 Avg Memory per Tab Total tab renderer process memory divided by the
 number of open tabs. Extension processes, the GPU process, and
 utility processes are excluded from the calculation. If all tabs are
 closed, the value is 0. Discarded tabs report approximately 0 MB and
 reduce the average. 

 Total Browser Memory Sum of all memory consumed by the browser
 application, including tab renderers, extension processes, the GPU
 process, utility workers, and the browser main process. This is
 browser-specific memory, not system-wide memory. 

 All four browser metrics are collected every 5 minutes. Browser metric charts do not
 include threshold lines or notification badges. If the browser extension stops
 reporting, the trend line shows a gap for that period. 

 The Top 5 Tabs Consuming Most Memory section appears below
 the Avg Memory per Tab chart. It lists the five tabs with the highest memory usage
 at the selected point in the trend, showing the full page URL and memory in MB.
 Discarded or suspended tabs display approximately 0 MB and are labeled as
 (suspended) . Select the section header to expand or collapse the list.
 The list updates every 30 seconds, correlated with the Avg Memory per Tab
 trend.
