 Debug Commands 

 config syncd 

 Use the config syncd command to enable or disable the syncd
 service on the branch device. 

 Enable: When you enter this command, the service starts immediately and is configured to
 start automatically after each system reboot. 

 Disable: When you enter this command, the service stops immediately and remains disabled
 even after a system reboot. 

 Because standalone branch devices don't have a High Availability (HA) peer to synchronize
 with, you only need the syncd service for branch HA deployments where
 two devices operate as an active-standby pair. 

 Command 

 config syncd (enable | disable) 

 Options 

 enable Enter the config syncd enable, the service starts
 immediately and is configured to start automatically after each
 system reboot. 

 disable Enter the config syncd disable, the service stops
 immediately and remains disabled after a system reboot. 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands 

 dump syncd status 

 Introduced in Release 6.6.1 

 Example 

 config syncd disable
Syncd disabled. 

 config syncd enable
Syncd enabled.
