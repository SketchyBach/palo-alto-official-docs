 Access Zoom Application Experience Data 

 View the data for the Zoom application experience across your entire organization on
 the Application Details page or for an individual user on the
 User Details page. 

 You must have purchased a Zoom Quality of Service Subscription
 (QSS) as an add-on from Zoom in order to enable this feature. You can use Zoom QSS along
 with the standard ADEM license. 

 ADEM shows you the Zoom application experience data at an organizational level and also
 at an individual user level. You can navigate to this data from the following
 dashboards: 

 Summary 
 When you select the Zoom app
 card in the Top 20 applications with lowest to highest experience
 score widget, the Application Details 
 page opens. By default, the Synthetics tab is selected,
 where you can see the Zoom app experience across your organization relative to
 all other monitored apps. To view data exclusively for the Zoom app across your
 organization, select Zoom Performance Analysis . 

 Monitored Mobile Users User Details 
 To view the Zoom data for a specific Mobile User, select the
 User Name in the Monitored Mobile User
 Devices table to open the User Details 
 page. Select the Zoom application card in the Application Experience
 Details widget to expose the Zoom Performance
 Analysis button. The Synthetics tab shows
 you the Zoom app experience relative to all monitored apps for the user. To view
 data exclusively for the Zoom app, select Zoom Performance
 Analysis button, if not already selected. 

 Applications Application Details Experience tab 
 Select the Zoom Application Name in the
 Total Applications table under the
 Applications tab to open the Application
 Details page. By default, the Synthetics 
 tab is selected, which displays the Zoom app experience relative to all
 monitored apps across the organization. To view data exclusively for the Zoom
 app, select Zoom Performance Analysis . 

 To edit the
 Zoom app test, select the Zoom Application Test Name in
 the Application Tests tab. 

 To access the Zoom experience metrics for a Mobile User, see Zoom Performance Analysis for Mobile Users .
 For Zoom metrics relative to other apps in an organization, see Zoom Performance Analysis for an Application .
