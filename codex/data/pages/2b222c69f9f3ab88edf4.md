 inspect routing multicast fc site-iface 

 Use the inspect routing multicast fc site-iface command
to inspect the local and remote site id published data of the multicast. 

 Command 

 inspect routing multicast fc site-iface (local id= | remote-site id=)

 Options 

 local id Enter local id to display the published data
of the multicast. 

 remote-site id Enter remote-site id to display the published
data of the multicast. 

 Command Notes 

 Role Super, Read Only 

 Related Commands — 

 Introduced in Release 6.0.1 

 Example 

 inspect routing multicast fc site-iface local id=1650537302974020296
