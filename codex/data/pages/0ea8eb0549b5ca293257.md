 Replace a PA-7500 Series Firewall NPC in a NGFW Cluster 

 Learn how to remove and replace a PA-7500 NPC in a NGFW clustering
 configuration. 

 Disconnect all connections to and from the NPC. 

 If this NPC is still functioning prior to
 replacement, any traffic using orphan ports or LAGs may encounter
 interruption during this procedure. 

 Unlock the NPC and remove it from the
 chassis. 

 Install the replacement NPC.

 Reconnect all the connections to and from the new NPC, including any
 transceivers that were previously installed. 

 Verify the slot and serial number of the new NPC using the following CLI
 command: show chassis inventory . 

 Monitor the NPC boot process using the following command: show
 chassis status slot [0] where [0] is the number of the slot in
 which the new NPC is installed. 

 Once the NPC is up, verify that all existing links and network connections are
 working.
