 Learn more about migrating to the latest broker VM image 

 Following is the recommended process for migrating to the latest Broker VM image installed with Debian 13. This process ensures that you can upgrade to the latest supported Broker VM versions and continue to benefit from new features. 

 These procedures are recommended for all brokers that were deployed with a Broker VM image, downloaded prior to February 22, 2026 (installed with Ubuntu 20.04 or earlier).
