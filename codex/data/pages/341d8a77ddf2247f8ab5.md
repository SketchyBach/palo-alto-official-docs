 Set up Jira Cloud for Integration 

 Configure Jira Cloud API tokens to enable integration with Device Security .

 It is assumed that you already have Jira Cloud set up in your 
 organization.

 Log in to your Atlassian account and access 
 View all apps Account settings to open the account settings page.

 Select Security , and then under the API tokens section, 
 select Create and manage API tokens to go to the API 
 Tokens page.

 Select Create API token to bring up the Create an API 
 token popup, and then configure your API token.

 Enter a Name .

 Set the date that your token Expires on .

 When you generate a new API token after the current one expires, 
 you will need to use the new API token to update the integration 
 instance in Cortex XSOAR .

 Create your API token to go to the Copy your 
 API token screen in the popup.

 Copy your API token into a secure location.

 After you close the workflow, you cannot view the API token again. If you 
 forget the API token, you will need to generate a new one and update the 
 integration instance in Cortex XSOAR .

 Click Done to close the popup.
