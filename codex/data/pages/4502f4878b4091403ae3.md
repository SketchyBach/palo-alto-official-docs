 Enable or Disable a Multitenant Notifications Profile 

 Learn how to enable or disable multitenant notifications profiles manually or by
 using the quick start template through the Strata Multitenant Cloud Manager . 

 Where Can I Use This? What Do I Need? 

 Strata Multitenant Cloud Manager 

 Prisma Access license 

 Identity & Access
 role : Multitenant Superuser or Superuser for
 managing 

 Other roles have read access to profiles and can view the
 notification feed, including performing actions 

 After you have added a notifications profile , you can enable
 or disable the profile. 

 Enable a Profile 

 Notifications profiles are disabled by default. You
 need to enable a profile before you can see email or webhook notifications for the
 profiles you configure. 

 Access the 
 Strata Multitenant Cloud Manager and select the bell
 icon . 

 Select the Settings tab. 

 Toggle Enabled to On . 

 After you enable a profile, the Status displays
 success or failure. 

 Optional If there is a failure enabling the profile on any of the
 tenants, your options are to try again or to file a support ticket. 

 Disable a Profile 

 Notifications profiles are disabled by default. You
 need to disable a profile before you can delete it. 

 Access the 
 Strata Multitenant Cloud Manager and select the bell
 icon . 

 Select the Settings tab. 

 Toggle Enabled to Off .
