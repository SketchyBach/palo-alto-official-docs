 Access the Network Trust Security Page 

 Navigate to the Network Trust Security page to view and manage certificates synced
 from Strata Cloud Manager. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 Secure-Flex Credits 

 One of these roles for Strata Cloud Manager Shared Services: Network Administrator, Security Administrator, Superuser, View Only Administrator, Tier 1 Support, Tier 2 Support 

 See About Roles and
 Permissions 

 The Network Trust Security page provides centralized visibility into certificates used across your Strata Cloud Manager configuration. When you first access this page, certificates sync from your configuration to the Next-Gen Trust Security inventory. The page displays certificate health widgets, expiration warnings, and certificate management recommendations. You can learn more about Strata Visions and focused workflows. 

 Navigate to Network Trust Security. 

 Log in to Strata Cloud Manager. 

 Select Insights Security Network Trust Security . 

 View certificate inventory. 

 The page displays: 

 Summary widgets : Certificate count, expiration warnings, cryptographic health status 

 Recommendations : Suggested actions to improve certificate security 

 Certificate table : All synced certificates with status (managed/unmanaged), expiration date, and usage locations 

 From the Network Trust Security page, you can: 

 View certificate details, including expiration dates and cryptographic settings 

 Manage certificates to enable Next-Gen Trust Security lifecycle tracking - see Manage Certificates in Next-Gen Trust Security 

 Renew managed certificates using enterprise-approved CAs - see Renew Certificates Using Next-Gen Trust Security 

 Access the full Next-Gen Trust Security certificate inventory for advanced management - see Manage Certificates in Your Inventory
