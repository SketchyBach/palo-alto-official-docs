 Migrate from Custom Dashboards 

 Legacy Custom Dashboards in Strata Cloud Manager are retired. Use this guide to find
 your data in AI Canvas pre-built widgets and Activity Insights. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 Strata Cloud Manager
 Pro license 

 Strata Cloud Manager® has retired the Custom Dashboards feature. Because Custom
 Dashboards and AI Canvas run on different architectures, there is no automated migration
 script — you'll need to rebuild your dashboards manually. To minimize disruption, the
 legacy widgets you relied on have been recreated as pre-built widgets in the AI Canvas
 library and are available immediately. The sections below map each legacy widget to its
 replacement so you know exactly where to find your data. 

 Custom Dashboards are permanently removed on July 31, 2026. After
 this date, you will no longer be able to access your saved Custom Dashboards or their
 data. Complete your migration to AI Canvas before July 31, 2026. 

 Find Your Data in AI Canvas Pre-Built Widgets 

 The following legacy Custom Dashboard widgets have been rebuilt and are available as
 pre-built widgets in the AI Canvas widget library. To access them, select Strata Canvas AI Canvas , open the widget library, and browse the pre-built widget

 Find ATP Threat Data in Activity Insights 

 The following legacy ATP widgets are not available as AI Canvas pre-built widgets.
 This data already exists in the Activity Insights module: 

 Threat Overview 

 Host Generating Cloud-Detected C2 Traffic 

 Hosts Targeted by Cloud-Detected Exploits 

 To find this data, select Insights Activity Insights Threats . 

 No Longer Available 

 The following legacy Custom Dashboard widgets and categories are not available in AI
 Canvas: 

 Applications Using Non-Standard Ports (App Usage) — This widget is not
 supported in AI Canvas and has no direct replacement. 

 Compliance Summary — All Compliance Summary category widgets have been
 dropped. Compliance data is not available in AI Canvas at this time. 

 DNS Security — All DNS Security dashboard widgets have been dropped. DNS
 Security data is available through the dedicated DNS Security dashboard,
 currently in Beta. 

 WildFire® — All WildFire widgets have been dropped due to minimal
 usage. 

 Incidents — The Incidents category is no longer active. 

 DLP and Device Security — These categories are under evaluation.
 Availability in AI Canvas will be confirmed once data source verification is
 complete.
