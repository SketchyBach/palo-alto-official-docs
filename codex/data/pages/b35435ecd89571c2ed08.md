 dump app-l4-prefix table 

 Use the dump app-l4-prefix table command
to display TCPPROXY L4-Prefix-Lookup table information based on
L4 rules of TCP, UDP, or non-TCP-UDP. 

 Command 

 dump app-l4-prefix table (all | l4Rule=tcp | udp | ip ) 

 Options 

 all Enter all to display summary of all the TCPPROXY L4-Prefix-Lookup
table. 

 l4Rule Enter rule to view the TCPPROXY L4-Prefix-Lookup table
matching the rule. 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands — 

 Introduced in Release 5.4.1 

 Example 

 dump app-l4-prefix table all
