 The information below is for reference only if you're maintaining pre-6.0.1
 deployments. 

 If you are a new user starting with Release 6.0.1, you can configure
 only stacked security policies. You will not be able to view or access
 Security Policies (Original) . If you have configured original
 or legacy policies, you have to migrate these legacy policies to stacked
 policies before you can upgrade your device to Release 6.0.1. 

 Prisma SD-WAN focuses on security policies that control access to applications
 through zone-based firewalls. Prisma SD-WAN provides a stateful, flexible,
 application-aware and enterprise Zone-Based Firewall (ZBFW) that secures an
 ever-changing WAN perimeter, facilitates segmentation within a branch. ZBFW translates business security intent and
 requirements into configurable security policy rules that determine connectivity and
 secure access, ensuring compliance across different network circuits and interfaces.
