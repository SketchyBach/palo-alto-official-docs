 Informational Alerts 

 Learn about informational alerts that require an Prisma Access 
 license. 

 Where can I use this? What do I need? 

 Prisma Access (Managed by Strata Cloud Manager) 

 Prisma Access (Managed by Panorama) 

 Prisma Access license 

 Strata Cloud Manager uses the Unified Incident Framework to
 centralize incident management and provide a more contextual experience. The
 product-specific alerts and incidents are now located under Incidents . The previous Alerts & Incidents
 dashboard remains available in read-only mode for reference. 

 Informational alerts notify you about upcoming software upgrades and status for upgrades
 that are in progress or completed. To view data about informational alerts in Strata Cloud Manager , select Incidents & Alerts Prisma Access Incidents & Alerts Informational Alerts . 

 This section lists informational alerts , which require a Prisma Access license. For more information, see Prisma Access Overview in the Prisma
 Access Administration Guide .
