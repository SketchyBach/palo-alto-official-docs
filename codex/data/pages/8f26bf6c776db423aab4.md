 Device Security subscription

 Device Security X subscription

 The following list includes all known issues that impact a Device Security Network
 Discovery plugin 2.0 release. This list includes both outstanding issues and issues that
 are addressed, as well as known issues that apply more generally or that are not
 identified by a specific issue ID.

 DIT-45871 

 In some cases, the SNMP neighbor discovery job has a parsing issue when trying
 to get LLDP/CDP neighbors. This causes the SNMP crawl to error out.

 This issue is resolved in Network Discovery plugin 2.0.2. 

 BAN-18017 

 When changing the Network Discovery plugin config, the previous job continues to
 run. This prevents a new job from being run.

 This issue is resolved in Network Discovery plugin 2.0.1.
