 Ports Used for Infrastructure 

 Network ports used by PAN-OS firewall infrastructure components for proper network
 configuration and troubleshooting. 

 The firewall and Panorama use the following ports for
infrastructure functions. 

 Destination Port 

 Protocol 

 Description 

 111 

 TCP/UDP 

 Port used as a port mapper. 

 23 

 TCP/UDP 

 Port used for the Telnet application protocol. 

 69 

 TCP/UDP 

 Port used for TFTP. 

 2049 

 TCP/UDP 

 Port used for the Network File System (NFS). 

 28260 

 TCP 

 Port used by internal sysd IPC communication
for internal processes. 

 28261 

 TCP 

 Port used by internal md applications
to manage internal processes. 

 Dynamic 

 TCP/UDP 

 Dynamic port used by NFS operations to a host dataplane file system
 in the management plane.
