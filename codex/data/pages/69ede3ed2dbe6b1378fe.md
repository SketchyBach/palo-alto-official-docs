 Line Card Failure 

 Incident Code 

 INC_NGFW_LINE_CARD_FAILURE 

 Severity 

 High 

 Category 

 Device 

 Subcategory 

 Hardware 

 Description 

 A software or hardware issue that has caused the card to enter a failure state
 has been detected. 

 Raise Condition 

 This incident triggers when the error "Unable to detect FPGA on PCIe bus" is
 detected in one of the line cards in the chassis 

 Clear Condition 

 The Incident clears if after taking the recommended remedial actions the FPGA is
 detected.
