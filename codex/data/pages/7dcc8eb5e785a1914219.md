 SSPM Administrator Activity Logs 

 Release Date: August 2026 
 | 
 Last Updated: August 2026 

 To audit administrator activity and to track changes to SaaS Security Posture Management (SSPM), you need a centralized, chronological record of administrative actions. To address this need, SaaS Security captures actions performed by administrators and records them in an activity log. From the Activity Log page , which previously contained information for other SaaS Security components, you can view SSPM information. 

 From the Activity Log page, you can view the record of administrator actions. Activity logging tracks events across several key areas, including: 

 Application Events: When an administrator onboards an application, modifies application configurations, or deletes a connection. 

 Policy Events: When an administrator creates, updates, or manages policies. 

 Report Download Events: When an administrator downloads compliance, rule, or configuration data. 

 Configuration Setting Events: When an administrator modifies a configuration setting for a managed application instance. 

 Third-Party Plugins Events: When an administrator manages or reviews third-party plugins and their access permissions. 

 Ticketing Events: When an administrator creates a ticket in an issue tracking system from within SSPM. 

 You can filter the Activity Logs table to focus on information of interest. For example, you can filter the Activity Logs table to view logged activity for a single administrator or for a specific time frame.
