 inspect dpdk vrf 

 Use the inspect dpdk vrf command
to inspect the dpdk route table for a specific vrf configured on
the device. 

 Command 

 inspect dpdk vrf vrf= 

 Options 

 None 

 Command Notes 

 Role Super, Read Only 

 Related Commands 

 inspect dpdk ip-rules 

 Introduced in Release 5.6.1 

 Example 

 inspect dpdk vrf vrf=2010
 # - Preferred, * - Active, > - selected
