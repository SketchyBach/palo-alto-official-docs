 Understand and prioritize CI/CD pipeline assets 

 Access, review, filter, and prioritize CI/CD pipeline assets. 

 How to access CI/CD pipeline assets 

 Under Inventory , select All Assets → Code → CI/CD Pipelines . 

 The CI/CD Pipelines page includes a dashboard and an inventory. 

 CI/CD pipeline dashboard 

 The dashboard displays connected CI/CD providers and their discovered pipelines. Providers include GitHub Actions, GitLab CI, Jenkins, Azure Pipelines, Bitbucket Pipelines, CircleCI, and AWS CodeBuild. 

 Select a provider to filter the inventory table. 

 CI/CD pipeline asset inventory 

 Select Menu Settings to view additional properties, including last job execution time and file contributors. 

 Property 

 Description 

 Name 

 The pipeline name discovered through the CI/CD integration. It is the primary asset identifier. 

 CI/CD Provider 

 The platform hosting the pipeline. 

 CI Instance 

 The CI/CD platform instance that executes the pipeline. 

 Repository 

 The parent repository containing the pipeline definition. 

 VCS Provider 

 The VCS provider hosting the parent repository. 

 CI File Path 

 The path to the pipeline definition file. 

 Business Application Names 

 Applications inherited from the parent repository, including business criticality. 

 Filter and prioritize CI/CD pipelines 

 Use search and filters to narrow the inventory by operational and security metadata. 

 High-priority filtering workflows 

 Use these filters to prioritize remediation: 

 Prioritize active workflows: Sort Last Job Execution by most recent. Focus on pipelines that actively run. 

 Scope by CI/CD provider: Filter by CI/CD Provider or select a dashboard provider. This isolates provider-specific misconfigurations.
