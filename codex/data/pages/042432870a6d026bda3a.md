 Description

 (Windows) 

 Fixed an issue to improve the Cortex XDR agent security and stability posture. 

 CPATR-26204 

 (Windows) 

 Fixed an issue where an Access Denied error may be displayed to the user during system boot.

 Fixed an issue that may have caused the agent to prefer IPV4 interfaces in dual-stack environments, causing agent disconnections.

 Fixed an issue where a post-detection alert may be listed in the Alerts Table incorrectly.

 Fixed an issue that on rare occasions may interrupt MS Office applications.
