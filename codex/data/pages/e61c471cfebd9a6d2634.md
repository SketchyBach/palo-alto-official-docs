 dump priority-policy config policy-stacks 

 Use the dump priority-policy config policy-stacks command
to display the QoS policy sets within a stack for a device. 

 Information
displayed includes the policy stack ID, policy set names and IDs. 

 Command 

 dump priority-policy config policy-stacks all 

 Options 

 None 

 Command Notes 

 Role Super, Read Only, Monitor 

 Related Commands — 

 Introduced in Release 5.0.1 

 Example 

 dump priority-policy config policy-stacks all
 Priority Policy Stack : 15311184545800050 : 1531118454364

 Default Policy Set : 15306021021010029 : QoS DR
