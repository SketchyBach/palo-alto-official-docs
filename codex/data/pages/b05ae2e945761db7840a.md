 Telemetry in Cortex XSOAR 

 Documentation for Cortex XSOAR On-prem 8.5 (EoL). 

 Cortex XSOAR uses telemetry to collect specific usage data. This data is analyzed and used to improve Cortex XSOAR and to identify common usage to help drive the product roadmap. 

 You can limit or turn off telemetry, except for essential information according to your license type. For more information, see Configure server settings .
