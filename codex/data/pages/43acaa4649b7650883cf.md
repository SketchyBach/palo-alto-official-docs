 Add an Existing Tag to an Asset 

 Add an existing tag to one or more assets in your Inventory. 

 Perform these steps to add an existing Asset Tag (AT) or IP Range Tag (IPR) to an asset. 

 Navigate to Inventory and select the appropriate asset list view page. 

 Select one or more rows in the asset list. 

 On the Unified Inventory page, you can tag only one asset at a time. On the asset-specific pages ( Domains , Certificates , Owned IPv4 Ranges , etc) you can apply a tag to multiple assets at once. 

 Right click and select Assign Asset Tags or Assign IP Range Tags , as appropriate. 

 Click in the Add tag... field and select an existing tag from the drop-down menu. 

 Click Save .
