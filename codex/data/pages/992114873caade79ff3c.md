 ATT&CK Tactic 

 Initial Access (TA0001) 

 ATT&CK Technique 

 Valid Accounts (T1078) 

 Severity 

 Informational 

 Description 

 A user account was modified to password never expires. 

 Attacker's Goals 

 An attacker may attempt to gain access to the account. 

 Investigative actions 

 Confirm that the account is not a temporary account that could be exploited by an attacker.* Verify this action with the user who performed the change.* Ensure the organization has a strong password aging policy.
