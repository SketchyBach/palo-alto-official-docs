 Configure SafeSearch 

 Enable SafeSearch on a DNS Security profile to enforce safe search and YouTube content restrictions at the DNS layer without decrypting traffic. 

 Where Can I Use
 This? What Do I Need? 

 Strata Cloud Manager 

 Advanced DNS Security Resolver License 

 SafeSearch is a feature on internet search engines that filters explicit and inappropriate content from search results. When you enable SafeSearch on a DNS Security profile, the Advanced DNS Security Resolver automatically rewrites DNS queries for supported search engines to their SafeSearch-enforced domains (for example, google.com to forcesafesearch.google.com). This enforcement occurs at the DNS resolution stage, so it applies to all users on your network without requiring per-device browser configuration or traffic decryption. 

 The following search engines are supported: 

 Google 

 Bing 

 Brave 

 DuckDuckGo 

 Yandex 

 For YouTube, you can configure a separate restrict mode that controls the degree of content filtering: 

 Strict —Redirects to restrict.youtube.com for maximum content restriction. 

 Moderate —Redirects to restrictmoderate.youtube.com for moderate content restriction. 

 Unrestricted —No YouTube content restriction is applied. 

 When SafeSearch is enabled, the Advanced DNS Security Resolver evaluates policies in the following order: 

 Internal Domains 

 Custom Domain Groups (if the queried domain appears in a custom domain group, SafeSearch rewrite is skipped) 

 External Dynamic Lists (if the queried domain appears in an EDL, SafeSearch rewrite is skipped) 

 SafeSearch rewrite 

 Category action through Inspection Service (if you set the search-engines or streaming-media category to sinkhole or block, the category action takes precedence over SafeSearch) 

 SafeSearch supports A and AAAA DNS record types only. 

 Log in to Strata Cloud Manager . 

 Select Configuration ADNS Resolver and then go to the DNS Security Profiles tab. 

 Select an existing DNS Security profile or create a new one. 

 Select the Safe Search tab. 

 Enable Safe Search . 

 When enabled, the Advanced DNS Security Resolver rewrites DNS queries for supported search engines to their SafeSearch-enforced domains. All supported search engines (Google, Bing, Brave, DuckDuckGo, and Yandex) are enforced collectively—you cannot enable SafeSearch for individual search engines. 

 ( Optional ) Configure Restrict YouTube Access and select a Filtering Level . 

 Select a filtering level: 

 Strict (Recommended)—Enforces maximum content restriction. 

 Moderate —Enforces moderate content restriction. 

 Unrestricted —No YouTube content restriction is applied. 

 YouTube restriction is independent of the general SafeSearch toggle—you can enable YouTube restriction without enabling SafeSearch, or vice versa. 

 Save the DNS Security profile configuration.
