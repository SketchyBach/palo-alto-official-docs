 View a Catalog of Third-Party Plugins 

 SSPM provides a catalog of the plugins that are available from the various app
 marketplaces. 

 Where Can I Use This? What Do I Need? 

 Strata Cloud Manager 

 SaaS Security Posture Management license 

 Or any of the following licenses that include the Data Security license: 

 CASB-X 

 CASB-PA 

 To simplify the process of identifying third-party plugins that are security risks,
 SaaS Security Posture Management provides a catalog of the plugins. The catalog shows the
 plugins that are available from the supported marketplaces. 

 Based on the available catalog information, you can judge whether you want to allow
 the plugin in your environment. Depending on the marketplace, the catalog
 information might include the publisher of the plugin, the number of downloads, and
 the whether the plugin is currently installed. 

 Log in to 
 Strata Cloud Manager . 

 Select Configuration SaaS Security Posture Security 3rd Party Plugins . 

 Navigate to the Plugin Library tab. 

 From the drop-down, select the marketplace whose available plugins you want to
 view. 

 To view more details for a listed plugin, click on the name of the
 plugin.
