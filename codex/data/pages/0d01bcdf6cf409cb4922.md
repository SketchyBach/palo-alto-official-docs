 Cortex Cloud Runtime Security Release Information 

 Cortex Cloud Runtime Security includes Cortex Cloud Posture Management and provides additional comprehensive protection of your cloud workloads, containers, and virtual machines while they are actively running, from code to cloud to SOC. Cortex Cloud Runtime Security enables real-time threat detection, investigation, and remediation of cloud security issues across all cloud providers.
