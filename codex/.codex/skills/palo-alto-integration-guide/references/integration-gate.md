# Integration evidence gate

Before publishing steps, verify:

- Exact integration pair and supported deployment model.
- Applicable version, OS, management plane, and Preview/GA status.
- Required licenses, roles, permissions, credentials, and tenant-specific inputs.
- Network routes, domains, ports, proxy/PAC behavior, certificates, and trust where applicable.
- Exact installation or configuration sequence.
- Validation signal and expected result.
- Rollback/uninstall evidence, or an explicit statement that it was not found.

Every executable command, API request, policy value, UI path, and irreversible or disruptive action must be directly supported by an opened official page. Cite the source beside the relevant steps, not only at the end.

If sources conflict, show both scopes and dates and do not choose silently. If a page is stale for a current-state claim, refresh it or label the procedure with its documented date/version.
