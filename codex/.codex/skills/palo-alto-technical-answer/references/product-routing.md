# Product routing

Use the product name as a scope filter, not merely as a search term.

- Strata and network security: NGFW, PAN-OS, Panorama, VM-Series, CN-Series, Cloud NGFW, GlobalProtect, Strata Cloud Manager, and Cloud-Delivered Security Services.
- Prisma SASE: Prisma Access, Prisma Access Agent, Prisma SD-WAN, Prisma Browser, Autonomous DEM, Enterprise DLP, SaaS Security, Next-Generation CASB, Strata Logging Service, Common Services, and the Strata Multitenant Cloud Manager.
- Prisma Cloud: Enterprise Edition and Compute Edition use the separate official `docs.prismacloud.io` corpus. Do not substitute Cortex Cloud documentation.
- Cortex Security Operations: Cortex XDR, XSIAM, XSOAR, Xpanse, Cortex Cloud, Cortex Agentix, endpoint agents, APIs, and XQL.
- AI security: Prisma AIRS, AI Runtime Security, AI Access Security, and AI Security Posture Management.
- Identity and agent security: Idira and KOI retain their own official provenance rules.

For Prisma Access and shared SASE services, identify the management plane before answering: Strata Cloud Manager, Panorama, or multitenant management. Do not merge their UI paths. Treat renamed products and redirects as aliases only after the indexed official page confirms the relationship.
